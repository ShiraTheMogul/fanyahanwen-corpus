邯鄲淳藝經
[

藏鉤
[
编辑
]

《義陽》臘日，飲祭之後，叟嫗兒童為藏鉤之戲，分為二
曹，以校勝負。若人偶即敵對，人奇即人為遊附，或屬
上曹，或屬下曹，名為「飛烏」，以齊二曹人數。一鉤藏在
數手中，曹人當射知所在。一藏為一籌，三籌為一都。

藏鉤部藝文
[
编辑
]

《藏鉤賦》
晉·庾闡
[
编辑
]

歎近夜之藏鉤，復一時之戲望。以道生為元帥，以子
仁為佐相。思朦朧而不啟，目炯冷而不暢。多取決於
公長，乃不咨於大匠。鉤運掌而潛流，手乘虛而密放。
示微跡而可嫌，露疑似之情狀。輒爭材以先叩，各銳
志於所向。意有往而必乖，策靡陳而不喪。退怨歎於
獨見，慨相顧於惆悵。夜景煥爛，流光西驛。同朋誨其
「夙退，對者催其連射。忽攘袂以發奇，探意外而求跡。
奇未發而妙待，意愈求而累僻。疑空拳之可取，手含
珍而不摘。督猛炬而增明，從因朗而心隔。壯顏變成
衰容，神材比為愚策
​

《李白詩》：「更憐花月下，宮女笑藏鉤。」

藏鉤部紀事
[
编辑
]

《漢武故事》：鉤弋夫人少時手拳，帝披其手，得一玉鉤，
手得展，故因為「藏鉤」之戲。後人效之。

《異苑》：「晉海西公時，有貴人會，因藏鉤欻。有一手間在
眾臂之中，修骨巨指，毛色麤黑，舉坐咸驚。尋為桓大
司馬所殺。」舊傳藏鉤令人生離，斯驗深矣。

《渚宮故事》：殷仲堪與桓元共藏鉤，一朋百籌。桓朋欲
不勝，唯餘虎探在。顧愷之為殷仲堪參軍，屬病，疾在
廨，桓遣信請顧起病，令射取。虎探即來，坐定語顧云：
「君可取鉤。」答云：「賞百匹布。」顧即取得鉤，桓朋遂勝。
《酉陽雜俎》：《舊記》：藏鉤令人生離，或言古語有徵也。舉
人高映善意鉤，成式嘗於荊州藏鉤，每曹五十餘人，
十中其九，同曹鉤亦知其處。當時疑有他術，訪之，映
言但意舉止辭色，若察囚視盜也。山人石旻尤妙打
鉤，與張又新兄弟善。暇夜會客，因試其意，鉤注之必
中，張遂寘鉤於巾襞中，旻曰：「盡張空拳左。」有頃眼鉤
在張君愨頭左翅中。其妙如此。旻後居揚州，成式因
識之，曾祈其術。石謂成式曰：「可先畫人首數十，遣胡
越異辦則相授。疑其見欺，竟不及畫。」

《孔帖》：「王琚既失志，稍自放，在州與官屬小吏摴蒱藏
鉤為樂。」

藏鉤部雜錄
[
编辑
]

《荊楚歲時記》，歲前為藏鉤之戲。按周處《風土記》，醇以
告蜡，竭恭敬於明祀，乃有藏彄。臘日之後，叟嫗各隨
其儕為藏彄，分二曹，以校勝負。《辛氏三秦記》以為鉤
弋夫人所起。周處、成公綏並作彄字，《藝經》庾闡則作
鉤字，其事同也。俗云：「此戲令人生離有禁忌之家，則
廢而不修。」

《酉陽雜俎續集》：《列子》云：「『瓦摳者巧，鉤摳者憚，以黃金
摳者昏』。殷敬訓曰：『彄與摳同，眾人分曹，手藏物，探取
之。又令藏鉤，剩一人，則往來於兩朋，謂之餓䲭』。」
《海錄碎事》：段成式詩序云：「賞心樂事，不廢良辰；遷燭
投鉤，必窮永夜。」

《東皋雜錄》：「孔常甫言：唐有《藏鉤》詩云：『城頭旗鼓傳花
枝，席上搏拳掘松子』。」

《採蘭雜志》：「九為陽數，古人以二十九日為上九，初九
日為中九，十九日為下九，每月下九置酒，為婦女之
懽，名曰『陽會。蓋女子陰也，待陽以會，故女子於是夜
為藏鉤之戲，以待月明，至有忘寐而達曙者』。」

鞦韆部彙考
[
编辑
]

《荊楚歲時記》。

鞦韆施鉤之戲
[
编辑
]

《古今藝術圖》云：「鞦韆，北方山戎之戲，以習輕趫者。施
鉤之戲。以綆作蔑纜相𦊰，綿亙數里，鳴鼓牽之。求諸
外典，未有前事。公輸子遊楚，為舟戰，其退則鉤之，進
則強之，名曰鉤強，遂以時越。」以鉤為戲，意起於此。《涅
槃經》曰：「鬥輪骨輪索。」其鞦韆之戲乎。鞦韆亦施鉤之
類也。

鞦韆部藝文一
[
编辑
]

《漢武帝後庭鞦韆賦》
〈并序〉
唐高無際
[
编辑
]

臣無際才非馬融，位叨麟閣。屬祕書監博陵崔公畫鞦韆障而得一觀，皓齒蛾眉，遍於後庭鞦韆之觀樂焉。考古之文苑，惟《鞦韆賦》未有作，況鞦韆者，千秋也。漢武祈千秋之壽，故後宮多鞦韆之樂。今因睹斯畫，而善前名，臣雖不敏，謹述漢武《後庭鞦韆賦》以歌之。詞曰：

大哉漢武兮尊一人，域中無事兮天下皆春，豐比黍
​
兮欲東巡，風雨時若兮輝光日新。百寮良哉，六宮清
謐。外無金革之警，內馭玉帛之逸，王母呈益地之圖，
素女授延齡之術，河鼓效職於永巷，洛神負書而入
室。當是時也，初度禖鷰之辰，未屆親蠶之日。鬥春服，
競新裳，臨鏡臺，耀殿堂。態越千金之態，香除百和之
香。下珠樓，巡玉砌，並伍徐出，叢三連袂。照綠池而嬌
多，步晴天而影細。妍兮雅，佳兮麗，爭攀桃李之花，競
說間以紅綈。叢嬌亂立以推進，一態嬋娟而上躋。乍
龍伸而蠖屈，將欲上而復低。擢纖手以星曳，騰弱質
而雲齊。一去一來，鬥舞空之花蝶；雙上雙下，亂晴野
之虹蜺。徑如風，捷如電。倏忽顧盼，萬人皆見。香裾颯
以牽空，珠汗集而光面。時進時退，以遊以遨。類七縱
而七擒，期必高而讓高。取其至樂，靡辭其體勞。徒觀
其天仙步虛，飛鳥頡頏，飛鳥不離於羽族，天仙不舉
而自上。漢皇由是闢昭陽，臨未央，歌《虞舜》，誡幽王，知
所以失，知所以昌。察六宮之閒曠，耗五綵之衣裳。念
一朝之罷織，想十月之寒霜。俾游者有禮，乃輟而不
荒。豈茲賞之為樂，蓋欲習夫采桑。必令動也無害，何
必勞而有妨。詔宮掖，慕共姜，克勤筐篚之事，繼美《葛
覃》之章。則知漢武之德，與堯舜而齊芳。於昭聖王兮，
穆穆兮皇皇。

《雜憶》
元·稹
[
编辑

花籠微月竹籠煙，百尺絲繩拂地懸。憶得雙文人靜
後，潛教桃葉送「鞦韆。」

《鞦韆詞》
王建
[
编辑
]

長長絲繩紫復碧，嫋嫋橫枝高百尺。少年兒女重鞦
韆，盤巾結帶分兩邊。身輕裙薄易生力，雙手向空如
鳥翼。下來立定重繫衣，復畏斜風高不得。傍人送上
那足貴，終睹鳴璫鬥自起。迴迴若與高樹齊，頭上寶
釵從墮地。眼前爭勝難為休，足踏平地看始愁。

《鞦韆詠》
〈并序〉
周復俊
[
编辑
]

昔人賦《麗人行》，而近世學士亦有《鞦韆》之作，其思一也。惜詞謝雅馴，情流綺靡，君子譏之。余乃借「反騷」 以見志，而率道之以正焉。

「閨中少女怯春眠，日日行遊玉砌偏。芳草萋時花壓
谷，高臺望處柳彌川。綵絲蕩颺渾無跡，繡柱縈紆會
有緣。弱力儗攀青漢上，笑聲常寄白雲邊。鶯鳴拂澗
如爭勝，蝶舞穿林亦助憐。倏忽扶搖曾萬里，尋常軒
舉詎三千。丹褣一任丹霞落，翠帶雙飄翠葉搴。絕伎
漸驚凌幻化，纖肢宜妬為嬋娟。樓藏綠水侵珠履，陌
染飛塵上翠鈿。面藥肯隨清露泣，佩香遙借惠風傳。
倒垂度影天山竹，仰睇澄光玉井蓮。躡景偶同黃鵠
舉，憑虛聊聽紫雲旋。私危落勢頻相顧，共許輕容未
易捐。豈逐魚軒春宴後，若依鸞扇晚妝妍。」「團情團思
牽芳杜，微酒微歌近小筵。寧羨玉樓雙進斝，不窺寶
馬並搖鞭。閑寮倚幌臨明月，佳樹垂」條鎖嫩煙。蒲柳
不因涼後萎，千秋常傍此臺前。

《鞦韆謠》
薩都剌
[
编辑
]

「寒梅零落春雪灑，蕭郎腰瘦無一把。澹黃楊柳未成
陰，何人已繫青驄馬。」畫樓深處迎春歸，鞦韆影裡紅

間報風月。

《應制題鞦韆》
泰不花
[
编辑

芙蓉宮額半塗黃，雙送鞦韆過畫牆。簾底燕驚花雨

道士馬臻
[
编辑

《鞦韆》
前人
[
编辑
]

《綠窗》美人閉深院，燕語鶯啼春事半。畫欄睡足四無
人，空與東君說幽怨。綵繩裊裊挂青煙，羅襪纖纖翩
翠袖。紅粧高出牆頭花，繡帶斜飛亭際柳。香風蕩漾
春誰主？願學飛仙飛不去。黃昏溪月浸梨花，背立鞦
韆悄無語。

《鞦韆怨》
明·蔡羽
[
编辑
]

丹楯朱干傍花砌，青絲流蘇兩頭繫。葡萄結束相思
​
帶，玉釵斜挽盤龍髻。對對來尋花下繩，雙雙去作雲
間戲。難消寂寂玉樓情，可惜青青芳草地。玉樓易斷
腸，芳草令心亂。空上鞦韆架，春愁未曾斷。

《鞦韆行》
王問
[
编辑
]

「東風桃李鬥芳辰，城邊陌上啼鶯新。當窗美人罷鍼
線，並結《鞦韆》招比親。百尺長繩掛香霧，結束衫裙學
仙舉。一回蹴蹋一回高，漸絕飛塵逼清宇。幼女十五
纔出閨，舉步嬌羞花下迷。自矜節柔絕輕趫，不倩人
扶獨上梯。春意撩人重離析，每出邀懽不知夕。柳暗
沙昏未肯歸，汗濕鮫綃不愛惜。此戲曾看北地多，三」
三五五聚村娥，笑聲遠出垂楊裡。倦遊歸客意如何，
今日江南初見此。麗人如花映瑤水。金飾丹題綵作
繩，宜在君家牆院裡。

鞦韆部紀事
[
编辑
]

《東京夢華錄》：駕幸臨水殿，觀爭標錫宴，有兩畫船上
立鞦韆，船尾百戲人上竿，左右軍院虞候監教鼓笛

鞦韆部雜錄
[
编辑
]

《緗素雜記》：許慎《說文後序》徐注云：「『案詞人高無際作
《鞦韆賦》序云：『鞦韆，漢武帝後庭之戲也』。本云『千秋祝
壽之詞也』。語訛傳為秋千，後人不審本義，乃旁加『革』
為鞦韆』字。案秋千非皮革所為，又非車馬之用，不合
從革。」又《古今藝術》曰：「秋千，北方山戎戲，以習輕趫。」又
《開元遺事》云：「天寶宮中，至寒食節，競豎秋千，令宮嬪」
輩以為晏樂，帝呼為「半仙」之戲，都下士民因而呼之。

風箏部藝文一
[
编辑
]

《紙鳶賦》
唐·采
[
编辑
]

代有遊童，樂事末工。飾素紙以成鳥，象飛鳶之戾空。
飜兮將度；振沙之鷺；杳兮空光。漸陸之鴻。抑之則有
限，縱之則無窮。動息乎絲綸之際，行藏乎掌握之中。
其翰非逸，其羽乃疾。弄輕影，昂素質。侔瑞鵲之臨河，
學靈烏之就日。詭狀萬殊，奇姿匪一。衝激吹而頻驚，
入增塵而乍失。及夫晚際蕭寥，近日迢遙。出虛景，逼
「長霄。艷艷裔裔，亭亭迢迢。如片雲之初下，似殘雪之
欲銷。何裕如之囂囂，紛攜茲而翫翫。其上同綺翼之
遷喬，其下若馴騶之就喚。虞羅獲免，弦繳莫憚。野鵠
來遷而伴飛，都人相視而指看。歎乎升沉得勢，真假
相亂。殊不慚鸚鵡之被籠，蒼鷹之受絆。六鶂尚退於
宋都，大鵬猶沉於海畔。彼無識而無」知，亦曷足以見
嗤。但仰牽運，不能自為，無仙鶴九皋之響，乏晨雞五
德之奇。零落倏忽，悠揚暫時，偕鴛鴦之侶，入鳳凰之
池，向若勞力，高風莫吹，安有望於寥廓，必不出於藩
籬。且紙之所尚，事有攸往，供筆陳之樂，起詞華之賞。
故莫載於鳳文，而反圖於䲭像。因人而進，爭路而長，
固不濟於時須，欲屏之兮何爽。

「相彼鳶兮，亦飛戾天。問何能爾？風之力焉。」余因稽於
造物，知不得於自然。原其始也，謀及小童，徵諸哲匠。
蔡倫造紙，公輸獻狀。理纖篾以體成，刷丹青而神王。
殷然而髡彼羽翼，邈爾而引夫圓吭。膺繫纖縷，趾續
長繩。俯劇驂之七達，挂高臺之九層。形全而和，似鬥
雞之養紀渻；目大不睹，若異鵲之在鵰陵。因所好而
毛羽，思有遇而鶱騰。鄙宋都之退鶂，慕溟海之摶鵬。
於是扇以扶搖，縱諸寥廓。絢練倏閃，翕赫忽霍。瞬息
而上千里，咄嗟而遊大漠。翔鶤仰而不逮，況青鳥之
與黃雀。彼都人士，瞻佇城隅。初指中天之鶴，遠言拂
日之烏。望有塵埃，謂翻形而載斾；聽無音響，疑避影
以銜蘆。始迴翔於元氣，終出入於高衢。所以羽翮既
成，雲霄自致。期上騰以奮激，何中路之顛墜。力不培
風，勢將控地。感魚龍之失水，義蚊䖟之附驥。比畫虎
之非真，與芻狗之同棄。寧待時而蓄力，信因人以成
事。吁嗟鳶兮適時，與我兮相期。知我者使我飛浮，不
知我者謂我拘留。啄腐鼠兮非所好，嘯茅棟兮增至
愁。才與不才，且異能鳴之鴈；適人之適，將同可狎之
鷗。我於風兮有待，風於我兮焉求？幸接飛廉之便，因
從汗漫之遊。當一舉而萬里，焉，比夫榆枋之與《鷽鳩》
者哉！
