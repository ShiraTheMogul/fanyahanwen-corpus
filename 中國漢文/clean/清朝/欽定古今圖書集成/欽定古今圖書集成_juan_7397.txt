明二十
[
编辑
]

張元凱
[
编辑
]

按「《列朝詩集》：元凱字左虞，吳縣人。以世弁筦蘇州衛
事，再督漕北上，有功不得敘，自免歸。左虞少受毛氏
詩，折節讀書，改而從戎，非其志也。既膺世爵，屬橐鞬
挽強躍馬，顧盼自喜，冀馳騖功名之會，以洗紈褲之
辱，而卒不得一。當督漕之役，出徐淮，達燕冀，縱觀古
英雄戰爭都會之地，前迎後卻，貰酒高歌，入長安覽」
觀宮闕苑囿，親見齋宮醮壇之盛。作《西苑》詩，竊比諷
諫之義。歸而悒悒不得志，游於酒人以自放。酒間談
說天下事，慷慨風發，意有所不可。使酒罵坐，坐客皆
亡去，意自如也。善王長公兄弟暨其甥曹子念，每過
弇山園，鯨吸牛飲，推為酒人之雄。長公敘其詩，以沈
始興、曹竟陵為比，左虞夷然不屑也。左虞沒，長公伏
日曝書，得其行卷，歎其知之未盡，為詩一章，屬其子
孟孺酹而焚之殯宮。有《伐檀詩集》十二卷。孟孺亦能
詩。

童珮
[
编辑
]

按「《列朝詩集》，珮字子鳴，一字少瑜，龍游人。從其父以
粥書為業，往來吳越間。少不能從師塾，從其父挾筴
問字，輒能通曉意義。買一舫不能直項，帆檣下皆貯
書，讀之窮日夜不休。已而能為詩，清俊可誦。嘗游崑
山，執經於歸太僕，歲莫往錫山寓舍，太僕為贈序，道
其依依問學之意。久之，詩益有聲。又善攷證書畫金」
石彝敦之屬。太保朱忠僖與其兄恭靖王遣人邀至
京師，愛而欲客之，一夕遯去，弗顧。嘗與高淳韓邦憲
定交逆旅，邦憲守衢，過其家龍丘山塢中，序布衣兄
弟之誼。太守下教邑綱紀，龍丘逸民前萇後珮，其樹
綽楔左閭，以風在野，子鳴固辭，請為祠以祀龍丘先
生。邦憲卒於官，徒步送其喪，踰嶺病憊，夢太守邀與
並駕，以婚嫁未畢，辭不可。病寢，劇而卒，年五十四。子
鳴藏書萬卷，皆手自勘讎，面峻削骨立，語吶吶不出
口。篤於交誼，有所期，雖千里不爽。薄田數十畝，割其
租以創村塾。俗三男一女，捐羨粟以給舉女者。其制
行，士大夫弗逮也。余竊取子厚吏商之義，題之曰「書
賈」云。王伯穀曰：「子鳴詩皆性靈，讀之蕭蕭有雲氣。往
歲游燕山，燕山詞客如雲，所至必分曹命簡，聽漏畫
燭，爭晷刻之捷。子鳴方危坐匡床，目瞪不出聲，比誦
一篇，風調敻絕群客，氣色沮喪，子鳴退然不敢當。性
喜閉戶，必屢易而後出，出則使人彈射，往往未愜，并
其槁削之，不存一字。存者又漫置床頭，魚蠹鼠嚙之
略盡」，以是所存益無幾也。今所存《童子鳴集》，有詩四
卷，文二卷。子鳴師歸太僕，得其指授，王元美為子鳴
​
作《傳》，詳敘其生平師友，不及太僕。伯穀之志亦然。太
僕之問學，非時賢所知，亦可見矣。

李言恭
〈宗城〉
[
编辑
]

按「《列朝詩集》言，恭字惟寅，岐陽武靖王之裔孫也。萬
曆二年，襲封臨淮侯，環衛扈從，屢荷恩眷，以勳戚留
守陪京，位元戎，列師保，累年而後卒。李氏自岐陽父
子已好文墨，親近文士。惟寅沿襲風流，奮跡詞壇，招
邀名流，折節寒素，兩都詞人遊客，望走如騖。子宗城，
字汝蕃，亦有文好事。東封之役，奉使不終，家於金陵」，
賦詩結社，徵歌選妓，有承平王孫之風。惟寅詩風氣
婉弱，時有韻致。《送安茂卿詩》云：「夢回芳草遠，人去落
花多。」藝苑至今傳之。汝蕃以敏捷自誇，其佳句如《秋
夜》云：「醉後晚鐘頻入枕，夢回寒月半當樓。」《贈汪子建》
云：「夢去月明秋水闊，愁來霜逐鬢毛新。」皆可誦也。

王同軌
[
编辑
]

按《列朝詩集》，同軌字行父，黃岡人，稚欽之從孫也。以
貢生為江寧令。嘗從吳明卿出遊，與王弇州、李雲杜
善。作詩不多，自有風格，不欲寄諸公籬下，撰《前後耳
談》，纂集異聞，亦洪氏、夷堅之流也。

王宗沐
[
编辑
]

按《列朝詩集》：宗沐，字新甫，臨海人。嘉靖甲辰進士，仕
至刑部右侍郎。在比部時，王元美所謂「與同舍郎吳
峻伯、袁履善，進余於社」者也。元美《詩評》云：「天台王宗
沐，齒最卑，最擅曹中稱，自謂得初唐，未易許也。」伯承、
峻伯、新甫之詩，皆優於七子之中所稱三甫者。履善，
名福徵，華亭人。詩集甚富，每一題輒蔓衍百餘首，沓
拖詰屈。王元美嘗讌客云：「今日分賦戲作」袁履善體。
袁中郎記其事，以為笑。

況叔祺
[
编辑
]

按《江西通志》：「叔祺，字吉夫，高安人。弱冠登進士，授刑
部主事。曹署清暇，益肆力學問，與東吳王元美、南昌
余德甫游從，以聲詩相唱和。歷禮部郎中，貴州提學
副使。貴州僻處蠻方，士多質魯，弗力於學。祺至，日為
諸生講說經義，士知嚮方。攝司篆，平山寇，欽賜銀幣。
祺負才名，抗直不諧於俗，遂棄官歸，卜築藥湖之傍」，
興至買棹下章江，訪德甫諸名士，徘徊龍沙南浦間，
弔古賦詩。所著《大雅堂集》。

李蔉
〈蔭〉
[
编辑
]

按《列朝詩集》：「蔉字于田，內鄉人。嘉靖癸丑進士，選翰
林庶吉士，除檢討，左遷為南儀部郎，歷官提學副使，
罷歸。本朝以博學聞者，莫過於新都楊用修、汝寧陳
耀文。」
〈字晦伯捃拾新都之謬誤作正楊以〉
駁之。于田
多藏好學，與晦伯相埒。著《于堧注筆》諸書，援据該博。
其持論多呰毀道學，譏評氣節，而詆諆新建太過，言
多失實，論篤者弗與也。左官家居，好縱倡樂，有所狎
女優，往來汳雒間。于田微服往從之，與群優雜處。女
優登場，持鼓板為按拍。久之，群優相與目笑，漏言於
主人翁。主人翁知為李翰林，具衣冠，肆筵席，再拜延
請于田，拂衣就坐，歡飲竟日，借主人翁廄馬，與女優
連騎而去。中州人至今傳其事。弟蔭，字于美，嘉靖中
舉人，授陽穀知縣，改知宛平。風流好客，諸公皆稱之。
李北海《雲麾將軍碑石》蕪沒良鄉驛舍，裂為柱礎。襲
美輦貯邑署，名其齋曰「古墨。」為京邑令，強項執法，中
官毋殺人，捕論如法。司禮馮保以屬江陵，江陵曰：「此
令非吾所能禁也。」召之竟不往。遷戶部主事，以終養
歸于田。撰《明蓺圃集》，錄于美詩為多。

王逢年
[
编辑
]

按《列朝詩集》，逢年，字舜華，初名治，字明佐，崑山人，故
司業同祖之子也。少為諸生，試經義，多入古文奇字，
為有司所黜，往謁袁文榮公於政府，文榮以故人子
厚遇之，曰：「天子方修祠祀，新禮樂，生幸從我遊，事筆
扎，承明著作之庭，可接武也。」文榮令草應制文字，有
所更竄，退而上書閣下，以時文取科，以青詞拜相，惡
「知天下有古文哉？」不辭而去。文榮遣騎追之，不得。及
渡淮，困於旅人。淮陰人魯道者，少從李空同學詩，徒
步追舜華於逆旅，資之以歸。輯其詩曰《海岱集》，王元
美為序，盛相推挹。舜華顧時時指摘王、李詩，嗤為俗
調，元美怒而排之。舜華益自負，作五敵詩，謂「慢世敵
嵇康，綴文敵馬遷，賦詩敵阮籍，述騷」敵屈宋，書法敵
二王。著書一編曰《天祿閣外史》。妄男子，輯東漢文誤
入之，益自喜，以為當吾世得追配古人也。盡斥其田
產，市古器物，得古琴曰焦尾，謂真蔡中郎故物也。晚
年持過王敬美，曰：「老病無聊，願以此贖城南數頃為
饘粥計。」敬美唯唯受之。數日，出謂曰：「焦尾果神物也。
昨宵風清月白，焚香撫操，二元鶴從空下飛鳴盤舞，
挾之而上。少選不知所之矣，其可奈何？」舜華頫首曰：
「固宜有是。」所知惎之曰：「焦尾無恙乎？」曰：「去矣。」年八十，
無疾，端居欠伸，取所書《金剛經》捧持而逝，翛然若坐
脫者。舜華與先宮保善，余兒時猶及見之，先宮保言
其生平如是。舜華詩集甚富，余從其家鈔得之，亂後

失去。今從先《宮保遺篋》中搜得若干首
​

王伯稠
[
编辑
]

按《列朝詩集》，伯稠字世周，其先常熟人，移家崑山。父
冕，字元肅，多長者之交。王雅宜《白雀帖》所謂「元肅參
軍有精廬在虞山下，去白雀不遠」者也。世周少謝博
士弟子，肆力於歌詩，閉門擁被，悉取晉唐以下諸家
吟咀諷詠，稍間則棲止花宮蘭若，或留連狹斜旬月，
不知所之。對客不問姓字，無寒暄語。遇酒炙，放箸，大
嚼喉吻問時作囁嚅聲，竟坐或不交一言。晚年嘗過
余，投所著「樂府古詩一帙，蠅頭細字，塗乙刪改，旁行
側出，如蛛絲蚊翼，非定睛諦視，不能詳也。」其苦心於
斯道如此。王舜華為中表兄弟，其依隱傲世，略相似
焉。

按《蘇州府志》：伯稠少有俊才，父㩦之入京，見城闕戚
里之盛，輒有詠歌，時號神童。王弇州在比部，請與相
見，曰：「故是吾輩人。」會鄉試，見監試者列卒露索，遂掉
頭出，謝去舉業，肆力詩歌，悉取唐晉諸家，吟咀諷詠。
對客無寒暄酒炙，放箸大嚼，或竟坐不交一言。其依
隱傲世，雅慕孫太初之為人，而詩實過之。生平說詩
不及長慶，晚乃一省。嘗語人云：「香山有言，路人回顧
應相怪，十一年來見此翁，吾深愧此語。」卒，年七十三。

朱邦憲
[
编辑
]

按《列朝詩集》：「邦憲字察卿，上海人。父豹，字子文，官至
福州太守。邦憲性慷慨，通輕俠，急人之難甚於己，恥
為紈褲子弟及儒衣冠，呼盧挾妓，舉觥船數十不醉，
意豁如也。福州故吏官雲間者思報稱，太守為邦憲
買田宅，固辭不肯。邑令雅重邦憲，日造請其廬驩飲，
欲請間為邦憲壽，終不敢發言。令死，邦憲經紀其喪」，
千里還葬。趙尚書文華督師江南，下教邑令：故人子
朱生安在，其母夫人無恙乎？為我好致之。邑令一日
三及門，具樓船趣行。邦憲自櫂扁舟，褐衣詣督府，尚
書驩甚，握手相勞苦。酒酣，從容為言：「丈夫當乘時射
取功名，多顧金錢，庀母夫人甘毳，何用硜硜守匹夫
之節乎？」言之再至於三，邦憲三辭之。尚書歎息曰：「福
州有子，我所不逮也！」尚書敗，人無敢名為尚書客者；
邦憲為人語尚書，輒拊膺流涕，人以此益多之。邦憲
好讀書，稱詩，多長者之游，數千里內，信使趾屬於道；
所最厚善為四明沈明臣、吳門王穉登。邦憲沒，明臣
哭之過時而悲，且與穉登並為立傳。其沒也，四明余
寅移書卲御史，請祀諸瞽宗。

王寅
[
编辑
]

按《列朝詩集》，「寅字仲房，歙縣人。父賈，淮北生。仲房於
淮小字淮孺。少年俶儻自負，具文武材，以高才為諸
生祭酒，輒棄去不顧，北走大梁，問詩於李獻吉，不遇。
聞少林僧扁囤，習兵杖，最精，則之少林授其術，十得
五六。歸而盡破其產，辭家遠遊，南歷海隅，北走沙漠，
周游吳、楚、閩、越名山，求異人，冀得不死之藥，然卒無」
驗，而家益貧。海上用兵，客胡尚書督府幕客，率諂事
督府仲房嶽，嶽多所匡正，督府不能盡用，竟以敗。仲
房西入歙，鄰省賊起，土人匿不以聞。仲房馳告有司，
屬郡從事縣簿，部民兵往，賊且近，按兵不行。仲房入
軍中讓曰：「公等不扼賊於險，逗遛里中，脫賊踰嶺長
驅，他日簿責公等，其將何辭？第勒兵鼓行，賊且望風
卻矣。」我兵乃乘連嶺，賊果引去。淛兵追及之，殲焉。里
人語曰：「生自負知兵，字仲房，果不媿子房也。」中年習
禪，事古峰禪師。峰曰：「吾遍游海內五岳者三，今將遍
歷海外五岳，而後出世。」仲房聞而說之，因自號十岳
山人。

黃克晦
[
编辑
]

按《列朝詩集》：克晦字孔昭，惠安人。少好學，善畫。或謂
之曰：「君工畫不能使畫重，而工詩則畫重。」乃發憤學
詩，遂以詩名閩中。出游匡廬、嵩岳，縱觀江河泰岱之
勝，徘徊二京，遂與沈嘉則、王伯穀相上下。其歿也，晉
江黃克纘刻其詩於聊城，凡六卷。

陳鍾琠
[
编辑

按《福建通志》：「鍾琠，字石丈，晉江人。善古文詞詩歌，屢

日以讀書為事。一
日，惡頭癢，倦於梳櫛，遂去其髮，禿而加巾。卓吾所著
書，於上下數千年之間，別出手眼。而其掊擊道學，抉
擿情偽，與耿天臺往復書，累累萬言，胥天下之為偽
學者，莫不膽張心動，惡其害己。於是咸以為妖為幻，
噪而逐之。馬御史經綸迎之於通州。尋以妖人逮下
詔獄，獄詞上，議勒還原籍。卓吾曰：「我年七十有六，死
​
耳，何以歸為？」遂奪薙髮刀自剄，兩日而死。御史收葬
之通州北門外。秣陵焦竑題其石曰李卓吾先生墓，
過者皆弔焉。袁小修嘗語余曰：「卓老多病寡慾，妻莊
夫人生一女，莊歿後，不復近女色，其戒行老禪和，不
復是過也。」平生痛惡偽學，每入書院講堂，峨冠大帶，
執經請問，輒奮袖曰：「此時正不如攜歌姬舞女，淺斟
低唱。」諸生有挾妓女者見之，或破顏微笑曰：「也強似
與道學先生作伴。」於是麻黃之間，登壇講學者，銜恨
次骨，遂有宣淫敗俗之謗。蟾蜍擲糞，自其口出，豈足
以污卓老哉？余兄中郎，以吳令謝病歸，再起儀部。卓
老以謂理不當復出，為詩曰：「王符已著《潛夫論》，為問
中郎到也無？」已而中郎將抵國門，乃改前句曰：「黃金
臺上思千里，為報中郎速進途。」其於進退出處，介介
如此。人知卓老為柳下之不恭，不知其為伯夷之隘
也。卓老風骨稜稜，中燠外冷，參求理乘，剔膚見骨，迥
絕理路，出語皆刀劍上事。獅子送乳，香象絕流，直可
與紫柏老人相上下。遺山《中州集》有異人之目，吾以
為卓吾可以當之。錄其詩附於高僧之後。《傳燈》所載，
旁出法嗣，卓吾或其儔與？

憂。丙戌，苫塊中，慨然曰：「南海之墟有二越焉：於越當
其北，甌越當其南。生長台宕，席其山川，而山川不知
可乎？」於是入四明海，登普陀，轉姚江，出曹娥，走鑑湖，
上禹穴。既而渡錢塘，下桐廬，過嚴陵，入蘭溪，復東南
至永，由樂清遊鴈宕而歸。仍入天台山，結廬於華頂
桃源之麓。明年，以為三吳南龍之委也，其奇秀甲天
下，與二越稱，不可不以次舉。復發天台，過胥江，登虎
丘，入太湖，眺金焦、北固三山。至金陵九華山，自白岳
而返。戊子服闋北上，駐帆濟寧，趨曲阜觀孔子廟庭。
遂由泰安登岱宗，凡齊、魯之名山川，無不覽焉。入都，
給事禮垣，以為「漢、唐、宋五陵，曲江、艮岳、雞鳴牛首，非
百官賜湯沐之地耶？今乃束於功令，未敢越宿。出都
門，徒柱笏而望西山爽氣，人生幾何，其為消阻精神
也何限矣！」乃乘間而遊西山。是年秋，奉命典試四川，
所經燕、趙、韓、魏、宋、衛、中山之墟，無不窮覽「其名勝。」取
道華陰，遂登華岳，出寶雞，渡渭水，入益門關。試事畢，
登峨眉，題名於天門石。間道而西，復游恆岳。聞命轉
廣西參議。遂自蜀入粵，道經衡陽，復游衡岳。於是五
岳遍歷矣，皆天之假公時與地與官，以畢公志。自是
由粵藩轉滇臬副使。己丑赴粵，則有太湖山、廬山、楚
江諸記。己丑蒞粵，則有《桂海志》、「七星巖」、「獨秀山」、「訾家
洲」諸記。辛卯入滇，則有「泛舟昆明池」、「歷太華諸峰」、「游
九鼎山」諸記。庚寅行部，則有「點蒼山」、「雞足山」諸記。公
蓋無時不游，無官不游，而文章即於是燦焉耳。癸巳
陞大理寺少卿。乙未擢都察院右僉都御史，巡撫河
南。例不當辭，而公力辭，遂改南鴻臚寺正卿。公意氣
凌霄，一官為寄。天下有九州履其八。所未到者，閩耳
諸名山，自五岳而外，窮幽極險，凡一巖一洞、一草一
木之微，無不精訂。他若堪輿所述，象胥所隸，千名百
種，無不羅而致之。筆札之間，有《五岳游記》十二卷、《廣
遊志》二卷行世。析津楊體元又刻其佚稿《廣志釋》六
卷於武林。公卒於萬曆戊戌，年五十有二。子立轂，字
紫芝，中萬曆丙午鄉試，授新淦令。見「對簿」冤號，遂解
組歸。終太夫人養，即祝髮於西湖禪林。忽一日，焚沐
作偈，召徒眾，示以去來，趺坐而逝。喬、梓，蓋皆煙霞中
人歟？

林章
[
编辑
]

按《列朝詩集》：章字初文，福清人。七歲能詩，塾師試題
群羊，應聲而就。落句云：「曾從北海風霜裡，伴過蘇卿
十九年。」又《題韓文公像》云：「獨立藍關雪，回看秦嶺雲。
非干馬不進，步步戀明君。」塾師嘆曰：「此子他日必忠
而苦節者也。」世宗末，倭寇犯閩，年十三，上書督府，求
自試行間。萬曆元年，以春秋舉於鄉，累上不第。嘗走
塞上從戚將軍游，座上作《灤陽宴別序》，《酒未三巡詩
序》並就。將軍持千金為壽，緣手散去。挈家僑寓金陵。
性好公正，發憤南曹曲法，斷梗陽之獄，奮臂直之。坐
繫金陵獄三年。出獄，旅燕京十年。關白之亂，兩上書
請出海上用奇兵勦賊，報聞而已。戊戌、己亥間，礦稅
四出，逮繫相望。初，文謂「大工軍興，縣官仰屋，不當以
空言聒譟，徒激明主之禍。」抗疏請止礦稅，兼陳立兵
行鹽之策。上感動，下內閣票擬，舉行四明，相承中人
指閣其事密揭請逮治。望闕長嘆，憤懣撫膺，即日下
獄，暴病而死，天下惜之。初，文為人，經奇奡兀，抗志經
濟，謂天下事數著可了，而功名富貴可以契戾，致骯
髒忤俗，動與禍會。約略似南宋陳同甫。葉適有言：「使
同甫晚不登進士第，則亦為狼疾人而已矣。」豈不然
哉！初文二子君遷、古度，皆能詩。古度與余好，居金陵
市中，家徒四壁，架上多謝皋羽、鄭所南殘書，婆娑撫
玩，流涕漬濕，亦初文之遺忠也。古度屬鄉人徐興公
為初文立傳，而曹能始敘其詩，皆傳於世。能始拈初
文佳句，如「客情似春草，無處不堪生」、「春風與柳樹，年
年是故人」、「無家逢寺好，多病見僧親」、「春好年年晚，月
寒夜夜秋。」皆酸楚寥落，可詠可傳。吾謂閩中詩派宗
子羽，而禰善夫以橅倣蹈襲為能事。初文才情跌宕，
於唐人格律，時欲跳而去之，要能不為閩派所羈紲，
可謂傑出者也。其詩《蛾眉篇》最著，在《晉安風雅》中，不
具錄。

按《列朝詩集》，名由初名凡，字公路，嘉定人。通古今學，
好奇計。家在安亭，有田數百畝，僮僕數十人，一旦盡

足跡不至縣庭，向之笑者皆嘆慕焉。平居好論兵，其
於古人勝敗之數，必求其所以然。北歷燕、趙、齊、魏之
​
郊，登眺山川形勢，問昔人城郭營陣之處，往往悲歌
慷慨，恨不馳驅其間。萬曆申辰，年七十有九，嘔血屬
疾。以其詩四百餘篇，屬同里唐叔達序之公路。同時
有張應、武茂仁、丘集、子成，皆宿學老儒。茂仁好談經
濟，以龐德公、司馬德操自命。而子成精於《三禮》，古今

按《浙江通志》：「尚忠，字世卿，浦江人。萬曆戊戌進士，授
廣東順德令。誠篤慈祥，粵故多盜，大辟以下恆薄懲。
邑人以為言，忠曰：『使其能改，何過督為』？乃著《宣化錄》
以勵民，風遂丕變。尤博學，工古今文詞詩，登大曆之
選，而精鑒知人。先是順稱下邑，科第寂寥，忠日進士
課藝文，取資敏者拔之。嗣即春秋二榜不絕。躋顯仕」
者，先後得二宗伯，人比之文翁云。萬曆中，設採珠廠，
閹使橫甚，所及者身家立盡。忠下令邑中，見有珠廠
勾役，杖而禁之。時有傾害及孝廉某者，執其甲首置
之獄。閹怒，欲疏劾，眾懼禍不測。忠曰：「吾令一邑，不能
為一邑驅豺虎。吾罪較豎更甚。」力言制、按兩院，得奏
罷。採亦竟以是與邑豪紳忤。遷吉州府同知。會母老
疾，致仕歸。邑人追思不已，更為祠祀之。所著有《居雲
草》《鳴籟草》《宣化錄》《學製編》數十萬言。年八十端坐而
逝。
