明十七

楊瀾
[
编辑
]

按《台州府志》：「楊瀾，字東之，號若山，為郡諸生，以謹慎
聞。父母性嚴且好客，瀾事之惟謹，每客至，必極力營
脩。醑父後喪明，瀾左右扶持，曲意取歡，愈久弗懈。撫
諸弟妹有恩，每以己貲給公費。父悅之，謂諸子曰：『汝
兄，孝子也』。一日，置酒侍父，忽遘寒疾卒，人咸傷之。」

陳大名
[
编辑
]

按《台州府志》：「陳大名，字子顯。父萬伯，以事卒於杭。大
名扶櫬歸，重不可行，夜宿神廟，禱曰：『大名力殫財盡，
願輕而易舉』。質明果輕。柩下有鈔十錠，人以為神所
錫。歸葬，廬於墓側，朝夕悲號，不茹葷者三年。後以薦
任豐城知縣。」

余啟
[
编辑
]

按《台州府志》：余啟，字元明。幼失怙，事其母鄭，克盡色
養。時家有滇南之役，二兄議行未果，啟毅然曰：「二兄
​
皆有嫂氏，不可行，吾當代之行。」備嘗艱苦，閱三年乃
返。

林元
[
编辑
]

按《台州府志》：「林元，字用白，性至孝。年十三，父病，醫者
莫能療，元刲股作糜以進，夜則稽顙北辰，願以身代。
越數日，父病良已，刀痕亦隨以復，人謂孝感所致。居
常供養之需，皆潛自營辦，不令父母知其難也。會歲
饑，富家射利閉糶，乃攜古器物往他縣易米，即負歸
以供二親，如是往返者凡數四。比秋則喜曰：『吾父母
自今可保無虞矣』。」二親卒，頓擗幾絕。既葬，月朔必至
墓所，號慟徘徊不忍去。李都憲匡為作《孝子傳》。

張疇
[
编辑
]

按《台州府志》：「張疇母徐，年八十六，病床褥者三載。疇
旦夕扶持至以手掬其穢衾裯，必日澣之，令潔乃已。
以貢授六合教諭。」

蔡智榥
[
编辑
]

按《台州府志》：「蔡智榥，字元丌，天性孝友，甫十歲，母卒，
哀毀如成人。父有疾，躬調湯藥，衣不解帶。父卒，奉祖
母備極甘旨，晨昏定省，數十年如一日。其先五世合
食，既而中析，智榥乃與弟智諍，承其父志，合族人數
千指，同居共爨。尤輕財樂施姻戚，貧者賑之，死者葬
之。立塾延師，以教里人子弟，歲出粟數百石，代之輸」
虛稅，義聲翕然。

應練
[
编辑
]

按《台州府志》：「應練，字茂習。天性至孝，事父母無疾言
遽色，飲食必躬饋，晨昏定省無少懈。父母有疾，惶懼
求藥籲天，祈以身代。卒則哀號幾絕，不食者三日。居
喪一循古制，三年閒泣血不止。親墓產瑞芝盈把，人
謂孝誠所感云。」

李翀
[
编辑
]

按《台州府志》：李翀，幼習禮經，父清，宿州判官，卒於任。
翀扶柩還，盜欲剖之，翀叩頭流血曰：「破吾柩，寧破吾
腹。」盜感其孝，奪衣裳而去。母陶氏，遘危疾，醫謂非人
肉不療，翀刲股作羹以進之，母疾漸蘇。比卒，苫塊一
如禮。歲時忌日，必齋素涕泣，自號其室曰「思齋。」陳太
守勉以哀不可過，更曰「輟思，作《孝行傳》紀之。」

丘鐔
[
编辑
]

按《台州府志》：「丘鐔蚤喪母，事父極孝。父年高無齒，鐔
取魚肉之精美者，製為丸餅以進。比父卒，遺命葬祖
塋側。去家遠而歲歉費鉅，鐔極力營葬，卒如父命。鄉
人稱其孝云。」

戴守溫　洪美
[
编辑
]

按《台州府志》：「戴守溫，名瑱，少孤，事母極孝。母病，醫者
曰：『得鯽魚和劑可愈』。時隆冬，守溫解衣入水，捕得之，
服果愈。母沒，哀毀過常，尋以疾卒，貧無以葬，邑令袁
公道為營塚窆於小唐嶺之側，題其墓曰：『方岩之北，
唐嶺之南，孝子之風流千百年』。同時有洪美者，泉溪
人也，嘗割股以愈母疾，袁公嘗舉充鄉飲賓云。」

章士麟
[
编辑

按《台州府志》：「章士麟，字祉盛。少篤孝義，慕陽明先生
學，凡言動取與，無不準諸道義。廬墓三年，時切哀號。
忽墓產異竹同本，而生人以為孝感所致。」

袁洵

编辑

按《台州府志》：「袁洵，號月川。父沒，母哭病目，洵供湯藥

出所有衣食之，以安母心。一時族黨無間言。屢舉鄉

楊錞
[
编辑

按《衢州府志》：「楊錞，添之曾孫。兒戲即習定省儀，長不

​

割股和饘粥以進，遂愈。親沒，執喪哀，葬祭以禮，鄉里
以為難。大學士商輅為作墓銘。」

達監察御史。」

汪璉

終始不懈，喪祭悉循家禮。鄉黨言孝，必以璉為首，稱

劉怡

按《衢州府志》：「劉怡，父疾，不能動履二十餘年，率其季

方惟豪

禱福南華。又刲股餌飲，母疾遂愈。」

徐公遷

方希成

婦汪氏曲盡孝道。母終，哀毀，寢柩側，葬祭咸如禮。」

龔曇
[
编辑
]

按《金華府志》：「龔曇，字汝霖，性至孝。年十七，因父演病，
躬侍湯藥，衣不解帶。比卒，哀毀，殯葬如禮，事母尤謹，
幾四十年。母卒，廬墓苫塊，饘粥奠獻，悲號，三年如一
日。有司以孝聞，詔旌表其門，賜八品官，復其家。後配
享永慕廟。」

倪大海
[
编辑
]

按《金華府志》：「倪大海，祖病，日夜侍奉不離側，焚香告
天，願減己齡以延祖壽。後祖年逾九十乃終，大海哀
毀踰禮，廬墓三年。繼母李患癰，吮之而愈。及沒，廬墓
三年。值歲饑，餓者施粥，死者施棺，仍割田儲廩，賙其
族人。有司具奏，旌其門曰『孝義』。」

王世名
[
编辑
]

按《金華府志》：「王世名，字時望，幼有大志，言動以古人
自期。萬曆丙子，年十七，其父為族人毆死，訟於官。欲
檢其父屍，不忍，欲即死以報，不可。不得已，與讎和受
讎百金，及諸所贈遺，一一封置，繪父小像，己佩刀侍，
懸之密室，朝夕焚香泣拜，鑄一刀，銘之曰『報讎刀，集
《忠義格言》一冊以自勵。三年，補邑弟子員。又三年得』」
子，喜曰：「吾可以死矣。」一日紿讎入蝴蝶山，揮刀斬其
頭祭父，取前所封置，詣官請死。官憐其孝，欲檢其父
屍以生之世名曰：「吾不忍毀父屍至此。」遂以首觸階，
濺血赤地死，面色如生。是日風雷大作，滿城哭聲震
天。金華縣令汪大受為之立傳。其妻俞氏，矢志同穴，
撫孤三年而殉之。事聞詔下，旌其門曰「孝烈之門。」府
從祀鄉賢，縣有專祠，縣令陳公大烈表其里曰「孝里」，
大司寇王鳳洲為之傳。

朱助
[
编辑
]

按《金華府志》：「朱助，字士貞，天性孝友，母卒，廬墓孝感
三異，家燬回祿，而師萊堂匾出，煨燼若新，一也；盆柏
蒼枝，致黃鳥馴而不驚，二也。家有母大病瘡，其兒銜
食食之，三也。兄士安，謪戍麻陽，歲具衣錢供給，每出
粟貸貧，不收其息，里中有甲當償乙者，輒代償之，其
他善行亦多。」

潘琢
[
编辑
]

按《金華府志》：「潘琢，字時循，純孝鄉人。性孝友，不私妻
子。父喪，毀瘠骨立，酒肉不入口者三年。母患瘋痺，琢
衣不解帶，痒痾痛楚，隨意搔摩，梳洗火水皆親理之。
母久臥思起，乃制軟輿與弟舁之，惟其所適，如此者
七年。母沒，哀痛幾死，既葬，廬墓九年，人皆稱其克盡
子道云。有司延為鄉飲大賓，匾其門曰『孝行』。」

王晁
[
编辑
]

按《金華府志》：「王晁，字公亮，居貧，養親誠至。母卒，廬墓
三年。知縣張立嘗雪夜往察之，果見嗚咽僵臥，大加
嘆賞，給俸助之，聲稱大著。太守劉𦶜大書『孝行之門
旌之，仍復其家丁役』。」

===金洪===
​
按《錢塘縣志》：金洪，馨如，里人。竭盡孝敬。嘗割胸肉愈

母疾。及沒，刻木像，工人以血料塗塑。洪曰：「奈何以豬
血污母身？」刺胸臂血盈盂，周塗其像，朝夕奉祀，一如
生時忌日，悲號，哀動鄰里。

邵允宜
[
编辑
]

按《富陽縣志》：「邵允宜，字仙谷，性純孝，甫離提抱，即能
循古孝子禮，扇枕溫衾，父母異之。髫齡失恃，事繼母
如母，遇鮮果進母啖乃敢嘗。父五泉鄉進士，仕華亭
雲和，教允宜綜理家事，課臧獲，勤耕織，賴以克濟。及
父歸田，家居二十年，念親耄，咫尺不離，酷暑嚴寒，潛
侍親床側，候親熟寐乃休，親謦咳，又在旁問安。服父」
喪，年已六十有五，苫塊不御酒肉三年幾骨立。子二，
長起元早卒。允宜教孫尤篤，以孝友讀書傳家為法。
其急人之難，焚券契，完人夫婦，祲歲開廩賑饑，村落
全活，不至為亂。皆曰：「賴有孝子到今。」人猶思之。

陳弘志
[
