王來
[
编辑
]

按《明外史王來傳﹕》：「來字原之，慈谿人。宣德二年，以會
試乙榜，授新建教諭。用薦擢御史，巡按蘇、松、常、鎮四
府。英宗即位，再以薦擢山西左參政。來居官廉，練達
政事，然疾惡過甚，為巡按曹泰所劾，當徒。遇赦，以原
官調廣東，遷河南左布政使。十四年，改左副都御史，
巡撫河南及湖廣襄陽諸府。景泰元年，貴州苗韋同」
烈作亂，進來右都御史，總督軍務。事平，召為南京工
部尚書。英宗復辟，六尚書罷，來歸，卒于家。

王璘
[
编辑
]

按《太倉州志﹕》：「璘，字廷用，任鎮海衛指揮僉事。宣德二
年，交趾梗，命將往討。同衛周指揮年老在選，璘毅然
請代行。從安遠侯柳昇抵昌江，戰屢捷。深入，會大雨，
泥扤馬足，死之。」

王琰
[
编辑
]

按《襄陽府志﹕》：「琰字良璧，棗陽人。由進士授行人，陞監
察御史，巡按蘇松，有聲。吳地號難劇，琰清心竭慮，遍
訊輿臺，巨奸宿蠹，一剔而盡。生平清苦，人所不堪。宣
廟時，以直諫杖斃。」

王元弼
[
编辑
]

按《龍巖縣志﹕》：元弼，宣德間，沙寇刦巖，元弼與林洪中
謀請師要其去路。至上坪遇賊，度力不支，與兄用興
匿山中。賊知其謀，必蒐殺乃已。元弼決于兄曰﹕：「我有
三子，且兄子獨幼。今兄弟不能兩全父母，雖老兄在，
吾無憾焉。」兄難之，次日不令兄知，奮出犯賊而死。

王偉
[
编辑
]

按《明外史于謙傳﹕》：「王偉，字士英，攸人。隨父謫戌宣府。
年十四，宣宗北狩，獻《安邊頌》，命補保安州學生。舉正
統元年進士，改庶吉士，授戶部主事。英宗北狩，命行
監察御史事，守廣平。謙重其才，引為職方郎中。又以
謙薦，超擢兵部右侍郎。偉喜任智數，既為謙所引，而
朝臣多嫉謙。與謙善者率目為朋附。偉乃伺謙誤，密」
奏之。然竟坐謙黨罷歸。成化三年復官。五年病歸，卒。

王晟
[
编辑

按《鄆城縣志﹕》：「晟字景昭，邑人。正統丙辰進士，初授刑
部主事，陞員外郎。英敏剛直，鞫獄平恕。陞浙江按察
司僉事，專理山場銀課。時麗水、青田諸縣山賊陳鑑
湖等哨聚刦掠，晟召募勇敢，殺賊數百人。已而賊勢
復張，官兵不能支，晟被執，罵賊不屈，賊刺晟于破橋。
事聞，朝廷遣官諭祭，贈江西布政司參議，官一子。」

王俊

按《明外史王俊傳﹕》：「俊，城武人。父為順天府知事。母卒

王竑
[
编辑
]

按《明外史王竑傳﹕》：「竑字公度，其先江夏人。祖俊卿，坐
事戍河州，遂著籍。竑登正統四年進士，十一年授戶
科給事中，豪邁負氣節，正色敢言。英宗北狩，郕王攝
朝午門，群臣劾王振誤國，請族振。錦衣指揮馬順者，
振黨也，厲聲叱言者去。竑怒，奮臂起，與眾共擊之，立
斃。王恐，遽起入，竑率群臣隨之。王使中官問所欲言」，
曰﹕：「內官毛貴、王長隨亦振黨，請寘于法。」遂出二人，眾
又捶殺之，竑名震天下。王即位，會也先入犯，命竑守
禦京城。擢右僉都御史，督毛福壽、高禮軍。寇退，詔竑
鎮守居庸。景泰元年以疾還朝。明年出督漕運，兼巡
撫江北四府及徐、和、滁三州。明年兼理兩淮鹽課，就
進右副都御史。英宗復辟，革巡撫官，改竑浙江參政。
石亨、張軏追論竑擊馬順事，除名，編管江夏。居半歲，
帝於宮中得竑疏，見正倫常、篤恩義語，因感悟，命歸
里。天順五年，孛寇莊浪，都督馮宗等出討。乃用李賢
薦，起竑故官，參贊軍務。師還，仍令督漕撫淮、揚。憲宗
即位，六科給事中、十三道御史薦竑堪大用，召為兵
部尚書。引疾求退。初，竑號其菴曰「戇。」既歸，改曰「休。」杜
門謝客，家食二十餘年，至弘治初卒。正德間，諡《莊毅》。

王宇
[
编辑
]

按《明外史王宇傳﹕》：「宇字仲宏，祥符人。登正統四年進
士，授南京戶部主事。秩滿當轉郎中，吏部以宇才，特
用為撫州知府。為政簡靜，一府大治。天順元年，超擢
山東右布政使。明年遷右副都御史，巡撫宣府。遭喪，
起復為大理卿，固辭不許。宇剛介，所至有盛名。居大
理，平反為多。七年卒。」

王驥
[
编辑
]

按《名山藏勳封記﹕》：「靖遠伯王驥，束鹿人。正統七年，以
兵部尚書總軍雲南，勦平麓川寇，封推誠宣力武臣、
特進榮祿大夫、柱國伯，祿千二百石，身免一死，子孫
世指揮同知。八年，復征麓川，擒獲黨賊者六十餘人。
九年，加祿米三百石。十三年，總督軍務，征勦孟養。賊
子思機發，首奪金沙大江，攻破賊柵，擒獲賊黨。十四」
年勦殺湖、貴苗賊首划平王。景泰元年予世加，祿米
百石，賜券。天順元年改封奉天翊衛、推誠宣力守正
文臣、特進光祿大夫、柱國，加祿百石，凡伯。十一年卒，
贈侯，予諡。子瑺嗣。成化七年，添嗣。十九年，憲嗣。正德
十年，瑾嗣。萬曆元年，學詩嗣。卒亡子。四年，弟學禮嗣。

王復
[
编辑
]

按《明外史王復傳﹕》：「復字初陽，固安人。正統七年進士。
授刑科給事中。聲容宏偉，善敷奏，擢通政參議，遷右
通政，再遷通政使。天順中，歷兵部左右侍郎。成化元
年進尚書，出視陝西邊務，在邊建置，多合機宜。及還
朝，言者乃謂治兵非復所長，改工部。十四年加太子
少保。復好古嗜學，守廉約，與人無城府，當官識大體。」
會災異，給事中張海等劾復衰老，令致仕歸。久之卒，
諡「莊簡。」

王概
[
编辑

按名山藏《分藩記﹕》：「概，廬陵人。正統壬戌進士。起家刑

大理寺卿，刑部尚書。概所歷多，在法司，精習律比，了
決無宿案。卒諡恭毅。子文，年十六，舉進士，以翰林出
為參政。」

王恕
[
编辑
]

按《明外史王恕傳﹕》：「恕字宗貫，三原人。正統十三年進
士，選庶吉士，出為大理右評事，進左寺副，遷揚州知
府。天順四年，以治行最，超遷江西右布政使。成化初，
南陽、荊襄流民嘯聚為亂，擢恕右副都御史撫治之。
會丁母憂，詔奔喪兩月即起視事，恕辭，不許。與尚書
白圭共平大盜劉通，移撫河南，錄功進左副都御史」，
遷刑部右侍郎。父憂，服除，以原官總督河道，旋改南
京戶部左侍郎。十二年，大學士商輅等以雲南遠在
萬里，議遣大臣有威望者為巡撫，乃改恕左副都御
史以行，就進右都御史，召掌南京都察院，參贊守備
機務。遷兵部尚書。考選官屬，嚴拒請託，同事者咸不
悅。而錢能屢譖恕於帝，帝亦銜恕數直言，遂命兼右
副都御史，巡撫江南。二十年復改南京兵部尚書。恕
先後應詔陳言者二十一，建白者三十九，皆力阻。權
倖。貴近皆側目，帝亦頗厭苦之。會南京兵部侍郎馬
顯乞罷，忽附批「恕致仕。」孝宗即位，用廷臣薦，召入為
吏部尚書。是時丘濬入閣，與恕不相能。太醫院判劉
文泰者求遷官，為恕阻，銜之。文泰故往來濬家，知濬
​
忮恕，因劾恕。恕遂求去。正德三年卒。諡《端毅》。

王得仁
[
编辑
]

按《明外史王得仁傳﹕》：「得仁，名仁，以字行，新建人。本謝
姓，父避讎外家，因冒王姓。得仁初為衛吏，以才薦，授
汀州府經歷，廉能勤敏，上下愛之。秩滿當遷，軍民乞
留再任。居三年，推官缺，英宗從軍民請，就令遷擢，數
辨冤獄，政績益著。鄧茂七黨陳景政等攻城，得仁與
知府劉能擊敗之，擒景政等八十四人。兵事未解，忽」
遘疾卒，時正統十四年冬也。

王振
[
编辑
]

按《明外史王振傳﹕》：「振，蔚州人。少選入內書堂，侍英宗
東宮，為局郎。初，太祖禁中官預政，自永樂後漸加委
寄，然犯法輒置極典，中官以是畏法。及英宗立，年少，
振狡黠，得帝懽，遂掌司禮監。以帝未習政事，慮文臣
欺蔽，勸帝用重典。于是大臣下獄者不絕，而振因以
市權。帝方以天下事聽振，威福刑賞莫由朝廷，公使」
勛戚呼曰：「翁父。」遷擢視金多寡。振自謂威無不加，遂
構釁瓦剌。正統十四年，其太師也先以二子入貢馬，
號三千。振以為詐，減馬直，其使者恚而去。秋七月，也
先遂大舉入寇，振挾帝親征，廷臣交諫，弗聽。次土木，
瓦剌兵追至，師大潰，帝蒙塵，振亦為亂兵所殺。

王克復
[
编辑

按《福州府志﹕》：「克復，字師仁，福清人。天順丁丑進士，歷

王鑑
[
编辑
]

按《明外史楊瑄傳﹕》：「天順初，十三道御史張鵬、盛顒、周
斌、費廣、張寬、王鑑、趙文博、彭烈、張奎、李人儀、邵銅、鄭

怒，下諸御史于獄，搒掠備至，且詰主使者。會大風震
雷，帝感悟，戍瑄、鵬鐵嶺，餘貶知縣。鑑，太原人，進士，授」
御史。降知膚施，有善政。憲宗嗣位，所司以《治行》聞。擢
延安守，特賜封誥。

王一夔
[
编辑
