周禎
[
编辑
]

按《明外史周禎傳》：「禎字文典，江寧人。元末，流寓湖南。
太祖平漢，用為江西僉事。吳元年，進大理丞，旋為卿。
洪武元年，設刑部，以禎為尚書，尋改治書御史，出為
廣東行省參政。二年，復召為刑部尚書，尋引疾致仕。」

周湞
[
编辑
]

按《明外史周禎傳》：「周湞，字伯寧，鄱陽人，江西十才子
之一也。官至刑部尚書。」

周觀政
[
编辑
]

按《明外史韓宜可傳》：「洪武初御史，以敢言著者。周觀
政，山陰人，以薦授九江教授，擢監察御史，累官江西
按察使。」

周顛
[
编辑
]

按《明外史周顛傳》：「顛，建昌人，無名字。年十四，得狂疾，
走南昌市中乞食，語言無恆，人呼之曰顛。年三十餘，
忽有異狀，長官初至，必入謁曰：『告太平』。當是時，天下
猶寧謐，人莫測其所謂也。及太祖克南昌，顛謁於道
左。洎還金陵，顛亦隨至。一日駕出，顛來謁，問：『此來何
為』？曰：『告太平』。自是每出，輒以是告太祖。久而厭之，命」
覆以巨缸，積薪煆之，薪盡火息，啟缸視，則顛凝然無
恙，命寄食蔣山寺。太祖親征陳友諒召問曰：「此行可
乎？」對曰：「可。」太祖攜與行，顛見江豚戲水，忽曰：「水怪見
損人多。」太祖惡之，命投於江。及師至湖口，顛復來見，
且乞食，太祖益異之，既與食，即辭去。太祖殪友諒，遣
使往廬山物色之，不得蹤跡，疑其仙去云。

周忠
[
编辑
]

按《江西通志》：「忠字伯厚，金谿人。太祖兵起，忠力勸王
溥歸命。甲辰，召見青龍殿，奏對稱旨，寵賜優渥。從征
湖廣，命參謀左右。己酉，復獻《太平十六策》，上嘉納。尋
使沙漠，不知所終。」

周德興
[
编辑
]

按《名山藏勳封記》：「江夏侯周德興，鳳陽人。從渡江，取
金華、安慶、高郵、安豐、合肥、贛安、福水、新自提兵拔安
​
吉、西安。洪武三年，授開國輔運推誠宣力武臣，榮祿
大夫、柱國、侯，祿千五百石，賜誥券。與誓身免二死，子
一死侯。二十三年，坐帷薄不修，論死除。」

周武
[
编辑
]

按《名山藏勳封記》：「雄武侯周武，開州人。從取江南，累
功都督僉事，屬西平侯，討平西蕃洮州戎。洪武十二
年，授開國輔運推誠宣力武臣，榮祿大夫、柱國侯，祿
二千石，指揮使。賜券與誓免二死，卒竟除。」

周丹
[
编辑
]

按《萬姓統譜》：「丹，永嘉人。洪武初進士，授新化縣丞。在
官以廉勤，門無私謁，吏卒不敢欺。驗民貧富及丁稅
多寡，第為上中下，籍記之。遇有賦役，隨輕重使之，故
民不擾而事易集。至於獄訟文牘之務，皆躬理之，吏
胥不得為奸。罷諸役作，民晏然安業，由是流民之歸
者益眾。滿考課最，陞考功主事。」

周榮
[
编辑
]

按《萬姓統譜》：榮洪武間河南知府，遇事果斷。洛陽民
婦張氏失綿線，不知盜名，訴于府。榮密謂之曰：「汝但
歸焚香罵府官，不為我捕盜，有嗔怒者即以聞。」張如
其言，不二日，果有嗔者，一問即伏，府中稱為神明。

極諫，書奏報聞。」

周新
[
编辑
]

按《明外史周新傳》：「新，南海人，初名志新，字日新。成祖
常獨呼新，遂為名，因以志新字。洪武中，以諸生貢入
太學，授大理寺評事。成祖即位，改監察御史，敢言多
所彈劾，貴戚震懼，目為冷面寒鐵。巡按福建，改按北
京。還朝，擢雲南按察使。未赴，改浙江錦衣衛指揮。紀
綱使千戶緝事浙江，招搖攫賄，新欲治之。千戶脫走」，
訴於綱，誣奏新罪。帝怒，命逮之。在道搒掠無完膚。既
至，伏陛前抗聲辨。帝愈怒，命戮之。

周琬
[
编辑
]

按《明外史周琬傳》：「琬，江寧人。洪武時，父為滁州知州，
坐罪論死。琬年十六，叩閽請代。帝疑受人教，命斬之，
琬顏色不變。帝異之，命宥父死，謫戍邊。琬復請就死，
以贖父戍。帝復怒，命縛赴市曹，琬色甚喜，帝察其誠，
即赦之，尋授兵科給事中。」

周是修
[
编辑

按《明外史周是修傳》：「是修名德，以字行，泰和人。洪武
末，舉明經，為霍丘訓導，擢周府奉祀，遷紀善。建文元
年，改衡府紀善。衡王，建文帝弟，未之藩，是修留京師，
預翰林纂修。京城失守，入應天府學。拜先師畢，自經
于尊經閣。福王時，諡貞毅。」

禦計。吏民逃散，度不可為，懷印南奔，糾義旅勤王。聞

等，當皇上舉兵靖難，俱棄職逃亡，宜寘諸法』。詔令遣
戍。有司械縉至，謫興州。居數年，子代還，年八十而沒。」

周忱
[
编辑
]

按《明外史周忱傳》：「忱字恂如，吉水人。永樂二年進士，
選庶吉士，擢刑部主事，進員外郎。忱有經世才，浮沈
郎署二十載。洪熙間，稍遷越府長史。宣德五年，帝以
天下財賦多不理，而江南為甚，乃用大學士楊榮薦，
超遷忱工部右侍郎，巡撫江南諸府，兼督稅糧。正統
初，敕兼理松江鹽課，以九載秩滿，進左侍郎。忱素樂」
易，既久任江南，與吏民相習，若家人父子。雖卑官冗
吏，悉開心訪納，故事無不舉。奸民尹崇禮欲撓忱法，
奏忱不當多徵耗米。忱劾奏崇禮罪，寘之。詔獄舉行
如故。再以九載滿秩，進戶部尚書。尋以江西人不得
官戶部，乃改工部，仍巡撫。景泰元年，溧陽奸民彭守
學復訐忱如崇禮言。明年又以給事中金達言，召忱
還朝。言官交章劾忱。景帝素知忱賢，大臣亦多保持
之者，但令致仕而已。景泰四年卒。諡「文襄。」

周述　周孟簡
[
编辑
]

按《明外史曾棨傳》：「周述，字崇述，吉水人。永樂二年，與
從弟孟簡並舉進士及第，並授翰林編修，讀書文淵
閣。述累進左春坊諭德。宣宗時，進左庶子，正統初卒。
孟簡在翰林二十年，始遷詹事府丞，出為襄王長史。
述溫厚簡靜，未嘗疾言遽色，文章雅贍。孟簡謙退不
伐，生平無睚眥于人，並為世所重云。」

周瑛
[
编辑
]

按《萬姓統譜》：「瑛，莆田人。其立志欲求見聖人之一貫，
而必欲由博以反于約，于是肆力于百家群藝，事必
為之。所教人先于靜，得必隨事窮理，求其自然與其
當然，又會其所以然，積累既多，于融貫處亦自得之。
官至布政使。」

周子良
[
编辑
]

按《萬姓統譜》：子良，錢塘人。舉人材，授永清縣主簿。永
樂己丑，應求賢之詔，陞苑馬寺丞，改工部主事，遷兵
部郎中。苦節自持，數鬻產以支宦費。宣德間，山東清
理軍伍，方歲饑，民流離，奏乞俟豐年，許之。以疾賜致
仕，作小軒曰「樂稼」，棲遲乎中者二十年。正統丙寅，壽
八十卒。人皆稱其廉簡謹重。所著有《樂稼詩稿》。

周瑄

编辑

按《明外史周瑄傳》：「瑄字廷玉，陽曲人。由鄉舉入國學。

元，遷右都御史，督理南京糧儲，捕懲作奸者數輩，宿
弊為清。久之，遷南京刑部尚書。屢疏乞休，得請。家無」
田園，卜居南京。卒諡「莊懿。」子紘，成化進士，為南京吏
科給事中，仕終山東參議。

周賢
[
编辑
]

按《明外史周賢傳》：「賢，滁人。襲宣府前衛千戶。景泰初，

參將。天順初，總兵官楊能奏擢都督僉事。能以寇駐
塞下，檄賢與大軍會。失期，徵下獄，以故官赴寧夏，隸
定遠伯石彪。寇騎入安邊營，彪率賢等擊之，連戰皆
​
捷，追至野馬澗半坡墩，寇大敗，而賢追不已，中流矢」
卒。

周洪謨
[
编辑
]

按《明外史周洪謨傳》：「洪謨，字堯弼，長寧人。正統十年
進士及第，授編修。博聞強記，善文詞，熟國朝典故，喜
談經濟。景泰元年，疏陳時務十二事，再遷侍讀。成化

鑒自縊。寧夏兵再亂，廷徵以孤騎入營撫定之；仍九
