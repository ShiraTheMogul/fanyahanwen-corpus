李向妻郭氏
[
编辑
]

按《山西通志》：「郭氏，絳人，郭郊女，諸生李向妻也。向以
疾亡，郭即自經，未遂。越三日，夫殯之夕，復以衣帶繫
頸，潛入園內，墜井死，頭埋淤泥尺許。」

姚在陛妻胡氏
〈李氏附〉
[
编辑
]

按《山西通志》：胡氏，生員姚在陛妻，子翼宸為諸生，娶
​
李氏。甲申闖逆將至，胡氏謂媳李曰：「賊熾甚，倘不免，
奈何？毋寧先死。」遂以襁褓幼子囑付乳姆，姑媳相繼
投井而死。

馬從麒妻甯氏
[
编辑
]

按《山西通志》：「甯氏，馬從麒妻，生員毓秀女。夫亡無子，
年二十，誓不再嫁。甲申逆闖屠城，投井死。」

[
编辑

〈女附〉
[
编辑

按《山西通志》：「馬氏，趙知二妻，同知汝驊次女。夫亡，氏
年二十二，無子，止一女，立姪開圻以繼夫嗣。事孀姑
盡孝，撫子入庠，孀居五十餘年。有司旌其門。甲申闖
賊攻城，將陷，氏與女魯參政妻，同自經死。」

裴潤妻范氏
[
编辑
]

按《山西通志》：「范氏，生員裴潤妻。夫亡，遺四女一子，子
希度方五歲，氏哀毀，屢欲投繯，四女抱幼子環泣，日
夜哀請，得不死。苦節二十載。課希度登進士，授堂邑
令。每出氏誨，以省刑卹民，潔己報國。秩滿，封太孺人。
崇禎癸未，以母節奏聞，奉旨建坊，未及舉行。逆闖逼
犯太原，氏抱幼孫避北城別墅。城陷，呼老僕以幼孫」
付之，投井死。

[

罵猶不已。賊稱其烈，釋之，尋死。」

牛氏女
[
编辑
]

按《蒲州志》：牛氏女許劉愷為繼妻。愷客外娶衛氏，生
一子。衛亡，愷父母聘牛，女預迎歸。愷扶衛櫬旋里，中
途被害，幼子釗與雙棺並返。牛撫釗若己出，事愷父
母至孝。服禫，父母謂曰：「汝處子未識夫面，豈真劉氏
婦耶？」遂陰納施氏聘牛女聞，哀痛幾絕，三日不食。死
後釗成立，生忠甫，忠甫生東旭，不忘牛恩，三世廬墓。

孫氏女
[
编辑
]

按《臨晉縣志》：孫氏女，父永徽，幼許士人子孟，將嫁前
五日，孟亡。孫以死自誓，日夕飲泣。尋遘疾危，語祖母
曰：「兒夜夢遊澗，遇一柳二椿。遂憩焉。閱月而沒。祔葬
於孟，其墳正當一柳二椿間也。」

李世昭妻王氏
[
编辑
]

按《臨晉縣志》：王氏，李世昭妻。闖賊入境，氏偕眾婦避
難蛾眉原土穴中，為賊搜得，群驅而出，氏伏地不起。
賊舉刃呵之，氏曰：「頭可斷，身不可辱。」賊曳之出，行十
餘步，投深崖死。

[
编辑

令狐怒曰：「我指乃為賊吏所污！」即以夾剪斷其指，人
咸稱其烈。
