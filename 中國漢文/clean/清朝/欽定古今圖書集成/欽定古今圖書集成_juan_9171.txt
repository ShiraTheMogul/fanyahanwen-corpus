虎豹圖

虎豹圖考
[
编辑
]

按《楚辭》云：「虎豹九關。」注謂：天門九重，虎豹守之。蓋假
借以言其嚴密之至也。天子清禁，上法紫宮，故門闕
必陳虎豹者，所以象上帝之居也。元制，每大朝會，則
陳虎豹于日精月華門外。國朝正旦、聖節朝會及冊
拜接見蕃臣，則以虎二豹二，各用闌檻承之，分左右
陳于奉天門外。

馴象圖

馴象圖考
[
编辑
]

晉《輿服志》云：「武帝太康中，南越獻馴象，詔作車駕之，
以載黃門鼓吹數十人，使越人騎之。正旦大會，駕象
入庭。」唐開元中，畜巨象於閑廄，供陳設儀仗。宋制，鹵
簿，象六，中道，分左右，並木蓮花坐，金蕉盤，紫羅繡襜
絡腦，當腦後。鞦，並設銅鈴杏葉，紅氂牛尾，拂跋塵。駕
出則先導，朝會則充庭。今制，每大朝會，以馴象六，分
左右、陳於奉天門外

仗馬圖

仗馬圖考
[
编辑
]

漢《長樂宮朝儀》，陳車騎於庭。唐有立仗馬。宋則以御
馬十匹分左右，陳於門外。元大朝會，設仗馬於內仗
之南。今制，以馬六匹鞍勒金，左右各三匹，陳於文武
樓南，東西相向

五輅圖

五輅圖考
[
编辑
]

《周官》：「典輅掌王之五輅，大賓客則出路。」
〈與輅同〉
漢朝集
使上計法，則陳屬車於庭，謂之「充庭車。」唐天子鸞輅
五等，屬車十二乘。行幸則分前後，施於鹵簿之內；大
陳設則分左右，施於儀仗之中。宋大朝會、冊命，設五
輅於大慶殿前。國朝參酌前代五輅，大朝會則陳於
殿前。玉輅青質，玉飾諸末；金輅赤質，金飾諸末；象輅
黃質，象飾諸末。革輅白質，鞔以革；木輅黑質，漆之，無
飾。

黃麾圖

黃麾圖考
[
编辑
]

《通典》曰：「黃帝振兵，設五旗五麾。」則黃麾製自有熊始
也。漢鹵簿有前後黃麾。《開元禮義纂》：唐太宗法夏后
之前制，取中方之正色，故制大麾色黃。宋制，以絳帛
為之，如旛，錯綵成黃麾篆字，下繡交龍及雲日。朱漆
竿，金龍首，上垂朱絲小蓋，四角垂佩，末有橫板，作碾
玉文。元制同，今制亦同宋，但蓋用朱絲。黃麾字楷書，
用金，下二龍塗金為之。

絳引旛圖

絳引旛圖考
[
编辑
]

按《釋名》曰：「旛，旛也。其貌旛旛然也。」唐、宋鹵簿，並施於
黃麾仗。宋制，朱漆竿，金龍首，朱絲蓋，四角，每角垂佩，
繫五色間暈氅，末垂橫板，作碾玉文。元制，四角，朱絲
蓋，每角垂羅文雜佩，繫於金銅鉤竿，竿以朱飾，懸五
色間暈羅，下有碾玉橫板。今制與宋同。

告止旛圖

告止旛圖考
[
编辑
]

按《開寶通禮義纂》曰：「唱止旛所以從行也，以為行止
之節。」宋制，緋帛錯采為「告止」字，承以雙鳳，下有橫玉
板，作碾玉文，上有朱絲，蓋四角，每角垂羅文佩，繫於
金銅龍頭鉤，朱漆竿。元制，用紅羅銷金升龍錯采為
「告止」字。今制與宋同
​

傳教旛圖

傳教旛圖考
[
编辑
]

按《開元禮義鑑》曰：「傳教旛、信旛，皆取飛騰輕疾之義。」
《開元禮義纂》曰：「若行幸征討，軍機有速，教令之所不
及，但相去三隊，置旛以傳教，謂之傳教旛。」宋制如告
止旛，錯采為傳教字，承以雙白虎。元制，用白羅，繪雲
龍。今制與宋同，但下繪金雙龍。

信旛圖

信旛圖考
[
编辑
]

按崔豹《古今注》曰：「信旛，古之徽號也。題表官號，以為
符信。」《宋書》曰：「孝武詔信旛，非省臺官悉用絳。」《古今注》
又曰：「信旛用鳥書，取飛動輕疾。一曰以鴻鴈燕，以有
去來之信。」舊用穎字。宋景祐五年，改制麾旛，易以小
篆，錯采為信旛字，承以雙龍，餘同傳教旛。元制，下繪
雙鳳。今制與宋同，但下繪金雙龍。

豹尾圖

豹尾圖考
[
编辑
]

按崔豹《古今注》曰：「豹尾車，周制也，以象君子豹變，尾
言謙也，古者軍正建之。」又漢《輿服志》曰：「屬車最後一
車，垂豹尾，金置於竿。」亦其遺制。元制，竿如戟，繫豹尾。
今制，朱漆竿，金龍首，垂豹尾。

龍頭竿繡氅圖

龍頭竿繡氅圖考
[
编辑
]

按《字書》曰：「氅鶖，鳥毛也。」《宋書》曰：「孝武詔王侯槊眊不
得用孔雀白氅。」梁有赤氅。隋大業二年，上幸臨江宮，
時羽儀新成，霜戈花氅，輝翳雲日。初造之時，毛氅多
出江南，為之略盡。又唐制，左右衛、驍衛皆建黃麾，武
衛建鶖毛四色氅，威衛建青氅、黑氅，領軍建赤氅。又
《禮令》，黃麾仗長戟大六色氅、大槊、孔雀氅、短戟大六
色鵝毛氅；小槊，小五色鵝毛氅戈，雞毛氅。宋建隆中
郊祀及開寶定禮，皆依此制。天聖鹵簿，有龍頭竿繡
氅。其制：青氅繡孔雀，用五角蓋；緋氅繡鳳，用六角蓋；
皂氅繡鵝，亦用六角蓋；白氅亦繡鵝，用四角蓋；黃氅
繡雞，亦用四角蓋。每角綴珠佩一帶，末有金銅鈴。《元
儀仗解》，但有繡氅，不知其色。今制，竿如戟鉤，下有小
橫木，刻龍頭，垂紅五角，蓋下綴紫綠銷金裙，腰連綴
青氅帶五，各繡一鳳，末垂金銅鈴，每角仍垂珠佩
​

皂纛圖

皂纛圖考
[
编辑
]

《唐六典》云：「後魏有纛頭，每天子行幸，大軍征伐，則建
於旗上。」蓋即古旄頭之遺制也。旄頭者，魏文帝《列異
傳》曰：「秦文公時，梓化為牛，以騎擊之，不勝，或墜地，髻
解髮散，牛畏之入水。故秦因此置旄頭騎，使先驅。」宋
天聖《鹵簿圖》云：「纛即皂旗，其制黑質，黑火焰腳，揭以
朱槍竿，竿首垂纛。」元則建纓於竿首，而不設旗。今制，
用旄牛，尾如巨斗大，建朱槍竿上。

大豹尾圖考
[

《通考》載，秦、漢駕後一乘垂豹尾。崔豹曰：「豹尾，周制，以
象君子。豹變，尾言謙也。」古者軍正建之，唐宋皆有豹
尾車。元有豹尾竿，今制以朱漆槍竿懸紅絲拂，垂豹
尾。

龍旗圖

龍旗圖考
[
编辑
]

周官：司常掌九旗，有交龍為旗。《覲禮》曰：「天子載大旗，
升龍降龍。」《司馬法》又曰：「旗章周以龍尚文也。」漢制，龍
旗九斿七仞。仞，尺也。古者以尺為仞。宋《天聖鹵簿圖
記》有龍旗十二，今制因之。皆為青質、黃襴，赤火焰，間
綵腳，繪金龍於中，揭以朱漆槍竿，飾以纓。

北斗旗圖

北斗旗圖考
[
编辑
]

《禮記·曲禮》：「招搖在上，急繕其怒。」鄭氏註：招搖星在北
斗杓端，主指者。畫招搖星於旌旗上，以起勁軍之威
怒，象天帝也。疏曰：「並作七星，而獨云招搖者，舉指者
為主也。」《穆天子傳》：「建日月七星旗」，蓋畫北斗七星也。
宋有北斗旗一。元制，北斗旗黑質，赤火燄腳，畫七星。
今制，黑質，黑火焰間，綵腳中塗金為七星像。

門旗圖

​

門旗圖考
[
编辑
]

《周禮》天官掌舍職曰：「帷宮，設旌門。」春官司常職曰：「會
同賓客，置旌門。」至漢謂之牙旗。故唐鹵簿內大㦸隊
後置牙門一，次牙門，左右廂各開五門。宋制，牙門旗
赤質錯綵，為神人像。元制，四旗赤質，赤火燄腳，繪神
人冠，武士冠，鎧甲、裲襠、束帶，大口褲，執戈戟。今制，門
旗四，皆赤質、黃襴，赤火燄，間綵腳，中塗金為「門」字，揭
以朱漆槍竿

月旗圖

{{{2}}}

日旗月旗圖考
[
编辑
]

《周官》：司常掌九旗之物，名其一曰日月為常。《左氏》曰：
「三辰旂旗，昭其明也。」按揚子《太元經》曰：「日以煜乎晝，
月以煜乎夜。」登日月於旗，以象天也。宋太祖始制日、
月旗各一。《天聖鹵簿圖》，日旗赤質，畫日中以雞。月旗
青質，畫月中以兔。元制，日旗一，青質，赤火燄腳，繪日
於上；月旗一，青質，赤火燄腳，繪月於上。今制，日旗、月
旗各一。俱青質、黃襴，赤火燄間。綵腳。繪日以赤，繪月
以白。

《曲禮》：「行前朱雀而後元武，左青龍而右白虎。」《義疏》曰：
「四者，四方宿名也。蓋古者君行師從，故畫此四者於
旌旗，以為前後左右之兵陳也。」唐制，四旗在鹵簿中。
宋朱雀旗，赤質、赤火燄腳，繪朱雀；元武旗，黑質、黑火
燄腳，繪龜蛇；青龍旗，青質、赤火燄腳，繪蹲龍；白虎旗，
白質、赤火燄腳，繪蹲虎。元同宋制，今制與宋同

[

按《韓子》曰：「黃帝合鬼神於泰山，風伯進掃，雨師洒路。」
至宋御殿儀仗制風伯、雨師、雷公、電母旗各一，以錯
繡為之。元因之，制風、雨、雷、電四旗，旗皆青質，俱畫神
人，狀各詭異。今制旗四，曰風、雲、雷雨，去電不設。旗皆
青質，黃襴、赤火燄間綵腳，風畫箕星，雨畫畢星，雲畫
雲氣，雷畫雷文。

四瀆旗圖

四瀆旗圖考
[
编辑
]

按《爾雅》曰：「江、河、淮、濟為四瀆者，發源注海者也。」《白虎
通》曰：「謂之瀆者何？瀆者，濁也。」中國垢濁，發源東注於
海，其功著大，故稱瀆也。宋制，四旗：江瀆旗，赤質，青火
燄腳，繪神人，冠七梁冠，青襴，朱袍，跨赤龍。河瀆旗，黑
質，赤火燄腳，繪神人，冠七梁冠，皂襴，黃袍，跨青龍。淮
瀆旗，素質，赤火燄腳，繪神人，冠七梁冠，皂襴，素袍，乘
青鯉。《濟瀆旗》，青質，赤火燄腳，繪神人，冠七梁冠，皂襴
青袍，乘一鱉。今制，江旗赤質，河旗白質，淮旗青質，濟
旗黑質，俱黃襴，赤火燄間，綵腳中繪水形。

五嶽旗圖

​

五嶽旗圖考
[

按鄭康成《周禮註》，「五嶽，東曰岱宗，南曰衡山，西曰華
山，北曰恆山，中曰嵩高山。」宋東嶽旗，青質，赤火燄腳，
繪神人，冠七梁冠，皂襴，青袍，黃裳，白中單，素蔽膝，執
圭。南嶽旗，赤質，赤火燄腳，繪神人，冠七梁冠，黑襴，緋
袍，黃裳，黃中單，朱蔽膝，執圭。中嶽旗，黃質，赤火燄腳，
繪神人，冠七梁冠，皂襴，黃袍，黃裳，白中單，朱蔽膝，執
圭。《西嶽旗》，白質，赤火燄腳，繪神人，冠七梁冠，青襴，白
袍，黃裳，白中單，素蔽膝，執圭。《北嶽旗》，黑質，赤火燄腳，
繪神人，冠七梁冠，紅襴，皂袍，黃裳，白中單，素蔽膝，執
圭。元因宋制，惟神人裳色不同。今制，東嶽旗青質，南
嶽旗赤質，中嶽旗黃質，西嶽旗白質，北嶽旗黑質，俱
黃襴赤火燄間，綵腳，中繪山形。

五星旗圖

五星旗圖考
[
编辑
]

按《考靈耀》曰：「歲星木精，熒惑火精，鎮星土精，太白金
精，辰星水精。」宇文周太常旗，畫日月五星。宋制，五旗
俱青質、黃襴，赤火燄腳，各繪神人，服隨方色。元制，五
旗金星旗，素質、赤火燄腳，畫神人冠五梁冠，素衣，皂
襴，朱裳，秉圭。水星旗，黑質、赤火燄腳，畫神人冠五梁
冠，皂衣，皂襴，綠裳，秉圭。木星旗，青質、赤火燄腳，畫神
人，冠五梁冠，青衣，皂襴，朱裳，秉圭。「《火星》旗」，赤質，青火
燄腳，畫神人冠五梁冠，朱衣，皂襴，綠裳，秉圭。《土星》旗，
黃質，赤火燄腳，畫神人冠五梁冠，黃衣，皂襴，綠裳，秉
圭。今制，木星旗青質，火星旗赤質，土星旗黃質，金星
旗白質，水星旗黑質，俱黃襴赤火燄間，綵腳，中以金
塗星形一。

天鹿旗圖

天鹿旗圖考
