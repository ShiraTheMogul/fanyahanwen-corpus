宣和宮詞
〈三首〉
　　　　　宋徽宗
[
编辑
]

小桃初放未全香，清晝金胥漏已長。臨罷《黃庭》無一
事，日移花影上迴廊。

太皇生日最尊榮，獻壽宮中未五更。天子捧觴仍再
拜，寶墀侍立到天明。

清晨檐際肅霜鮮，曉日初消萬瓦煙。隆德重陽開小
宴，競將黃菊作花鈿。

春晝偶書　　　　　　　　　　寇準
[
编辑
]

白晝偶成芳草夢，起來幽意有誰知。風簾不動黃鸝
語，坐見庭花日影移。

五更睡　　　　　　　　　　王禹偁
[
编辑
]

數載直承明，寵深還若驚。趁朝雞喚起，殘夢馬馱行。
左宦離雙闕，高眠盡五更。如將問比貴，此味敵公卿。

夕陽　　　　　　　　　　　錢惟演
[
编辑
]

遠色連高樹，迴光射迥樓。自翻歸雁影，更急思蟲愁。
煙暝長先隔，霞烘久未收。華燈知可繼，惟照洞房幽。

秋曉　　　　　　　　　　　范仲淹
[
编辑
]

牆外轆轤響，樓前河漢攲。曙光和月色，猶記早朝時。

秋晝　　　　　　　　　　　　前人
[
编辑
]

日色清如照，前林葉未零。海東新隼至，一點在青冥。

秋夜　　　　　　　　　　　　前人
[
编辑
]

春色人皆醉，秋光獨不眠。君看明月下，何似落花前。

夜夜曲　　　　　　　　　　文彥博
[
编辑
]

明月流清漢，娟娟照洞房。微風吹敗葉，颯颯下銀床。
塵晦流黃素，鑪銷辟惡香。年年機杼妾，獨怨夜何長。

夜意　　　　　　　　　　　張方平
[
编辑
]

群動已沉響，蛩吟時一聲。露寒仙掌重，月午庾樓清。
感慨聞雞舞，悲涼感笛情。幾多塵役者，夙駕待鐘行。

夜意　　　　　　　　　　　歐陽修
[
编辑
]

蕙炷爐薰斷，蘭膏燭豔煎。夜風多起籟，晚月漸虧弦。
鵲去星低漢，烏啼樹暝煙。「惟應牆外柳，三起復三眠。」

將至淮南馬上早行學謝靈運體六韻
[
编辑
]

前人

晴霞照東浦，驚鳥動煙林。曙河兼斗沒，沓嶂隱雲深
​
寒雞隔樹起，曲塢留風吟。征夫倦行役，秋興感登臨。
衡皋積涂迥，江蘺香露沉。行矣歲華晚，歸歟勞歎音。

夜賦　　　　　　　　　　　梅堯臣
[
编辑
]

月從東殿生，叢竹照修竦。葉間清露滴，枝上寒禽動。
閒覺萬慮空，靜聞嚴鼓重。官燭剪更明，相看應似夢。

夜宴　　　　　　　　　　　龔宗元
[
编辑
]

兔魄侵階夜三刻，蜀錦堆香花院窄。風動簾旌玳瑁
寒，露垂蟲網珍珠白。美人正席羅絃管，綺幄雲屏爐
麝煖。只恐金壺漏水空，不怕鷥觴琥珀滿。勸君莫負
秉燭遊，曾見古人傷晝短。

早行　　　　　　　　　　　范純仁
[
编辑
]

夙駕冒輕寒，身勞意自閒。鳴雞起遙墅，殘月滿空山。
水落灘沙白，林稀落葉殷。東方上朝旭，始免畏途艱。

古興　　　　　　　　　　　　沈遼
[
编辑
]

夜半山氣冷，始知秋序深。開軒望明月，西嶺莽涔涔。
人籟久已息，繁然蟪蛄吟。緬懷故丘鶴，清唳有餘音。

秋曉　　　　　　　　　　　　賀鑄
[
编辑
]

未卷半簾霜，猶疑在庭月。倚樹汲清泉，疏風獵華髮。

擬阮步兵夜中不能寐　　　　　前人
[
编辑
]

夜久不成夢，張燈開古書。清霜屏雲物，有月來庭除。
良時悵難再，不與佳人俱。掩卷長太息，望子城之隅。

夜意　　　　　　　　　　　　陳襄
[
编辑
]

薰爐香燼蕙煙沉，凜冽寒生翡翠衾。月國音塵千里
信，仙山樓閣五雲深。離懷暗耿金壺漏，獨夢多驚玉
女碪。騎省中郎才調逸，擬將文筆賦《秋心》。

曉　　　　　　　　　　　　郭祥正
[
编辑
]

曉光初透玉玲瓏，迥與真山意思同。蒼翠正含煙霧
濕，一峰先占太陽紅。

早行　　　　　　　　　　　晁端友
[
编辑
]

馬上雞初唱，天涯星未稀。驚風時墜笠，零露暗沾衣。
山下疏鐘發，林梢獨鳥飛。遠峰煙靄淡，迤邐見朝輝。

宮詞二首　　　　　　　　　王仲修
[
编辑
]

月沉天角曉星明，上直妝成趁五更。昨夜宣徽初進
曲，《仙韶院》裏未知名。

銀河清淺夜縱橫，魚鑰傳呼鎖禁城。試上紅樓三十
級，憑欄好看「月華生。」

夜吟　　　　　　　　　　　　張耒
[
编辑
]

簾捲涼侵戶，窗虛月過帷。高桐清露濕，深柳夜蟬悲。
斷續銀河轉，攲斜斗柄移。風來高葉報，伏近候蟲知。
陶令尊無酒，潘生鬢有絲。將何慰愁寂，倚杖獨題詩。

東方　　　　　　　　　　　　前人
[
编辑
]

東方未明更五鼓，星河寥寥寒鴈度。鏜鏜鳴鐸誰家
車，陌上驅牛輾霜去。北風吹面足踏冰，邨南早飯天
未明。年年輸稅洛陽城，慎莫後期官有刑。

守關　　　　　　　　　　　劉季孫
[
编辑
]

晨雞三叫未開關，留住行人更解鞍。卻上月明高處
立，曉風吹面作清寒。

早行　　　　　　　　　　　　陳淵
[
编辑
]

夢中聞得子規啼，燈下驚呼馬亦嘶。宿霧故迷山遠
近，肩輿纔辨路高低。雞鳴犬吠遙相應，野草幽花自
不齊。待得晨光開霽色，不知行道幾人迷。

秋夜　　　　　　　　　　　　朱弁
[
编辑
]

秋夜雖漸永，未抵客愁長。秋月雖已圓，不照寸心方。
將心貯此愁，真作萬斛量。為月憐此夜，誰共千里光。
空令還家夢，欲趁征鴻翔。

早行二首　　　　　　　　　鄭剛中
[
编辑
]

風柳驚霜日夜飄，客程中夜馬蕭蕭。據鞍髣髴如殘
夢，曉月一鉤猶未消。

赬肩攜擔又催程，寸詐孤燈照壁青。破縣殘更誤傳
曉，馬行十里見明星。

春晝　　　　　　　　　　　　前人
[
编辑
]

「深村春晝水，事事不相關。花少蝶蜂瘦，水清鷗鷺閒。」
柏香薰紙帳，竹枕傍屏山。「付與翛然夢，樂哉天地間。」

日暮　　　　　　　　　　　　張綱
[
编辑
]

地偏車馬靜，門閉水雲深。野艇收晴網，村春續暮砧。
危腸逢酒怯，病骨畏寒侵。又見鴉歸盡，誰賡「《梁甫》吟。」

晨興　　　　　　　　　　　　陸游
[
编辑
]

倦枕厭寒夜，起尋殘火溫。喈喈眾雞動，耿耿一燈昏。
野氣增霜力，窗光淡月痕。早朝非老事，且復灌吾園。

晨起　　　　　　　　　　　　前人
[
编辑
