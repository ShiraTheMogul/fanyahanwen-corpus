明四十五

傅承寵妻徐氏
〈俞氏附〉
[
编辑
]

按《蕭山縣志》：「徐氏，傅承寵妻。承寵未娶，得癇疾，徐父
欲悔之，氏不從，卒歸傅承寵，癇益甚，氏調護曲盡。越
六載，寵亡，寵弟承宸方娶俞氏而病瘵六月死，妯娌
共守節。俞氏父憐女少，欲嫁之，俞持刀斷髮自刃，瀕
死父乃止。徐有子德新，俞通經史，常提誨之，有司表
其閭。」

徐鳳梧妻魏氏
[
编辑
]

按《蕭山縣志》：魏氏，徐鳳梧妻。梧浪遊客死，氏年二十，
守一子，奉姑以居，晝夜辟纑，易粟以爨。及姑沒，子為
姦人誘賣，氏獨處一室，竈常無煙，雪夜以草薦自覆。
或謀娶之，惕以威勢。氏曰：「人不畏死，又何畏焉？我必
不以窮餓故辱我祖先也。」後子長，得脫歸，漁釣為業，
以養母焉。

包曾義妻孫氏
[
编辑
]

按《蕭山縣志》：「孫氏，包曾義妻。義賈京師亡，氏年二十
六，苦節，誓酬夫志，晝夜勤劬，養姑字幼，姑亡，殯葬盡
禮。邑令上其事，歲給粟帛終其身。」

單之祥妻盛氏
[
编辑
]

按《蕭山縣志》：「盛氏年十六，適單之祥。祥病蠱，氏日夜
籲天請代，衣不解帶。歲餘祥沒，欲從死，姑勸止之。孤
幃匿影，蹈矩循繩，凡四十餘年如一日。邑令上其事，
臺使者歲給粟帛旌其門。」

丁露妻陳氏
[
编辑
]

按《蕭山縣志》：「陳氏，儒士丁露妻，陳殷女也。年十七，歸
露。期年露亡，誓不二適。遺腹生子，隨殤，舅姑欲奪其
志，陳氏泣曰：『所以不死，以舅姑在耳，何乃不諒若是？
嫠居八十餘年，年九十九卒。嘉靖初，縣令秦鎬表其
閭』。」

張誼妻黃氏
[
编辑
]

按《蕭山縣志》：「黃氏，名淑貞，張誼妻。誼舉進士，迎黃之
京，而誼已病亟，氏籲天請代，卒不起。黃年二十六，欲
從死，左右以遺孤苦勸之，稍進饘粥，扶柩抵家，事舅
姑以孝，睦宗黨以禮，捐膏沐，謝宴會。苦節四十年，足
不踰閾，言不妄發。臺使歲給粟帛復其家。」

沈炳秀妻陳氏
[
编辑
]

按《蕭山縣志》：「陳氏，長巷沈炳秀妻。父遘疾，贅秀於家。
時秀年十五，陳年十四，合巹甫四月，秀患腹疾死，陳
號慟欲絕。父母憐其幼，欲令改適，使婢持百花綺裙
示之，揮去不顧。年二十一，有富人倩一達者為媒，父
為治具，陳問故，叔母以告，陳慟哭，即持溷水濺媒氏
衣，媒遑遽走。由是辭父母歸夫家，立夫兄子為嗣。母」
子相守，煢煢一室，人罕得見其面，惟寒食展墓，偕妯
娌一往，哭必盡哀，聞者垂涕，以是終焉。

周大器妻徐氏
[
编辑
]

按《蕭山縣志》：「徐氏名清源，儒士周大器妻。年十九，歸
大器。七年夫亡，氏哭踊不食，幾絕者再。其母故餓，其
兒啼於前，乃抱兒曰：『吾為爾延一息耳』。」既葬夫，並營
己壙，以示不二。蓬垢蔬食，苦鞠遺孤，手寫夫像懸於
室。值望日，題其像曰：「此月有時缺，此心終不虧。願將
今夜月，常與我心隨。」忌日哭奠盡哀。凡遇婚嫁慶賀，
即潸潸淚下，宗人咸為感泣。後子長，家業漸隆，親戚
前為壽，輒恚不見。終身寢不解衣，足不踰閾。年六十
三，臨終又自題其像，有司九表其門。

王宗岱妻張氏
[
编辑
]

按《蕭山縣志》：「張氏，誼之姊，讀書知古訓，歸諸生王宗
岱，六載而岱沒。二子紹充、紹冕，皆在孩提。氏辛苦備
嘗，訓子讀書，充有聲文學，冕仕至苑馬寺副。孫明允，
曾孫鴻業、鴻烈，皆舉明經孝廉。」

===楊敏妻齊氏===
​
按《諸暨縣志》：齊氏，名妙觀，南隅楊敏妻。年十八，敏亡，
子仲洧甫週歲，舅姑欲奪其志，齊斷髮破面，抱孤向
舅姑泣曰：「婦為死者守此，孤不忍使之無歸。」舅姑怒，
令自食，齋居斗室，紡績資生。舅姑沒，託老婢經理。其
家閉門不啟，開一竇以通飲食。如是二十年，年六十
七卒。

駱黼妻錢氏
〈鄭氏附〉
[
编辑
]

按《諸暨縣志》：「錢氏，舉人駱黼妻。婉慧貞靜，寡言動。夫
亡，子茂應甫二週。錢事舅姑及遇諸伯仲，秩然有禮。
一日失火，氏驅群婢取諸珍玩，投井中，翁不之知，明
日取出，欲以其半予之，固不受。年九十六卒。其後有
鄭氏者，黼從子宗迪妻也。年二十有二。宗迪死，即以
黼孫玠為嗣。玠雖子，行非其應後。鄭曰：『吾心慕錢孺
人爾』。」守節五十年，年七十餘。事聞，旌表。

余獅妻曹氏
[
编辑
]

按《諸暨縣志》：曹氏，余獅妻。獅亡，氏年二十一，子良充
甫五月，姑憐其少，將改嫁之。氏抱子泣曰：「夫雖死，有
子在，終不去也。」閉門斷髮，資紡績以養姑，久而愈謹。
歲大歉，值姑喪，家益貧。鄰婦勸曹別圖，庶可兩全。曹
忿其言，嚙大指濺血於獅之神主。鄰婦窺見，為泣下。
嘉靖中，事聞旌表，年九十餘卒。

陳有智妻李氏
〈姚氏附〉
[
编辑
]

按《餘姚縣志》：李氏，陳有智妻。智與弟有容並早喪，李
年二十一，容妻姚二十九。初，智叔中丞克宅，攜智之
松番，病亡，中丞貽書慰李甚至，李泣曰：「叔翁豈以是
堅我哉？微叔翁言，寧當二心者。」久之，室燬，編茅以居，
娣姒相依一室，寂不聞人音，第見壁間炊煬，乃知有
人耳。已與群從共建一室，未遷而其姑沒，二婦欲殮
於新室。同室者懼禨祥，不許。姚、李負屍竟寘新室。眾
皆錯愕，睥睨不敢言，並以壽終。

王爚妻陸氏
〈陳氏附〉
[
编辑
]

按《餘姚縣志》：陸氏，王爚妻。爚與弟灴皆早死，陸方妊，
爚臨絕，謂陸曰：「汝年纔十八，勿自誤。」陸揮涕曰：「君言
誤矣。得子則撫之，否則與君偕死耳。」及爚亡，陸氏刑
面毀容，哀不勝支。閱七月果生子，撫之如初言。灴妻
陳氏亦守志。其父母諭之曰：「姒幸抱子，汝何恃而自
苦？」陳泣曰：「吾知身，焉知子？」因斷髮自誓，立烘弟之子
為嗣，復殤。於是妯娌合資併食，足不踰閾。薦祭感愴，
相對涕泣。嘉辰令節，見者皆為罷懽。有司上其事，並
旌之。

聞人才後妻黃氏
[
编辑
]

按《餘姚縣志》：黃氏，貢士聞人才後妻，黃愷女。才病沒，
黃年十八，無出，家貧。或諷之嫁，黃曰：「婦人守節，固不
因富而有出也。夫前妻子在，吾雖貧，猶能紡績為衣
食計。」卒守志無變。事聞，詔表其閭。

諸永言妻鄭氏
[
编辑
]

按《餘姚縣志》：「鄭氏，諸永言妻。年二十一而寡，家徒壁
立。子巽方二歲，鄰嫗百計誘其改適，鄭叱絕之，卒守
苦節以壽終。有司上其事，未報。會孫敬之中嘉靖戊
戌進士，疏請旌表。」

韓塤妻項氏
[
编辑
]

按《餘姚縣志》：「項氏，韓塤妻，名昭。少閱書史，能操翰製
詞，智巧絕倫，歸韓克修婦事。年二十三，塤遘疾不起，
昭痛絕欲俱死，念母早寡，恐傷其心，乃隱忍苟延。鄉
之少年慕昭者，爭賂其伯氏求之，昭皆峻拒，居恆備
刀自衛。一日，謀者候其展墓，將劫諸塗，會與母兄同
行，不獲逞，則為流言詬辱於路，昭乃擲刀曰：『謀者智
窮，故辱吾以自退耳』。」是後果息。立伯少子銀生為塤，
後親授書拓，復舊業。邑人錢德洪作《釋刀傳》以表之。

史鸞妻陳氏
[
编辑
]

按《餘姚縣志》：「陳氏，史鸞妻，郡守陳雲鶴女。鸞，都御史
琳之子，弘治戊午舉人，早亡。陳年二十六，雖宦家婦，
而蕭然四壁，不啻貧民。一夕鄰失火，鸞柩猶在室，陳
伏棺號慟，願與俱焚，火竟隨滅。或勸他適，陳曰：『以須
臾無死，而人遂不諒其心耶』？」自縊，垂絕救甦。嘉靖三
十年旌表。

周汝登妻沈氏
[
编辑
]

按《餘姚縣志》：「沈氏，周汝登妻。年二十四而寡，舅姑俱
耄，伯氏太僕卿如底，廉而貧。沈忍死操作，奉老撫幼
六十年。屏居一室，即群從子姪罕見其面。女家迎之
亦不往，以壽終。」

呂氏女
[
编辑
]

按《餘姚縣志》：「呂氏女，名成，少傅呂本女，許字太傅謝
遷孫用模。嘉靖乙卯，用模舉於鄉，上春官，至吳門病
亡。女聞而飲泣廢食，誓以死殉。有議姻者，女即絕粒，
父母知不可強而止，遂以處女終焉。」

陳克華妻楊氏
[
