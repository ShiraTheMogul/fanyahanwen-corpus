《汝墳三章》
周南
[
编辑
]

遵彼汝墳，伐其條枚。未見君子，惄如調饑。

「遵彼《汝墳》」，伐其條肄。既見君子，不我遐棄。

魴魚赬尾，王室如燬。雖則如燬，父母孔邇。

《秋日題汝陽潭壁》
唐·劉希夷
[
编辑
]

獨坐秋陰至，悲來從所適。行見汝陽潭，飛蘿蒙水石。
懸瓢木葉上，風吹何歷歷。幽人不耐煩，振衣步間寂。
迴流清見底，金砂覆銀礫。錯落非一丈，空蒙幾千尺。
魚鱗可憐紫，鴻水自然碧。吟詠《秋水篇》，渺焉無損益。
秋水隨形影，清濁混心跡。歲暮歸去來，東山餘宿昔。

《故園置酒》
前人
[
编辑
]

酒熟人須飲，春還鬢已秋。願逢千日醉，得諼百年憂。
舊里多青草，新知盡白頭。風前燈易滅，川上月難留。
卒卒周姬旦，棲棲孔聖丘。平生能幾日，不及日遨遊。

《代悲白頭翁》
前人
[
编辑
]

「洛陽城東桃李花，飛來飛去落誰家？洛陽女兒惜顏
色，行逢落花長歎息。今年花落顏色改，明年花開誰
復在？已見松柏摧為薪，更聞桑田變為海。古人無復
洛陽東，今人還對落花風。年年歲歲花相似，歲歲年
年人不同。寄語全盛紅顏子，須憐半謝白頭翁。」「此翁
白頭真可憐，伊昔紅顏美少年。公子王孫芳樹下，清」
歌妙舞落花前。光綠池臺開錦繡，將軍樓閣畫神仙。
一朝臥病無人識，三春行樂在誰邊。宛轉蛾眉能幾
時，須臾鶴髮亂如絲。但看舊來歌舞地，惟有黃昏鳥
雀悲。

復春。野老不知堯舜力，酣歌一曲《太平人》。

《秋夜宿仙遊寺》
前人
[
编辑
]

「太乙連太白，兩山知幾重。」路磐石門窄，匹馬行才通。
日西到山寺，林下逢支公。昨夜山北時，星星聞此鐘。
秦女去已久，仙臺在中峰。簫笙不可聞，此地留遺蹤。
石潭積黛色，每歲投金龍。亂流爭迅湍，噴薄如雷風。
夜來聞清磬，月出蒼山空。空山滿清光，水樹相玲瓏。
迴廊映密竹，秋殿隱深松。燈影落前谿，夜宿水聲中。
愛茲林巒好，結宇向豁東。相識惟山僧，鄰家一釣翁。
林晚栗初折，枝寒梨已紅。物幽興已愜，事勝趣彌濃。
願謝區中緣，永依金人宮。奇報垂輦客，簪裾爾何容。

《山寺僧房》
前人
[
编辑

窗影搖群木，牆陰載一峰。野爐風自爇，山碓水能舂。
勤學翻知誤，為官好欲慵。高僧瞑不見，月出但聞鐘。

樹冷無棲鳥，邨深起暮煙。洛陽山已盡，休更望《伊川》。

《夜集汝州郡齋聽陸僧辨彈琴》

编辑

《過龍泉寺精舍》
前人
[
编辑
]

亭午聞山鐘，起行散愁疾。尋林採芝去，谷轉松翠密。
傍見精舍開，長廊飯僧畢。石渠流雪木，金子耀霜橘。
竹房思舊遊，過憩終永日。入洞窺石髓，傍崖探蜂蜜。
日暮辭遠公，虎谿相送出。

《登白雲寺》
元·結
[
编辑
]

出門見南山，喜逐松逕行。窮高欲極遠，始到白雲亭。
長山遶井邑，登望宜新晴。洲渚曲湘水，瀠洄隨郡城。
九疑千萬峰，嵺嵺天外青。煙雲無遠近，皆傍林嶺生。
俯視松竹間，石水何幽清。涵映滿軒戶，娟娟如鏡明。
何人病惛憒，積醉且未醒。與我一登臨，為君安性情。

《送賈閣老出汝州》

[
编辑

西掖梧桐樹，空留一院陰。艱難歸故里，去住損春心
​

《望箕山》
宋·歐陽修
[
编辑

朝下黃盧坂，夕望箕山雲。緬懷巢上客，想彼巖中人。

空祠亂驚鳥，山木含餘曛。聊茲謝芝桂，歸月及新春。

《聽珍珠泉》
楊億
[
编辑

何須十斛買明珠，滴瀝泉聲迥不殊。蠙腹從來歸大

中》瀉出銀河萬丈高，收拾明珠獻聖朝。

《溫泉》
前人
[
编辑

大造真爐冶，不炊亦沸湯。珠噴泉帶雨，煖溢谷稱暘。
伏滌塵凡慮，兼滋枯槁鄉。惟餘詩酒癖，未肯告醫王。

《巢父井》
晏殊
[
编辑
]

稟生值堯年，率性在龐厚。安巢一枝上，豈曰鶉居陋。
潁波人洗耳，曾不污牛口。諒茲耕耒暇，鑿飲隈林藪。
含飴鼓其腹，帝力予何有。遂令千載外，此地存遺甃。
泓然逼喬木，宛若棲時舊。鄉人揭題榜，行旅皆瞻覯。
我來觀古跡，愕立徘徊久。凄其望清風，不獲見師友。
願言斟一勺，拭面洗心垢。翹勤慕高躅，感慨陳巵酒。
思齊胡可望，度以寬慵瞀。夙駕恨長途，憑高重回首。

《琴臺》
元·好問
[
编辑
]

「荒城草木合，破屋風雨侵。千年一琴臺，睠焉涕盈襟。
遺愛食縣社，公寧不堪任。此臺即甘棠，忍使無餘陰。
旁舍高以華，大豪自捐金。蒼雲元武暮，鬼物憑陰岑。
尚德抑清虛，墜典誰當尋。我與薦寒泉，百拜公來臨。
公來不能知，落日下饑禽。懷哉空山裏，鶴飛猿與吟。
當年《于蒍歌》，補袞一何深。承平示得意，猶能正哇淫
​
君相此一時，又復悟良箴。諛臣坐廢黜，合亦起幽沉。
蒲輪竟推轂，香草空深林。寂寞授書室，孤甥舉遺衾。
生平諒已然，薄俗矧來今。千山為公臺，萬籟為公琴。
夔曠不並世，月露為知音。人間蹄涔耳，已矣非公心。

《送詩人秦簡夫歸蘇墳別業》

汝州部紀事
[
编辑
]

夏帝履癸五十二載，伊水竭。

漢高祖后四年秋，汝州大水，沒民舍千家。

後漢光武帝建武十七年十月，有鳳凰五見於郟邑。
魏明帝青龍元年四月，青龍見於郟邑之摩陂井中。
晉成帝咸康四年，太白晝見於柳。

安帝義熙四年，汝水竭。

北齊文宣帝天保八年，汝州大蝗。

隋文帝開皇十八年，汝州大水。

唐元宗開元八年，伊水溢，漂溺民產數十家。

代宗太曆十年七月，太白、辰星合於柳。

《唐書閻讓傳》：「太宗幸洛陽，詔立德按爽塏，建離宮清
署。乃度地汝州西山，控汝水，睨廣成澤，號襄城宮，役
凡百餘萬。宮成，煩燠不可居，帝廢之，以賜百姓，坐免
官。」

德宗建中四年九月，龍見汝州城壕。

懿宗咸通四年，汝州大水，傷稼。

僖宗廣明元年，汝州《現峰陽》龍池涸。

後唐明宗天成四年，汝州火。

後周太祖廣順三年，汝州旬日無鳥。

宋太祖乾德四年六月己亥，太白、熒惑合於張。
真宗大中祥符元年，汝州醴泉出。

天禧二年八月癸丑，歲星、熒惑合於張。

徽宗政和五年，汝州芝草生。

宣和三年，汝州麒麟出。

元仁宗延祐元年，汝州地震。

七年，汝州大饑。

順帝至正十七年，汝州大饑，蝗飛蔽天。

十八年，伊陽縣蝗飛蔽天，人不能行，所過溝壑皆滿。
明憲宗成化二十年，伊陽縣饑。

武宗正德二年，「太白經天。」

三年，魯山縣大水。

六年，薊賊劉六、劉七反，攻寶豐縣縣土城，不能禦，遂
入搶掠。首領趙《風子》，係文安秀才，注念斯文，凡士大
夫家授令箭一枝，掛藍衫於門，部卒俱不敢入，百姓
殺戮亦少，知縣徐端遁。賊又攻郟縣城，郟縣民多方，
縣民多方禦之，大炮擊死賊首領白大王，賊遂退。
世宗嘉靖元年，賊王堂反，過郟縣境不敢入，至禹州
遂滅。

七年，魯山旱，大祲，郟縣大饑，伊陽蝗，寶豐蝗尤甚，所
過田禾悉盡。歲大饑，斗米千錢，民餓死者十有八九。
九年，魯山《大有》。

十七年秋，寶豐大水，北門危甚，城幾溺，壞民廬舍不
可數紀，遂大饑，人相食。

十八年，魯山、伊陽俱蝗，大祲。

十九年，「魯山大有。」

三十二年，歸德賊師「尚詔反」，未至，風聲甚厲，闔邑大
恐。兵備王之誥禦于郟，東，至襄城白嶺岡，殺絕。是年，
寶豐大水，伊陽春不雨；秋七月，淫霖不止，汝水泛溢，
漂沒田舍無算。

四十一年壬戌春，寶豐亢旱，知縣袁亮竭誠步禱。至
四月夜初，忽有星光自乾方來，明耀若晝，墜落縣衙
琴堂前柏樹上，火星紛紛下落，官民驚異。時知縣袁

亮卜日致祭，祈禱益虔。不數日，霖雨大降，火咎亦消
​
秋大熟。

穆宗隆慶二年秋八月，伊陽大水。

神宗萬曆十四年，伊陽大旱。七月始雨蕎麥，斗錢三
百。

十五年，伊陽「自春到六月不雨。」九月十二日，大雪尺
餘，晚禾盡殺。

十六年春，伊陽縣大饑。魯山有龍出自窊石里，經康
家渡口、「十里頭、看花里」、白象里，陸地而行，雷電從之，
雲霧旁繞，所至草木盡拔，牆傾屋摧，至倉子頭飛去。
十七年三月，魯山郟縣寶豐有黑風自東而西，吽吽
有聲，人對面不相見，拜掃者皆屯野不敢行，鳥獸多
誤入水死牛馬。逸民攜兵尋之，刃皆火，次日乃霽。是
歲旱，大祲。

十八年，《魯山縣》《大有》。

二十一年，魯山、郟縣、寶豐，皆霪雨害稼，自夏至秋不
止。魯山平地為淵，麥秋未登，民至相食，盜賊蜂起。汝
州兵備移鎮魯山，發賑彈壓始息。

二十二年春，汝州寶豐、郟縣皆大饑，至父子相食。
四十年，郟縣、寶豐大水，平地深一丈許，人多溺死。
四十六年，伊陽不雨。

四十七年，汝州旱，自三月至八月乃雨，是歲大荒。
熹宗天啟元年，鳳落於鳳翅山下，山在禹、郟之間。
七年夏，魯山東鄉牛產一獸，似麟，雷電交集，黑雨如
注，火光滿室。

愍帝崇禎三年春，郟縣有黑風自東北而來，遍地，「錢
印大者如盤盂，小者如棗栗」，行人衣巾皆有之，其跡
三日猶見。

四年，郟縣柏樹俱生，黃耳，大如蓮蕊。

五年五月，郟縣大雨，河水溢，房屋頹，禾盡淹，人多溺
水死。六月，汝州大水，湮沒村落，頹壞城垣十之五。魯
山縣大霖雨，城垣盡圮。東鄉土賊張三、杜小川等乘
機作亂。

六年春夏，汝州屬縣俱大疫，有闔戶死者。秋，寶豐有
鳥自西北來，群以百千計，似鶉而頗大，爪無後距，不
能棲樹，時人呼為「殺雞」，又呼為「反雞」，續過至歲終止。
魯山有番鳥自西北來，每群萬餘，羽似燕，足似鼠。
八年，賊攻魯山城，五晝夜防守甚密，又兵自北至，寇
乃遁。

十一年，伊陽不雨，蝗。

十二年，伊陽不雨。夏四月，蝗竟月飛翔，往來不定，所
落之處，草木靡有萌糵。秋八月，蝝生民家，釜臼皆滿，
井水臭穢，不可食。時兵凶交熾，民有數日不舉火者。
季冬，魯山忽有異香如檀者數日。

十三年，汝州土賊流寇交肆焚擄。六月二十五日，魯
山守城千總詹思鸞鼓譟搶掠，距城跋扈，挾令招安
知縣楊呈芳陽從陰拒。至十一月十三日夜，《秘謀》令
千總李一鳴擒殺其首，逆黨盡誅。冬，郟縣土賊聶二
並父聶三登、高世泰、李文昇陷城，與賊首楊同錦據
兩月餘，屠戮士民，劫掠財物，焚毀廬舍，蕩然一空。後
闖寇李自成至，殺同錦並邑令，置偽官。自成去，高凌
雲遂殺偽官洎聶二並父聶三登、高世泰、李文昇等。
十四年，寇陷汝州城，男女悉搜殺之。李自成自西至
郟縣，驅土賊出城

十五年春，闖寇復至郟縣，因高凌雲殺所置偽官，平
城剮凌雲，執邑令李某。李大罵，並剮之。殺紳民無算，
死者十之八。貰死者割鼻耳。官廨民舍，毀之殆盡。夏
四月初十日，魯山土兵復鼓噪搶掠，甚於詹賊。楊令
急登南城樓，好言撫之。賊懼其紿，竟刃楊令。閏十一
月朔，「流寇」舉眾剋魯山城，土賊潛遁。是時，闖賊數十
萬人入寶豐，慘毒十日，殺擄十之七八。十六年二月
十一日，流寇復陷魯山，民有避居西山者，無論男女，
悉搜殺之。又武岡賊王承選等復掠郟縣，割人手萬
餘雙以示威。以人肉味美，凡數十男子養一窖如羊
豕，賊中互賣以食。殺人之法，略如屠豕。以婦人油多
煉數十缸，供洞中燈火，自是城野斷絕人煙。又闖寇
駐襄陽，安置偽官。九月，經略孫傅庭兵至，賊哨騎五
十餘人奔入城中，分制防禦。孫兵攻城，多被死傷，傅
庭大怒，圍三晝夜，城陷，無少長貴賤皆屠滅，跳城下
者只百餘人，遺婦女千數，赤身跣足，以書為衣，凍餓
死及自盡者甚眾，星散他方者亦多。其不能動移者，
食死，人強活。後西山土賊入寶豐城，拷審財物，當街
設鑊烹人，以食不盡者，驅入山，作牛羊用，春燕巢林，
虎狼入市，凡四五年

《汝州志》按《唐新語》：劉希夷一名庭芝，汝州人。少有文
華，好為宮體，善彈琵琶，嘗為《白頭翁詠》云：「今年落花
顏色改，明年花開復誰在。」既而自悔曰：「『我此詩讖，與
石崇白首同所歸』何異。」乃更作一聯云：「年年歲歲花
相似，歲歲年年人不同。」既而嘆曰：「此句復似向讖語，
然死生有命，豈復由此。」乃兩存之。詩成未周歲遇害。
或云宋之問後。孫翌撰《正聲集》，以希夷詩為集中最。
夫希夷死所，其為「之問」與否未詳，而白頭翁詩則已
誤入之問集中，焉知非為所掠。古來名士相妬，如馬
季常故事，往往有之，而好事者或遂託以詫其說，亦
不可曉。
