洪汝文
[
编辑
]

按《壽昌縣志》：「洪汝文，字文同，市心人。存心仁恕，孝于
親，友于兄弟。與兄同居醋坊巷而出入怡怡。一日，兄
病其居之隘，遂以其地悉讓于兄，而自構于巷東棲
焉。其後子孫咸掇科顯仕，人以為世德之報云。」

洪祚
[
编辑
]

按《壽昌縣志》：「洪祚，字天祐，號靜庵，景德之子。嚴毅莊
重，幼穎悟，能詩詞，治書經，補邑庠生。每考居首，終厄
不第，乃以貢入南雍，即疏運河便宜數事，未任而卒，
鄉人惜之。公孝於奉先，嚴於教子，處宗族則盡仁，待
朋友則盡義，而于兄弟之好尢篤。凡貲財田宅，甘於
磽弊。或有說之者，則曰：『設父母無所遺，亦將與之較
耶』？」所著有《家廟義莊》、「制」、《禹貢節要》、「詩文」若干卷。

劉應龍
[
编辑
]

按《壽昌縣志》：劉應龍，六都勞村人，邑庠生。父早喪，事
母孝，問安視膳，不離親側。嘗曰：「古人不以三公貴而
換一日養。」遂白於宗師趙，辭歸，養親許之，例錫冠帶。
弟嘗病鼻衄，醫云必得犀角可療，公即以犀帶和藥
治之。

季養
[
编辑
]

按《瑞安縣志》：「季養，字彥良。父歿，結廬墓側，手植松柏，
終身不飲酒。每忌日，輒不食。因先世遺文散逸，購得
之，奔走燕趙間，以求表彰。與人言輒流涕，人哀其志。
及歸，得疾，至家強起，陳詩文于庭卒。」

謝廷俊
[
编辑
]

按《瑞安縣志》：「謝廷俊喪父，貧未能葬。鄰火延及，廷俊
獨扶柩呼天而泣。俄風返火滅，人以為孝感所致。時
立碑亭志其事。子伯恭亦以孝聞。」

姜約
〈弟綱〉
[
编辑
]

按《瑞安縣志》：姜約，字子充，弟綱，字子斐，俱廩生。事親
孝養備至，操行端莊，兄弟燕見如賓，寸粟匹帛未嘗
私入。親歿，廬墓三年。約以貢死京邸，郡人王粟果誄
之曰：「孝友忠信，可通於神明，整齊嚴肅，不違於造次，
可謂篤行君子矣。」綱聞約卒，朝夕慟哭。及櫬歸數日，
亦飲痛而卒。

項愛親
[
编辑

按《瑞安縣志》：「項愛親，字允孝，事親至孝。家貧，灌園易
甘脆以養，顛沛不廢定省。每祭祖考必齋戒越宿，邑
延為鄉飲賓。」

方舜韶

錢必應

编辑

按《淳安縣志》：「錢必應嘗侍父病，扶掖床褥，衣不解帶

願以身代。及父卒，若孺子泣，喪葬如禮。事詳下令旌

毛公器

编辑

按《江山縣志》：「毛公器，北門人。孝行純篤，父歿，廬墓三
年。母歿，復廬墓側，朝夕哀號，有烏鳥馴遶墓側，人以
為孝感所致。有司上其事，榜曰『孝子之門』。」

徐顓
[
编辑

按《江山縣志》：「徐顓，字世張，汝舟曾孫。事親愛敬篤至，

毛棟
[
编辑
]

按《江山縣志》：「毛棟，粗通書史，事親以孝聞。父母繼故，
哭泣幾喪明。既葬，結廬墓所，終喪三年。鄉族以孝稱。」

欒惠
[
编辑
]

按《西安縣志》：「欒惠，字子仁，師王陽明，事父母曲盡孝
道。母嘗患瘋疾，手足拘攣者十三年，每扇枕溫衾，飲
食搔摩，必躬必親，終始不怠。及父母相繼亡，一遵古
制，廬墓三載，朝夕奠祭，衰絰頃刻不離身。偶雨夜遇
虎，卒保無傷，時築墳塋，妻吳氏抱石運土。」

鄒瑩
[
编辑
]

按《西安縣志》：「鄒瑩，為某邑司訓，德器粹然，于諸士不
責禮，餽尤厚于寒素。始之官，覆舟失父像，悲悼不自
勝，常籲天懇祈，必獲。後果有持獻者。僉謂誠孝所致。」

馮蘭
[
编辑

按《西安縣志》：「馮蘭事母邵，刲股進湯。比出訪醫，母索
前飲，婦洪、王二氏割臂爭先，妻妾同心，良足稱異。」

陳情
[
编辑
]

按《西安縣志》：「陳情，字汝孝，事二親繼母俱以孝聞，父
疾，籲天願以身代，躬事醫藥，衣不解帶。年五十未舉
子，因葬親，馴燕舞于墓側，甘露濡于木端者五日。嗣
​
生子通，郡皆稱孝義所感，郡侯易為立高逸傳。」

徐應雷
[
编辑
]

按《西安縣志》：「徐應雷，字震伯，太學生。五歲喪母，哀毀
不減成人。父官直指留京，逮事王父極孝。繼母吳氏
多病，竭力醫治十餘年，病轉劇，禱籲願以身代，罄篋
笥以與舅氏。繼母歿，又膳外祖母二十年，復為置產
立祀。推父愛庶出叔父，為之營田廬，完家室，延師卜
館，孝友之稱，內外無閒言。學使誌其墓。」

葉斆

编辑

按《青田縣志》：「葉斆，為庠增廣。父癇疾，曲意承順，母癰
吮血。」

蔣光哲
[
编辑

按《青田縣志》：「蔣光哲，字士明，髫年游泮，比鄰失火，扶

王詔
[
编辑

按《松陽縣志》：「王詔，號龍溪，為邑諸生。居喪，躬負土築
父母墓，致白雀蒼鴿之應。」

葉元芳
[
编辑
]

按《松陽縣志》：葉元芳，字邃府，性孝友，嘗瀝血焚肉以
療母病。後為高要丞，有「廣海青天」之號。監司薦擢崇
義令，以內艱歸，亦不復出仕。

徐鼎臣
[
编辑
]

按《松陽縣志》：「徐鼎臣，字忠孺，天性至孝。總角時，母有
危疾，籲天刲股幾絕，若有神掖之乃甦。母卒不起，號
慟廢寢食，伯叔父強之進糜粥。邑上其事，院道交旌
之。服闋，補弟子員，以扶父櫬京邸，勞瘁而卒。邑人憐
其死孝，目其葬地為『徐孝子墓』。」

詹朝宣
[
编辑
]

按《松陽縣志》：「詹朝宣，號梧岡，邑廩生。多著作，孝友性
成。父卒，居喪廬墓，有賦詩退虎之異。」

毛炳文
[
编辑
]

按《松陽縣志》：「毛炳文，號桂林，性孝友，父病，割股祈禱
身代。及卒，母以家貧，令其改儒業。文多方孝養，仍苦
讀遊庠，復教二子成名，為時所推重。」

周九道
[
编辑
]

按《松陽縣志》：「周九道，字禹開，素行克孝，父母病劇，籲
天割股三次，名載憲綱。院臺旌其孝，孝達。皇都初授
興山尉，勤慎有聲，轉桂巡幕，念繼母老，不便迎養，告
致而歸，作斑衣繞膝，娛其親焉。」

葉志
〈子尚木　孫克芳〉
[
编辑
]

按《遂昌縣志》：「葉志，字希尹，孝友性植，黨族推敬。母病，
割股以療。後己身病篤，子尚木割股以進。孫克芳方
九歲，亦割肉煮羹，持甌避人，至祖帷，群異之，索其甌，
方知子父不謀。而均能輕生行孝，人謂世孝傳芳，均
志異德貽謀云。後尚木、克芳均鄉飲。年七十卒。」

周應鳳
[
编辑
]

按《遂昌縣志》：「周應鳳，南隅人。孝友性成。家世食貧，拮
据買藥，佐父治生。助弟應鶴負笈下帷。母病篤，割股
醫治，至誠所格，延母壽一紀。」

包可大
〈子經郊〉
[
编辑
]

按《遂昌縣志》：「包可大，北隅人。十歲喪父，即知孝。侍母
孀居，晨昏定省，不離左右。母至六旬病篤，可大割身
籲天，母困而後甦，復能教子成立。三子經邦、經都、經
郊，俱膺恩歲薦。經郊亦以割身救母稱孝。」

鄭邦紀
〈子汝富〉
[
编辑
]

按《宣平縣志》：「鄭邦紀，字君正，恪守清貧。父階病危，割
左股煎湯救痊。後二十五年，子汝富，字愛卿，方十一
歲，值邦紀病，家貧無醫，慟哭告天，昏夜剖臂肉救愈。
年幼知孝尤罕得也。」事聞，當道交獎。

陳文新
[
编辑
]

按《宣平縣志》：陳文新，幼習儒，父母在堂，斑綵為樂。母
病篤，藥不愈，籲天身代，割股煎湯以進，母病遂瘳。鄉
閭咸稱其誠格當道，詳入憲綱，後月旦推賓典焉。

编辑

多方調治，夜告天願減己壽，仍割股進湯，病即愈，屢
賜旌匾。」

竭其力。嫡母有疾，朝夕不離左右，湯藥必親嘗，割股
煎湯，以延母壽。入憲綱匾，旌云「孺孝。」

按《宣平縣志》：「生員章自蘊，年十三歲，父病，告天割股，
可稱孺孝。」

方維城

编辑

按《淳安縣志》：「方維城，府庠生，割股廬墓。」

楊時雍
[
编辑
]

按《嘉興縣志》：「楊時雍，胥山四都民。父病瞽，母馬氏形
影相依，家貧不能娶，出贅，念父母莫為省視，棄歸，以
筆札代耕，力修菽水。母病篤，雍籲天哀號，割股飼母，

​
有司獎其門。」

褚元卿
[
编辑
]

按《嘉興縣志》：「褚元卿，幼有至性，事親孝養備至。父病，
元卿衣不解帶，籲天請代。父沒，哀毀骨立，淚枯流血，
水漿不入口者七日，廬墓三年，孝聞屢奉旌獎。」

竇卿
[
编辑
]

按《嘉興縣志》：「竇卿，性至孝。父患足癰，朝夕敷洗。卿時
年七十五歲，行必負之。母病，親嘗湯藥，衣不解帶。及
卒，哀毀骨立，廬墓三年，父產悉分二弟。有妹適錢俸
者，孀居乏嗣，迎養於家，族之貧乏者，咸賴周給，人多
其義。」

戴華
[
编辑
]

按《嘉興縣志》：「戴華，字君實，有兄夭死，獨身與父母居，
不娶，曰：『汲爨可自任，奈何以井臼故累二親耶？久之，
父病，家貧甚，乃痛苦拮据湯藥。父卒不起，悲號垂絕。
又十餘年，母病，拮据一如父病時，而母亦卒不起。初，
母病，華晝夜哭甚，哀聲達里巷。一日，閴然無聲，戶竟
日不啟，鄰父老相與排闥而入，視其母已死，華伏母』」
旁，面覆著床上，候其氣息甚微，似已絕者，急灌以湯
得甦。鄰父老責以毀不滅性，乃勉進飲食。既免喪，鄰
父老力勸其娶存祀，相與求里中得賢女，曰：「是可以
配孝子矣。」華遂有室。是時華赤貧，粗糲常不給，而歲

按《漳州府志》：「蔡保禎，詔安人，字瑞卿，鄉賢方平子。純
孝，衰絰守父墓，先輩傳其『展墓千迴，子心未恔，居山

功世教者。

按《漳州府志》：「郭俊，字獻傑，龍溪人，池州守舒曾孫。幼

祠崇祀』。」

方安榮
[
编辑
]

按《漳州府志》：「方安榮，龍溪人。家貧不知書，而性最孝，
以宰豬為業，日割所賣之肉數兩，以資母飯。母病，又
割股食之。其鄉人聞之，皆曰：『安榮孝子也』。因為大書
其門曰：『貧而能養』。」

按《漳州府志》：「余喬烈，詔安人。賃傭養親。親百餘歲，齒
