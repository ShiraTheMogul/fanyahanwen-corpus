[
编辑

秦王金作柱，漢帝玉為欄。仙人飛往易，道士出歸難。

编辑

匝欄生暗蘚，覆板沒魚衣。岸曲斜梁阻，何時香步歸。

[
编辑

連延過絕澗，迢逓跨長津。已數逢仙客，兼曾渡獦人。

《賦得渡岸橋》
陳陰鏗
[
编辑
]

畫橋長且曲，傍險復憑流。寫虹晴尚飲，圖星畫不收。
跨波連斷岸，接路上危樓。欄高荷不及，池清影自浮。
何必橫南渡，方復似牽牛。

《登渭橋》
北周·宗羈
[
编辑
]

仲山朝飲馬，還坐渭橋中。南瞻臨別館，北望盡離宮。
四面衣裾合，三條冠蓋通。蘭香想和季，雲起憶成公。
圯上相知早，雞鳴幸共同。

《和庾司水修渭橋》
王褒
[
编辑
]

東流仰天漢，南渡似牽牛。長堤通甬道，飛梁跨造舟。
使者開金堰，太守擁河流。廣陵候濤水，荊峽望陽侯。
波生從故舶，沙漲湧新洲。天星識辨對，檢玉應沈鉤。
空悅《浮雲賦》，非復採蓮謳。

《看治渭橋》
庾信
[
编辑
]

大夫參下位，司職渭之陽。富平移鐵鎖，甘泉運石梁。
跨虹連絕岸，浮黿續斷航。春洲鸚鵡色，流水桃花香。
星精逢漢帝，釣叟遇周王。平隄石岸直，高堰柳枝長。
羨言杜元凱，河橋獨舉觴。

《賦得浮橋》
唐·太宗
[
编辑

曲岸非千里，斜橋異七星。暫低逢輦渡，還高值浪驚。
水搖文鷁動，纜轉錦花縈。遠近隨輪影，輕重應人行。

《橋》
李嶠
[
编辑

烏鵲填應滿，黃公去不歸。勢疑虹始見，形似鴈初飛。
妙應七星制，高分半月輝。秦王空構石，仙島遠難依。

《賦橋》

[
编辑

「造橋浮渭日，鞭石表秦初。」星文遙瀉漢，虹勢尚凌虛。
已授文成履，空題武騎書。別有臨濠上，棲偃獨觀魚。

《天津橋賜宴》
張九齡
[
编辑

清洛象天河，東流形勝多。朝來逢燕喜，春盡卻妍和。
泉鮪歡時躍，林鶯醉裏歌。賜恩頻若此，為樂奈人何。

《惠州東新橋》
蘇軾
[
编辑
]

群鯨貫鐵索，背負橫空霓。首搖翻雪江，尾插崩雲溪。
機牙任信縮，張落隨高低。轆轤卷巨索，青蛟挂長隄。
奔舟免狂觸，脫筏防撞擠。一橋何足云，誰傳「廣東西。
父老有不識，喜笑爭攀躋。魚龍亦驚跳，雷霆生馬蹄。
嗟此病涉久，公私困留稽。姦民恃此險，出沒如鳧鷖。
似賣失船壺，如去登樓梯。不知百年來，幾人如沙泥。」
豈知濤瀾上，安若堂與閨。往來無晨夜，醉病休扶攜。
使君領我言，妙割無牛雞。不云二子勞，歎我捐腰犀。
我亦壽使君，一言聽《扶藜》。常當修未壞，勿使後噬臍。

《西新橋》
前人
[
编辑
]

昔橋本千柱，挂湖如斷霓。浮梁陷積淖，破版隨奔溪。
笑看遠岸沒，坐覺孤城低。聊因三農隙，稍進百步隄。
炎州無堅植，潦水輕推擠。千年誰在者，鐵柱浮羅西。
獨有石鹽木，白蟻不敢躋。似開銅駝峰，如鑿鐵馬蹄。
岌岌類鞭石，山川非會稽。嗟我久閣筆，不書紙尾鷖。
蕭然無尺壁，欲駕飛空梯。百尺下一杙，椓此百尺泥。
探囊賴故侯，寶錢出金閨。父老喜，雲集簞壺無空攜。
三日飲不散，殺盡西村雞。似聞百歲前，海近湖有犀。
那知陵谷變，枯瀆生茭藜。後來勿忘今，冬涉水過臍。

《栖賢三峽橋》
前人
[
编辑
]

吾聞泰山石，積日穿線溜。況此百雷霆，萬世與石鬥。
深行九地底，險出三峽右。長輸不盡溪，欲滿無底竇。
跳波翻潛魚，震響落飛狖。清寒入山骨，草木盡堅瘦。
空濛煙靄間，澒洞金石奏。彎彎飛橋出，斂斂半月彀。
玉淵神龍近，雨雹亂晴晝。垂瓶得清甘，可嚥不可嗽。

《垂虹橋》
王安石
[
编辑
]

「三江五湖口，地與天不隔。日月所蔽虧，東西渺然白。
漫漫浸北斗，浩浩浮南極。誰投此虹蜺，欲濟兩間阨。
中流雜蜃氣，欄楯相承翼。初疑神所為，滅沒在頃刻。」
晨興在其上，傲兀至中昃。獨監造化工，不謂因人力。
今君持酒漿，談笑顧賓客。頗誇九州物，壯麗此無敵。
熒煌丹砂柱，璀燦黃金壁。中家不慮始，助我皆豪殖。
愧予獨不可，還當采物力。

《河橋成》
〈并序〉
金·李俊民
[
编辑
]

「橋成有日，必有佳句。」 寫《河上逍遙之興》。《贈子榮及督役楊成之》

預積他山木，重新兩岸堤。龍依天上臥，虹傍水心低。
不假鞭秦石，何勞立蜀犀。落成應有日，誰向柱先題。

其二

勢截長河浪，橫陳百步梁。經營方假手，過涉不褰裳。
漫惜千金瓠，休誇一葦杭。西風簫鼓咽，奠酒水仙堂。

《三峽橋》
元·揭徯斯
[
编辑
]

兩山束飛橋，下塹不測淵。誰開萬尋鐵，逗此無窮泉。
淙淙輥空曲，洶洶投奔川。陽光下照之，忽作龍騰天。
常恐桑田變，中有瞿塘船。

《過魯橋》
周權
[
编辑
]

泗河汨汨流青銅，魯橋突兀橫長虹。驚波蕩潏石鬥
怒，石門空洞如弛弓。風霜剝蝕勢欲壓，亂石齒齒填
深洪。南連淮楚九地厚，東導齊魯群流通。商賈貿遷
百貨阜，來帆去棹紛奔衝。車輪彭鍧鐸聲急，馬蹄蹴
踏塵影紅。我遊天京偶經此，一見淳俗真堯封。扁舟
膠涸守連日，欲去未去心忡忡。嗟予行役浪自苦，颯
颯吟鬢將秋蓬。摩挲殘碣討遺跡，搔首躑躅斜陽中。
銜杯一洗胸芥蔕，浩歌目送吳天鴻。

《題垂虹橋亭》

《獨架橋》
明·方孝孺
[
编辑
]

「名為不祥器，斯理昔未覺。及茲困奔走，始歎立論確。
險哉七盤山，羊腸凌巘崿。三年八往返，顛頓髮早皬。
此行當盛夏，溽暑逞餘虐。晝伏避蚊䖟，石徑越林薄。
危橋帶褒水，俯瞰波流惡。鑿石勞眾工，傍崖構飛閣。
下扶千柱壯，上倚浮雲弱。怒雷地底鳴，懸瀑崖際落。
山中郵傳少，過客資棲泊。勞者務苟安，寧思非所托。」
更闌急雨至，洪濤相噴薄。鬼神助晦冥，天地混磅礡。
病身倦輾轉，酣寢絕疑愕。晨興宵景澄，林壑還可樂。
有生大化中，萬變相綜錯。所遇聽自然，何處匪安宅。
