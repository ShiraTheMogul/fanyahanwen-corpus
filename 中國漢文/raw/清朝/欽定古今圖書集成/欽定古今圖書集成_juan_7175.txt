陳昉
[
编辑
]

按《九江府志》：「陳昉，德安人。十三世同居，長幼七百口，
不畜僕妾，上下婣睦，人無閒言。每食必群坐廣堂，未
成人者列為一席。有犬百餘，亦置一槽，共食一犬不
至，群犬亦皆不食。建書樓於別墅，延四方之士，肄業
者多依焉。鄉里率化，爭訟稀少。開寶初，平江南，知州
​
張齊上請仍舊免其徭役，從之。昉弟之子鴻，太平興」
國七年，江南轉運使張齊賢又奏免雜科。競即鴻之
弟。淳化元年，知州康戩又上言競家常苦食不足，詔
本州每歲貸粟二千石。後競死，其從父弟旭每歲止
受貸粟之半，云省嗇而食，可以及秋成。屬歲儉穀貴，
或勸其全受而糶之，可邀善價。旭曰：「朝廷以旭家群
從千口，軫其乏食，貸以公粟，豈可見利忘義，為罔上
之事乎？」至道初，遣內侍裴愈就賜御書，還，言旭家孝
友儉讓，近於淳古。太宗嘗對近臣言之，參知政事張
洎對曰：「旭宗族千餘口，世守家法，孝謹不衰，閨門之
內，肅於公府。」且言及旭受貸事，上以遠民義聚，復能
固廉節，為之歎息。大中祥符四年，以旭為江州助教。
旭卒，弟蘊主家事。天聖元年，又以蘊繼為助教。蘊卒，
弟泰主之。泰弟度，太子中舍致仕。從子延賞舉進士，
延賞，職方員外郎。

許九
[
编辑
]

按《無錫縣志》：「許九，本田家子，早喪父，獨與母居。淳化
三年饑，九往來城邑求食養母，人厭其數，多斥之，九
絕粒病數日。時牟麥未登，九刈青煮食，得強起，念母
終不得食，哀痛不忍俱死，因持斧自斷其手，手斷血
不出，人皆異之。九乃繫斷手杖頭，示信於市。於是眾
皆哀感，爭餽盤飧，母子俱全。進士孫浩以其事聞於」
令，令謂九傷毀支體，不孝，逐之。浩與俱去常州，留養
於家。九每與母同出，累日不至浩所。浩問之，曰：「所得
幸足供母，不欲數累長者。」浩益憐之，為置緇衣衣之。
居歲餘，母死，九服所得緇衣，漆其斷手，口誦《浮圖》言。
與母俱卒。

許頻
[
编辑

按《長沙府志》：「許頻，字仲先，湘陰人。性至孝，卓行著聞。
淳化閒，母彭氏卒，水漿不入口者三日，哀毀骨立。葬
踰月，芝草生墓側，人以為孝感云。」

王景
[
编辑
]

按《郫縣志》：王景，字仰山。淳化咸平中，景以積行純孝
稱於鄉里，號「王孝子。父母嘗病革，割股以進，翼日瘳。
及父母沒，負土成墳，結廬其側。有甘露降於竹柏，鳥
雀銜果，鹿馴擾其廬。乾道己丑夏，孝子立墓石，復產
紫芝一本，人以為仁孝之報云。」

陳侃
[
编辑

按《溫州府志》：「陳侃，字君和，永嘉人。居建牙鄉，事親孝
養備至，執喪盡禮，五世不異爨。至道二年，郡守何蒙
上其事，太宗嘉之，詔旌其門曰『孝門，賜其母李氏粟
帛』。」

李鼇
[
编辑
]

按《吳縣志》：「李鼇，壽昌令燧子也。燧，濮州人。咸平中，自
睦州罷官北歸，過吳江而卒，葬吳天平山。鼇時幼奉
母鄭家于吳。天聖中，母卒，合葬父兆。鼇倚杖寢苫，廬
于墓，早夜悲痛，甘露降于松楸。母常誦《金剛經》，鼇刺
血書刻于墓中。郎中楊備表之。」

楊榮
[
编辑
]

按《兗州府志》：楊榮，鄆州人。七世同居。咸平中旌表，仍
蠲課調。榮嘗諭子孫曰：「吉甫賢人也，伯奇孝子也。賢
父御孝子，合得終于天性，而後妻閒之。」伯奇遂放曾
參。婦死，謂其子曰：「吾不及吉甫，汝不及伯奇。」王駿喪
妻，亦謂人曰：「我不及曾參，子不及曾元。」並終身不娶。
此等足以為戒。

王樵
[
编辑
]

按《濟南府志》：「王樵，字肩望，淄川人。咸平中，舉家為遼
騎所掠。樵棄妻，挺身入遼，訪父母，累年不獲還，刻木
招魂以葬，立祠畫像，事之如生。服喪三年，哀動行路。
又為屬之尊者，次第成服，北望嘆曰：『身世如此，自比
于人可乎』？遂與俗絕。自稱贅世翁，唯以論兵擊劍為
事。晚年屢遊塞下，畫策干何承矩、耿望求滅遼復仇」，
不用，乃于城東南隅壘磚自環，謂之「繭室。」病革，入室，
自掩戶，卒。

許俞
[
编辑

按《黟縣志》：許俞，字堯言，城西人。登祥符五年進士，為
大冶令。俞事父以孝謹聞，供給甘旨，晝夜不怠。與妻
子共食粗糲，供父則盡珍異示豐厚。父病篤，澣濯衣
服必躬親之，曰：「寄於家人之手，吾恐厭怠也。」其孝如
此。胡瑗為作《孝子傳》。

===羅孟郊===
​
按《南昌郡志》：「羅孟郊，南昌人，徙居興寧縣。天聖閒，舉

按《休寧縣志》：「曹矩，字誨之，登景祐進士，官至屯田郎

编辑

按《南昌郡志》：「過昱，字彥明，豐城人。母早卒，刻木為像，
早暮漱盥，飲食必進，愈久愈勤。閔世俗鮮知事親，乃

雷庠
[
编辑
]

按《廣東通志》：「雷庠，字長善，陽山人。少聰敏，與孔文仲
登岳陽樓翫古碑，一閱即記。三與鄉薦，年踰六十，始
登慶曆進士，調衢州西安令。母年八十，不與就養，庠

棄官歸，籲天請以身代，母遂愈，不復出。」

裘仲容
[
编辑
]

按《紹興府志》：「裘仲容，會稽人。事母至孝。慶曆中，母病
亟，仲容刲股肉飼母。弟仲莊亦將刲之，聞兄已進，乃
止母食之，病輒瘳。時有祥雲覆其家，人以為誠孝所

邵維
[
编辑
]

按《湘陰縣志》：邵維，祿塘人。宋嘉祐閒，任率府正。五子
𤣱、琥、珪、琢、珣，克盡其孝，兄弟友恭，家產不析。士大夫

句。

張阿蟠
[
编辑
]

按《無錫縣志》：「張阿蟠，生甚微。致和中，歲饑，從父母就
食晉陵。父卒，家益貧。蟠方成童，傭於馬氏，馬，染工也。
蟠因善其業，主愛之，歲益其傭直，蟠乃盡其力之所
能，得以養母。暑月夜自焚艾，以驅蚊蚋。窮冬雨雪，爐
未嘗斷薪，積二十餘年。母年六十有五而卒，舁喪歸
葬，哀感旁人。」

周大雅
[
编辑
]

按《嚴州府志》：「周大雅，壽昌人。治平中，登進士第。居親
喪，廬墓三年，羶葷絕不入口。有群烏馴其旁。會趙清
獻公抃還自京師，道縣訪焉，察其實，請於朝，錫以束
帛，改鄉曰至孝，里曰求忠。今其故居在艾溪南，距縣
一里許。」

丁天錫
[
编辑
]

按《如皋縣志》：丁天錫，赤岸鄉人。性沈靜，有器識，博學
能文。父早卒，奉母周至孝。有盜入其家，以兵懾母，天
錫身衛母，曰：「寧殺我以代母命，所有任取之。」盜亦自
慚曰：「天不殺孝子。」於是母子獲全。治平四年，母將革，
語天錫曰：「死生人之常也，況年九十，又何憾已。」引聲
浩歌而終。親死，喪葬一稟於禮，終身衣不純采。

蕭汝為
[
编辑

按《吉水縣志》：蕭汝為，字叔展。父喪，廬墓，手植松柏數

張仲友

编辑

按《臨江府志》：「張仲友，新淦人。元祐閒，父業醫，早喪，仲

嚴希孟
[
编辑
]

按《如皋縣志》：「嚴希孟，沿海鄉人。嗜學能詩。父文式蚤
卒，事母李孝。元祐三年，母病痁，醫禱弗愈，密刲股炊
糜以進，母病遂痊。越六載，母沒，哀毀如禮。居喪三年，
無見齒。鄉人語曰：『嚴家孝子無雙』。」

史聲
[
编辑
]

按《如皋縣志》：「史聲，沿海鄉人。元祐閒以進士登顯官。
始家貧失母，帶經樵蘇，以給父養，自糲食時抱惄也。
及授官迎養，中途聞父訃，即奔跣四日，至父喪所，慟
幾絕，扶櫬還葬，結廬墓旁，躬負土培墓，成壟如山，遇
弔者惟觸地叩哀而已。」

張汝明
[
编辑
]

按《安福縣志》：「張汝明，元祐中任司諫，極言蔡京中書
執政，蔡卞樞密秉兵，文武兩權盡出兄弟之手，于社

榮之。文章孝弟，著於遠近，一時學者多出其門。

李文珍
[
编辑
]

按《東安縣志》：「李文珍，咸淳中人，天性孝友。母鄧氏獲
異疾，思魚作羹，會時沍寒，堅不可破，珍禱於潭，持斧
鑿冰，得魚三尾供母，疾即愈。越三年，疾復作，珍仍禱，
于是入水，良久不出，傍視者危之。既而掖巨魚出，母
得食復瘳，人以為孝感，名其潭為『孝子云。又一日，母
疾將革，珍割股和藥，母啜之即安』。」後以上壽終。縣尹
趙崇。
以事聞，命下賜粟帛，旌表其門。建孝感坊于
宅旁立碑記之。歲久碑仆。至大元年，曾孫李覺昕告
於邑，為重立碑文，彰其「潛德」，入鄉賢祠。
