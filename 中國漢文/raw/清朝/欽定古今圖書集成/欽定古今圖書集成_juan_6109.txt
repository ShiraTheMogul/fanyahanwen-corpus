錢蘭妻桑氏
[
编辑
]

按《常熟縣志》：桑氏，錢蘭妻，通判瑾之孫女。蘭以役死
南京，桑年三十，子繼宗甫六歲。或諷改圖，桑泣曰：「桑
家世禮義，我寧死不辱。」先是繼宗出嗣周某，桑命歸
主蘭祀，守節終身。

顧軾妻陸氏
[
编辑
]

按《常熟縣志》：「陸氏，顧軾妻。年二十七，軾亡，無子，孝養
其翁與少姑盡力。翁沒，嗣子破其家，煢煢食貧，至死
不變。」

陳龍泉妻錢氏
[
编辑
]

按《常熟縣志》：「錢氏，陳龍泉妻，封御史亨女。嫁逾年，泉
亡，撫七月遺孤道一成立。龍泉有二弟，錢俱為之婚
娶。」

王湖妻錢氏
[
编辑
]

按《常熟縣志》：「錢氏，王湖妻。無子，勸湖買妾。盧有身而
湖亡。後三月生一子，錢懷抱鞠養，逾於腹出。亡何，盧
亦死，錢拮据女紅以給。姑沒，喪葬如禮。萬曆十四年，
詔旌其門。年八十餘卒。」

仲補之妻錢氏
[
编辑
]

按《常熟縣志》：「錢氏，仲補之妻，立之女。年十八而嫁，踰
年補之亡，翁亦沒。仲本饒於資，至是家日落。或勸改
圖，錢悲號自誓，日閉門焚修。萬曆間旌表。」

管母閔氏
[
编辑
]

按《常熟縣志》：「閔氏，孝廉管一德母年二十九而寡，一
德甫十歲，閔矢志撫孤，惟絣䌟自給，或累日不得食。
鬻簪珥得一金，半市薪米，半買書以課子，日夜飲泣，
兩目失明。一德年十五，入縣學有聲，目乃復視。萬曆
辛卯，德舉鄉試第二，閔始一開顏，年七十終。」

蔣栻妻季氏
[
编辑
]

按《常熟縣志》：「季氏，蔣栻妻，文村舊族也。年二十六，栻
亡，家貧，養姑盡孝，撫孤。世卿為縣學生，孫以忠成進
士，疏請得旌，為建專祠，春秋與祭。」

高祥妻許氏
[
编辑
]

按《常熟縣志》：許氏，高祥妻。年十七而嫁，未踰月，祥遠
出不歸，許煢煢無倚。嚴文靖知而憐之，為授一廛。又
數年終，嗣子葬之石梅之側。後有欲占其地者，許數
現形，復憑人語曰：「我苦節一生，此三尺土，魂魄所安，
如不可保，當訴之上帝。」遂懼而止。且為封樹，立墓門
額曰「高節婦墓。」

錢鶴年妻王氏
[
编辑
]

按《常熟縣志》：「王氏，錢鶴年妻。年二十九，鶴年亡，抱從
子庠為嗣。王入侍舅姑，輒引庠隨後。庠仕至千戶，王
年九十卒。」

鄒淑妻周氏
[
编辑
]

按《常熟縣志》：「周氏，生員鄒淑妻，方泉女。淑幼孤，育於
其嫂。嫂悍戾，周莊事之，猶日呵責。淑訓蒙以給，得入
縣學。嫂罵淑三日，淑憤而死。周時年二十三，拮据度
日，撫孤孟卿成立。周偶灑掃，失足仆地，折一肱，生計
益困。年八十二卒。」

其門。年六十九卒。」

===李逢祥妻呂氏===
​
按《常熟縣志》：「呂氏，李逢祥妻。年二十一祥亡，呂毀容

编辑

徐裕德妻葉氏
[
编辑
]

按《常熟縣志》：「葉氏，徐裕德妻，教諭元之女。年二十七，
德亡，葉閉戶自經，姑解之復甦。撫孤待揚，為縣學生。
萬曆間，巡按秦懋義、巡撫趙可懷聞於朝，旌表，歲給

陳欽明妻華氏
[
编辑
]

按《常熟縣志》：「華氏，生員陳欽明妻，無錫人，鴻臚復誠
之女。嘉靖甲子，欽明文戰弗利，憤死。華年二十五，子
繩武僅彌月。翁文周時宦廣東，華持家撫孤，門庭肅
然。翁歸好客，烹鮮擊肥，咄嗟而辦。既沒，家難四作，華
割田房以讓之，怡怡如也。萬曆甲午，繩武舉鄉試，華
遂齋心皈佛，年六十七卒。巡按及學使俱表其門。」

周鏇妻王氏
[
编辑
]

按《常熟縣志》：「王氏，周鏇妻。鏇早亡，王撫二孤，又相繼
夭喪。鏇父某命以其弟球子泌嗣之，氏撫之終其身。
萬曆間，有司以聞，詔旌其閭。」

錢順時妻卞氏
[
编辑
]

按《常熟縣志》：卞氏，進士錢順時妻。順時登第，未仕而
沒，時年三十，子世揚甫七歲，卞截髮貯棺中，以撫孤
自誓。翁性嚴重，奉事惟謹，庀治喪事，必先諸叔，曰：「吾
冢婦弗敢後也。」分財產，戒世揚無取贏，曰：「若孺子弗
敢先也。」世揚能勝外傅，不假與顏色，稍不如命，則對
案不食，涕淚交頤，居恆以綱常為典訓，曰：「吾願汝為
古之愚人，不願汝為今之聞人也。」歲時命世揚省視
故舊族戚閭里之貧窶者，待以舉火。解衣推食，掩骼
設糜不吝。脫簪珥為之尢。好佛肖像，飯僧無虛日。興
福寺大殿久頹廢，獨力修復，金碧燦然。萬曆末，孫謙
益以苦節上聞。

周世恩妻凌氏
[
编辑

按《常熟縣志》：「凌氏，周世恩妻。年二十三，恩亡，生子甫
期月，族人利其資，逼凌改嫁，至火其廬，逐之。凌刺『節』
字於掌以自誓。養姑訓子，四十餘年卒。孫汝禎上其
節於臺府，旌之。」

世弟際世妻朱氏，年二十二而寡。與蘇同心守節，以

沈從吉妻宋氏
[
编辑
]

按《常熟縣志》：「宋氏，沈從吉妻。從吉為孝子良之孫，宋
為生員之鳳之女。年二十八，從吉亡，遺一子自勵。宋
上事病翁，下鞠幼子。翁沒歲凶，宋益困以自勵，寄食
姻戚，自依兄居，力䌥紉咽，糠秕度日。垂二十年而自
勵為縣學生直指房壯麗，縣令楊忠烈給與廩粟，表
其門。年六十六卒。自勵常輯良與程宋遺事及志傳」
詩贊名《孝節世紀》。

韋福謙妻郁氏
[
编辑
]

按《常熟縣志》：「郁氏，生員韋福謙妻。年二十一，謙亡，有
姑無子。或謂郁勿守，郁嚙指曰：『吾不知所守，但知不
事二夫已耳』。力營養姑，自飫糠覈。姑沒，舉兩喪盡力。
自是無所歸，寄居於其姻，歸氏家不下樓者數年，立
族子某為後。萬曆間，中丞及諸有司皆歲頒粟帛表
其廬。年七十餘卒。天啟元年，奉詔建坊旌表。」

吳剛妻陳氏
[
编辑
]

按《常熟縣志》：陳氏，吳剛妻。年二十一而剛沒，遺腹生
子宇。越十三年，翁沒，家難群起，陳曰：「彼謂嫠婦不出
閨耳。」某攘田，某據宅控之有司，三勘皆白。從伯誣剛
無子，陳攜宇鳴鼓告縣伯遁去。又嘗充巨繇，身受桁
楊。後里黨欲舉其節，陳曰：「我百苦盡嘗，醜辱莫掩，何
舉為？」年六十六卒。

唐一麟妻盧氏
[
编辑

按《常熟縣志》：「盧氏，唐一麟妻。一麟，忠臣天恩曾孫也，

死葬，悉出十指。教撫諸孤成立，兄弟同居，友愛無間，

之女也。年十六于歸，二十八喪夫，矢志守節，歷五十
