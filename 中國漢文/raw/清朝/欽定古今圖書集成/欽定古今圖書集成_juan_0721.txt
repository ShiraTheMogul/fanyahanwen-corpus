梅部藝文四
〈詩〉

编辑

《蠟梅》
宋·王十朋
[
编辑
]

蜂採花成蠟，還將蠟染花。一經坡谷眼，名字壓群葩。

《紅梅》
前人
[
编辑
]

似桃非桃杏非杏，獨與江梅相早晚。天姿約略帶春
酲，便覺花容太柔婉。霞觴㶑灔玉妃醉，應誤劉郎來
閬苑。會須參作《比紅詩》，莫學牆頭等閒見。

《次韻王龜齡省中黃梅》
周必大
[
编辑
]

化工未約酴醾菊，先放緗梅伴群玉。幽姿著意慕鉛
黃，正色何心輕萼綠。妝成自淺風味深，對此寧辭食
無肉。可憐涪翁被渠惱，中歲梅屏桮杓醁。

《紅梅》
范成大
[
编辑
]

華燈收盡江梅落，別有橫枝照林薄。天教閬苑染芳
根，不住山城慰蕭索。騰騰醉後酒紅醺，淡淡妝成笑
靨新。斟酌東君已傾倒，為渠都費十分春。別乘胸懷
有風月，催喚新樽洗愁絕。花知主客得不凡，一夜光
風融絳雪。樓頭煙暝吹單于，花梢掛星光有無。歸來
境熟落春夢，夢入鎖香紅綺疏。

《嶺上紅梅》
前人
[
编辑
]

霧雨臙脂照松竹，江南春風一枝足。滿城桃李各嫣
然，寂寞傾城在空谷。城中誰解惜娉婷，遊子路傍空
復情。花不能言客無語，日暮清愁相對生。

《次韻元夕賞倅廳紅梅》
前人
[
编辑
]

新安絕少紅梅，唯倅廳特盛。通判朝議，召幕僚賞之，坐皆有詩。

春入林梢一再風，破寒勻染費天工。雖然媚蕩新妝
別，只與橫斜舊格同。午枕乍醒鉛粉退，曉奩初罷蠟
脂融。後來顏色休論似，夾路漫山取次紅。

又

「司花一笑為誰開，知道朱幡得得來。」疏影有情當洞
戶，蔫香無語墮空杯。風生翰墨留連看，月入笙歌次
第催。來歲如今翻舊唱，五雲叢裏望三台。

《紅梅》
前人
[
编辑
]

酒力欺朝寒，潮紅上妝面。桃李漫同時，輸了春風半。

《梅為雪所禁》
前人
[
编辑
]

凍蕊粘枝瘦欲乾，新年猶未有春看。雪花祇欲欺紅
紫，不道梅花也怕寒。

《次韻漢卿舅蠟梅》
前人
[
编辑
]

垂垂瘦萼泫微霜，剪剪纖英鎖暗香。金雀釵頭金蛺
蝶，春風傳得舊宮妝。

又

湘袂朝天紫錦裳，光風微度絳綃香。壽陽信美無仙
骨，空把心情學淡妝。

===
《梅花》
陸游
===
​
幽香淡淡影疏疎，雪虐風饕只自如。正是花中巢許

輩，人間富貴不關渠。

又

亂篸桐帽花如雪，斜挂驢鞍酒滿壺。安得丹青如顧
陸，憑渠畫我《夜歸圖》。

《江上尋梅》
前人
[
编辑
]

小園風月不多寬，一樹梅花開未殘。剝啄敲門嫌特
地，緩拖藤杖隔籬看。

又

鐘殘小院欲消魂，漠漠幽香伴月痕。江上人家應勝
此，明朝更出《小南門》。

《折梅花》
前人
[
编辑
]

湖上梅花手自移，小橋風月最相宜。主人歲歲常為
客，莫怪「幽香怨不知。」

《梅花》
前人
[
编辑
]

當年走馬錦城西，曾為梅花醉似泥。二十里中香不
斷，青陽宮到「浣花溪。」

《觀梅》
前人
[
编辑
]

春暖山中雲作堆，放翁艇子出尋梅。不須問信道傍
叟，但覓梅花多處來。

《雪後尋梅》
前人
[
编辑
]

雙鵲飛來噪午晴，一枝梅影向窗橫。幽人宿醉閒欹
枕，不待聞香已解酲。

又

竹籬曲曲水邊村，月淡霜清欲斷魂。商約前身是飛
燕，玉肌無粟立黃昏。

《紅梅》
前人
[
编辑
]

雪裏溪頭已占春，小園又試晚妝新。放翁老去風情
在，惱得梅花醉似人。

《梅花》
前人
[
编辑
]

家是江南友是蘭，水邊月底怯新寒。畫圖省識驚春
早，玉笛孤吹怨夜殘。冷淡合教閑處著，清癯難遣俗
人看。相逢剩作樽前恨，索笑情懷老漸闌。

又

月地雲階暗斷腸，知心誰解賞孤芳。相逢只怪影亦
好，歸去始驚身染香。渡口耐寒窺淨綠，橋邊凝怨立
昏黃。與卿俱是江南客，剩欲樽前說故鄉。

《十二月初一日得梅一枝絕奇戲作長句》
[
编辑
]

前人

高標已壓萬花群，尚恐嬌春習氣存。月兔擣霜供換
骨，湘娥鼓瑟為招魂。孤城小驛初飛雪，斷角殘鐘半
掩門。盡意端相端有恨，夜寒皴玉倩誰溫。

《浣花賞梅》
前人
[
编辑
]

老子人間自在身，插梅不惜損烏巾。春回積雪層冰
裏，香動荒山野水濱。帶月一枝低弄影，背風千片遠
隨人。石家樓上貪吹笛，肯放朝朝玉樹新。

《山亭觀梅》
前人
[
编辑
]

「與梅歲歲有幽期，忘卻如今兩鬢絲。」乘淡月時和雪
看，斸蒼苔地帶花移。先春瘦損應多恨，靜夜香來更
一奇。醉倒欄邊君勿笑，明朝紅萼綴空枝。

《射的山觀梅》
前人
[
编辑
]

凌厲冰霜節愈堅，人間乃有此癯仙。坐收國士無雙
價，獨立東皇太乙前。此去幽尋應盡日，向來別恨動
經年。花中竟是誰流輩，欲許芳蘭恐未然。

《古梅》
前人
[
编辑
]

《梅花》吐幽香，百卉皆可屏。一朝見古梅，梅亦墮凡境。
重疊碧蘚暈，夭嬌蒼虯枝。誰汲古磵水，養此塵外姿。

《梅花》
前人
[
编辑
]

山月皜中庭，幽人酒初醒。不是怯清寒，愁蹋梅花影。

《普明寺見梅》
楊萬里
[
编辑
]

「城中忙失探梅期，初見僧窗一兩枝。猶喜相看那恨
晚，故應更好半開時。」「今冬不雪何關事，作伴孤芳卻
久伊。」月落山空正幽獨，慰存無酒且新詩。

《梅花下小飲》
前人
[
编辑
]

今年春在臘前回，怪底空山早見梅。數點有情吹面
過，一花無賴背人開。為攜竹葉洗瓊樹，捉折冰葩浸
玉杯。近節雨晴誰料得，明朝無興也重來。

《梅坡》
前人
[
编辑
]

淺水低坡幾樹苔，冷光搖動玉塵埃。橫斜直似安排
得，古怪多應折損來。潔白要從侵夜看，飄零卻是被
春催。閒行立斷清風影，一片飛香落酒杯。

《池亭雙樹梅花》
前人
[
编辑
]

開盡梅花半欲殘，兩枝晴雪作雙寒。團欒遶樹元無
見，只合池亭隔水看。

《南齋梅花》
前人
[
编辑
]

朝來早起挂南窗，要看《梅花》試曉妝。兩樹相挨前後
發，老夫一月不「燒香。」

《瓶裏梅花》
前人
[
编辑
]

膽樣銀瓶玉樣梅，北枝折得未全開。為憐落寞空山
裏，喚入詩人几案來。

​
雪凍霜封稍欲殘，殷勤折向坐中看。綺窗深閉珠簾

密，不遣花愁半點寒。

前人
[
编辑

山間幽步不勝奇，正是深寒淺暮時。一樹梅花開一
朵，惱人偏在最高枝。

《慶長叔招飲花下》
前人
[
编辑
]

長廊盡處繞梅行，過盡風聲得雪聲。醉裏不愁飄濕

《道傍梅花》
前人
[
编辑
]

一徑誰栽十里梅，下臨溪水恰齊開。此行便是無官
事，只為梅花也合來。

《蠟梅》
前人
[
编辑
]

江梅珍重雪衣裳，薄相紅梅學杏裝。渠獨小參黃老
面，額間艷艷發金光。

又

蜜蜂底物是生涯，花作餱糧蠟作家。歲晚略無花可
採，卻將香蠟吐成花。

又

天向梅梢別出奇，國香未許世人知。殷勤滴蠟緘封
卻，偷被霜風折一枝。

又

香蜜栽葩分外工，疏枝數點綴雛蜂。嬌黃染就宮妝
樣，香暖猶宜愛日烘。

《瓶中梅花長句》
前人
[
编辑
]

幽人蚤作月滿階，月隨幽人登船齋。推門欲開猶未
開，猛香排門撲我懷。徑從鼻孔上濯頂，拂拂吹盡髮
底埃。恍然墮我眾香國，欲問何祥無處覓。冥搜一室
一物無，瓶裏一枝梅的皪。平生為梅到斷腸，何曾知
渠有許香。夜來偶忘挂南窗，貯此幽馥萬斛強。卻憶
去年西湖上，錦屏下瞰千青嶂。谷深梅盛一萬株，千
頃雪波浮欲漲。是時雨後初開前，日光烘花香作煙。
政如新火炷博山，蒸出沈水和龍涎。醉登絕頂撼疏
影，掇葉餐花照冰井。蜀人老張同舍郎，喚作謫仙儂
笑領。如今茅屋臥山村，更無載酒來叩門。一尊孤斟
懶論文，猶有梅花是故人。

《梅花下遇小雨》
前人
[
编辑
]

偶來花下聊散策，落英滿地珠為席。繞花百匝不忍
歸，生怕幽芳怨孤寂。仰頭欲折一枝斜，自插白鬢明
