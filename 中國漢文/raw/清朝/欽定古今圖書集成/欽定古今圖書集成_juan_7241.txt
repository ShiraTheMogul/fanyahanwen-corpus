明十五

编辑
]

曾猷
[
编辑
]

按《建昌府志》：「曾猷，字獻嘉，號裕齋，南豐人，庠生。性質
嚴毅，自少慕古，其文行不與時類，食不重肉，寒不衣
絮，議論動止，硜硜如也。將貢被黜，不少介意，讀書山
室，浩歌自得。」

黃隆
[
编辑
]

按《建昌府志》：「黃隆，南豐人。富而好行其德，歲饑，賴以
救，活甚眾。餽餉禦寇，全城之功尤大。」

湯邦翰
[
编辑
]

按《建昌府志》：「湯邦翰，字良甫，號純齋，南豐人。舉人，祀
縣鄉賢，事祖父母以孝聞，撫二孤姪，讓以餘產。有宰
牛者，縣罰金為公車費，翰還其金，勸以改行，卒為良
民。將謁選，見守令事上屈抑，志不得行。曰：『吾豈能隨
俗俯仰，自負所學乎』？遂終身不仕，好讀《性理大全》及
陶詩，雖耄期，手不釋卷。」

黃有仁
〈子鳳陽〉
[
编辑
]

按《建昌府志》：「黃有仁，字新甫，太學生，官州同知。績茂
循良，致隆恬隱。夙厚樹典型以矜式諸人，更樂施賑
恤而佐成大政。賦性簡默厚重，和易，安閒修己講學，
綽有古賢哲遺蹤。居恆孝友天植，仁慈夙成。即今年
春，天災流行，饑疫相尋，郡邑餓殍盈村，骸胔遍埜。偕
其仲子鳳陽，出帑金，發倉粟，施棺給粥無算。儻所謂
『富而好行其德』」者，非耶？

黃文經
[
编辑
]

按《建昌府志》：「黃文經，字景綸，號桓撥，南豐人。中進士
第，湘潭知縣。湘邑城卑僅可數尺許，捐俸增築，屹然
改觀。卻藩使，拒紳牘，校士以公，清驛惟嚴。歸遇歲荒，
開倉以待，活者無算。性和易，與人言，洞見肺腑，橫逆
至者，不與較。常曰：難處之事，應之以寬；難處之人，待
之以恕。教子弟惟以朴誠謙厚，雖處失意，未嘗有慍」
色，曰：「造命吾所不能，吾所知者，安命而已！」疾革時，鄉
人日禱于家。既沒，有撫棺而慟者。

===鄧瑜===
​
按《建昌府志》：「鄧瑜，字宜清，新城人。嘗發粟賑饑，官表

其門曰『彰義坊，為學宮造橋、造門，又割田二百畝以
助。今學田尚存，義士之名尚在，而子孫無復知者』。」

涂瀗
[
编辑
]

按《建昌府志》：「涂瀗，字毓秀，號霽川，新城人，欽元孫，舉
人，潯州知府，永嘉稱難治，調劑周勤，不事聲色吏牘
民志久益晏然。有問其得民之道，曰：『無他，惟積誠而
已』。其家居見盜夜潛於廁，呼出慰贈遣之，不問其名
姓。」

王二存
[
编辑
]

按《金谿縣志》：王二存，家於世，宦城南學前里。幼穎慧，
博洽經史。及弱冠，補弟子員，食邑餼，立城南文社，約
同志者數人，悉屬谿邑領袖。不數科而前後登科甲。
存獨艱於嗣，喟然曰：「功名之被於一身者輕，而苗裔
之係於宗祧者重。」遂視呫嗶為餘事，以積德累行為
兢兢。凡立渡立橋賑乏者不一。猶慮其施之不廣也，
予人以可受之名，曰「無息債。」誠於布德施惠，罔間親
疏，天之報善不爽。果舉五子，長幼俱補邑庠，孫支世
守，其德不替云。

車元俊
[
编辑
]

按《金谿縣志》：「車元俊，字沖甫，忍叟其別號也。幼讀書，
不為章句之學，弱冠偕廉憲肄業南雍。當承平右文
之世，留京人士，霞蔚雲蒸。未幾，廉憲獨捷京闈，成進
士。俊數奇不售，歸里，不復問京兆事。廉憲治兵秦楚，
用勞瘁卒官。俊痛心先烈，于國家典章制度，兵餉扼
塞，多所咨識，名聞諸公。方伯王龍友特舉應賢良之」
詔，而俊謝絕弓旌，人以龔勝、管寧。方之歲凶，發粟以
賑饑者，市纊以衣寒者，周人緩急惟恐後，不計其報。
厥嗣趾美光大。先人之烈，固有在此而不在彼者，可
不謂有道仁人哉！

蔡文淯
[
编辑
]

按《金谿縣志》：蔡文淯，王二存，長女子也。幼穎異，年甫
十三，應童子試，郡侯蘇閱三奇首拔，以冠六邑。鄉紳
默吾李愈大奇之，而以長孫諱大覺之姊妻焉。六試
棘圍，三登乙榜。族有貧賣妻者，淯檢囊中無所有，將
居肆鬻之，以全其偶。族與鄰鬨淯曰：「鄰好不可傷也。」
代出金修睦焉。值途有遺金，淯偶拾之，必密訪全還，
行誼篤摯類如此。子筮亨，邑庠生。

樂譜
[
编辑
]

按《東鄉縣志》：「樂譜，字叔和，邑庠生，長林人，崙之曾孫，
廷槐之孫也。生平敦信義，尚風節，好周人急，有古慷
慨俠烈之行。會秦、晉、齊、豫饑，譜聞之，首助穀二百石。」

何鏜
[
编辑
]

按《東鄉縣志》：「何鏜，何坊人，邑庠生。闇然自修，賑貧恤
孤，厚與薄取。前令周莓厓、蔡龍屏俱以詩文贈之。都
御史以旌善匾其廬。」

俞朝貴
[
编辑
]

按《東鄉縣志》：「俞朝貴，橫山人，邑庠生。天性孝友，持己
端方，有古人風。鄉里以忿爭求質，徐出一言解之。有
為不義者，愧懼不令其知，舉鄉飲賓，力辭不赴。」

何東
[
编辑
]

按《東鄉縣志》：「何東，何坊人。為諸生時，力學不倦，天性
孝友，與人誠確不欺，以善行著于鄉縣，採其實聞之
撫按，賜布帛，匾其廬。復獎以孝親尊祖，友愛來弟族
之歡，賑乏恤孤，德義重存沒之感云。」

龍珝
[
编辑
]

按《吉安府志》：「龍珝，永新人。以上舍謁選京師，值鄒忠
介抗疏劾江陵，廷杖幾斃，一時知交親暱無敢近者。
珝初未相識，亟往救之，躬負入獄，朝夕護視，人服其
義。」

王元統
[
编辑
]

按《吉安府志》：「王元統，安福人。八歲而孤，事母孝。有堂
兄利其居，輒踞之，忍而不較。家貧陋巷種樹課農桑，
自給晏如也。力學，通經史，數奇弗售，遂棄舉子業，庭
訓肅睦。見學者與其子言正言，行正行，則大喜，留坐
終日。若棋酒諧謔，則拂然屏處不願見，曰：『蘭艾薰蕕，
不可不別也』。以故子貴不敢驕人。獨創祖祠，建義倉」，
多行善事，當路重其行。祀鄉賢。著有《日恭子》。

李尚德
[
编辑
]

按《吉安府志》：「李尚德，號如賓，吉水人。性豪爽任俠，刻
勵讀書不第，改冑監為真定府幕。時熊廷弼為司李，
重其才，引置左右，凡所設施，皆其措畫。熊與太守不
合，恨尚德附熊，誣以事，後寤遂釋。尚德遂棄簪冠歸
里，里中貧乏，悉仰給之。園池居室，為族人侵踞，亦弗
較，曰：『吾有子幸能讀書，不憂貧也』。與同邑曾同亨一」
意為地方興除，如修學宮及雪浪閣，復同江水次本
里保禦，皆其經營，不遺餘力。里人至今賴焉。

彭日新
〈子際遇〉
[
编辑
]

按《吉安府志》：「彭日新，安福人。官經歷，即棄不仕。性仁
厚，軫恤親族，周人困急。年九十四，屢舉賓飲。其子際
遇如其官。亦好行陰德，或轉貸于人，不遺餘力。有嫁
​
其妻償逋者，遇代酬之，其人竟不知姓名。世德隱行
如此。」

羅士友
[
编辑
]

按《吉安府志》：「羅士友，字兼善，一字晉卿，世為廬陵之
新安人。士友生五歲，容止去幼度。未弱冠喪父，即取
先逋券焚棄之，曰：『迫人非仁也。人有急，亟振之，有負
之者，無少動于色。久之，自悔愧且死，而士友益恩恤
其妻子。士友為人謹約，旦起盥櫛畢，危坐堂中，終日
不惰倚，雖盛寒暑以為常。端靜對賓客，賓客或不能』」
自持，閨中無敢疾呼，女隸無敢近几席。由是里之言
家法者，皆曰：「羅氏遺文有《史編》及諸家詩體。」

鄒匡明
[
编辑
]

按《吉安府志》：「鄒匡明，字子尹，安福人，四山第四子也。
負才學，為太學生，嘗歷南北雍，兩中副榜，一擬解元，
不果第。已乃棄去，遊學于燕趙齊楚閒。性孝友，與人
無畛域。為季父後，得所遺七千金，施予立盡。常過宜
黃，出三十萬文為涂氏子酬逋。涂氏子素未常識明
也。其豁達類如此。邑北濱大江，涉者苦之，四山倡建」
鳳林橋，功未竟，罄其家給之，復不足。於是披緇乞助
于人，橋賴以成。沒祀鄉賢。所著有《苦竹》《淡竹》《法雲》《翰
音、駢語》等集。同邑趙士康《讀書目》十行下；長詩古文
辭，後學有疑義及古事，皆折衷之。所著有《蟬吟詩》《可
矣軒》《覽古彙編》《桃源日聽》。

李挺
[
编辑
]

按《吉安府志》：「李挺，號一吾，安福人。為邑諸生，師事劉
三五，倡學南里，有時瞑目習靜，望如木偶。邑侯閔世
翔高其行，破格造請，邑中興除大利害，多所取裁，而
挺不言其事。有富民為仇家所中，侯密以訊挺，挺對
不知。數問乃對曰：『果係渠惡，挺獨不聞乎』？侯領之，事
竟寢。又有投匿名書于縣，而署名其尾，挺笑曰：『既云
匿名，復自署之，詎人情乎』？」侯服其敏達，釋之。挺中表
大宰歐疾革，念挺貧，授以金，不納，則投以田，亦不納。
歐曰：「非以云贈，實為托吾孤也。」挺曰：「撫孤事重，厚托，
誓不敢受。」挺故貧，或日不再食，歲不易衣，晏如也。隱
行節操，不可勝紀，授徒甚眾。同里李道卿多隱行，其
高弟云。

夏夢夔
[
编辑
]

按《吉安府志》：「夏夢夔，號雲屏，安福人。棄舉子業不就
試，從學鄒文莊，讀書南嶽，三年而歸。邑令閔師事之。
邑清丈田畝，左右文莊，剔弊除害，至今賴焉。常為母
市材於楚。時劉虞部榷荊州，與夔夙契，不一謁。劉揖
之河干，欲有所屬。夔正色曰：『某來為母須材，非有所
求也』。有巨商以誣越關，沒貨萬計，商持千金來請，夔」
曰：「吾生平未嘗以私干人。」及歸，劉餞之舟中，因語劉
曰：「某昨夜舟中聞有越關得罪者，實出於誣。」語畢，解
纜去。劉遂釋其人，曰：「非江西夏某幾冤爾。」商齎數百
金追謝，夔曰：「彼自恤爾，吾未嘗言也。」堅弗受，商感泣
去。事親孝，父病篤，為之嘗惡。及居喪，寢苫廬墓悉中
禮。年七十五，以壽終。《易簣》時，諸賢達以祠鄉賢為請，
堅持不可；口占一律，乃瞑。

羅晉用
[
编辑
]

按《吉安府志》：「羅晉用，字楚材，太和人。生平畏事如處
女，言若不出諸口，擇所與交，不過幾人。曾學醫，得異
傳，無問富貧，一應之。雖屢著奇效，而終不言利與人。
退然不以醫自名。常言吾愛龐安，輕財如糞土，耐事
如慈母。人以為晉用實似之。劉雲章、陳海桑皆稱之
為篤行君子云。」

歐陽務本
[
编辑
]

按《吉安府志》：「歐陽務本，號雲谷，廬陵人。性慷慨，急大
義，嘗捐貲建祠，為族人營婚葬，傾橐無所靳。歲甲寅，
邑里大歉，乃罄囷中粟哺饑。時兵憲吳檄民輸粟者
予冠帶，里中士將摭其事以應，辭弗受。常遊粵西全
州，信義孚於人。時西延猺以私忿內訌，州大夫不能
制，奉檄往諭，力陳利害，猺遂帖然。州大夫嘉其能，全」
人稱焉。晚歲夷猶田閒，對客徐引，談笑風生，人欽其
雅度云。年八十，以壽終。以子貴，贈南京兵部主事，祀
「鄉賢祠。」

周啟龍
[
编辑
]

按《吉安府志》：「周啟龍，號雙池，安福東鄉人，後徙居郡
西。事父母孝謹，親沒，廬墓三年，哀慟中禮。居平守正
不阿，周人困乏，人有疾病扶持之，貧不能殯者殯之。
歲戊寅旱，捐囷以活貧者。年八十四，以壽終。」

朱繼德
〈子吾楫〉
[
编辑
]

按《瑞州府志》：「朱繼德，高安人，善士達善之子也。任真
定衛經歷，頗有能聲。復委署稿城邑篆，大得民心，至
攀轅不忍捨。任三載，以親老乞養，三院薦留不得，益
羨其高。旋丁父憂，養母孝敬備至，敦睦族黨，內外無
閒言。平生見老貧孤寡，憐而周之，施屨以濟途人無
算，修建飛仙等橋十數區。生平兢持至老，為善不倦」，

柯頌功
[
编辑
]

按《德安府志》：「柯頌功，字元川，先世孝感白雲山人，以
三世祖志能館甥於安陸呂千戶溳潭，遂家焉。頌功
早補諸生，為文不起草，援筆立就，試輒冠軍，志節耿
介如石，落落寡合，居恆矜重自持，雖盛夏冠裳秩如
也。閉戶讀書，不問家人生產，以此益食貧。性至孝，父
大梁，字子任，將以歲貢謁選，時年六十矣。頌功歎曰：
『父年屆杖里，猶奔走京洛，從明經起家。毋乃菽水不
給於養乎？人子之過也』！」因痛自省責。父嘗病，殆不起
​
頌功日夜侍湯藥，睫不交，泣禱於神，請以身代，竟得
瘥。後四年，父沒，喪葬易戚咸備，事繼母尤以孝聞。搆
一樓於先祠後，訓誨子弟，肅然朝典。一日，盛暑登樓，
見其子文跣足欹坐，怒曰：「居處恭，當如是耶？」及甲午，
文登賢書，而頌功亦由選貢考授縣職。顧文性和易，
雅好音律歌舞，偶為詞贈歌者，頌功聞而大怒不已，
杖之。其嚴峻如此。戊戌，文成進士，筮仕蜀之富順，頌
功教以當官之要曰：「廉生公，公生明，明生斷，根本既
立餘，則遊刃有餘爾。」文迎養甚懇，頌功答曰：「使富順
農安於野，商安於市」，士大夫無閒言，即戲綵承歡不
啻也。竟不往。身課農桑猶然，貧諸生不復與戶外事。
及文入為西曹，躬具版輿頌功，終不肯入京邸。於後
園築一土屏，植海棠百本於茅齋前，日引子孫讀書
其下。所著有《海棠屏集》十餘卷，《家訓遺矩》一篇。嘗語
其季子亹之婦父右藩楊芷曰：「吾於古人《法言》中服
膺君家敬仲」四語，如「讀書以饑餓為進道，居家以無
事為平安，二者吾庶幾焉。至若仕宦，以孤寒為安身，
君殆得其家法」意。許芷不附時相以求開府也。時人
以為篤論文之。同年友大司馬熊廷弼心重之，為作
《傳》。弟頌德，字洞廷，癸酉舉人。頌功子六人：文、齊、京、奕、
亹立。
