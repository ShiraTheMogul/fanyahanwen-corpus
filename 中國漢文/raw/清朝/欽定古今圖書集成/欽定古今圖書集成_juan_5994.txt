徐弘修妻田氏
[
编辑
]

按《荊州府志》：「田氏，江陵諸生徐弘修妻。崇禎癸未春，
賊破白兔湖，修死之。氏哭奔溺水。水淺，賊追援，欲犯
之，氏伏泥中大罵被害。」

李曙實妾潘氏
[
编辑
]

按《荊州府志》：「潘氏，宜都諸生李曙實妾。崇禎末，王寇
殺曙實，逼氏為媳。潘開便門投河死。三日尸浮，顏色
如生。」

涂昇庸妻王氏
[
编辑
]

按《荊州府志》：「王氏，江陵涂昇庸妻。有儉德，甘貧窘。壬
午賊至，昇庸被害。氏罵賊攖其怒，捽氏，髮控馳十餘
里，至馬驛街，逼之，不屈，縛於杵殺之。」

王運達妻姜氏
[
编辑
]

按《荊州府志》：「姜氏，興山王運達妻。崇禎時，夫妻避亂
巖谷，遭賊掠，欲污之。氏堅不從，逼以刃，氏曰：『汝釋吾
夫身，則聽汝』。」賊如其言，氏度夫去遠，墜巖而死。

萬邦孚妻李氏
[
编辑
]

按《荊州府志》：「李氏，遠安萬邦孚妻。崇禎甲戌，賊犯遠
安，李被掠，欲辱之，大罵不屈，為所磔。」

涂麟妻殷氏
[
编辑
]

按《荊州府志》：殷氏，江陵涂麟妻。年三十夫亡。壬午闖
賊陷荊，二子執去。殷被逼藏牆中，夜靜，以書櫃縱火
而焚，手抱孫女泣曰：「吾身守節多年，汝亦不幸為女
於此，不死更待何時！」遂與共死。殷二子脫歸，從鄰嫗
得骸骨葬焉。

[
编辑

按《荊州府志》：「某氏，施州衛黃鼎妻。兵燹之後，夫亡無
棺，氏積薪與夫同焚。」

编辑

沱，投水死。越二日，母子同浮水面。」

劉氏
[
编辑
]

按《荊州府志》：「劉氏，江陵劉汝濟女。年十八，其夫某罹
賊難死，劉矢志孀居。甲申獻逆大掠，倉卒出走，與祖
母蕭同被執。劉謂祖母曰：『吾家世清白，今日之事，有
死而已』。遂赴水死。旬日，汝濟得其尸，並其夫合葬。」

繡衣女子
[
编辑
]

按《荊州府志》：繡衣女子，不知何許人。荊賊犯之，不從，
囚之別室，遣老嫗勸諭之，違則殺焉。女曰：「妾已名登
鬼錄，非死不欲聞。所乞於媼者，死後以抔土掩吾體
耳。」遂俛首受刃，顏色不變。觀者咸為流涕。

[
编辑

仕。值大亂，不獲歸，乃流寓興山卦子山寨。李來亨破
其寨，見氏美，殺玉衡，欲掠氏。氏紿曰：『埋吾夫則從汝』。」
賊從之，埋畢，氏抱幼女墜巖死。

[
编辑

相與徬徨終夜。及曉，兵果至，遇其婢于門，殺之，驅英
武及妻女俱去。行數十武，縛英武鍛之，索其金，英武
告以窶貧，恃館穀自養，僅餘數金置某所，眾兵爭取
之，黃亟挈二女共躍入池中死。時沍寒，池冰將結，軍
士欲挽之，已無及。相顧愕眙，乃拔刀斫英武。及兵退，
英武竟得甦，訊妻女所在。越數日，池冰解，三尸俱浮
​
顏色如生。兩女猶堅握母裾不釋。聞者莫不悲之。

编辑
]

按《建昌縣志》：「王氏，釣臺鄉鄒廛六妻。崇禎癸未，左兵
驅掠群婦至清橋，氏不肯度，兵持刀下馬，逼之，氏前
奮擘摑，裂眥穿頰，迸血纍纍。兵怒殺氏，割截十指，抉
口鑿齒而去。」

呂遠四妻胡氏
[
编辑
]

按《建昌縣志》：胡氏，名梅貞，呂遠四妻。歸三載，夫亡，乃
還侍母。聞左兵掠污婦女，方食投箸。亡何，兵南去，越
兩日復返，大索山谷。梅貞被執，則矯指絰冠曰：「我新
孀，願隨將軍。但夫遺百金，可惜為他人有。」兵挾氏往，
就藏金處，過泉塘堤，氏從馬上躍入塘。兵恚，下石塘
內，已又向塘三叩頭而去。

但驄妻傅氏
[
编辑
]

按《建昌縣志》：「傅氏，永豐鄉學訓民望女，嫁星子縣但
驄。崇禎末，潰將郝效忠摽掠過星子，望高門大閥即
屯營，遂蟠但氏宅，殺驄，驄父及弟皆遇害。乃逼傅殺
其乳下兒，懼之，血流沾胸，傅無撓色，罵賊而死。賊行
至建昌白槎，會鄉勇四，合馬步四百餘人，一鼓殲焉。」

夏既瑚妻毛氏
〈朱氏附〉
[
编辑

按《九江府志》：「毛氏，德化人，名大姑，省祭毛光卿女。母
廖氏，早寡，撫子明遴及大姑，誓守清操。大姑長適瑞

魏光宇妻陳氏
〈孫氏余氏附〉
[
编辑
]

按《九江府志》：「陳氏，德化人，魏光宇妻，諸生可遠母。生
三子，早寡，截髮自誓，甘貧守節。娶三婦俱賢，季婦孫
氏尢孝。崇禎末，城危，孫攜姑避禍母家，姑婦指庭前
井曰：『此吾二人致命處也』。」孫氏嫂余氏聞其語，欣然
相約。城尚未陷，先期數日，三人以次投井而死。

宋景賢妻張氏
〈二女附〉
[
编辑
]

按《九江府志》：「張氏，德化人，庠生宋景賢妻。幼讀書，通
大義。景賢貧，教授生徒以養親。張節口求甘旨以供
舅姑。城將陷，張于一室纍木器，積薪于上，謂其夫曰：
『此妾致命所也』。」城破，果舉焰自焚而死。二女：一適廖，
投繯死；一適毛，奪賊刀自殺。

繆用中妻陳氏
[
编辑
]

按《九江府志》：「陳氏，德化諸生繆用中妻。年二十八，夫
死，遺二子極幼。氏治夫喪畢，家益窘。諸親勸改適，陳
泣曰：『死即死耳，苟失節，何以見亡夫于地下』？毀面為
誓，事姑終天年，喪葬如禮，教二子最嚴。左師陷城，自
縊死。」

王秉陽妻洪氏
[
编辑
]

按《九江府志》：洪氏，彭澤王秉陽妻，故宦王演疇媳，洪
維幹女。左逆南下，逃陶潭鄉，遇賊，欲掠氏去，罵曰：「吾
父何人，吾翁何人，汝敢辱我！」厲罵不屈。賊怒，拔刀砍
其左臂，復斬其首。

萬世奇妻朱氏
[
编辑
]

按《瑞昌縣志》：朱氏，萬世奇妻。李賊寇瑞昌，氏度不能
自全，歎曰：「計惟一死，可以見舅姑于九原，恨不得吾
夫與子一永訣耳。」俄頃，曰：「必俟面訣，將不得死所。」遂
自殺。

编辑

按《貴溪縣志》：吳氏，畢貞士妻。嫁二十餘年無嗣，事姑

揭廷才妻傅氏
[
编辑
]

按《廣昌縣志》：傅氏，廩生揭廷才妻。年十七于歸，踰年，
才亡，傅哀慟欲殉，姑諭之曰：「予年八十，且盲，汝死，予
安能獨生？」傅乃感悟，遂以刀破面，誓無二志，勤織紝
以養姑。姑病，百計莫療，刺血和湯以進。逾數年，姑沒，
傅泣曰：「前未敢殉夫者，為姑也。姑逝，予何為生？」遂絕
粒七日而死。
