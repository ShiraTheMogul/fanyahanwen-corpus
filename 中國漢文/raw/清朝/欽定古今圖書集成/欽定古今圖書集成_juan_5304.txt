劉元佐
[
编辑
]

按《唐書劉元佐傳》：「元佐，滑州匡城人，犯法亡命，從永
平軍，稍為牙將。大曆中，李靈曜據汴州反，元佐乘其
無備。」
取宋州，詔以隸李勉，即表署刺史。德宗建中
初，李納叛，元佐大破納兵。李希烈反，元佐數困賊。帝
在奉天，垂意關東，乃詔檢校尚書左僕射，加汴宋節
度使、陳州諸軍行營都統。元佐本名洽，至是賜名以
尊寵之。假子樂士朝私元佐嬖妾，懼事覺，酖元佐死，
諡曰「壯武。」眾起元佐子士寧於喪，帝遂以士寧為左
金吾衛將軍，嗣節度。士寧忍暴，嘗手殺人，其下厭苦
不服。嘗畋城南未還，李萬榮分兵閉諸門，士寧奔京
師。

劉士涇
[
编辑

按《唐書劉昌傳》：「昌子士涇，尚雲安公主，拜駙馬都尉，
累遷少卿。家積財，內結權近，後遷太僕卿，給事中。」

劉忠翼
[
编辑
]

按《唐書黎幹傳》：「德宗在東宮，幹與宦者特進劉忠翼

有寵於代宗。當盛時，爵賞在其口吻，掊冒財賄，貲產
累皆巨萬，至是積前罪誅。」

劉太真
[
编辑
]

按《唐書劉太真傳》：「太真，宣州人，善屬文，舉高第進士，
淮南陳少遊表為掌書記。興元初，為河東宣慰賑給
使，累遷刑部侍郎。貞元四年，遷禮部，掌貢士，多取大
臣貴近子弟，坐貶信州刺史，卒。」

劉怦
[
编辑
]

按《唐書劉怦傳》：「怦，幽州昌平人，少為范陽裨將。朱滔
時，積功至雄武軍使李寶臣以兵擊滔于瓦橋，滔走，
寶臣乘勝欲襲幽州，怦設方略，勒兵完守，滔敗歸，終
不二。及。滔死，軍中盡推怦，乃總軍事。俄詔為節度副
大使，居鎮纔二月，死，諡曰恭。」

劉滋
[
编辑

按《唐書劉子元傳》：「子元子貺。貺子滋，字公茂，通經術，
喜持論。以廕歷漣水令，累授左補闕。興元元年，以吏
部侍郎知南選。貞元二年，擢左散騎常侍同中書門
下平章事。為相無所設施，廉抑畏慎而已。明年罷。又
明年，復為吏部侍郎，遷尚書，卒諡曰貞。」

劉濟
[
编辑
]

按《唐書劉怦傳》：「怦子濟，字濟，游學京師，第進士，歷」

州刺史怦病，詔濟假州事。及怦卒，嗣節度，累遷檢校
尚書右僕射、同中書門下平章事。王承宗叛，濟裨將
譚忠激濟伐承宗，拔饒陽，屯瀛州，進攻安平，命次子
總以兵八千先登，拔其城，進中書令。濟之出，以長子
緄攝留務，總為行營都知兵馬使。濟病甚，總與左右
親近謀寘毒，濟飲而死。緄至涿州，總矯濟命殺之，諡
曰《莊武》。

劉澭
[
编辑
]

按《唐書劉澭傳》：「澭，盧龍節度使怦之次子，濟母弟也。
涉書史，有材武，好施愛士，能得人死力。為瀛州刺史，
請以所部為天子戍隴，悉發其兵千五百馳歸京師，
無一卒敢違令者。德宗甚寵之，拜秦州刺史，番戎畏
懾，不敢入寇。封累彭城公，卒諡曰景。」

劉昌裔
[
编辑
]

按《唐書劉昌裔傳》：「昌裔字光後，太原陽曲人，客河朔
間。曲環方攻濮州，表為判官，為環檄李納剴曉大誼，
德宗異之，累遷營田副使。環卒，上官涗知後務。吳少
誠引兵薄城，涗欲遁去，昌裔止之。賊攻堞，壞不得修，
昌裔密造飛棚聯柵，募突將鑿城以出，擊賊走之。比
還，柵已立，守陴遂安。兵馬使安國寧謀應賊，昌裔以」
計斬之，以功擢陳州刺史，改陳許行軍司馬。涗卒，軍
中推昌裔，有詔檢校工部尚書。元和八年，召還京師，
卒，諡曰威。

姓，故改焉。性忠強，識義理。平涼之盟，在渾瑊軍中，被

劉禹錫
[
编辑
]

按《唐書劉禹錫傳》，「禹錫，字夢得，自言系出中山，世為
儒，擢進士第，登博學宏詞科，為監察御史。時王叔文
得幸太子，禹錫與之交。憲宗立，叔文等敗，禹錫斥朗
州司馬，易連州，又徙夔州。入為主客郎中，復作《游元
都詩》以詆權近，聞者益薄其行。裴度雅知禹錫，薦為
禮部郎中。度罷，出為蘇州刺史，徙汝、同二州，遷太子」
賓客。禹錫恃才而廢，年益晏，偃蹇寡所合，乃以文章
自適。素善詩，晚節尢精，《白居易》推為「詩豪。」會昌時，加
檢校禮部尚書，卒。

劉軻
[
编辑

按《摭言》：「劉軻慕孟子文」，故名焉。少為僧，止于豫章高
安之果園。後復求黃老之術，隱於廬山。既而進士登
第，文章與韓、柳齊名。

劉闢
[
编辑
]

按《唐書韋皋傳》：「劉闢，字太初，擢進士宏詞科，佐韋皋
府。皋卒，闢主後務。憲宗以給事中召之，不奉詔。時帝
新即位，欲靜鎮四方，拜檢校工部尚書，劍南西川節
度使。闢意帝可動，益驁蹇，求統三川。杜黃裳薦高崇
文等將神策行營兵皆西，詔許自新，闢不聽。崇文取
東川，帝乃下詔奪其官，進破鹿頭關，遂下成都，闢從」
數十騎走至《羊灌》田，自投水不能死，擒之，檻車送京
師，斬于城西南獨柳下。子超郎等九人以次誅。

劉全諒
[
编辑
]

按《唐書董晉傳》：「宣武節度董晉死，司馬陸長源總留
後事。長源死，監軍俱文珍密召宋州刺史劉全諒使
總後務，即詔全諒檢校工部尚書、宣武節度使。全諒
始名逸淮，至是賜名，本懷州武涉人也。父客奴，以行
戍籍幽州，事平盧軍，以材力顯。開元中，拜左驍衛將
軍。天寶十五載，以為柳城郡太守，賜名正臣，為王元」
志酖殺之。全諒事劉元佐為牙將，以勇果善騎射累
兼御史中丞。及元佐子士寧代立，疑宋州刺史翟良
佐不附己，以全諒代之，故汴將士多歸心焉。視事凡
八月，卒。

劉悟
[
编辑
]

按《唐書劉悟傳》：「悟其祖正臣，平盧軍節度使。悟豪橫
犯法，繫河南獄。留守韋夏卿貸免，李師古迎之，始未
甚知，後從擊毬，軒然馳突，撞師古馬仆，師古恚，將斬
之，悟盛氣以語觸師古，師古奇其才，令將後軍。師道
被討，田弘正兵屯陽穀，悟徙營潭、趙、魏師踰河取盧
縣，壁阿井。城中亂語，謂悟當為帥。師道內疑，遣使兩」
輩來責戰，密語其副張暹，使殺悟。暹以情告，悟乃召
諸將議，夜半薄西門殺師道。即拜悟義成節度使，封
彭城郡王。元和十五年來朝，進檢校兵部尚書。穆宗
立，徙昭義軍，進兼幽鎮招討使，治邢州。與監軍劉承
偕不葉，以兵圍監軍，殺小使，帝貶承偕。然悟自是頗
專肆，上書言多不恭。寶曆初卒。

按《唐書劉子元傳》：「子元子貺，貺子浹，有學稱。生子敦

劉弘敬
[
编辑
]

按《尚友錄》：弘敬字元溥，彭城人。貲財巨萬，修德不耀，
人莫知之。長慶初，有善相者曰：「不久天期且至。」弘敬
曰：「壽夭天也，先生其奈我何？」相者曰：「夫相不及德，德
不及度量。君雖不壽而德且厚，於度量又寬。夫一德
可以消百邪，猶享厚祿，而況壽乎？」後有女將適人，抵
維揚，求女奴，用錢八十萬，得四人焉。內一人名蘭孫
者，風骨姿態，全不類賤，乃名家子也。弘敬曰：「此女衣
冠之後，不可婢使。」乃備妝資，先女嫁之。是夜，夢一人
​
曰：「我蘭孫父，荷君嫁女無以報，今告天，延君壽二十
四年。」後過一年，相者復至曰：「相君面可延二紀，行何
陰德而至此？」弘敬曰：「無他，不忍以貴為賤，嫁一婢耳。」
後果延壽二紀而終。

按《唐書劉克明傳》：「克明亡所來，得幸敬宗。帝獵夜還，

有信否？」昭文曰：「主上新平河南未熟，公名信曰：『漢有

按《五代史東漢世家》：「旻，漢高祖母弟也。初名崇。為人

甚銳。顯德元年，親征，戰於高平，旻大敗，以憂得疾。明
