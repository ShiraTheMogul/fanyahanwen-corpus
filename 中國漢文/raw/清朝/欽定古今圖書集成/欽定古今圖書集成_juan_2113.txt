《觀滄海》
魏·武帝
[
编辑
]

東臨碣石，以觀滄海。水何澹澹，山島竦峙。樹木藂生，
百草豐茂。秋風蕭瑟，洪波湧起。日月之行，若出其中。
星漢燦爛，若出其裏。幸甚至哉！歌以詠志。

《遊赤石進帆海》
宋·謝靈運
[
编辑
]

首夏猶清和，芳草亦未歇。水宿淹晨暮，陰霞屢興沒。
周覽倦瀛壖，況乃凌窮髮。川后時安流，天吳靜不發。
揚帆採石華，掛席拾海月。溟漲無端倪，虛舟有超越。
仲連輕齊組，子牟眷魏闕。矜名道不足，適己物可忽。
請附任公言，終然謝天伐。

《和劉西曹望海臺》
齊·謝脁
[
编辑
]

滄波不可望，望極與天平。往往孤山映，處處春雲生。
差池遠鴈沒，颯沓群鳧驚。囂塵及簿領，棄捨出重城。
臨川徒可羨，結網庶時營。

《小臨海》
梁·劉孝威
[
编辑
]

碣石望山海，留連降尊極。秦帝枉鉤陳，漢家增禮秩。
石橋終不成，桑田竟難測。蜃氣遠生樓，鮫人近潛織。
空勞帝女填，詎動波神色。

劉峻

编辑

滄潦聯霄岫，層嶺鬱巑崱。下盤鹽海底，上轉靈烏翼。
滇
非可辨，鴻溶信難測。輕塵久弭飛，驚浪終不息。
雲錦曜石嶼，羅綾文水色。

编辑

登高臨巨壑，不知千萬里。雲島相接連，風濤無極已。
時看遠鴻度，乍見驚鷗起。無待送將歸，自然傷客子。

浮天迥無岸，含靈固非一。委輸百谷歸，朝宗萬川溢。
分城碧霧晴，連洲彩雲密。欣同夫子觀，深愧元虛筆。

《春日望海》
唐·太宗
[
编辑
]

披襟眺滄海，憑軾翫春芳。積流橫地紀，疏派引天潢。
仙氣凝三嶺，和風扇八荒。拂潮雲布色，穿浪日舒光。
照岸花分彩，迷雲鴈斷行。懷卑運深廣，持滿守靈長。
有形非易測，無源詎可量。洪濤經變野，翠島屢成桑。
之罘思漢帝，碣石想秦皇。《霓裳》非本意，端拱且圖王

《奉和聖製春日望海》
楊師道
[
编辑

春山臨渤海，征旅輟晨裝。迴瞰盧龍塞，斜瞻肅慎鄉。
洪波迴地軸，孤嶼映雲光。落日驚濤上，浮天駭浪長。
仙臺隱螭駕，水府汎黿梁。碣石朝煙滅，之罘歸鴈翔。
北巡非漢后，東幸異秦皇。搴旗羽林客，跋距少年場。
電擊驅遼水，鵬飛出帶方。將舉青丘繳，安訪《白霓》裳。

《韓》《夷𠍴》奉。
憑險亂天常。乃神弘廟略，橫海剪吞航。
電野清元菟，騰笳振白狼。連雲飛巨艦，編石架浮梁。
周遊臨大壑，降望極遐荒。桃門通山抃，蓬渚降《霓裳》。

長驅七萃卒，成功百戰場。俄且旋戎路，飲至肅巖廊。

《景龍四年春祠海》
宋·之問
[
编辑
]

肅事祠春溟，宵齋洗蒙慮。雞鳴見日出，鷺下觀濤騖。
地闊八荒近，天迴百川澍。筵端接空曲，目外惟雰霧。
暖氣物象來，周遊晦明互。致牲匪元享，禋滌期靈煦。
的的波際禽，沄沄島間樹。安期今何在，方丈蔑尋路。
仙事與世隔，冥搜徒已屢。四明背群山，遺老莫辨處。
撫衷良自慨，弱齡忝恩遇。三入文史林，兩拜神仙署。
雖嘆出關遠，始知「臨海趣。」賞來空自多，理勝孰能喻。
留楫竟何待，徙倚忽云暮。

《度安海入龍編》
沈佺期
[
编辑
]

嘗聞交趾郡，南與貫胸連。四氣分寒少，三光置日偏。
尉佗曾馭國，翁仲久遊泉。邑屋遺氓在，魚鹽舊產傳。
越人遙捧翟，漢將下看鳶。北斗崇山掛，南風漲海牽。
別離頻破月，容鬢驟催年。昆弟推由命，妻孥割付緣。
夢來魂尚擾，愁委疾空纏。虛道崩城淚，明心不應天。

编辑

積氣衝長島，浮光溢大川。不能懷魏闕，心賞獨泠然。

《海上作》
宋·務光
[
编辑
]

「曠哉潮汐池，大哉乾坤力。浩浩去無際，沄沄深不測。」
崩騰翕眾流，泱漭環中國。鱗介錯殊品，氛霞饒詭色。
天波混莫分，島樹遙難識。漢主探靈怪，秦皇恣遊陟。
搜奇大壑東，竦望成山北。方術徒相誤，蓬萊安可得。
吾君略仙道，至化孚淳默。驚浪接窮溟，飛航通絕域。
馬韓底厥貢，龍伯修其職。粵我遘休明，匪躬期正直。
敢輸鷹隼埶，以問豺狼忒。海路行已殫，輶軒未遑息。
勞歌元月暮，旅睇滄浪極。魏闕渺雲端，馳心附歸翼。

《送祕書晁監還日本國》
王維
[
编辑

積水不可極，安知滄海東。九州何處遠，萬里若乘空。
向國惟看日，歸帆但信風。鼇身映天黑，魚眼射波紅。
鄉樹扶桑外，主人孤島中。別離方異域，音信若為通。

《登高丘而望遠海》
李白
[
编辑

《登高丘，望遠海》，「六鼇骨已霜，三山流安在。扶桑半摧
折，白日沉光彩。銀臺金闕如夢中，秦皇漢武空相待。
精衛費木石，黿鼉無所憑。君不見驪山茂陵盡灰滅，
牧羊之子來攀登。盜賊劫寶玉，精靈竟何能。窮兵黷
武今如此，鼎湖飛龍安可乘。」

《熱海行》
岑參
[
编辑
]

側聞陰山胡兒語，西頭熱海水如煮。海上眾鳥不敢
飛，中有鯉魚長且肥。岸傍青草常不歇，空中白雪遙
旋滅。蒸沙爍石然虜雲，沸浪炎波煎漢月。陰火潛燒
天地鑪，何事偏烘西一隅。勢吞月窟侵太白，氣連赤
坂通單于。送君一醉天山郭，正見夕陽海邊落。《柏臺》。
霜威寒逼人，熱海炎氣為之薄。

《和賀蘭判官望北海》
高適
[
编辑

「聖代務平典，輶軒推上才。迢遙溟海際，曠望滄波開。
四牡未遑息，三山安在哉。巨鰲不可釣，高浪何崔嵬。
湛湛朝百谷，茫茫連九垓。挹流納廣大，觀異增遲迴。
日出見魚目，月圓如蚌胎。跡非想像到，心以精靈猜。
遠色帶孤嶼，虛聲涵殷雷。風行越裳貢，水遏天吳災。
攬轡隼將繫，忘機鷗復來。緣情韻騷雅，獨立遺塵埃。」
吏道竟殊用，翰林仍忝陪。長鳴謝知己，所媿非龍媒。

《觀海》
獨孤及
[
编辑

「北登渤海島，迴首秦東門。誰尸造物功，鑿此天池源。」

澒洞吞百谷，周流無四垠。廓然混茫際，望見天地根
​
白日自中吐，扶桑如可捫。迢遙蓬萊峰，想像金臺存。

秦帝昔經此，登臨冀飛翻。揚旌百神會，望日群山奔。
徐福竟何成，羨門徒空言。唯見石橋足，千年潮水痕。

《西陵口觀海》
薛據
[
编辑
]

長江漫湯湯，近海勢彌廣。在昔坯渾凝，融為百川泱。
地形失端倪，天色潛滉瀁。東南際萬里，極目遠無象。
山影乍浮沉，潮波忽來往。孤帆或不見，棹歌猶想像。
日暮長風起，客心空振蕩。浦口霞未收，潭心月初上。
林嶼幾邅迴，亭皋時偃仰。歲晏訪蓬瀛，真遊非外獎。

《越中問海客》
劉眘虛
[
编辑
