席祥妻吳氏
[
编辑
]

按《浙江通志》：吳氏，席祥妻，山陰人。祥贅于吳，生子未
晬而祥歿。氏年二十有六，歎曰：「吾席婦也，義不當留
父母家。」乃奉祥靈，櫬絕濤江而東，葬于錢塘先塋之
次。從妯娌，事舅姑，撫遺嬰。姑患瘍痛，醫曰：「此膿所苦，
孰能吮之？」吳氏吮之，無難色，姑瘍遂愈。親戚鄉黨咸
​
稱為節孝云。

勞載是妻董氏
[
编辑
]

按《浙江通志》：「董氏，名貴珍，衢人，董士疇女也。年二十，
適勞載是。未三月，載是亡，無子，服闋，姑憐其少，勸改
適。貴珍剪髮矢志，寧餓死，勿失節。孀居三十七年。有
司上其事，旌表。」

陳取新妻許氏
[
编辑
]

按《錢塘縣志》：「許氏，諸生陳取新妻。新亡，氏年二十三，
守節五十年。于崇禎十四年卒，年七十有三。」

顧恆宇妻陳氏
〈張氏附〉
[
编辑
]

按《仁和縣志》：「陳氏，顧恆宇妻，御史豹文之祖母也。年
三十，恆宇游粵，客死，訃聞，氏立旛剎，設靈几，擗踴哭
絕，曰：『無祿，恆郎旅次，孤魂萬里外，飄泊無依，誰與歸
耶？子大觀，年十二，涕泣請奔喪，與祖俱。氏朝夕哭奠
甚哀，鄰人為罷舂。及柩歸，橐中裝已為寓主所乾沒。
貧苦，訓子經營治生。久之，家隆隆起。長孫媳張氏，性』」
端淑，亦早寡。兀坐一室，咫尺不踰。叔豹文成進士，僅
遣女鬟詣姒處一叩頭賀，族從姻婭雲集，如勿聞者。
苦節三十餘年，教子之珩，能文，有聲庠序。

陳天相妻陸氏
[
编辑
]

按《仁和縣志》：陸氏，陳天相妻。夫亡，氏年二十二，遺腹
生子文社。值明季群寇充斥，或訹以盜至，懼不免。氏
叱曰：「我藏霜刃久矣，必先斷盜首，而後自殺，以殉吾
夫，誓不與俱生也。」賊亦竟毋窺其門者。一鄉稱為節
俠。年六十九卒。

李青虯妻張氏
[
编辑
]

按《仁和縣志》：「張氏年十八適李青虯，夫亡。氏年二十
九，室如懸罄。撫幼子三人，縫紉自給，掬水為沐，採藿
為餐，鄉閭共嘆其苦節。年六十八，抱病焚香，默坐而
逝。」

張天俸妻殷氏
[
编辑
]

按《海寧縣志》：「殷氏，庠生張天俸妻。年二十四夫亡，子
邦彥甫四歲，次子未及週，方天俸猝構疾，氏隨姑蠶
於郊，歸視疾革，號慟不欲生。舅姑語之曰：『吾二人年
高，孫方幼，若不為張氏宗祀計乎』？始稍進飲食，鞠育
兩兒，勤苦備至，奉事舅姑彌謹。無何，舅姑繼沒，養生
喪死，一身拮据，家故單傳，次子復夭，旁無宗族倚毗」，
產日以落。躬操紡績，督邦彥就塾。暮歸，一燈熒熒，機
杼誦讀聲相間達旦，率以為常。邦彥補博士弟子，娶
婦亦賢。漸且孫曾繞膝，每舉先世艱難，訓子孫力學
勤善，老而靡間。崇禎間，縣令旌其閭。年八十有二卒。

陸禮妻徐氏
[
编辑
]

按《海寧縣志》：「徐氏，大參炳孫女，合浦令若在女也。年
十六，歸憲副陸州孫太學生禮。時禮父坐誣獄十餘
年矣，氏侍姑沈，氏委曲承奉，退則飲泣，誓佐夫，白乃
翁無辜狀。閱十一年，翁果脫獄。未幾，姑亡，而禮亦旋
殞。氏年二十七，止一女，茹荼食堇，事翁一切，代供子
職，喪葬盡禮，屏肥甘，絕繒綺。嚴冬冷月，長齋繡佛斗」
室中，足不踰閫者幾四十餘年。年六十七，卒。

吳元礦妻鄭氏
〈妾周氏附〉
[
编辑

按《海寧縣志》：「鄭氏，吳太學元礦妻。年二十九，夫亡，無

氏刲股和藥救之。十歲而殤，以姪灝承祀。二嫠共守
苦節，鄭年六十一，周年八十二卒。御史朱泰禎誌而
銘之。」

编辑

列庠序者三人。氏年六十五卒。」

编辑

蔣之琬妻張氏
[
编辑
]

按《海寧縣志》：「張氏，邑庠生蔣之琬妻。年二十餘而寡，
二子尚襁褓，氏悉鬻所存匳資，內供舅姑，外禮師傅。
夫之諸弟眾析產，輒推腴取瘠，人告乏絕者必賑之。
有佃負租將賣妻以償，悉蠲之，召其妻還。年七十將
卒，先十日畢，呼兒孫諸婦遍告誡，然後瞑目。唯以禁
佛事、薄衣衾及時埋葬為囑。崇禎九年，縣令旌之。」

華國章妻徐氏
[
编辑
]

按《富陽縣志》：「徐氏，邑諸生華國章妻。生而克孝，名聞
母黨。及笄適章，事舅姑，動嫺內則，夫妻相敬如賓，勉
夫力學。無何，章病亡，徐年二十餘，遺孤儁枝尚幼，煢
煢子母伶仃相依，夜則績紝訓子，每至雞鳴。儁枝早
有文名。徐孀居四十年，治家嚴肅，一嫺於禮，教子孫
若孫，媳以勤儉。邑人屢欲請旌，徐固辭而止。年七十」，
無疾卒。鄉黨無不稱為賢節。

夏之時妻楊氏
[
编辑

按《富陽縣志》：「楊氏，諸生夏之時妻。工刺繡，勤中饋，儀

撫養如己出。孀居垂四十年，繼子復沒，所遺產無幾。
而族人猶紛爭聚訟，竟不為立後。氏惟皈衣天竺，朝
夕誦梵唄，不與之較，以壽終。」

陳天生妻陸氏
[
编辑
]

按《富陽縣志》：「陸氏，開化里諸生陳天生妻，江陰陸萬
女也。甫數歲，聞父誦詩書，即能默識，父心異之，因教
以《古列女傳》諸書。及笄配天生，閨中吟詠相唱和。天
