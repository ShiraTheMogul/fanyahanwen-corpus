# README

This aims to be a Literary Chinese corpus viewer with robust implementations to make it as flexible and readable as possible. It takes the perspective of Literary Chinese being a living language used across multiple nations for thousands of years; it hopes to go far beyond the standard Chinese classics and show a complete picture. 

Particularly, it has the following objectives:
- Support pan-Asian Literary Chinese materials through my [Fanya Hanwen Corpus](https://github.com/ShiraTheMogul/fanyahanwen-corpus)
- Horizontal or vertical, starting left or right reading orientations.
- Traditional and Simplified Chinese support, as well as variant forms for JKVR variants.
- Option to remove punctuation
- Annotations for placenames, people, etc, as displayed in Qing dynasty texts
- Kanbun/hanmun/hanvan support
- Option to submit works to the corpus for viewing, which will take independent review. 

There is a small dictionary available, featuring:
- Unihan Data
- Wenjin Mincho font
- Hanzi Writer stroke order demo
- Latin and Han script Cangjie combinations
- HK Cards Cangjie decomposition
- Kangxi Dictionary, Unihan, and and CC-CEDICT Definitions.
