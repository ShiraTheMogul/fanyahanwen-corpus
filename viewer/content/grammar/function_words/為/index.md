## Explanation

### Copula-like function
為 (or 爲) literally translates to "act as," and can be seen as a copula akin to the English "is/are" on a surface-level. It is similar to 作 in modern Mandarin Chinese. 

Therefore, to say someone is something, it is as simple as this:
{% corpus_quote path="中國漢文/clean/宋朝/北宋/孟子註疏/孟子註疏__juan_04.txt" text="孟子為卿於齊" highlight="為" source="孟子·卷四上·公孫丑章句下" %}

However, 為 has two meanings: to do/make, or to be something. In the case of do/make senses, an interrogative pronoun must precede it; this is a general rule for pronouns with transitive verbs. Therefore:
{% corpus_quote path="朝鮮漢文/clean/高麗/高麗版大藏經/clean/文殊師利問經/ 文殊師利問經__juan_0002.txt" text="我初得道，先為誰說法？" highlight="為誰" source="文殊師利問經" %}

There is a semantic difference between this and 誰也: When using 誰也, the expectation is further information. When using 為誰, the expectation is the person's name.

### Superlatives

The copula-like 為 can be used with an adjective to articulate "most so," or "-est"-like meanings. A somewhat common use for this is to denote when something is correct with 正:
{% corpus_quote path="越南漢文/clean/大越/阮朝/欽定越史通鑑綱目/欽定越史通鑑綱目__0001__卷首_凡例.txt" text="關於義理得失者，以前為正" highlight="為正" source="欽定越史通鑑綱目" %}

Likewise, to say something like "bestest," "particularly," and so on, 甚 can be used to articulate it:
{% corpus_quote path="維基大典/clean/允禩/允禩.txt" text="諭謂：「陰邪叵測，莫此為甚！」" highlight="為甚" source="維基大典·允禩" %}

### Passive voice
為 has a function that allows one to articulate passive voice, similar to "the ball was kicked by Jim" in English, and 被 constructions in Mandarin Chinese.
{% corpus_quote path="中國漢文/clean/周朝/東周/戰國時代/宋/莊子/莊子__juan_32.txt" text="明者唯為之使" highlight="為之使" source="莊子·列禦寇" %}

{% corpus_quote path="中國漢文/clean/周朝/東周/春秋時代/魯/春秋左氏傳/春秋左氏傳__襄公_18.txt" text="曰止，將為三軍獲" highlight="為" source="春秋左氏傳·襄公十八年" %}

Come the Han dynasty, 所 began being used to mark the passive verb at the end. In the case of our second example, it would go from 曰止，將為三軍獲 to 曰止，將為三軍所獲. This can be seen in works like 史記.

### Expressing "in order to"
To articulate "for the sake of," "in order to," or similar constructions, 為 can be used at the start of a sentence. It is similar to the Mandarin Chinese 為了. Therefore, 為 + Purpose = "in order to purpose". 
{% corpus_quote path="朝鮮漢文/clean/高麗/高麗版大藏經/clean/解深密經/ 解深密經__juan_0001.txt" text="為令獲得義利安樂。" highlight="為" source="解深密經" %}
In this example, 令 is used alongside it to say "in order to cause...". What is to be caused is not said, but you get the idea, right?

## Technical explanation

Verb phrases used after 為 can be seen as unmarked nominalization.

The auxiliary 可（以） can be used before 為 to express a possibility. As 可（以） requires a verb (doing word), when 為 is not present, if there is no other verb, one can assume 為 is implicit.

As a passive, 為 is best understood as a sort of pivot construction: The first object is not direct, but indirect. The embedded verb that serves as the second object has the subject of the main verb as the patient, and the indirect object as the agent.
