黏膠魔（Slime，俗謂史萊姆）者，夙敵生靈生於濘澤生態域及其變體也。

生

黏膠魔生於四〇层以下之特定“黏膠魔区块”中（亮度不限）可生成方塊之上，其亦可生於沼澤與紅樹林沼澤生態域五一至六九层且亮度等小於或等於七可生成方块之上。

僅一、二與四尺寸之黏膠魔可生於自然。爪哇版中，借/summon可生一至一二七（實體數據Size零至一二六）尺寸之黏膠魔。

慾生黏膠魔一，需空间二點零八乘二點零八乘二點零八，其生之域須無任何液於方塊碰撞。黏膠魔生之时均以黏膠魔巨者之尺寸判其域是否足也，故無黏膠魔可生於域小於二點零八乘二點零八乘二點零八。

黏膠魔於生之时，其尺寸因副区域难度影响，三者尺寸之概率各为：微者百分之一六點五至百分之三三，中者百分之三四，巨者百分之三三至百分之四九點五。

沼泽

於濘澤與沒潮木澤中，黏膠魔可生於五一至六九層且亮度等級小於或等於七之地。满月之时，生率至大；新月之时，不曾生也。

更確言之，遊將察二因素：

亮度等级是否小於或等於一隨意整數（零至七）

月亮之明亮部分所佔比例是否大於一隨意小數（零至一）

若其皆成，高度適宜，則可生也，概率為半。

煉孳衍籠

煉孳衍籠小者於煉孳之室中或為黏膠魔十連刷怪籠。

黏膠魔區塊

黏膠魔可生於全世（除蕈野和黯淵）之特定區塊四〇層以下，不限亮度等級。约每一〇區塊中有一“黏膠魔區塊”。

爪哇版

爪哇版中，“黏膠魔區塊”定於世界之種與區塊坐標結合之偽隨機二成也：

import java.util.Random;

public class CheckSlimeChunk {

public static boolean isSlimeChunk(long worldSeed, // 世界之種，六四位整数一也，借/seed以得
int chunkX, // 區塊X軸坐標，三二位整數一也
int chunkZ) { // 區塊Z軸坐標，三二位整數一也
Random rng = new Random(
worldSeed +
(chunkX * chunkX) * 0x4C1906 +
(chunkX * 0x5AC0DB) +
(chunkZ * chunkZ) * 0x4307A7L +
(chunkZ * 0x5F24F) ^ 0x3AD8025F
);
return rng.nextInt(10) == 0;}}

換言之，借區塊坐標生一種，後生一為隨機數於〇至九間，若數乃〇，則此區塊可生黏膠魔。須易世之坐標至區塊坐標，將其除以一六並向下取整。

基石版

基石版中，黏膠魔區塊之算法異於Java版。算法不依於种，故各世之中，黏膠魔區塊一也。

状态效果

拥有滲漿態效之生物会生黏膠魔二於斃之時。

為戲者或狼已為所馴所殺之黏膠魔可另落与其尺寸对应之经验球：一 經驗、二 經驗或四 經驗。

行

黏膠魔借躍而行，間一，躍一。異於他生，近無戲者，亦不停也。

黏膠魔有命等於其尺寸之平方，其各方之長乃其尺寸之〇點五二倍，近傷等於其尺寸（除無攻击能力者，即黏膠魔尺寸為一）。

黏膠魔躍的距取于其尺寸，黏膠魔四尺寸者可躍約五點五格遠，二尺寸者可躍約三點五格遠，一尺寸者可躍约二格遠。黏膠魔躍之高不因其尺寸而異，一躍僅至一格之高。其有響於躍之時，而無聲於空閒之時。著陸之時，會現適量黏膠團粒子，其尺寸为外表尺寸之八分之一。

黏膠魔可尋戲者、鉄傀儡和雪傀儡[僅基石版]於球半徑一六、高以自碰撞箱上下擴展四格之范围内，且黏膠魔倾于尋戲者。若無目標，其會待已〇至三〇刻（二至六秒）。其將隨意轉左或轉右，变其向之角至大为五七點二六度（一弧度），躍，后复其行。若有目标，則待之時为無目標之三分之一（三至一〇刻），后躍前，其向乃至近之目標。

異於他生，黏膠魔毫無能力以尋路，僅可試向目標躍以前。換言之，於追目標之時，其可落於崖且弗能绕墙也。

異於他生，黏膠魔近攻之速無限也，可攻而無休，且可攻距離範圍內一切目標。受擊後傷害免疫使黏膠魔每秒僅能使目標傷二次，但爪哇版中，借盾牌挡傷不可觸發受擊後傷害免疫，故黏膠魔巨者可耗盡盾牌之耐久度以極高之速。

黏膠魔尺寸大于一者斃之時，將裂出新黏膠魔二至四。其尺寸除以二，并向下取整。亡后裂而生之黏膠魔者，不具先之態效，而具先之通過下界傳送門冷卻時長。

黏膠魔微者無能以傷他生，即使改其属性attack_damage。

爪哇版中，黏膠魔不可阻戲者寢，而戲者仍將醒因受傷於黏膠魔尺寸大於一。

黏膠魔免疫於滲漿態效。

一點九〇

易黏膠魔之纹理。

汝可知否

戲者可从黏膠魔巨者與其分裂所生之黏膠魔至高可得经验二八：最大的能获得4经验；分裂至多可得经验八；分裂再至多可得经验一六（每分裂得四）。

黏膠魔大者分裂為黏膠魔小者時，黏膠魔小者之名同於黏膠魔大者。

爪哇版中，借命令而生黏膠魔尺寸為一二七者，戲中體至大生也。

黏膠魔微者，至弱夙敵生靈也，其命僅一（），弗能傷他生。

因黏膠魔之移速與其尺寸有关，於平地，黏膠魔尺寸八者竟快於不具態效之戲者。

黏膠魔尋戲者而攻之或判其是否消失時，黏膠魔非從碰撞箱外之緣始查，而從碰撞箱至X轴與Z轴中之点一及Y轴之底始查。換言之，黏膠魔尺寸自定義且大者可於戲者右前方，且乃被动型生。若足大矣，此黏膠魔可消失於其外缘小於一格時。

基石版中，黏膠魔可於黑耀石上生於自然，然黑耀石已不可借常法置其於世界。
