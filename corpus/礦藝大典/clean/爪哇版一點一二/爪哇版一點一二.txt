一點一二（1.12）者，爪哇版之主更新也，廣佈於丁酉年五月十三。是更新增合成新法与函令系统，置导蒙提示，添釉陶瓦、混凝土、彩榻、幻术师、鹦鹉诸物，以进业代旧勋绩，并修缮纰漏百余。

新物

砼

色有十六，取染膏为别。

混凝土粉末遇水则固结成型。

砼粉

色有十六，取染膏为别。

受重力所牵（类礫）。

遇水则化为砼。

合成法：取沙四、礫四，佐染一，可造八枚，诸材序不拘。

釉陶瓦
色有十六，取染膏为别。
烧炼染色陶瓦（素陶瓦除外）可得同色釉陶瓦。
可朝四向而立：东、西、南、北。
依特定朝向布列，可成祥纹。如：黄釉陶瓦四，列如日轮。
附于黏液块侧、顶、底则不受粘滞，附于正、背面则粘。

知书
绿封书卷。
现仅能凭令 give <戏者名> knowledge_book 获之。
此书怀 Recipes 签，载物ID录，玩家用之即消，并启所列之物合成谱。
于戏规 doLimitedCrafting 启时尤有用。

唤灵卵
鹦鹉唤灵卵
底绿而缀赤斑。

幻术师
灾厄村民之新属。
先予玩家盲瞽之效二十息，继而发矢相攻。
盲瞽之效仅于域难≥三时生效。
可召与己身无异之幻影。
诸影皆显射姿，然惟本尊可攻受击。
本尊能隐迹。
是版尚无对应唤灵卵，惟可以令 summon illusion_illager 唤之。
袭玩家与村民。

鹦鹉
可以籽驯。
性喜飞巡，倦则栖止。
若食饼饵，立毙。
因饼而毙者，亡时现中毒尘粒，然实非中毒致死。
若玩家饲驯鹦鹉以饼，则示：“鹦鹉殒于<玩家名>之手”。
喜随聚于邻近生灵之侧。
善效他生灵之声。
近有乐匣奏曲时，能起舞。
交互（右键）：
- 击已驯鹦鹉可使栖。
- 玩家过鹦鹉所处之位，则其立踞玩家肩。
- 驯主跃起可使离肩。
能随御翅衣翱翔之玩家。
血气：三心（♥♥♥）。
变种色有：赤、青、碧、苍、灰。

戏规
announceAdvancements
默为真。
切换完成进业时是否示告，代 server.properties 旧制。
doLimitedCrafting
默为伪（关）。
启后玩家仅可合成已解之谱内物。
gameLoopFunction
每刻一行之函令名。
maxCommandChainLength
默为六万五千五百三十六。
制连锁令砖执行之令链极长。

@s
择行令之本体。例：/execute @e[type=villager] ~ ~ ~ say @s
/advancement <予|夺|验> <玩家> <进业> [条件]
可对指定玩家予、验、夺进业或其特例。
修饰符有五：“一切”、“自…始”、“至…止”、“贯穿”、“惟此”。
- “一切” — 所有进业，无需格式（同“*”）。
- “自…始” — 指定进业及其所有子业。
- “至…止” — 指定进业及其所有父业。
- “贯穿” — 兼上二者。
- “惟此” — 仅指定进业。
例：
/advancement grant dinnerbone until story/elytra
/advancement revoke dinnerbone everything
/function 名域:径/函件
实体或令砖行此令时执行函数。
增新参：
- if <择器> — 仅当择得特定对象时行函。
- unless <择器> — 仅当未择得特定对象时行函。
/recipe <予|取> [玩家] <名|*>
可为指定玩家解或锁特定合成谱。
指定为 * 时，则解或锁所有合成谱。
/reload
用于重载盘中之进业与战利表。
仅单机具管权者，或联机具四级管权者可用。
不可由令砖行。

进业
代旧勋绩。
可以 JSON 牍自定义。
无需严守序次。
多签界面。
签有五（可增）：
1. Minecraft：戏核与本事
2. 历险：历险、探赜与征战
3. 下界：勿忘夏服
4. 末地：或为新始？
5. 农牧：寰宇皆友雔，处处有珍馐
数据驱之界面，可制位与局。
奖赏可呈谱、战利、经验、函令诸形。
原版惟“挑战”进业予玩家奖，乃定量经验。
完成时现提示框。
新滑入效。
色有二：完常业为黄，完“挑战”业为紫。
多求之进业以分数示其完度。

制控
为创式物品栏存档增捷键选。
增启进业新捷键（默 L）。

创式
增“存工具栏”签。
创式下可以 C + 1-9 存物品快栏组，以 X + 1-9 载之。
可存至多九组。
若试存空组，则清对应存组，并于格中置“信笺”。

函令
增新函令系统，乃存于 名域:径/函件、缀 .mcfunction 之纯文牍。
如行 /function custom:example/test 即指 [世界名]/data/functions/custom/example/test.mcfunction 之函。
函式为令列，一行一令（无斜杠），可以 # 注。

JSON式
于配方 JSON 牍增“群”，用于类谱归集。
增新“键束”文组件，用于供玩家按键束信。

谢启与著权屏
可于主菜单击版权文阅之。

复述能
按 Ctrl + B 启，可自诵玩家聊文，含发信者名。
模式有四：“关”、“诵聊文与系讯”、“惟诵聊文”、“惟诵系讯”。
切换时现弹告。
不诵令或令出，亦不诵用 /me 之讯。
当其不
可用时显讯。

NBT签
- 长整 LastExecution：存连锁令砖末次被激之戏刻。
- 长整 LoveCauseLeast 与 LoveCauseMost：用于可育之实体，二者记使其育者之 UUID。
- 复合签/JSON物 recipeBook：含谱录之串，玩家可见如谱书信般 JSON 化。
- 字节 isFilteringCraftable：玩家启谱书“仅示可合”能时，值变一。
- 字节 isGuiOpen：检 GUI 是否启。
- 字节 unlocked
- 列签/JSON阵 recipes：含玩家已览之全谱信。
- 字节 displayed：检玩家已于谱书内启何合成谱（击或览）。
- 列签/JSON阵 toBeDisplayed：储玩家已解未于合成助中览之谱名。用于播新谱解时动画。
- 列签/JSON阵 Recipes：玩家持知书时，击右键可解之合成谱录。若未定签，知书不耗。
- 字节 seenCredits：玩家经门离末地时为一。
- 复合签/JSON物 ShoulderEntityLeft 与 ShoulderEntityRight：含玩家左、右肩上实体之实体数据。
- 字节 UpdateLastExecution：默 1b。若设为 0b，可造循环，即于一戏刻内激同令砖多次。

谱书
达条件时解之合成谱目。
击已解之谱，谱即现于合成格；料足则可制。
按 ⇧ Shift 时左击一谱，可将所有可用原材置入合成格。
玩家解新合成谱时现灰白提示框。此告框显借此新解谱可合新物之图标。
若于谱书内索“excitedze”，戏语则化海寇英语。

旗帜
新配色纹理。
“顶横条”、“底横条”旗今更名为“顶条”、“底条”旗。

榻
当非敌态僵尸猪人在侧时亦可眠。
今可于榻上弹跃，效类黏液块而稍弱。
今坠于榻时，所受摔伤减。
玩家可自离榻四十一格之高坠而生。
若更高，弹落后再坠之伤可致死。
玩家可于榻旁地筑七格高台以自保，于此况玩家可坠四十五格仍存。
增可以染色羊毛合成或染膏染之彩榻。
今榻为方砖实体，且其半皆可以 NBT 签 color 染。
榻有新色，故今榻以三维形显于物品栏，不似携版之以二维显。

令砖
今于行毕令链中全令后，方将其加诸下计刻。
今能即时经令终/改令链并得相应回馈（非待一戏刻后）。
优化令砖中误条件。
令砖中以 Tab 自补之令名不再含 / 前缀。

栅栏、圆石墙、玻板与铁栏
今可与阶梯接。

硬化黏土

岩浆砖

制控

合成
当闭合成界面时，其上物不复坠落，代以物自入物品栏。

创式
将材签并入杂签。

爪哇版
自此版始，行戏所需爪哇版最低为爪哇八。

语言
众多前锁为英语之文今可译。

移行
今玩家退时身全面正前。此前，玩家退时身转侧，观似向后方侧步。

NBT式
改进 NBT 于令中之析。
签今可被引号含（可选），例："Motion":[0.0,0.0,0.0]。
无引号含之串值今更严，其不可含空格或特符，例：CustomName:Test Test。
昔于列中可选之索引今不可用，例：Motion:[0:7.3,1:1.0,2:3.1]。
空签名、空值今不可用。
改进误讯提示，今指误处。

优化
对创式物品栏索能行大幅优化。
优化区块载。

闪烁标
“今爪哇六！”更作“今爪哇八！”。

音声
增二新洞音：cave17.ogg、cave18.ogg。

方砖·南瓜灯
钮、杆、红石火把、火把、绊线钩今可置于南瓜灯上。红石火把、火把仍不可置其顶。
