術

改/function之令以合乎/return。

今之術也，惟令、謬以反。至於/function，不反不察。
謬曰：
查無此術。

術籖以虛。

宏不能實。

果也者，/execute store之所錄也。

去/execute store ... run 術名之悉錄術令。
形如術名者，一錄而罷。不以/return，則乃不錄。

術籖繁目，則累其果，或有綴從者。

精進術制，以時變辟害：
今雖疏行，制如如術。
如/execute as @e run 術名所以，其制悉同。

命令塊所行，猶單立也。

今以如左者，maxCommandChainLength之章則悉以爲一行焉：
一令而施左右。

/execute之一章，不顧左右。

術而見以。

增章則，曰maxCommandForkCount，以制/execute等增注之極。
如有五物，行/execute as @e則左右增注五，/execute as @e at @e則增廿五。

/execute

復(if|unless) function之機。
以行術、籖，已而審其所反。籖則必行其端術。

章法曰：... (if|unless) function <function> -> execute

參數曰：
function：所行者。

惟有行以應，反必/return而不虛然。
術之未央，if、unless皆不能行也。

/return

復run之支，其章法曰：/return run ...。
取令之所反，而轉奉諸術也。
令而不反，則/return不行，術不已。

令敗績，則反〇。

不然，則如/return之躬設。

如復有歧，如/return run execute as @e run 令語者，則取其當先者。
如無所行，如/return run execute if @e[自虛者] run 令語者，則令不反，術不輟。
