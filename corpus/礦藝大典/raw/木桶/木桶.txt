桶既損，則桶及其內之物俱坠。

用

可擺之「桶」，蓋塞之活栓得之滑軌隨之[僅基石版]。流水熔石得自其下，然桶寧死不屈，唯火方自其上生焉。

藏

凡桶，廿七方之倉也，與箱同之。舉投可循之，漏斗亦可循之以儲物、虛其存。惟其木損則其中之實物遂墮。舉桶，右擊而啟其倉。與箱異者，桶蓋可被紅石導體遮而不妨其用也。

木桶GUI左上角的文字默认为“木桶”，可通过铁砧或命令重命名木桶以改变显示文字。例如，命令/data merge block 0 64 0 {CustomName:"贵重物品存放处"}可以将位于(0,64,0)的木桶重命名为“贵重物品存放处”。

爪哇版中，LockNBT标签可以将木桶锁定，玩家只能手持名称与其值相同的物品打开该木桶。例如，命令/data merge block 0 64 0 {Lock:"神奇钥匙"}可以使位于(0,64,0)的木桶锁定，只能被手持名为“神奇钥匙”的物品的玩家打开。

薪

凡桶，亦可用以爲煆爐燃料，每一木桶可燒煉物品一點五個。

改行

若桶尚未为鄉民所认领，则附近处于失业状态之鄉民将有机会认领桶并转变职业为渔夫。

豕靈

成年豕靈如遇附近開啟或毀損桶之戏者，則視其爲敵對對象。
