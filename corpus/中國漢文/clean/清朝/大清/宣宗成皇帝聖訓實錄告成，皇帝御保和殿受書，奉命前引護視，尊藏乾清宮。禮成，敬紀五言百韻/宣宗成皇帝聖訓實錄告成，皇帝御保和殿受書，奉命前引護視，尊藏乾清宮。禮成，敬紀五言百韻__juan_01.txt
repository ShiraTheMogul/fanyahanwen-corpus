# PAGE_TITLE: 宣宗成皇帝聖訓實錄告成，皇帝御保和殿受書，奉命前引護視，尊藏乾清宮。禮成，敬紀五言百韻
# NATION: 清朝
# WS_CATEGORIES: 奕訢;清朝;詩

景運丕基鞏，洪謨邁帝唐。

紹先欽聖主，佑後仰宣皇。

赫赫宏猷著，巍巍寶籙藏。

八朝衷協揆，卅載政提綱。

建極符天健，持躬懋日強。

無私恢覆幬，有耀普輝煌
〈（謹按《御製聖訓》序，曰聖德，昭心法也）〉
。

侍膳依璇殿，迎暉啟采堂。

歡承溫復清，慕永露還霜
〈（曰聖孝，立人極也）〉
。

齔齒勤惟誦，仔肩勖就將。

慎修耽至道，養正肇元良
〈（曰聖學，崇正宗也）〉
。

布闓醲沾雨，含生渥酌漿。

登三臻顯鑠，撫五懍幾康
〈（曰聖治，宣教化也）〉
。

齋室凝精白，深宮格昊蒼。

雩壇親步禱，誠祝揭宸章
〈（曰敬天，凝寶命也）〉
。

監憲陪都蒞，吟詩祖誥彰。

貞厘皆矩蠖，繼述見羹墻
〈（曰法祖，紹鴻模也）〉
。

率土同文闡，寰瀛雅化昌。

國書殷改試，恩榜睹頻張
〈（曰文教，闡欽明也）〉
。

箭殪初圍鹿，星流迅翦狼。

神槍殲教匪，秘策靖囘疆
〈（曰武功，除邪慝也）〉
。

廣業懷維惕，思艱刻不遑。

緝熙歌《大武》，待旦媲成湯
〈（曰勤政，建皇極也）〉
。

饑溺求其瘼，綏來視若傷。

鴻慈真保赤，鳳詔遍謄黃
〈（曰愛民，敷仁政也）〉
。

錫類欣悼睦，酬庸更篤慶。

本源綿玉牒，支派衍銀潢
〈（曰睦族，固本支也）〉
。

六計昭澄敘，羣僚悚激揚。

貪風懲簠簋，循吏達圭璋
〈（曰察吏，飭官常也）〉
。

選士搜楨幹，掄賢任杜房。

鑒衡懸九升，鴛鷺肅千行
〈（曰用人，昭浚哲也）〉
。

樸儉崇逾切，瑰奇御未嘗。

貢鮮停越嶠，采璞罷氐羌
〈（曰崇儉，敦樸質也）〉
。

壤賦舟車挽，圜錢出入量。

薄徵輸稅課，查欠剔官販
〈（曰理財，慎明德也）〉
。

珥筆爭敷奏，從繩賴贊襄。

石看投水受，善喜樹旌颺
〈（曰求言，廣益思也）〉
。

廑問同民隱，輕徭軫歲荒。

寬和涵部屋，愷惻喻村莊
〈（曰恤下，達民情也）〉
。

軒獄仁覃溥，雞竿眚赦常。

鞫研周雀鼠，明允恤桁楊
〈（曰慎刑，弼政教也）〉
。

牙爪嫻雲陣，熊羆厚月糧。

甲披叨例賞，戍役念邊防
〈（曰恤兵，罷征戍也）〉
。

冬賑蒙膏飫，春祺沛德洋。

逋曾蠲火旱，供只斂金穰
〈（曰蠲賑，廑恫療也）〉
。

封號隆關廟，梗儀拜素王。

壁琮柔嶽瀆，蘋藻薦馨香
〈（曰崇祀典，嚴祈報也）〉
。

告誡廉兼法，栽培棟與梁。

寅恭期左右，申勸效勖勃
〈（曰訓臣工，敘官方也）〉
。

指授攻騎射，膚公紀斧斨。

勵兵咸虎奮，簡武亦龍驤
〈（曰勵將士，修戎政也）〉
。

惑世除邪慝，垂箴遏獗猖。

澨陬歸並育，軌物範胥匡
〈（曰嚴法紀，定民閑也）〉
。

定志尊卑辨，緣情品制詳。

科條參損益，貴賤限冠裳
〈（曰正制度，朝秩序也）〉
。

仗節功宜泝，褒忠詔立坊。

綸音餘悼惜，襲次表芬芳
〈（曰褒忠節，振綱常也）〉
。

舊輔嘉旁作，前勛眷對揚。

青瑉銘帶礪，紫閣繪珩璜
〈（日篤勛舊，懋延賞也）〉
。

南畝遙扶耒，西園各具筐。

擴圖資粟帛，敦俗務農桑
〈（曰重農桑，育羣生也）〉
。

渾噩偕遵轍，驕奢戒濫觴。

黜華頒敕諭，尚質首膠庠
〈（曰厚風俗，端治化也）〉
。

內使閽應守，中涓竈懼煬。

紊幹嚴宦豎，僭侈斥貂璫
〈（曰飭宦寺，肅宮廷也）〉
。

伏莽譏奸宄，耕田去莠稂。

廓清開泰富，撻伐秉乾剛
〈（曰靖奸宄，安良善也）〉
。

蠻服瞻顏幸，雄藩引領望。

語言通譯寄，琛羹輳梯航
〈（曰綏藩服，廣懷徠也）〉
。

絕塞消瑕釁，重臺戢寇攘。

牧遊安部落，市易靜帆檣
〈（曰輯邊疆，固封土也）〉
。

太僕閑分廄，淩河草滿塘。

馳驅多騄弭，肥廂共牛羊
〈（日飭牧政，達報章也）〉
。

礮械威掀震，艨艟浪破狂。

線沙巡遠島，銅海穩飛艎
〈（曰海防，綏邊僥也）〉
。

樁誌諮詢屢，堤工砌築忙。

波恬桃泛汛，岸闊葦堪杭
〈（曰河道，述平成也）〉
。

穀麥覘雙穗，粳秈集萬箱。

班糈恆發廩，聚米久盈倉
〈（曰倉儲，裕積聚也）〉
。

轉漕籌江浙，牽船積稻粱。

銜連經堰濟，瀦泄借睢漳
〈（曰漕運，嚴正供也）〉
。

淮楚新興販，滇黔昔免商。

睿裁虞淡食，軍餉裕鹽場
〈（日鹽法，普美利也）〉
。

貔旅能棱種，鱗塍解插秧。

耘耔攜子婦，穜稑熟甘涼
〈（曰屯墾，寓兵農也）〉
。

卌目紛璀璨，單心獨勉蘉。

配郊辭享獻，拊廟謝粢薌。

遺器陳都卻，豐碑讓弗當。

緘朱留巽命，揮翰溢謙光。

鼓舞孚林總，垓埏暢洽翔。

漸摩包庶匯，淪浹徹遐方。

珍笈祗編貝，瑤函敬飾緗。

一人膺纘緒，列卷炳琳瑯。

郅理時於燮，聰聽治孔陽。

式型行是訓，迓祉壽而臧。

典杓森杓斗，材輇愧桷宋。

管窺驚浩蕩，蠡測駴滄茫。

門辟闔閶。

曙曦呈糾縵，執事恪趨蹌。

嗣統延庥祐，貽謀降福祥。

詠賡忱莫罄，鼎祚億年長。
