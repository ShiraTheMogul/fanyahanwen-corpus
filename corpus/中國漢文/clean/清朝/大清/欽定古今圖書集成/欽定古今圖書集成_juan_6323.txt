《古諺》

编辑

月麗于畢雨滂沱，月麗于箕風揚砂。

《泛湖歸出樓中望月》
宋·謝惠連
[
编辑
]

日落泛澄瀛，星羅遊輕橈。憩榭面曲汜，臨流對迴潮。
輟策共駢筵，並坐相招要。哀鴻鳴沙渚，悲猿響山椒。
亭亭映江月，颲䬟出谷飈。斐斐氣羃岫，泫泫露盈條。
近矚祛幽蘊，遠視蕩諠囂。晤言不知罷，從夕至清朝。

《玩月城西門廨中》
鮑照
[
编辑
]

始見西南樓，纎纖如玉鉤。末映東北墀，娟娟似蛾眉。
蛾眉蔽珠櫳，玉鉤隔鎖窗。三五二八時，千里與君同。
夜移衡漢落，徘徊帷戶中。歸華先委露，別葉早辭風。
客遊厭苦辛，仕子倦飄塵。休澣自公日，宴慰及私辰。
蜀琴抽《白雪》，郢曲發《陽春》。肴乾酒未闋，金壺啟夕淪。
迴軒駐輕蓋，留酌待情人。

《奉和月下》
齊·王融
[
编辑
]

雕雲度綺錢，香風入珠網。獨知此夜月，依遲慕神賞。

[
编辑

「流輝入畫堂，初照上梅梁。形同七子鏡，影類九秋霜。」桂花那不落，團扇與誰妝。空聞「北窗彈，未舉《西園觴》。」《前題》
同前
[
编辑
]

今夜月光來，正上《相思臺》。可憐無遠近，光照悉徘徊。

编辑

编辑

《關山月》
元·帝
[
编辑

朝望青波道，夜上《白登臺》。月中有桂樹，流景自徘徊。
寒沙逐風起，春花向雪開。夜長無與晤，衣單誰為裁。

《望江中月影》
同前
[
编辑
]

澄江涵皓月，水影若浮天。風來如可泛，流急不成圓。
秦鉤斷復接，和璧碎還聯。裂紈依岸草，斜桂逐行船。
即此春江上，無俟百枝然。

《望新月》
蕭綸
[
编辑
]

霜氛含月影，靄靄下南樓。霧濃光若晝，雲駛影疑流。

《應王中丞思遠詠月》
沈約
[
编辑
]

《月華臨靜夜》，夜靜滅氛埃。方暉竟戶入，圓影隙中來。
高樓切思婦，西園遊上才。網軒映朱綴，應門照綠苔。
洞房殊未曉，清光信悠哉。

《望秋月》
前人
[
编辑
]

《望秋月》「秋月光如練，照曜三爵臺。徘徊九華殿，九華玳瑁梁，華榱與璧璫。以茲雕麗色，持照明月光。凝華入黼帳，清暉懸洞房。先過飛燕戶，卻映班姬床。桂宮裊裊落桂枝，早寒淒淒凝白露。上林晚葉颯颯鳴，鴈門早鴻離離度。湛秀質兮似規，委清光兮如素。照愁軒之蓬髮，影金階之輕步。居人臨此笑以歌，別客對之傷且慕。經衰圃，映寒叢；凝清夜，帶秋風。隨庭雪以偕素，與池荷而共紅。臨玉墀之皎皎，含霜靄之濛濛。躪天衢而徙度，轢長漢而飛空。隱巖崖而半出，隔帷幌而纔通。散朱庭之奕奕，入青瑣而玲瓏。寒階悲寡鶴，沙洲怨別鴻。文姬泣胡殿，昭君思漢宮。余亦何為者，淹留此山東。」《效阮公詩》
江淹
[
编辑
]

宵月輝西極，女圭映東海。佳麗多異色，芬葩有奇采。
綺縞非無情，光陰命誰待。不與風雨變，長共山川在。
人道則不然，消散隨風改。

《和望月》
庾肩吾
[
编辑
]

桂殿月偏來，留光引上才。圓隨漢東蚌，暈逐淮南灰。
渡河光不濕，移輪轍詎開。此夜臨清景，還承終宴杯。

《和徐主簿望月》
前人
===

樓上徘徊月。窗中愁思人。照雪光偏冷。臨花色轉春。

星流時入暈。桂長欲侵輪。願以《重光曲》。承君歌扇塵。

《望新月示同羈》
何遜
[
编辑
]

初宿長淮上，破鏡出雲明。今夕千餘里，雙蛾映水生。
的的與沙靜，灩灩逐波輕。望鄉皆下淚，非我獨傷情。

《望秋月》
蕭子範
[
编辑

「河漢東西陰，清光此夜出。」入帳華珠被，斜筵照寶瑟。
霜慘庭上蘭，風鳴簷下橘。獨見傷心者，孤燈坐幽室。

《望月有所思》
劉孝綽
[
编辑
]

秋月始纖纖，微光垂步簷。膧朧入床簟，髣髴鍳窗簾。
簾螢隱光息，簾蟲映光織。玉羊東北上，金虎西南昃。
長門隔清夜，高堂夢容色。如何當此時，懷情滿胸臆。

前人

编辑

《侍宴賦得龍沙宵明月》
劉孝威
[
编辑

「鵲飛空繞樹，月輪殊未圓。嫦娥望不出，桂枝稍隱殘。」落照移樓影，浮光動塹瀾。櫪馬悲笳吹，城烏啼塞寒。
傳聞機杼妾，愁余衣服單。當秋絡已脆，銜啼織復難。
斂眉雖不樂，舞劍強為歡。請謝函關吏，行當封一丸。

《月重輪行》
戴暠
[
编辑
]

「皇基屬明兩，副德表重輪。」重輪非是暈，桂滿目恆春。
海珠含更滅，階蓂翳且新。婕妤比團扇，曹王譬洛神。
浮川疑漾璧，入戶類燒銀。從來看顧兔，不曾聞𩰚麟。
北堂豈盈手，西園偏照人。

编辑
