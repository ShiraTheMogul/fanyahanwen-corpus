《詠菊》
晉·袁山松
[
编辑
]

靈菊植幽崖，擢穎陵寒飆。春露不染色，秋霜不改條。

《飲酒》
陶潛
[
编辑
]

「結廬在人境，而無車馬喧。問君何能爾，心遠地自偏。採菊東籬下，悠然見南山。」山氣日夕佳，飛鳥相與還。
此中有真意，欲辨已忘言。

又

「秋菊有佳色，裛露掇其英。汎此忘憂物，遠我《遺世情》。」一觴雖獨進，杯盡壺自傾。日入群動息，歸鳥趨林鳴。
嘯傲東軒下，聊復得此生。

《和郭主簿》
前人
[
编辑
]

《和澤周三春》清涼素秋節。露凝無遊氛，天高風景澈。
陵岑聳逸峰，遙瞻皆奇絕。芳菊開林耀，青松冠巖列。
懷此貞秀姿，卓為霜下傑。銜觴念幽人，千載撫爾訣。
檢素不復展，厭厭竟良月。

《答休上人菊詩》
宋·鮑照
[
编辑
]

酒出野田稻，菊生高岡草。味貌復何奇，能令君傾倒。
「玉碗徒自羞，為君慨此秋。金蓋覆牙柈，何為心獨愁。」《採菊篇》
梁·簡文帝
[
编辑
]

「日精麗草散秋株」，洛陽少婦絕妍姝。相呼提筐採菊
珠，朝起露濕霑羅襦。東方千騎從驪駒，更不下山逢
故夫。

《摘園菊贈謝僕射舉》
王筠
[
编辑
]

靈茅挺三脊，神芝曜《九明》。菊花偏可憙，碧葉媚金英。
《重九》唯嘉節，《抱一》應元貞。泛酌宜長久，聊薦野人誠。

《賦得殘菊》

[
编辑

階蘭凝曙霜，岸菊照晨光。露濃晞曉笑，風勁淺殘香。
細葉凋輕翠，圓花飛碎黃。還將今歲色，復結後年芳。

《詠菊》

[
编辑

霜間開紫蔕，露下發金英。但令逢採摘，寧辭獨晚榮。

《秋菊》
駱賓王
[
编辑

擢秀三秋晚，開芳十步中。分黃俱笑日，含翠共搖風。
碎影涵流動，浮香隔岸通。金翹徒可泛，玉斝竟誰同。

《菊》
李嶠
[
编辑
]

《玉律》三秋暮，金精九日開。榮舒洛媛浦，香泛野人杯。
靃靡寒潭側，丰茸曉岸隈。黃花今日晚，無復白衣來。

《感遇》
李白
[
编辑
]

可歎東籬菊，莖疏葉且微。雖言異蘭蕙，亦自有芳菲。
未泛盈樽酒，徒沾清露輝。當榮君不採，飄落欲何依。

《復愁》
杜甫
[
编辑
]

每恨陶彭澤，無錢對菊花。如今《九日至》，自覺酒須賒。

《歎庭前甘菊花》
前人
[
编辑
]

庭前甘菊移時晚，青蕊重陽不堪摘。明日蕭條盡醉
醒，殘花爛漫開何益。籬邊野外多眾芳，采擷細瑣升
中堂。念茲空長大枝葉，結根失所纏風霜。

《菊榮一篇五章章十句》
蕭穎士
[
编辑
]

采采者菊，芬其榮斯。紫英黃萼，照灼丹墀。愷悌君子，
佩服攸宜。王國是維，大君是毘。貽爾子孫，百祿萃之。
采采者菊，于邑之城。舊根新莖，布葉垂英。彼美淑人，
應家之禎。有絃既鳴，我政則平。宜爾棟崇，必復其慶。
采采者菊，于邦之府。陰槐翳柳，邇楹近宇。彼勞者子，
喧卑是處。慨其莫知，蘊結誰語。企彼高人，色斯遐舉。
采采者菊，于賓之館。既低其枝，又弱其榦。有斐君子，
是焉披翫。良辰旨酒，宴飲無算。愴其仳別，終然永歎。
「歲方晏矣，霜露殘促。誰其榮斯，有英者菊。豈微春華，懿此貞色。人之侮我，混于薪棘。詩人有言，好是正直。」《效陶彭澤》
韋應物
[
编辑
]

「霜露悴百草，時菊獨妍華。物性有如此，寒暑其奈何。」「掇英泛濁醪，日入會田家。盡醉茅簷下，一生豈在多。」《九日奉陪令公登白樓同詠菊》
盧綸
[
编辑
]

「瓊樽猶有菊，可以獻留侯。願比三花秀，非同百卉秋。」金英分蕊細，玉露結房稠。黃雀知恩在，銜飛亦上樓。

《秋夜宴王郎中宅賦得露中菊》
朱灣
[
编辑
]

眾芳春競發，寒菊露偏滋。受氣何曾異，開花獨自遲。
晚成猶有分，欲採未過時。忍棄東籬下，看隨秋草衰。

《賦得寒蜂採菊蕊》
耿湋
[
编辑
]

遊颺下晴空，尋芳到菊叢。帶聲來蕊上，連影在香中。
去住霑餘霧，高低順過風。終慚異蝴蝶，不與夢魂通。

《萬年厲員外宅賞殘菊》
顧非熊
[
编辑
]

纔過重陽後，人心已為殘。近霜須苦惜，帶蝶更宜看
​
色減頻經雨，香銷恐漸寒。今朝陶令宅，不醉卻應難。

《病中辱朱諫議惠甘菊藥苗因以詩贈》
[
编辑
]

姚合

蕭蕭一畝宮，種菊十餘叢。採摘和芳露，封題寄病翁。
熟移茶鼎裡，餐稱石甌中。香氣將何比，從來味不同。

《和令狐相公玩白菊》

编辑

「家家菊盡黃，梁國獨如霜。瑩淨真琪樹，分明對玉堂。」仙人披雪氅，素女厭紅妝。粉蝶來難見，麻衣拂更香。
向風搖羽扇，含露滴瓊漿。高艷遮銀井，繁枝覆象床。
桂叢慚並發，梅萼妒先芳。一入《瑤華詠》，從茲播樂章。

《和令狐相公九日對黃白二菊花見懷》
[
