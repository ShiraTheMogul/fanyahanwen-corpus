嚴恪
[
编辑
]

按《常熟縣志》：「嚴恪，字心萱，少嘗投牒為群掾，旋棄去力田，遂掌賦於鄉邑。有白茆塘，江南諸水注海道也。歲久壅淤，則下流無從疏洩，以故江南多水患。恪為掌賦，輸運至都，適鄉民陳宗祥叩闕上疏，請濬白茆，恪遂與同事，因得大濬，自是言水利者，咸祖其說。又嘗以吳中多蕪田，歲逋無所出，因出所有膏腴資諸」逋賦者，名曰「助役。」為人氣概軒舉而度闊達，于民瘼，
時務無不周知，撫按多從咨訪焉。所著《水利紀略》《隨
意吟》等書。

李栗
[
编辑
]

按《常熟縣志》：「李栗，字翼寬，由歲貢順天中式入京。有蜀人陳清者，坐法當刑，其子寵年甫十四，請代父死，繫獄。栗憐之，為之營救，費白金三百餘兩。朝廷嘉寵孝，併赦之。後清為崑山縣丞，崑山去栗居止一舍，絕不往。清將歸，願以女侍，固卻之，復以金資其行。當其救清也，非有相知之素，特以幼子代父，身在逆旅，不」惜重費，脫人于縲絏，較之晏子脫越石父，固為過之。
後謁選，得虔州府通判。子嗣賢，亦鄉舉。

袁墨津
[
编辑
]

按《常熟縣志》：袁墨津，逸其名，授徒餬口。嘗夜行，拾金
一囊，密記其數，榜于里門，叩領者凡三人。津審其言
與數合者𢌿之，其人願割半為謝，不受。孫司理樓，作
《還金頌》。

徐訥
[
编辑
]

按《常熟縣志》：「徐訥，字敏叔，博學有高行，累世聚居，輯古今同居者為集，刻行之。又取《袁氏世範》《浦江鄭氏遺範》為家規，旦夕男女長幼，聚一室以飲食，每晨列于堂下，鳴鼓述訓警勵之。已乃升堂敘揖，題於楹曰：『永遵家訓，不聽婦人言。有善必獎勵以成之，有過必為之覆掩。有田百頃，躬課僮奴以耕，察其勞苦，未嘗』」加以詈詬。夜大雨，水暴漲壞防，其僕某獨往視水當
缺處，以身障之，亟呼眾塞之。及明，僕從田閒歸，訥慰
​
勞甚至，曰：「汝有士人之心，豈可久沒於我乎？」斥田百
餘畝以業之，使居於旁舍，不復待以僕隸。家量出入
無二，每歲歉，必捐粟以賑，當雨雪，輒使人問貧乏者
施之。賓賢好士，常若不及。布衣大帶，食無加味。其言
動閒皆有繩矩。與人語，必依於忠信孝友。君子以為
有「萬石君」之行。按部憲臣守令皆禮重之，詢以民務。
卒年七十一，號「南溪翁。」子恪，成化丙戌科進士，自有
《傳》。

邵天相
[
编辑
]

按《常熟縣志》：「『『邵天相，號恥齋，嘗涅孝弟』二字於左臂，已又刻孝弟忠信禮義廉恥』八字，隱懸於胸，時才八九齡耳。家貧，教授有聖裔孔朝綬者，宰松陵，聞天相名，延訓其子黃給事鉞死節，人未識其墓，天相訪得之，樹碑以識。又憫公無嗣，有族人在田閒，徒步相等，慰勞甚至。邑令楊子器時嘗造訪，問民閒疾苦，以賑饑」事委天相，相家至戶察，見釜多蘼蕪，捧之而泣，全
活甚眾。

余銘
[
编辑
]

按《常熟縣志》：「余銘，字新之。邑校生周謹，自好力學，冀科名，累被薦，不得意，以疾卒。嘗議婚妻，後喪明，其家請罷婚。銘曰：『夫娶者豈以貌哉？卒娶之，待之良厚。銘與人交有信義，取舍無所苟，有不當其意必面舉，人皆服其義』。」劉昇
[
编辑
]

按《常熟縣志》：劉昇，字仲昇，其先歸德人。宋有以都統
制鎮許浦，子孫因家于常熟。昇少以開敏聞鄉曲，縣
庫災，縣令將歸罪于下，昇白令曰：「罪非己致，固當順受，奈何陷無辜于死地？」令愧而止。彭瑛歿于官，妻孥
無所歸，昇為之僦居，營其途費而送之，時人以為義。

陳至善
[
编辑
]

按《常熟縣志》：「陳至善，字用拙，中丞司成之從孫。父燦，敦尚信義，有友人遠行，以七百金寄之。十七年後，其友歸，即以原金還之，封識宛然，其狷潔多類此。生有夙因，襁褓中聞大母誦佛，號啼輒止，讀《魯論》至『朝聞夕死章，問母死歸何處，父訝詰之，答曰：『聞道必知生死』。父默然，謂是兒當于無生法中得解。及長，喜吟詠』」，
善臨池，篤信雲棲淨土法門。寂公為雲棲嫡嗣，駐錫
藤溪，茅茨不剪，至善倡為檀施，浸成寶坊。漢月、聞谷
諸禪宿咸以法器許之。錢宗伯刱放生會，亟訪一善
信董厥事，國人皆曰：「無如陳用拙。」因悉以𢌿勝果圓
集。族子偶貽貲數鍰，堅弗受。其人潛藏書笥，踰年，曝
書得之，以佐佛事。途行遇字紙，必袖歸付閼伯。一日，
從故紙獲遺鏹，見大豕過屠門，即以鏹贖豕畜徑山。
嘗詣邑完稅司記者誤浮其數。至善歸，始覺，懼為司
記譴，通夕不寐，質明，急使釐正焉。死之日，藤溪寂法
師夢至善緇衣黃絛，含笑言別，亟走視，見誦佛號「吉祥」而逝。子式，貢生。

楊周
[
编辑
]

按《松江府志》：「楊周，字起東，華亭之漕涇。里人。以俠節聞，當世賢豪皆折節下禮之。兄伊故豪於貲，悉以授周，周撫其孤，紀綱之，身無所私。時族有利其產者，思以危法相傾，周恩遇之，其人愧止。周雖布衣，而里中敬服，得其一言為重，訟者多就控焉。郡邑長賢其才，里中事疑不能決者，輒牒下案剖之。有周甲者，為族」人所窘，周奉檄勸諭，歸其侵田。甲夜饒五百金拜庭
下，周叱曰：「若不惜床頭金贈我，曷不即予族人乎？」有
賈持金三千留寄，遲十年賈至，倍其子母錢還之，客
堅謝子不受，周不得已，散之貧民。療疾賑饑，所存活
以萬數。都下一鴻臚，與周旅館相接，貧不能歸，櫬罄
橐賑之。金山總戎楊卒於官，麾下有報仇者，力為營
救，更捐資以賻吳門，見一少婦行乞，使人廉其狀，曰：
「夫坐侵糧六百石，將就肆朝耳。」周叩篋，如數輸之官，
立脫其厄。

陳仲山
[
编辑
]

按《松江府志》：「陳仲山，字仁卿，其先由虎林徙青浦之貞溪，幼鞠於張蒙張姓。少工舉業，為督學楊宜所知。伯仲兄故食貧，悉推餘產資之，獨奉兩尊人，備滫瀡懽父卒，甫就斂而島寇犯，貞溪號哭掖母，奉櫬而逃。已葬父泖涇，復犯泖涇，乃復奉母還。貞溪。後居華亭里，里人困以踐更，仲山奮身出代。知府胡峻德廉其」賢，竟罷役。婦翁朱克裕客死，為養其嫠室及孤。友人
以積逋就逮，為捐資代輸。四方負笈者益多，則察其
貧者，返贄授餐，士用感勵。吳太僕炯其一也。臺使守
令先後表門。仲山年八十九終。所著有《讀論語諸記》
《省愆日錄》。子善能孝養，有《續省愆錄》，陸彥章重其惇
行焉。

周禋
[
编辑
]

按《松江府志》：「周禋，字維敬，為府掾。太守鄢陵劉璟器之。璟以剛直忤時，侍御黃憲欲按以墨，悉拘諸掾拷掠之，皆誣服。禋獨鳴其冤，楚毒備至，無撓辭。黃怒，繫之獄。或曰：『此上官意，何自苦』？乃抗言曰：『贓罪安在？即​如君輩言，天理人心，澌滅盡矣』。詰朝，黃復召鞫之，乃大呼曰：『前上海令張蓋入太守門，太守庭撻之，果墨，安能爾』？」黃悟得解，一時服其膽識。補樂平簿，改興國。
尋告歸，登臨眺詠，與顧文僖清、曹定庵時中詩篇酬
和。禋好著述，善星學，數工草書。手輯詩評，範圍奇門
醫圃雜言數十種。所著《樵唱集》，定庵為序。孫思兼傳
見《名臣》中。

周榆
[
编辑
]

按《松江府志》：「周榆，字永新，賢而好施，常行田閒得遺金，乃僧募貲跡而還之。一日，操舟入城，舟尾鱗次不得渡，有鬨者迫甚，問其故，曰：『吾婦產且殆，求醫不得前』。榆即舍舟假之，謂曰：『吾居周家藻里，爾暇以舟歸我』。竟徒步而還。年八十一。先一夕沐浴，晨起更衣禮佛，趺坐而逝。」莊大儒
[
编辑
]

按《松江府志》：「莊大儒，字仲醇，其先隨宋南渡，家於華亭，累世敦睦。大儒賦性渾樸，容止端凝，自幼以孝聞。繼母或卞急，輒長跪責躬，至使感動隕涕。撫同母異母弟四人，教養婚娶，毫髮罔閒，姻黨皆蒙周卹。有母族之貧者，弗克葬，大儒為之襄事焉。家僅中人產，然為德不倦，常從錢蓬萊大復受經。及大復倡興理學」，
首與講席，多所闡發。三試京兆不售，益刻志聖賢之
學，著有《鞭駑》《知非》二錄，論者謂得省身之要。董文敏
其昌、陳徵君繼儒每加欽挹。年僅五十有一卒。子若
孫皆能世其素風。後十餘年，知府方岳貢訪先賢學
行可師者，眾以「大儒」對，惜不及其世，乃為傳以表之。

葉蕃春
[
编辑
]

按《松江府志》：「葉蕃春副憲，有聲之父，嘗宿海上邸舍，主人出追逸僕，獨少婦在，日且暮矣，蕃春渡浦避之。時暴風疾雨，足繭血濡，無所顧。又有妾媵與嫡忤胠篋迷失道，夜匿蕃春園中，密召其夫與俱歸，曰：『毋箠楚，更聞諸人以垢汝』。」其質行修飭，真有古人之風。

湯聘
[
编辑
]

按《宜興縣志》：「湯聘，字起莘。生八歲，見塾師吟《桂花》詩云：『三種擅天香，黃開白已芳』。後韻閣筆不就。聘續成云：『一枝紅未發，留待狀元郎』。時稱神童。嗣補博士弟子員，食餼設帳授徒，每年館穀，悉公之兄弟。析箸時，得街北房，因季弟為母鍾愛，讓北就南。生平無二色，嘗有婦挑之不亂。九赴棘闈屢蹶，因絕意仕進，嘯吟」林圃，自號「南園處士。」所著《詩文遺稿》，杭雙溪為之
序。

施𤣱
[
编辑
]

按《宜興縣志》：施𤣱，事母甚孝，嘗割股以療母疾。平生
嚴謹，不發一褻語。善作短簡，通佛書，嘗揭「暗室虧心」等語於楣以自警。與保安寺僧交，僧忽病且篤，出所
私蓄托敦後事。𤣱乃令僧手識之。及卒，謀為殮殯，極
其周致，出所寄歸其徒，封識宛然。年九十而終。

陳一經
[
编辑
]

按《宜興縣志》：「陳一經，號懷古，至性純孝。生不識父，詢得貌，繪而事之。每諦視輒嗚咽欷歔，至老不衰。母節蒙旌，以筆耕所獲佐官鏹建坊。為人方正有器識，好義若渴。年十六，有里艾私挑，正色拒之。後迂道弗過其門。僕人娶婦，一經視其舉止，非奴匹，詰之，乃故儒生妻也。急遣還，不問其直。少與異母叔同塾，陵虐百」端，皆忍受不使母知。後叔以嫟敗饑寒，乃更周之。諸
生時昂視軒舉。及再受封爵，而布衣徒步，人不知為
御史父也。設義塾，置義田，子於廷，克成其志。初，從弟
一教幼孤，撫而誨之如於廷。每就館，兩挈以往，主人
難其食，則別寄一教館，餐餐不飽，潛㩦杖頭買餅脯
啗之。考終後，鄉黨公諡曰「孝潔先生」，建特祠於城西
南隅。《玉音》賜「增光廟祏」四字。

曹佩
[
编辑
]

按《宜興縣志》：「曹佩，字國聲。父病，旦夕侍湯藥，踰數月不怠。父憐之，授以遺蓄，固辭，強而受命，卒藏以備女弟嫁奩。歲歉米貴，民爭鬻覓利，佩以其家之稍贏，貸鄉人之貧甚者。子三暘，補漳州守，迎養于署。每稱『一飯一著，皆君之賜，民之力也』。」徐守魁
[
编辑
]

按《宜興縣志》：「徐守魁，字光甫，別號湛如。父用儒，貧不克延師自課。其子守魁奉教，博學力行，為鄉祭酒。初以館穀養其親，及親年高，遂不以館事違膝下。孤姪無依者，撫如己出，必為納婦置產而分析之。有族人入圃行竊，守魁見之，掩身卻走，不忍以園蔬細物斥辱人。嘗夜讌歸，遇賊竊遁，遺其器。守魁見器上有識」，
急置道旁，俾賊自取去。其寬厚體物類如此。歲饑，鄉
之不舉火者千餘家，嘆曰：「彼嗷嗷待賑，貧者有心艱於力，富者有力靳於心，可奈何？」於是殫其力之所可
能，率族人素封者為好義先，群鄉之人咸免於饑。年
五十七卒。子喈鳳、翽鳳俱勉紹家學云。

吳挺秀
[

而老，未嘗抱疾病。《易簀》先一日前知數，因遍辭姻友，
燒羊設酒，盡生平歡。更約以「俗重道場周七一作殊不達幽冥理，茲永別矣。」每七日，令兒童輩亦燒羊設
酒，屈諸公臨而舉觴，倣今夕狀，如生平歡也。嘗三徵
三飲，賓力謝不赴，惟閉戶樂年，印證古今忠義人不
休毫不為細得失、分喜怒。當事者高其品額，旌榮壽，
江淮閒稱「隱君子」焉。少子逢時，明敏有大志，登第後
仕湖州別駕，陞秩寧波郡丞，仕籍最著。
