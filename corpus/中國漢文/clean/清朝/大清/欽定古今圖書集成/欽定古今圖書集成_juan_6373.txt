《詠雪》
聯句　　　　　　　　晉謝道韞
[
编辑
]

《謝太傅安》，寒雪日內集，與兒女講論文義。俄而雪驟，公欣然唱韻，兄子胡兒及兄女道韞賡歌，公大笑樂。

白雪紛紛何所似，
〈謝公〉
撒鹽空中差可擬。
〈胡兒〉
未若「柳絮因風起。」《和元日雪花應詔》
宋·謝莊
[
编辑
]

從候昭神世，息燧應頌道。元化盡天祕，凝功畢地寶。
笙鏞流七始，玉息承三造。委霰下璇蕤，疊雪翻瓊藻。
積曙鏡㝢明，聯萼千里杲。掩映順雲懸，搖裔從風掃。
發貺燭侄前，騰瑞光圖表。澤厚見身末，恩踰悟生眇。
竦誠岱駕肅，側志梁鑾矯。

《發長松遇雪》
鮑照
[
编辑
]

土牛既送寒，奠陵方浹馳。振風搖地局，封雪滿空枝。
江渠合為陸，天野浩無涯。飲泉凍馬骨，斲冰傷役疲。
昆明豈不慘，黍谷寧可吹。

《詠白雪》
前人
[
编辑
]

白珪誠自白，不如雪光妍。工隨物動氣，能逐勢方圓。
無妨玉顏媚，不奪素繒鮮。投心障苦節，隱迹避榮年。
蘭焚石既斷，何用恃芳堅。

《白雪歌》
齊·王儉
[
编辑
]

風閨晚翻靄，月殿夜凝明。願君早流盼，無令春草生。

《阻雪連句遙贈和》
謝脁
[
编辑
]

積雪皓陰池，北風鳴細枝。九逵密如繡，何異遠別離。

〈謝脁〉
風庭舞流霰，冰沼結文澌。飲春雖以燠，欽賢紛若
馳。
〈江秀才革〉
珠霙條間響，玉溜檐下垂。杯酒不相接，寸心
良共知。
〈王承融〉
飛雲亂無緒，結冰明曲池。雖乖《促席讌》，
白首信勿虧。
〈王蘭陵僧儒〉
飄素瑩簷溜，巖結噎通岐。樽疊
如末澣，况乃限音儀。
〈謝洗馬吳〉
原隰望徙倚，松筠竟不移。
隱憂恧萱樹，忘懷待山巵。
〈劉中書繪〉
初昕逸翮舉，日昃駑
馬疲。幽山有桂樹，歲暮方參差。
〈沈右率約〉

《白雪曲》
朱孝廉
〈失名〉
[
编辑
]

凝雲沒霄漢，從風飛且散。聯翩下幽谷，徘徊依井幹。
既興楚客謠，亦動周王歎。所恨輕寒早，不迫「《陽春》旦。」《貌雪》
梁·昭明太子
[
编辑
]

既同《摽梅》萼散，復似大谷花飛。密如公超所起，皓如
淵客所揮。無羡「崑巖列素，豈匹振露群飛。」《校書祕書省對雪詠懷》
劉孝綽
[
编辑
]

桂華殊皎皎，柳絮亦霏霏。詎比《咸池》曲，飄颻千里飛。
恥均班女扇，羞儷曹人衣。浮光亂粉壁，積照郎彤闈。
鶺鴒搖羽至，鵯鶋拂翅歸。相彼猶自得，嗟余獨有違。
終朝守玉署，方夜勞石扉。未能奏湘綺，何由辨國圍。
坐銷風露質，遊聯珠璧暉。偶懷笨車是，良知高蓋非
​
寄言謝端木，無為陳巧機。

《同劉諮議詠春雪》
簡文帝
[
编辑
]

晚霰飛銀礫。浮雲暗未開。入池消不積。因風墮復來。
思婦流黃素。溫姬玉鏡臺。看花言可折。定自非「春梅。」《雪朝》
同前
[
编辑
]

「同雲凝暮序，嚴陰屯廣隰。落梅飛四注，翻霙舞《三襲》。」實斷望如連，恆分似相及。已觀池影亂，復視簾珠濕。

《詠雪》
〈顛倒使韻〉

编辑

「鹽飛亂蝶舞，花落飄粉匳。」匳粉飄落花，舞蝶亂飛鹽。

沈約
[
编辑
]

思鳥聚寒蘆，蒼雲軫暮色。夜雪合且離，曉風驚復息。
嬋娟入綺窗，徘徊騖情極。弱桂不勝枝，輕飛屢低翼。
《玉山》聊可望，瑤池豈難即。

《詠餘雪》
前人
[
编辑

任昉
[
编辑
]

土膏候年動，積雪表晨暮。散葩似浮玉，飛英若總素。
東序皆白珩，西雝盡翔鷺。山《經》陋密榮，騷人貶瓊樹。

《詠花雪》
庾肩吾
[
编辑
]

瑞雪墜堯年，因風入綺錢。飛花灑庭樹，凝瑛結井泉。
寒光晦八極，同雲暗九天。已飄黃竹路，共慶「白渠田。」《詠雪》
吳均
[
编辑
]

微風搖庭樹，細雪下簾隙。縈空如霧轉，凝階似花積。
不見楊柳春，徒看桂枝白。零淚無人道，相思空何益。

前人
[
编辑
]

雪逐春風來，過集巫山野。瀾漫雖可愛，悠揚詎堪把。
問君何所思，昔日同心者。坐須風雪齊，相期洛城下。

《詠春雪寄族人治書思澄》
何遜
[
编辑
]

可憐江上雪，迴風起復滅。本欲映梅花，翻悲似玉屑。
朝鶯日弄響，暮條行可結。咸言不適時，安知非矯節。

《和司馬博士詠雪》
前人
[
编辑
]

凝階夜似月，拂樹曉疑春。蕭散忽如盡，徘徊已復新。
暫蔽卷紈質，復慚施粉人。若逐微風起，誰言非玉塵。

《詠雪》
裴子野
[
编辑
]

飄颻千里雪，倏忽度龍沙。從雲合且散，因風卷復斜。
拂草如連蝶，落樹似飛花。若贈離居者，折以代瑤華。

《望雪》
虞羲
[
编辑

[
编辑
]

長城飛雪下，邊關地籟吟。濛濛九天暗，霏霏千里深。
樹冷月恆少，山霧日偏沉。況聽南歸鴈，切思《胡笳》音。

《詠雪》
徐陵
[
编辑
]

瓊林元圃葉，桂樹日南華。豈若天庭瑞，輕雪帶風斜。
三農喜盈尺，六出舞祟花。明朝關門外，應見海神車。

《雨雪曲》
張正見
[
编辑
]

胡關辛苦地，雪路遠漫漫。含冰踏馬足，雜雨凍旗竿。
沙漠飛恆暗，天山積轉寒。無因辭日逐，團扇掩齊紈。

《詠雪應衡陽王教》
前人

编辑

前人
