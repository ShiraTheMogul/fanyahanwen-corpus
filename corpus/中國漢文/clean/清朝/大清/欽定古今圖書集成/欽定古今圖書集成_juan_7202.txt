揭容
[
编辑
]

按《建昌府志》：揭容，揭文昭家僕。容不讀書，而孝敬出
天性。或得佳味，必歸獻主。次及母，母死，遂辭主廬墓
上。容父先是出亡，喪畢，誓曰：「若不見父，雖天涯吾往。」乃刻其像，戴於首，衣襖跣足，無閒寒暑。自江而浙，歷
荊襄，過建業，直抵燕遼，行丐於市，歷幾歲竟不得，人
咸哀之。

毛普聖
[
编辑
]

按《建昌府志》：「有毛普聖者，父棄家遠遊。普聖既長，娶妻養母，脫身獨出，歷訪其父，得於岳州迎歸。」何學恂
[
编辑
]

按《建昌府志》：「何學恂，字遵信，號涵斐，廣昌人。恩貢，贈提學副使。生未彌月即失母，王父不甚嚴督，而檢飭端重。事庶母撫庶弟無閒言。均產時，祖母胡欲溢予產，力辭不受。」吳縫
[
编辑
]

按《建昌府志》：「吳縫，字子縫，南豐人，庠生。性篤孝友，兄弟七人義不分析。父病便閉，醫云可吮而通，縫如其言。母病亟，為嘗糞甜苦。」王衡
[
编辑
]

按《建昌府志》：「王衡，廣昌邑庠生。母卒，哀毀骨立，朝夕一食，寢苫枕塊。越小祥，猶不啖虀鹽，因以疾終。縣令表其門。」饒衡
[
编辑
]

按《建昌府志》：「饒衡，廣昌人。執父母繼母之喪皆盡禮，不茹葷酒，不離苫塊者九年。弟以租逋繫獄，衡棄業代贖其罪。族叔某，貧困無依，夫婦俱流落，勉力請歸，供贍至老如一。」李鐸
[
编辑
]

按《建昌府志》：「李鐸，廣昌邑庠生。長兄松久外處，鐸迎歸而養，撫次兄柏二遺孤，教養如己子。比卒，無嗣，貧不能殮，縣令梁榮助以棺。王素節輓詩有『歐陽義重存孤子，司馬情真篤老兄』。」楊旻
[
编辑
]

按《建昌府志》：「楊旻，南豐歲貢，賦性淳厚，學問該博。應貢入監，乞假終養，事必稟命，新不先嘗。應物接人，言動有禮。」汪士寬
[
编辑
]

按《建昌府志》：「汪士寬，字用毅，號密峰，新城人。講學讀書，力行古禮。事其母，必夫婦侍饌畢而後己食。母或他往，必兄弟自肩之。」李實
[
编辑
]

按《新城縣志》：「李實，字維亮，號杏園，北坊人。少以孝聞，舉孝廉，以親老辭不就。縣令陳員韜舉為耆老。年九十，屢賓鄉飲。」吳駒
[
编辑
]

按《建昌府志》：「吳駒，字彥驤，南豐人。父潮宗，傭里人孫乙家。里胥彭文傑縛孫乙去，潮宗率諸子毆文傑致死，法坐潮宗。彥驤曰：『吾父老矣，吾弟幼且無後』。自詣獄曰：『死文傑者，彥驤也』。令憫而代之。孝子日侍父獄中，朝夕起居，猶荷校而立。父出獄，人曰：『孝哉，吳氏之子乎』！或有感而泣下者。居二載，有詔讞獄行在所。孝」子行至淮安，病卒，年六十，時宣德六年辛亥也。史官
曰：「世以孝聞者，或刲肉一臠，廬墓三載，精感天地，誠動鬼神，況以身代死若彥驤者乎？」祝錫引
[
编辑
]

按《建昌府志》：「祝錫引，字貞元，南豐人。乙酉，潰兵掠南豐，偕父抱祖母出走，力疲弗前。事急，父揮之不去。有頃，皆被執，痛哭請以身代，遂遇害，而祖母暨父免于難。」李嘉祐
[
编辑
]

按《新城縣志》：「李嘉祐，南坊人。自少喪父，事母頃刻不離左右，每事必咨稟母命而後行，出告反面，未嘗少違。母年九十卒，哀號躄踊，勺水不入口者三日，絕而復甦。三年之間，非奉祭祀，夫婦未嘗一相見。服闋，每歲忌辰必齋戒，每月朔朢必躬詣塋域拜掃。年六十而卒。」余永壽
[
编辑
]

按《建昌府志》：「余永壽，新城人。家貧，授徒養母。母死三年，卻酒肉，結廬墓側，日夜號泣。鄉人惡之，燬其廬，永壽復覆，以終三年。」李綸
[
编辑

按《建昌府志》：「李綸，字廷言，新城人。父年九十，晨夕承歡，敬養不怠。居喪，廬墓三年不肉食。族戚貧者，日就食，其家不厭。」王灝
〈孫達〉
[
编辑

按《建昌府志》：「王灝，字清宇，號進齋，新城舉人，終河閒府教授。天性純孝，領教職，陳情乞便養，授雩都教諭​再補福建懷安。所至師道端嚴，才傑興起。冢宰王翱知其學行，特薦陞河閒府教授，以淑其鄉。聞父訃，哀毀，卒于官。孫達，事寡母亦以孝聞。陳參政敦請教子，閱半載，念母告歸，幣禮再至，以晨昏闕侍，力辭不赴。」鄧植
[
编辑

按《建昌府志》：「鄧植，字宜春，新城人。少豪任，多才技，已乃棄去。所宿好，篤信義，讀書交友。父病，侍湯藥，旬月不盥櫛，不解衣帶。與仲兄弟共增祭田，正祭儀，定家規，約族眾于仁禮。兄卒，哀號委頓，終喪不設燕會。郡守曾璵稱南山孝子。」裘獻
[
编辑

按《建昌府志》：「裘獻，新城人。業皮。父患足疾，不能行，每日負至市肆，具酒肉飲食之，晚則負以歸。事繼母陳，孝謹無二。」陶亮
[
编辑

按《建昌府志》：「陶亮，新城人。業庖，事親力盡孝養。父母歿，皆年八十，廬墓終喪。每朔望必往省，歲除必宿墓所哀號。嘗虎過其旁而不傷。」劉公腹
[
编辑

按《建昌府志》：「劉公腹，字克彰，南豐人。公腹生而遺孤，痛母苦節，奉養皆踰恆情。母疾則嘗糞甜苦，沒則臥廬墓旁，不食肉者三年。竟以哀毀卒。」何宗
[
编辑

按《建安府志》：「何宗，字本茂，廣昌人。好學能文，嘗修輯邑志，不樂仕進。省父于溫州，布衣繩屨，往返數千里，與諸弟居，每舉聖賢之學相勸勉。居父喪，哀毀。縣人有誣以罪者，下錦衣衛獄。奏覆，得白遘疾卒。」吳懷英
[
编辑

按《建昌府志》：「吳懷英，號蒲石，南城人。九歲失父，母以疾廢，與妻設椅擔于庭。鄰人失火，英負母避風，旋反居，得不燎。母卒，廬墓三年，行年七十，不以老廢禮。」涂懋政
[
编辑

按《建昌府志》：「涂懋政，字西麓，舉人，柳州知州。家貧父老，膳必甘毳，出必乘輿，每枵腹以食。舁人夜歸，則身秉炬以逆風雪不廢。母病，刲股以進，尋愈。兩院欲疏聞，泣辭乃止。守柳民有訟兄者，聞其風，感泣而止。」羅鈇
[
编辑

按《建昌府志》：「羅鈇，字明衛，號愚丘，南城人，南京工部營繕所所正。父增，被族人經獄，連繫，獄成，鈇七上書，以非例，格不行。再詣闕，泣不絕聲。御史大夫汪鋐憫之，為代奏，迺出增計事，始終凡三十六年，備嘗艱苦，歸養終。」曾椿
[
编辑
]

按《建昌府志》：「曾椿，廣昌舉人。博極群書。家雖貧而孝養竭力。父母病，侍臥床地，瘳而後已。弟極梧，皆其造就。」史仲偉
[
编辑
]

按《饒州府志》：「史仲偉，字古泉，鄱陽西隅人。偉性孝義，業儒而貧。母羅氏遘危疾，齋沐籲天，願以身代。及歿，以衣裾兜土成墳，旦夕哭拜。墓下忽產瑞芝徑尺，人異之，以比王裒云。厥後子姓果昌，代以明經科名顯。偉壽九十三，配趙氏九十有五。」朱厚鑣
[
编辑
]

按《饒州府志》：「朱厚鑣，字桂軒，鄱陽人。天性馴厚。早失怙，事母惟謹，省問侍疾，必竭誠盡禮。治喪不出戶庭，衰絰號痛，雖寢臥弗懈。匡廬白鹿洞，鑣捐自置都昌莊田二百九十二畝，計租四百餘石，歲入紫陽倉以佐諸生日費。」王良弼
[
编辑

按《饒州府志》：「王良弼，字白石，鄱陽人。伯祖有年，弘治間，輸粟賑饑，當事褒之。弼幼習舉業，補弟子員。既而厭去之，遂潛心實學。父母歿，俱廬墓三年，人咸稱其至性。」王維貞
[
编辑
]

按《饒州府志》：「王維貞，字公顯，萬年人。事親孝養備至。親歿，哀毀骨立，廬墓三載，肖像刻木，供祀如生。邑庠公舉，巡按倪扁其廬曰『旌獎孝行』。縣令俞額云：『刻木繪像，孝心逼古』。迄今猶存焉。」徐惠德
[
编辑
]

按《饒州府志》：「徐惠德，字志甫，德興人。仁孝性生，事孀母，定省無違。遇母疾，即焚香告天，願身代。及母死，哭曰：『送死實當大事，子而吝所有，不以厚葬厥親，忍乎』？遂傾貲以治殮，追祭盡禮。後雖赤貧，欣然自得。」巡按
旌「孝子」二字，以表其廬。

李岐

编辑

按《饒州府志》：「李岐，鄱陽人。其家四世未析居，至岐以孝聞。巡按陳旌之曰：『四世同居，友愛承乎先德；一門敦孝，和順藹於家庭』。因得請建坊。」王慶雲

编辑

按《饒州府志》：「王慶雲，字文儀，鄱陽人。歲餘而孤。及長，涉獵書史，尤精《左氏春秋》，不干仕進。性孝，事母朝夕​定省。遇疾，嘗藥祝神，願以身代。色養二十餘年不衰。為人倜儻，尚大節，樂施予，鄉里重之。」徐流傳
[
编辑

按《饒州府志》：「徐流傳，德興人。幼聰敏，日記數千言。隨父宦遊石門，王縣尹命賦《譙樓》詩，立就，王器重之。母患乳癰，弗瘳，傳以口吮之，遂瘳，以隱終。」舒方伯清輓
詩有云：「處士聞捐館，人嗟制行難。吮癰能活母，學道不求官。」李信中
[
编辑

按《饒州府志》：「李信中，浮梁人。三歲孤，母與嬸黃氏忤。會失貓，黃紿以伏臥內。母入而黃之，夫在臥，黃鑰戶大呼有奸，母不能白而縊死。信中年十二，知之，泣誓母墓而行。傭抵京師，上訴于朝，上嘉嘆，論黃死，欲授之官。信中辭曰：『乞歸報母』。上手摩其頂曰：『人家乃有此兒』。取黃帛親為裹髮資之，歸，終身不冠櫛。」蔡天祥
[
编辑

按《饒州府志》：「蔡天祥，字君瑞，餘干人。事母孝。一日，母疾，思食鴿鶉，天祥求之草莽中，得兩翼。母夜夢神人語之曰：『汝子孝，天與汝九』。其後母年增九歲。」李瓊玉
[
编辑

按《饒州府志》：「李瓊玉，浮梁人。母病篤，刲股食之，因感異夢而母愈。踰年母卒，廬墓三年，行人感涕。院司表其里門。知縣汪宗伊疏聞。」倪蒼　倪旺真
[
编辑
]

按《饒州府志》：「倪蒼、倪旺真，俱安仁人。兩人父役糧長，各當極刑。適決蒼與旺真擊登聞鼓，各以身代其父死。上宥之，兩人父子俱得免。」夏子羽
[
编辑
]

按《饒州府志》：「夏子羽，字伯起，樂平人。自幼至孝，刻苦讀書。父疾，避人刲股。及歿，廬墓三載。晚從史汝寧遊，遂豁然不復苦讀。途中自吟曰：『問道歸來月滿肩，忻然長笑任吾天。夜分見月弄梅』。又吟曰：『瘦影不嫌貧，橫斜上茆屋』。其妻徐氏，化于孝義嫂生兒三日，亡，乳哺之如己子。子羽病危，禱以身代，而徐果卒。無子，力」為娶妾。其里中好善者二十四人，擇日投誓，禱天曰：
「奈何子羽無後？」次年，妾以是日生一子，手足生六指，
應二十四之數。蓋報施之奇徵焉。

陶慶

按《撫州府志》：「董弘學，字旋吉，樂安人。年十二，母見背踴，泣輒瀕死。大父懼以慟夭，糜之粥。及至塾，則執書不讀，瞬淚無乾。師加杖跪，弘學泣曰：『師無以兒書為也，吾僅欲得長侍吾母』。師亦感泣。母柩向停館側，日必三省。異時師偶他飲，醉歸就寢，漏下三鼓，師醒，值大雷雨，忽聞嗚咽聲，風雨聲相錯，鄰怖為妖，獨師心」動曰：「得無某孺子猶號母所？」亟視之，從電光中見其
兩手翼柩，如晤語然，柩中似有應者，亟護歸。後繼母
兩張，再娶何，又為李為郭，最後為楊，凡六事之，皆如
所生。楊常病疫，家人無敢近，獨弘學日夕與側。壬申
流寇掠其族，弘學倉卒負母去。賊見其四壁所列，皆
聖賢格言，題其門曰：「窮孝子家，獨免」于燬。

按《撫州府志》：「吳二，臨川人。事母極孝。一夕，夢神語曰：『汝有夙譴，明午當雷震死。二以母老在堂，必至受驚。詰旦具膳以進，白母暫往妹家，母不許。俄黑雲起日中，須臾遍布天地，暝晦雷電大作，二益慮驚母乃開戶，獨出空所，跪而待罪。頃之雲開，竟免禍。亟歸拊母道故鄉鄰異之。或勸二盍隱其事，二曰：『天鑒昭彰，敢自昧乎』』？」夜復夢神語曰：「汝以至孝感天，夙譴已宥，宜加敬事。」自是孝養其母終身。
