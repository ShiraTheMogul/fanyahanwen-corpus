《富春渚》
宋·謝靈運
[
编辑
]

宵濟漁浦潭，旦及富春郭。定山緬雲霧，赤亭無淹薄。
愬流觸驚急，臨圻阻參錯。亮乏伯昏力，險過呂梁壑。
洊至宜便習，兼山貴止託。平生協幽期，淪躓困微弱。
久露干祿請，始果遠遊諾。宿心漸申寫，萬事俱零落。
懷抱既昭曠，外物徒龍蠖。

《濟浙江》
梁·任昉
[
编辑
]

昧旦乘輕風，江湖忽來往。或與歸波送，乍逐翻流上。
近岸無暇目，遠峰更興想。綠樹懸宿根，丹崖頹久壤。

《還渡浙江》
劉孝綽
[
编辑
]

季秋弦朢後，輕寒朝夕殊。商人泣紈扇，客子夢羅襦。
憂來自難遣，況復阻川隅。日暮愁陰合，繞樹噪寒烏。
濛漠江煙上，蒼茫沙嶼蕪。解纜辭東越，接軸騖西徂。
縣帆似馳驥，飛棹若驚鳧。言歸遊俠窟，方從冠蓋衢。

《日夕出富陽浦口和朗公》
何遜
[
编辑
]

客心愁日暮，徙倚空望歸。山煙涵樹色，江水映霞暉。
獨鶴凌空逝，雙鳧出浪飛。故鄉千餘里，茲夕寒無衣。

《黃蘗山》
江淹
[
编辑
]

長望竟何極，閩雲連越邊。南州饒奇怪，赤縣多靈仙。
金風各虧日，銅石共臨天。陽岫照虹谿，陰巒噴龍泉。
蘢蓯千代木，廧萃萬古煙。禽鳴丹壁上，猿嘯青崖間。
秦皇慕隱淪，漢武願長年。皆負雄豪威，冠劍藏名山。
況我葵藿志，松木橫眼前。所喜同遊好，臨風意悠然。

《將適天台留別臨安李主簿》
唐·孟浩然
[
编辑
]

枳棘君尚樓，《匏瓜》吾豈繫。雖念離當夏，漂泊指炎裔。
江海非遊倩，田園失歸計。空山既早發，漁浦亦宵濟。
泝泝隨波瀾，行行任艫枻。故林日已遠，群木坐成翳。
羽人在丹丘，吾亦從此逝。

《下浙江》
前人
[
编辑
]

八月觀濤罷，三江越海潯。迴瞻魏闕路，無限子牟心。

《送盧郎中除杭州之任》
岑參
[
编辑
]

罷起郎官草，初分刺史符。海雲迎過楚，江月引歸吳。
城底濤聲震，樓端蜃氣孤。千家窺驛舫，五馬飲春湖。
柳色供時用，鶯聲送酒須。知君望鄉處，枉道上姑蘇
​

《送丘員外還臨平山居》
韋應物
[
编辑
]

長棲白雲表，暫訪孤齋宿。還辭郡邑喧，歸乏松江綠。
結茅蒼嶺間，伐薪響深谷。同是山中人，不知往來躅。
靈芝非定草，遼鶴遠池鶩。終當標里門，一表高陽族。

《送金昌宗歸錢塘》
劉長卿
[
编辑

新家浙江上，獨泛落潮歸。秋水照華髮，涼風生褐衣。
柴門嘶馬少，藜杖拜人稀。惟有陶潛酒，蕭條對掩扉。

《海鹽官舍早春》
前人
[
编辑
]

小邑滄州吏，新年白首翁。一官如遠客，萬事極飄蓬。
柳色孤城裏，鶯聲細雨中。羈心早已亂，何事更春風。

《送王少府之富春》
韓翃
[
编辑
]

歸舟一路轉青蘋，更欲隨潮向富春。吳地陸機稱地
主，錢塘蘇小是鄉親。葛花滿地能消酒，梔子同心好
贈人。早晚重過魚浦宿，遙憐佳句篋中新。

《暮泊富陽》
孫逖
[
编辑
]

扁舟夜入江潭泊，露白風高氣蕭索。富春渚上潮未
迴，天姥岑邊月初落。煙水茫茫多苦辛，更聞江上越
人吟。洛陽城闕何時見，西北浮雲朝暝深。

《送元盛歸於潛山》
皇甫冉
[
编辑
]

深山秋事早，君去欲何如。挹露收新稼，迎寒葺舊廬。
題詩即《招隱》，作賦是《閒居》。別後空相憶，嵇康懶寄書。

《官舍》
白居易
[
编辑
]

「高水換新葉，陰陰覆地隅。何言太守宅，有似幽人居。」太守臥其下，閒慵兩有餘。起嘗一甌茗，行讀一卷書。
早梅結青實，殘櫻落紅珠。稚女弄庭果，嬉戲牽人裾。
是日曉彌靜，巢禽下相呼。嘖嘖護兒鵲，啞啞母子烏。
豈維云鳥爾，吾亦引吾雛。

《城上對月》
前人
[
编辑
]

古人惜晝短，勸令秉燭遊。況此迢迢夜，明月滿西樓。
復有盈樽酒，置在城上頭。期君君不至，明月兩悠悠。
照水煙波白，照人肌髮秋。清光正如此，不醉即須愁。

《城上》
前人
[
编辑
]

城上鼕鼕鼓，朝衙復晚衙。為君慵不出，落盡遶城花。

《葛仙翁丹鼎》
前人
[
编辑
]

千古仙居物象饒，道成丹熟晝昇霄。巖前寶磬傳松
韻，洞口靈池應海潮。崖折百花遲日晚，鶴歸清夜唳
聲遙。登臨漸到希夷境，手拂行雲渡石橋。

《除官去未閒》
前人
[
编辑
]

除官去未閒，半月恣游討。朝尋霞外寺，暮宿波中島。
新木少於松，平湖半連草。躋攀有次第，賞翫無昏早。
有時騎馬醉，兀兀冥天造。窮通與生死，其奈吾懷抱。
江山信為美，齒髮行將老。在郡誠未厭，歸鄉去亦好。

《於潛南亭城樓送春》
前人
[
编辑
]

含桃實已落，紅薇花尚熏。冉冉三月盡，曉鶯城上聞。
獨持一杯酒，南亭送殘春。「半酣復長歌，歌中何所云？云我五十餘，不是苦老人。刺史二千石，亦不為賤貧。天下三品官，多老於我身。同年登第者，零落無一分。親故半為鬼，童僕多見孫。念此聊自解，逢酒日歡欣。」《南樓晚興》
前人
[
编辑
]

「極浦收殘雨，高城駐落暉。山明虹半出，松暗鶴雙歸。」將吏隨衙散，文書入務稀。閒吟倚新竹，嫩粉汙朱衣。

《餘杭形勝》
前人
[
编辑
]

餘杭形勝四方無，州傍青山縣枕湖。遶郭荷花三十
里，拂城松樹一千株。夢兒亭古傳名謝，教妓樓新道
姓蘇。獨有使君年太老，風光不稱白髭鬚。

《郡中即事》
前人
[
编辑
]

漫漫潮初平，熙熙春日至。空闊遠江山，晴明好天氣。
外有適意物，中無繫心事。數篇對竹吟，一盃望雲醉。
行攜杖扶力，臥讀書取睡。久養病形骸，深諳閒氣味。
遙思九城陌，擾擾趨名利。今朝是隻日，朝謁多軒騎。
寵者防悔尤，懽者懷憂畏。為報高車蓋，恐非真富貴。

《花樓望雪命宴賦》
前人
[
编辑
]

「連天際海白皚皚，好上高樓望一迴。何處更能分道路，此時兼不認池臺。」萬重雲樹山頭翠，百尺花樓江
畔開。素壁聯題分韻句，紅爐巡飲煖寒盃。冰鋪湖水
銀為面，風捲汀沙玉作堆。絆惹舞人春艷曳，勾留醉
客夜徘徊。輸將虛白堂前鶴，失卻樟亭驛後梅。別有
故情偏憶得，曾經窮苦照書來。

《喜元微之官越與杭鄰州》
前人
[
编辑
]

稽山鏡水歡遊地，犀帶金章榮貴身。官職比君雖較
小，封疆與我且為鄰。郡樓對玩千峰月，江界平分兩
岸春。杭越風光詩酒主，相看更合是何人。

《別州民》
前人
[
编辑
]

耆老遮歸路，壺漿滿別筵。甘棠無一木，那得淚澘然。
稅重多貧戶，農飢是旱田。惟留一湖水，與汝救凶年。

《憶杭州梅花因敘舊遊寄蕭協律》
前人
[
编辑

「三年閒悶在餘杭，曾與梅花醉幾場。」伍相廟前繁似

亦香。賞自初開直至落，歡因小飲便成狂。薛劉相次
埋新隴，沈謝雙飛出故鄉。歌伴酒徒零散盡，唯餘頭
白老蕭郎

《答客問杭州》
前人
[
编辑
]

龍頭。所嗟水路無三百，官繫何因得再遊。

[
编辑

樹色連秋靄，潮聲入夜風。年年此光景，催盡白頭翁。

《孤山》
前人
[
编辑

斷橋荒蘚合，空院落花深。猶憶西窗月，鐘聲出北鄰。

《杭州開元寺牡丹》
前人
[
编辑
]

權德輿
[
