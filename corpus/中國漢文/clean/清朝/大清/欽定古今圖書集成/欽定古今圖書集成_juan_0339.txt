雉部藝文二
〈詩〉

编辑

《越裳操》
周公
[
编辑
]

《琴操》曰：「周公之所作也。周公輔成王，成文王之王道。《越裳》重九譯而來獻白雉，周公乃援琴而歌之，遂受之，獻於文王之廟。」於戲嗟嗟，非旦之力也，乃文王之德也。

《雉朝飛操》
犢沐子
[
编辑
]

崔豹《古今注》曰：「《雉朝飛》者，犢沐子所作也。齊處士泯宣，年五十無妻，出薪於野，見雉雄雌相隨而飛，意動心悲，乃作《雉朝飛之操》以自傷焉，其聲中絕。」雉朝飛兮鳴相和，雌雄群遊於山阿。「我獨何命兮未有家，時將莫兮可奈何，嗟嗟莫兮可奈何。」《白雉詩》
漢·班固
[
编辑
]

《啟靈篇》兮披瑞圖，獲白雉兮效素烏。嘉祥阜兮集皇
都，發皓羽兮奮翹英，容潔朗兮於純精。彰皇德兮侔
周成，永延長兮膺天慶。

《代雉朝飛》
宋·鮑照
[
编辑
]

《雉朝》飛，振羽翼，專場挾雌恃彊力。媒已驚翳，又逼蒿
間，潛彀盧矢。直刎繡頸，碎錦臆，絕命君前無怨色。握
君手，執杯酒，意氣相傾死何有。

《雉朝飛操》
梁·簡文帝
[
编辑
]

晨光照麥畿，平野度春翬。避鷹時聳角，妬隴或斜飛。
少年從遠役，有恨意多違。不如隨蕩子，羅袂拂塵衣。

《雉子斑》
吳均
[
编辑
]

可憐雉子斑，群飛集野甸。文章始陸離，意氣已驚狷。
幽并遊俠子，直心亦如箭。生死報君恩，誰能孤恩眄

前人

编辑

二月雉朝飛，橫行傍壟歸。斜看水外翟，側聽嶺《南翬》。
躞蹀恆欲戰，耿耿恃彊威。當令君見賞，何辭碎錦衣。

陳後主

雊麥且專場，排花聊勇戰。唯當渡弱水，不怯如皋箭。

《雉子斑》
江總
[
编辑

麥壟新秋來，澤雉屢徘徊。依花似協妬，拂草乍驚媒。
三春桃照李，二月柳爭梅。暫住如皋路，當令巧笑開。

《雉子斑》
毛處約
[
编辑

春物始芳菲，春雉正相追。澗響連朝雊，花光帶錦衣。
竄跡時移影，驚媒或亂飛。能使如皋路，相逢巧笑歸。

《射雉》
蕭有
[
编辑
]

二月春翬動，曹王挾妬媒。插翳依花合，芟場向野開。
隔田聞雊近，橫溪見影來。弦明青壓碎，箭落錦衣摧。
「今日如皋路，能將巧笑迴。」《雉》
唐·李嶠
[
编辑
]

《白雉振朝聲》，飛來表太平。楚郊疑鳳出，陳寶若雞鳴。
童子懷仁至，中郎作賦成。冀君看飲啄，耿介獨含情。

《射雉詞》
儲光羲
[
编辑
]

曝暄理新翳，迎春射鳴雉。原田遙一色，皋陸曠千里。
遙聞咿喔聲，時見雙飛起。羃䍥疏蒿下，毰毸深麥裏。
顧敵乃忘生，爭雄方決死。仁心貴勇義，豈復能傷此。
超遙下故墟，迢遞回高畤。大夫昔何苦，取笑歡妻子。

《雉朝飛操》
李白
[
编辑

〈一作犢沐〉
《采薪》感之悲。春天和，白日暖。啄食飲泉
勇氣滿，爭雄鬥死繡頸斷。

《雉子斑曲》
前人
[
编辑
]

《辟邪伎作鼓吹驚雉》子斑之奏曲成，「喔咿振迅欲飛鳴。扇錦翼，雄風生。雙雌同飲啄，趫悍誰能爭。乍向草中耿介死，不求黃金籠下生。」《射雉》
韋應物
[
编辑
]

走馬上東岡，朝日照野田。野田雙雉起，翻射斗迴鞭。
雖無百發中，聊取一笑妍。羽分繡臆碎，頭弛錦鞘懸。
方將悅羇旅，非關學少年。弢弓一長噫，憶在灞城阡。

《山雉》
白居易
[
编辑
]

五步一啄草，十步一飲水。適性遂其生，時哉山梁雉。
梁上無繒繳，梁下無鷹鸇。雌雄與群雛，皆得終天年。

《雉朝飛操》
韓愈
[
编辑
]

雉之飛，於朝日。群雌孤雄，意氣橫出。當東而西，當啄
而飛。隨飛隨啄，群雌粥粥。

《雉帶箭》
前人
[
编辑
]

原頭火燒靜兀兀，野雉畏鷹出復沒。將軍欲以巧伏
人，盤馬彎弓惜不發。地形漸窄觀者多，雉驚弓滿勁
箭加。衝人決起百餘尺，紅翎白鏃相傾斜。將軍仰笑
軍吏賀，五色離披馬前墮。

《雉將雛》
王建
[
编辑
]

雉咿喔，雛出殼。毛斑斑，觜啄啄。學飛未得一尺高，還
逐母行旋母腳。麥隴淺淺難蔽身，遠去戀雛低怕人。
時時土中鼓兩翅，引雛食蟲不相離。

《雉朝飛操》
張祜
[
编辑
]

《朝陽隴東》泛暖景，雙啄雙飛雙顧影。朱冠錦襦聊日
整，漠漠霧中如衣褧。傷心「《盧女》弦」，七十老翁長獨眠。
雄飛在草雌在田，衷腸結憤氣呵天。

《越裳貢白雉》
王若嵒
[
编辑
]

素翟宛昭彰，遙遙自越裳。冰睛朝映日，玉羽夜含霜。
歲月三年遠，山川九譯長。來從碧海路，入見白雲鄉。
作瑞興周后，登歌美漢皇。朝天資孝理，惠化且無疆。

《艾如張》
李賀
[
编辑

錦襜褕，繡襠襦，強飲啄，哺爾雛。「隴東臥穟滿風雨，莫信龍媒隴西主。齊人織網如素空，張在野田平碧中。網絲漠漠無形影，誤爾觸之傷首紅。艾葉綠花誰翦刻，中藏禍機不可測。」《雉場歌》
溫庭筠
[
编辑
]

茭葉萋萋接煙曙，雞鳴埭上梨花露。彩仗鏘鏘已合
圍，繡翎白頸遙相妒。雕尾扇張金縷高，碎鈴素拂驪
駒豪。綠場紅跡來相接，箭發銅牙傷彩毛。麥隴桑陰
小山晚，六虯歸去凝笳遠。城頭卻望幾含情，青畝春
蕪連古苑。

《食雉》
蘇軾
[
编辑
]

雄雌曳修尾，驚飛向日斜。空中紛格鬥，綵羽落如花。
喧呼勇不顧，投網復誰嗟。百錢得一雙，新味時所嘉。
烹煎雜雞鶩，爪距漫槎牙。誰知化為蜃，海上落飛鴉。

《雉朝飛操》
曹勛
[
编辑

雉兮朝飛，鳴聲相隨。朝刷其羽兮夕哺其兒。雖有風

《感興》
方夔
[
编辑
]

「斑斑林中雉，雌雄同朝暉。鼓翅飛不遠，山田麥苗肥。飲啄百步間，未暮相隨歸。當春哺群雛，長大各自飛。宇宙豈不大，嗟爾為生微。」窮途守一轍，畢命芝與薇。

《雉朝飛》
元·楊維楨
[
编辑
]

《琴操》有《雉朝飛》，多指《犢牧子》之作，據揚雄所記，則曰「衛女傅母之所作也。」 余以犢牧之歎，不如衛女之善死，有關世教，故賦以補舊樂府之缺云。

《雉朝飛》一雄挾兩雌，雄死雌誓黃泥歸。衛女嫁齊子，
未及夫與妻。青縭綰素結，一死與之齊。人言衛女蕩
且離，烏得冢中有雉飛，琴聲鼓之聞者悲。

《錦雞》
周權
[
编辑

巴山靈鳥初離群，葳蕤麗組雲錦文。羽翎新刷爪距

范守己
[
编辑

《雉子》斑嘎嘎，鳴中林，黃鵠來掠青雲。雲外嗈嗈遺好

《錦雞》
楊基
[
编辑
]

暖風晴日融春晝，閒看花陰雞唾綬。綺縠都將綵羽
妝，紅絲不待金鍼繡。疊疊胭脂縷縷金，龍紋盤錯鳳

《錦雞圖》
胡儼
[
编辑
]

昔聞楚人不識鳳，忽見山雞重購之。今我畫圖寫生
態，羽毛五色光陸離。扶桑天雞啼一聲，陽烏散彩天
下晴。此時山雞亦出谷，喔喔飛來耀林麓。千巖萬壑
含東風，杏花吹香春雪紅。顧影徘徊自愛惜，揚翹聳
翅紛蒙茸。竹上花間日正高，向陽吐綬垂花絛。吳綾
蜀錦織不得，戴勝偷眼驚伯勞。切莫臨溪照碧流，對
鏡逢人舞便休。舞多目眩終顛仆，世人空詫《韋公賦》。

《四禽圖》
〈詠雉〉
李東陽
[
编辑
]

樛枝老樹幽巖裏，山鷓雙飛掉長尾。高鳴俯搦勢不
停，似向春風矜爪觜。山頭錦雞金作冠，身披五采色
斑斕。遠從紅日霽時見，更向碧山深處看。人言此物
真奇特，同是山禽不同格。休將綠水照毛衣，祇恐桃
花妬顏色。

雉部選句
[
编辑
]

後漢班固《西都賦》：「遊鷮高翬，絕阬踰斥。」晉夏侯湛《梁田賦》，察田疇之疆畔，觀游雉之逸形，
