蕭撒八
[
编辑
]

按《遼史蕭孝穆傳》：「孝穆子撒八，字周隱。七歲以戚屬加左右千牛衛大將軍。重熙初，補祗候郎君。性廉介，風姿爽朗，善毬馬馳射。帝每燕飲，喜諧謔，撒八雖承寵顧，常以禮自持，時人稱之。以柴冊禮恩，加檢校太傅，永興宮使，總領左右護衛，同知點檢司事。尚魏國公主，拜駙馬都尉，為北院宣徽使，仍總知朝廷禮儀。」重熙末，出為西北路招討使、武寧郡王，居官以治稱。
清寧初，薨，年三十九，追封齊王。

蕭奪剌
[
编辑
]

按《遼史蕭奪剌傳》：「奪剌字挼。」遙輦洼可汗宮人。祖
涅魯古，北院樞密副使。父撒抹，字胡獨菫，重熙初，補
祗候郎君，累遷北面林牙，拜大。父敞穩，知山北道邊
境事。清寧初，歷西南面、西北路招討使，加同中書門
下平章事，卒。奪剌體貌豐偉，騎射絕人，由祗候郎君
陞漢人行宮副部署，後為烏古敵烈統軍使，克敵有
功，加龍虎衛上將軍，授西北路招討使，改東北路統
軍使。乾統元年，以久練邊事，復為西北路招討使。北
阻卜耶睹刮率鄰部來侵，奪剌逆擊，追奔數十里。二
年，乘耶睹刮無備，以輕騎襲之，獲馬萬五千疋，牛羊
稱是。先是，有詔「方面無事，招討副統軍都監內一員入覲。」是時同僚皆闕，奪剌以軍事付幕吏而朝，坐是
免官。改西京留守，復為東北路統軍，卒于官。

蕭滴洌
[
编辑
]

按《遼史蕭滴洌傳》：「滴洌，字國寧，遙輦鮮質可汗宮人。重熙初，遙攝鎮國軍節度使。六年，奉詔使宋，傷足而跛，不告遂行，帝怒。及還，降同簽南京留守事，遙授靜江軍節度使，歷群牧都林牙，累遷右夷离畢，以才幹見任使。會車駕西征，元昊乞降，帝以前後反覆，遣滴洌往覘誠否，因為元昊陳述禍福，聽命乃還。拜北院」樞密副使，出為中京留守。十九年，改西京留守，卒。

蕭圖古辭
[
编辑
]

按《遼史蕭圖古辭傳》：「圖古辭，字何寧，楮特部人。仕重​熙中，以能稱，累遷左中丞。清寧初，歷北面林牙，改北院樞密副使。辨敏善伺顏色，應對合上意，知北院樞密使事。六年，出知黃龍府。八年，拜南府宰相。頃之，為北院樞密使，詔許便宜從事。為人姦佞有餘，好聚斂專愎，變更法度。為樞密數月，所薦引多為重元黨與」，
由是免為庶人。後沒入興聖宮，卒。

蕭阿剌
[
编辑
]

按《遼史蕭阿剌傳》：「阿剌字阿里懶，北院樞密使孝穆之子也。幼養宮中，興宗尤愛之。重熙六年，為弘義宮使，累遷同知北院樞密使，加同中書門下平章事，出為東宮留守。二十一年，拜西北路招討使，封西北郡王。尋尚秦晉國王公主，拜駙馬都尉。清寧元年，遺詔拜北府宰相，兼南院樞密使，進王韓。明年，改北院樞」密使，徙王陳，與蕭革同掌國政。革諂諛不法，阿剌爭
之不得，告歸。上由此惡之，除東京留守。會行瑟瑟禮，
入朝，陳時政得失。革以事中傷，帝怒，縊殺之。

蕭烏野
[
编辑
]

按《遼史蕭烏野傳》：「烏野，字草隱，其先出興聖宮分，觀察使塔里直之孫也。性孝悌，尚禮法，雅為鄉黨所稱。重熙中，補護衛。興宗見其勤恪，遷護衛太保。佐耶律仁先平重元亂，以功加團練使。時敵烈部數為鄰部侵擾，民多困弊，命烏野為敵烈部節度使，恤困窮，省徭役，不數月，部人以安。尋以母老，歸養于家。母亡，尢」極哀毀。服闋，歷官興聖、延慶二宮使，卒。

蕭朮哲
[
编辑
]

按《遼史蕭朮哲傳》：「朮哲，字石魯隱，孝穆弟高九之子。以戚屬加監門衛上將軍。重熙十三年，將衛兵討李元昊有功，遷興聖宮使。蒲奴里部長陶得里叛，朮哲為統軍都監，從都統耶律義先擊之，擒陶得里。朮哲與義先不協，誣義先罪，免官，稍遷西南面招討都監，坐事下獄，以太后言，杖而釋之。清寧初，為國舅詳穩」、
西北路招討使，私取官粟三百斛及代留畜產，令主
者鬻之以償。後族弟胡睹到部，發其事，帝怒，決以大
杖，免官。尋起為昭德軍節度使，徵為北院宣徽使。九
年，上以朮哲先為招討，威行諸部，復為西北路招討
使。訓士卒，增器械，省追呼，嚴號令，人不敢犯，邊境晏
然。十年，入朝，封柳城郡王。咸雍二年，拜北府宰相，為
北院樞密使耶律乙辛所忌，誣朮哲與護衛蕭忽古
等謀害乙辛。詔獄無狀，罷相，出鎮順義軍。卒，追王晉、
宋、梁三國。

蕭素颯
[
编辑

按《遼史蕭素颯傳》：「素颯，字特免，五院部人。重熙間始仕，累遷北院承旨、彰愍宮使。清寧初，歷左皮室詳穩、右夷离畢。咸雍五年，剖阿里部叛，素颯討降之，率其酋長來朝。帝嘉其功，徙北院材牙，改南院副部署，卒。」蕭迂魯
[
编辑
]

按《遼史蕭迂魯傳》：「迂魯，字胡突堇，五院部人。父約質，歷官節度使。迂魯，重熙間為牌印郎君。清寧九年，國家既平重元之亂，其黨郭九等亡，詔迂魯追捕，獲之，遷護衛太保。咸雍元年使宋，議邊事，稱旨，知殿前副點檢事。五年，阻卜叛，為行軍都監，擊敗之，俘獲甚眾。初，軍出止給五月糧，過期糧乏，士卒往往叛歸。迂魯」坐失計免官，降戍西北部。未行，會北部兵起，迂魯將
烏古敵烈兵擊敗之，每戰以身先，繇是釋前罪，命總
知烏古敵烈部。九年，拜左皮室詳穩。會宋求天池之
地，詔迂魯兼統兩皮室軍，屯太牢古山以備之。太康
初，阻卜叛，遷西北招討都監，從都統耶律趙三征討
有功。改南京統軍都監、黃皮室詳穩。未幾，遷東北路
統軍都監，卒。

蕭速撒
[
编辑
]

按《遼史蕭速撒傳》：「速撒字禿魯堇，突呂不部人。性沉毅，重熙間，累遷右護衛太保。蒲奴里叛，從耶律義先往討，執首亂陶得里以歸。清寧中，歷北面林牙、彰國軍節度使，入為北院樞密副使。咸雍十年，經略西南邊，撤宋堡障，戍以皮室軍。上嘉之。太康二年，知北院樞密使。耶律乙辛權寵方盛，附麗者多至通顯，速撒」未嘗造門，乙辛御之，誣構速撒首謀廢立。按之無驗，
出為上京留守。乙辛復令蕭訛都斡以前事誣告，上
怒，不復加訊，遣使殺之。乾統間，追封蘭陵郡王。

蕭胡睹
[
编辑
]

按《遼史蕭胡睹傳》：胡睹字乙辛，口吃，視斜髮鬈，伯父
孝穆見之曰：「是兒狀貌，族中未嘗有。」及壯，魁梧桀傲，
多揚人惡。重熙中，為祗候郎君，俄遷興聖宮使，尚秦
國長公主，授駙馬都尉。以不諧離婚，復尚齊國公主，
為北面林牙。清寧中，歷北南院樞密副使，西北路招
討使，同知北院樞密事，耶律乙辛知北院樞密事，胡
睹位在乙辛下，意怏怏不平。初，胡睹嘗與重元子涅
魯古謀逆，欲其速發。會車駕獵太子山，遂與涅魯古
脅弩手軍犯行宮。既戰，涅魯古中流矢而斃，胡睹被
創，單騎遁走，至十七濼，投水死，五子同日誅之。

===蕭迭里得===
​
按《遼史蕭迭里得傳》：「迭里得，字胡睹菫，國舅少父房之後。父雙古，尚鈿匿公主，仕至國舅詳穩。迭里得幼警敏不羈，好射獵，太平中，以外戚補祗候郎君，歷延昌宮使、殿前副點檢。重熙十三年，伐夏，迭里得多所俘掠，遷都點檢，改烏古敵烈部都詳穩。十八年，再舉西伐，失利，還復為都點檢。十九年，夏人來侵金肅軍」，
上遣迭里得率輕兵督戰，以功命知漢人行宮都部
署事。出為西南面招討使。族弟黃八家奴告其主私
議宮掖事，迭里得寢之。事覺，削爵為民。清寧中，起為
南京統軍使。至是，從重元子涅魯古等亂，敗走，被擒，
伏誅。

蕭余里也
[
编辑
]

按《遼史蕭余里也傳》：「余里也，字訛都碗，國舅阿剌次子。便佞滑稽，善女工。重熙間，以外戚進。清寧初，補祗候郎君，尚鄭國公主，拜駙馬都尉，累遷南面林牙。以父阿剌為蕭革所譖，出余里也。為奉先軍節度使。十年，召為北面林牙。咸雍中，出為寧遠軍節度使，乙辛薦為國舅詳穩。太康初，封遼西郡王。時乙辛擅恣，凡」不附己者出之，乃引余里也為北府宰相，兼知契丹
行宮都部署事。及乙辛謀構皇太子，余里也多助成
之，遂知北院樞密事，賜「推誠協贊功臣。」坐與乙辛黨，
以天平軍節度使歸第。尋拜西北路招討使。以母憂
去官，卒。

蕭巖壽
[
编辑
]

按《遼史蕭巖壽傳》：「巖壽，乙室部人。性剛直尚氣，仕重熙末，道宗即位，皇太后屢稱其賢，由是進用。上出獵較，巖壽典其事，未嘗高下于心，帝益重之。歷文班太保，同知樞密院事。咸雍十年，討敵烈部有功，為其部節度使。太康元年，同知南院宣徽使事，遷北面林牙。密奏乙辛有陰謀，上出乙辛為上京留守。會乙辛生」日，上遣近臣賜物為壽，乙辛因私屬白上，上反疑巖
壽，出為順義軍節度使。乙辛復入為樞密使，流巖壽
于烏隗路，終身拘作三年。乙辛誣巖壽與謀廢立事，
執還殺之，年四十九。乾統間，贈同中書門下平章事，
繪像宜福殿。巖壽廉直，面折廷諍，多與乙辛忤，故及
于難。

蕭兀納
[
编辑
]

按《遼史蕭兀納傳》：「兀納一名撻不也，字特免，六院部人。其先嘗為西南面拽剌。兀納魁偉簡重，善騎射。清寧初，兄圖獨以事入見，帝問族人可用者，圖獨以兀納對，補祗候郎君，遷近侍敞史、護衛太保。太康初，為北院宣徽使。時乙辛已害太子，因言宋魏國王和魯斡之子淳可為儲嗣。群臣莫敢言，唯兀納及夷离畢」蕭陶隗諫。五年，同知南院樞密使事，封蘭陵郡王，授
殿前都點檢，令輔導燕王。太安初，詔尚越國公主，兀
納固辭，改南院樞密使。壽隆元年，拜北府宰相。初，天
祚在潛邸，兀納數以直言忤旨。及嗣位，出為遼興軍
節度使，守太傅。以佛殿小底王華誣兀納借內府犀
角，天祚怒，奪太傅官，降寧邊州刺史。尋改臨海軍節
度使。天慶元年，知黃龍府事，改東北路統軍使。及金
兵來侵，戰于寧江州，其孫移《敵蹇》，死之。兀納退走入
城，留官屬守禦，自以三百騎渡混同江而西，城遂陷。
後與蕭敵里拒金兵于長濼，以軍敗免官。五年，授上
京留守。六年，耶律章奴叛，來攻京城，兀納以死拒戰，
以功授副元帥，尋為契丹都宮使。天祚以兀納先朝
重臣，有定策勳，每延問以政，兀納對甚切。上雖優容，
終不能用。以疾卒，年七十。

蕭得裏特
[
编辑
]

按《遼史蕭得裏特傳》：「得裏特，遙輦洼可汗宮分人，善阿意順色。清寧初，乙辛用事，甚見引用，累遷北面林牙、同知北院宣徽使事。及皇太子廢，遣得裏特監送上京，得裏特促其行，不令下車，起居飲食數加陵侮，至則築圜堵囚之。太康中，遷西南招討使，歷順義軍節度使，轉國舅詳穩。壽隆五年，坐怨望，以老免死，闔」門籍興聖宮，貶西北統軍司，卒。二子：得末、訛里，乾統
間，以父與乙辛謀伏誅。

蕭達魯古
[
编辑
]

按《遼史蕭達魯古傳》：「達魯古遙輦嘲古可汗宮分人，性姦險。清寧間，乙辛為樞密使，竊權用事，陰懷逆謀。達魯古比附之，遂見獎拔，稍遷至旗鼓拽剌詳穩。乙辛欲害太子，以達魯古兇果，可使為國舅詳穩。乾統間，詔樞密使耶律阿思大索乙辛黨人，達魯古以賂獲免，後以疾卒。」蕭阿魯帶
[
