《黃帝素問》

《金匱真言論》
[
编辑
]

北風生於冬，病在腎，俞在腰股。

〈註〉
俞者，經氣之所注也。

《五臟生成篇》
[
编辑
]

肝痹，得之寒濕，與疝同法，腰痛足清頭痛。

〈註〉
清濕地氣之中人也，必從足始。足厥陰之脈，從足上膕入毛中，過陰器，抵小腹，布脅肋，故病證與疝病相同，而腰痛足冷也。厥陰與督脈會於巔，故頭痛也。

《脈要精微論》
[
编辑
]

腰者腎之腑，轉搖不能。腎將憊矣。

〈註〉
兩腎在於腰內，故腰為腎之外腑。

腎脈搏堅而長，其色黃而赤者，當病折腰。

〈註〉
腰者腎之腑，腰傷故腎脈盛也。

推而上之，上而不下，腰足清也。

〈註〉
「上而不下」者，其氣上盛下虛，當主腰足清冷也。

「按之至骨脈氣少」者，腰脊痛而身有痹也。

《臟氣法時論》
[
编辑
]

心病者，「虛則脅下與腰相引而痛。」〈註〉
心氣不能下交於腎陰，故「脅下與腰相引而痛也。」《熱論》
[
编辑
]

傷寒一日，巨陽受之，故頭項腰脊強。

〈註〉
太陽之氣主皮毛。故傷寒一日。太陽受之。陽氣在上。故頭項痛。背為陽。故腰脊強。此言始病太陽之氣也。

《瘧論》
[
编辑
]

瘧之始發也，先起於毫毛，伸欠乃作，寒慄鼓頷，腰脊
俱痛。

〈註〉
衛氣同邪氣。將入於陰。表氣虛。故先起於毫毛伸欠。

巨陽虛，則腰背頭項痛。

〈註〉
太陽之氣。主表。而上升於頭。其經脈上會於腦。出於項。下循背膂。故腰背頭項俱痛。

邪中於腰脊者，氣至腰脊而病。

〈註〉
中於腰背。邪即舍於腰背之間。衛氣行至腰背。與腰背所舍之邪相遇。而病作焉。

《痿論》
[
编辑
]

腎氣熱，則腰脊不舉，骨枯而髓減，發為骨痿。

〈註〉
腎主藏精。腎氣熱。則精液燥竭矣。腰者腎之腑。是以腰脊不能伸舉。腎生骨髓。在體為骨。腎氣熱
​

而精液竭。則髓減骨枯。而發為骨痿也。

《厥論》
[
编辑
]

厥陰厥逆，攣腰痛。

〈註〉
攣者。肝主筋也。腰者肝之表也。

少陽厥逆，機關不利者，腰不可以行。

〈註〉
少陽主樞。是以少陽氣厥。而機關為之不利也。腰脊者。身之大關節也。故機關不利。而腰不可以轉行。

手太陽厥逆。腰不可以俛仰。

〈註〉
腰不可俛仰。蓋腰乃脈絡經俞之大會。

《病能論》
[
编辑
]

帝曰：「有病厥者，診右脈沉而緊，左脈浮而遲，不然病主安在？」岐伯曰：「冬診之，右脈固當沉緊，此應四時；左脈浮而遲，此逆四時。在左當主病在腎，頗關在肺，當腰痛也。」帝曰：「何以言之？」岐伯曰：「少陰脈貫腎絡肺，今得肺脈，腎為之病，故腎為腰痛之病也。」〈註〉
脈合四時，故冬診之左右脈皆當沉緊，今左脈浮而遲，是逆四時之氣矣。腎主冬氣，而又反浮在左，故當主病在腎，頗關涉於肺，當為腰痛之病，行奇恆之法。以太陰始五臟相通，移皆有次，是水穀所生之精氣，先至於手太陰，太陰肺金相生而順傳於腎，腎當復傳於肝。今反見浮遲之肺脈，是腎臟有病，而氣反還逆之於母臟。故當主腎病之腰痛。而頗關涉於肺也。

《脈解篇》
[
编辑
]

《太陽》所謂腫，腰脽痛者，正月太陽寅，寅，太陽也，正月
陽氣出，在上而陰氣盛，陽未得自次也，故腫腰脽痛
也。

〈註〉
此解奇病之脈也。「太陽為諸陽主氣，生於膀胱水中，故以太陽之氣為歲首。正月陽氣雖出於上，而陰寒之氣尚盛，陽氣未得次序而出，故太陽所謂腫，腰脽痛者，因太陽之氣尚為陰氣所鬱，故腫腰脽痛也。」此論陽氣之微也。

少陰所謂腰痛者，少陰者腎也，十月萬物陽氣皆傷，
故腰痛也。

〈註〉
十月寒水用事，故主於「足少陰腎。」《刺要論》
[
编辑
]

刺筋無傷骨，骨傷則內動腎，腎動則冬病脹腰痛。

〈註〉
動腎氣，則所藏者少，故當病虛脹而腰痛。腰乃腎之腑也。

《長刺節論》
[
编辑
]

病在少腹，腹痛，不得大小便，病名曰疝。得之寒，刺少
腹兩股間，刺腰踝骨間，刺而多之，盡《炅》病已。

〈註〉
少腹兩股及腰踝骨間，為厥陰肝脈之所循，刺而多留之，俟其盡熱，而病是已。

《氣交變大論》
[
编辑
]

歲水不及，濕乃大行，民病腰股痛發。

〈註〉
六辛之歲，水運不及，土乃勝之，故濕氣大行，傷及腎陰，故為腰股痛，發諸病。

歲火不及，寒乃大行，民病脅下與腰背相引而痛，甚
則屈不能伸，髖髀如別。

〈註〉
「六癸之歲，火運不及，水反勝之，故寒乃大行。」太陽乃氣之為病，故為腰背等病。

《五常政大論》
[
编辑
]

太陰司天，濕氣下臨，腎氣上從，當其時反腰脽痛，動
轉不便也。

〈註〉
當冬令之時。腎臟主氣。而反腰脽痛。動轉不便。蓋腎氣上從而大衰於下也。

《六元正紀大論》
[
编辑
]

太陰司天之政，氣化運行，後天終之氣，寒大舉，濕大
化。感於寒，則病人關節禁固，腰脽痛，寒濕推於氣交
而為疾也。

〈註〉
終之主，客乃在泉，寒水之氣，故寒大舉。寒濕之氣，上下相交，故濕大化，關節禁固，骨節不利也。腰脽者，腎之腑，寒濕推於氣交，而人在氣交之中也。

少陰司天之政，氣化運行先天，寒厥入胃，心痛腰痛
腹大。初之氣，民反周密，關節禁固，腰脽痛。

〈註〉
寒厥清病生於下也。入胃，心痛腰痛腹大，寒熱交爭於中而為病也。初之客氣，乃「太陽寒水；初之主氣，乃厥陰風木，故風乃至陽。」春之氣鬱，而民反周密。太陽主腎，而為腎之腑，故「關節禁固而腰脽痛也。」水鬱之發，民病寒客心痛，腰脽痛，大關節不利，屈伸
不便。

〈註〉
腰脽，腎之腑也。關節屈伸。乃筋骨之病。腎主骨。而筋屬於節也。

太陽所至為腰痛。

〈註〉
此夏病之常也。

《至真要大論》
[
编辑
]

歲太陰在泉，民病衝頭痛，目似脫，項似拔，腰似折，髀
不可以曲，膕如結，腨如別
​

〈註〉
「太陰在泉，辰戌歲也。自衝頭痛，至腨如別」，乃土氣淫勝，而水臟水腑皆為病也。

歲太陽在泉，寒淫所勝，民病少腹控睪，引腰脊，上衝
心痛。

〈註〉
《太陽在泉》，丑未歲也。太陽之脈，挾脊抵腰中，故引腰脊。腎脈絡心，故上衝心痛。

太陰司天，濕淫所勝，胕腫骨痛。陰痹者，按之不得，腰
脊頭項痛，病本於腎。太谿絕，死不治。

〈註〉
「太陰司天，丑未歲也。」胕腫陰痹，皆感寒濕之氣。病在陰者，名曰「痹。」腎主骨，而膀胱為之腑，故腰脊頭項骨痛。太谿，腎之動脈，在足內踝外踝骨上。太谿脈不至，則腎氣已絕，故死不治。

陽明司天，燥淫所勝，民病嗌乾，面塵腰痛，病本於肝。
太衝絕，死不治。

〈註〉
「陽明司天，卯酉歲也。」嗌乾，面塵腰痛，皆肝經之病。蓋金淫於上，故病本於肝。太衝在足大指本節後二寸，動脈應手，肝經之俞穴也。肝氣已絕，故死不治。

太陰之勝，火氣內鬱，燥化乃見，少腹滿，腰脽重強。

〈註〉
「腰脽重」者，濕氣下淫，而不及於腎也。

太陽之復，厥氣上行，腰脽反痛，屈伸不便，少腹控睪，
引腰脊，上衝心。

〈註〉
腰脽反痛。屈伸不利。水淫而反自傷也。少腹控睪。引腰脊上衝心者。厥陰病也。蓋亦報復歲半以前之木火土也。

厥陰在泉，主勝則腰腹時痛。

〈註〉
腰腹時痛者，乃在泉之主氣，太陰陽明太陽三氣之為病也。

少陰在泉，客勝則腰痛。

〈註〉
四之客氣，乃太陽寒水；腰痛乃太陽經證，同氣相感也。

少陽在泉，客勝，則腰腹痛而反惡寒。

〈註〉
腰腹痛而反惡寒者，客勝而太陽之主氣乃病也。

陽明在泉，主勝則腰重腹痛。

〈註〉
腰重腹痛，太陽寒水之氣，發於下也。

太陽在泉，寒復內餘，則腰尻痛，屈伸不利，股脛足膝
中痛。

〈註〉
「寒復內餘」者，太陽寒水之客氣，入於內而有餘也。腰尻股脛足痛者，太陽之經證也；屈伸不利者，太陽之主筋也。

《靈樞經》
[

《邪氣臟腑病形篇》
[
编辑
]

肺脈微急，為肺寒熱，怠惰欬，唾血，引腰背胸。

〈註〉
肺主氣，怠惰欬唾血，引腰背胸，皆肺氣虛寒之所致。

小腸病者，腰脊控睪而痛。

〈註〉
《小腸病》者，謂病小腸之腑氣也。其氣與膀胱相通，是以腰脊控睪而痛。

《本神篇》
[
编辑
]

腎盛，怒而不止則傷志，志傷則喜忘其前言，腰脊不
可以俛仰屈伸。

〈註〉
腰者腎之腑，腎藏志，今志傷，故腰脊不可以俛仰屈伸。

《終始篇》
[
编辑
]

從腰以上者。手太陰陽明皆主之。從腰以下者，足太
陰陽明皆主之。

〈註〉
手太陰陽明主天，足太陰陽明主地。身半以上為天，身半以下為地。

病在腰者。取之膕。

〈註〉
腎臟膀胱之水氣，應天泉之上下也。

《經脈篇》
[
编辑
]

膀胱足太陽之脈。其直者從巔入絡腦。挾脊抵腰中。
其支者從腰中下挾脊貫臀。是動則病脊痛腰似折。

〈註〉
此病在太陽之氣也。

肝足厥陰之脈，是動則為腰痛，不可以俛仰。

〈註〉
是在厥陰之動氣。則病腰痛不可以俛仰。蓋厥陰從少陽中氣之化。厥陰之化氣病也。

《經筋篇》
[
编辑
]

足少陰之筋病。在外者不能俛。在內者不能仰。故陽
病者。腰反折不能俛。陰病者不能仰。

〈註〉
病在外在陽者，病太陽之氣，故腰反折不能俛；在內在陰者，病少陰之氣，故不能仰。

《脹論》
[
编辑
]

腎脹者，腹滿引背，央央然腰髀痛。小腸脹者，少腹䐜
脹，引腰而痛。

〈註〉
此衛氣逆於城郭之中，而為臟腑之脹也。

《五癃津液別篇》
[
编辑
]

陰陽不和。則使液溢而下流於陰。髓液皆減而下。下
過度則虛，虛故腰背痛而脛痠。

〈註〉
陰陽不和者。少陰與陽明之不和也。陰陽之氣
​

「不和則液與精不合，故使液溢於骨外而下流於陰」 矣。液溢於外，則髓液皆減而下，是不能為高矣。下流過度，則骨虛而腰痛脛痠矣，此髓道之閉癃也。

《陰陽繫日月篇》
[
编辑
]

「腰以上為天，腰以下為地」，故「天為陽，地為陰。」〈註〉
積陽為天，積陰為地，天地合氣，命之曰「人。」故身半以上，天氣主之；身半以下，地氣主之。人秉天地水火而生，故與天地參也。

腰以上者為陽，腰以下者為陰。

〈註〉
此陰陽之定位。手經有陰。足經有陽。乃上下之氣交。

《本臟篇》
[
编辑
]

腎小則臟安難傷；腎大則善病腰痛，不可以俛仰，易
傷以邪。腎下則腰尻痛，不可以俛仰，為狐疝。腎堅則
不病腰背痛；腎偏傾則苦腰尻痛也。

〈註〉
腰脊者，身之大關節也。故腰痛、背膂痛、腰尻痛，皆不可以俛仰。腎附於腰脊間，故病諸痛也。

《百病始生篇》
[

以欲竭其精，以耗散其真，則腎臟虛傷，膀胱之腑安
能獨足，於是六氣乘虛侵犯太陽，故分別施治。有寒、
有濕、有風熱、有挫閃、有瘀血、有滯氣、有痰積，皆標也，
腎虛其本也。標急則從標，本重則從本，標本不失，病
無遁狀矣。

濕熱
[
编辑
]

久處卑濕，雨露侵淫，為濕所著，腰重如石，冷如冰，喜

實者，二炒蒼蘗散，加柴胡、防風煎服。虛者，七味蒼蘗
散。溺赤者，五苓散、清燥湯、健步丸。有諸藥不效者，用
甘遂、牽牛大瀉其濕而止，乃濕熱甚也。古方有以甘
遂末三錢，和猪腰子煨熟，空心酒下。
