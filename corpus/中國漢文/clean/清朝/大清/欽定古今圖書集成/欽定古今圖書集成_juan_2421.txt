職方典第三百五卷

太原府部藝文二
〈詩詞〉
[
编辑

《從駕幸晉陽應詔》
隋·薛道衡
[
编辑
]

省方遵往冊，遊豫葉前經。金吾朝戒道，校尉晚巡營。
重巒下飛騎，絕浦渡連旌。澗水寒逾咽，松風遠更清。
方觀翠華反，簪筆上芸亭。

《汾上警秋》
唐·蘇頲
[
编辑
]

北風吹白雲，萬里渡河汾。心緒逢搖落，秋聲不可聞。

《經行嵐州》
杜審言
[
编辑
]

「北地春光晚，邊城氣候寒。往來花不發，新舊雪忘殘。」水作琴中聽，山疑畫裏看。日驚牽遠役，艱險促征鞍。

《長城梁》
王翰
[
编辑
]

長安少年無遠圖，一生惟羨執金吾。麒麟殿前拜天
子，走馬為君西擊胡。胡沙獵獵吹人面，漢虜相逢不
相見。遙聞鉦鼓動地來，傳道單于夜猶戰。此時顧恩
寧顧身，為君一行摧萬人。壯士揮戈迴白日，單于濺
血汙朱輪。歸來飲馬長城窟，長城道旁多白骨。問之
耆老何代人，云是秦王坑趙卒。黃昏塞北無人煙，鬼
​
「哭啾啾聲沸天。無罪見誅功不賞，孤魂流落此城邊。」當昔秦王按劍起諸侯，膝行不敢視。富國強兵二十
年，築怨聲冤九千里。秦王築城何太愚，天實亡秦非
北胡。一朝禍起蕭牆內，渭水咸陽不復都。

《鴈門胡人歌》
崔灝
[
编辑
]

高山代郡東接燕，鴈門胡人家近邊。解放胡鷹逐塞
鳥，能將代馬獵秋田。山頭野火寒多燒，露裏孤峰濕
作煙。聞道遼西無𩰚戰，時時醉向酒家眠。

《塞上曲》
常建
[
编辑
]

翩翩雲中使，來問太原卒。百戰苦不歸，刀頭怨秋水。
塞雲隨陣落，寒日傍城沒。城下有寡妻，哀哀哭枯骨。

《太原早秋》
李白
[
编辑
]

歲落眾芳歇，時當大火流。霜威出塞早，雲色渡河秋。
夢遶邊城月，心飛故國樓。思歸若汾水，無日不悠悠。

《送人之嵐州》
前人
[
编辑
]

塞魯乘秋下，天兵出漢家。將軍分虎竹，戰士臥龍沙。
邊月隨弓影，胡霜拂劎花。玉關殊未入，少婦莫長嗟。

《過宋員外之問舊莊》
杜甫
[
编辑
]

宋公舊池館，零落首陽阿。枉道祗從入，吟詩許更過。
淹留問父老，寂寞向山河。更識將軍樹，悲風日暮多。

《使至塞》
王維
[
编辑
]

單車欲問邊，屬國過居延。征蓬出漢塞，歸鴈入胡天。
大漠孤煙直，長河落日圓。蕭關逢候吏，都護在燕然。

《送都督赴代州》
前人
[
编辑
]

天官動將星。漢地柳條青。萬里鳴刁斗。三軍出井陘。
忘身辭鳳闕。報國取龍庭。豈學書生輩。窗間著一經。

《冀北春望》
崔湜
[
编辑
]

迴首覽燕趙，春生兩河間。曠然萬餘里，際海不見山。
雨歇青林潤，煙空綠野閑。問鄉何處所，目送白雲還。

《塞下曲》
李頎
[
编辑
]

黃雲鴈門郡，日暮風沙裏。千騎黑貂裘，皆稱《羽林子》。
金笳吹朔雪，鐵馬嘶雲水。帳下餘蒲萄，平生寸心是。

《駕幸河東》
王昌齡
[
编辑
]

晉水千廬合，汾橋萬國從。開唐天業盛，入沛聖恩濃。
下輦回三象，題碑駐六龍。睿明懸日月，千載此時逢。

《寶賢堂》
李頻
[
编辑
]

遊訪曾經駐馬看，竇犨遺像在林巒。泉分石洞千條
碧，人在冰壺六月寒。時雨欲來騰霧靄，微風初動漾
波瀾。箇中若置羊裘叟，絕勝當年「七里灘。」《送邊將之鴈門》
前人
[
编辑
]

防秋戎馬恐來奔，詔發將軍出鴈門。遙領短兵登隴
首，獨橫長劍向河源。旌旗落日黃雲動，鼓角陰風白
草翻。若使干戈更深入，應聞收捷到《崑崙》。

《奉和聖製早登太行山中言志》
苖發
[
编辑
]

金吾戒道清，羽騎動天聲。砥路方南紀，重巖始北征。
關樓前望遠，河邑下觀平。喜氣迴輿合，祥風入斾輕。
祝堯三老至，會禹百神迎。月令農先急，春蒐禮後行。
仍親后土祭，更理晉陽兵。不以勞車轍，空留八駿名。

《晚秋東遊寄氏第五明府解縣韓明府》
[
编辑
]

耿湋

步出青門去，疏鐘隔上林。四郊多難日，千里獨歸心。
暮鳥聲偏苦，秋雲色易陰。亂墳松柏少，野徑草茅深。
霸涘袁安履，汾南宓賤琴。何由聽《白雪》，祗益淚沾襟。

《太原送許侍御出幕歸東都》
前人
[
编辑
]

昔隨劉越石，今日獨歸時。汾水風煙合，并州花木遲。
荒庭增別夢，野雨失行期。莫向山陽過，鄰人夜笛悲。

《邊行書事》
李昌符
[
编辑
]

朔夜煙塵起，天軍又舉戈。陰風向晚急，殺氣入秋多。
樹盡禽棲草，冰堅路在河。《汾陽》無繼者，羌虜肯先和。

《送林明府歸榆次》
韋應物
[
编辑
]

「無嗟千里遠，亦是宰王畿。」策馬雨中去，逢人關外稀。
邑傳榆石在，路繞晉山微。別意方蕭瑟，新秋一葉飛。

《送裴相公上太原》
王建
[
编辑
]

還攜堂印向并州，將相兼權是武侯。時難獨當天下
事，功成卻進手中籌。再三陳乞罏煙裏，前後分張玉
案頭。朱架早朝排立戟，綠槐殘雨看張油。遙知鴈塞
從今好，直到漁陽以北愁。《邊鋪》恐巡旂盡換，山城欲
過館重修。千群白刃兵迎節，十對紅粧妓打毬。聖主
分明教暫去，不須高起見京樓。

《夕次壽陽驛》
韓愈
[
编辑
]

風光欲動別長安，及到邊城特地寒。不見園花兼陌
柳，馬頭惟有月初團。

《渡桑乾河》
賈島
[
编辑
]

客舍并州已十霜，歸心日夜憶《咸陽》。無端更渡桑乾
水，卻望并州是故鄉。

《留題南趙古廟》
前人
[
编辑
]

鱗皴老樹鐵生斑，神宇荒涼野壑閒。地僻無人秋寂
寂，一川紅影夕陽間。

《送鮑中丞赴太原》
盧綸
[
编辑
]

分路引鳴騶，喧喧似隴頭。暫移西掖望，全解北門憂。

拜命臨都護，分曹制督郵。積冰營不下，盛雪獵方休
​
白草連胡帳，黃金擁戍樓。今朝送旌斾，一減魯儒羞。

《過故關》
宋·韓琦
[
编辑
]

春日并州路，群芳夾故關。前騶驅弩過，別境荷戈還。
古戍遺殘堞，新耕入亂山。時平民自適，白首樂農間。

《行代因話江山》
范仲淹
[
编辑
]

數年風上塞門行，說著江山意暫清。求取罷兵南北
去，滿樓蒼翠足平生。

《題岢嵐軍雲際寺》
邵雍
[
编辑
]

煙嵐一簇峙崔嵬，到此令人心自灰。上有神仙無姓
氏，洞門閑倚白雲開。

《黃河》
歐陽修
[
编辑
]

河水激箭險，誰言航葦遊。堅冰馳馬渡，伏浪捲沙流。
樹落新摧岸，湍驚忽改洲。鑿龍時退鯉，漲潦不分牛。
萬里通槎漢，千帆下漕舟。怨歌今罷築，故道失難求。
灘急風逾響，川寒霧不收。詎能窮禹跡，空欲問張侯。

《感興神堯起兵太原》
朱熹
[
编辑
]

晉陽啟唐祚，王名紹巢封。垂統已如此，繼體宜昏風。
麀聚瀆天倫，牝晨司禍凶。乾綱一以墜，天樞復崇祟。
淫毒穢宸極，虐焰燔蒼穹。向非狄張輩，誰辦取日功。
云何歐陽子，秉筆迷至公。唐經亂周紀，凡例孰此容。
侃侃范太史，受說伊川翁。《春秋》二三策，萬古開群蒙。

《代州書事》
金·趙秉文
[
编辑
]

金波曾醉鴈門州，端有人間六月秋。萬古山河雄朔
部，四時風月入南樓。漢家戰伐雲千里，唐季英雄土
一丘。繫馬朱欄重回首，煙波誰在釣魚舟？

《過鴈門關》
元·好問
[
编辑
]

四海於今正一家，生民何處不桑麻。重關獨據千尋
嶺，深夏猶飛六出花。雲暗白楊連馬邑，天低青塚渺
龍沙。憑高弔古情無盡，空對西風數去鴉。

《石嶺關書所見》
前人
[
编辑
]

軋軋輈車轉石槽，故關猶復戍弓刀。連營突騎紅塵
暗，微服行人細路高。己化蟲沙休自歎，厭逢虎豹欲
安逃。青雲玉立三千丈，元只東山意氣豪。

《讀書山居六首》
前人
[
编辑
]

「瘦竹藤斜挂，藂花草亂生。林高風有態，苔滑水無聲。石潤雲先動，橋平水漸過。」「野陰添晚重，山意向秋多。樹合秋聲滿，村荒暮景閒。虹收仍白雨，雲動忽青山。川迥楓林散，山深竹港幽。疏煙沈去鳥，落日送歸牛。漲落沙痕出，堤摧岸口斜。斷橋堆聚沫，高閣樹浮槎。鷺影兼秋靜，蟬聲帶晚涼。陂長留積水，川闊盡斜陽。」《馬嶺》
前人
[
编辑
]

「仙人臺高鶴飛度，錦繡堂傾去無路。人言馬嶺差可行，此似黃榆猶坦步。」石門木落風颼颼，僕夫衣單望
南州。皋落東南三百里，鬢毛衰颯兩年秋。

《過鴈門見鴈》
黃庭筠
[
编辑
]

家在孤雲落照間，行人已上鴈門關。憑君為報平安
信，纔是雲中第一山。

《龍安》
元·王構
[
编辑

《下馬龍安寨》，仙人五字詩。「白雲君去後，翠巘我來時。異代怳神遇，百年勞夢思。山陰已陳跡，俯仰重嗟咨。」《石馬寺》
前人
[
编辑
]

碧水孤村靜，高臺古寺陰。僧談傳石馬，客至聽山禽。
杯動疏松影，笳吹空谷音。夕陽城市路，回首隔叢林。

《淤泥寺》
前人
[
编辑
]

野寺消煩暑，長途促晚行。落霞明遠岫，返照下孤城。
月傍前村出，風從古渡生。僕夫毋乃倦，於此亦關情。

《晉溪》
小倉月僧
[
编辑
]

削桐宮殿古溪泉，寰海聲高利濟全。曉日僧鐘雲外
寺，晚山漁笛浪頭船。三秋白鴈蘆花雪，二月金鶯楊
柳煙。野老石橋驢背上，人家村落錦屏前。

《過盤陀鎮》
明·于謙
[
编辑
]

「群峰行盡是盤陀，小徑紆迴亂石多。風約閒雲難作雨，渠分流水不成河。」門開野店群雞唱，花發春山百
鳥歌。一段好懷無處著，令人對景費吟哦。

《石門煙雨》
李崇義
[
编辑
]

「不見石門山，長臥西陵病。不作石門遊，徒懷石門景。」雙壁下層霄，中央作門屏。風和景明時，萬里雲霄淨。
一朝煙雨晨，更覺湖山勝。煙橫十里洲，雨浥三川溟。
寒霏裊如絲，漠漠群峰映。甘霖湧如注，滂沱沛千頃。
白鷺過平沙，孤鴈沒雲嶺。夷歌速歸期，樵牧時相應。
桃李亦蕭疏，松楸更悽耿。茫茫青草湖，晻藹汀洲並。
濛濛綠楊岸，渙若瀟湘境。蒹葭半江秋，離披暗疏影。
