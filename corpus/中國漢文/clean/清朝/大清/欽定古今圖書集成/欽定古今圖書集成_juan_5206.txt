張道源
[
编辑
]

按《唐書張道源傳》：「道源，并州祁人，名河，以字顯。年十四，居父喪，士人賢其孝，縣令郭湛署所居曰復禮鄉至孝里。道源嘗與客夜宿，客暴死，道源恐主人匆怖，臥尸側，至曙乃告，又徒步護送還其家。隋末政亂，辭監察御史，歸閭里。高祖興，署大將軍府戶曹參軍，至賈胡堡，復使守并州。京師平，遣撫慰山東，下燕趙，有」詔褒美，封累范陽郡公。淮安王神通略定山東，令守
趙州，為竇建德所執。會建德寇河南間，遣人詣朝，請
乘虛擣賊心脅，即詔諸將率兵應接。俄而賊平，還拜
大理卿。時何稠得罪，籍其家屬，賜群臣。道源曰：「禍福何常，安可利人之亡，取其子女自奉，仁者不為也。」更
資以衣食遣之。天子見其年耆，拜綿州刺史。卒，贈工
部尚書，諡曰「節。」張長遜
[
编辑
]

按《唐書張長遜傳》，「長遜，京兆櫟陽人，精馳射。在隋為里長，以平陳功擢上開府，累遷五原郡通守。遭亂，附突厥，突厥號為割利特勒。義兵起，以郡降，即拜五原太守、安化郡公，徙封范陽。時梁師都、薛舉請突厥兵南渡河，長遜矯作詔，與莫賀咄設以伐其謀。武德元年，詔高世靜聘始畢可汗，至豐州而始畢死，詔留金」幣不遣。突厥怒，引兵南至河。長遜遣世靜出塞勞之，
且若專致賻賜者。突厥引還，授總管，改楊國公。入朝，
授右武候將軍，徙息國公。後歷遂、夔二總管，政以惠
稱。貞觀十一年卒。

張善相
[
编辑
]

按《唐書李育德傳》：「張善相，襄城人。大業末，為里長，督兵跡盜，為眾附賴，乃據許州奉李密。密敗，挈州以來，詔即授伊州總管。王世充攻之，屢困賊，遣使三輩請救，朝廷未暇也。會糧盡，眾餓死，善相謂僚屬曰：『吾為唐臣，當效命，君等無死，斬吾首以下賊可也』。眾泣不肯，曰：『與公同死，愈於獨生』！城陷被執，罵賊見殺。高祖」歎曰：「吾負善相，善相不負我。」乃封其子襄城郡公。

張志寬
[
编辑
]

按《唐書張志寬傳》：志寬，蒲州安邑人。居父喪而毀，州
里稱之。王君廓兵略地，不暴其閭，倚全者百許姓後
為里正，忽詣縣稱母疾，求急，令問狀，對曰：「母有疾，志寬輒病，是以知之。」令謂其妄，繫於獄。馳驗如言，乃慰
遣之。母終，負土成墳，手蒔松柏。高祖遣使就弔，拜員
外散騎常侍，賜物四十段，表其閭。

張平高
[
编辑
]

按《唐書張平高傳》：「平高，綏州人。為隋鷹揚府校尉，戍​太原，遂預謀議，從唐公平京城，累授左領軍將軍，封蕭國公。貞觀初，為丹州刺史。坐事以右光祿大夫還第，卒追封羅國，贈潭州都督。」張善安
[
编辑
]

按《唐書張善安傳》：「善安，兗州方與人。年十七，亡命為盜，轉掠淮南。會孟讓敗，得其散卒八百，襲破廬江郡，依林士弘，不見信，憾之，反襲士弘，焚其郛，去保南康。蕭銑取豫章，遣將蘇胡兒守之，善安奪其地，據以歸國，授洪州總管。武德六年，反，輔公祏，以為西南道大行臺。善安掠孫州，執總管王戎，襲殺黃州總管周法」明，會李大亮兵至，為開曉禍福，答曰：「善安初不反，為部下詿誤降。今易耳，恐不免，奈何？」大亮曰：「總管定降，吾固不疑。」因獨入其陣，與善安握手語，乃大喜，將數
十騎詣大亮營。大亮引入，命壯士執之。其騎皆驚，引
去，悉兵來戰。大亮諭以善安自歸，無庸鬥。其黨罵曰：
「總管賣我。」遂潰，送善安京師，稱不與「公祏謀」，高祖赦
之。公祏破，得其書，遂伏誅。

張允濟
[
编辑
]

按《唐書張允濟傳》：「允濟，青州北海人。仕隋為武陽令，以愛利為行。元武，民以牸牛依婦家者久之，孳十餘犢，將歸而婦家不與牛。民訴縣，縣不能決，乃詣允濟，允濟曰：『若自有令，吾何與焉』？民泣訴其抑，允濟因令左右縛民蒙其首，過婦家，云：捕盜牛者命盡出民家牛質所來。婦家不知，遽曰：『此婿家牛，我無豫』。即遣左」右撤蒙曰：「可以此牛還婿。」婦家叩頭服罪，元武吏大
慚。允濟過道旁，有姥廬守所蒔蔥，因教曰：「第還舍，脫有盜，當告令。」姥謝歸。俄大亡蔥，允濟召十里內男婦
盡至，物色驗之，果得盜者。有行人夜發遺袍道中，行
十餘里乃寤，人曰：「吾境未嘗拾遺，可還取之。」既而得
袍。舉政尢異，遷高陽郡丞。郡缺太守，獨統郡事，吏下
畏悅。賊帥王須拔攻郡，於是糧缺吏食，槐葉槁節，無
叛者。貞觀初，累遷刑部侍郎，封武城縣男。擢幽州刺
史，卒。

張公謹
[
编辑
]

按《唐書張公謹傳》：「公謹字弘慎，魏州繁水人。為王世充洧州長史，挈城歸天子，授檢校鄒州別駕，累遷右武候長史，未知名。李勣、尉遲敬德數啟秦王，乃引入府。王將討隱巢亂，使卜人占之，公謹自外至，投龜於地曰：『今事無疑，何卜之為』？隱太子死，其徒攻元武門，銳甚，公謹獨閉關拒之，以功授左武候將軍，封定遠」郡公。貞觀初，為代州都督，置屯田以省餽運，數言時
政得失。後副李靖經略突厥，條可取狀於帝，帝然所
謀。及破定襄，敗頡利，璽詔慰勞，進封鄒國公，改襄州
都督。卒官，諡曰襄。十三年，追改郯國公。

張行成
[
编辑
]

按《唐書張行成傳》：「行成，字德立，定州義豐人。少師事劉炫，炫謂門人曰：『行成體局方正，廊廟材也』。」隋大業
末，察孝廉，為謁者臺散從員外郎，後為王世充度支
尚書。世充平，以隋資補穀熟尉。家貧，代計吏集京師，
擢制舉乙科，改陳倉尉，調富平主簿，有能名，召補殿
中侍御史，紏劾嚴正，太宗以為能。嘗侍宴，帝語山東
及關中人意有同異，行成曰：「天子四海為家，不容以東西為限。」帝稱善。自是有大政事令與議焉。累遷給
事中。帝嘗謂群臣：「朕為人主，兼行將相事。」行成曰：「奚用損萬乘之尊，與臣下爭功？」帝嘉納之。轉刑部侍郎、
太子少詹事。太子駐定州監國，謂曰：「吾乃送公衣錦還鄉邪？」令有司祠其先墓。帝幸靈州，詔皇太子從，行
成諫曰：「皇太子宜留監國。」帝以為忠。遷侍中。高宗即
位，封北平縣公，監修國史。俄拜尚書左僕射、太子少
傅。永徽四年，自三月不雨至五月，行成懼，以老乞身。
帝曰：「公，朕之舊，奈何舍朕去邪！」泫然流涕。行成不得
已，復視事。未幾，卒於尚書省舍，年六十七，諡曰定。

張大師

编辑

按《唐書張儉傳》：「儉兄大師，太僕卿，華州刺史，武功縣男。」張儉
[
编辑
]

按《唐書張儉傳》：「儉字師約，京兆新豐人。隋相州刺史、皖城郡公威孫。父植，車騎將軍、連城縣公。儉，高祖從外孫也。高祖起，儉以功除右衛郎將、朔州刺史。李靖既平突厥，有思結部者，窮歸於儉，儉受而安輯之。其在磧北者，親戚私相過省，儉不禁，示羈縻而已。儉徙勝州，後將不察其然，遽奏思結叛，朝廷議進討，時儉」以母喪奪服為使者，撫納之。儉單騎入其部，召酋帥
慰諭，推腹心咸匍匐歸命，因舉徙代州，遂檢校代州
都督，遷營州。高麗引眾入寇，儉率兵破之，俘斬略盡。
太宗征遼東，拜行軍總管，使領諸蕃騎，為六軍前鋒。
儉進度遼，趨建安城破賊。累封皖城郡公。永徽初，加
金紫光祿大夫。卒，諡曰「密。」張延師
[
编辑
]

按《唐書張儉傳》：「儉弟延師，左衛大將軍、范陽郡公，性謹畏，典羽林兵三十年，未嘗有過。卒贈荊州都督，諡​曰敬，陪葬昭陵。」張士貴
[
编辑
]

按《唐書張士貴傳》：「士貴，虢州盧氏人。本名忽峍。彎弓百五十斤，左右射無空發。隋大業末，起為盜，攻剽城邑，當時患之，號忽峍賊。高祖移檄招之，士貴即降，拜右光祿大夫。從征伐有功，賜爵新野縣公。又從平洛，授虢州刺史。帝曰：『顧令卿衣錦晝遊耳』。進封虢國公，右屯衛大將軍。貞觀七年，為龔州道行軍總管，破反」獠還，累遷左領軍大將軍。顯慶初卒，陪葬昭陵。

張懷約
[
编辑
]

按《尚友錄》：懷約，建昌人。初仕隋，官至學士，後歸唐，以
為溫州司馬。懷約幼有令名，鄉人宗其德行。尢博學
強記，文祠典麗，講《三禮》，三傳，出諸儒之右，性尚簡雅。
後隱於富陽山，莫知所終。

張進
[
编辑
]

按《萬姓統譜》：「進，饒陽人，少負奇質，有膽氣。唐初與饒陽太守諸葛德威合謀擒劉黑闥，以功授開府儀同三司，賜廄馬五十匹，黃金百萬。」張鎮周
[
编辑
]

按《尚友錄》：鎮周，舒州人。初為壽州都督。武德中，遷本
州都督。到州，就故宅多市酒殽，召親戚與之酣宴，如
為布衣時，凡十日。既而分贈金帛，泣與之別，曰：「今日張鎮周猶得與故人歡飲，明日之後，則舒州都督治百姓耳，官民禮隔，不復得為交遊。」自是親戚故人犯
法，一無所縱，境內肅然。

張亮
[
编辑
]

按《唐書張亮傳》：「亮，鄭州滎陽人。起畎畝，志趣奇譎，外敦厚而內不情。隋大業末，李密略地滎汴，亮從之，署驃騎將軍，隸李勣。勣以黎陽歸，頗佐佑之。擢鄭州刺史。房元齡以亮沉果有謀，白秦王，引為車騎將軍。王即位，除右衛將軍，封長平郡公，累遷御史大夫，進爵鄅國公，歷豳夏鄜三州都督，相州長史，徙鄖國，召拜」工部尚書、太子詹事，出為洛州都督。侯君集已誅，以
刑部尚書參豫朝政。帝將伐高麗，亮頻諫不納，因自
請行，進至建安，營壁未立。賊奄至，亮不知所為，踞胡
床直視，無所言，眾謂其勇，得自安。於是副將張金樹
鼓於軍士奮擊，因破賊。及從帝還至并州，乃得罪。初，
亮為相州，假子公孫節以讖有「弓長之主」，當別都，亮
自以相舊都，弓長其姓，陰有怪謀。會陝人常德發其
謀，并言亮養假子五百。帝使馬周案之，斬西市，籍其
家。

張元素
[
编辑
]

按《唐書張元素傳》：「元素，蒲州虞鄉人，仕隋為景城縣戶曹。竇建德陷景城，將殺之，邑人千餘號泣請代曰：『此清吏，殺之是無天也。大王即定天下，無使善人解體』。建德命釋縛，署治書侍御史，不拜。聞江都已弒，始為建德黃門侍郎。賊平，授景州錄事參軍。太宗即位，問以政，對曰：『自古未有如隋亂者。陛下跡所以危，鑒所以亡，日慎一日，雖堯舜何以加』？」帝曰：「善。」拜侍御史，
遷給事中。貞觀四年，詔發卒治洛陽宮乾陽殿，且東
幸。元素上書，帝即詔罷役。魏徵嘆曰：「張公論事有回天之力，可謂仁人之言哉！」歷太子少詹事，遷右庶子。
時太子承乾事游畋，不悅學，元素上書不納。又上書，
帝知，數裁正太子。頻擢至銀青光祿大夫，行左庶子。
太子久不見賓友，元素曰：「宮中所見止婦人，不知如樊姬等可與益聖德者幾何？」太子諱其切，夜遣戶奴
以騎檛狙擊，危脫死。嘗聞宮中擊鼓叩閣，正言，太子
出鼓，對元素破之。既不悛，醜德日聞，元素不能已，上
書。書入，太子怒，遣刺客伺之。會宮廢，元素坐除名為
民。頃之，召授潮州刺史，徙鄧州，訖不復親近。高宗時，
以老致仕。麟德初卒。

張昌宗
[
编辑
]

按《唐書張昌齡傳》，「昌齡兄昌宗，官至太子舍人、修文館學士，撰《古文紀年新傳》數十篇。」張昌齡
[
编辑
]

按《唐書張昌齡傳》：昌齡，冀州南宮人，與兄昌宗皆以
文自名，州欲舉秀才，昌齡以科廢久，固讓。更舉進士，
與王公治齊名，皆為考功員外郎王師旦所絀。太宗
問其故，答曰：「昌齡等華而少實，其文浮靡，非令器也。取之則後生勸慕，亂陛下風雅。」帝然之。貞觀末，翠微
宮成，獻頌闕下，召見，試息兵詔少選成文帝大悅，戒
之曰：「昔彌衡、潘岳矜己傲物，不得死。卿才不減二人，宜鑒于前，副朕所求。」乃敕于通事舍人裏供奉。俄為

行，后詔舉外司可為相者，崇曰：「張柬之沉厚有謀，能斷大事，其人老，惟亟用之。」即日召見，拜同鳳閣鸞臺
平章事，進鳳閣侍郎。誅二張也，柬之首發其謀，以功
擢天官尚書、同鳳閣鸞臺三品、漢陽郡公。不半歲，以
漢陽郡王加特進，罷政事。柬之既失權，願還襄州養
疾，乃授襄州刺史。懇辭王爵，不許。俄及貶，又流瀧州。
憂憤卒，年八十二。景雲元年，贈中書令，諡曰文貞。柬
之剛直不傅會，然邃于學，論次書數十篇。

===張仁愿===
​
按《唐書張仁愿傳》：「仁愿，華州下邽人。本名仁亶，以睿宗諱音近避之。有文武材。武后時累遷殿中侍御史。萬歲通天中，孫承景監清邊軍，戰還，自圖先鋒當矢石狀，擢為右肅政臺中丞。仁愿劾奏承景罔上，貶崇仁令，以仁愿代為中丞，檢校幽州都督。默啜寇趙、定，還出塞，仁愿以兵邀之，賊引去。遷并州都督長史。神」龍中，進左屯衛大將軍，兼檢校洛州長史。會穀貴多
盜，仁愿一切捕殺，胔積府門，畿甸震懾，無敢犯。三年，
朔方軍總管沙吒忠義為突厥所敗，詔仁愿攝御史
大夫代之。時默啜悉兵西擊，仁愿請乘虛取漠南地，
於河北築三受降城，絕南寇路。中宗從之，自是突厥
不敢踰山牧馬。初，三城不置，壅門曲敵戰格。或曰：「邊城無守備，可乎？」仁愿曰：「寇至當併力出拒，敢回望城者斬，何事守備？」後常元楷代為總管，始築壅門，議者
益重仁愿而輕元楷。景龍二年，拜左衛大將軍、同中
書門下三品，封韓國公。春還朝，秋復督軍備邊，帝為
賦詩祖道。遷鎮海大將軍。睿宗立，乃致仕。開元二年
卒。仁愿為將，號令嚴明，將吏信伏。後人思之，為立祠
受降城，出師輒享焉。宰相文武兼者，當時稱「李靖、郭元振、唐休璟、仁愿」云。
