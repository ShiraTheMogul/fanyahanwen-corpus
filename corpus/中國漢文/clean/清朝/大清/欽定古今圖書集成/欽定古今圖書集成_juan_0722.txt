《梅雨》
元·張弘範
[
编辑
]

輕雲薄薄暗江干，幾陣紗窗送嫩寒。濃醉呼童新摘
得，未黃梅子已微酸。

《蠟梅》
耶律楚材
[
编辑
]

越嶺仙姿迥異常，洞庭春染六銖裳。枝橫碧玉天然
瘦，蕾破黃金分外香。反笑素英渾淡抹，卻嫌紅艷太
濃妝。臨風浥此薔薇露，醉墨淋漓寄渺茫。

《謝王巨川惠蠟梅》
前人
[
编辑
]

雪裏冰枝破冷金，前村籬落暗香侵。令人多謝王公
子，分惠幽芳寄好音。

《早梅》
趙次誠
[
编辑
]

江南冬十二月，溪上梅三兩花。載取小舟香影，月明
自棹回家。

《題梅》
杜本
[
编辑
]

點點苔枝綴玉，疏疎檀蕊凝香。還記當年月色，簫聲
暗度宮牆。

《蠟梅》
馮子振
[
编辑
]

洗卻鉿膏飾道裝，檀心淺露紫香囊。從今宮額翻新
樣，變作眉間一點黃。

《詠綠萼梅》
前人
[
编辑
]

蕊珠宮裏小仙娃，暫別椒房柳翠華。底事塵緣猶未
斷，謫來人世列名花。

《月下觀梅》
許楨
[
编辑
]

老樹清溪映白沙，可人竹外一枝斜。黃昏信步前村
去，香到「松林賣酒家。」《賞紅梅》
郝經
[
编辑
]

汴梁宮中絳綃梅，移向汴河堤上栽。青條團楉杏花
顆，瑣細向陽才半開。張公小隊呼我飲，風色偃髯寒
氣凜。玉銜徑踏黃河冰，貂帽颯簷掀紫錦。金鞍細馬
歌舞人，雪壓小橋不動塵。入門下馬簇花宴，紅蓮舊
府花正新。玉川金波碧香酒，折花遍插分素手。春透
寒梢未全綻，風流正要臙脂瘦。賞梅不用歌落梅，緩
「歌卻著銀笙催。愛向細纈生霞蕊，浮動雲腴嚼一杯。本是前村冷淡花，不稱王侯將相家。明朝更向明月​底，藉雪凍吟疏影裏。」《立春賞紅梅》
元·淮
[
编辑
]

昨夜東風轉斗杓，陌頭楊柳雪纔消。曉來一樹如繁
杏，開向孤村隔小橋。應是花工嫌粉瘦，故將顏色助
花嬌。青枝綠葉何須辨，萬卉叢中奪錦標。

《梅》
仇遠
[
编辑
]

為怕緇塵著素衣，凍痕封蕊放香遲。月來忽送闌干
影，春到不分南北枝。啼夢翠禽依樹宿，斷魂玉笛隔
花吹。從他萬片隨風去，須有青青葉底時。

又

「夢想幽芳無處尋，相逢依舊歲寒心。要看月底玲瓏玉，休折枝頭蓓蕾金。」清曉風霜和艷冷，黃昏庭院覺
香深。揚州一樹春多少，殢得何郎瘦不禁。

《江邊梅樹》
劉秉忠
[
编辑
]

江邊繚繞惜芳叢，絕筆天真在眼中。素艷乍開珠蓓
蕾，暗香微度玉玲瓏。一枝倒影斜斜月，萬樹浮光細
細風。明日行經山下路，幾回特地駐青驄。

《謝書巢惠梅花》
虞集
[
编辑
]

巢翁遠送梅花樹，正在東風四日前。紅萼無言餘舊
雪，白頭相見又新年。喜從嘉樹來江雨，憶共香秔上
海船。春夜不眠賓客醉，只留孤鶴伴清妍。

《留宿上方觀》
前人
[
编辑
]

燈前自了讀殘經，風入疏簾月入櫺。坐到夜深誰是
伴？數枝梅萼一銅瓶。

《移梅》
馬祖常
[
编辑
]

植爾當庭隅，豈復資鼎味。遷爾自谷中，豈復相嫵媚。
冽冽元冥候，眾植各浮脆。高標自凌寒，孤尚獨冠歲。
幺禽何處來，飛下雙羽翠。

《題竹外一枝梅花》
黃清老
[
编辑
]

仙標何處來，一枝倚寒玉。晴窗見疏林，座上春可掬。
山陰帶殘雪，水影兼趣綠。珍重孤竹君，歲寒伴幽獨。

《題墨梅》
傅若金
[
编辑
]

老樹亞晴空，疏花帶寒野。風流不自惜。淡泊從人寫。
歲晏孰能娛。空山少來者。

又

孤花何婉娩，玉立含幽素。短短時出橋，疏疎或臨路。
生疑簷下月，半照牆西樹。

《元日賦紅梅》
劉詵
[
编辑
]

紅梅本遲暮，冬暖遂爭先。亂蕊額黃淡，細蘤丹砂圓。
雖加點染工，風致終自然。懷哉生意具，欲折還復憐。
物理且如此，吾生寧怨天。

《竹外梅梢》
前人
[
编辑
]

誰家修篁千萬竿，短牆流水朱闌干。孤芳託根得春
早，一枝斜出行路看。遙擬青林炯初霽，一點兩點雪
未殘。小窗月落霜角動，誰與伴此空山寒。

《燈夕觀梅》
薩都剌
[
编辑
]

翠禽偷夢出南園，綽約冰姿傍綠尊。水鏡玉釵浮翠
影，風簾銀燭照妝痕。粉香微潤無人見，素質多寒藉
酒溫。不似海棠春睡去，西樓月落已黃昏。

《二月梅》
雅琥
[
编辑
]

去年呵筆賦《寒梅》，又見仙家二月開。不是東君留客
醉，肯教神女逐春回。梨花院落為雲妒，柳絮池塘作
雪猜。東閣如今清興減，羅浮誰與寄香來。

《梅魂》
謝宗可
[
编辑
]

枝南枝北路迢迢，飛入孤山夜寂寥。水月浮香應自
返，溪風弄影為誰招。縞衣夢裏和愁斷，玉笛聲中逐
恨消。似欠靈均歌《楚些》，逋仙墳冷草蕭蕭。

《水中梅影》
前人
[
编辑
]

「澄澄寒碧映冰條，雲母屏開見阿嬌。」春色一枝流不
去，雪痕千點浸難消。臨風倚檻雲鬟濕，帶月凌波玉
佩搖。最是黃昏堪畫處，橫斜清淺傍溪橋。

《蟠梅》
前人
[
编辑
]

縈春絆碧裂蒼苔，歲晏寒香宛轉來。蛟蟄凍雲冰骨
瘦，龍眠夜月玉鱗開。風霜氣勢從千折，鐵石心腸亦
九迴。祇為東君甘自屈，不教枉占百花魁。

《紅梅》
前人
[
编辑
]

梨雲無夢倚黃昏，薄倩朱鉛蝕淚痕。宿酒破寒薰玉
骨，仙丹偷暖返冰魂。茜裙影露羅衣卷，霞佩香封縞
袂溫。回首孤山斜照外，尋真誤入杏花村。

《鴛鴦梅》
前人
[
编辑
]

兩兩魁春簇錦機，文衾夢覺月分輝。枝頭交頸棲香
暖，花底同心結子肥。金殿鎖煙妝粉額，玉堂環水浴
紅衣。有情一種隨流去，莫被風飄各自飛。

《觀紅梅》
袁桷
[
编辑
]

雲閣香溫睡覺遲，不堪殘角曉鐘時。玉妃瓊屑難為
從，青女鉛華敢弄姿。可怪絞綃能幻色，誰將猩血解
填肌。團團似就《迴文錦》，薄暮凝愁下翠枝。

《紅梅》
楊載
[
编辑
]

玉人中酒殢芳華，盡壓東風百種花。襆被冬深裁異
錦，篝燈夜永障輕紗。纖蕤露沁蜂腰蠟，密蕊雲蒸鶴
頂砂。為問閬風何處在，相期高舉籋晨霞
​

《疊葉梅》
吳澄
[
编辑
]

羅浮夢斷杳無蹤，冰雪仙姿兩兩逢。縞袂怯單寒後
襲，粉妝嫌薄曉來濃。迎風一笑知顏厚，臨水相看見
影重。道眼只將平等視，玉環飛燕總天容。

《二月江城見梅》
葉顒
[
编辑
]

二月江城第一枝，怕寒故故著花遲。不嫌艷杏夭桃
俗，甘受狂蜂妒蜨疑。月落西湖驚舊夢，雪消南國憶
當時。樓頭亦有霜天角，嬾對春風暖日吹。

《梅花》
黃鎮成
[
编辑
]

吟遍蕭疏霜後村，江頭千樹欲黃昏。等閒又被春風
覺，添得寒梢月一痕。

《題墨梅》
劉永之
[
编辑
]

茅屋蒼苔野水濱，歲寒冰雪久相親。《江湖》後夜扁舟
夢，猶記尊前對玉人。

又

仙館曾逢玉帶姿，夢中要作《曉寒詞》。於今相對情如
水，唯有清霜繞鬢絲。

《梅》
貢性之
[
编辑
]

眼中誰識歲寒交，只有梅花伴寂寥。明月滿天天似
水，酒醒聽徹玉人簫。

《登道山亭觀梅用東坡韻》
朱德潤
[
编辑
]

道山亭下梅花村，坡仙作詩為招魂。明姿照人隔寒
水，瘦影帶月欺黃昏。先生頗厭郡齋冷，持書晚約窺
山園。松風吹香清人骨，地爐煙消酒初溫。孤標已出
群卉上，故遣雪意迷晴暾。和羹結子時較晚，先傳春
色來衡門。天寒谷幽翠袖薄，豈知青鳥能傳言。明晨
看花重有約，呼童掃石羅清樽。

《紅梅》
丁鶴年
[
