金山部藝文二

金山　　　　　　　　　　　唐張祜
[
编辑
]

一宿金山寺，微茫水國分。僧歸夜船月，龍出曉堂雲。
樹影中流見，鐘聲兩岸聞。因悲在城市，終日醉醺醺。

送僧歸金山寺　　　　　　　　許渾
[
编辑
]

老歸江上寺，不忍舊師恩。駐錫逢山色，停盃見浪痕。
秋江吞楚驛。曉月上荊門。為訪題詩處，莓苔幾字存。

金山寺　　　　　　　　　　杜荀鶴
[
编辑
]

僧愛無塵地，江心島上居。接船山影瘦，登陸路頭疏。
載土春栽樹，拋生日放魚。入雲蕭帝寺，畢竟欲何如。

《前題》
孫魴
[
编辑
]

《萬古波心寺》，金山名目新。天多剩得月，地少不生塵。
過櫓妨僧定，驚湍濺佛身。誰言張處士，題後更無人。

《前題》
李翱
[
编辑
]

《山載江心寺》，魚龍是四鄰。樓臺懸倒影，鐘磬隔囂塵。
石室堪容膝，雲堂可憩身。我來登眺處，能有幾閒人。

《前題》
韓垂
[
编辑
]

金山一峰秀，岌然殊眾山。盤根大江底，撐影浮雲間。
雷霆常間作，風雨時往還。象外縣清景，千載長躋攀。

《前題》
馬戴
[
编辑
]

金陵江色裡，蟬急向秋分。回首橫孤島，歸僧渡水雲。
夕陽依岸盡，清磬隔潮聞。遙想禪林下，罏香帶月焚。

《前題》
徐道暉
[
编辑
]

兩寺今為一，僧多外國人。流來天際水，截斷世間塵。
雨宿腥林徑，龍歸繞塔輪。卻宜成片石，曾坐謝心身。

《前題》
許棠
[
编辑
]

「四面波濤匝，中流日月鄰。上窮如出世，下瞰忽驚神。」剎礙長空鳥，船通上國人。禪房皆疊翠，風掃永無塵。

憶萬歲樓望金山　　　　　　　李紳
[
编辑
]

樓高雉堞千師壘，峰拔驚波萬壑攢。山絕地維消虎
踞，水浮天險尚龍盤。蜃噓雲拱飛江島，鼇噴仙巖隔
海瀾。長對碧波臨古渡，幾經風月與悲歡。

宿金山寺　　　　　　　　　　劉滄
[
编辑
]

一點青山翠色危，雲巖不掩與星期。海門煙樹潮歸
後，江面山樓月照時。獨鶴唳空秋露下，高僧入定夜
猿知。蕭疏水木清鐘梵，灝氣寒光動石池。

金山寺　　　　　　　　　　　竇庠
[
编辑
]

一點青螺碧浪中，全依水府與天通。晴江萬里雲飛
盡，鼇背參差日氣紅。

題金山僧房　　　　　　　　　羅隱
[
编辑
]

根盤蛟蜃路藤蘿，四面無人輟棹過。得似吾師始惆

金山寺石堂　　　　　　　　李群玉
[
编辑
]

白波四面照樓臺，日夜潮聲遶寺回。千葉紅蓮高會
處，幾曾龍女獻珠來。

望金山寺　　　　　　　　　　鮑溶
[
编辑
]

一朵蓬萊在世間，梵王宮闕翠雲閒。近南秋水更清

[
编辑
]

崒然天立鎮中流，雄跨東南百二州。武士每登須破

登金山　　　　　　　　　　范仲淹
[
编辑
]

空半簇樓臺，紅塵安在哉？山分江色破，潮帶海聲來。
煙景諸鄰斷，天光四望開。疑師得仙去，白日上蓬萊。

金山　　　　　　　　　　　王安石
[
编辑
]

數重樓枕層層石，四壁窗開面面風。忽見鳥飛平地
上，始驚身在半空中。插雲金碧虹千丈，倚漢崢嶸玉
一峰。想得高秋涼月夜，分明人世《蕊珠宮》。

平甫遊金山見寄次韻　　　　　前人
[
编辑
]

漳南開寺好叢林，慧劍何年出水心。獨往便應諸漏
盡，相逢未免故情深。檻窺山鳥有真意，窗聽海潮非
世音。一笑上方人事外，不知衰境兩侵尋。

題金山寺三首　　　　　　　　前人
[
编辑
]

北楫南檣泊四陲，共憐金碧爛參差。孤根萬丈滄溟
底，除卻蛟龍世不知。

其二

波瀾蕩沃乾坤大，氣象包藏水石閒。祇有此中宜曠
望，誰令天作「海門山。」其三

天日蒼茫海氣深，一船西去此登臨。丹樓碧閣皆時

事，只有江山古到今

化城閣集句　　　　　　　　　前人
[
编辑
]

層宮憑風迥，兩岸聞鐘聲。鑿翠開戶牖，構雲有高營。
化城若化出，仰攀日月行。俛視大江奔，茫茫與天平。
大江盤嵌根，回波自成浪。卻略羅翠屏，秀色各異狀。
楞伽海中山，杳出霄漢上。中有不死庭，天龍盡回向。
惜我不得往，側坐渺難望。登茲翻百憂，意欲鏟疊嶂。
忽憶年少時，孤嶼坐題詩。空懷焉能果，唯有故人知。

會宿次平甫韻寄親友　　　　　前人
[
编辑
]

天末海雲橫北固，煙中沙岸似西興。已無船舫猶聞
笛，遠有樓臺只見燈。山月入松金破碎，江風吹水雪
崩騰。飄然欲作乘槎計，一到扶桑恨未能。

同大覺遊金山寄介甫兄　　　王安國
[
编辑
]

憶同支遁宿嶔崟，不負平生壯觀心。北固山連三楚
盡，中泠水入九江深。紛紛落月搖空影，杳杳歸舟送
梵音。東去何時來蠟屐，天邊爽氣夢相尋。

金山　　　　　　　　　　　歐陽修
[
编辑
]

地接龍宮漲浪賒。鷲峰岑絕插雲斜。巖披宿霧三竿
日。路引迷人四照花。海國鹽牙爭起榻。河童施缽但
驚沙。春蘿攀倚難成去。山谷疏鐘落暮霞。

送金山鄉僧　　　　　　　　　蘇軾
[
编辑
]

「撞鐘浮玉山，迎我三千指。眾中聞謦欬，未語知鄉里。」我非個中人，何以默識子。振衣忽歸去，隻影千江裡。
涪江與中泠，共此一味水。冰盤薦琥珀，何似糖霜美。

金山　　　　　　　　　　　　前人
[
编辑
]

「魏王大瓠無人識，種成何翅實五石。不辭破作兩大樽，只憂水淺江湖窄。我才廓落無所用，虛名驚世終何益。東方先生好自譽，伯夷子路并為一。杜陵布衣老且愚，信口自比契與稷。暮年欲學柳下惠，嗜好酸鹹不相入。」金山也是不羈人，早歲聞名晚相得。我醉
而嬉欲仙去，傍人笑倒山謂實。問我此生何所歸，笑
指浮休百年宅。蒜山幸有閑田地，招此無家一房客。

遊金山　　　　　　　　　　　前人
[
编辑
]

「我家江水初發源，宦遊直送江入海。聞道潮頭十丈高，天寒尚有沙痕在。中泠南畔石磐陀，古來出沒隨濤波。試登絕頂望鄉國，江南江北青山多。羈愁畏晚尋歸楫，山僧苦留看落日。微風萬頃靴文細，斷靈半空魚尾赤。是時江月初生魄，二更月落天深黑。江心似有炬火明，飛焰照山棲鳥驚。悵望歸臥心莫識，非」鬼非人竟何物。江山如此不歸山，江神見怪驚我頑。
我謝江神豈得已，有田不歸如江水。
〈是夜所見如此〉

寄佛印禪師妙高臺詩　　　　　前人
[
编辑
]

我欲乘飛車，東訪赤松子。蓬萊不可到，弱水三萬里。
不如金山去，清風半帆耳。中有妙高臺，雲峰自孤起。
仰觀初無路，誰信平如砥。臺中老比丘，碧眼照窗几。
巉巉玉為骨，凜凜霜入齒。機鋒不可觸，千偈如翻水。
何須尋德雲，即此比丘是。長生未暇學，請學長不死。

將遊金山寄元禪師　　　　　　蘇轍
[
编辑

麤砂施佛佛欣受，怪石供僧僧不嫌。空手遠來還要
否，更無一物可增添。

金山　　　　　　　　　　　　前人
[
编辑
]

「長江欲盡闊無邊，金山當中惟一石。潮平風靜日浮空，縹緲樓臺轉金碧。」瓜洲初見石頭城，城下波瀾與
海平。中流轉舵疑無岸，泊舟未定僧先迎。山中岑寂
恐未足，復將江水繞山麓。四無鄰家群動息，鐘聲鏗
鍠答山谷。烏鳶力薄墮中路，惟有胡鷹石上宿。誰知
江海多行舟，遊人上下集巖幽。老僧心定身不定，送
往迎來何時竟。潮來未厭夜未歸，愛山如此如公稀。
不待遊人盡歸去，恐公未識山中趣。

金山寺　　　　　　　　　　　前人
[
编辑
]

《揚州望金山》，「隱隱大如幘。朅來長江上，孤高三千尺。僧居厭山小，四面貼蒼石。虛樓三百間，正壓江潮白。清風斂霽霧，曉日曜金碧。直侵魚龍居，似有鬼神役。我行有程度，欲去空自惜。風吹渡江水，山僧方午食。波瀾洗我心，筍蕨飽我腹。平生足游衍，壯觀此云極。鐵甕本誰安，海門復誰植。東南遞隱見，遙與此山匹。」茲遊幾不遂，深愧幕府客。歸時日已暮，正值江月黑。
顧視天水并，坐恐星斗濕。使君何時罷，登覽不可失。

《前題》
蘇舜欽
[
编辑
]

「孤峰湧滄江，突兀臺殿積。驚波四面起，日夜走霹靂。陰壑畜風雲，陽崖產金碧。離披萬年樹，根抱太古石。修廊轉峻閣，窈窕壓山脊。寶像浮海來，珠瓔冷光滴。扣闌見黿鼉，揚首意自得。偃蹇互出沒，日此飽餘食。又有翠羽禽，群飛喜賓客。口銜紺蔕花，近我若相識。開軒心曠絕，上下無異色。氣象特清壯，所覽輒快適。」余心本高灑，誤為塵土隔。不知人間世，有此物外跡。
落日將發舟，低回空自惜。

遊金山　　　　　　　　　　　曾鞏
[
编辑

城外岧嶢鷲嶺宮，駕虛排險出青紅。林光巧轉滄波

摶風。連荊控蜀長江水，盡在迴廊顧盼中。

遊金山寺作　　　　　　　　　前人
[
编辑
]

候潮動鳴艣，出沒縱方舟。舉箔見茲山，巋然峙中流。
朱堂出煙霧，縹緲若瀛洲。十年入夢想，一日恣尋遊。
屣履上層閣，披襟當九秋。地勢已瀟灑，風飆更颼颼。
遠挹蜀浪來，旁臨滄海浮。壺觴對京口，笑語落揚州。
