朱明　　　　　　　　　　漢鄒子樂
[
编辑
]

朱明盛長，旉與萬物。桐生茂豫，靡有所詘。敷華就實，
既阜既昌。登成甫田，百鬼迪嘗。廣大建祀，肅雍不忘。
神若宥之，傳世無疆。

夏苗田　　　　　　　　　　晉傅元
[
编辑
]

「夏，《苗田》。」 言大晉畋狩，順時為田除害也。

夏苗田，運將徂，軍國異容文武殊。乃命群吏選車徒
​
辨其號名讚《契書》。王軍啟，八門，行同上帝居。時路建

大麾，雲旗翳紫虛。百官象其事，疾則疾，徐則徐。回衡
旋軫，罷陳敝車獻禽，享祠烝烝配有虞，惟大晉，德參
兩儀化雲敷。

夏　　　　　　　　　　　　　郭璞
[
编辑
]

羲和騁丹衢，朱明赫其猛。融風拂晨霄，陽精一何冏。
閒宇靜無娛，端坐愁日永。

夏　　　　　　　　　　　　　李顒
[
编辑
]

炎光爍南溟，溽暑融三夏。霮䨴重雲蔭，砰稜震雷咤。

出下館　　　　　　　　　　齊謝朓
[
编辑
]

麥候始清和，涼雨銷炎燠。紅蓮搖弱荇，丹藤繞新竹。
物色盈懷抱，方駕娛耳目。零落既難留，何用存華屋。

夏日臨江　　　　　　　　　梁武帝
[
编辑
]

夏潭蔭修竹，高岸坐長楓。日落滄江靜，雲散遠山空。
鷺飛林外白，蓮開水上紅。逍遙有餘興，悵望情不終。

納涼　　　　　　　　　　　簡文帝
[
编辑
]

斜日晚駸駸，池塘生半陰。避暑高梧側，輕風時入襟。
落花還就影，驚蟬乍失林。遊魚吹水沫，神蔡上荷心。
翠竹垂秋采，丹棗映疏砧。無勞《夜遊曲》，寄此託微吟。

夏　　　　　　　　　　　　　徐勉
[
编辑
]

夏景厭房櫳。促席玩花叢。荷陰斜合翠。蓮影對分紅。
此時避炎熱。清樽獨未空。

夏日　　　　　　　　　　　　徐怦
[
编辑
]

炎光歇中宇，清氣入房櫳。晚荷猶卷綠，疏蓮久落紅。

夏日還山庭　　　　　　　　陳江總
[
编辑
]

獨於幽棲地，山庭暗女蘿。澗𣹟長低篠，池開半卷荷。
野花朝暝落，盤根歲月多。停樽無賞慰，狎鳥自經過。

江都夏　　　　　　　　　　隋文帝
[
编辑
]

黃梅雨細麥秋輕，楓樹蕭蕭江水平。飛樓綺觀軒若
驚，花簟羅幃當夜清。菱潭落日雙鳧舫，綠水紅粧兩
搖漾。還似扶桑碧海上，誰肯空歌《採蓮唱》。

白紵歌　　　　　　　　　　　虞茂
[
编辑
]

長洲茂苑朝夕池，映日含風結細漪。坐當伏檻紅蓮
披，雕軒洞户青蘋吹。輕幌芳煙鬱金馥，綺簷花簟桃
李枝。蘭苕翡翠但相逐，桂樹鴛鴦恆並宿。

夏日　　　　　　　　　　　李德林
[
编辑
]

夏景多煩蒸，山水暫追涼。桐枝覆玉檻，荷葉滿銀塘。
輕扇搖明月，珍簟拂流黃。壺盛仙客酒，瓶貯帝臺漿。
才人下銅雀，侍妓出《明光》。歌聲越齊市，舞曲冠平陽。
微風動羅帶，薄汗染紅粧。共欣陪宴賞，千秋樂未央。

梅夏應教　　　　　　　　　薛道衡
[
编辑
]

長廊連紫殿，細雨應黃梅。浮雲半空上，清吹隔池來。
集鳳桐花散，騰龜蓮葉開。幸逢為善樂，頻降濟時才。

夏日聯句　　　　　　　　　唐文宗
[
编辑

奉和夏日晚景應詔　　　　　楊師道
[
编辑
]

「輦路夾垂楊，離宮通建章。日落橫峰影，雲歸起夕涼。」雕軒動流吹，羽葢息迴塘。薙草生還綠，殘花落尚香。
青巖類《姑射》，碧澗似汾陽。幸屬無為日，歡娛尚未央。

奉和聖製夏日遊石淙山　　　狄仁傑
[
编辑
]

宸暉降朢金輿轉，仙路崢嶸碧澗幽。羽仗遙臨鸞鶴
駕，帷宮直坐鳳麟洲。飛泉灑液恆疑雨，密樹含涼鎮
似秋。老臣預陪懸圃宴，餘年方共「赤松遊。」夏日仙萼亭應制　　　　　　宋之問
[
编辑
]

高嶺逼星河，乘輿此日過。野含時雨潤，山雜夏雲多。
睿藻光巖穴，宸襟洽薜蘿。悠然小天下，歸路滿笙歌。

夏日過鄭七山齋　　　　　　杜審言
[
编辑
]

「共有樽中好，言尋《谷口來》。」薜蘿山逕入，荷芰水亭開。
日氣含殘雨，雲陰送晚雷。洛陽鍾鼓至，車馬繫遲回。

夏日遊目聊作　　　　　　　駱賓王
[
编辑
]

暫屏塵囂累，言尋物外情。致逸心逾默，神幽體自輕。
浦夏荷香滿，田秋麥氣清。詎假滄浪上，將濯楚臣纓。

夏日遊山家同夏少府　　　　　前人
[
编辑
]

返照下層岑，物外狎招尋。蘭徑薰幽珮，槐庭落暗金。
谷靜風聲徹，山空月色深。一遣樊籠累，唯餘松桂心。

夏日與崔二十一同集衛明府宅
[
编辑
]

孟浩然

言避一時暑，池亭五月開。喜逢金馬客，同飲《玉人杯》。
舞鶴乘軒至，遊魚擁釣來。座中殊未起，簫管莫相催。

夏日辨玉法師茅齋　　　　　　前人
[
编辑
]

「夏日茅齋裏，無風坐亦涼。」竹林深筍概，藤架引梢長。
燕覓巢窠處，蜂來造蜜房。物華皆可翫，花蕊四時芳。

夏日浮舟過陳大水亭　　　　　前人
[
编辑
]

水亭涼氣多，閒棹晚來過。澗影見松竹，潭香聞芰荷。
野童扶醉舞，山鳥助酣歌。幽賞未云遍，煙光奈夕何。

夏日山中　　　　　　　　　　李白
[
编辑

嬾搖白羽扇，裸體青林中。脫巾挂石壁，露頂洒松風。

夏日　　　　　　　　　　　韋應物
[
编辑
]

「已謂心苦傷，如何日方永。」無人不晝寢，獨坐山中靜。
悟澹將遣慮，學空庶遺境。積俗易為侵，愁來復難整
​

夏景園廬　　　　　　　　　　前人
[
编辑

群木書陰靜，北窗涼氣多。閒居逾時節，夏雲已嵯峨。
塞葉愛繁綠，緣澗弄驚波。豈為論夙志，對此青山阿。

夏花明　　　　　　　　　　　前人
[
编辑
]

夏條綠已密，朱萼綴明鮮。炎炎日正午，灼灼火俱然。
翻風適自亂，照水復成妍。歸視窗間字，熒煌滿眼前。

夏冰歌　　　　　　　　　　　前人
[
