明四

焦瑞
[
编辑
]

按《明外史循吏傳》：「瑞字伯賢，南京人。萬曆初，以恩貢生為靈山知縣。時一條鞭法，嶺南已行十餘年，有司以僻遠里甲之供如故。瑞至，首罷之，民始有更生之樂。地多叢篁密箐，群盜嘯聚其內，督府檄推官劉子麒勦之。賊執子麒，將加害，瑞急率眾往救，賊驚拜曰：『此真吾父母，奈何犯之』？俱斂眾去，乃拔。子麒進兵，擊」斬甚夥，竟不上功，賞亦不及嶺表。去京師遠，仕者率
取珍寶以自潤，漁利之孔百端，瑞一無所問。縣產熊
膽、天竺、黃花石諸物，上官不時徵求，瑞皆卻不應。民
恐其獲罪，咸願輸納緩其怒。瑞固不聽，然竟其去，亦
無取靈山一物者。賊猶窺伺，瑞慮武備廢弛，日集士
訓練，以銀為的，射中即賞之。由是卒競勸，賊不能近。
見士子不勤學，躬督課之，日夕靡倦。時張居正枋國，
有司賦斂苛急，民多繫纍，嘆曰：「吾安忍以民命博一官乎？」遂引疾告歸，橐止八金，抵半道而卒。靈山人莫
不哀之。

王繼夏
[
编辑
]

按《山西通志》：「繼夏，岢嵐人。萬曆元年癸酉舉人，授寧遠知縣。邑當通衢，供役將迎倍他邑，且地磽瘠，水復陂汙，一值荒歲，無復生計，民難於賦而困於役。繼夏乃櫛比其俗，差為等，捐冗費，禁苛取，平均驛置之序，歲時行鄉落，勸農力耕，覈社倉，教積貯，墾荒萊，招流亡，因山就澤，聽民自利，不為禁，大庾小橐，咸以充盈」，
喜曰：「民可以教矣。」舉鄉約，《申六訓》，延見諸生，考德問
業，鼓鐘間作，聲詩繼之，諷詠不輟。又增築陴堞，鑿渠
引水，萬民利之。

蕭文璧
[
编辑
]

按《濟南府志》：「文璧，號朴菴，關中人。萬曆二年，知禹城縣。值凶歲，蒿目計之，問民疾苦，視產厚薄為登降。巨豪沃壤，嘗巧賂里胥，幸脫差使，而瘠弱廢業者卒不獲輕減。文璧均定案牘，手注參互，其丁產上下輕重，無不相恤。流亡來復，且為給牛力，資墾闢。歷三歲，來復徵科如舊額，歲時上官行部暨道路使者，供億轉」置，為費不貲。舊一以委諸編戶，文璧定吏會之議，使
度支在官，無得傷農，且稽覈有法，禁絕漁冒，數十年
弊政一朝更始。新廟學，崇文教，士之為其陶鑄者，皆
得第去。以課最擢濟寧知州，禹人為立《去思碑》。

胡其高
[
编辑
]

按《武昌府志》：「其高，字汝升，四川井研人，辛未進士。萬曆二年，自蒲城調補蒲圻令。邑舊無城，市居曠若野外，暴客猝至無備，其高始創築城，四面屹然，士民始​有寧宇。今城名曰『胡公城。修城之日，獲有異應，事詳修城碑記中』。」楊寅秋
[
编辑
]

按《廣東通志》：「寅秋，字義叔，江西泰和人。萬曆三年，以進士知東莞縣。九年，詔天下覈所部田，以清賦稅。寅秋為十四議，規畫周悉，日單騎馳田間，計畝數均科，凡溢額萬石有奇。寅秋曰：『賦為求舊』。」遂以所贏餘均
則之輕重。自此浮稅一清，數月奏績。其明敏周當，類
多過人，至今稱之。

王嘉忠
[
编辑
]

按《金華府志》：「嘉忠，號全吾，東陽人。萬曆四年丙子舉人，署吳興教諭，改平縣知縣。有奸民以白蓮教惑人，置之法。一富家為仇誣入，立雪之。調繁澄海，浚三川，築石梁，民利賴焉。俗例，上元、中元日，男婦跨彩橋禮佛，諸惡少艷歌謔浪。嘉忠聞，遂毀橋，懲其首事者，著為令。」徐震
[
编辑
]

按《廣東通志》：「震，餘姚人。萬曆六年由進士知增城縣，以清白著聲，涖事尤明，決異常。增俗類以小忿輕生，自經服毒，乘以誣人，震灼其情，反罪之，仍揭姓氏四門，其弊始息。又捕狀師書其面，沿行里巷，諸積惡慣賭者，咸俛首自歸，震薄懲之，自是公庭無事，民力寬饒。有刁民越訴，上官諭之曰：『爾增有賢令，何至於此』？」後卒於官，民咸奠賻，舉祀名宦。

陳秉浩
[
编辑
]

按《松江府志》：「秉浩，字養自，江西湖口人。萬曆十一年進士。授華亭知縣。初至，謁文廟，諸生進講，或誦『牛羊芻牧章，秉浩歎曰：『今之視民，焉得如牛羊然，猶有芻牧之字乎』？即進父老，問民疾苦，悉釐革之。恤重役，卻羡餘，廉治舞文，佐訟及奸猾吏，煩苛一洗。歲大旱，徒步禱雨，躬行阡隴，檢視災害。又出俸錢葺學宮，置田』」贍士，表「三高士墓」，建四賢祠，葬貞女，廩節婦，以示風
尚。丁憂去官，起復福建南安知縣，再調華亭，以疾乞
改散職，得湖州教授。

俞相廷
[
编辑
]

按《紹興府志》：「相廷，字中岳，新昌人。萬曆十三年乙酉中式。為南江令。當奢賊肆亂，民力疲敝，特以緩徵課練鄉勇為事。賊犯遵義府，督帥朱燮元統兵進勦，見其轉餉弗絕，大為褒獎，有牛鼎烹雞之喻。賊入蜀，逼邑境，城守特固，料敵自通江來，必從山麓行。豫率民兵伏高山，乘其前後隊進，滾石推木，自高而下，斃賊」以千計。再請援兵躡之，城賴以全。調雲陽令，一時交
薦。陞御史。赴任南都，卒於途。論者以「未竟其才」，惜之。

劉世光
[
编辑
]

按《明外史循吏傳》：「世光，字晦卿，山陽人。萬曆七年舉於鄉。十四年任趙城知縣，治獄明決，旁縣民有訟，咸願下。趙城以內艱去，服除，補沈丘。民貧不善治生，歲稍歉即束手待斃。世光曰：『民以食為天，可不預為計耶』？倣古常平社倉法，城內外置倉七所，勸富民出粟實之，不足則益以公廩羡餘，擇耆老有士行者司其」出入，月朔親臨驗視。自是凶荒有備，野無餓殍。二十
二年，潁州歲凶，貧民倡亂，突至沈丘，居人倉皇議請
兵。世光曰：「此饑民，欲得升斗活旦夕耳。用兵多，殺無辜，吾當自撫之。」乃單騎詣其壘，賊露刃相向，世光叱
曰：「吾劉沈丘也，特來活汝。不速降，將安逃死！」眾告以
饑故，世光曰：「吾故知汝輩非好亂。吾有社倉七所，為沈丘民備緩急。潁民即吾民也，當輸粟食之，慎毋動，動則兵來勦汝矣！」眾羅拜聽命。世光歸，即發粟賑給，
眾歡然散去。世光以狀白上官，時承平久，上官諱言
盜反，督過之。世光憤，即投劾歸。士民扳留不得，為立
祠奉祀。

劉一臨
[
编辑
]

按《明外史劉世光傳》：「世光子一臨，年十六，先其父舉於鄉第，萬曆十七年進士，歷知常山、長興、信豐三縣。所至興學校，勸農息訟，有政績。以不善事上官，故所如不合，卒於任。一臨後舉進士，歷顯仕者，復三世五人。人謂沈丘厚德之報。」顧允元
[
编辑
]

按《蘇州府志》：「允元，字懋善，崑山人。萬曆十四年丙戌進士。授甌寧縣令。為政持大體，婦孺皆得前陳訴，而執法不少假借。地產鐵，冶水灌田，田盡赭，允元疏免其稅，立開煎之禁，民賴有秋。先是以軍興倍征田租，軍罷不改，允元白捐其半。閩俗溺女，又蓄婢，至老不嫁，皆設法禁之，其風少變。持母服歸，以暴疾卒。」顧天敘
[
编辑
]

按《蘇州府志》：「允元子天敘，字禮初，萬曆戊子鄉薦，選鉛山令。時開採之使方張，群盜假竊其威，縱暴山谷，乃擒四十餘人，寘之法，涓人奪氣。宅艱，補元城令，與中州接壤，為潞藩舟楫取道，私鹽窟穴。天敘嚴立禁防，積弊遂絕。魏地多大剎，其僧習為不法，郡守欲盡逐之，僧大譁，天敘曰：『逐之不若安之』。乃治以保甲連​坐法，使與編戶等，魏人稱便。遷嘉魚，決志請歸，結廬鄧尉構，得閒亭以見志。卒，年八十二。葛文炳[编辑]按《寧波府志》：「文炳，字星垣，萬曆十六年舉於鄉，授江西南城令。宗藩攫民爭利，文炳進謁益王，徐陳其弊，王感悟，由是犯者得以按其罪而面決之，民賴以安。縣南有煙火山，二十七陣，供民樵牧。奸民借王府建塋名踞之。文炳請清其界，斷歸於民，立石遵守。又建水倉，免輸兌之艱。民俗鬥狠，常服山砒草自死以誣人」，乃嚴禁絕其種。時乘小竹輿，遍歷阡陌，察水利，勸
農桑，創立社學，以興絃誦。在邑六年，民立祠祀之。陞
大理評事，以疾歸，遂卒。

甘汝遷
[
编辑
]

按《廣東通志》：「汝遷，廣西富川人。萬曆十九年，以選貢知三水縣。儉朴慈愛，嘗單騎行縣，講讀《六箴》，躬親解說，延見父老，教育子弟，人親之若父母。歲旱，為文禱神，三日不雨，自繫以禱，須臾滂沱四遍，圜土烖疫，必躬禳之。胥江盜麥孔陽等，晝為漁人，夜則群繫檣桅，操之若飛，往來劫掠殺人，沉之深潭，人無知者。汝遷」廉得其情，親往詰之，召善沒者撈骨為證。會潭深，輒
不可得，乃焚香告天，朱書沒者之臂曰：「取骨伸冤。」遂
躍入，盡撈而出，盜始伏辜。每詣郡，他邑獄難決者，上
官悉以委訊。有業箕者，傭於人家，箕斷，自刺其腸而
死，誣人殺之，數年不決。汝遷一讞，即白其誣，合郡嘆
服。其為政精誠明敏，多類此也。

鄒元忠
[
编辑
]

按《廣東通志》：「元忠字時效，新建人。少學濂洛關、閩之學，由舉人萬曆二十一年知增城縣。勤政愛人，力持古道，築號舍數十於學宮之東，集諸士講學不輟。邑科試士子限於額，元忠請益之，遂為例。丙申大饑，發倉捐俸糜粥賑濟，不給，則又力勸富民之好義者，全活以萬計。又於城東四十里築隄三千一百丈，以除」水患，民賴有秋。居五載，擢丞延平，不就，歸家，晚節益
勵，謂得理學真派云。增之人士，俎豆不衰。

余懋衡
[
编辑
]

按《吉安府志》：「懋衡，號少原，婺源人。萬曆二十一年壬辰進士。除永新令，興利除害，與民更始。初邑學徙置西南隅，群稱不善，於是捐俸復創於治東故址，又創明新書院，延一時名公鉅儒講學其中，置田以資供膳，建崇閣於浮玉洲，屹然為中流之柱，立官解之法以甦民困。大吏下其法於諸郡。江省之有官解，自衡」始也。崇祀名宦祠。

趙一鶴
[
编辑
]

按《蘇州府志》：「一鶴字治心，吳縣人。萬曆二十二年甲午舉於鄉，授大名知縣，革贖鍰，免徭稅。縣居漳、衛下流，歲罹河患，召父老議，必甃隄乃可捍禦。白上官，具餱糧，興畚鍤，而界錯元城。元城令持不可，一鶴與力爭，隄竟成，名萬勝。一鶴知同官相忌，上隄議，即解組，民老幼哭送數百里。奏聞，罷元城，而調一鶴補廣之」徐聞。先是，縣城北門不啟，一鶴詢故，曰：「癸道也。啟之利民，不利令。」會火，延燒民居甚慘，一鶴命啟勿閉，災
遂寧。亡何，一鶴泛舟謁臺府，還次羚羊峽，風暴，舟覆，
溺死。一鶴初蒞徐聞，適崖州黎亂，督撫調狼兵二萬
往征。道出縣境，帥卒驕悍，劫掠騷然。一鶴密白督撫，
梟示其戎首，眾始戢。縣又多盜，豪右素為營窟，急之
即入海。一鶴諭以誠信，半皆嚮化，擒其魁以獻。一鶴
禔躬清嚴，自常祿外，毫無取，惠澤及民，不意酷報若
此！訃聞，士庶慟失聲，並設位祭享，崇祀學宮。

何如禮
[
编辑
]

按《寧波府志》：「如禮字謙六，萬曆二十三年領鄉薦，教諭海陵，擢資陽令。見聖宮頹朽，捐俸葺之。縣城及四司俱圯，竊嘆曰：『前宰是者，獨無城社之責乎』？皆更新之。」蜀中舊習，男甫十齡，父即自娶其婦，迨十五六，始
歸之於子。如禮痛禁之，俗漸革，遠邇咸稱德化。在官
不留一疑獄，不受一私錢，以不善事上官，即掛冠歸。

章嘉禎
[
编辑
]

按《太平府志》：「嘉禎，字元禮，浙江德清人。進士。初令蒲圻，卓異冠三楚。外艱歸，蒲人遮道泣送，為立祠。萬曆二十四年丙申，補知當塗，直歲祲且疫，死者載道。嘉禎賑饑施藥，暑雨不輟。時大水，圩岸將崩，嘉禎躬督捍救，宿花真天妃宮者旬月，水勢愈溢，幾不保。嘉禎涕簌簌下，誓天曰：『堤潰，民其魚矣。無民奚令為？嘉禎何惜一身，不為闔邑請命也』？」躍入巨浸，波流濚洑中，
若有物翼之者，眾亟挽以上，得不死。水漸平，圩竟無
恙。由是盡力修築圩岸，至今堅緻不毀。嘉禎善形家
理，以黃山係郡，護山種松，滿山為廕。又以府治下流
水駛，主財不豐，故前此無千金之家。特於抱流沙水
匯處造浮屠七級，東岸創興福寺，對峙鉗鎖。自後邑

免。偶於市，值養心，亟趨避，養心輿上見之，曰：「彼非前犯某事者耶？」執之訊服。分《癸酉南闈》，得人稱盛。
