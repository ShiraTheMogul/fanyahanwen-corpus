西湖部藝文四
〈詩詞〉

编辑
]

西湖夏夜觀荷　　　　　　　明高啟
[
编辑
]

雨晴南浦錦雲稠，曉待湖平蕩槳遊。狂客興多惟載
酒，小娃歌遠不驚鷗。半湖月色偏宜夜，十里荷香已
欲秋。為愛前沙好涼景，滿身風露未回舟。

夏日憶西湖　　　　　　　　　于謙
[
编辑
]

湧金門外柳如煙，西子湖邊水拍天。玉腕羅裙雙蕩
槳，鴛鴦飛近採蓮船。

歎賈平章廢宅　　　　　　　　前人
[
编辑
]

豪華汨沒幾星霜，廢宅空遺古道旁。鼠跡印塵盈故
榻，燕巢經雨落空梁。《紫雲歌》斷人千古，《金谷》花殘夢
一場。世事盛衰總如此，啼鴉不必怨斜陽。

過葛嶺懷古　　　　　　　　　陳雝
[
编辑
]

山上樓臺湖上船。平章醉酒懶朝天。《羽書》莫報《樊城》
急。新得蛾眉正少年。

賈似道別墅　　　　　　　　　丘濬
[
编辑
]

事到窮時計亦窮，此行難倚鄂州功。《木棉》庵上千年
恨，秋壑堂前一夢空。石徑苔痕猿步月，松庭樹影鳥
呼風。客來不必頻惆悵，試向吳山望故宮。

登龍山寫懷　　　　　　　　王守仁
[
编辑
]

靈鷲高林暑氣清，南屏石上雨初晴。客來湖上逢雲
起，僧到峰頭坐月明。世路久知難直道，此身何得戀
虛名。「移家早訂尋山計，種竹誅茅卻易成。」西湖曲五首　　　　　　　　李東陽
[
编辑
]

湖波綠如剪，美人照青眼。一夜愁正深，春風為吹淺。

其二

不信湖中好，儂身別有家。翻愁歲華盡，不敢采蓮花。

其三

風落平沙稻，霜垂別渚蓮。西湖三百畝，強半富兒田。

其四

草碧明沙際，花紅試雨初。官船盪素槳，驚散一雙魚。

其五

「莫唱《西湖曲》，湖邊歌舞稀。」儂家年少日，遊冶誤芳菲。

西湖子夜歌八首　　　　　　　吳兆
[
编辑
]

湖女二三月，相將戲水涯。新堤看楊柳，舊堤看桃花。

其二

新著杏紅衫，試騎赭白馬。馬驕堤路窄，急為扶儂下。

其三

三橋當路半，正好與郎期。湖水原無信，郎來那有時。

其四

南峰望北峰，如歡又如儂。何當雲霧合，兩峰作一重。

其五

渡頭人眼眾船開不敢要。慣知儂泊處，不過西泠橋。

其六
​
外湖歌《折柳》，裡湖歌《採蓮》。聞聲不相及，意緒風中傳。

其七

「西陵花深處，舊是情人路。」湖船不在湖，願歡尋故步。

其八

「悔寄孤山梅，悔折斷橋柳。」兩地本無情，郎心那得久。

湖上晚興　　　　　　　　　張文介
[
编辑
]

「日夕湖水佳，波光皎如雪。」沿堤踏花去，獨行自怡悅。
浮香時有無，流螢乍明滅。興盡櫂歸舟，山齋照涼月。

望湖亭　　　　　　　　　　何景明
[
编辑
]

獨坐湖亭望，霜空萬里明。檻疑天上立，槎是斗邊行。
雲霧開山殿，芙蓉暗水城。先朝四百寺，秋日遍題名。

西湖　　　　　　　　　　　　陸深
[
编辑
]

夜氣消殘暑，天光浸曉星。草青藏白鳥，波綠泛紅菱。

西湖雜興二首　　　　　　　方以智
[
编辑
]

露冷芙蓉色不紅，孤山無限老梧桐。當時油壁車前
路，猶在西陵「風雨中。」其二

款乃魚歌杜若洲，露寒燈火不知愁。朝朝盡醉餘杭
酒，厭薄樓船歌舞遊。

西湖　　　　　　　　　　　沈之琰
[
编辑
]

微雲淡淡碧天空，叢桂香生細細風。百頃西湖一明
月，此身已在《廣寒宮》。

忠節祠　　　　　　　　　　　海瑞
[
编辑
]

三輔烽煙接帝京，背城一戰尚縱橫。家酬士死黃金
散，身報君恩白骨輕。北極銅駝春草沒，西風畫鷁夜
潮傾。合門就義尋常事，遺恨猶聞鼓角聲。

萬松書院　　　　　　　　　　費宏
[
编辑
]

萬松深處一堂開，遊客來鐫翠壁臺。前代偏安多古
跡，清時臨眺有餘哀。憑欄遠欲吞東海，引袖高應拂
上台。卻愛暮雲消散後，相攜玩月漫徘徊。

八蟠嶺　　　　　　　　　　王元章
[
编辑
]

「路遶危垣上，風高松檜鳴。花飛殊失意，草長不知名。」遊客諮遺俗，居民指舊京。浮屠天末起，
望忽傷情。

西湖夜泛　　　　　　　　　朱長春
[
编辑
]

孤山一半月中明，橋影浮湖入畫清。兩岸白沙如雪
淨，獨楊枝下酒船橫。

西湖　　　　　　　　　　　廖孔說
[
编辑
]

水中樹影樹中山，山自無心水自閒。明月兩堤人不
見，小舟獨向斷橋還。

西湖夜別葉環中　　　　　　　顧猷
[
编辑
]

水落西陵日已斜，濃煙疏柳半藏鴉。相逢莫漫輕相
別，燈火湖頭是酒家。

西湖月夜二首　　　　　　　　祝淵
[
编辑
]

落月鱗鱗水面浮，露華濃滴桂叢秋。不知何處鳴柔
櫓，驚起一雙雪色鷗。

其二

佛火漁燈漸寂寥，推篷起坐已中宵。夜來極浦灘聲
急，知入西泠第幾橋。

西湖紀興　　　　　　　　　陶宗儀
[
编辑
]

浩浩春波闊，冥冥夜雨縣。笙歌傳別館，燈火隔疏煙。
作客頻遷次，傷時更可憐。明朝晴未卜，還是醉湖船。

題西湖小景　　　　　　　　　徐階
[
编辑
]

「西湖一別幾經秋，畫裡分明見舊遊。」花隔六橋天乍
遠，松圍三竺地偏幽。官槎到處笙歌擁，野寺連宵節
序留。何日主恩粗報塞，結廬終老白蘋洲。

西湖遊覽　　　　　　　　　田汝成
[
编辑
]

蘇堤如帶束湖心，羅綺新妝照碧潯。翠幕淺搴憐草
色，華筵小簇占花陰。凌波人渡纖纖玉，促柱箏翻疊
疊金。月出笙歌斂城市，珠樓縹緲綵雲深。

遊西湖　　　　　　　　　　張復亨
[
编辑
]

山翠湖光晝染扉，珠宮縹緲晚鐘微。僧尋《三竺》沿堤
過，鶴認孤山背水歸。橋影亂分公子棹，荷香輕看美
人衣。繁華不醉飄零客，愁聽啼鵑又夕暉。

西湖　　　　　　　　　　　張若羲
[
编辑
]

三月遊人去不留，獨攜小艇漾中流。掠波翡翠無端
過，出水鴛鴦故意浮。已對淡妝遲夜月，更迴素影待
空秋。六橋煙景仍無恙，載酒重來散百愁。

自錢塘門抵浙江驛望西湖諸峰
[
编辑
]

姚公綬

不見湖山已七年，湖光山色兩依然。青鞋自踏芙蓉
露，畫槳誰衝翡翠煙。目斷蘇堤新柳外，僧歸天竺舊
峰前。丁寧春勿堂堂去，有待重來醉管絃。

西湖夜月　　　　　　　　　高孟昇
[
编辑
]

共說西湖天下景，秋來有月更奇哉。寒波拍岸金千
頃，灝氣涵空玉一杯。桂子遠從雲外落，藕花多在露
中開。酒船清夜乘清興，絕勝笙歌日往來。

西湖雜感　　　　　　　　　錢謙益
[
编辑
]

方袍瀟灑角巾偏，纔上紅樓又畫船。修竹便娟調鶴
地，春風蘊藉養花天。蜨過柳院迎丹粉，鶯坐桃溪候
管絃。不是承平好時節，湖山容易著《神仙》。

===留題湖舫　　　　　　　　　　前人===
​
湖上隄邊艤棹時，菱花鏡裡去遲遲。分將小艇迎桃

葉，遍采新歌譜《竹枝》。楊柳風流煙草在，杜鵑春恨夕
陽知。憑闌莫漫多回首，水色山光自古悲。

六橋詩　　　　　　　　　　王世貞
[
编辑
]

拂幰鶯啼出谷頻，長堤夭矯跨蒼旻。六橋天闊爭虹
影，五馬飆輕散麴塵。碧水乍搖如轉盼，青山初沐競
舒顰。「莫輕楊柳無情思，誰是風流白舍人。」西湖夜宿　　　　　　　　　李孟昭
[
编辑
]

蹇驢衝雪岸烏紗，夜醉西湖賣酒家。十六吳姬吹《鳳
管》，捲簾燒燭看梅花。

西湖　　　　　　　　　　　胡應麟
[
编辑
]

繽紛桃李盡成蹊，夾岸晴沙送馬蹄。遠水落霞蕭寺
外，孤峰殘雪斷橋西。欄杆半倚青林出，睥睨遙看碧
樹齊。小扇輕羅歌未闋，樓船已到百花堤。

湖亭小集　　　　　　　　　宋守一
[
编辑
]

為問《竹溪》逸，誰當處士星。高標希俗累，彩筆動山靈。
鏡落芙蓉紫，園開薜荔青。肯憐朋好在，風雨望湖亭。

題瞽者遊湖　　　　　　　　石應奎
[
编辑
]
