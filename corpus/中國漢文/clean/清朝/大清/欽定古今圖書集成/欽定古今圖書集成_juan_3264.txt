《郢州白雪樓》
宋·梅詢
[
编辑
]

「楚之襄王問宋玉，玉峕對以郢中歌。歌為《白雪陽春曲》，始唱千人和，再唱百人逐。」至此和者纔數人，乃知
高調難隨俗。後來感慨起危樓，足接浮雲聲出屋。曲
中古意世應希，惆悵鯤魚盂諸宿。樓傾瓦覆春又春，
酒瀉琉璃烹錦鱗。青山繞檻看不盡，眼穿蕩槳石城
人。昔人一去不知處，寒花雨斂自生嚬。今聞太守新
梁棟，試選清喉可動塵。

《白雪樓》
滕宗諒
[
编辑
]

《白雪》樓危壓晴霓，樓下波光數毛髮。雕甍刻桷出煙
霞，萬瓦參差鵬翼截。蘭汀蕙浦入平蕪，天遠孤帆望
中滅。屈平宋玉情不盡，千古依然在風月。漂零坐想
十年舊，歲月飛馳爭裂缺。青雲交友夢魂斷，白首漁
樵誠契結。安居環堵袁安老，泣抱荊珍卞和刖。折楊
雖俚亦知名，猶欲樓中賡《白雪》。

《和郢州張伯常惠詩》
范純仁
[
编辑
]

高標早與利名疏，獨向朱門肯曳裾。舉眼正無羈客
伴，開顏長喜故人書。相期消息應端的，久別情懷待
展舒。聞說山城春色早，安車乘興莫徐徐。

《郢城新亭》
劉賓
[
编辑
]

「每到新亭即厭歸，野香經雨長松圍。」四簷山色消煩
暑，一局碁聲下翠微。冰片角巾簪澗月，錦紋拳石砌
苔磯。近來學得籠中鶴，迴避鶯聲笑不飛。

《白雪樓》
前人
[
编辑
]

「江上樓高十二梯，梯梯登盡與雲齊。」人從別浦經年
去，天向平蕪儘眼低。寒色不堪長黯黯，秋光無奈更
凄凄。闌干曲盡愁難盡，水正東流日正西。

《漢上茅屋張伯常寓郢峕築居》
曾鞏
[
编辑
]

遠山清漢上，隱然一隄長。槐柳若雲布，連陰入虛堂。
駕險注鳴溜，分畦植群芳。豈惟富桑柘，蓋亦餘囷倉。
主人事幽屏，不願尚書郎。即此徇高志，《風》《騷》恣徜徉。
強起迫義重，還歸直明光。清風凜然在，素壁盈文章。
故棲勿回眄，黃鵠本高翔。

===
《和張伯常自郢中將及本境先寄長句》
===
​

前人

㧞薤威名亦壯哉，握蘭丰度冠中臺知音忽有雙魚
至，喜氣遙欣五馬來。梨顆玉腴含雨重，菊芳金粉傍
寒開。池邊且欲留同醉，思獨難酬「《白雪》才。」《白雪樓》
王安石
[
编辑
]

《折楊》《皇華》笑者多，《陽春》《白雪》和者少。知音四海無幾
人，況乃區區郢中小。千載相傳始欲慕，一峕獨唱誰
能曉。古心以此分冥冥，俚耳至今徒擾擾。朱樓碧瓦
何年有，榱桷連空欲驚矯。郢人爛熳醉浮雲，郢女參
差躡飛鳥。丘墟遺響難再得，欄檻茲名誰復表。我來
欲歌聲更吞，石城寒江暮雲繞。

《送張伯常移居郢州》
司馬光
[
编辑
]

楚江白逶迤，楚山碧參差。玉炊稻粒長，縷切魚膾肥。
羨君盡室行，飄然無所羈。伐竹營茅茨，種菊為藩籬。
荒陂無四垣，但以荷塘圍。官雖朝大夫，身世已相違。
埜老爭坐席，林叟談忘歸。猶嫌沮溺徒，名字為人知。

《惠泉》
蘇軾
[
编辑
]

泉源從高來，走下隨石脈。紛紛白沫亂，隱隱蒼崖折。
灣回成曲沼，清澈見肝膈。潨瀉為長溪，奔駛蕩蛙蟈。
初開不容碗，漸去已如帛。傳聞此山中，神物頗遭謫。
不能致雷雨，灩灩吐寒碧。遂令山前人，千古灌稻麥。

《竟陵簿謝保》
黃庭堅
[
编辑
]

謝公文章如虎豹，至今班班在兒孫。竟陵主簿極多
閒，萬事不理專討論。澗松無心古須鬣，天球不琢中
粹溫。落筆塵沙百馬奔，劇談風霆九河翻。胸中恢疏
無怨恩，當官持廉且不煩。吏民欺公亦何忍，慎勿驚
魚使河渾。漢濱耆舊今誰存，駟馬高蓋徒紛紛。安知
四海習鑿齒，拄笏看度南山雲。

《荊門冬夜》
陸游
[
编辑
]

「常饑龜老欲無腸，臨聽寒更自短長。」香碗得閒聊作
伴，酒盃因病頗相忘。有情窗罅恰通月，耐冷艣枝多
得霜。歷盡風波知險阻，平生錯羨「捕魚郎。」《哀郢》
前人
[
编辑
]

遠接商周祚最長，北盟齊晉勢爭強。章華歌舞終蕭
瑟，雲夢風煙舊莽蒼。草合故宮惟雁起，盜穿荒塚有
狐藏。《離騷》未盡《靈均》恨，志士千秋淚滿裳。

又

荊門十月早梅春，徂歲真同下阪輪。天地何心窮壯
士，江湖從古著羈臣。淋漓痛飲長亭暮，慷慨悲歌《白
髮》新。欲弔張華無處問，廢城霜露濕荊榛。

《沔陽夜行》
前人
[
编辑
]

《夜發沔陽驛》，坡「陁岡阜重。月斜攲帽影，霜重濕裘茸。野岸鳴枯葉，煙林度曉鐘。梁州明日到，一笑解衰容。」《諸葛武侯書臺》
前人
[
编辑
]

沔陽道中草離離，臥龍老矣空遺祠。當時典午稱猾
賊，氣喪不敢當王師。定軍山前寒食路，至今人祠丞
相墓。松風想像《梁父吟》，尚憶翻然答三顧。出師一表
千載無，遠比管樂蓋有餘。世上俗儒寧辦此，高臺當
日讀何書。

《荊門州》
范鍾
[
编辑
]

荊門道路阻且修，荊襄南北當咽喉，乘傳往來絡繹
無時休。我來適值山木啼，鉤輈。但見高原《下隰》，一碧
萬頃麥浪浮，呼天控訴天知不。願天十日不雨，而暘
立俟萬雲收。比及年來三不秋，十室九餓逃而流。賣
兒鬻女骨肉相仇讎，歸來收麥聊為身家謀。含哺鼓
腹歡以謳，俯仰穹壤夫何求。嗚呼我方素䬸而飽徒
包羞為渠。樂其樂而憂其憂，不然視若風馬牛。而我
一斯世之綴旒。已焉哉，厥咎將誰尤。

《送安伯寧和沔陽》
傅汝礪
[
编辑
]

水郭春為市。沙村夜種田。雞栖桑雨外。魚網荻風前。
山獻荊人璞。江通郢客船。使幡當任過。賓斝隔花傳。

《莫愁歌》
周竹坡
[
编辑
]

蓮花深紅蓮葉綠，平沙月上鴛鴦宿。青腰三板蘭作
橈，月下莫愁歌一曲。「移舟入花花轉深，花深調苦難為音。江邊夜半誰為語？只有嬋娟知此心。」露花漸白
月漸午，刺舟自覓來時路。明朝繫纜柳邊門，卻在夜
來潮落處。

《梅花嶺》
無名氏
[
编辑
]

徒有梅花名，不見梅花樹。昔日種梅人，今日歸何處？
四顧盡荊榛，令人發長喟。長喟良有因，種植猶有繼。
何當採其實，重調商鼎味。

编辑

《詠羊左》
李東陽
[
编辑
]

山深雪寒路坎坷，兩死何如一生可。桃才自信不如
哀，君若有功何必我。楚王好士得燕才，燕家未築黃
金臺，當峕周室何為哉？吁嗟乎！樹中餓死安足戚，何
似西山採薇食。

《自承天進船暮至潛江寄郭舜符》
[
编辑
]

高叔嗣

漢渚雨聲聲，日暮愁客心。楚山雲霧多，其奈客行何。
時時登岸覽風物，往往張帆去超忽。泱漭江流雨正
添，蒙茸春樹日催發。茲行豈是乘桴意，欲遣虛舟隨
所至。生平本是江海人，終朝遂諳魚鳥事。投札鄉園
報所思，搴芳欣及仲春時。頓忘異國勞行役，但闕同
心廢賞期。

《復州故城謠》
潘子安
[
编辑
]

《陰風生》，紙錢空掛墳前樹。墳上荊棘穴狐兔。燒場未
