華山部藝文五
〈詩〉

華山館為國家營功德　　　　梁沈約
[
编辑
]

沐芳禱靈嶽，稽首恭上元。帝昔祈萬壽，臣今請億年。
丹方緘洞府，河清時一傳。錦書飛雲字，玉簡黃金編。

行經太華　　　　　　　　隋孔德紹
[
编辑
]

紛吾世網暇，靈嶽展幽尋。寥廓風塵遠，杳冥川谷深。
山昏五里霧，日落《二華陰》。竦峰起蓮葉，危塞隱桃林。
何必東都外，此處可抽簪。

祀西嶽　　　　　　　　　　唐元宗
[
编辑
]

飭駕去京邑，鳴鸞指洛川。循途經太華，迴蹕蹔周旋。
翠崿留斜影，懸崖凝夕煙。四方皆石壁，五位配金天。
彷彿看高掌，依稀聽子先。終當銘歲月，從此寄靈仙。

奉和聖製途經華嶽　　　　　　張說
[
编辑
]

西嶽鎮皇京，中峰入太清。玉鑾重嶺應，緹騎薄雲迎。
白日懸高掌，寒空類削成。軒遊會神處，漢幸望仙情。
舊廟青林古，新碑綠字生。群臣願封岱，迴駕勒鴻名。

辛丑歲十月上幸長安時扈從出西嶽作
[
编辑
]

沈佺期

「西嶽何穹崇，壯哉信靈造。諸嶺皆峻秀，中峰特美好。旁見巨掌存，勢如石東倒。頗聞首陽去，開拆此河道。磅礡壓河源，巍峨壯清昊。雲泉紛亂瀑，天磴屹橫抱。子先呼其巔，宮女世不老。下有府君廟，歷載傳灑掃。星明應天遊，十月戒豐鎬。微末忝閒從，兼得事蘋藻。宿心愛此山，意欲拾靈草。」陰壑已永閉，雲竇絕探討。
芳月期來過，迴策思方浩。

嶽館　　　　　　　　　　　　前人
[
编辑
]

洞壑仙人館，孤峰玉女臺。空濛朝氣合，窈窕夕陽開。
疏澗含輕雨，虛巖應薄雷。正逢鸞與鶴，歌舞出天來。

華嶽　　　　　　　　　　　　王維
[
编辑
]

西嶽出浮雲，積翠在太清。連天凝黛色，百里遙青冥。
白日為之寒，森沈華陰城。昔聞乾坤閉，造化生巨靈。
右足踏方山，左手推削成。天地忽開拆，大河注東溟。
遂為西峙嶽，雄雄鎮秦京。大君包覆載，至德被蒼生。
上帝佇昭告，金天思奉迎。神祇望幸久，何獨禪云亭。

過華陰　　　　　　　　　　王昌齡
[
编辑
]

《雲起太華山》，「雲山互明滅。東峰始含景，了了見松雪。羈人感幽棲，窗映轉奇絕。欣然忘所疲，永望吟不輟。信宿百餘里，出關玩新月。何意昨來心，遇物遂遷別。人生屢如此，何以肆愉悅。」行經華陰　　　　　　　　　　崔灝
[
编辑
]

岧嶢太華俯咸京，天外三峰削不成。武帝祠前雲欲
散，仙人掌上雨初晴。河山北枕秦關險，驛樹西連漢
畤平。借問路傍名利客，何如此處學《長生》。

西嶽雲臺歌贈丹丘子　　　　　李白
[
编辑
]

「西嶽崢嶸何壯哉，黃河如絲天際來。黃河萬里觸山動，盤渦轂轉秦地雷。榮光休氣紛五彩，千年一清聖人在。巨靈咆哮擘兩山，洪波噴流射東海。三峰卻立如欲摧，翠崖丹谷高掌開，白帝金精運元氣，石作蓮花雲作臺，雲道閣道連窈冥。中有不死丹丘生，明星玉女備洒掃，麻姑搔背指爪輕，我皇手把天地戶，丹」丘談天與天語。九重出入生光輝，東求蓬萊復西歸。
玉漿倘惠故人飲，騎二茅龍向天飛。

===望嶽　　　　　　　　　　　　杜甫===
​
西嶽峻嶒竦處尊，諸峰羅立似兒孫。安得仙人《九節》
杖，拄到玉女洗頭盆。車箱入谷無歸路，箭括通天有
一門。稍待秋風涼冷後，高尋白帝問真源。

經太華贈盧司倉　　　　　　　陶翰
[
编辑
]

作吏到西華，乃觀三峰壯。削成元氣中，傑出天漢上。
如有飛動色，不知青冥狀。巨靈安在哉，厥跡猶可望。
方此顧行旅，末由飭仙裝。朦朧記星壇，明滅數雲障。
良友隨真契，宿心所微。尚敢投《歸山》吟，霞徑一相訪。

尋華山雲臺觀道士　　　　　　錢起
[
编辑
]

秋日西山明，勝趣引孤策。桃源數曲盡，洞口兩崖拆。
還從罔象來，忽得仙靈宅。《霓裳》誰之子，霞酌能止客。
殘陽在翠微，攜手更登歷。林行拂煙雨，溪望陵金碧。
飛鳥下天窗，褭松際雲壁。稍尋元蹤遠，宛入寥天寂。
願言葛仙翁，終年鍊玉液。

入華山訪隱者經仙人壇　　　　李益
[
编辑
]

三考西嶽下，官曹少休沐。久負青山諾，今還獲所欲。
常聞玉清洞，金簡受元籙。夙駕昇天行，雲霞恣遊宿。
平明矯輕策，捫石入空曲。征人古石壇，苔遶青瑤局。
陽桂凌煙紫，陰蘿冒水綠。隔山聞丹經，懸泉注明玉。
前驚羽人會，白日天居肅。問我將致辭，笑之自相目。
竦身雲遂起，仰見雙白鵠。墮其一紙書，文字類鳥足。
視之了不識，三返又三復。歸來問方士，舉世莫能讀。
何必若蜉蝣，然後為跼促。鄙哉宦遊子，身志俱降辱。
再往不及期，勞歌叩山木。

訪法華雲公　　　　　　　　　岑參
[
编辑
]

野寺聊解鞍，偶見法華僧。開門對西嶽，石壁青稜層。
竹逕厚蒼苔，松門盤紫藤。長廊列古畫，高殿懸孤燈。
五月山雨熱，三峰火雲蒸。側聞樵人言，深谷猶積冰。
久願尋此山，至今嗟未能。謫宦忽東走，王程若相仍。
欲去戀雙樹，何由窮一乘。月輪吐山郭，夜色空清澄。

華山　　　　　　　　　　　　張喬
[
编辑
]

青蒼河一隅，氣壯杳難圖。卓傑三峰出，高奇四嶽無。
力疑擎上界，勢似壓中區。眾水東西走，群山遠近趨。
天迴諸宿照，地聳百靈扶。石壁煙霞麗，龍潭雨雹麤。
澄凝臨甸服，險固束神都。淺覺川原異，深應日月殊。
鶴歸青靄合，僊去白雲孤。瀑溜斜飛凍，松長倒挂枯。
每來探洞穴，不擬返江湖。倘有芝田種，巖間寄野夫。

關門望華山　　　　　　　　劉長卿
[
编辑
]

客路瞻太華，三峰高際天。夏雲亙百里，合沓遙相連。
雷雨飛半腹，太陽在其巔。翠微關上近，瀑布林稍懸。
愛此眾容秀，能令西望偏。徘徊忘溟色，泱漭成陰煙。
曾是朝百靈，亦聞會群仙。瓊漿豈易挹，毛女非空傳。
彷彿仍佇想，幽奇如眼前。金天有青廟，松柏隱蒼然。

經太華　　　　　　　　　　　衛光
[
编辑

太華五千尋，重巖才沓起。勢飛白雲外，影倒黃河裏。
上有千葉蓮，服之久不死。山高採難得，歎息徒仰止。

華山　　　　　　　　　　　　韓愈
[
编辑
]

洪鍾作《高山》，大氣鼓其橐。俄然神功就，峻拔在寥廓。
靈蹤露指爪，殺氣見稜角。凡木不敢生，神仙聿來托。
天資帝王宅，以我為關鑰。能令下國人，一見換神骨。
高山固無限，如此方為嶽。丈夫無特達，雖貴猶碌碌。

玉井　　　　　　　　　　　　前人

编辑

太華峰頭玉井蓮，花開十丈藕如船。冷比雪霜甘比

夤緣。安得長梯上摘實，下種七澤根株連。

有雪草不死，無風松自吟。會當求大藥，他日復追尋。

急瀑和煙瀉，清猿帶雨聞。幽棲未忍別，峰畔日將曛。

華山　　　　　　　　　　　　李洞

编辑

月遊。峰頂高眠靈藥熟，自無霜雪入人頭。

编辑

夾道人家水竹間，馬頭山色畫應難。天公故故開雲
幕，乞與《蓮峰》仔細看。

===太華山　　　　　　　　　　　鄭谷===
​
峭仞聳巍巍，晴嵐染近畿。孤高不可狀，圖寫盡應非。
絕頂神仙會，半空鸞鶴歸。雲臺分遠靄，樹谷隱斜暉。
墜石連村響，狂雷發廟威。氣中寒渭闊，影外白樓微。
雲對蓮花落，泉橫露掌飛。乳懸危磴滑，樵徹上方稀。
澹泊生真趣，逍遙息世機。野花明澗路，春蘚澀松圍。
遠洞時聞磬，群僧晝掩扉。他年洗塵骨，香火願相依。

[

其二

縹緲真探白帝宮，三峰此日為誰雄。蒼龍半掛秦川

陽空。生平突兀看人意，容爾深知造化功。

其三

濕，倚劎明星白日寒。東走峰陰搖砥柱，西來紫氣屬
長安。自憐彩筆驚人在，咫尺天門謁帝難。
