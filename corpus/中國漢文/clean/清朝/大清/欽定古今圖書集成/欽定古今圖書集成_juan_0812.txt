海棠部藝文三
〈詞〉
[
编辑
]

《如夢令》
宋·吳潛
[
编辑
]

江上綠楊芳草。想見故園春好。一洞海棠花，昨夜夢
魂飛繞。驚曉。驚曉。窗外一聲啼鳥。

《點絳唇》
王十朋
[
编辑
]

絲蕊垂垂，嫣然一笑新妝就。錦亭前後。燕子來時候。
誰恨無香，試把花枝嗅。風微透。細熏錦袖。不止嘉
州有。

《浣溪沙》
〈燭下海棠〉
范成大
[
编辑
]

傾坐東風百媚生。萬紅無語笑逢迎。照妝醒睡蠟煙
輕。綵蝀橫斜春不夜，絳霞濃淡月微明。夢中重到
錦官城。

又

催下珠簾護綺叢。花枝紅裏燭枝紅。燭光花影夜蔥
蘢。錦地繡天香霧裏，珠星璧月綵雲中。人間別有
幾春風。

===
《卜算子》
〈海棠盛開遇風雨〉
劉克莊
===
​
片片蝶衣輕，點點猩紅小。人道東君不惜花，百種千

般巧。朝見樹頭繁，暮見枝頭少。人道東君解惜花，
雨打風吹了。

又

盡是手栽成，合得天饒借。風雨於花有底讎，著意相
陵藉。做暖逼教開，做冷催教謝。不負明年花下人，
只負栽花者。

《卜筭子》
葉夢得
[
编辑
]

嬌豔醉楊妃，輕裊憐飛燕。人在昭陽睡足時，初試妝
深淺。一段錦新裁，萬里來何遠。高燭休教照夜寒，
媚臉融春暖。

《菩薩蠻》
王安石
[
编辑
]

《海棠》亂發皆臨水，君知此處花何似。涼月白紛紛，香
風隔岸聞。囀枝黃鳥近。隔岸聲相應。隨意坐莓苔。
飄零酒一杯。

《菩薩蠻》
劉儗
[
编辑
]

東風去了秦樓畔。一川煙草無人管。芳樹雨初晴。黃
鸝三兩聲。海棠花已謝。春事無多也。只有牡丹時。
知他歸不歸。

《訴衷情》
晏殊
[
编辑
]

海棠枝綴一重重，清曉近簾櫳。臙脂誰與勻染，偏向
臉邊濃。看葉嫩，惜花紅。意無窮。如花如葉，歲歲年
年，共占春風。

《錦園春》
張孝祥
[
编辑
]

醉痕潮玉。愛柔英未吐，露華如簇。絕豔矜春，分流芳
金谷。風梳雨沐。耿空抱、夜闌清淑。杜老情疏，《黃州》
賦冷，誰憐幽獨。

《畫堂春》
〈賞海棠〉
趙長卿
[
编辑
]

夜來暖趁海棠時。臉邊勻透臙脂。亂紅嬌影困垂垂。
睡損楊妃。多少玉溫香潤，朱脣綠鬢相偎。晚風何
苦過臺西。斷送春歸。

《柳梢青》
〈詠海棠〉
曾覿
[
编辑
]

雨過風微，溫泉浴倦，妃子妝遲。翠袖牽雲，朱脣得酒，
臉暈臙脂。「年年海燕新歸。怎奈向黃昏。恁時倚遍瓊闌，燒殘銀燭，花又爭知。」《柳梢青》
〈冬月海棠〉
盧炳
[
编辑
]

笑菊欺梅，嫌蜂卻蝶，壓盡寒荄。月下精神，醉時風韻，
紅透香腮。天工造化難猜。甚怪我、愁眉不開。故遣
名花，凌霜帶露，先送春來。

《柳梢青》
〈海棠〉
葛長庚
[
编辑
]

一夜清寒，千紅曉燦，春不曾知。細看何如，醉時西子，
睡底楊妃。盡皆蜀種垂絲。晴日暖、熏成錦圍。說與
東風，也須愛惜，且莫吹飛。

《浪淘沙》
〈雨中海棠〉
張矩
[
编辑
]

春夢草茸茸。愁雨愁風。對花須𢬵酒頻中。莫遣枝頭
銀燭暗，辜負嫣紅。推起簿書叢。何苦匆匆。慳吟卻
說少陵公。天定為花開一笑，日上籬東。

《南鄉子》
李廌
[
编辑
]

十月小春天。紅葉紅花半雨煙。點滴紅酥真耐冷，爭
先。奪取梅魂鬥雪妍。坐待曉鶯遷。織女機頭蜀錦
鮮。枝上綠毛幺鳳子，飛僊。乞取雙雙作被眠。

《玉樓春》
〈海棠〉
柳永
[
编辑
]

東風催露千嬌面。欲綻紅深開處淺。日高梳洗甚時
忺，點滴臙脂勻未遍。霏微雨罷殘陽院。洗出都城
新錦段。美人纖手摘芳枝，插在釵頭和鳳顫。

《玉樓春》
〈題畫海棠花〉
高觀國
[
编辑
]

臙脂染出春風錦。生怕黃昏人有恨。雨難揩淚玉環
嬌，煙不遮愁紅袖冷。醉魂吹斷香魂靜。拂拂翠眉
羞帶粉。最憐新燕識風流，只為春寒消瘦損。

《一斛珠》
〈賞海棠〉
管鑑
[
编辑
]

春陰漠漠。海棠花底東風惡。人情不似春情薄。守定
花枝，不放花零落。綠樽細細供春酌。酒醒無奈愁
如昨。殷勤待與東風約。莫苦吹花，何似吹愁卻。

《醉落魄》
范成大
[
编辑
]

馬蹄塵撲。春風得意笙歌逐。款門不問誰家竹。只揀
紅妝，高處燒銀燭。碧雞坊裏花如屋。燕王宮下花
成谷。不須悔唱《關山曲》。只為海棠，也合來西蜀。

《醉落魄》
京松坡
[
编辑
]

芳塵休撲。名花喚我相隨逐。淺妝不比梅欺竹。深注
朱脣，妝面稱紅燭。阿嬌合住黃金屋。是誰卻遣來
空谷。酡顏遍倚闌干曲。一段風流，不枉到西蜀。

《蝶戀花》
王道輔
[
编辑
]

濯錦江頭春欲暮。枝上繁紅，著意留春住。祇恐東君
嫌面素。新妝勝把臙脂傅。曉夢驚寒初過雨。寂寞
珠簾，問有餘花否。悵望草堂無一語。丹青傳得凝情
處。

《蝶戀花》
張材甫
[
编辑
]

前日海棠猶未破。點點臙脂，染就珍珠顆。今日重來
花下坐。亂鋪宮錦春無那。勝摘繁枝簪幾朵。痛惜
深憐，只恐芳菲過。醉倒何妨花底臥。不須紅袖來扶
我
​

《臨江仙》
〈種海棠作〉
劉克莊
[
编辑
]

「落魄長官江海客，少年萬里尋春。而今憔悴向溪濱。斷無觴詠興，惟有簿書塵。」手插海棠三百本，等閒
妝點芳辰。他年絳雪映紅雲。「叮嚀風與月，記取種花人。」《殢人嬌》
張奕
[
编辑
]

多少臙脂，勻成點就，千枝亂、攢紅堆繡。花無長好，更
光陰去後，對景憶良朋，故應招手。曾記年時，花開
把酒，枉淋淋、春衫濕透。文園今病，問速能來否，卻道
有荼𧃲，牡丹時候。

《感皇恩》
〈海棠〉
晁補之
[
编辑
]

常歲海棠開，偷閒須到。多病尋芳嬾春老。偶來恰值，
半謝妖嬈猶好。便呼詩酒伴，同傾倒。繁枝高蔭，疏
枝低繞。花底杯盤花影照。多情一片，恨我歸來不早。
斷腸鋪碎錦，門前道。

《驀山溪》
〈海棠〉
王千秋
[
编辑
]

清明池館，側臥簾初卷。還是海棠開，睡未足、餘酲滿
面。低頭不語，渾似怨東風，心始吐，又驚飛，交現垂楊
眼。少陵情淺。花草題評遍。賦得惡因緣，沒一字、聊
通繾綣。黃昏時候，凝佇怯春寒，籠翠袖，減豐肌，脈脈
情何限。

《踏青遊》
陳濟翁
[
编辑
]

濯錦江頭，羞殺豔桃穠李。縱趙昌、丹青難比。暈輕紅，
留淺素，千嬌百媚。照綠水。恰如下臨鸞鏡，妃子弄妝
猶醉。詩筆因循，不曉少陵深意。但滿眼、傷春珠淚。
燕來時，鶯啼處，年年憔悴。便除是、秉燭憑欄吟賞，莫
教夜深花睡。

《洞僊歌》
晁補之
[
编辑
]

群芳未盡，是海棠時候。雨過寒輕好晴晝。最妖嬈一
樹，全是初開，雲鬟小，塗粉施朱未就。全開還自好，
駘宕春餘，百樣宮羅鬥繁繡。縱無語、也應心恨我來
遲，怕柳絮、將春歸後。醉猶倚柔枝，恰黃昏，一點愁，須
共花同瘦。

《洞僊歌》
〈海棠〉
京鏜
[
编辑
]

東皇著意，妙出妝春手。點綴名花勝於繡。向魚鳧國
裏，琴鶴堂前，仍共賞，蜀錦堆紅炫晝。妖嬈真豔麗，
盡是天然，莫恨無香欠檀口。幸今年風雨，不苦摧殘，
還肯為、游人再三留否。筭魏紫姚黃號花王，若定價
收名，未應居右。

《滿江紅》
〈夜飲海棠花下〉
劉克莊
[
编辑
]

老子年來，頗自許、心腸鐵石。尚一點、消磨不盡，愛花
成癖。懊惱每嫌寒勒住，叮嚀莫被晴烘拆。奈暄風、烈
日太無情，如何得。張畫燭，頻頻惜。憑素手，輕輕摘。
更一番雨過，彩雲無跡。今夕不來花下飲，明朝空向
枝頭覓。對殘紅、滿院杜鵑啼，添愁寂。

《滿江紅》
〈括東坡海棠〉
林正大
[
编辑
]

寂寞江城，𢬵只共、梅花幽獨。揩病眼、佳人何許，嫣然
空谷。幻出天姿真富貴，朱脣殢酒紅生肉。笑漫山、繁
李與妖桃，俱麤俗。遲日麗，春睡足。明月照，尢清淑。
筭移根千里，遠從西蜀。流落天涯應可念，為渠劇飲
仍歌曲。怕明朝、酒醒落紛紛，那容觸。

《燭影搖紅》
劉處靜
[
编辑
]

蜀錦華堂，寶箏頻送花前酒。妖嬈全在半開時，人試
單衣後。花面圍春競秀，如紅潮、玉腮微透。欲甦還睡，
淺酒扶頭，朦朧晴晝。金屋名姝，恨情空貯閒眉岫。
世閒還有此娉婷，拚盡珠量斗。真豔。可令消受，倩鶯
催、天香共袖。冷煙庭院，淡月梨花，空教春瘦。

《漢宮春》
〈張園賞海棠〉
陸游
[
编辑
]

浪跡人閒，喜聞猿楚峽，學劍秦川。虛舟汎然不繫，萬
里江天。朱顏綠鬢，作紅塵、無事神僊。何妨在，鶯花酒
裏，行歌閒送流年。休笑放慵狂眼，看閒坊深院，多
少嬋娟。燕宮海棠夜宴，花覆金船。如椽畫燭，酒闌時、
百炬吹煙。憑寄語，京華舊侶，幅巾莫換貂蟬。

《念奴嬌》
〈宜雨亭詠千葉海棠〉
張鎡
[
编辑
]

綠雲影裏，把明霞織就，千里文繡。紫膩紅嬌扶不起，
好是未開時候。半怯春寒，半宜晴色，養得臙脂透。小
亭人靜，嫩鶯啼破春晝。猶記㩦手芳陰，一枝斜戴，
嬌豔雙波秀。小語輕憐花總見，爭得似花長久。醉淺
休歸，夜深同睡，明日還相守。免教春去，斷腸空歎詩
瘦。

《念奴嬌》
〈初見海棠〉
程珌
[
编辑
]

嫣然一笑，向燭花光下，經年纔見。欲語還羞如有恨，
方得東君一盼。天意無情，更教微雨，香淚流丹臉。今

《饒州志》：「蜀錦亭在府治慶朔堂右，宋范仲淹植海棠二株，其後鄒柯築亭，題曰『蜀錦』。」王十朋詩：「亭廢名猶在，春來花自芳。猶餘蜀中錦，愛惜此甘棠。」《雞肋編》：「信州弋陽縣海棠滿山，村人至并花，伐以為薪。廣南以根啖豬。」陳思《海棠譜》：「閩中曹宇修貢堂下海棠極盛，三面共二十四叢，長條脩榦，頃所未見。每春著花，真錦繡段，其閒有如紫綿揉色者，亦有不如此者，蓋其種類不同，不可一概論也。至其花落，則皆若宿妝淡粉矣。余三春對此觀之至熟，大率富沙多此，官舍人家往往皆種之，並是帚子海棠，正與蜀中者相類，斯可貴耳。」今江浙閒別有一種柔枝長蔕，顏色淺紅，垂英向下，

《種樹書》：「海棠候花謝，結子剪去，來年花盛，無葉。」《平泉草木記》：凡花木以海為名者，悉從海外來，如海
棠之類是也。

《東坡雜記》：「海棠似絹花。」《復齋漫錄》：仁宗朝，張冕學士賦蜀中海棠詩，沈立取
以載《海棠記》中云：「山木瓜開千顆顆，水林檎發一攢攢。」注云：大約木瓜、林檎初開，皆與海棠相類。若冕言，
江西人正謂棠梨花耳，惟紫綿色者謂之海棠，似木
瓜、林檎六出者，非真海棠也。晏元獻云：「已定復搖春水色，似紅如白海棠花。」亦張冕同意。

《王禹偁詩話》：「『杜子美避地蜀中，未嘗有一詩說著海棠』，以其生母名海棠也。」《韻語陽秋》：杜子美居蜀累年，詠吟殆遍，海棠奇豔，而
詩章獨不及，何耶？鄭谷詩云：「浣花溪上空惆悵，子美無心為發揚」是已。本朝名士賦海棠甚多，往往皆用
此為實事。如石延年云：「杜甫句偏略，薛能詩未工。」錢
易詩云：「子美無情甚，都官著意頻。」李定詩云：「不霑工部風騷力，猶占勾芒造化權。」獨王荊公用此作梅花
詩，最為有意。所謂「少陵為爾牽詩興，可是無心賦《海棠》」也。

《冷齋夜話》：東坡海棠詩曰：「只恐夜深花睡去，故燒銀燭照紅妝。」事見《太真外傳》。

前輩作花詩，多用美女比其狀，如曰「若教解語應傾國，任是無情也動人。」誠然哉！山谷作《酴醾》詩曰「露濕何郎試湯餅，日烘荀令炷爐香。」乃用美丈夫比之，特
若出類。而吾叔淵材作《海棠》詩又不然，曰：「雨過溫泉浴妃子，露濃湯餅試何郎。」意尢工也。

《金城記》：𥟖舉嘗曰：「欲以梅聘海棠，但恨時不同耳。」牡丹榮辱志花命婦重葉海棠，花戚里多葉海棠。
《詞話》：曾覿取友於十花海棠名友也。
