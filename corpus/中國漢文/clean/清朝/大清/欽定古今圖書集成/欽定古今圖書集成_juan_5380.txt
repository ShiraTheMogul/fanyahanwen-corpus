杜淹
[
编辑
]

按《唐書杜如晦傳》：「如晦叔淹，字執禮，才辯多聞，有美名。隋開皇中，授承奉郎，擢累御史中丞。王世充僭號，頗親近用事。洛陽平，秦王引為天策府兵曹參軍。及踐阼，召為御史大夫，封安吉郡公。俄檢校吏部尚書，參預朝政。貞觀二年卒。子敏同襲爵，官至鴻臚卿。」杜伏威
[
编辑
]

按《唐書杜伏威傳》：「伏威，齊州章丘人，與里人輔公祏為盜。伏威狡譎多筭，每剽劫，眾用其策，皆效其黨愛服，共推為主。海陵賊趙破陣聞伏威兵少，輕之，召使并力。伏威突斬破陣，并其眾至數萬。破高郵，引兵渡淮，攻歷陽，據之，稱總管，分兵徇屬縣皆下，江淮群盜爭附。伏威上表越王侗，侗以為東南道大總管。是時」秦王方討王世充，遣使招懷，伏威乃獻款，高祖授以

上柱國、吳王，賜姓豫屬籍。秦王已平劉黑闥，師次曹
​
兗，伏威懼，乃入朝。詔拜太子太保，留京師。伏威好神

仙長年術，餌雲母被毒，武德七年二月暴卒。

杜如晦
[
编辑
]

按《唐書杜如晦傳》：「如晦字克明，京兆杜陵人。祖杲，有名周隋間。如晦少英爽，喜書，內負大節，臨機輒斷。隋大業中，補滏陽尉，棄官去。高祖平京師，秦王引為府兵曹參軍，徙陝州總管府長史，進司勳郎中，封建平縣男。天策府建，為中郎。王為皇太子，授左庶子，遷兵部尚書，進封蔡國公，位尚書右僕射，與元齡共筦朝」政，以疾辭職。薨，諡曰成。子構，位慈州刺史。次子荷，尚
城陽公主，封襄陽郡公。承乾謀反，坐誅。構以累貶死
嶺表。

杜楚客
[
编辑

按《唐書杜如晦傳》：「如晦弟楚客，少尚奇節。貞觀四年，召為給事中，擢中郎將，進蒲州刺史，政有能名。後為魏王府長史，遷工部尚書，攝府事。揣帝意薄承乾，乃為王諧媚用事臣。及王貶爵，廢於家，終虔化令。」杜正倫
[
编辑
]

按《唐書杜正倫傳》：「正倫，湘州洹水人。太宗表直秦王府文學館。貞觀元年，擢兵部員外郎，俄遷給事中，知起居注，進累中書侍郎。太子監國，詔正倫行左庶子。太子稍失道，帝語正倫可審喻之，教而不徙，其語『我來』。故正倫顯諫無所避，太子不從，輒道帝語督切，太子即表聞。帝怒，出為穀州刺史。太子廢，坐受金帶流」驩州。顯慶元年，擢黃門侍郎，進同中書門下三品，遷
中書令。初，正倫已貴，李義府官尚微，及同執政，不能
下義府，使人告正倫有異計。高宗惡之，出正倫為橫
州刺史，卒。

杜求仁
[
编辑

按《唐書杜正倫傳》：「正倫從子求仁，有雅才，永淳中，授監察御史。坐事為黝令，與徐敬業舉兵，死於難。」杜景佺
[
编辑
]

按《唐書杜景佺傳》：「景佺，冀州武邑人，性嚴正，舉明經中第，累遷殿中侍御史，出為益州錄事參軍，入為司刑丞，與徐有功、來俊臣、侯思止專治詔獄，時稱遇徐、杜者生，來、侯者死。改秋官員外郎，擢鳳閣舍人，延載元年，同鳳閣鸞臺平章事。后嘗季秋出棃華示宰相，眾賀，景佺曰：『陰陽不相奪倫，瀆即為災。今草木黃落而復華，瀆陰陽也』。」頓首請罪，后曰：「真宰相。」會李昭德
下獄，景佺苦申救，后以為面欺，左遷溱州刺史。入拜
司刑卿。聖曆元年，復以鳳閣侍郎同鳳閣鸞臺平章
事，罷為秋官尚書。坐漏省內語，降司刑少卿，出為并
州長史，道病卒。初名元方，垂拱中改今名。

杜易簡
[
编辑
]

按《唐書杜審言傳》：「審言從祖兄易簡，九歲能屬文，長博學，擢進士，補渭南尉。咸亨初，歷殿中侍御史。嘗道遇吏部尚書李敬元，不避，敬元恨，召為考功員外郎屈之。易簡上書言敬元罪，敬元因奏易簡險躁，高宗怒，貶開州司馬。」杜審言
〈子并〉
[
编辑
]

按《唐書杜審言傳》：「審言，字必簡，襄州襄陽人，晉征南將軍預遠裔。擢進士，為隰城尉。恃才高，以傲世見疾，累遷洛陽丞。坐事貶吉州司戶參軍。周季重構其罪，將殺之。審言子并年十三，袖刀刺季重於坐，左右殺并，審言免官後，武后召授著作佐郎，遷膳部員外郎。神龍初，坐交通張易之，流峰州，入為修文館直學士」，
卒。

杜暹
[
编辑
]

按《唐書杜暹傳》：「暹，濮州濮陽人。父承志，武后時為監察御史，見羅織獄興，移疾去，卒於家。自高祖至暹，五世同居。暹尢恭謹，事繼母孝，擢明經第，補婺州參軍，為鄭尉，以清節顯，擢為大理評事。開元四年，以監察御史遷給事中，以母喪解，奪服拜安西副大都護，守邊四年，為夷夏所樂。十四年，召同中書門下平章事」，
罷為荊州都督長史。歷魏州刺史。帝幸北都，復東幸，
以暹為留守。進禮部尚書。卒諡「貞孝。」杜生
[
编辑
]

按《唐書杜生傳》：「『生，許州人，善《易》占，有亡奴者，問所從追，戒曰：『自此行逢使者，懇丐其鞭』。其人果值使者於道，如生語。使者異之曰：『去鞭吾無以進馬，可折道旁葼代之』。乃往折葼，見亡奴，伏其下，獲之。它日又有亡奴者，生戒，持錢五百伺於道，見進鷂使者，可市其一，必得奴』。俄而使至，其人以情告，使者以一與之，忽飛」集灌莽上。往取之。而得亡奴。眾以為神。

杜希望
[
编辑
]

按《唐書杜佑傳》：「佑父希望，為安陵令，坐小累去官。開元中，署靈州別駕、關內道支度判官。自代州都督召還京師，對邊事，元宗才之。屬吐蕃攻勃律，拜希望鄯州都督，破烏莽眾，還，擢鴻臚卿。於是置鎮西軍。吐蕃悉眾爭壇泉，希望大小戰數十，俘其大酋，卒城而還。」===杜咸===
​
按《唐書杜正倫傳》：「正倫從孫咸，擢進士第，累遷右臺監察御史。牂牁反，咸監軍出討賊，平之。遷侍御史，出為汾州長史。開元中，為河北按察使，坐用法深，貶睦州司馬。」杜甫
[
编辑
]

按《唐書杜審言傳》：「審言兄子閑。閑子甫，字子美，少貧不自振，客吳越齊趙閒。舉進士不中第，困長安。天寶十三載，奏賦三篇。帝奇之，使待制集賢院，命宰相試文章，擢河西尉，不拜，改胄曹參軍。會祿山亂，天子入蜀，甫避走三川。肅宗立，自鄜州羸服欲奔行在，為賊所得。至德二年，亡走鳳翔上謁，拜右拾遺，出為華州」司功參軍。關輔饑，輒棄官去。客秦州，負薪採橡栗自
給，流落劍南，嚴武表為參謀，檢校工部員外郎。武卒，
崔旴等亂，甫往來梓、夔閒。大曆中，出瞿唐，下江陵，泝
沅、湘以登衡山。因客耒陽，游嶽祠，大水遽至，涉旬不
得食，縣令具舟迎之，乃得還。令嘗饋牛炙白酒，大醉，
一昔卒。

杜鴻漸
[
编辑
]

按《唐書杜暹傳》，「暹族子鴻漸，字之巽。父鵬舉，終安州刺史。鴻漸第進士，解褐為朔方判官。祿山亂，皇太子按軍平涼，未知所適，鴻漸與魏少游等謀奉迎太子。太子既至靈武，鴻漸即與裴冕等勸即皇帝位，授鴻漸兵部郎中，俄為武部侍郎，遷河西節度使。兩京平，節度荊南。代宗廣德二年，以兵部侍郎同中書門下」平章事，尋進中書侍郎。崔旴據成都，命鴻漸以宰相
往鎮撫之。鴻漸性畏怯，無它遠略，而晚節溺浮圖道，
畏殺戮，憚旴雄武，反委以政。進門下侍郎。大曆四年，
疾卒，諡文憲。

按《唐書杜亞傳》：「亞字次公，自云本京兆人。肅宗在靈武上書論當世事，擢校書郎。杜鴻漸奏署幕府。入朝，歷吏部員外郎，再遷諫議大夫，悒悒不悅。常袞惡之，出為江西觀察使。德宗立，召還，建奏疏闊，不稱旨，罷為陝虢觀察。興元初，入遷刑部侍郎，又拜淮南節度使。亞厭外官，往往不親事。貞元中罷歸，卒諡曰肅。」杜位

[

按《唐書杜佑傳》：「佑字君卿，京兆萬年人。父希望，鴻臚卿。佑以蔭補濟南參軍事，剡縣丞。嘗過潤州，刺史韋元甫署司法參軍。入為工部郎中，再遷容管經略使。楊炎輔政，歷金部郎中，以戶部侍郎判度支。盧杞惡之，出為蘇州刺史，改饒州，俄遷嶺南節度使。佑為開大衢，疏析廛閈，以息火災。召拜尚書右丞，俄出為淮」南節度使。貞元十九年，拜檢校司空、同中書門下平
章事。德宗崩，詔攝冢宰，進檢校司徒，封岐國公。後數

精於吏職，為治不皦，察數斡計賦，相民利病而上下
之。議者稱佑治行無缺。

杜黃裳
[
编辑

按《唐書杜黃裳傳》：「黃裳，字遵素，京兆萬年人。擢進士第，又中宏辭。郭子儀辟佐朔方府，入為侍御史。為裴延齡所惡，十期不遷。貞元末，拜太子賓客，遷太常卿。時王叔文用事，黃裳未嘗過其門。皇太子總軍國事，擢黃裳門下侍郎。始，德宗務姑息藩鎮，黃裳言宜鑒貞元之弊，帝嘉納之。由是平夏，剪齊滅蔡，復兩河，以」機秉還宰相，紀律設張，赫然號「中興。」元和二年，以檢
校司空同中書門下平章事，為河中、晉絳節度使，俄
封邠國公。明年卒，諡宣獻。黃裳達權變，有王佐大略，
性雅澹，未始忤物。子載，終太僕少卿。

===杜兼===
​
按《唐書杜兼傳》：「兼字處弘，中書令正倫五世孫。初，正倫無子，故以兄子志靜為後。父廙為鄭州錄事參軍事。安祿山亂，逃去，為追騎所害。兼尚幼，逃入終南山。伯父存介為賊執，臨刑，兼號呼願為奴以贖，遂皆免。建中初，進士高第，徐泗節度使張建封表置其府。積勞為濠州刺史。性浮險，尚豪侈。元和初，入為刑部郎」中，改蘇州刺史。比行，上書言「李錡必反」，留為吏部郎
中。尋擢河南尹，卒。
