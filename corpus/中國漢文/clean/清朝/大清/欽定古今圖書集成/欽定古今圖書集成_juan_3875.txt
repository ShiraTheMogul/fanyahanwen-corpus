《送夏侯參軍赴廣州》
唐·賈至
[
编辑
]

聞道衡陽外，由來鴈不飛。送君從此去，書信定應稀。
雲海南溟遠，煙波北渚微。勉哉孫楚吏，綵服正光輝。

《送李侍郎赴常州》
前人
[
编辑
]

雪晴雲散北風寒，楚水吳山道路難。今日送君須盡
醉，明朝相憶路漫漫。

《南州有贈》
前人
[
编辑
]

極浦三春草，高樓萬里心。楚山晴靄碧，湘水暮流深。
忽與朝中舊，同為澤畔吟。停杯試北望，還欲淚沾襟。

《送陸協律赴端州》
前人
[
编辑
]

越井人南去，湘川水北流。江邊數杯酒，海內一孤舟。
嶺嶠同仙客，京華即舊遊。春心將別恨，萬里共悠悠。

《酬王維春夜竹亭贈別》
錢起
[
编辑
]

「山月隨客來，主人興不淺。今宵竹林下，誰覺花源遠。」惆悵曙鶯啼，孤雲還絕巘。

《送李協律還東京》
前人
[
编辑
]

芳草忽無色，王孫復入關。長河侵驛道，匹馬傍雲山。
愁見離居夕，螢飛秋月閑。

《秋夜寄袁中丞王員外》
前人
[
编辑
]

一夕盈千念，方知別者勞。衰榮難會面，魂夢暫同袍。
片月臨階早，晴河度鴈高。應憐蔣生逕，秋露滿蓬蒿。

《送時暹避難適荊南》
前人
[
编辑
]

三歎把離袂，《七哀》深我情。雲天愁遠別，豺虎擁前程。
駐馬戀㩦手，隔河聞哭聲。相思昏若夢，淚眼幾時明。

《送楊著作歸東海》
前人
[
编辑
]

楊柳出關色，東行千里期。酒酣暫輕別，路遠始相思。

《送歐陽子還江華郡》
前人
[
编辑
]

江華勝事接湘濱，千里湖山入興新。才子思歸催去
棹，汀花且為駐殘春。

《送崔山人歸山》
前人
[
编辑
]

東山殘雨掛斜暉，野客《巢由》指翠微。別酒稍酣乘興
去，知君不羨白雲歸。

《秋夜送趙洌歸襄陽》
前人
[
编辑
]

斗酒忘言良夜深。紅萱露滴鵲驚林欲知別後思今
夕。漢水東流是寸心。

《晚過橫灞寄張藍田》
前人
[
编辑
]

亂水東流落照時，黃花滿徑客行遲。林端忽見南山
色，馬上還吟「《陶令》詩。」《奉寄皇甫補闕》
張繼
[
编辑
]

京口情人別久，揚州估客來疏。潮至潯陽回去，相思
何處通書。

《贈別王侍御赴上都》
韓翃
[
编辑
]

翩翩馬上郎，執簡佩銀章。西向洛陽歸鄠杜，回頭結
念蓮花府。朝辭芳草萬歲街，暮宿春山一泉塢。青青
柳色傍行衣，乳燕流鶯相間飛。遠過三峰臨八水，幽
尋佳賞偏如此。殘花片片細柳風，落日疏鐘小槐雨。
相思掩泣復何如，公子門前人漸疏。幸有心期當小
暑，葛衣紗帽望迴車。

《送李明府赴滑州》
前人
[
编辑
]

《渭城》寒食罷，送客歸遠道。烏帽背斜暉，青驪踏春草。
酒醒孤燭夜，衣冷千山早。去事沈尚書，應憐詞賦好。

《送客遊江南》
前人
[
编辑
]

桂水隨去遠，賞心知有餘。衣香楚山橘，手膾湘波魚。
芳芷不共把，浮雲悵離居。遙想汨羅上，《弔屈》秋風初。

《送元詵還江東》
前人
[
编辑
