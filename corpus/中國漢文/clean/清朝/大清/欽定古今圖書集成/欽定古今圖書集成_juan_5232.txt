王彥章
[
编辑
]

按《五代史王彥章傳》：彥章字子明，鄆州壽昌人也。少
為軍卒，事梁太祖，為開封府押衙、左親從指揮使、行
營先鋒馬軍使。末帝即位，遷濮州刺史，又徙澶州刺
史。彥章為人驍勇有力，能跣足履棘，行百步，持一鐵
鎗，騎而馳突，奮疾如飛，而他人莫能舉也，軍中號「王鐵鎗。」梁晉爭天下為勁敵，晉破澶州，擄彥章妻子，歸
之太原，賜以第宅，供給甚備。間遣使者招彥章，彥章
斬其使者以自絕。梁與晉夾河而軍，彥章常為先鋒。
遷汝、鄭二州防禦使、匡國軍節度使，北面行營副招
討使，又徙宣義軍節度使。被讒間謀，不見用。龍德三
年，晉取鄆州，梁人大恐，末帝乃召彥章為招討使，以
段凝為副，問破敵之期，彥章對曰：「三日。」左右皆失笑。
彥章馳兩日至滑州，置酒大會，酒半，佯起更衣，引精
兵數千擊南城，南城遂破，蓋三日矣。莊宗徹北城為
栰，下楊、劉，彥章攻之，戰敗。凝上書言彥章輕敵而敗，
趙巖等從中日夜毀之。乃罷彥章，勒還第。唐兵攻兗
州，末帝召彥章使守捉東路。是時梁之勝兵皆屬段
凝，京師祇有保鑾五百騎以屬彥章。至逓坊，戰敗，退
保中都；又敗，與其牙兵百餘騎死戰。唐將夏魯奇舉
槊刺之，彥章傷重，馬踣被擒。莊宗愛其驍勇，欲全活
之，遣明宗往諭。彥章病創，臥不能起，仰顧明宗，呼其
小字曰：「汝非邈佶烈乎？我豈苟活者！」遂見殺，年六十
一。晉高祖時，追贈太師。

王敬蕘

按《五代史王敬蕘傳》：「敬蕘，潁川汝陰人也，事州為牙將。唐末，王仙芝等攻劫汝、潁間，刺史不能拒，敬蕘遂代之，即拜刺史。敬蕘沉勇有力，善用鐵槍，重三十斤。秦宗權悉陷河南諸州，獨敬蕘不可下，由是潁旁諸州民皆依敬蕘避賊。梁太祖攻淮南，道過潁州，敬蕘供饋梁兵甚厚。太祖大喜，表敬蕘沿淮指揮使，後拜」節度使。天祐三年，為左衛上將軍。太祖即位，敬蕘以
疾致仕，卒于家

王處直
[
编辑
]

按《五代史王處直傳》：「處直字允明，京兆萬年人也。父宗，善殖財貨，富擬王侯，為唐神策軍使，子處存、處直。處存以父任為驍衛將軍，乾符六年拜義武軍節度使，乾寧二年卒。三軍以河朔故事，推處存子郜為留後，處直為都知兵馬使。光化三年，梁兵攻定州，郜遣處直率兵拒之，戰於沙河，為梁所敗。敗兵返入城逐」郜，郜出奔晉，亂兵推處直為留後。梁兵圍之，處直乃
與梁盟。梁太祖表處直義武軍節度使。梁兵攻王鎔，
鎔求救於晉，處直亦遣人至晉，願絕梁以自效。晉兵
救鎔，處直以兵五千從，破梁軍於柏鄉。其後晉北破
燕，南取魏博，與梁戰河上十餘年，處直未嘗不以兵
從。處直客李應之於陘邑，闌得小兒劉雲郎與處直，
處直養以為子，更名曰「都」，甚愛之，應之由此益橫。是
時，幽州李匡儔假道中山以如京師，處直伏甲城外，
以備不虞。匡儔已去，甲士入城，圍應之第，執而殺之。
因詣處直請殺都，處直不與。明日第功行賞，因陰疏
甲士姓名，自隊長以上，藏於別籍。其後因事誅之，凡
二十年，無一人免者，而處直終為都所殺。

王檀
[
编辑
]

按《五代史王檀傳》，「檀字眾美，京兆人也。少事梁太祖為小校。尚讓攻梁，戰尉氏門，檀勇出諸將，太祖奇之，遷踏白指揮使。後朱珍募兵東方，戰數有功。梁與蔡兵戰板橋，李重裔馬踣，為蔡兵所擒，檀馳取之，并獲其將一人。從太祖破魏內黃，遷衝山都虞候。復從朱珍攻徐州，檀獲其將一人。梁兵攻王師範，檀以一軍」破其密州，拜密州刺史。太祖即位，遷保義軍節度使、
潞州東北面招討使。王景仁敗柏鄉，晉兵圍邢州，太
祖大懼，欲自將救之，檀止太祖，請自拒敵，力戰，卒全
邢州。以功加同中書門下平章事，進封琅邪郡王。友
珪立，徙鎮宣化。貞明元年，又徙匡國。是時，莊宗取魏
博，檀以謂晉兵悉在河北，乃以奇兵西出陰地，襲太
原，不克而還，徙鎮天平。檀嘗招納亡盜，居帳下，帳下
兵亂，入殺檀。年五十八。贈太師，諡曰「忠毅。」王景仁
[
编辑
]

按《五代史王景仁傳》：「景仁，廬州合淝人也。初名茂章，少從楊行密起淮南，驍勇剛悍，行密壯之。梁太祖遣子友寧攻王師範于青州，行密遣景仁以步騎七千救之，斬友寧，以其首報行密。是時，梁太祖方攻鄆州，聞友寧死，以兵二十萬倍道而至。景仁閉壘示怯，伺梁兵怠，驅馳疾戰。戰酣退坐，召諸將飲酒。已而復戰」，
太祖登高望見之，歎曰：「吾得此人，天下不足平也。」軍
還，為潤州團練使。行密死，子渥立，景仁奔錢鏐。梁太
祖素識景仁，乃遣人召之。景仁間道歸梁，以為寧國
軍節度使。開平四年，將韓勍、李思安等兵伐趙，及晉
人戰，大敗于柏鄉，乃罷就第。末帝立，以景仁為淮南
招討使，使攻廬、壽。軍過獨山，山有楊行密祠，景仁再
拜號泣而去。歸，病卒，贈太尉。

王虔裕
[
编辑
]

按《五代史王虔裕傳》：「虔裕，瑯琊臨沂人也。少從諸葛爽，起青、棣間。其後攻黃巢，爽兵敗降巢，巢以爽為河陽節度使。中和三年，孫儒陷河陽，虔裕隨爽奔于梁。是時太祖新就鎮，黃巢、秦宗權等兵方盛，太祖數為所窘，而梁未有佗將，乃以虔裕將騎兵，常為先鋒，擊巢陳蔡間，拔其數柵。巢走，梁兵躡之，戰于萬勝戍，巢」敗而東，虔裕功為多，乃表虔裕義州刺史。秦賢攻汴
南境，太祖遣虔裕拒賢于尉氏，戰敗，太祖怒，拘于軍
中。邢州孟遷降梁，為晉人所圍，太祖遣虔裕以精兵
百人疾馳，夜破晉圍，入邢州。已而晉兵復來，遷執虔
裕降於晉，見殺。

王重師
[
编辑

按《五代史王重師傳》：「重師，許州長社人也。為人沉默多智，善劍槊。秦宗權陷許州，重師脫身歸梁，從太祖平蔡，攻兗、鄆，為拔山都指揮使，遷潁州刺史。太祖攻濮州，重師率精卒取之，累遷佑國軍節度使、同中書門下平章事。劉捍構之太祖，太祖疑之，賜死。」王瓚
[
编辑
]

按《五代史王珂傳》：瓚，重盈之諸子也。梁太祖已執珂，
自領河中節度使，以瓚為吏。瓚事梁為諸衛大將軍，
泰寧鎮國軍節度使。末帝時為開封尹。莊宗自鄆入
京師，瓚開門迎降，伏地請死，莊宗勞而起之曰：「朕與卿家世婚姻，然人臣各為主耳，復何罪邪？」已而故梁
臣趙巖等相次誅死，瓚以憂卒。

王審知
[
编辑
]

按《五代史閩世家》：「王審知，字信通，光州固始人也。父恁，世為農。兄潮為縣史。唐末群盜起，壽州人王緒攻陷固始，召潮為軍校，緒為前鋒擒殺，推潮為主。是時泉州刺史廖彥若，為政貪暴，泉人苦之，潮引兵圍彥若，逾年克之。光啟二年，福建觀察使陳巖表潮泉州刺史。景福元年，巖卒，唐即以潮為福建觀察使，潮以」審知為副使。審知為人狀貌雄偉，隆準方口，常乘白
​
馬，軍中號「白馬三郎。」乾寧四年，潮卒，審知代立。唐以
福州為武威軍，拜審知節度使，累遷同中書門下平
章事，封琅邪王。唐亡，梁太祖加拜審知中書令，封閩
王，升福州為大都督府。是時，楊行密據有江、淮，審知
歲遣使汎海，自登、萊朝貢於梁。同光三年卒，年六十
四，諡曰「忠懿。」鏻即皇帝位，追諡為《昭武孝皇帝》，廟號
太祖。

王延彬
[
编辑
]

按《十國春秋》：「閩王延彬，天祐初，太祖承制，加平盧節度使，權知泉州軍州事，二年實授。開平三年加金紫光祿大夫，轉右僕射，封琅邪郡開國男，尋轉司空。四年加雲麾將軍。乾化二年授特進階，加檢校太保，進封開國伯。五年加檢校太傅，權知泉州刺史。四年加檢校太尉。延彬任泉州，前後歷二十六年，會得白鹿」紫芝，僧浩源以為王者之符，延彬由是漸驕縱，密遣
使浮海貢梁，求泉州節鎮。事覺，太祖黜延彬歸私第，
卒，贈雲州節度使，葬雲臺山，閩人謂之「雲臺侍中。」王彥復
[
编辑
]

按《十國春秋》：閩王彥復，太祖從弟也。景福初，彥復為
都統，同太祖攻范暉于福州，親犯矢石，指授方略，遂

按《十國春秋》，閩王定簡，世為汴州人。祖護，父伸，始遷

王仁繢
[
编辑
]

按《十國春秋》：「閩王仁繢，福唐人。少有志操。太祖聞其賢，命試大理評事，仁繢固辭，隱居龍山，終其身。」王綰
[
编辑
]

按《十國春秋》，吳王綰，合肥人。仕太祖為漣水防遏使，
遷海州副使。天復中，青州王師範以沂、密內叛，乞師
太祖。太祖遣臺濛及綰將兵援之，已拔密州，將進攻
沂州城，諜者偵城中盡偃旗息鼓，綰謂「此不可擊也。」諸將堅欲攻之，綰不能止，乃設伏林間以待。頃之，攻
沂者果不克，敵兵乘勢追之，綰伏發，得以濟師。武義
元年，加「鎮東大將軍」，已遷百勝軍節度使，卒。

王潛
[
编辑
]

按《十國春秋》，「吳王潛，廬州人。初居太祖莫府，及事高祖，歷官左司郎中，典選事。時喪亂之後，官失其守，甲簿湮落。潛雍容款接，坐客常滿，隨才而使，人人自以為得。」徐知誥為相，掄選有序，潛之力也。

王安
[
编辑
]

按《十國春秋》，吳王安，廬州廬江人。少事太祖，隸戲下。
太祖常臨戰，升高冢望敵，安捧唾壺侍側，左右皆注
目前視，忽有武士持槊徑趣，太祖莫能禦者。安置壺
于地，引弓射之，一發而殪，徐納弓弢中，復捧壺立，色
不變。太祖喜，撫其背曰：「汝器度如此，它日必富貴。」積
功至袁州刺史。南唐禪代，用為百勝軍節度使，更賜
名會。昇元五年卒，年七十有三。

王建
[
编辑
]

按《五代史？前蜀世家》：「王建，字光圖，許州舞陽人也。為人隆眉廣顙，狀貌偉然。少無賴，以屠牛盜驢販私鹽為事，里人謂之賊王八。」後為忠武軍卒，稍遷隊將。黃
巢陷長安，忠武軍將鹿晏弘以兵八千屬楊復光討
賊，復光以其兵為八都，都將千人，建為一都頭。已而
晏弘東歸，建奔於蜀，僖宗以屬田令孜，令孜以為養
子。僖宗還長安，使將神策軍宿衛。光啟二年，幸興元，
以建為清道使。已至興元，令孜為西川監軍，楊復恭
為軍容使，出建璧州刺史。令孜使人招建，建馳至鹿
頭關，擊取漢州，攻彭州。文德元年，分卭蜀、黎、雅為永
平軍，拜建節度使。建攻成都，入城，以令孜為監軍，既
而殺之。大順二年，唐以建為檢校司徒、成都尹、劍南
西川節度副大使、知節度事。四年，攻東川，破之。於是
並有兩川之地。天復元年，拓拔思敬降，并有山南西
道。三年，唐封建蜀王。四年，唐改元天祐，建隔絕不知，
仍稱天復六年，并有三峽。七年，梁滅唐，建會兵討梁，
四方皆不應。九月己亥，建乃即皇帝位。武成元年正
月，祀天南郊，大赦，改元。永平三年，立宗衍為太子。通
正元年十月，大赦，改元。十二月，又改明年元曰天漢，
國號漢。天漢元年十二月，大赦，改明年元曰光天，復
國號蜀。光天元年六月，建卒，年七十二。太子立，去宗

编辑
]

按《十國春秋》，前蜀王宗弁，本姓鹿，名弁，高祖賜姓，名
以為子。初從高祖與宗瑤、宗弼、宗侃同入西川，積功
至蜀州刺史。一日稱疾，請罷歸成都，高祖疑其矜功
觖望，加檢校太保，固辭不受。宗弁常謂人曰：「廉者足而不憂，貪者憂而不足。吾小人致位至此足矣，豈可求進不已乎？」高祖嘉其志而許之，竟獲善終。

王宗本
[
编辑
]

按《十國春秋》，前蜀王宗本，本姓謝，名從本，事陳敬瑄，
為資簡都制置應援使。高祖攻成都，從本殺雅州刺
史張承簡，舉城來降，高祖錄其功，及敬瑄平，養以為
子，改姓名曰王宗本。久之，擢渝州刺史。無何，罷官歸
成都。天復三年，宗本請出兵取荊南，高祖署宗本開
道都指揮使，將兵下峽，降夔州刺史侯矩，遂定夔、忠、
萬、施四州，已而遷武泰留後。武泰軍舊治黔州，宗本
以其多瘴癘，請徙涪州，高祖因許焉。

王宗綰
[
编辑
]

按《十國春秋》，前蜀王宗綰本姓李，名綰。乾寧元年與
王釗等同為高祖義兒，更今姓名，累官知蜀州。高祖
破東川，命宗綰分兵徇昌、普等州，頃之領武定軍節
度使。高祖與岐構兵，宗綰充馬步都指揮使，豫城西
縣為安遠軍，利州一面恃此以為捍蔽。未幾，詔兼中
書令，復充北路行營都制置使，以攻秦州。已而敗岐
兵于金沙谷，擒岐將李彥巢。再克成州，擄刺史李彥
德。隨陷秦州，拔鳳州，高祖因遂有秦、鳳、階、成之地，宗
綰實為首庸焉。通正元年，又領東北面都招討，將兵
​
伐岐，師出大散關，大破岐兵，進取寶雞，圍鳳翔，岐人
為之震恐。光天時，與王宗瑤等同受顧命輔政。後主
嗣位，封臨洮王。

王宗儒
[
编辑
]

按《十國春秋》，前蜀王宗儒本姓楊，名儒，彭城人，事陳
敬瑄為大將。高祖攻卭州，敬瑄遣儒將兵三千，助刺
史毛湘守之。湘出戰屢敗。儒登城見高祖兵彊甚，歎
曰：「唐祚盡矣！王公治眾嚴而不殘，殆可以庇民乎！」遂
帥所部出降。高祖錄為假子，更其姓名曰王宗儒。

王宗朗
[
编辑
]

按《十國春秋》，「前蜀王宗朗，本姓金，名師朗，金州人也。唐昭信節度使馮行襲據金州，師朗居戲下為親校。及王宗賀攻行襲，行襲奔均州，師朗遂以城降。高祖嘉其功，賜姓名，補金州觀察使，割渠、巴、開三州以隸之。居三月，金州復為行襲所取，宗朗不能守，奔成都。已而蜀兵又克金州，仍以宗朗為刺史，俄改金州為『雄武軍』」，宗朗領本軍節度使兼中書令。後主時，以罪
削奪官職，復其姓名，執歸成都，久之病卒。

王宗渥
[
编辑
]

按《十國春秋》，前蜀王宗渥，本姓鄭，名渥，京兆人也。初
事高祖為牙校。高祖攻成都，令渥詐降，以覘城中虛
實。陳敬瑄為「人戇而愚，遽納其降，署渥大將，且使守陴，以拒我師。已而乘間脫歸，悉得成都聲息。」高祖嘉
賞之，列為義子，賜姓王氏，名宗渥。咸康元年，為魏王
繼岌所殺。

王宗範
[
编辑
]

按《十國春秋》，前蜀王宗範，不知何地人。母張氏，故高
祖之後宮也。宗範初隨母歸高祖，冒母姓為「張」，高祖
畜為子，賜今姓名。從高祖討陳敬瑄，累立戰功，已而
封夔王。長和蠻入寇𥟖州，宗範率眾敗之，西南震恐，
人人懾服。後數年卒。

王宗瑤
[
编辑
]

按《十國春秋》，前蜀王宗瑤，高祖義子也。高祖圖成都
時，宗瑤與王宗弼等俱西上，破鹿頭關，拔漢州，陷德
陽，宗瑤之功為多，官茂州刺史，將兵攻彭州，敗楊晟
于城下。未幾，徙簡州。乾寧二年，三鎮犯關，宗「瑤帥師赴難，屯兵於綿州，軍容甚盛，國人莫不嘖嘖稱之。高祖即皇帝位，詔宗瑤兼中書令。永平五年，充東北面」招討使，攻鳳州，遂克其地。已而受遺詔輔政。後主立，
論功封臨淄王。

王宗訓
[
编辑
]

按《十國春秋》，前蜀王宗訓，本名茂權，初為刁子都虞
候。高祖攻彭州，茂權斬楊晟于陳前，論功受上賞賜
名「宗訓」，與諸子比。永平中，累官武泰軍節度使，鎮黔
州。宗訓恃恩貪暴，驕縱踰制，不奉詔輒回成都，多所
邀求。高祖見宗訓大怒，命衛士撲殺之。

王宗勉
[
编辑
]

按《十國春秋》，前蜀王宗勉，本姓趙，名章，從楊晟為內
外都指揮使。彭州之圍，章率眾出降，高祖與李綰等
同錄為子，更其姓名曰「王宗勉。」王宗鍔
[
编辑
]

按《十國春秋》，「前蜀王宗鍔，少饒技勇，從高祖入西川，錄為假子。後主嗣位，歷官定遠軍使。乾德末，充招討馬步使，帥二十一軍屯洋州，以備唐師。」後不知所終。

王宗儔
[
编辑
]

按《十國春秋》，前蜀王宗儔，高祖養子也。累有戰功，起
家為排陳使。武成時，授秦州留後，已而授天雄軍節
度使，兼侍中。乾德三年，擢山南節度使，充西北面都
招討、行營安撫使，將兵伐岐。後主荒淫日甚，宗儔憂
宗社不祀，密與王宗弼約為伊霍之舉，謀廢立。宗弼
猶豫未決，宗儔憂憤卒。

王宗夔
[
编辑
]

按《十國春秋》，「前蜀王宗夔，故高祖養子也。初隸高祖戲下為親校，進拔龍州，殺刺史田昉有功，累官至兼中書令。高祖彌留之際，與王宗弼、宗瑤、宗綰等同受遺詔輔政。後主即位，封琅邪郡王。」王宗裔
[
编辑
]

按《十國春秋》，「前蜀王宗裔，亦高祖養子，歷官兼中書令。後主即位，封琅邪郡王。」王宗弼
[
编辑
]

按《十國春秋》，前蜀王宗弼，本姓魏，名弘夫，高祖錄為
「假子」，更今姓名。楊守厚之攻梓州也，高祖遣華弘等
救顧彥暉，謀因犒師，執之，宗弼乃以密語泄之彥暉，
高祖殊不為意，待之如初。已而從高祖攻東川，為東
川兵所擒，彥暉念舊恩，畜為子。及彥暉敗，復自歸于
高祖，積功至兼中書令，充北面行營招討使。高祖病
且劇，以宗弼沉靜多謀，召為馬步都指揮使，同諸臣
受遺詔。後主繼立，命宗弼守太師、兼中書令，判六軍
輔政。已，又封鉅鹿王，進封齊王。是時，後主不親政事，
內外遷除，皆自宗弼出，納賄行私，上下咨怨。唐兵入
境，會王宗勳等師至，三泉，望風退走。後主詔宗弼守
​
綿谷，且令誅宗勳等。宗弼反與宗勳等合謀送款，魏
王繼岌數其不忠，族誅焉。

王宗信
[
编辑
]

按《十國春秋》：前蜀王宗信，高祖假子也，積功至左神
勇軍師。高祖時無顯績，後主嗣位，命宗信與王宗昱、
宗晏為三招討，副王宗儔以伐岐，進屯威武城，厲兵
秣馬，竟無所成功而還。

王宗賀
[
编辑
]

按《十國春秋》，前蜀王宗賀，不知其所自起。事高祖，賜
姓名，以為子，官指揮使。天復二年，山南西道節度使
王宗滌以罪死，高祖命宗賀權與元留後。居數年，將
兵擊馮行襲于金州，所向克捷。永平元年，與王宗祐
等充招討使，伐岐，青泥嶺之戰，師盡殲焉。俄加中書
令。會太子元膺之變，宗賀與有定亂功。久之卒。

王宗紹
[
编辑
]

按《十國春秋》，前蜀王宗紹，高祖養子也。歷官至左金
吾大將軍。高祖與岐王茂貞交惡，命王宗祐等為三
招討使以伐之，而以宗紹為之副，帥步騎兵十二萬
人，軍容甚盛。已而青泥嶺之役，大軍敗績，竟無成功。
後數年，復會劉知俊圍鳳翔，隨召還。未詳其所終。

「東北面第二招討以伐岐。」王宗鐸

按《十國春秋》，「前蜀王宗魯，高祖養以為子，從入成都。已而攻拔龍州，殺刺史田昉。久之，授利州團練使。太子元膺之變，宗魯發兵陳西毬場門，頗有平亂功。永平末，置武興軍于鳳州，宗魯遂領節度使。」王宗昱
[
编辑
]

按《十國春秋》，前蜀王宗昱，不知其世系所出，《高祖錄》
為假子，賜姓名，與諸子等。歷官天雄節度使同平章

東遊，會唐師入寇，以宗昱領招討使，逆戰於三泉，為

王宗勳
[
编辑

按《十國春秋》，「前蜀王宗勳事高祖為義子，賜姓名。乾德中，後主東巡，命宗勳為清道指揮使。已而唐師入寇，與王宗儼、宗昱為三招討以拒之。三泉之敗，遂降干唐。未幾，為魏王繼岌所殺。」王宗晏
[
编辑
]

按《十國春秋》：「前蜀王宗晏，高祖時賜姓名為子，官永寧軍使。乾德二年，同王宗儔伐岐，師次威武城，無功而還。」王環
[
编辑
]

按《十國春秋》，楚王環，為人勇悍，善兵法，從武穆王數
征討有功。乾化中，授岳州都指揮使。時刺史許德勳
將水軍巡邊，夜分南風暴起，環乘風趣黃州，以繩登
城，徑奔州署，執吳刺史馬鄴，大掠而回。德勳曰：「鄂州將邀我，奈何？」環曰：「我軍入黃州，鄂人不知，奄過其城，彼方自救不暇，安敢邀我？」乃展旗鳴鼓，揚帆大進。鄂
人殊出不意，果恇擾不敢逼。天成三年，改六軍副使，
與荊南戰于劉郎洑，荊南大敗，請和。武穆王讓環不
即取荊南，環曰：「江陵在中朝及吳、蜀之間，四戰之地也，宜存以為吾扞蔽，安可徒快一時心，而自失唇齒之形乎？」王以為識時勢，大悅之。環前後凡六破吳兵，
再破荊南兵，聲震一時。環每戰身先士卒，與眾同甘
苦，常置鍼藥在左右。戰罷，索傷者于帳前，親為傅治。
士卒隸戲下者相賀曰：「吾屬得死所矣！」故所向克捷。
不數年卒。子贇。

王仝

按《十國春秋》：「楚王仝，湘鄉人，武穆王時，為江華指揮使，與蠻將戰死。」王元
[
编辑
]

按《十國春秋》：楚王元字文元，桂林人，隱居不出，工于

王定保
[
编辑
]

按《十國春秋》，南漢王定保，南昌人。舉唐光化三年進
士第，南遊湖湘，不為馬氏所禮。已而為唐容管巡官，
遭亂不得還。烈宗招禮之，辟為幕屬。及高祖欲稱帝，
憚定保不從，先遣定保出使荊南。及即位而定保回，
知其心未善也，預使倪曙迎勞之，且告以建國事。定
保曰：「建國當有制度，吾入南門，清海軍額猶在，其不​見笑于四方乎？」高祖笑曰：「朕備定保久矣，而不思此，宜其譏也。」大有初，官寧遠軍節度使。十三年冬，代趙
損為中書侍郎、同平章事，不踰年卒。定保善文辭，高
祖嘗作《南宮》，極土木之盛，定保獻《南宮七奇賦》以美
之，一時稱為絕倫。所著《摭言》十五卷。

王宏
[
编辑
]

按《十國春秋》：南漢王宏，少穎異，工詩賦。乾亨時，由進
士官翰林院學士承旨，珥筆左右，甚被親信。會白虹
化為白龍，見三清殿，宏為《白虹化白龍賦》上之。文采
鉅麗，辭旨暢洽。高祖悅改元白龍，深加欣賞。已又譔
《昭陽殿賦》，亦見稱于時。

王詡
[
编辑
]

按《十國春秋》，南漢王詡，南海人也。及高祖改縣名，遂
為咸寧人。乾亨初，舉進士，拜中書舍人。會白龍見南
宮，詡進《白龍頌》，文采斐然。大有七年，昭陽殿成，詡又
著《昭陽殿賦》上之。是時獻賦者數十百人，稱詡為第
一。每賜予稍緩，詡必揚言曰：「吾賦字字作金聲，何受賜之晚也。」其自負如此。

王帽仙
[
编辑
]

按《十國春秋》：王帽仙，蜀人也，失其名。居常出入闤闠，
為人飾敝冠，號曰「王帽子。」性落魄，忘爾我，暮則臥涪
州天慶觀。一夕間暴死，道士斂貲葬之。甫匝月，王自
果州貽書來，始知其為尸解。
