職方典第六卷

京畿總部藝文二
〈詩詞〉

宮中絕句　　　　　　　　　金章宗
[
编辑
]

五雲金碧拱朝霞，樓閣崢嶸帝子家。三十六宮簾盡
捲，東風無處不楊花。

書龍德宮八景亭　　　　　密國公璹
[
编辑
]

刻桷朱楹墮紺紗，裙腰草色趁階斜。誰知剝落亭中
石，曾聽宣和「《玉樹》花。」宮詞　　　　　　　　　元歐陽原功
[
编辑
]

麗正門當千步街，九重深處五雲開。雞人三唱《萬官
集》，應制須迎學士來。

海子上即事　　　　　　　　　盧亙
[
编辑
]

馳道塵香散玉珂，彤樓花暗弄雲和。光風已轉瀛洲
草，細雨微添太液波。月榭管絃催樹發，水亭簾幕受
寒多。少年易動傷春感，喚取青霞對酒歌。

團殿　　　　　　　　　葛邏祿迺賢
[
编辑
]

臺殿有殊狀，團團海月涼。隔簾聞鳳管，秉燭奏《霓裳》。
銅爵晨霞眩，金盤夕露瀼。仙人不復返，愁殺海生桑。

宮詞　　　　　　　　　　　　前人
[
编辑
]

千官鵠立五雲間，玉斧參差擁畫闌。今日君王西內
去，安排天仗趣儀鸞。

又　　　　　　　　　　　　　前人
[
编辑
]

廣寒宮殿近瑤池，千樹長楊綠影齊。報道夜來新雨
過，御溝春水已平堤。

憶舊　　　　　　　　　　　　前人
[
编辑
]

秋水清無底，涼風起綠波。錦帆非昨夢，玉樹憶清歌。
帝子吹笙絕，漁郎把釣多。磯頭浣紗女，猶恐是宮娥。

粧臺詩　　　　　　　　　　　前人
[
编辑
]

廢苑鶯花盡，荒臺燕麥生。韶華如逝水，粉黛憶傾城。
野菊金鈿小，秋潭玉鏡清。誰憐舊時月，曾向日邊明。

宮詞　　　　　　　　　　　　史學
[
编辑
]

寶帶香褠水府仙，黃旂綵扇九龍船。薰風十里瓊華
島，一派歌聲唱《采蓮》。

宮詞　　　　　　　　　　　　朱瀾
[
编辑
]

太液芙蓉上下天，秋波澹澹白生煙。采蓮宮女分花
了，笑把蘭篙學刺船。

直延春閣　　　　　　　　　　張翥
[
编辑
]

蓬萊海上第三山，仙掌雲間十二槃。雞樹煙深殊窅
窱，鳳樓天近自高寒。銅壺傳漏聲相應，紫詔封泥墨
未乾。願祝君王千萬壽，坐施雄斷濟艱難。

輦下曲　　　　　　　　　　　前人
[
编辑
]

爐香夾道涌祥風，梵輦游城女樂從。望拜綵樓呼萬
歲，柘黃袍在半天中。

興聖殿進史作　　　　　　　黃清老
[
编辑
]

瑤編初進侍明光，日麗龍池晝刻長。堤柳染成春水
色，宮花併入御爐香。金壺灑露層階滑，玉碗分冰廣
殿涼。矇瞍似知天意喜，鳳笙新奏《五雲章》。

海子上有期　　　　　　　　　前人
[
编辑
]

金堤晴日共鳴鑣，傾蓋松陰待早朝。數盡荷花數荷
葉，碧雲移過水東橋。

京師守歲　　　　　　　　　傅若金
[
编辑
]

日月催時序，乾坤隔晦明。殘年萬里夢，今夕幾人情。
久客煩朋友，雙親倚弟兄。深慚須薄祿，不得謝浮名。

登崇文閣　　　　　　　　　　陳璉
[
编辑
]

「崇巍乎高哉！崇文之閣兮，吾不知其幾百尺，突兀直倚蒼冥中。」雕簷高飛近曉日，瓊窗洞啟來清風。前瞻
兮帝闕，下顧兮辟雍。京畿鬱兮千里，五雲近兮九重。
太行西來兮迤𨓦，居庸北拱兮巃嵷。峰巒遠近共環
峙，削出朵朵金芙蓉。是中奇勝甲天下，何況此地名
儒宗。圖書浩瀚紛莫數，文光夜吐猶晴虹。漢家天祿
「不可以復見，幸喜斯閣之高崇。值校文之多暇，日徙倚而從容。愛扶輿磅礡之奇秀兮，呼吸盡使歸心胸。闌干笑拍飛鳥上，豪氣不減陳元龍。俯視十二衢，車​馬塵濛濛。欲招太白老，更約東坡翁。葡萄酒傾瑪瑙甕，日醉三百玻璃鍾。人間亦自有勝境，何必飛度扶桑東。」觀內廄洗馬　　　　　　　　朱德潤
[
编辑
]

《黃雲灑雨》沙埸秋，灘高水平凝不流。曉霜襲透蒼駝
裘。圉人浴馬津水頭。綠驃連錢雙驊騮，日光射波脂
膩浮。青絲脫鞚黃金鉤，輕爬短刷濕未收。三花剪鬣
平且柔，雲駿氣將無儔。束芻斗豆豈馬羞，茫茫豐
草生林丘。霜蹄何為踏長楸，振鬣一躍期天遊。

御溝春日三首　　　　　　　馬祖常
[
编辑
]

御溝流水曉潺潺，直似長虹曲似環。流入宮牆才咫
尺，便分天上與人間。

春波十頃碧琉璃，白日樓臺照影時。好為畫船都載
酒，半酣西望碧參差。

水南沙路雨清塵，桃李花開蛺蝶春。三月京華寒食
近，東風十里酒旗新。

丁卯上京絕句　　　　　　　　前人
[
编辑
]

山雨晴時已是秋，苑中行殿日華浮。長楊十里旌旗
宿，不使飛霜入畫樓。

鼇峰　　　　　　　　　　　　前人
[
编辑
]

視草堂深白晝遲，瀛洲仙子到來時。閣鈴不響文書
靜，相對鼇峰日賦詩。

又題史館　　　　　　　　　　前人
[
编辑
]

畫省真仙居，華屋映丹樹。青石倚闌干，松髮沐雲霧。
綺疏刻連錢，承塵繪翔鷺。中有「《河漢》文」，夜深寶光聚。
玉函黃金鑰，太史自侍御。河上一豎儒，咿唔誦章句。
偶趨彤庭詔，詞林邇天路。雖樂文雅懿，終慚紬繹誤。

燕都　　　　　　　　　　　　宋褧
[
编辑
]

萬戶千門氣鬱蔥，漢家城闕畫圖中。九關上徹星辰
界，三市橫陳錦繡叢。玉盌金盃丞相府，珠幢寶剎梵
王宮。遠人縱睹爭修貢，不用雕戈塞徼通。

又　　　　　　　　　　　　　前人
[
编辑
]

豪傑紛紛白玉京，汗顏血指戰功名。九重見帝多因
鬼，萬里封侯不用兵。肥馬塵深心獨苦，鮒魚波涸事
難平。西山小隱煙蘿暗，依舊春犁趁雨耕。

又　　　　　　　　　　　　　前人
[
编辑
]

風物鮮妍飾禁城，豪家戚里競留情。花圍錦幄清明
宴，香擁珠樓乞巧棚。叱撥馬搖金轡具，帡幪車颺繡
簾旌。他年定擬持鉛槧，細數繁華紀太平。

又　　　　　　　　　　　　　前人
[
编辑
]

流珠聲調錦琵琶，韋曲池臺似館娃。羅袖舞低楊柳
月，玉笙吹綻牡丹花。龍頭瀉酒紅雲灔，象口吹香綠
霧斜。卻笑西鄰蠹書客，牙籤緗帙費年華。

燕城懷古　　　　　　　　　劉彥昺
[
编辑
]

廣寒宮殿玉為樓，萬歲鰲峰壓九州。番國梵僧青鼠
帽，天魔宮女綵龍舟。鉤陳蒼闕山南拱，太液紅橋水
北流。惟有盧溝溝上月，年年鴻鴈不勝秋。

燕都　　　　　　　　　　　　宋本
[
编辑
]

拋卻漁竿滄海邊，拂衣來看九重天。畫闌幾曲橋如
月，綠樹千門雨似煙。南國佳人王幼玉，中朝才子杜
樊川。紫雲樓上如澠酒，孤負春風二十年。

又　　　　　　　　　　　　　前人
[
编辑

繡錯繁華遍九衢，上林詞賦漢西都。朱門細婢金條
脫，紫禁材官玉鹿盧。萬里星辰開上界，四朝冠蓋翊
皇圖。東鄰白面生紈綺，笑殺揚雄臥一區。

又　　　　　　　　　　　　　前人
[
编辑
]

盧溝曉月墮蒼煙，十二門開日色鮮。海上神山無弱
水，人間平地有《鈞天》。寶幢珠珞瞿曇寺，豪竹哀絲玳
瑁筵。春雨如膏三萬里，盡將《嵩祝》頌堯年。

又　　　　　　　　　　　　　前人
[
编辑
