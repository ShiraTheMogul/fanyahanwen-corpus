金鋐
[
编辑
]

按《衢州府志》：「金鋐，字士珫，實仲子。鄉舉知蓬州。志識高遠，文學優裕。治蓬九載，政成清操如一日。給由便歸田里，日以詩文自娛。同宗一門疫死二十餘人，無敢視者，公獨周旋其閒，為之殯埋。卒之日至，無以為殮。其果所謂孝廉者歟。」徐存禮
[
编辑
]

按《衢州府志》：「徐存禮嘗於道傍亭中得一青囊，啟視之，白金也。㩦歸，陰置之密室，復往亭候之，適有三人徬徨而來，問之，曰：『某皆徽人，往遂安市杉木，道此少憩，遺囊於此，內白金近百兩，皆稱貸於人者，不獲有死而已。存禮審其實，遂偕抵於家，出以還之。三人羅拜，請任其取，弗聽，舉一錠酬之。存禮曰：『吾欲之，當盡匿，顧乃取其少乎』』？」固弗受。人皆以為義。

宋𤣱
[
编辑
]

按《衢州府志》：「宋𤣱，字玉成，貢生，刑部主事，澂江通判。穎悟不凡，樂易有守，刑部治獄詳明，未幾制歸，哀毀致病十載，始克起復，依例改外任雲南澂江。適王師征勦，命師𤣱，連歲督餉，不憚勞勩。繼有土官爭襲，賂公以白金三百兩卻之，以實聞。民有訟水利者，久不直，釐正之以息其爭。秩滿宜陞歸，志已決。居家曲盡」友愛。周人危急，邑東要津，民病涉𤣱與侍郎吾紳輩
建「通濟橋」及橋亭，至今民賴焉。

===吾琰===
​
按《衢州府志》：「吾琰，字廷瑞，孝友誠篤，處己接物，率真無偽。饒寇之變，琰以義民協謀調濟，邑賴以安，居鄉務成人美，有紛難即為排釋，無不感服。昆弟業已分貲，因兄老姪幼，兼為總理，置產俱與均分。繼分基址，曰『姪猶子也，多與不計。其尚義每如此。晚築室於文山之麓，以山水自娛，日與從姪翕游息其閒。夢漁棠』」凌時過訪之，書《陽塢遊跡》以名其堂，每稱為仁厚君
子。

方景溫
[
编辑
]

按《衢州府志》：「方景溫，沐塵里人，祠部郎應祥六世祖父童，以人才舉薦，任福建監運司運判。省父道，拾遺金三百兩，待失主不可得，義不欲以自利，為市槥與衣衾，施不能葬者。施日浸廣，所獲遺金不足，父所與三百金繼之，已又折產。繼之至老不倦，沒而身無以殮也。」周世衍
[
编辑
]

按《嚴州府志》：「周世衍，淳安人。忠誠醇厚，有大節，事繼母邵備極孝謹。有異母弟，析產任所願取，家貧，好義更篤。嘗夜行，得應某道遺三十金，蚤起訪其人還之。事聞，縣令蕭元岡重其行，旌曰：『天庭友孝淳安。茅坤有贊。詳見大參徐應簧狀』。」徐友文
[
编辑
]

按《溫州府志》：「徐友文，字彥章，樂清人。嗜義好施。有張堂者，苦逋累鬻妻，途遇文，即代贖之。歸語其妻，鄭更益以貲為女買媵，詢係良家，即還之，不復索價。家落貧困，治圃以活，處之泰然。」鄭瑞
[
编辑
]

按《溫州府志》：「鄭瑞，永嘉人。嘗掌鄉賦，里人貧不能輸者，輒代輸之。上書當道，請毀淫祠，興社學，以壽終。」王勳
[
编辑
]

按《溫州府志》：「王勳，字景銘，永嘉人。弱冠即有志聖學，精思力踐，有聲庠序。錄先正格言及所自得者，曰《檢身集》，用自鏡考。孝友天至，推誠秉禮，雖隱微造次，肅然端飾。年三十二卒。邑士摭其遺行，上雷、阮二督學，表其廬曰『善行』。」趙秀裒
[
编辑
]

按《溫州府志》：「趙秀裒，字盤東，樂清人。性惇厚，居鄉恂恂，每有義舉，慷慨率先。捐資修壽寧橋，建文昌祠，施田二十畝，以供祀事。敬士恤貧，三舉大賓，壽八十三。」史君實
[
编辑
]

按《溫州府志》：「史君實，字二酉。年六十猶具慶侍養，菽水及調藥餌悉躬為之，雖盛暑必冠襪以進。有橫逆加者，置弗問，曰：『吾家二百年未嘗隻字煩有司也』。」為
學一宗考亭，因以尊朱名其子。著有《物格說》《蘭齋小
言》。

王至亮
[
编辑
]

按《溫州府志》：「王至亮，字昭采，永嘉人。太學生。嗜圖史，工翰墨，以博雅稱。性至孝，以兄早世，不忍離二人側，遂不求仕進。居鄉樂善好施，凡恤貧賑饑，掩骼施藥，築橋梁塘堰之關於鄉土者，歲無虛日。鄉人迄今頌德不置云。以子欽準仕封惠州府通判。」王至兗
[
编辑
]

按《溫州府志》：「王至兗，字昭信，永嘉人。太學生。性行端直，好施恤貧。永嘉場濱海，塘路、橋嶺、陡門諸費，率數千金，皆力為修築。郡守施鵬最器重之，嘗造廬致禮焉。子詠，邑庠生。孫澐，孫國學生。俱以詩名。有《竹居集》《自怡集》諸刻。」宣鐸
[
编辑
]

按《溫州府志》：「宣鐸，樂清縣蒲坂人。孝友樂施。里有餓者，常裹飯餉之，割己產三之一，專以賙所親。楠溪有接莆嶺，極險峻，人往往墮死。鐸捐金百餘鑿之，遂為康途。」方輶
[
编辑
]

按《溫州府志》：「方輶，字孟夙，樂清人。十二，補弟子員。平生無疾言遽色。友人屠希顏無子，妾有孕，妻悍不能容顏以托，輶即避書舍居之，候長乃還。屠門人稱古君子。」蔡思權
[
编辑
]

按《溫州府志》：「蔡思權，平陽人。任質好義，家中落無變節。一日，拾金耳環於路，詢其人，還之。或哂之，權曰：『我雖貧，肯妄取耶』？」侯敬
[
编辑
]

按《溫州府志》：「侯敬，字明正，樂清人。年十三入邑庠，事繼母至孝，妻沒不再娶。以兩子廷訓、廷誡托于庶母黃，下帷七年不出。以貢上國學，祭酒劉異之，目為真儒。廷訓、廷誡皆領鄉薦。次年，廷訓成進士，敬除州判，尋封子官。大禮事起，二子俱下獄，禍且不測，敬誡家人曰：『勿泣，為臣死，忠職耳』。其定養如此。前後母黨親」及鄰里無歸者，皆衣食之終身寒冬設杯醪井傍，以
煦冒寒而汲者。壽八十二。

===張珙===
​
按《溫州府志》：「張珙，字存誠，泰順人。讀書好禮，嚴毅誠篤，教子姪必以正。鄉人不衣冠，不敢見，有為不善者，皆曰願。無為張東山所知。屢舉蜡賓，士紳重之。」吳亨
[
编辑
]

按《溫州府志》：「吳亨，字惟嘉，永嘉人，表臣八世孫。兄惟安早卒，奉嫂氏惟謹，擇婿嫁其女。友沈宗潛貧病，購醫治之。及不救，為營喪葬。自奉儉素，教五子皆成立，築室匾曰『西湖書隱』，詩名《竹庵集》。」華一鵬
[
编辑
]

按《溫州府志》：「華一鵬，字天池，平陽人。由太學授京衛經歷。閩南鎮有婦以夫亡，鬻身為婢，鵬以三十金買之，婦至，有慼色，詢知其姑，無倚也。鵬曰：『忍以予之故，使其姑失所乎』？焚其券遣還。晚年尢慕義不勝紀。三舉蜡賓，壽八十。」李孟奇
[
编辑
]

按《溫州府志》：「李孟奇，瑞安人。家殷，好施予，郡邑廨舍學宮，多所營造。四邑民告饑，出粟以賑，計前後出粟萬餘、金千餘，設義塾、義倉、義塚、義渡。郡邑屢上其事，朝遣行人黃恕賚璽書勞羊酒，旌其門曰『義門』。」李思鎮
[
编辑
]

按《溫州府志》：「李思鎮，字秉遠，樂清人。性至孝友，樂德好施，以不逮力事父母，終身孺慕。嘗以意追二親像，人謂逼肖，蓋冥感云。微時拾遺道上，候其人還之。早歲失耦，矢不再娶，撫諸從如己子。以子光春貴，累封雲南道監察御史。兩受華綸，巾履翛然。壽八十四。」梁宗律
[
编辑
]

按《溫州府志》：「梁宗律，字皋東，樂清人。天性篤孝，執親喪哀毀逾禮，寢食不離衰絰。鄰居夜火，倉卒向火拜，火遂熄。嗜義樂施，嘗鬻產以濟人急。邑令聞其善，微行造之，見內外肅然，為之嘉歎。舉蜡賓。後以子一孚貴，贈知縣。」石安民
[
编辑
]

按《溫州府志》：「石安民，字惠夫，瑞安人。讀書秉禮。鍾令沔延為申明亭長，有大事必令剖決。嘗委視三港稅務，正稅外無纖取。郡守何文淵深加器重，凡有興革，輒就諮議。」戴幵
[
编辑
]

按《金華府志》：「戴幵，字善甫，種德尚義。嘗捐己田五百畝，置義莊，以給養宗族親姻之貧乏者。又設義塾以教訓其子弟。當時殿講御史盧虙為撰記，子孫食報者奕奕不衰。」葉伯仕
[
编辑
]

按《處州府志》：「葉伯仕，字行可，麗水人。邑廩生。博覽書史，學行兼優。丙午赴科，途遇商人發麻被拐，貨轄擔夫賠償，貧無所措。父子俱思自溺，仕出己資斧五兩代還，得全兩命。既而治病在省，夢神人增壽一紀。」詹應霆
[
编辑
]

按《處州府志》：「詹應霆，字體震，松陽人。布衣能文，纂修家乘。為府掾時，有無辜受冤者，府尹欲置極刑，為力白乃免。斯時尚乏嗣，忽夢神人告曰：『汝能活人，陰德不少，錫爾嗣，且錫爾程』。後任廣東雷鄉親，見子孫食餼，壽至耋。」李繼澤
[
编辑
]

按《處州府志》：「李繼澤，字霽宇，縉雲人。父為東浙素封，因得澤，晚遂盡散其積，家徒壁立。及長，竭甘旨，不以艱難傷父心。父逝，哀毀絕粒，祭葬盡禮。服闋，應秋試，偶與南京潘商人同舟。潘主僕染疫，僕病且死，同舟友皆棄去。澤曰：『潘有重貲，我在彼未必死，苟舍之，寧禁他人，不利其有而速之斃乎』？調以藥餌，踰旬，潘霍」然。潘有金七百，欲分半謝之，堅卻不受。潘曰：「公年踰強仕，未得嗣，小女年十七，願備枕簟。」澤曰：「兒孫心上影，天道暗中燈，金且不受，何以女為？」越兩月，潘㩦女
至，拒之如初詞。其妻陶氏出簪珥背為拜納。其夫義
婦順如此。月餘，陶氏自孕。期年，擇良人配潘，嫁飾如
其女。六歲內，陶舉七男子焉。世傳為盛德之報云。

詹立敬

按《處州府志》：「包可成，字汝材，遂昌人。天性孝友，與人謹厚。家貧，習舉子業弗售，遂棄去。篤志實修，授徒鄉里，訓子及孫，並餼於庠。生平仗義釋紛，每周旋人患難，所全活者甚眾。閭黨欽為彥方肅然推戴。兩沐院獎，屢舉賓筵，以壽考終。」朱九職
[
编辑
]

按《處州府志》：「朱九職，字廷任，遂昌人。性孝友，輕財好施，崇儒重道。捐貲建義塾，造就鄉俊造舟龍鼻頭濟渡，置租二十畝，凡茶亭橋梁道路圮廢者，修建不惜重費。遇歉賑饑，施藥救病，周急掩骼，倡義全輸，解紛​息訟。生平與物無競，樂善不倦。」朱國泰
[
编辑

按《處州府志》：「朱國泰，字于保，遂昌人。性孝友，事節母黃氏至九旬，備極色養，輕財周急，有逋負不能償者，輒焚券免之。中丞高嘉其孝義，給冠帶獎勵，以稀壽終。」奚庚
[
编辑
]

按《溫州府志》：「奚庚，字以明，永嘉人，塾師。歿為營葬。武弁裔不能襲職，資之施棺施茶，歲以為常。」章性
〈子新民　孫文洪〉
[
编辑
]

按《溫州府志》：「章性，樂清人。尚書綸之曾祖。嘗有盜挾刃入其室，性識之，佯寐不覺也。既去，亦不言。臨沒始潛戒其子孫，令謹戒而已。子新民，亦長者。有里人以忮懻欲乘閒戕三命，新民堅止之，且怵以法，乃止。新民生文寶，文寶生綸，皆以綸貴，贈侍郎。文洪亦新民子，嘗以庠生挺身代兄文寶赴戍籍，文寶逮繫，又援」出之，其世有至行如此。

王可諒
[
