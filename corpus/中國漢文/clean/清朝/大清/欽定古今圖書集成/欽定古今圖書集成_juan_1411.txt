《命宮天柱星》
〈攔駕經〉
[
编辑
]

「金星守命夜生吉，白日生人減半力。木星照命有多般，白日逢之必作官。夜生若有暗曜雜，反為凶禍主憂煎。水星在命合入廟，夜裡生人太陰照。或居雙女與陰陽，決定少年居顯要。火星入命不堪詳，白日生人主禍殃。更被孛羅三合照，定知啞吃與人傷。患勞枉死人孤寡，夜生又宜卻無妨。」土星入命主頑鈍，夜
「裡生人不可論。水命定知須啞吃，黃腫氣疾命難存。太陽坐命如逢木，羅炁同宮須食祿。火星不照定封侯，月孛臨之患心腹。太陰在命生逢夜，水宿同宮為僕體。土星入命孛星來，有祿定知非久謝。紫氣印星號天乙，凡在命宮皆有益。生時不被惡星臨，善宿合兮多子息。木月見炁入夜宮，夜裡生人為輔弼。若是土星三合照，雖則高強終是疾。羅㬋入命許謀多，木炁同宮主豪富。金木太陽三合照，此人慷慨更英豪。女命夜生羅照著，自縊勞刑貧又薄。炁火水計入命時，此人定作般般惡。計都入命憂火命，此則十殺惡無定。貴人遇者以無權，白日生人宜修進。木星紫氣如臨照，主命居強為」福慶，孛星入命人廉潔，目快心
清為性別。炁木日金，若合時，所作高強皆有節。日生
火孛主星微，決定刑傷。蛇虎食，掩口不開氣衝人，直
得為官須歇滅。

金屬陰，故喜夜生，木屬陽，故喜晝生。《雙女》巳宮陰陽，申宮土，喜晝生，夜生人不吉。天乙為紫氣，主吉，土為瘟星，故主人多疾。

《財帛宮天寶星》
[
编辑
]

金臨財帛足隨時，夜裡生人皆進鎡。木臨財帛必豐
隆，日中生者最難逢，水臨財帛財帛散，更被孛來不
足看，火居財帛與前同，土居財帛皆豐亨，太陽居此
足錢財，質庫常開待物來，月居財帛多財帛，只怕土
星三合剋，炁入二宮亦忌之，遇日木扶還，又得羅計，
孛入損資財，終身不得資財力。

「水性就下」 ，其形漂流而不息，主不住財。火性炎，勢雖高而不耐久。

《兄弟宮天玉星》
[
编辑
]

木金兄弟主英雄，水星和樂旺門風，火在此宮定孤
寡，夜生不與孤寡同，土臨兄弟終和睦，日居未可同
言語，生時父母決相背，木計合宮主貧苦，太陰若得
主星來輔弼，榮華由此胎炁臨，第三兄弟少，計星遇
此漸生災，月孛來時損兄弟，古人傳說難躲避。

木星主仁，金星主義，水星主智，故吉。

《田宅宮天富星》
[
编辑
]

金居田宅父母宮，白日生人主困窮，如逢夜裡最為
吉，產業自榮邁祖宗，木臨田宅興父母，自然福壽世
難同，水居第四旺田莊，更有雙親壽命長，火星臨此
不堪說，土星躔入有房廊，白日生人為最吉，夜生父
母早年亡，日居田宅足田園，木到雙親福壽全，火孛
不照多產業，水金合會常堪憐，月臨雖稱旺田宅，白
日生人反作累，紫氣居之多壯麗，父母一時居富貴。
木星入位必有官，水月合兮居顯位，羅居田宅不堪
猜，十般死惡反破財，計都侵之憂父母，田莊牛馬化
成灰。月孛居安亦如之，夜生亦可減毫釐，晝生又忌
火來剋，父母早亡主孤恓。

田宅，土也，水有資助之力，火能害物，故少利。日木土主晝生，火月金水主夜生，反之不吉。

《男女宮天孤星》
[
编辑
]

「金星若在男女宮，四男聰俊各英雄。火在此宮不得地，遇著來時定主窮。土臨第五遲遲有夜生，決定主孤蹤。太陽若照男女宮，必主貴子顯門風。太陰到此亦如之，三男富貴夜為功。紫氣當生照男女，不被惡星并。火土三合水月同聰俊，男女榮華定文武。羅照男女主夭亡，計都臨照亦災苦。孛星倘若居此宮，十」生九死空費乳。為人性狠惡心腸，此乃《依經》與君語。

金數四，主有四子，太陽太陰，本人之父母也。日生太陽，吉。夜生太陰，吉。反背者，無力。

《奴僕宮僕馬星》
[
编辑
]

金木星居足奴僕，土若加之夜為毒。火在此宮必少
力，太陰值此多悲哭。非惟辛苦有多般，決定生時非
正屋。月居此位被日土，一世多迍更貧苦。第六宮中
​
見太乙，男女頑愚多忌疾。不然遲忌亦寡微，此乃皆
言多不利。計羅居此有災殃，孛若臨之號凶極。

「奴僕不宜高於命主」 星也；若高於《命主，則奴欺主》也。

《妻妾宮天對星》
[
编辑
]

金在妻宮妻妾好，木星晝會喜相逢，其妻非但能廉
潔，貌白容妍世孰同。水在妻宮多妖冶，火則傷殘莫
論容，夜生尤自主分離，何況生逢在日中。土入妻宮
無貌娘，妻妾命如日裡霜。太陽美貌火孛醜，太陰見
水美容妝。紫氣木星太陰吉，羅㬋自縊檢尸傷，計入
妻宮勞患死，不然毒藥溺江亡。妻妾宮中見孛星，計
都水火自相刑，兼主蛇傷并自弔，不然產難墮胎生，
火孛瘟癀死暴哀，落水懸梁產難災，木炁二星多美
麗，姿容可與貴妃齊，羅計二星產難別，暴喪逃亡自
帶來，炁孛水金淫慾甚，交情奴僕老心灰。

金乃為男之妻，火乃為妻之夫也。且妻妾宮遇金星，得其正也。

《疾厄宮殺難星》
[
编辑
]

「金臨疾厄永無疾，木居富貴常安逸。水在此宮遇孛計，必定腰駝并背曲。白日生人火曜衝，必定風痰吐血終。熒惑疾厄須驚悸，土臨八位主瘟凶。太陽遇計火土孛，風勞血病不久歿。如見木月獨照之，一世優游無消歇。此宮若見紫氣臨，定是安榮居要津。羅照此宮應篤疾，計會孛來定凶侵，非惟癆瘵又瘟㾮，抑」且吐血臥床亡。

疾厄之宮，惟金木主仁義，則無災厄也，木月次之，其餘計都羅㬋孛水之星，皆主不安，火土更甚，紫氣又能解人之厄。

《遷移宮地驛星》
[
编辑
]

木金之宿入遷移，定主遷移福祿齊，水星卻主遠行
吉，金木合照封侯印，土星阻滯難遠行，太陽晝生反
為益，金水會月夜生奇，命度相逢喜見之，此宮見炁
主為官，太陰合照為瑞端，羅在遊行必見別，家中當
見檢屍靈，計都，若會孛星入，決定蛇傷并虎擒，切聞
月孛入遷移，損田損宅損妻兒。

《官祿宮天福星》
[
编辑
]

「太白木星入官祿，一世為官居顯軸。天上之宮會水星，太陽合照作公卿。水居好樂合於月，官居位顯職非輕。火在十宮夜入廟，朝端定列仍年少。羅星計孛本為凶，官祿之宮不可容。」土星尊重多豐祿，紫氣添
成衣食足。只宜興旺不宜衰，為人慷慨多榮富。

官祿之宮正，乃人之壯，而行之之位，宜吉星則大有為，士君子立於朝，庶人興於家，商賈發於市，苟若凶星會照，誠為一匹夫輩也。

《福德宮福壽星》
[
编辑
]

福德宮中或見金，夜生一世福神欽，木會太陽居十
一，祿厚福優居顯秩，水會月吉火淺薄，金土同照主
食邑，十一宮中羅最吉，太陽木炁三合值，生則須封
萬戶侯，死則定知當廟食。

「廟食」 謂列忠臣廟而受祭。

《相貌宮》
[
编辑
]

土星相貌卻烏黃，木宿元來瘦且長。金白不惟多嗜
慾，水星行動受趨蹌，羅㬋薄藝隨身有，月孛為人帶
黑醜。熒惑一星多性惡，水星最是雙眉好，計都巧計
愛談論，羅火東西打殺人。水火相隨多雜藝，太陽為
性卻逡巡。月孛一生多嘴舌，水星伶俐木都美。土星
頑鈍言語澀，羅火為人貪可鄙。

十一曜一星主一相。凡人之美惡、兇狠、溫和、古怪、俊逸，皆由各星形狀所稟，生之初者也，非一而論之。

《日月》
[
编辑
]

「太陽太陰單守命，間世英賢誰可並。忠直廉平性任真，覆庇生民朝野迥。若臨財帛金滿籯，倏忽翔威萬里程。臨在兄弟多生一，若居父母保年齡，子息一子真鸑鷟，奴僕一呼須百諾。臨妻賢敏必興家，照疾一生無患惡。遷宮務重多功績，官祿超榮兼重職。福德應知恆與升，相貌巍然美顏色。天福來臨期百六，滿」用廟方魁，福祿官資榮顯至中書士庶逢之發金穀。

日月乃為人之父母，十二宮皆吉，只恐凶星相犯而欺之者，則不能為吉。

《金木》
[
编辑
]

金星守命福昌熾，木性寬仁金禮義，若臨財帛粟麥
豐，敏慧虹蜺為膽氣，兄弟金四木須三，父母長年福
祿深，子息木三金主四，如臨奴僕盛車軫，臨妻員敏
期偕老，照疾多康災害少，遷宮之位任重權，官祿當
之權永久，福德加臨福祿盈，貌宮應喜好顏容，若期
百六添官爵，凡庶當之福勢隆。

「金木」 者，仁義之星也。凡在十二宮多為福，只怕惡星同宮，則不能自任其用，而從惡宿為凶者有之。

《夜火晝土》
[
编辑
]

火星威焰恃賢親，土宿敦恭信且誠，臨照財宮多積
​
聚，文章錦繡作公卿，兄弟火二土須五，田宅康寧期
百六。子宮土五火主二，臨照奴牛須得取，照妻偕老
年期百，臨在八宮無疾厄，遷宮調任總遷榮，兼有良
朋貴親戚，官祿榮官掌權柄，常人爭訟欲拖延，若臨
福德南山壽，相貌無虞但百年，大抵晝土福星魁，夜
火終為百福謀，百六會時升廣漢，常人遇此旺錢財。

「夜火晝土」 者，各得其時，所以不相反背，在十二宮為吉。

《晝火夜土》
[
编辑
]

「莫教晝火夜兼土，命遇危亡即哀苦，若臨財帛罄囊傾，悖禮乖誠多莽鹵，兄弟只應多自處，田宅當之重父母，子宮絕嗣俱螟蛉，奴僕當之奴反主。若在七宮三五妻，土主惡死火分離，如當滿用來居婿，妻忌刑夫亦不宜。八宮惡疾夭天年，自縊風勞日火躔，腰腎乾焦濕與腫，必當夜土惡迍邅，官祿之宮不可逢，遷」移官厄係囚中，若臨福德貧窮輩，相貌破形或性兇，
忌星若也臨百六，命入荒郊定哀哭，滿中救援是三
方，不在相中發衣祿。

火本夜，土本晝，今而晝火夜土，則相背逆而不向時，每事主人不利。

《孛羅計》
[
编辑
]

「羅計孛臨本命宮，剛強暴虐足威風，臨財主執多權概，勢力過人膽氣雄，兄弟合胎皆異姓，若臨父母二三重，臨子一如兄弟應，或是螟蛉隨母聘。臨在妻宮主換妻，妻臨一例斷裁之，倘逢滿用當居廟，免見刑傷主別離，滿用依然見惡星，依前刑剋濫無情，如臨奴僕奴牛盛，疾厄當之怪疾刑，遷宮任重足威權，官」祿宮中事亦然，福德若臨皆滿用，貌宮威虐孰能前。

三星臨宮，若得廟旺，有吉星押之，則不為禍。有凶曜攻之，為害甚速。

《水星》
[
编辑
]

「水星和順多能智，喜會日月木金炁，怕逢忌宿孛計羅，男可為奴女為妓，臨財財帛足昌榮，博覽詩書通六經，若臨兄弟宜一二，若同父母足年齡，在子一人為後裔，臨妻妻位皆吉利，若臨奴僕在犧牲，疾厄宮中無疾病，遷宮出處總榮歡，官祿當之掌大權，福德當之豐福壽，如居相貌性溫然，若期百六限無憂，更」逢滿用足禎休。廟宮會遇升騰處，百里光華遍地流。

《水》主智，好動之星多，則喜吉星輔之。

《炁星》
[
编辑
]

景星尊大最廉平，志氣孤高又敏明，臨在財宮多粟
帛，文章擲地作金聲，兄弟子位三五人，僧家或說是
孤辰，父母妻宮長福壽，第四宮中田宅盈，奴生逢會
多奴婢，疾厄當之斥禍災，若是遷宮俱顯職，正臨官
祿上金階，福德當之福勢隆，貌宮喜主美顏容，如逢
百六朝宸陛，庶位當之粟帛豐。

炁好清閑，主九流藝術，得地，主清貴。逢空陷為僧道，有壽，能解人之災厄。

《羅計》
[
编辑
]

大抵羅計本相對，莫把對宮推禍福。羅計權高日月
星，直入火土乃為英。官高殺伐威名振，諫諍趨庭叩
上清，值者多為天眷屬，不然將相是宗親，廟宮滿用
人人好，群小當之破損身。

羅星在天，號曰「天首」 ，計星號「天尾。」 諸星逆行，惟《羅計》順行，逢日月則蝕。

《輪宮賦》
[
编辑
]

天命為最，己身欲強，值吉星以守照，獲厚福以無疆，
倘入廟以清奇，更須高位。若陷囚而喜旺，又且何妨。
太陽臨位而榮貴無災，月后入宮而清慈有福，美容
貌而且秀，處人事而最足。切防忌宿照臨而減算，除
年大緊，凶星對照而興災失祿。金潔體而立性多剛，
水鼠眸而為人不一，非言辭之無准，惟處世之多失。
木須清秀，體長而好學文章；炁必寬慈，經史而博覽
廣識。或云孤宿，亦號官星，云寡宿者，為僧為道，道官
星者，有職有權。孛星身瘦小而人前，好說家風。羅計
粗雄而膽大，性多鄙吝。喜獨居於一位，忌相會於諸
星。惡曜而多白不安，凶星而遂成殃釁。火星赤黑，煩
燥暴以難瞞。土星矮肥，最寡言而多慮，各分晝夜，切
論晨昏，若為忌宿之臨，深作殃危之急。

財帛宮位，吉凶可知，遇木星而守照，無凶曜以為奇，
資財必獲於昌榮，金庫盈滿於囊篋。平生空乏，水土
難欺，金炁歸垣，與木曜以頗同。日月同宮，主人財而
猶旺，火孛兩曜，須破敗以無成。羅計二星，主離祖而
有望。吉凶混雜，前後須知，多寡宜詳，高低無妄，
兄弟宮數，要知多寡之分，星宿推遷，須識吉凶之佐。
值太陽者，先損其父，遇太陰者，卻無其母。土星生晝
兄弟而五人，金星夜值鴈行之四箇，計羅二三，木炁
還多，水土兩娘而生火星，爾我而已。

男女宮內得火者一雙，子孫位中，遇木星而三箇，太
陽得位，一二人而有可成。月曜入宮，二三子一雙無
禍，水星一子須聰明，彗孛無男常坎坷，計羅有剋，火
星難保於初前，太乙多傷紫炁，頭兒決剋破
奴為惡曜吉凶不殊，日守則防父沒，月照則當母除，
若遇惡星而入此，定係蓬蓽以安身，倘逢吉曜而加
臨，須知僕馬以昌盛。

夫宮無異，妻位且同，最喜金炁而相照，惟嫌日月以
難逢，火星土宿而非忌咸安。木宿端正，彗孛計羅而
二三多厄。水宿孤窮，若惡星以相臨於鼓盆而難逃。
疾厄之位兮知吉知凶，禍患之宮兮理優理正。太陽
臨位，百禍俱消。月曜入宮而一身遭釁，水主蹇厄孛
守而喉腹生災，火主眼腰土臨而心胸疾定。木金救
解，災痾不致於侵凌。羅計為憂，手足安能於馳騁。宜
當仔細推詳，庶無一毫差謬。

遷移之位逢火孛切忌遠行，合照之方遇羅㬋必須
破宅，太陽嫌晦怕囚，木金多樂於風流，水炁卻豐於
財帛。

官祿，吉曜職權自昌。日月相逢之最貴，羅計入廟以
為強。孛星守而刑獄難逃，木炁臨而資財豐盛。
福德宮神，最宜明淨。此一宮之強盛，獲百福以來臨。
倘逢凶曜之加，壽齡何保。縱有吉星之助，財產須傾。
且聞相貌之宮，須識凶吉詳推，全籍身命之宮，始知
禍福堪憑。所以星辰五六，榮枯貴賤以安排；宮分四
三，否「泰窮富而列定，宜詳宜究，愈審愈精。
