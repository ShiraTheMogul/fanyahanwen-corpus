《夜聽擣衣》
魏·曹毗
[
编辑
]

寒興御紈素，佳人治衣襟。冬夜清且永，皓月照堂陰。
纖手疊輕素，朗杵叩鳴碪。清風流繁節，迴飆灑微吟。
嗟此嘉運速，悼彼幽滯心。二物感余懷，豈但聲與音。

《擣衣》
宋·謝惠連
[
编辑
]

衡紀無淹度，晷運倏如催。白露滋園菊，秋風落庭槐。
肅肅莎雞羽，烈烈寒螿啼。夕陰結空幕，宵月皓中閨
​
美人戒裳服，端飾相招攜。簪玉出北房，鳴金步南階。
簷高碪響發，楹長杵聲哀。微芳發兩袖，輕汗染雙題。

《秦王卷衣》
梁·吳均
[
编辑
]

咸陽春草芳，秦帝卷衣裳。玉檢茱萸匣，金泥蘇合香。
初芳薰複帳，餘輝耀玉床。當須宴朝罷，持此贈《華陽》。

《擣衣》
王僧孺
[
编辑
]

足傷金管遽，多愴緹光促。露團池上紫，風飄庭裡綠。
散度廣陵音，摻寫《漁陽曲》。別鵠悲不已，離鸞斷還續。
尺素在魚腸，寸心憑鴈足。

《擣衣》
柳惲
[
编辑
]

孤衾引思緒，獨枕悵憂端。深庭秋草綠，高門白露寒。
思君起清夜，促柱奏《幽蘭》。不怨飛蓬苦，徒傷蕙草殘。
行役滯風波，遊人淹不歸。亭皋木葉下，隴首秋雲飛。
鶴鳴勞永嘆，採綠傷時暮。念君方遠遊，賤妾理紈素。
秋風吹綠潭，明月懸高樹。軒高夕杵散，氣爽夜碪鳴。
瑤華隨步響，幽蘭逐袂生。

《賦得香出衣》
劉孝威
[
编辑
]

香出衣步近氣逾飛。博山登高用鄴錦，含情動靨比
《洛妃》。香纓麝帶縫金縷，瓊花玉勝綴珠徽。蘇合故年
微恨歇，都梁路遠恐非新。猶賢漢君芳千里，尚笑荀
令止三旬。

《華光省中夜聽城外擣衣》
費昶
[
编辑
]

閶闔下重關，丹墀吐明月。秋氣城中冷，秋砧城外發。
浮聲繞雀臺，飄響度龍闕，宛轉何藏摧，當從上路來，
藏搉方未已，定自乘軒里，乘軒盡世家，佳麗似朝霞。
圓璫耳上照，方繡領間斜，衣燻百和屑，鬢插九枝花，
昨暮庭槐落，今朝羅綺薄。拂席捲鴛鴦，開縵舒龜鶴。
金波正容與，玉步依砧杵。紅袖往還縈，素腕參差舉。
徒聞不得見，獨夜空愁佇。

《夜聽擣衣》
北周·庾信
[
编辑
]

秋夜擣衣聲，飛度長門城。今夜長門月，應如晝日明。
小鬟宜粟瑱，圓腰運織成。秋砧調急節，亂杵變新聲。
石燥砧逾響，桐虛杵絕鳴。鳴石出華陰，虛桐採鳳林。
北堂細腰杵，南市女郎砧。擊節無勞鼓，調聲不用琴。
並結連枝縷，雙穿長命針。倡樓驚別怨，征客動愁心。
同心竹葉碗，雙去雙來滿。裙裾不奈長，衫袖偏宜短。
「龍文鏤剪刀，鳳翼纏篸管。風流響和韻，哀怨聲悽斷。新聲繞夜風，嬌轉滿空中。應聞長樂殿，判徹昭陽宮。花鬟醉眼纈，龍子細文紅。濕摺通夕露，吹衣一夜風。玉階風轉急，長城雪應闇。新綬始欲縫，細錦行須纂。聲煩廣陵散，杵急漁陽摻。新月動金波，秋雲泛濫過。誰憐征戍客，今夜在交河。」栩陽《離別》賦，臨江《愁思歌》。
復令悲此曲，紅顏餘幾多。

《端午日賜衣》
唐·杜甫
[
编辑
]

宮衣亦有名，端午被恩榮。細葛含風軟，香羅疊雪輕。
自天題處濕，當暑著來清。意內稱長短，終身荷聖情。

《寄盧儼員外秋衣詞》
于鵠
[
编辑
]

寄遠空以心，心誠亦難知。篋中有秋帛，裁作遠客衣。
縫製雖女工，尺度手自持。容貌常自中，長短不復疑。
斜縫密且堅，遊客多塵緇。意欲都無言，澣濯耐歲時。
慇懃託行人，傳語慎勿違。別來已年老，亦聞鬢成絲。
縱然更相逢，握手唯是悲。所寄莫復棄，願見長相思。

《元九以紵絲布白輕褣見寄製成衣服以詩報之》
白居易
[
编辑
]

綠絲文布素輕褣，珍重京華手自封。貧友素勞君寄
附，山妻親為我裁縫。褲花白似秋雲薄，衫色青於春
草濃。欲著卻休知不稱，折腰無復舊形容。

《詶樂天得稹所寄紵絲布白輕褣製成衣服以詩報之》
元·稹
[
编辑
]

湓城萬里隔巴庸，紵薄綈輕共一封。腰帶定知今瘦
小，衣衫難作遠裁縫。惟愁書到炎涼變，忽見詩來意
緒濃。春草綠茸雲色白，相君騎馬好儀容。

《邊軍支春衣》
柳公權
[
编辑

挾纊非真纊，分衣是假衣。從今貔虎士，不憚戍金微。

《寄邊衣》
裴說
[
编辑

「深閨乍冷開香篋，玉著微微濕紅頰。一陣霜風殺柳條，濃煙半夜成黃葉。重重白練如霜雪，獨下閒階轉凄切。祇知抱杵向秋砧，不覺高樓已無月。時聞寒鴈聲相喚，紗窗只有燈相伴。幾展齊紈又懶裁，離腸恐逐金刀斷。細想儀形執刀尺，回波剪破澄江色。愁捻銀針信手縫，惆悵無人試寬窄。時時舉袖勻殘淚，紅」箋謾有千行字。書中不盡心中事，一半慇懃託邊使。

《故衣》
宋·林景熙
[
编辑
]

《篋中出故衣》，絡緯生四壁。昔年慈母線，一一手所歷。
眷眷遊子心，惻惻虛堂夕。遊水不返流，孤雲杳無跡。
空令攬衣人，一線淚一滴。衣敝奈有時，母恩無窮期。
「終憐寸艸心，何以報春暉。朝寒縱砭骨，念此不忍披。且復返所藏，永寄霜露思。」《寄衣曲》
張耒
[
编辑
]

秋風西來入庭樹，攀條正念征人苦。空窗自織不敢
住，鳴機愁寂如鳴櫓。練成欲裁新絲香，抱持含愁上
姑堂。別來不見衣寬窄，試比小郎身更長。

《裁衣曲》
陳基
[
编辑

「殷勤織紈綺，寸寸成文理。」裁作遠人衣，縫紉不敢遲。

编辑

嬋娟霜月照荒垣，妾擁重衾尚怯單。況是玉門關外

《擬寄衣曲》
鄭氏允端
[
编辑
]

男兒遠向交河道。鐵馬金戈事征討。邊頭八月霜風
寒，欲寄戎衣須趁早。急杵清砧擣夜深，玉纖銅斗熨

寄邊使，為語夫君奮忠義。好將功業立邊陲，要使聲
名垂史記。

《周國雍參藩寄紅罽衣賦此為謝》
[
编辑
]

明朱多炡

萬里蠶叢亦浣紗，使君緘贈自三巴。濯殘秋水天孫

《製衣詞》
陳汝言
[
编辑
]

妾把春蠶絲，勤向寒窗織。織成鴛鴦紋，洗花染春色。
誰知裁剪時，為郎三嘆息。郎身別已久，長短今未識。
聊將夢中見，彿彷試刀尺。霜天萬里塗，特寄淚沾臆。
願郎衣著時，細看針線跡。

《裁衣行》
劉秩
[
编辑
]

裁衣須裁短短衣，短衣上馬輕如飛。縫袖須縫窄窄
袖，袖窄彎弓不礙肘。短衣窄袖樣時新，殷勤寄與從
軍人。願郎著衣便弓馬，破敵長驅古城下。明年佩印
披紫緋，裁衣不比從軍時。

《寄衣曲》
林鴻
[
编辑
]

漢月絓庭樹，邊霜拂城樓。遠人一夜寒，深閨始知秋。
起來理征衣，纖手一何柔。雙杵幾不勝，寸心未能休。
梧葉下淅淅，草蛩閑幽幽。月明嗟慰意，風急復含愁。
白露下蘭心，蘭心亦枯槁。妾家有高臺，下有漁陽道。
明發寄征人，三挹蘼蕪草。

《前題》
石珤
[
编辑
]

越絲迴波翔紫凰，丹芝水花相間香。并刀剪綠藕絲
脫，中有二十四鴛鴦。碧窗夜寒鍼指冷，一線未縫雙
淚迸。秦雲隴樹千萬重，欲寄還愁道塗梗。封題錦字
託衣中，殷勤先謝西飛鴻。

《搗衣篇》
蔡羽
[
编辑

《夜迢迢》，草白露，寒衣未曾絮。碧杵白玉床，桂花新水
香，長廊曳屧踏月光。莎雞出戶螢入房，金井梧桐生
夜涼。涼風起，聲轉促，繡閣璚窗滅明燭。悽悽玉關情，
秋來亂心曲。亂心曲，其奈何。銀河咫尺愁風波，何況
桑乾道路多。

《前題》
張時徹
[
编辑
]

《鼓鼕》鼕，夜何其？月明露白風凄凄。闌干北斗映南箕，
莎雞入戶流螢飛。鳴玉珮，步瑤墀。揎皓腕，出鳳幃。念
君不歸搗君衣。心煩力疾雙杵揮，寒影散亂聲參差。
輕綃舉，繡帶垂。調玉節，淚交頤。庭柯葉落烏夜啼，流
音回轉聽者悲。「熠熠魚舒錦，出自流。黃機裁為合歡被，夜夜待君歸。君今未解黃龍戍，賤妾年年空搗衣。」《擣衣曲》
馮行可
[
编辑
]

征夫萬里長為戍，月明今夜知何處？城頭啞啞聞烏
啼，秋風淅瀝愁難寐。起坐閒庭夜擣衣，擣衣對影空
​
垂淚。妾今夜夜愁君寒，君心那得長相棄。

《寄衣曲》
馮大受
[

內勿服，踰月而國莫之服。
