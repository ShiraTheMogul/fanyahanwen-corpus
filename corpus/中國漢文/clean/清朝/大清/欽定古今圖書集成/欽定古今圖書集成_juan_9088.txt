第宅部藝文二
〈詩詞〉
[
编辑
]

《漢成帝時五侯歌》
[
编辑
]

《漢書》：「五侯群弟，悉競為奢侈，後庭姬妾各數十人，羅鐘磬，舞鄭女，作優倡，狗馬逐馳。大治第室，起土山漸臺，洞門高廊閣道，連屬彌望，百姓歌之。言其奢僭如此。」五侯初起，曲陽最怒。壞決高都連竟外。杜土山漸，臺
西《白虎》。

《還舊居》
晉·陶潛
[
编辑
]

疇昔家上京，六載去還歸。今日始復來，惻愴多所悲。
阡陌不移舊，邑屋或時非。履歷問故居，鄰老罕復遺。
步步尋往跡，有處特依依。流幻百年中，寒暑日相推。
常恐大化盡，氣力不及衰。撥置且莫念，一觴聊可揮。

《戊申歲六月中遇火》
前人
[
编辑
]

草廬寄窮巷，甘以辭華軒。長夏正風急，鄰室頓燒燔。
一宅無遺宇，舫舟蔭門前。迢迢新秋夕，亭亭月將圓。
果菜始復生，驚鳥尚未還。中宵佇遙念，一盼周九天。
總髮抱孤念，奄出四十年。形跡憑化往，靈府長獨閑。
貞剛自有質，玉石乃非堅。仰想東戶時，餘糧宿中田。
鼓腹無所思，朝起暮歸眠。既已不遇茲，且遂灌西園。

《飲酒》
前人
[
编辑
]

「結廬在人境，而無車馬喧。問君何能爾，心遠地自偏。採菊東籬下，悠然見南山。」山氣日夕佳，飛鳥相與還。
此中有真意，欲辨已忘言。

《讀山海經》
前人
[
编辑
]

孟夏草木長，遶屋樹扶疏。眾鳥欣有託，吾亦愛吾廬。
既耕亦已種，時還讀我書。窮巷隔深轍，頗迴故人車。
歡言酌春酒，摘我園中蔬。微雨從東來，好風與之俱。
汎覽《周王傳》，流觀《山海圖》。俯仰終宇宙，不樂復何如。

《治宅》
齊·謝脁
[
编辑
]

結宇夕陰街，荒幽橫九曲。迢遞南川陽，迤𨓦西山足。
闢館臨秋風，敞窗望寒旭。風碎池中荷，霜剪江南菉。
既無東都金，且稅東皋粟。

《行宅》
〈并序〉
蕭子良
[
编辑
]

「余稟性端疏，屬愛閒外。往歲羈役浙東，備歷江山之美。名都勝境，極盡登臨。山原石道，步步新情；迴池絕澗，往往舊識。以吟以詠，聊用述心。」 詩曰：

「訪宇北山阿，卜居西野外。」幼賞悅禽魚，早性羨蓬艾。

《行經范僕射故宅》
梁·何遜
[
编辑
]

旅葵應蔓井，荒藤已上扉。寂寂空郊暮，無復車馬歸。
瀲灩故池水，蒼茫落日暉。遺愛終何極，行路獨沾衣。

《入元襄王第》
蕭子範
[
编辑
]

伏軾窺東苑，收淚下玉橋。昔時方轂處，於今共寂寥。
夾池猶裊裊，仙榭尚迢迢。一同西靡柏，徒思芳樹蕭。

《和蕭子範入元襄王第》
王筠
[
编辑
]

昔入睢陽苑，連步披風雲。今遊故臺處，回望闃無人。
皓壁留餘篆，蕙圃有餘芬。行人皆隕涕，何獨孟嘗君。

《夏潦省宅》
任豫
[
编辑
]

風棹出天街，星言指沈室。頓楫俄毀垣，惻然悼窮陌。
春為發大道，夏為漵潮折。貴者陋懷居，鄙人安朝夕。
生長數十載，幸祐見衰白。堂遺孤孩音，庭餘笄齔跡。
入似聚族慰，出為里仁惜。

===
《南還尋草市宅》
陳江總
===
​
紅顏辭鞏洛，白首入轘轅。乘春行故里，徐步采芳蓀。

逕毀悲求仲，林殘憶巨源。見桐猶識井，看柳尚知門。
花落空難遍，鶯啼靜易諠。無人訪語默，何處敘寒溫。
百年獨如此，傷心豈復論。

《歲暮還宅》
前人
[
编辑
]

悒然想泉石，驅駕出城臺。翫竹春前筍，驚花雪後梅。
青山殊可對，《黃卷》復時開。長繩豈繫日，濁酒傾一盃。

《過故宅》
元·行恭
[
编辑
]

頹城百戰後，荒宅四鄰通。將軍樹已折，步兵途轉窮。
吹臺有山鳥，歌庭聒野蟲。草深斜徑沒，水盡曲池空。
林中滿明月，是處來春風。唯餘一廢井，尚夾兩株桐。

《過大哥宅》
元·宗
[
编辑
]

魯衛情先重，親賢愛轉多。冕旒豐暇日，乘景暫經過。
戚里申高宴，平臺奏《雅歌》。復尋為善樂，方驗保山河。

《還山宅》
楊師道
[
编辑
]

暮春還舊嶺，徙倚玩年華。芳草無人徑，空山正落花。
垂藤掃幽石，臥柳礙浮槎。鳥散茅簷靜，雲披澗戶斜。
依然此泉路，猶是昔煙霞。

《安樂公主新宅》
趙彥昭
[
编辑
]

雲物中京曉，天人外館開。飛橋像河漢，懸榜學《蓬萊》。
北闕臨仙檻，南山送壽杯。一窺輪奐畢，慚恧棟梁材。

《詠宅》
李嶠
[
编辑
]

寂寂蓬蒿徑，喧喧湫隘廬。屢逢長者轍，時引故人車。
孟母遷鄰罷，將軍辭第初。誰憐《草元》處，獨對一床書。

《奉和寧王宅應制》
張說
[
编辑
]

進酒忘憂館，簫韶喜降尋。帝堯敦睦禮，王季友兄心。
竹院龍鳴笛，梧宮鳳繞林。《大風》將《小雅》，一字重千金。

《奉和幸禮部尚書竇希玠宅應制》
蘇頲
[
编辑
]

尚書列侯地，外戚近臣家。飛棟臨青綺，迴輿轉翠華。
日交當戶樹，泉漾滿池花。圓頂圖嵩石，方流擁魏沙。
豫游今聽履，侍從昔鳴笳。自有天文降，無勞訪海槎。

《有客》
杜甫
[
编辑
]

「患氣經時久，臨江卜宅新。喧卑方避俗，疏快頗宜人。」有客過茅宇，呼兒正葛巾。自鋤稀菜甲，小摘為情親。

《為農》
前人
[
编辑
]

錦里煙塵外，江村八九家。圓荷浮小葉，細麥落輕花。
卜宅從茲老，為農去國賒。遠慚勾漏令，不得問丹砂。

《畏人》
前人
[
编辑
]

「早花隨處發，春鳥異方啼。萬里清江上，三年落日低。」「畏人成小築，褊性合幽棲。」「門逕從榛草，無心待馬蹄。」《入宅三首》
前人
[
编辑
]

「奔峭背赤甲，斷崖當白鹽。」客居愧遷次，春色漸多添。
花亞欲移竹，鳥窺新卷簾。衰年不敢恨，勝概欲相兼。

又

亂後居難定，春歸客未還。水生魚復浦，雲煖麝香山。
半頂梳頭白，過眉拄杖斑。相看多使者，一一問函關。

又

宋玉《歸州宅》，雲通白帝城。吾人淹老病，旅食豈才名。
峽口風常急，江流氣不平。只應與兒子，飄轉任浮生。

《一室》
前人
[
编辑

「一室他鄉遠，空林暮景懸。正愁聞塞笛，獨立見江船。」巴蜀來多病，荊蠻去幾年。應同王粲宅，留井峴山前。

《卜居》
前人
[
编辑
]

歸羨遼東鶴，吟同楚執珪。未成遊碧海，著處覓丹梯。
雲障寬江北，春耕破瀼西。桃紅客若至，定似昔人迷。

《舍弟占歸草堂檢校聊示此詩》
前人
[
编辑
]

久客應吾道，相隨獨爾來。孰知江路近，頻為草堂回。
鵝鴨宜長數，柴荊莫浪開。東林竹影薄，臘月更須栽。

《西郊》
前人
[
编辑
]

「時出碧雞坊，西郊向草堂。」市橋官柳細，江路野梅香。
傍架齊書帙，看題減藥囊。無人覺來往，疏懶意何長。

《將赴成都草堂途中有作先寄嚴鄭公五首》
[
编辑
]

前人

得歸茅屋赴成都，直為文翁再剖符。但使閭閻還揖
讓，敢論松菊久荒蕪。魚知丙穴由來美，酒憶郫筒不
用沽。五馬舊曾諳小徑，幾迴書札待潛夫。

又

處處清江帶白蘋，故園猶得見殘春。雪山斥堠無兵
馬，錦里逢迎有主人。休怪兒童延俗客，不教鵝鴨惱
比鄰。習池未覺風流盡，況復荊州賞更新。

又

竹寒沙碧浣花溪，橘刺藤梢咫尺迷。過客徑須愁出
入，居人不自解東西。書籤藥裹封蛛網，野客山橋送
馬蹄。肯藉荒亭春草色，先𢬵一飲醉如泥。

又

常苦沙崩損藥欄，也從江檻落風湍。新松恨不高千
尺，惡竹應須斬萬竿。生理祇憑黃閣老，衰顏全付紫
金丹。三年奔走空皮骨，信有人間《行路難》。

又

錦官城西生事微，烏皮几在還思歸。昔去為憂亂兵
入，今來已恐鄰人非。側身天地更懷古，回首風塵甘
​
息機。共說總戎雲鳥陣，不妨遊子芰荷衣。

《奉酬嚴公寄題野亭之作》
前人
[
编辑
]

拾遺曾奏數行書，懶性從來水竹居。奉引濫騎沙苑
馬，幽棲真釣錦江魚。謝安不倦登臨費，阮籍焉知禮
法疏。枉沐旌麾出城府，草茅無逕欲教鋤。

《敝廬遣興奉寄嚴公》
前人
[
编辑
]

野水平橋路，春沙映竹村。風輕粉蝶喜，花暖蜜蜂喧。
把酒宜深酌，題詩好細論。府中瞻暇日，江上憶詞源。
跡忝朝廷舊，情依節制尊。還思長者轍，恐避席為門。

《絕句六首》
前人
[
编辑
]
