贈答部藝文四
〈詩〉
[
编辑
]

《贈馬道士》
宋·李九齡
[
编辑
]

水共逍遙雲共孤，混時言笑只佯愚。經年但醉宜城
酒，千里惟擔「《華嶽》圖。」尋野鶴來空碧洞，覓琴僧去度
重湖。人間再見知何日，乞取先生古轆轤。

《答錢少卿》
舒雅
[
编辑
]

蓬萊閣下舊鄰居，偶別俄驚四載餘。每見寒葭思倚
玉，忽臨秋水得雙魚。人間貴盛誰能及，物外優閒我
自如。聞認歸艎向春渚，深知不與道情疏。

《贈湖州張從事》
王禹偁
[
编辑
]

前年春榜亞龍頭，詞賦曾推第一流。上直未歸紅藥
院，供吟先得白蘋洲。酒醒野寺烹山蕨，公退池亭狎
海鷗。自是吳門折腰吏，滿衣塵土為君羞。

《贈衛尉宋卿二十二丈》
前人
[
编辑
]

謫宦歸來髮更斑，迴翔猶在寺卿閒。幾多僚友三台
上，大半生徒兩制間。舊賜紫袍多貰酒，新裁紗帽欲
歸山。東垣小諫龍鍾甚，空媿洪爐早鑄顏。

《贈張處士》
趙湘
[
编辑
]

應問秋雲學得閒，飄然如不在人間。青藤篋裏詩多
怪，紫栗枝邊藥更殷。江客對碁曾賭鶴，野僧分屐借
登山。仍聞昨日來城市，又抱孤琴踏月還。

《贈杜鼎昇》
張及
[
编辑
]

家本樊川老蜀都，世家冠劍豈寒儒。筆耕尚可儲三
載，酒戰猶能敵百夫。僻愛舜琴《湘水弄》，每懸孫畫《醉
仙圖》。孟光笑語長相逐，喚作梁鴻得也無。

===
《依韻酬太傅張相公見贈》
范仲淹
===
​
出處曾無致主功，南陽為守地猶雄。醉醒往日慚漁

父，得失今朝賀塞翁。七里河邊歸帶月，百花洲上笑
生風。臥龍鄉曲多賢達，願預逍遙九老中。

《贈王介甫》
歐陽修
[
编辑
]

翰林風月三千首，吏部文章二百年。老去自憐心尚
在，後來誰與子爭先。朱門歌舞爭新態，綠綺塵埃試
拂絃。常恨聞名不相識，相逢尊酒盍流連。

《贈王子直秀才》
蘇軾
[
编辑
]

萬里雲山一破裘，杖端閒挂百錢遊。五車書已留兒
讀，二頃田應為鶴謀。水底笙歌蛙兩部，山中奴婢橘
千頭。幅巾我欲相隨去，海上何人識故侯。

《贈關子淵》
孔夷
[
编辑
]

吳越聲飛二十年，緇衣空復歎遺編。紫芝眉宇風塵
外，太白文章錦繡前。可是石渠方載筆，未應水國要
歸田。他年雪裏相逢處，能記騎驢孟浩然。

《酬晏伯達》
陳淵
[
编辑
]

半生流轉任飛蓬，萬里歸來興又東。寂寞倦投揚子
宅，低徊卻寄魯侯宮。阻尋雞黍他年約，長憶園林一
醉同。何日過君花下飲，爛看濃豔舞春風。

《贈張漢卿》
汪莘
[
编辑
]

相伴留侯訪赤松，碧桃花下醉溶溶。玉龍嘶罷還家
晚，月到蓬萊第一峰。

《贈陳宗之》
葉紹翁
[
编辑
]

官河深水綠悠悠，門外梧桐數葉秋。中有武林陳學
士，吟詩消遣一生愁。

《贈夏君宗禹》
真德秀
[
编辑
]

虎頭自合取侯封，好為明時立雋功。卻謝玉關班定
遠，早陪芝嶺夏黃公。

《酬故人見贈》
嚴羽
[
编辑
]

湘江南去少人行，瘴雨蠻煙白草生。誰念梁園舊詞
客，桄榔樹下獨聞鶯。

《酬贈夢真上人》
釋行肇
[
编辑
]

禪舍因吟住，晴來坐徹宵。春通三徑晚，家別九江遙。
巢重禽初宿，窗明葉旋飄。往期應未定，謝守有詩招。

《贈文兆》
釋惠崇
[
编辑
]

偶依京寺住，誰復得相尋。獨鶴窺朝講，鄰僧聽夜琴。
注缾沙井遠，鳴磬雪房深。久與松蘿別，空懸王屋心。

《贈魏野》
釋宇昭
[
编辑
]

別業惟栽竹，多閒亦好奇。試泉尋寺遠，買鶴到家遲。
藥就全遺母，詩高祇教兒。未能終住此，共有海山期。

《贈王司法》
釋惠洪
[
编辑
]

「輕帆已有渡江期，高會清遊惜此時。」水閣颺煙晴試
茗，雪窗剪燭夜論詩。衝寒遠鴈來橫浦，弄色新梅半
糝枝。林下自知無一事，亦應風月動關思。

《贈趙仲常》
金·辛愿
[
编辑
]

趙子年雖小，論詩樂最深。秋風凡幾首，冬日更多吟。
老大吾無力，文章爾用心。荒山松竹底，莫厭數相尋。

《贈劉菴主》
前人
[
编辑
]

早薄軒裳貴，高尋綺皓蹤。一囊閭里藥，六尺水雲筇。
午枕眠芳景，晴簷望遠峰。柴門常不掩，應得野夫從。

《贈趙宜之二首》
前人
[
编辑
]

夫子今詞伯，胡為遠帝京。青雲無轍跡，白髮有柴荊。
鬼戲多年病，人高四海名。《麟經》方有缺，無惜繼丘明。
轉徙家無地，逢迎客有尊。光陰連病枕，天地一愚軒。
霜雪青松古，風塵白璧溫。從渠投隙者，衮衮向金門。

《贈王南雲》
李夷
[
编辑
]

骯髒風儀古丈夫，鶴袍鐵面戟髭鬚。人間春色向頭
剩，天上月明當額孤。石鼎夜聯詩句健，布囊春醉酒
錢粗。危樓試看街頭月，應見潛飛入玉壺。

《贈答劉御史雲卿》
元·好問
[
编辑
]

舊聞劉君公，學《經》發源深。驊騮萬里氣，聖途已駸駸。
大梁語三日，副我夙所欽。濂溪無比流，此道日西沉。
百年牛山木，不復秀穹林。南風雖寥寥，聞絃猶賞音。
獨憐夸毗子，一我無古今。共學君所貪，適道我豈任。
相酬無別物，徒有好賢心。

《贈答楊煥然》
前人
[
编辑
]

詩亡又已久，雅道不復陳。人人握和璧，燕石誰當分。
關中楊夫子，高誼世所聞。十年元尚白，藜藿甘長貧。
有來《河水篇》，四海付斯文。斯文有定在，桓生知子雲。
古來知己難，萬里猶比鄰。千人國中和，要非心所親。
東楚西南秦，望君勞我神。相逢不得語，別去徒殷勤。
白雲不可贈，相思秋復春。

《贈答張教授仲文》
前人
[
编辑
]

「秋燈搖搖風拂席，夜聞歎聲無處覓。金筌怨曲《蘭畹辭》，元是寒螿月中泣。世間刺繡多絕巧，石竹殷紅土花碧。窮愁入骨死不銷，誰與渠儂洗寒乞。」東坡胸次
丹青國，天孫繰絲天女織。倒鳳顛鸞金粟尺，裁斷瓊
綃三萬疋。辛郎偷發金錢箱，飛浸海東星斗濕。醉中
握手一長嗟，樂府數年今幾家。剩借春風染華髮，筆
頭留看五雲花。

===
《贈劉潤之》
段克己
===
​
平生不願萬戶侯，但願一識《劉荊州》。荊州已遠不可

見，裔孫今幸從吾遊。慨然議論吐肝膽，腰間古劍鳴
蛟虯。酒酣醉墨出險怪，筆勢儻怳令人愁。世人爭欲
得一諾，黃金不用如山丘。結交以義不以利，樂人之
樂憂其憂。自從管鮑死，此道今悠悠。豈意流落中，忽
見古人儔。古來賢哲仕不達，饑寒不解為身謀。紛紛
「眼底知音少，幾向西風歎白頭。」《次答正卿》
元·楊奐
[
编辑
]

客愁青鏡裏，歸夢白鷗邊。故國人何在，新秋月又圓。
米鹽逢此日，詩酒負殘年。長羨平林鳥，雙飛入暮煙。

《君莫誇少年一首贈余光遠》
戴表元
[
编辑
]

『君莫誇少年，與我憊者疏。我亦嘗少年，少年君不如。談諧今已忘，猶有少年餘。東南山水國，早得飛長裾。春園虎丘樹，夏檻玉泉魚。吳妍與楚豔，過眼日千車。當此秋氣凄，游子易欷歔。我時未更事，意氣益發舒。出門有佳侶，遇勝不得虛。惟憂日晷短，當去亦躊躕。官曹人所厭，高士不肯居。平生縱觀處，最在客南徐』。
姻黨四面集，綵衣擁安輿。停觥待淮蟹，醇甘逮僮胥。
道路無此願，此願勝鄉閭。自從秣陵歸，鬱鬱不得攄。
三間風雨屋，僻在荒林墟。非君好事者，誰能至吾廬。
今來建溪上，逢君屢相于。行藏且勿問，人世有乘除。
舊狂吾已悔，新銳君當袪。男兒不用世，資身在犁鉏。
臨風贈君別，勸君惜居諸。勸君重桑梓，勸君重名譽。
歲晚未相忘，頻寄山中書。

《贈趙子實》
前人
[
编辑
]

北風吹沙溪倒飛，白日未落山中歸。千邀萬覓不相
