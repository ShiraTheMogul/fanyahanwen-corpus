張果星宗二

諸星起例
〈以後諸星起例皆從年干為主〉
[
编辑
]

　　變曜
[
编辑
]

「甲火乙孛」丙屬木，丁是金星戊上求。

己人太陰庚是水，辛炁壬計癸「羅㬋。」訣曰

祿暗福耗蔭貴刑印囚權。

火孛木金土月水炁計羅。

假如甲生人欲推何星化貴，則以祿念至貴是第六字，又念火至月第六字，便知月化貴也。餘倣此推。

凡當年星變為天祿者，即其星管官祿也○。變為暗者屬相貌○，變為福者屬財帛；福德遷移○變為耗者屬兄弟○；變為蔭者屬妻妾○；變為貴者屬男女○；變為刑者屬奴僕○；變為印者屬田宅○；變為囚者屬疾厄○；變為權者屬命宮。此又變曜之所屬也，故其為「管庫星」 云。

天祿
〈仕人遇之主食俸祿庶人有之亦主享福〉
[
编辑
]

祿主當生入命宮，田財旺氣大亨通。

官星更在高強位，年少聲名達聖聰。

凡祿主與官祿並詳，一宜在七強宮，二宜照命，三喜順行，四喜廟旺，五要在當生年，納音、長生臨官帝旺宮，以上並得用，主大富貴。如在五弱宮，或入四殺位，更行留逆，故為福不純，主人淹滯不遂。

天暗
〈此謂吉星化凶須吉而不吉也〉
[
编辑
]

富貴因何福不榮，只緣命裏暗傷星。

高強皆是為兇惡，入陷孤高禍自輕。

凡天暗星與相貌同推此星最忌在官宮，及官魁文星，身命逢之，皆無發達。

天福
〈德者福之基亦要人之有德者必得福壽也〉
[
编辑
]

身宮及命福星臨，廟旺高強享福深。

若遇陷宮并惡曜，榮華消鑠禍難禁。

凡天福與福德財帛遷移同詳，宜照福德為上，身命次之，男女宮見之為上吉，緣此宮與福德相對，故為上。喜在廟旺兼行順段為福，如在陷弱宮及伏逆留段為淺，更宜消詳身命根本，方可斷之。

天耗
〈唐元宗時天耗星盜貴妃玉環及香囊而去帝夢中叱之答曰吾天耗也〉
[
编辑
]

天耗之星不可逢，生來財帛化為空。

若臨貴地并權祿，尚自區區待限通。

凡天耗星與兄弟同推，此星耗財之神，故以兄弟當之，忌在田、財二宮、別宮，無甚害。

天廕
〈主父母榮貴封廕之下〉
[
编辑
]

廕星逄著有操持，須是高強廟旺時。

福祿印權并貴會，官榮極品耀天墀。

凡天廕星與妻妾同推，喜入生旺宮得妻財；入死絕宮主多病。順行則吉，逆行則凶。七強宮見之相宜，五弱宮不利此星，居遷移，主外婿在奴僕，不宜正婚。居四正宮主有妻財。惡星不犯，主夫妻偕老也。

天貴
〈吉星夾之有貴凶星拱夾則賤〉
[
编辑
]

身遇高強及印權，命宮三合更相聯。

貴多刑少居官祿，職位榮華祿更遷。

凡天貴星與男女並，詳此星居七強順行樂廟旺宮，及當生貴人祿馬之位，主生貴子，在遷移奴僕兄弟宮主過房子，或在五弱被惡曜刑破，多主傷剋，更男女宮星陷，主絕嗣。男女星好，還有子。

天刑
〈謂犯徒流賊盜刺字於面於肘者〉
[
编辑
]

天刑若陷最為惡，身命田宅怕逢著。

限臨必主身不全，黥面文身方免卻。

凡天刑星與奴僕同，推此星在閑極宮，無惡曜相犯，奴僕得力，或在七強及得地，主僕從奸狡，更有。
​

凶星入宮，小人無故相侵犯凌辱，此星宜弱不宜強，宜順不宜逆。若是命主星，又不妨無自刑之理。

天印
〈喜官祿等星〉
[
编辑
]

生來須有皇恩命，官祿高強賴此星。

若遇科名科甲貴，因茲食祿播王庭。

凡天印星與田宅並詳，此星喜居田宅宮，及七強入廟生旺之地，主多產業，如留逆無氣，更在閑極陷地，俱不得祖業。田宅宮別有吉星臨照，亦能自創立，如田宅有忌星相犯，加命弱失陷，必無田宅。

天囚
〈若遇闌干貫索相併主牢獄之患〉
[
编辑
]

天囚若在四刑宮，膿血傷殘命夭終。

若是壽星臨照著，也須為福不為凶。

凡天囚星與疾厄同推，此星怕入七強生旺，及在逆段，或照命，或臨身，並不相宜也。若是紫木星為囚星，然其性本善，不可便以囚忌為嫌，但戊癸人見之減力，終不為禍。

天權
〈主有威權掌生殺之職〉
[
编辑
]

權星遇貴在高強，縱有刑囚亦不妨。

更遇合宮高格局，定須官到紫微郎。

凡天權星與命宮並詳此星照命及伴身，若入廟順行，主得貴人扶持，更與太陽福祿同宮，尤奇。

科名
〈假士子用之主名高位重庶人有之亦有聲望〉
[
编辑
]

甲乙生人木向榮，丙丁火宿定科名。

庚辛金兮戊己土，壬癸生人是水星。

此上謂之十干科名星，要在七強順段，旺廟則名位高也；若在五弱之宮及留逆段，雖中科甲，名次低也。

科甲
〈主登高科亦要廟旺得力必中〉
[
编辑
]

科甲之星對命宮，對宮官主要強隆。

如居廟旺登高第，陷時及第必難逢。

假令寅宮安命，與申相對，申宮屬水，即取水星為科甲，要在七強順段，廟旺中高，甲居陷弱又退留，伏段雖貴，甲第必低。

文星
〈文旺身衰仲尼不仕身旺文衰廉頗就武要相均平則貴〉
[
编辑
]

甲羅乙計丙戊金，丁火巳炁庚木星，
辛人見土壬逢日，癸人見月主文名。

文星者，五行相濟而成文也。甲見羅則通明，乙見計，巳見炁則疏通，丙見金則陶鎔，丁見火則光明，戊見金，辛見土則秀氣，壬見日，癸見月則輝光，庚見木則斷削，此皆相濟而成文，獨不以水孛為文者，其無質也。

魁星
[
编辑
]

甲人太陰乙太陽，丙羅丁計戊炎方。

己金庚木辛逢孛，壬炁癸水號「魁光。」魁星者，陰陽和合，相生而成魁，獨不以土為魁者，以土愚濁故也。

官星
〈官者輔君之星也君以之而任政事〉
[
编辑
]

甲炁乙水是官星，丙羅丁計戊孛亨。
己火庚金辛用木，壬月癸土定功名。

官星者，乃十干官星之祿星，《琴堂》謂對祿是也。甲以辛為官，辛以炁為祿，則甲人用炁為官星，十干皆以此例。獨陽君不與者，以其官君之所授也。

印星
〈印者國之璽也君主掌之以信天下之人苟非其人而勿與焉〉
[
编辑
]

甲木乙日丙是熒，丁月戊土巳羅辰。

庚金辛計壬逢水，癸人見孛為印星。

「印星」 者，五行相符合而為印，甲以木，丙以火，戊土庚金壬水是也。五陰干取日月羅計孛，亦以相生而相類，然十一曜獨炁不與者，以其善柔，而非羅計孛之比焉。

催官
〈仕人賴之以薦舉〉
[
编辑
]

甲金乙水丙日安，丁羅戊木見為歡。

己炁庚孛辛土宿，壬月癸計是催官。

催官之星，主遷官進職也。大抵此星與祿主相為催剋，如甲人以火為祿，而見金則催。乙人以孛為祿，而見水則催。丙人以木為祿，而見日則催。丁人以金為祿，而見羅則催是也。十一曜獨火不與者，以其有太陽在焉。

祿神
〈主俸祿〉
[
编辑
]

「甲兼《木孛》乙水星，丙計丁羅」戊土名。

巳火庚金辛紫氣，壬日癸月是祿神。

祿神者，正祿神遇之主食正俸祿。十一曜俱全，而甲獨兼《木孛》者，以其陽干之首也。

喜神
〈主婚姻財喜之類〉
[
编辑
]

甲羅乙計丙炁星，丁水戊月是喜神。
巳土庚金辛見木，壬孛癸火最堪親。

人命月逆行，喜神逆祿，十曜司祿而順布，喜神隨月以逆承，故祿之序「火孛木金土月水炁計羅」 ，而喜神之序羅計炁，水月土金木孛火是也。

爵星
〈主進爵除拜之星〉
[
编辑
]

鼠猴土兮豬羊火，馬牛以水為爵星。

兔逢紫氣虎蛇木，雞犬逢金龍孛欣
​

爵者，地元爵也，自年支中出也。遇之進爵除拜，最要官福，身命有之，又喜在高強相遇。

天馬地驛
〈主陞遷馳驛之類〉
[
编辑
]

申子辰年用火木，寅午戌人是水金。

亥卯未生看木火，巳酉丑年計水真。

其法，以驛馬宮遁祿干所屬為地驛，祿干化祿為天馬。如申子辰人馬居寅，則遁甲祿在寅，以甲木為地驛，以甲火為天馬。又寅午戌人馬居申，則遁庚祿居申，以庚金為地驛，以庚水為天馬。餘倣此推。果老有天馬地驛，起例不同，以五虎遁官祿宮取二者，姑並詳之，惟果老者為切。

卦氣
〈卦氣是天祿之餘身命值之更無混雜主有福祿〉
[
编辑
]

壬甲從乾乙癸坤，戊坎丙艮震居庚。

辛巽己離丁兌位，此係「卦氣八宮神。」以年干為主，且如壬甲生人，從亥上起壬，即是卦氣之位。甲生人亥上，即是卦氣宮也。餘倣此例。

天元祿
〈滿用一星而得三用也〉
[
编辑
]

十曜天元化祿因，五遁迤前命位尋。

何干化祿為天祿，最宜滿用喜垣城。

以年干五虎遁，順數至命宮得何干，以此干化祿為是。且如甲生人寅上立命，以甲己之年起丙寅，就是丙寅宮坐命，以丙干化祿是木，即木為天元祿是也。餘倣此例。化祿者，即前甲火乙孛，丙屬木之類。

地元祿
〈取卦逆命何干屬某是〉
[
编辑
]

欲識地元推卦氣，逆至命裏即干神。

遇有吉星臨滿用，定擬金殿玉階行。

以年干所管卦氣，逆數至命宮，得何干，以此干屬某為是。且如甲生人寅上安命，以壬甲從乾，就於亥上起甲，逆數至寅命宮，得癸干，即以癸屬水，取水為地元祿。餘倣此例。

人元祿
〈以虎順宮何干屬某干為是〉
[
编辑
]

《人元虎遁》來官祿，以干受剋的為真。

中間若有閑神雜，斟酌當加仔細論。

以年干起五虎遁，順數至官祿，得何干，以此干受剋為是。且如甲生人寅上立命，以甲巳之年起丙寅，從寅上起丙，順數至巳上官祿宮，得巳干，即以巳屬土，取木剋土，以木為人元祿，餘依此推。

天經地緯
〈二星用星不用宮以虎順命干屬某是經以命支神屬某是緯〉
[
编辑
]

星有天經地緯神，虎遁輪流至命程。

地支支神名地緯，天干干主是天經。

身命逢他來拱夾，經天緯地有才能。

若值斗標來指破，一生名利算輕塵。

以年干起五虎遁，順數至命宮，得何干支，以干屬某為天經，以地支屬某為地緯，且如甲生人寅上坐命，以甲己之年起丙寅，就是丙寅宮安命，以丙火為天經，以寅木為地緯，餘倣此例。其論支神所屬者，即寅卯屬木，巳午屬火，申酉屬金，亥子屬水，辰戌丑未屬土，切不可以寅亥二宮屬木論也。

天馬地驛
[
编辑
]

《天馬地驛》，果老所著也，與前諸家者不同。

天馬須將五虎遁，遁過命宮官祿論。

論「干得祿歸何所，所屬支神天馬定。」官祿類垣推地驛，只在巳亥寅申局。

不論宮神只在支，即是支神天馬屬。

以年干起五虎遁，順數至官祿得何干支，取干之祿為天馬，取官支馬為地驛。且如甲生人寅上安命，以甲己之年起丙寅，從寅上起丙，順數至巳，官祿得己巳，以丁巳祿居午，取午火為天馬，以巳酉丑馬在亥，取亥水為地驛。餘倣此例。若驛馬有二屬星者，則取左右夾拱用之。

職元
〈主職分〉
[
编辑
]

卦氣順行至命程，干屬化曜職元星。

身命逢之居顯職，凡人遇此幹才能。

以年干起卦氣，順數至命宮，得何干，以此干化祿為是。且如甲生人，寅上安命，以壬甲從乾起，從亥上起甲，順數至命宮，在寅得丁，即以丁火為《職元》。

局主
[
编辑
]

《職元》六合推干化，即是一局主之辰。

命身值此無空破，士庶逢之眾仰欽。

以職元干所合之干，以此干化祿為是。且如前職元是丁，丁與壬合，取壬計為局主是也。

卦氣
〈此為天祿卦氣與前不同〉
[
编辑
]

年干卦氣逆回輪，日月住處定陽陰。

晝生日止夜生月，論干得祿取宮神。

以年干起卦氣，逆數至晝日夜月之宮得何干，以此干祿宮為是。且如甲生人，太陽在酉，以壬申從乾起，從亥上起甲，逆數至酉得丙，以丙戊祿在巳，巳上為卦氣，又名天祿《卦氣。經》曰：「官貴命無卦氣，安能食天祿。」 正謂此也。如乙生人，太陰在卯，以乙癸坤宮起，從申上起乙，逆數至卯上得庚，以庚祿。
​

居申申上為卦氣

斗標
〈斗標者北斗之柄也命無斗標為人不尊重〉
[
编辑
]

月建宮中起戌時，亥時便向次宮移。

順行只喜臨官祿，地緯天經忌見之。

又

命主身星斗柄宮，忌臨殺位怕逢空。

宜居祿貴并生旺，補袞終當立大功。

以戌時加月建，順數至生時為是。且如正月卯時生，正月建寅，以戌時加在寅宮，順數至未，得本生時，為斗標。餘倣此。

注受
〈亦曰陰注陽受〉
[
编辑
]

注：「受正七子垣逢，二六三五亥戌同。」八與臘月丑上立，九寅子月在寅宮。

四酉十卯為截法，身命逢之定富榮。

擎天屬火，遊奕屬水，以《六十花甲》隔節布於十宮，起於子，終於卯，而丑寅不與未申飛變者，以《河漢》始於丑寅，終於未申，而擎天屬火，不入故也。其殺，男怕擎天，女怕遊奕，皆主刑剋。

五行之道，有氣有質，還相本而迭相竭者也。故當時者旺，我生者相，生我者休，剋我者囚，我剋者死。萬物非時不生，觀星非時不驗。星盤之中，四時之星不一。因其時令，察其盛衰，則福之厚薄，禍之淺深，自有稱量於其間矣。。
