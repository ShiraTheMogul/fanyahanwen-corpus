《荷花》
宋·劉筠
[
编辑
]

水國開良宴，霞天湛晚暉。凌波宓妃至，盪槳莫愁歸。
粧淺休啼臉，香清願襲衣。即時聞鼓瑟，他日問支機。
繡騎翩翩過，珍禽兩兩飛。牢收《交甫佩》，莫遣此心違。

《荷花》
楊億
[
编辑
]

「絕岸疏煙合，回塘夕照和。水仙猶度曲，川后自收波。」銀漢橋橫鵲，蘅皋襪濺羅。玉杯承露重，鈿扇起風多。
翠羽芳洲近，青絲快騎過。「石城秋信斷，搔首奈愁何。」《再賦荷花》
前人
[
编辑
]

舒女清泉滿，黃姑列渚通。巴天迷峽雨，楚澤映江楓。
思逐鮫絲亂，香愁翠被空。灑從瓊蕊露，吹任石尤風。
怨淚連疏竹，私書託過鴻。雙魚應共戲，休問葉西東。

《白蓮》
前人
[
编辑
]

昨夜三更裡，嫦娥墮玉簪。馮夷不敢受，捧出《碧波心》。

《賦荷花》
前人
[
编辑
]

翠幄飄香映綺襦，鈿盤清曉露成珠。休啼為近鮫人
室，欲笑誰投玉女壺。雲氣乍迴《巫峽夢》，水嬉猶記《曲
池圖》。金花卻薦何人步，枉遣凌波襪縷濡。

《荷花》
前人
[
编辑
]

瑤水霓旌綺宴陳，漢宮渠怨露華新。誰燃百炬金花
燭，波襪歌梁暗落塵。

《荷花》
錢惟演
[
编辑
]

水闊雨蕭蕭，風微影自搖。徐娘羞半面，楚女妒纖腰。
別恨拋深浦，遺香逐畫橈。華鐙連霧夕，鈿合映霞朝。
淚有鮫人見，魂須宋玉招。凌波終未渡，疑待鵲為橋。

《賦荷花》
前人
[
编辑
]

欲網珊瑚碧浪深，橫塘斜日帶秋陰。漢宮此地留金
餅，洛浦何人遺錦衾。舞學西城迴雅態，歌傳南國有
餘音。韓憑恨魄如長在，青骨香銷亦見尋。

《荷花》
前人
[
编辑
]

唾露金銷月似霜，雲屏玉輦剩秋光。不知惟有《高唐
夢》，翠被華鐙徹曙香。

《荷花》
丁謂
[
编辑
]

「相倚秋風立，蘭言似有無。未饒霜女俊，不愛月娥孤。」力弱煙披素，心危露泣珠。剪裁隨楚思，幽怨寄吳歈。
半拆香囊解，微傾醉弁扶。涉江如可採，百琲答輕軀。

《荷花》
前人
[
编辑
]

夢散《高唐》夜正遙，楚天何處不無聊。秋風似會荊王
意，露渚煙汀養細腰。

《荷花》
杜衍
[
编辑
]

鑿破蒼苔漲作池，芰荷分得綠參差。曉開一朵煙波
上，似畫真妃出浴時。

《紅白蓮》
前人
===
​
芙蓉照水弄嬌斜，白白紅紅各一家。近日新花出新

巧，一枝能著兩般花。

《雨中荷花》
前人
[
编辑
]

翠蓋佳人臨水立，檀粉不勻香汗濕。一陣風來碧浪
翻，珍珠零落難收拾。

《榮歸堂觀蓮戲成》
韓琦
[
编辑
]

風捲蓮香不斷頭，田田荷影動清流。紅苞密障魚鷹
坐，綠蓋低容水馬游。時折嫩梢供玉箸，更裁圓葉代
金甌。何如滿艦傾醇酎，醉向花前打拍浮。

《渚蓮》
范仲淹
[
编辑
]

「武陵誰家子。波面雙雙渡。」空積心中絲，未成機上素。
似共織女期，秋宵苦霜露。

《起居退聞宣三館諸公觀瑞蓮》
梅堯臣
[
编辑
]

來朝十二旒，將出未央殿。微聞嘉蓮開，獨許侍臣見。
嘉蓮其如何？層樓擁霞片。玉輦下天泉，日昃不知倦。
恩魚應亦喜，跳沫珠欲濺。誰憐與眾歸，博士臣疏賤。

《蓮塘》
前人
[
编辑
]

不畏塘雨急，鈿葉自相遮。文禽忽驚去，衝落波上霞。

《荷葉》
歐陽修
[
编辑
]

池面風來波灔灔，陂間露下葉田田。誰于水上張青
蓋，罩卻紅粧唱《採蓮》。

《泉州北藏院見初荷花》
蔡襄
[
编辑
]

初花纔過小荷身，曉露霑紅點點勻。莫為愁心偏倚
望，清江元有未歸人。

《並蔕蓮》
邵雍
[
编辑
]

漢室嬋娟雙姊妹，天台縹緲兩神仙。當時儘有風流
過，謫向人間作瑞蓮。

《芰荷歌》
徐積
[
编辑
]

「孔雀團花翡翠鈿，青皇拋盡買花錢。淥魚飛膽大如拳，琉璃瓦墜紫微天。《湘妃曲譜》誰可傳，彩毫不動斜卷牋。我家食客常三千，杯盤一樣青瑤圓。麻姑下來尋水仙，不見波瀾只見煙。昨夜秋風吹洞房，起來先著碧霞裳。半含笑面齊鬥粧，家家院落紺為牆。不道採花人在傍，貪看飛來白紵郎。」亦有美人貞且良，獨
在碧綃幃下藏。

《芙蓉》
王曄
[
编辑
]

「菡萏初舒艷，奇芬暈碧霄。中洲欣邂逅，南浦自招搖。瑩色涵香霧，新袍拆絳綃。娉婷自珍愛，穠郁更清超。照水臨青鏡，偎蘋倚彩翹。駢枝疑貫寵，並萼似爭嬌。綽約霞初映，披敷煙正銷。鬚蕤金粉嫩，房闖玉冠喬。月下仙人氅，風前公子袍。清虛雲步濕，沈浸瀣津饒。濯濯靈修質，盈盈神女標。孤貞無漫蔓，雅則絕纖妖。」喜動文鴛舞，光搖錦鯉跳。瓊根托紺潔，翠蓋障炎囂。
靚賞聯瑤席，芳搴集桂橈。姚園多猥俗，陶徑亦蕭條。
華井分流潤，天池引脈遙。須移元圃種，莫向若耶漂。
木末興幽詫，濂溪結冥招。懷之思遠道，秋入鬢蕭蕭。
