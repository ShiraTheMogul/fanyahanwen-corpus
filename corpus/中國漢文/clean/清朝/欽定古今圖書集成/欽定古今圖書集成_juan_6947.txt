周憲王有燉
[
编辑
]

按《名山藏》：周定王橚子有燉，是為憲王，博學善書。為
世子時，嘗有「《東書堂帖》行世，所製《樂府新聲》，大梁人歌舞之。」
按《書史會要》：「憲王集《古名跡》十卷，手自摹臨，勒石傳世，名曰《東書堂法帖》。」
安塞王秩炅
[
编辑
]

按《藩獻記》：「安塞王秩炅，慶靖王季子，高皇帝諸孫也。好讀書，善文，精楷書，自稱滄洲野客。」
晉莊王鍾鉉
[
编辑
]

按《藩獻記》：「晉莊王鍾鉉，憲王之子，高皇帝曾孫也。正統七年，以榆社王進封，弘治十五年薨。王好博古，喜法書，嘗以絳帖歲久斷脫，采舊所藏古今名人墨跡，摹刻以傳，號曰『寶賢堂集古法帖』。」
蜀定王友垓
[
编辑
]

按《藩獻記》：「蜀定王友垓，和王之子，獻王之孫也。嗜學善書，能文章。」
蜀惠王申鑿
[
编辑
]

按《名山藏》，「蜀懷王弟申鑿，以通江王進封，是為惠王，好學能文，亦善書。」
鎮平王有爌
[
编辑
]

按《名山藏》：「周定王橚子鎮平王有爌，工詩歌書畫。」
于謙
[
编辑
]

按《吾學編》：「于謙字廷益，錢塘人。永樂十九年進士。文如雲行水湧，有奇氣，詩清麗，頃刻千言。景泰時為兵部尚書，加少保，贈太傅，諡肅愍。」
按：《弇州續槁》：「王世貞《國朝名賢遺墨》」有「于肅愍公書。」
陳詢
[
编辑
]

按《列卿紀》：「陳詢，字汝同，華亭人。永樂戊戌進士，選庶吉士，授編修。景泰五年為國子祭酒。」
按《呂文懿公集》，「詢工於草書，興至輒揮灑，求者恆接踵焉。」
楊翥
[
编辑
]

按《吳中往哲記》：「楊翥，字仲舉。景帝在邸時為宮僚，以醇謹見重。景泰初，用舊臣為禮部侍郎，奉身還吳，宦橐清貧，寓棲故人家，詣闕表賀，受尚書以歸。」
按王世貞《國朝名賢遺墨跋》：「翥所書《梅軒記》，辭翰皆頹然長者。」
王謙
[
编辑
]

按《列卿紀》：「王謙，武進人，領鄉舉，為太常寺少卿。」按《六館日抄》：景泰二年柯潛榜《進士題名碑》，大學士
陳循撰文，太常寺王謙書。

沐璘
[
编辑
]

按《雲南通志》：「沐璘，字廷章，襲指揮僉事。景泰間，為右軍都督同知，鎮雲南。天順初，陞右軍都督。好讀書，長於吟詠，尤工篆籀草書大字。」
汝訥
[
编辑
]

按《匏翁家藏集》：「汝訥，字行敏，吳江人。景泰四年鄉試中式，屢試禮部不中。素善書，會修《英宗實錄》，選入史館，授中書舍人，擢兵部員外郎，再遷郎中，出知南安。書法清勁，得晉人筆意。」
按《懷麓堂集》：「汝君行敏，其為書楷正有法表，然出儕輩。凡卿大夫士所得誥敕，皆願得君手筆，故君書傳於世日多。」
張寧
[
编辑
]

按《吾學編》：「張寧字靖之，海鹽人。景泰五年進士。授禮科給事中。成化時出為汀州知府。」
按《書史會要》：「張寧善書。」
任道遜
[
编辑
]

按《匏翁家藏集》：「任道遜字克誠，瑞安人。七歲能賦詩​作字徑數尺有法。有司以神童薦，宣宗面試其書，命為國子生。景泰初授順天府照磨，仍以書藝供奉，累遷至太常寺卿。自號坦然居士，又號八一道人。」

编辑

按《書史會要》：「曹泰，字時和，號九峰，華亭人。工行書，亦善章草。」

编辑

按《存徵錄》：「羅麟，字仲祥，性敏善書。舉景泰四年鄉試，累官廣東參議。」
劉昌
[
编辑
]

按《續藏書》：「劉昌，字欽謨，吳縣人。正統乙丑進士。景泰初，授南京虞衡主事，終廣東參政。」
按：《弇州續槁》：「王世貞《國朝名賢遺墨》有劉昌書。」
劉嘉䋭
[
编辑
]

按《松籌堂集》，劉嘉䋭字協中，欽謨之子也。年數歲，據
小几習書，選古詩，儼如成人。十五喪父，盡讀其遺書，
年二十四而卒。

按：《吳縣志》，《嘉》䋭文筆如泉湧，詩亦清遠，與楊循吉頡
頏一時。尤善書，最得古法。

聶大年
[
编辑

按《蓉塘詩話》：「聶大年，臨川人。景泰間用薦，起為仁和訓導。博涉群書，篤意古文及唐人詩。書法李北海，其名傳於遐邇。」
何觀
[
编辑

按《名山藏》：「何觀，晉江人。景帝初為中書舍人，謫九溪衛經歷，轉知象山縣，致仕歸。善草書，嫁女無以為奩，與書一簏，隱跡古元山中，不關俗務，鄉人高焉。」

编辑

按《懷麓堂集》：「羅琥，字彥武，茶陵人。以楷書選人中書，授南陽府通判。景泰時，擢南京戶部郎中。」
李淳
[
编辑

按《懷麓堂集》：李淳，號憩菴，茶陵人。精通楷書。東陽書
先府君遺墨後云：「嘗衍『永』字，八法變化三十二勢，及結構八十四例，著論一道。景泰間上之朝。」
林春
[
编辑
]

按《分省人物考》：「林春，字孟陽，代州人。工古文詞，且精書翰。景泰庚午，領鄉薦，授應天通判。性酷好書，每暇輒磨墨伸紙，揮汗呵凍不輟，字體清勁遒麗，得者皆珍襲之。」

编辑

按《海鹽圖經》：「劉泰，字世亨，海鹽人。能詩文，工行草書。景泰中，以庶吉士授監察御史。」

编辑

按《嘉興府志》：「劉侃，字克剛，景泰初，領鄉薦，選知涇州，擢知延平府，謝病受徒自給，號樂閒公。工楷書，詩文亦清麗。」
林宗道

编辑

按《閩書》：「林宗道，字仲學，景定間領鄉薦。為文詞氣豪逸，尤善隸書，晚年用筆益蒼勁。」

按《嘉定縣志》：「封錦，字尚絅，嘉定人。景泰間歲貢，官東平州同知。善篆隸，亦能行草。」
錢曄
[
编辑

按《常熟縣志》：「錢曄，字允暉，常熟人。景泰間為浙江都司經歷。能書真隸大字，善吟。常闢南皋別業，有山水花竹之勝，日與騷人觴詠自娛。」
汪瀚
[
编辑

按《徽州府志》：「汪瀚，字以淵，善真草書。領景泰癸酉鄉薦，授福州通判，終處州同知。」
朱曄
[
编辑
]

按《臨安府志》：「朱曄，字寅仲，建水州人。能詩，工書畫。都督沐璘重禮之。」
徐有貞
[
编辑
]

按《吳中往哲像贊》：「徐有貞，初名珵，字元玉。舉進士，改庶吉士，授編修。後迎太上皇於南城，復辟，進兵部尚書，華蓋殿大學士，封武功伯。於書少所不窺，能詩歌，善行草，得長沙素，師米襄陽風。」
按《書史會要》：「武功書法，古雅雄健，名重當時。」
岳正
[
编辑
]

按《懷麓堂集》：「岳正字季方，別號蒙泉，漷縣人。正統戊辰進士，授編修。英宗復辟直內閣，憲宗時出知興化​府。為文高簡峻拔，追古作者。詩亦雅健脫俗，字法精邃，大書尤偉，旁及雕繪鐫刻，悉臻其妙。」
彭時
[
编辑
]

按《列卿紀》：「彭時，字純道，安福人。正統戊辰進士第一，天順初，拜為吏部尚書，文淵閣大學士，贈太師，諡文憲。」
按：《弇州續槁》《國朝名賢遺墨》有彭時書。

葉盛

编辑

按《列卿紀》：「葉盛，字與中，崑山人。正統乙丑進士。授兵科給事中，進都給事中，遷山西參政。天順二年，英宗驛召至京，擢僉都御史。終吏部侍郎，諡文莊。」
按《書史會要》：「葉盛善行楷，得蘇文忠筆意。」
劉鉉

编辑

按《名山藏》：「劉鉉字宗器，長洲人。永樂中以善書徵入翰林。筆法溫媚，推重一時。久之，中鄉試，授中書舍人。景帝時為國子祭酒。英宗復辟，擢少詹事，贈禮部侍郎，諡文恭。」
周瑄
[
编辑
]

按《列卿紀》：「周瑄字德孚，陽曲人。宣德乙卯鄉舉，授刑部主事。天順二年為刑部侍郎，終南京刑部尚書。」按《析津日記》，《玉虛觀碑》，「禮部尚書吳濙撰，刑部侍郎周瑄篆。」
李紹
[
编辑
]

按《列卿紀》：「李紹，字克述，江西安福人。宣德癸丑進士，選庶吉士。天順中為禮部侍郎。刻苦問學，有異書及古碑文字，必購求之。字畫出入晉、唐間，參以蘇長公，剛勁奇逸，自成一家。」
按《分省人物考》：「李紹與人評書，必先法度，見有稍不合，則曰：『是無師承，不足觀也』。」
黃諫
[
编辑
]

按《列卿紀》：「黃諫，字廷臣，蘭州人。正統壬戌進士及第，授編修。天順中，為侍講學士。博涉諸經子史百氏之書，為文根極埋致，尤工於詩，兼善書，工古篆隸。」按《玉劍尊聞》：「黃諫博學工書，著《從古正文》五卷，藝林宗之。」
趙昂
[
编辑
]

按《懷麓堂集》：「趙昂，字伯顒，號竹溪，常山人。正統乙丑進士，授中書舍人。英廟復辟，超擢通政使司左參議。仕雖未達，而姓氏甚著。童兒隸卒皆稱為趙伯顒先生，無異辭。尤博涉群籍，苦吟詠，工書翰。」
劉玨
[
编辑
]

按《吳中往哲像贊》：「劉玨字廷美，號完菴，長洲人。舉應天鄉試，補太學生，授刑部主事，遷山西按察僉事。老而嗜學不衰。為詩清麗可詠，書正行出趙吳興。」按《吳中人物志》：「劉玨書效雲麾，行草各極其妙。」
官廉
[
编辑
]

按《劉古直集》：「官廉字汝清，東萊平度人。登天順甲申進士，授工部主事，終戶部郎中。楷、行、草書頗得二王法。」
按《張文僖公集》，「官廉，最好晉人遺帖，雖疾猶臨倣不懈。」
孔公恂

编辑
]

按《吾學編》：「孔公恂，字宗文，穎敏絕人，能詩善書。天順丁丑進士，給事中，禮科陞少詹事。」
胡信
[
编辑
]

按《鎮江府志》：「胡信，字宗實，丹徒人。天順元年進士。授戶部主事，遷知鶴慶軍民府。為詩文溫潤典則，書法得晉人體。」
