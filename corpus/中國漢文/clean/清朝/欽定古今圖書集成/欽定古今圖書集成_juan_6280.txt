《織婦怨》
宋·文同
[
编辑
]

「擲梭兩手倦，踏繭雙足趼。三日不住織，一匹纔可剪。織處畏風日，剪時謹刀尺。皆言邊幅好，自愛經緯密。昨朝持入庫，何事監官怒。大字雕印文，濃和油墨污。父母抱歸舍，拋向中門下。相看各無語，淚迸若傾瀉。質錢解衣服，買絲添上軸。不敢輒下機，連宵停火燭。當須了租賦，豈暇恤襦褲。前知寒切骨，甘心肩骭露。」里胥踞門限，叫罵嗔納晚。安得織婦心，變作監官眼。

《浣溪女詩》
陸游
[
编辑
]

江頭女兒雙髻丫，常隨阿母供桑麻。當戶夜機聲吚
啞，地爐豆䕸煎土茶。長成嫁與東西家，柴門相對不
上車。青裾《竹笥》何所差，插髻曄曄牽牛花。城中妖姝
臉如霞，爭嫁宮中慕豪華。青驪出入天之涯，年年傷
春抱琵琶。

《白紵詞》
葉適
[
编辑
]

有美一人兮表獨處，陟彼南山兮伐寒紵。挑燈細緝
抽苦心，冰花織成雪為縷。不憂絕技無人學，只愁不
堪嫁時著。鄭僑吳札今悠悠，爭看買笑錦纏頭。

《春日曲》
徐照
[
编辑
]

中婦掃蠶蟻，挈籃桑葉間。小姑摘新茶，日斜下前山。

《羅敷詞》
戴復古
[
编辑
]

妾本秦氏女，今春嫁王郎。夫家重蠶事，出採陌上桑。
低枝採易殘，高枝手難扳。踏踏竹梯登樹杪，心思蠶
多苦葉少。舉頭桑枝挂鬢唇，轉身桑枝勾破裙。辛苦
事蠶桑，實為良家人。使君奚所為？見妾駐車輪。使君
口有言，羅敷耳無聞。蠶飢蠶飢，採葉急歸。

《縫衣詩》
謝幼睿
[
编辑
]

懶向籹臺理曉妝，為郎獨自製衣裳。金針入處心俱
痛，素線牽時恨共長。霜戶敢辭纖手冷，芸窗思貼弱
肌香。縫成不怪無鴻雁，贏得宵來覆妾床。

《採桑曲》
鄭震
[
编辑

《晴採桑》，雨採桑，田頭陌上家家忙。去年養蠶十分熟，
蠶姑只著麻衣裳。

《染絲上春機二首》
許棐
[
编辑
]

染絲上春機，春濃絲色淺。妾心隨梭飛，郎心如軸轉。

其二

染絲上春機，錦成貴無價。不忍裁成衣，怕剪鴛鴦破。

《採桑行》
陳允平
[
编辑
]

「妾本秦羅敷，家住曲江曲。門前楊柳青，春風啼布縠。樹頭桑初芽，家家蠶始浴。相呼出採桑，採桑如採玉。屈曲迴高枝，攀條剪柔綠。朝晴採桑南，暮雨採桑北。採得桑歸遲，小姑怨相促。陌上綺羅人，問妾眉何蹙。妾恨妾自知，問妾何所欲。消磨三十春，漸喜蠶上簇。七日收得繭百斤，十日繅成絲兩束。一絲一線工，織」成羅與縠。百人共辛勤，一人衣不足。舉頭忽見桑葉
黃，低頭垂淚羞布裳。

《促刺詞》
徐集孫
[
编辑
]

促刺復促刺，勸織聲轉劇。小婦跣雨採桑歸，大姑煮
雪抽絲繹。辛勤欲織禦寒衣，朝暮惟恐不盈尺。織成
門外迫催租，不了輸租仍賣綌。婦姑對泣兒號寒，更
無可補。兒衣隙帛暖，本擬代綌寒，賣綌寒來愈無策。
促刺兮促刺，勸人織兮織何益。貯之金屋是何人，重
重綾錦飾珠璧。

《織婦歎》
謝翱
[
编辑
]

待得原蠶繭上絲，織成送女去還歸。支機本是寒砧
石，留取秋深自搗衣。

《寄邊衣》
裴說
[
编辑
]

「深閨乍冷開香篋，玉著微微濕紅頰。一陣霜風殺柳條，濃煙半夜成黃葉。重重白練明如雪，獨下閒階轉凄切。祇知抱杵搗秋砧，不覺高樓已無月。時聞塞雁聲相喚，紗窗只有燈相伴。幾展齊紈又懶裁，離腸恐逐金刀斷。細想儀形執牙尺，回刀剪破澄江色。愁捻金針信手縫，惆悵無人試寬窄。時時舉手勻殘淚，紅」牋漫有千行字。書中不盡心中事，一半殷勤託邊使。

《蠶婦》
張俞
[
编辑
]

昨日到城郭，歸來淚滿巾。遍身羅綺者，不是養蠶人。

此中非不愛羅衣，月曉霜寒不下機。織得羅成還不

燒罷心香午夜闌，玉纖輕捻剪刀寒。衣成恐不如郎

《寄衣戍所》
鄧氏
[
编辑
]

欲寄寒衣上帝都，連宵裁剪眼模糊。可憐寬窄無人
試，淚逐西風灑去途。

《題織圖》
元·趙孟頫
[
编辑
]

三月蠶始生，纖細如牛毛。婉孌閨中女，素手握金刀。
切葉以飼之，擁紙散週遭。庭樹鳴黃鳥，發聲和且嬌。
蠶飢當採葉，何暇事遊遨。田時人力少，丈夫方種苗
​
相將挽長條，盈筐不終朝。數口望無寒，敢辭終歲勞。

其二

四月夏氣清，蠶大已屬眠。高首何昂昂，蛾眉復娟娟。
不憂桑葉少，遍野如輕煙。相呼攜筐去，迢遞立遠阡。
梯空伐條枚，葉上露未乾。蠶飢當早歸，秉心靜以專。
飭躬修婦事，黽勉當盛年。救忙多女伴，笑語方喧然。

其三

釜下燒桑柴，「取繭投釜中。纖纖女兒手，抽絲疾如風。田家五六月，綠樹陰相蒙。但聞繰車聲，遠接村西東。旬日可經絹，弗憂杼軸空。婦人能蠶桑，家道當不窮。更望時雨足，二麥亦稍豐。酤酒田家飲，醉倒嫗與翁。」其四

七月暑尚熾，長日弄機杼。頭蓬不暇梳，揮手汗如雨。
嚶嚶時鳥鳴，灼灼紅榴吐。何心娛耳目，往來忘傴僂。
織為機中素，老幼要紉補。青燈照夜梭，《蟋蟀》窗外語。
辛勤亦何有，身體衣幾縷。嫁為田家婦，終歲服勞苦。

其五

池水何洋洋，漚麻水中央。數日庶可取，引過兩手長。
織絹能幾時，織布已復忙。依依小兒女，歲晚歎無裳。
布襦不掩脛，念之熱中腸。朝緝滿一籃，暮緝滿一筐。
行看機中布，計日漸可量。我衣苟已成，不憂天早霜。

其六

季秋霜露降，凜凜寒氣生。是月當授衣，有布織未成。
天寒催刀尺，機杼可無營。教女學紡纑，舉足疾且輕。
舍南與舍北，嘒嘒聞車聲。通都富豪家，華屋貯娉婷。
被服雜羅綺，五色相間明。聽說貧家女，惻然當動情。

《憫蠶婦》
黃應元
[
编辑
]

「出門天未明，歸來日過午。」遍身羅綺人，寧知採桑苦。

《織女圖》
薩都剌
[
编辑
]

「蘭閨織錦秦川女，大姬啞啞弄機杼。小姬織倦何所思，簾幕無人燕雙語。成都花發江水春，門前馬嘶車轔轔。髻鬟兩珥看欲墮，蛾眉八字畫不伸。良人一去無消息，冰蠶吐絲成五色。」柔腸九曲細為絲，萬縷春
愁正如織。綺窗睡起聞早鶯，西樓月落金盆傾。暖霞
拂地海棠曉，香雪潑戶梨花晴。日長深院機聲動，梭
「影穿花飛小鳳。水心驚起鴛鴦棲，花底不成蝴蝶夢。纖纖玉指柔且和，香鉤小襪裁春羅。滿懷心事付流水，盪日雲錦生層波。佳人自古多命薄，風裏楊花隨處落。豈知醜婦嫁田家，生則同衾死同槨。君不聞，長安市上花滿枝，東家蝴蝶西家飛。籠中鸚鵡喚新主，門外侍兒更故衣。」「又不聞，田家婦，日」掃春蠶宵織布。
催租縣吏夜打門，荊釵布裙夫短褲。我題此畫三嗟
吁，百年醜好皆虛無。排雲便欲叫閶闔，為我獻上《豳
風圖》。

《梳頭樂府》
前人
[
编辑
]

紅綃捲袖搖劍聲，摩挲睡眼窺秋菱。陽臺夢斷不知
處，一片烏雲愁欲傾。一鉤新月掀雲起，月漸低流麻
草地。玉纖盤轉戲龍形，寶釵壓定飛鴉翅。撩春撥曉
誇自然，黃金雙燕珍珠蟬。白頭老嫗低低笑，不覺婆
婆二八年。

《織錦》秦川窈窕娘，新翻花樣學宮坊。窗虛轉軸鶯聲

《蟠車》
王禎
[
编辑

績紡功才畢，蟠纑得此車。行桄運樞臬，交輳寄橫義。
宛轉金釵手，周旋里布家。豈知羅綺輩，惟務撥琵琶。

《擣衣》
張端
[
编辑
]

為擣清砧素，令人念槁砧。近寒將鴈至，入夜正蛩吟。
霜月三更杵，關山萬里心。金風何太弱，不與送餘音。

《繅絲行》
馬祖常
[
编辑
]

繅車軋伊繭抽絲，桑薪煮水急莫遲。黃絲白絲光縰
縰，老蠶成蛹啖兒飢。田家婦姑喜滿眉，賣絲得錢買
羃䍦。翁叟慣事罵婦姑，只今長男戍葭蘆。秋寒無衣
霜裂膚，鳴機織素將何須。翁叟喃喃罵未竟，當門叫
呼迎縣令。騶奴橫索馬鞭絲，婦姑房中拆《纑經》。

《春詞》
胡天游
[
编辑
]

綠窗紅燭製春衣，宮樣花紗要入時。玉手怕裁雙鳳
破，并刀欲下更遲遲。

《織婦吟二首》
舒頔
[
编辑
]

妾家住西湖，家貧守清素。年方二十初，學織常恐暮。
父母生我時，不識當門戶。夫君良家子，安肯受辛苦。

其二

機織不畏多，但畏官府促。去年布未輸，今年糧未足。
阿姑八旬餘，縮首檐下曝。君戍憂邊庭，妾心念機軸。

《繅絲歎》
前人
[
编辑
]

「東家繅絲如蠟黃，西家繅絲白如霜。黃白絲出蠶口，長短繅出婦手。大姑停車愁解官，小姑剝繭愁冬寒。向來苦留二月賣，去年宿債今未還。」手足皸瘃事亦
小，官府鞭笞何日了。吏胥夜打門，稚耋生煩惱。君不
​
見，江南人家種麻勝種田。臘月忍凍衣無邊，卻過廬
州換木綿。

《織婦吟二首》
舒遜
[
编辑
]

《錦織並蔕花》，花成謾停梭。停梭復細看，人與花如何。
明月照中天，敗葉鳴寒柯。誰知恩愛心，翻成離恨多。

其二

雙星照短牖，孤月懸高枝。仰睇星月明，對此令人悲。
手持《并州刀》，為君裁寒衣。不忍密密縫，此心君應知。

《織錦歌》
劉詵
[

《韓子外儲說》：鄭縣人卜子使其妻為褲，其妻問曰：「今褲何如？」夫曰：「象吾故褲。」妻子因毀新，令如故褲。
劉向《列女傳》：齊女徐吾者，齊東海上貧婦人也，與鄰
婦李吾之屬會燭相從夜績。徐吾最貧，而燭數不屬，
李吾與其屬曰：「徐吾燭數不屬，請無與夜也。」徐吾曰：
「是何言與？妾以貧燭不屬之故，起常先，息常後，灑掃陳席，以待來者，自與蔽薄，坐常處下，凡為貧燭不屬故也。夫一室之中，益一人燭不為暗，損一人燭不為明，何愛東壁之餘光，不使貧妾得蒙見哀之恩，長為妾役之事，使諸君常有惠施於妾，不亦可乎？」李吾莫
能應，遂復與夜，終無後言。君子曰：「婦人以辭不見棄於鄰，則辭安可以已乎？《詩》云：『辭之輯矣，民之協矣』」，此
之謂也。

《搜神記》：漢董永，千乘人，少偏孤，與父居，肆力田畝，鹿
車載自隨。父亡無以葬，乃自賣為奴，以供喪事，主人
知其賢，與錢一萬遣之，永行三年，喪畢欲還主人供
其奴職，道逢一婦人曰：「願為子妻。遂與之俱，主人謂永曰：『以錢與君矣』。永曰：『蒙君之惠，父喪收藏，永雖小人，必欲服勤致力，以報厚德。主人曰：『婦人何能』』？」永曰：
「能織。」主曰：「必爾者，但令君婦為我織縑百疋。」於是永
妻為主人家，織十日而畢。女出門謂永曰：「我，天之織女也，緣君至孝，天帝令我助君償債耳。」語畢，凌空而

晉愍帝時，零陵太守趙子元出門見一女子，姿容甚
美，年可十五。子元見而詰之曰：「汝何人之子，而敢獨行，又無伴侶？」女子曰：「我是客人，寄居城外，拋離父母，又無伴侶，孤眠獨處，何以問之？」子元不疑是鬼。又問
曰：「既無倚依，還善製衣否？」女子對：「善製衣。」子元曰：「可為作衣，吾與汝錢。」女曰：「諾。」乃使入宅中，每作一衣，與
錢一百文。經三年，往來宅內，大小愍之，或造衣服，而
多與酬之。忽一日，來告辭子元，愍之與金鑷子一枚，
金釵子一隻，細絹二匹。女子受得，拜辭太守：「明日必歸鄉里，不復來也。」太守乃使人送出城外，不辭而去。
行不數步，倏然不見。家人怪之。時有人出城，便同往
尋問。約二百餘步，見有一塚。詢訪近鄰，云是一女子
墓。不旬日，其父母發取女屍，於祖父塋內安葬，開塚
出棺改斂，見銅錢無數，并有金釵子一隻，金鑷子一
枚，細絹二匹，甚異之。後問其由，方知太守與之，太守
方知造衣女子之鬼在此，時人信鬼神，變易不可及。
《齊諧記》：吳縣張成夜起，忽見一婦人立於宅上南角，
舉手招成，成即就之，婦人曰：「此地是君家蠶室，我即是此地之神。明年正月半，宜作白粥泛膏於上祭我也。必當令君蠶桑百倍。」言絕失之。成如言作膏粥，自
此後大得蠶。今正月半作白膏粥，自此始也。

《述異記》：「園客者，濟陰人，貌美，人多欲妻之，客終不娶。常種五色香草，積十餘年，服食其實，忽有五色蛾集香草上，客薦之以布，生華蠶焉。至蠶時，有一女自來助養蠶，以香草食之，得繭二百二十枚，繭大如甕，每一繭繅六七日絲方盡。繅訖，此女與客俱仙去。」《異聞錄》：「馮媼者，廬江里中嗇夫之婦，窮寡無子。元和四年」，淮楚大歉，媼逐食於舒，途經牧犢墅，暝直風雨
止於桑下。忽見路隅一室，燈燭熒熒，媼因詣求宿，見
一女子，年二十餘，容服美麗，攜三歲兒，倚門悲泣。前
又見老叟與媼據床而坐，神氣慘戚，言語呫囁，有若
徵索財物之狀。見馮媼至，叟媼默然捨去。女久乃止
泣。入戶，備餼食，理床榻，邀媼食息焉。媼問故，女復泣
曰：「此兒父，我之夫也。」明日別娶，媼曰：「向者二老人何人也？於女何求而發怒？」女曰：「我舅姑也。今嗣子別娶，徵我筐筥刀尺，祭祀舊物，以授新人，我不忍與，是有斯責。」媼曰：「汝夫何在？」女曰：「我淮陰令梁倩女，適董氏七年，有二男一女，男皆隨父女，即此也。今前邑中董江即其人也。江官為酇丞」，家累巨產，發言不勝嗚咽，
媼不之異，又久困寒餓，得美食甘寢，不復言。女泣至
曉，媼辭去。行二十里，至桐城縣，縣東有甲第，張簾帷，
具羔雁，人物紛然，云今夕有官家禮事。媼問其郎，即
董江也。媼曰：「董有妻，何更娶焉？」邑人曰：「董妻及女亡矣。」媼曰：「昨宵我遇雨，寄宿董妻梁氏舍，何得言亡？」邑
人詢其二老容貌，即董江之先父母也。董江本舒州
人，里中皆得詳之。有告董者，董以妖妄罪之，令部者
逐媼去。媼言於邑人，邑人皆為感嘆，是夕，董竟就婚
焉。

回，走出門，遂甦，今尚無恙。
