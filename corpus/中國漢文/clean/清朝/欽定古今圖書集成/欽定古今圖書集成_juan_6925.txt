南平穆王鑠
[
编辑
]

按《南史》本傳：「宋南平穆王鑠，字休元，文帝第四子也。少好學，有文才。未弱冠，擬古三十餘首，時人以為跡亞陸機，進司空，贈司徒。」按《述書賦》，「南平筆力，結構老成。」海陵王休茂
[
编辑
]

按《南史》本傳：「宋海陵王休茂，文帝第十四子也，為雍州刺史。」按《述書賦》，「休茂長於用筆結字。」劉穆之
[
编辑
]

按《宋書》本傳：「劉穆之，字道和，小字道民，東莞莒人。與朱齡石並便尺牘，常於高祖坐與齡石答書，自旦至中，穆之得百函，齡石得八十函，而穆之應對無廢也。裁有閒暇，手自寫書，尋覽篇章，校定墳籍。疾卒，贈南昌縣侯。高祖受禪，進南康郡公，諡文宣。」按《述書賦》，「道和閑雅，高蹤絕塵。」朱齡石
[
编辑
]

按《南史本傳》：「朱齡石，字伯兒，沛國沛人也。封豐城侯，為雍州刺史。」按庾肩吾《書品》，朱齡石《書品》下之中。

王曇首
[
编辑
]

按《南史本傳》：「王曇首，太保弘之弟也。幼有素尚，兄弟分財，曇首唯取圖書而已。文帝即位，為侍中，遷太子詹事，追封豫寧縣侯，諡曰文。」按《宣和書譜》：王曇首作草字，雖未足以與古人方駕，
要之是一代宗臣，而人物典刑，千古如在。況其行筆
痛快，亦是自有可觀者也。今御府所藏草書一：《餘念
帖》。

编辑

按《宋書》本傳：「王微，字景元，琅邪臨沂人，太保弘弟子也。少好學，無不通覽，善屬文，能書畫。除中書侍郎，贈祕書監。」徐羨之
[
编辑

按：《宋書》本傳，「徐羨之，字宗文，東海剡人也。高祖踐阼，封南昌縣公，揚州刺史。」按庾肩吾《書品》，徐羨之《書品》下之下。

今見《草書》四行。

宗炳
[
编辑
]

按《宋書》本傳：「宗炳，字少文，妙善琴書，精於言理。元嘉初，徵為太子中書舍人，不應。」按論書，宋中庶宗炳出《九體書》，所謂「縑素書、簡奏書、牋表書、弔記書、行狎書、楫書、槁書、半草書、全草書」，此
九法極真草書之次第。

按《書品》，「後宗炳放逸屈攝，頗效康、許。量其直置孤梗，是靈運之流。」戴顒
[
编辑
]

按《宋書》本傳：「戴顒，字仲若，譙郡銍人也。父逵，兄勃並隱遯有高名，父善琴書，顒並傳之，世居剡下。後出居吳，元嘉中，徵並不就。」謝靈運
[
编辑
]

按《宋書》本傳：「謝靈運，陳郡陽夏人也。襲封康樂公，出為永嘉太守。靈運詩書皆兼獨絕，每文竟，手自寫之，文帝稱為二寶。」按《南史謝瞻傳》：「瞻與從叔琨、族弟靈運俱有盛名。嘗作《喜霽詩》，靈運寫之，琨詠之。王弘在坐，以為三絕。」按虞龢《論書表》：「謝靈運母劉氏，子敬之甥。故靈運能書而特多王法。」按《書斷》：謝靈運模憲小王，真草俱美。王僧虔云：「子敬上表，多在中書雜事中，靈運竊寫，易其真本，相與不疑。元嘉初，帝就索始進。」按《宣和書譜》：「謝靈運少好學，博綜群書，作為文辭，擅​江左之譽。學王羲之，真草，俱造其妙，草字尤為人所推與。」今御府所藏草書一古詩帖。

謝方明
[
编辑
]

按《宋書》本傳，「謝方明，陳郡陽夏人。高祖受命，為丹陽尹，轉會稽太守。」按《述書賦》，「方明寬和隱媚。」〈注〉
今見《正書》三行。

謝惠連
[
编辑
]

按《宋書謝方明傳》：「方明子惠連，年十歲能屬文，族兄靈運深相知賞。元嘉七年，為彭城王法曹行參軍。」按《歷代名畫記》：「惠連書畫並妙。」謝綜
[
编辑
]

按《宋書謝景仁傳》：「景仁弟述，述子綜，有才藝，善隸書，為太子中舍人。」按王僧虔《論書》，「謝綜書緊潔生起，實為得賞。至不重羊欣，欣亦憚之，書法有力，恨少媚好。」羊欣
[
编辑
]

按《宋書》本傳：「羊欣，字敬元，泰山南城人也。父不疑，桂陽太守。欣少靖默，無競於人。美言笑，善容止，汎覽經籍，尤長隸書。不疑初為烏程令，欣時年十二。時王獻之為吳興太守，甚知愛之。獻之嘗夏月入縣，欣著新絹帬畫寢，獻之書帬數幅而去。欣本工書，因此彌善。起家輔國參軍，府解還家。隆安中，朝廷漸亂，欣優游」私門，不復進仕。會稽王世子元顯每使欣書，常辭不
奉命。除中散大夫。素好《黃》《老》，常手自書章。

按：王僧虔《論書》，「欣書見重一時，行、草尤善，正乃不稱名。」按《書斷》，羊欣師資大令，親承妙旨。時人云：「買王得羊，不失所望。」今大令書中風神怯者，往往是羊也。
按《宣和書譜》，羊欣長隸書，其學出於獻之。而論者謂
欣學獻之，如顏回與夫子有步趨之近，雖號入室，終
不能度越獻之規矩，使洒落奔放，自成一家。故又有
婢作夫人之誚，以其舉止羞澀，終不似真，豈謂是耶？
欣嘗撰《續筆陣圖》一卷，又譔《古昔能書人名》一卷，以
此尢見其用心焉。今御府所藏草書一《筆精帖》。

孔琳之
[
编辑
]

按《宋書》本傳：「孔琳之，字彥琳，會稽山陰人。好文義，解音律，能彈棋，妙善草隸。永初二年，為御史中丞，遷祠部尚書，贈太常。」按《書斷》：孔琳之善草、行，師於小王，稍露筋骨，時稱曰：
「羊真孔草。」又以縱快比於桓元。王僧虔云：「孔琳之放縱快利，筆跡流便，二王已後，略無其比。但工夫少，太自任，故當劣於羊欣。」按《宣和書譜》：「琳之作行草，度越流輩。蓋其所養豪放，恥事遲拙，故筆端流暢快健，若不凝滯於物者。」今御
府所藏行書一《日月帖》。

蕭思話
[
编辑
]

按《南史本傳》：「蕭思話，南蘭陵人，孝懿皇后弟子也。工隸書，為散騎常侍，後拜郢州刺史。贈征西將軍，開府儀同三司，諡曰穆侯。」按《書斷》：蕭思話工書，學於羊欣，得其體法。王僧虔云：
「蕭令法羊欣，風流媚態，殆欲不減，筆力恨弱。」袁昂云：
「羊真、孔草，蕭行、范篆，各一時之妙也。然上方琳之不足，下方范曄有餘。」按《宣和書譜》：蕭思話方十許歲時，未知書，以博奕遊
遨為事，好騎屋棟，打腰鼓，侵惱鄰里，人多患之。稍長，
遂折節讀書作字，於是聲譽藉甚。初學書於羊欣，下
筆綿密𡞲婷當時有「鳧鷗鴈騖，遊戲沙汀」之比，然所
得乃其正書耳。今御府所藏正書一：《奏事帖》。

范曄
[
编辑
]

按《南史》本傳：「范曄，字蔚宗，小字塼。少好學，善為文章，能隸書，曉音律，累遷左衛將軍、太子詹事。及逆謀入獄，上有白團扇甚佳，送曄令書，出詩賦美句。曄受旨，援筆而書曰：『去白日之照照，襲長夜之悠悠』。上循覽悽然。曄自序云：『吾書雖小，小有意，筆勢不快。餘竟不成就，每愧此名』。」按《論書》，范曄與蕭思話同師羊欣，然范後背叛，皆失
故步，名亦稍退。

按袁昂《書評》：「羊真、孔草，蕭行、范篆，各一時絕妙。」按《書斷》：「范蔚宗工草隸小篆，尤精師範。羊欣不能儁拔。諸葛長民亦善行草，論者以為蔚宗之流也。」薄紹之
[
编辑
]

按《書斷》：「薄紹之，字敬叔，丹陽人。官至給事中。善書，憲章小王，風格秀異。其行草倜儻，時越羊欣。」按《宣和書譜》：「『紹之善書。袁昂評其字勢，謂如舞女低腰，僊人遠嘯』。以是言之，則必以婉麗清閒為主矣。」今
御府所藏草書二《日寒帖》千文。

[

按《梁書》本傳：「『蕭子雲，字景喬，子恪第九弟也。善草隸書，為世楷法。自云善效鍾元常、王逸少，而微變字體』。答敕云：『臣昔不能拔賞，隨世所貴，規摹子敬，多歷年所。年二十六，著《晉史》至《二王列傳》。欲作論草隸法，言不盡意，遂不能成，略指論飛白一勢而已。十許年來，始見敕旨。《論書》一卷，商略筆勢，洞徹字體』。」又以逸少

式始變。子敬全範元常。逮爾以來，自覺功進。其書跡
雅為高祖所重。嘗論子雲書曰：「筆力勁駿，心手相應，巧踰杜度，美過崔寔，當與元常並驅爭先。」其見賞如
此。出為東陽太守，太清元年，復為侍中國子祭酒。
按《南史》本傳：子雲為東陽太守，百濟國使人至建鄴
求書，逢子雲為郡，維舟將發，使人於渚次候之，望船
三十步許，行拜行前。子雲遣問之，答曰：「侍中尺牘之美，遠流海外，今日所求，唯在名跡。」子雲乃為停船三
日，書三十紙與之，獲金貨數百萬。性吝，自外答餉，不
書好紙。好事者重加賂遺，以要其答。

書。

按《書斷》：子雲少善草行小篆，諸體兼備。而刱造小篆

​
比肩。但少乏古風，抑居妙品。故歐陽詢云：「張烏巾冠世，其後逸少、子敬又稱絕妙爾。」飛而不白，蕭子雲輕
濃得中，蟬翼掩素，游霧崩雲，可得而語。其真草少師
子敬，晚學元常，及其暮年，筋骨亦備，名蓋當世，舉朝
效之。其肥鈍無力者，悉非也。景喬隸書飛白入妙，小
篆、行、草、章草入能。
