鴻鴈部藝文二
〈詩詞〉
[
编辑
]

《鴈詩》
魏·應瑒
[
编辑
]

《朔鴈鳴雲中》，音響一何哀。問子遊何鄉，戢翼正徘徊。
言我塞門來，將就衡陽棲。往春翔朔土，今冬客南淮。
遠行蒙霜露，毛羽日摧頹。常恐傷肌骨，身隕沉黃泥。

《歸鴻》
宋·顏延之
[
编辑
]

昧旦濡和風，霑露踐朝暉。萬有皆同春，鴻鴈獨辭歸。
相鳴去澗汜，長引發江畿。皎潔登雲侶，連綿千里飛。
長懷河朔路，獨與湘漢違。

《鳴鴈行》
鮑照
[
编辑
]

《邕邕》鳴鴈鳴始旦，齊行命侶入雲漢。中夜相失群離
亂，留連徘徊不忍散。憔悴容儀君不知，辛苦風霜亦
何為。

《賦得隴坻鴈初飛》
梁·簡文帝
[
编辑
]

高翔憚闊海，下去怯虞機。霧暗早相失，沙明還共飛。
隴狹朝聲聚，風急暮行稀。雖殄輪臺援，未解龍城圍。
相思不得返，且寄別書歸。

《夜望單飛鴈》
同前
[
编辑
]

天河霜白夜星稀，一鴈聲嘶何處歸。早知半路應相
失，不如從來本獨飛。

《詠湖中鴈》
沈約
[
编辑
]

白水滿春塘，旅鴈每迴翔。唼流牽弱藻，斂翮帶餘霜。
群浮動輕浪，單汎逐孤光。懸飛竟不下，亂起未成行。
刷羽同搖漾，一舉還故鄉。

《八詠詩晨征聽曉鴻》
前人
[
编辑
]

「聽曉鴻，曉鴻度將旦。」跨弱水之微瀾，發成山之遠岸。
怵春歸之未幾，傷此歲之云半。出海漲之蒼茫，入雲
途之瀰漫。無東西之可辨，孰遐邇之能算。微昔見於
洲渚，赴秋期於江漢。集勁風於弱軀，負重雪於輕翰。
寒溪可以飲，荒皋可以竄。溪水徒自清，微容豈足玩。
秋蓬飛兮未極，塞草寒兮無容色。吳山高兮高難度，
越，水深兮深不可測。羨明月之馳光，顧征禽之駛翼。
伊余馬之屢懷，知君行之未極。夜綿綿而難曉，愁參
差而盈臆。「望山川悉無似，唯星河猶可識。」「孤鴈夜南飛，客淚液沾衣。春鴻旦暮返，客子方未歸。歲去歡娛盡，年來容貌衰。攬衽形雖是，撫臆事多違。青緺雖長復易解，《白雲》誠遠詎難依。」《夜聽鴈》
蕭子範
[
编辑
]

天月廣庭輝，遊鴈犯霜飛。連翩辭朔氣，嘹唳獨南歸。
夜長寒復靜，燈光曖欲微。悽悽不可聽，何況觸愁機。

《賦得始歸鴈》
劉孝綽
[
编辑
]

洞庭春水綠，衡陽旅鴈歸。差池高復下，欲向龍門飛。

《詠鴈》
北周·王褒
[
编辑
]

伺潮聞曙響，妬壟有春翬。豈若雲中鴈，秋時塞外歸。
河長猶可涉，海闊故難飛。霜多聲轉急，風疏行屢稀。
園池若可至，不復怯虞機。

《賦得集池鴈》
庾信
[
编辑
]

逢風時迥度，逐侶乍爭飛。猶憶方塘水，今秋已復歸。

《詠鴈》
前人

编辑

《秋夜望單飛鴈》
前人

编辑

《賦得鴈送周員外戍嶺表》
隋·王胄
[
编辑

《旅鴈別衡陽》，「天寒關路長。行斷由驚箭，聲嘶為犯霜。罹繳無人憫，能鳴反自傷。何如侶汎汎，刷羽戲方塘。」《賦得早鴈出雲鳴》
唐·太宗
[
编辑
]

初秋玉露清，早鴈出空鳴。隔雲時亂影，因風乍含聲。

《秋鴈詩》
虞世南
[
编辑
]

日暮霜風急，羽翮轉難任。為有傳書意，聯翩入上林。

《同臨津紀明府孤鴈》
盧照鄰
[
编辑
]

三秋違北地，萬里向南翔。河洲花稍白，關塞葉初黃。
避繳風霜勁，懷書道路長。水流疑箭動，月照似弓傷。
橫天無有陣，度海不成行。會刷能鳴羽，還赴上林鄉。

《失群鴈》
〈并序〉
前人
[
编辑
]

《溫縣明府以鴈詩》垂示，余以為古之郎官，出宰百里；今之墨綬，入應千官。事止鴈行，未宜傷歎。至如羸臥空石者，乃可為失群慟爾。聊因伏枕多暇，以斯文應之。

三秋北地雪皚皚，萬里南翔渡海來。欲隨石燕沉湘
水，試逐銅烏繞帝臺。帝臺銀闕距金塘，中間鴛鴦已
​
成行。先過上苑傳書信，暫下中州戲稻粱。虞人負繳
來相及，齊客虛弓忽見傷。毛翎顦顇飛無力，羽翮摧
頹君不識。唯有莊周解愛鳴，復道《郊歌》重奇色。惆悵
驚思悲未已，徘徊自憐罔終極。傳聞有鳥集朝陽，詎
勝仙鳧邇帝鄉。雲間海上應鳴舞。遠得鶤弦猶獨撫。
金龜全寫《中牟印》。玉鵠當變萊蕪釜。願君弄影鳳凰
池，時憶籠中摧折羽。

《秋鴈》
駱賓王
[
编辑

聯翩辭海曲，搖曳指江干。陣去金河冷，書歸玉塞寒。
帶月凌空易，迷煙逗浦難。何當同顧影，刷羽泛清瀾。

《同張二詠鴈》
前人
[
编辑

唼藻蒼江遠。銜蘆紫塞長。霧深迷曉景。風急斷秋行。
陣照通宵月，書封幾夜霜。無復能鳴分，空知愧稻粱。

《鴈》
李嶠
[
编辑

往還倦南北，朝夕苦風霜。寄語能鳴侶，相隨入帝鄉。

《南中詠鴈》
韋承慶
[
编辑
]

萬里人南去，三春鴈北飛。不知何歲月，得與爾同歸。

《同綦毋學士月夜聞鴈》
張九齡
[
编辑
]

棲宿豈無意，飛飛更遠尋。長途未及半，中夜有遺音。
月思關山笛，風號流水琴。空聲兩相應，幽感一何深。
避繳歸南浦，離群叫北林。聯翩俱不定，憐爾越鄉心。

《孤鴈》
杜甫
[
编辑
]

「孤鴈不飲啄，飛鳴聲念群。誰憐一片影，相失萬重雲。」望重似猶見，哀多如更聞。野鴉無意緒，鳴噪自紛紛。

《歸鴈》
前人
[
编辑
]

「聞道今春鴈，南歸自廣州。見花辭漲海，避雪到《羅浮》。是物關兵氣，何時免客愁。」年年霜露隔，不過五湖秋。

《歸鴈二首》
前人
[
编辑
]

萬里衡陽鴈，今年又北歸。雙雙瞻客上，一一背人飛。
雲裏相呼疾，沙邊自宿稀。繫書無浪語，愁寂故山薇。
欲雪違邊地，先花別楚雲。卻過清渭影，高起洞庭群。
塞北春陰暮，江南日色曛。傷弓流落羽，行斷不堪聞。

《歸鴈》
前人
[
编辑

春來萬里客，亂定幾年歸。腸斷江城鴈，高高向北飛。

《官池春鴈二首》
前人
[

客從秣陵來者，云楚中諸才士近為《鴈字詩》，吳中亦有繼作者。俱未之見也。仲秋，乃見郡人林若撫所賦十首，諷詠久之，清婉流麗，姿態橫生，飄飄有凌雲之思，然亦未嘗有意為之也。已而木落天空，躊躇隴首，日睹來賓之侶，遲速應節，疏密成文，有感於中，遂成二十四首。如春蠶吐絲，必窮其緒；時鳥弄音，屢變其聲，非有意纏綿，苟為啁哳，蓋中心養養不能自止焉耳。時壬子孟冬也。
