明一百十八

安恆妻魏氏
[
编辑
]

按《壽光縣志》：魏氏，安恆妻。恆於崇禎九年以試事失
意死。子致遠方九歲，氏誓以死殉。其兄勸曰：「此兒頗
慧，可不忍須臾死，以待其成立耶？」乃止。後三年，致遠
試於有司，列高等，氏為之色喜。已而泣曰：「吾可以報
夫地下矣。」遂慟哭嘔血卒。

李矩妻黃氏
〈王氏籍氏附〉
[
编辑
]

按《壽光縣志》：黃氏，李矩妻。夫早亡，黃氏年二十七，遺
孤生引方七歲，妾王氏年二十歲，產子生祚，黃氏撫
之若己出。稍長，共就外傅。生引弱冠補博士弟子，生
祚，亦能屬文。娶籍氏，方二載，生祚又夭，遺孤傳芳僅
週歲。兩姑議嫁之，籍以死誓，人稱「三節。」

張納妻孫氏
[
编辑
]

按《壽光縣志》：「孫氏，張納妻。夫亡，遺一子，紡績自給，撫
孤成立，冰霜之操，歷三十餘年。」

魏繼文妻張氏
[
编辑
]

按《壽光縣志》：「張氏，魏繼文妻。年二十五，夫亡，誓不他
適。孝養翁姑，供甘旨，侍湯藥，終身無倦。」

王正明妻丘氏
[
编辑
]

按《壽光縣志》：「丘氏，王正明妻。明為唐縣丞，無子，納妾
陳氏，生一女，甫襁褓。明亡，丘撫陳女如己出。陳亦善
事丘，同心苦節五十餘年。」

游公子妻岳氏
[
编辑
]

按《壽光縣志》：「岳氏，游公子妻。游早亡，未踰月，舅亦沒，
遺孤在抱，隻影無依。其父母憐之，諭令他適，氏誓死
不從，守節旌表。」

劉潁妻牛氏
[
编辑
]

按《壽光縣志》：牛氏，靈石縣令劉潁妻，少司空劉學易
母。幼誦《女誡》，通經史。潁沒，撫學易，躬為講解書義。學
易初試不利，有慍色。氏曰：「而不勤誦讀，文必不佳，考
居下，固宜何慍子？」答曰：「但不憶論題耳。」母問何題，曰：
「甘陳功罪。」母曰：「此出《西漢書》。」為言甘延壽、陳湯平郅
支事甚悉。守節五十年終。

高崶妻張氏
[
编辑
]

按《壽光縣志》：「張氏，高崶妻。嫁未三載，夫病，氏焚香祝
天，祈以身代。及亡，欲以身殉，姑救獲免。守節五十九
年，事姑曲盡婦道。有司以聞，旌表。」

貴恪妻劉氏
[
编辑
]

按《壽光縣志》：「劉氏，貴恪妻。恪死，氏年二十二，矢志不
改適。年六十二終。」

馬住妻宋氏
[
编辑
]

按《壽光縣志》：宋氏，馬住妻。住早亡，人勸改嫁，曰：「青年
無子，家四壁立，何能守？」氏誓不從，訊之，曰：「有遺腹。」後
生一子，守之終身。

李體仁妻婁氏
〈臧氏附〉
[
编辑
]

按《諸城縣志》：「婁氏，陽城令李體仁妻。仁歿，氏課子三
人，皆為邑中名士。壬午歲，長子作哲歿於兵，次作聖、
作謀亦為兵所掠。李氏家無孑遺，田園悉為豪強所
占。作哲妻臧氏方娠，兩嫠，形影相弔。踰七月，孫沆生。
婁曰：『李氏血食有主，吾何畏大腹豪也』。」乃白有司，盡
取所失而歸。後作聖從軍還，以恩貢累官延平太守，
贈《婁恭人》，督其孫沆入邑庠。臧亦孀居，嚴靜有聲。年
八十卒。

牛光耀妻劉氏
[
编辑
]

按《諸城縣志》：劉氏，牛光耀妻。耀早亡，氏年二十五，遺
二子，皆在襁褓。值歲饑乏食，人曰：「不嫁且死。」氏正色
曰：「全節而死，雖死猶生。吾寧死不嫁。」苦節三十餘年，
教子入泮，年六十終。

臧爾令繼室柳氏
[
编辑
]

按《諸城縣志》：「柳氏，憲副臧爾令繼室。令亡，柳年二十
三，遺孤二：長文德，年八歲；次同德，年六歲。柳苦志撫
孤，和丸畫荻，教二子皆由諸生入國學。縣令旌之。」

惠淵妻李氏
[
编辑
]

按《諸城縣志》：「李氏，惠淵妻。性儉朴，夙勤內職。淵早亡，
氏守志，撫二孤。長國隆，年十歲；次運隆，年七歲。親師
取友，克振家聲。子若孫俱入邑庠。氏卒年八十有七。」

尚義妻何氏
[
编辑
]

按《諸城縣志》：何氏，尚義妻。義早沒，無子，兩女皆幼，孀，
姑在堂。或勸氏嫁，氏曰：「婦無再嫁之理，且有姑在，吾
去誰為姑養者？」撫二女，事姑甚謹。姑死以禮葬，年七
十終。

王化普妻陳氏
[
编辑

按《諸城縣志》：「陳氏，庠生王化普妻。普亡，子臺年十二，
陳誓不再嫁，撫孤紡績訓之，為邑名士。年九十六卒。」

曹幼學妻黃氏
〈李氏附〉
[
编辑
]

按《諸城縣志》：「黃氏，曹幼學妻。學年三十，病亡，氏自縊。
姑急救甦曰：『我老而雙瞽，既無子矣，若汝再死，更何
所恃』？黃泣曰：『婦無出，義當殉夫，承姑訓，敢不終姑餘
​
年』。其妾李氏亦謂黃曰：『主母能養姑，妾獨不能養母
耶』？」亦矢不他適。相依為命，二十餘年，未嘗少懈。崇禎
辛巳，黃病篤，曰：「『已送姑，終，可以死矣』。李曰：『母死，我豈
獨生』？」越二日，遂不食，與黃同死。

張必遜妻侯氏
[
编辑
]

按《諸城縣志》：侯氏，庠生張必遜妻。嫁未期年，必遜亡。
氏年十六，誓以死殉。或勸養舅姑，氏從之。遂治家人
生業，事親盡孝。氏幼從父讀古史「《列女傳》，每與諸子
弟姪孫婦輩話往代節烈事，歷歷若指掌。年八十五
終。」

公家棟妻徐氏
[
编辑
]

按《蒙陰縣志》：徐氏，諸生公家棟妻，天性慈仁，適棟無
子，勸娶妾張氏，生子寅，弱而多病，氏愛如己出，撫養
成立。未幾，棟與張氏暨寅俱亡，家窘甚，徐撫寅七歲
子，寓沂水縣，艱苦萬狀，勉孫力學。病將革，語之曰：「爾
祖父去世早，我與爾辛苦備嘗。我死後，爾務親正人，
毋廢詩書，必移我骸歸里遂沒，時年七十有三。」

===杜李妻紀氏===
​
