藝術典第六百六十九卷

堪輿部彙考十九
[
编辑
]

劉基堪輿漫興
[
编辑
]

山祖
[
编辑
]

崑䮗山祖勢高雄，三大行龍南北中。分布九州多態
度，精粗美惡產窮通。

水源
[
编辑
]

南海長江鴨綠江。黃河四路水汪汪。界來三幹分南
北。消息機關在此藏。

北龍
[
编辑
]

北龍結地最為佳，萬頃山峰入望賒。鴨綠黃河前後
抱，金臺千古帝王家。

中龍
[
编辑
]

中龍尊貴孰堪倫，水遶山環四海均。我祖祖陵鍾厥
秀，須知昭代萬年春。

南龍
[
编辑
]

南龍一幹亦多奇，當代高皇始帝之。惟有金陵稱勝
概，高祖下作上天梯。

枝幹
[
编辑
]

尋龍枝幹要分明，枝幹之中別重輕，欲識真枝與真
幹，短長界水得其情。

幹龍
[
编辑
]

天馬行空氣象尊，千軍擁護度鄉村。前頭門戶有關
閉，立郡遷都子又孫。

枝龍
[
编辑
]

擘脈分枝三兩行，到頭結作細參詳。直須辨別非橈
棹，此地於人亦小康。

支巃
[
编辑
]

葬山支，巃要旁燭，支葬其巔，巃葬麓，巃宜還伏，支宜
生病巃死，支莫駐足。

巃龍
[
编辑
]

巃龍行度勢猛烈。脫煞就堂方是結。時人不識撞其
毬。下後令人宗嗣絕。

支龍
[
编辑
]

支龍平地欠峰巒，眠倒星辰豎起看。界水不明還是
假，糢糊星散不須安。

旁正
[
编辑
]

出身共此祖和宗，旁正詳觀自不同，正結至尊如帝
座，旁雖有穴欠全功。

粗嫩
[
编辑
]

粗中抽出嫩為佳，嫩可安墳老卻差。又有盡頭名曰
老，莫教一例斷榮華。

長短
[
编辑
]

隨龍長短辨低昂，龍若長兮福亦長，一節有情一節
好，短長節數任端詳。

真假
[
编辑
]

真龍穿帳必中央，虛假糢糊似破裳。過峽還當觀護
送，有迎無送亦非良。

貴賤
[
编辑
]

分龍貴賤有蓍龜，貴賤攸分在動移，貴格星峰多振
作，賤龍懶散欠施為。

祖山
[
编辑
]

龍樓寶殿勢難攀，此處名為太祖山。若祖端方孫必
貴，亦須剝換看波瀾
​

少祖
[
编辑
]

近穴名為少祖山，此山凶吉最相關，開㬹展翅為祥
瑞，低小孤單力必慳。

父母
[
编辑
]

問君何者為父母，穴後峨峨聳一山，前後相生不相
剋，兒孫赴舉不空還。

胎息
[
编辑
]

胎息之山一線長，萬鈞之力此中藏。苟非束氣何能
結，漫散無收定不祥。

孕育
[
编辑
]

山家孕育是何形，不外巒頭看化生。有格有形方可
取，入眸須得一團清。

到頭可遷來龍略次
[
编辑
]

娶婦惟求工德容，外家安得盡豐隆。婚緣若也能相
協，奩贈雖微福在中。

出身
[
编辑
]

辭樓下殿向前行，棄甲曳兵身始清。臃腫牽連無跌
斷，家資雖有亦須傾。

剝換
[
编辑
]

行龍剝換金宜土，若見火羅災必來。兩臂展開有水
救，陰陽相濟亦奇哉。

龍過峽
[
编辑
]

過峽風吹不可當，尢嫌硬直大而長。兩邊護送如週
密，前面須知有棟梁。

枝腳
[
编辑
]

枝腳反背龍必假，枝腳歸纏龍必真。不知其父觀其
子，不知其君觀其臣。

梧桐枝
[
编辑
]

上格行龍梧桐枝，枝分兩翼各相隨。骨肉一家無剝
雜，出人忠孝似皋夔。

芍藥枝
[
编辑
]

中格行龍芍藥枝，兩邊長短有參差，嶂空補缺能包
穴，此地人間亦白眉。

蒹葭葉
[
编辑
]

龍行下格蒹葭葉，枝葉雖偏左右均。莫作尋常輕易
看，亦能發福力千鈞。

楊柳枝
[
编辑
]

手腳偏枯楊柳枝，邊無邊有未為奇。葬來定是虧公
位，別地須當品搭之。

無枝腳
[
编辑
]

龍身活動似生蛇，仙帶蘆鞭總一家。若出《三台》屏帳
下，狀元及第萬人誇。

護送
[
编辑
]

行龍護送要推詳，護送愈多福愈長。若得隨龍併顧
穴，兒孫行慶福無疆。

駐蹕
[
编辑
]

行龍暫止為《駐蹕》，駐蹕之山看出枝。旁正精粗由此
見，前頭結作不差釐。

行止
[
编辑
]

龍行龍止易為窺，龍若行時山水飛。止處渾如人坐
臥，山環水抱兩相宜。

分劈
[
编辑
]

分枝擘脈龍之常。分擘若多非吉祥。苟能逆轉為吾
用。反見兒孫福澤長。

背面
[
编辑
]

龍分背面有何徵，面可安墳背不成，若是背時多陡
岸，面生窩突更寬平。

賓主
[
编辑
]

兩山相對為賓主。賓要有情主要真。主若欹斜賓不
顧。定知此地欠緣因。

奴從
[
编辑
]

融結真兮將坐營，前後左右擁千兵。一呼百諾真堪
愛，此結方知是《大成》。

餘氣
[
编辑
]

腰結從來有大地，何須二水盡交流。世間多少尋龍
者，餘氣都將作盡頭。

一勢
[
编辑
]

《山》巃平岡平地勢，三般形勢一般看。巃宜起伏岡宜
活，平地草蛇頂上安。

三落
[
编辑
]

龍分三落初中末，初落惟看逆案橫。中為腰結宜環
抱，末處須防水勢傾。

生龍
[
编辑
]

重重起伏最為奇，屈曲之元東更西。好似龍行並鳳
舞，還如魚躍及鳶飛。

死龍
[
编辑
]

粗頑臃腫欠高低，擺摺全無莫作為。倒地恰如魚失
水，藏山真若木無枝。

強龍
[
编辑
]

出林猛虎爪牙稜，入海蒼龍力勢弘。前去若能成

穴，人家富貴驟然興
​

弱龍
[
编辑
]

瘦牛倒地露筋骨，野鶴無糧脫羽毛。不審妍媸如誤
下，伶仃孤寡一鷦鷯。

順龍
[
编辑
]

開㬹對對貼身後，布曜雙斉遶穴前。父子一堂慈更
孝，孫枝滿眼順而賢。

逆龍
[
编辑
]

星峰逆轉無來意，橈棹斜飛不顧墳。反目夫妻家罔
正，鬩牆兄弟義何存。

進龍
[
编辑
]

穴後相看節節高，猶如天馬下雲霄。子承於父孫承
祖，世代居官掛紫袍。

退龍
[
编辑
]

穴後一重低一重，此地須知是退龍。縱有穴情只一
代，兒孫不久便貧窮。

福龍
[
编辑
]

《福龍》賴有祖宗好，左右週圍輳集來。體勢縱非真正
結，盤桓安靜亦堪裁。

病龍
[
编辑
]

病龍慵懶不堪言。邊死邊生力欠完。鋤破崩殘同一
斷。縱然成地亦孤寒。

劫龍
[
编辑
]

旁正不明無分別，東牽西拽總模糊。時師無識空談
穴，笑殺人間幾丈夫。

殺龍
[
编辑
]

「稜稜殺氣石嵯峨」，脫殺全無尖射多。不獨《彊梁》並凶
惡，還須入室見操戈。

出脈
[
编辑
]

飛鵝降勢脤居中，細細微微吉氣鍾。若出兩邊左右
角，一官雖貴卻無終。

直龍入首
[
编辑
]

串珠接氣直撞來，力冠三軍十倍才。結作定知裀褥
大，朝貧暮富莫疑猜。

橫龍入首
[
编辑
]

橫龍鬼樂不離身，鬼樂俱無穴不真。但得一般堪結
地，亦須坐下看精神。

飛龍入首
[
编辑
]

飛龍入首最堪誇，聲勢掀天清貴家。四應有情來揖
塚，水城須見石交牙。

潛龍入首
[
编辑
]

潛結毫釐不可差。細看灰線草中蛇。禾鍬口肉皆堪
葬。務要鉗中不側斜。

閃龍入首
[
编辑
]

直龍直受理之常，閃落誰知結一傍。不特下砂看逆
轉，還須端正問《明堂》。

金星
[
编辑
]

金星形體淨而圓，弓起渾如月半邊。秀麗篤生忠義
士，高雄威武掌兵權。

木星
[
编辑
]

木星身聳萬人驚，倒地人看一樹橫。有水令人身貴
顯，欹斜不正反遭刑。

水星
[
编辑
]

漲天水星浪交加，或落平洋曲似蛇。智巧聰明多度
量，蕩然無制敗人家。

火星
[
编辑
]

火星作祖似蓮花，貪巨相承宰相家，只有開紅堪作
穴，亦須平地出萌芽。

土星
[
编辑
]

土星高大厚而端，牛背屏風總一般。若在後龍兼照
穴，兄弟父子並為官。

五星
[
编辑
]

火南水北木居東，西有金星土在中。此謂五星來聚
講，天壤正氣福無窮。

正受穴
[
编辑
]

迢迢特至為正受，《正受》之穴世罕有。萬水千山結我
墳，兒孫慶澤天壤久。

分受穴
[
编辑
]

一枝臂上脫形來，亦有規模堪剪裁。莫謂分龍為小
結，小以成小有餘財。

旁受穴
[
编辑
]

問君何者為旁受，正受龍身氣脈洪。或在兩邊龍虎
上，或於官鬼護纏中。

太陽
[
编辑
]

高聳金星號「太陽」，或生兩翅繞身傍。窩鉗之處裁真
穴，一品公卿佐廟堂。

太陰
[
编辑
]

弓腳金星號「太陰」，形如半月穴宜尋，江湖池沼來相
應，女作椒房誇《太妊》。

金水
[
编辑
]

金星重疊二而三，動處名為金水涵，斗口窩中莫放
過，其家興發百斯男
​

木星
[
编辑
]

木星直落下三停，深淺高低看內城。橫倒木星何處
下，節包之上有情真。

天財
[
编辑
]

天財金水土金分坳土《橫安蜴》。
論。「更有豬腰窩裏下，攀鞍出乳乳頭尊。」孤曜
[
编辑
]

金頭木腳為孤曜，上剋下兮何足妙？不惟世代換頭
妻，更至單傳子息少。

燥火
[
编辑
]

問君燥火果如何，有角有稜似刃戈，若非曜星出武
職，穴臨其上受災磨。

掃蕩
[
编辑
]

掃蕩星辰人共棄，全身是水金不至。水無金鎮必漂
流，淫蕩兒孫退家討。

總論
[
编辑
]

九星識破莫言精，變態千般無定名。惟有窩鉗併乳
突，不拘形狀盡依憑。

窩穴
[
编辑
]

龍身陽結為窩穴，葬法須知淺則宜。闊狹淺深如合
格，一家飽暖定無疑。

假窩
[
编辑
]

假窩有穴不堪扦，懶坦空亡缺一邊，若見漏漕並破
陷，令人夭折退牛田。

鉗穴
[
编辑
]

本身有手為鉗穴，直曲短長要抱灣，虎口推開安正
腦，仙宮逆轉即天關。

假鉗
[
编辑
]

元辰傾瀉田須賣，貫頂有漕人不留，橈棹假鉗仔細
認，莫教誤下令人愁。

乳穴
[
编辑
]

陽來陰受為乳穴，乳穴粘毬法葬深，兩臂護來無坳
缺，兒孫滿眼玉森森。

假乳
[
编辑
]

問君何者為假乳，劍脊煙包腳帶斜。峻急崚嶒人半
個，粗頑臃腫禍三年。

突穴
[
编辑
]

山中有突少人知，若在平洋突更奇。山谷藏風頂上
葬，平洋看水定高低。

假突
[
编辑
]

玉印金魚綠水濱生來奇異掌中珍誰知無意貪融
結只為他人作用神。

朝山証穴
[
编辑
]

大都捉穴有明徵，穴好朝山分外清。若使面前無真
對，縱然有結力惟輕。

明堂
[
编辑
]

休嗟穴法苦難尋，指汝迷途抵萬金，端正有堂不偏
側，其間便是《定盤》針。

水勢
[
编辑
]

點穴先須看水源，水纏原即是山纏，左邊灣抱穴居

是書一出，地理不待窮而豁然於心，四科不待察而
瞭然在目。蓋嘗見夫星峰特起，撥換分明，或露或隱，
或山或坪，傍分二砂而為龍虎，中流一脈而有正斜，
名曰「三義」，形如個字，水初分於兩邊，而合於龍虎之
前，任左右而出矣。中流脈伏而凸起節包，傍生陰砂
而為蟬翼，水次分於兩邊，而合於陰砂之際，而稱為
大八字矣；中脈略生塊硬，而名毬簷；傍水中分於左
石，而名小八字矣。自毬簷下有一坦窩子，而名曰「葬口」；自葬口下有一小明堂，而即其薄口。二砂隱隱合
襟於薄口之下者，毬髯也。二水微微交會於合襟之
端者，蝦鬚也。此四科之證佐也。何以別之？殊不知「個」字三義節包硬塊者，龍之證佐是也。毬簷葬口合襟
者，穴之證佐是也。砂之證佐，而有護龍之蟬翼，護穴
之毬髯，水之證佐，而有證龍之八字分合，證穴之界
水。蝦鬚何以取之？地中之造化，即人身之造化三義。
個字者，頭首之譬也。凸起節包者，人之額門，而第一
分合，名「大八」字，非兩眉乎？再生硬塊者，人之鼻頭，而
第二分合，名「小八」字，非兩眼乎？毬簷而即鼻準，葬口
而即人中。薄口合襟，乃人之下頦；毬髯蝦鬚，乃人之
髭鬚也。惟有陰砂，其義不同，其名不一。藏於龍虎之
內，生於節包之傍，輕薄貼身，微茫拱護，如蟬，硬翼之
下，又有軟翼，故名曰蟬翼。如人腰帶之間，所佩金魚，
故名曰金魚。邊有邊無，而有股明股暗之稱；邊明邊
暗，而有「明肩」「暗翼」之號，證佐明矣。可不究其理乎？蓋
理者陰陽，而陰陽者牝牡，牝為雌而牡為雄也。以龍
論之，星辰形如覆掌，或生
嘴來勢雄急者，陰落而
雄龍也。「星辰形如仰掌」，或生窩口，來勢坦緩者，陽落
而雌龍也。以《穴》論之，龍之雄者，結穴略生窩口，此其
陰極陽生，而為少陽之穴，乃雄龍而雌穴者矣。若無
窩口，而仍如覆掌。
「嘴」者，穴之太陰，而龍穴皆陰雄
也；龍之雌者，結穴略生小堆，此其陽極陰生，而為少
陰之穴，乃雌龍而雄穴者矣。若不生堆，而仍如仰掌
窩口，穴之太陽，而龍穴皆陽雌也。羅紋之稱少陽之
穴，其紋若指面之羅，葬則勿破其脣。「土縮」之稱少陰
之穴，其土如縮而中止，葬則休傷其頂。二者皆地中
之精粹，世間之罕有，故特取義如此。砂之明屬陽而
為雌，砂之暗屬陰而為雄。天門開於前山者，《乾儀》純
陽之謂。地戶閉於後山者，《坤儀》純陰之謂。太陰太陽
者，青龍白虎也。少陰少陽者，天乙太乙也。水短屬陽，
而為雌者先到；水長屬陰，而為雄者後到。故曰：「牡牝交承，雌雄相食」者歟！尤必看其龍從何來，氣從何入，
星辰正出而正求者，其龍順來，氣從頂入，故曰「拂頂。」星辰側出而架折者，其龍逆來，氣從耳入，故曰「拂耳。」逆順既明，生死可知。龍之強生而弱無，穴之厚生而
薄死。砂之明暗，水之寬緊，理亦然矣。且《四科》易察，葬
法難明，苟非其傳，差之毫釐，而謬於千里。苟得其傳，
道豈遠而術豈多哉？但當先定一十字於葬口之中，
而為十道之名。即倒一直杖於十道之中，而為倒杖
之方。上枕毬簷，必端必正，而曰「後倚」，以受其真氣臨
​
來，故曰「臨頭。」使水分於兩邊，謂眠乾；下對合襟，不偏
不倚，而曰「前親」，以取其真氣交會，故曰「合腳。」務要俯
就合水，謂之「就濕。」毬簷在上，而有放送之情；合襟在
下，而有迎接之意。倒杖之法，豈有餘蘊哉。由是用線
牽定，而開井放棺。切勿信諸家卦例，作向消水，有乖
氣脈。穴法雖然，急緩無方，而穴有傷龍脫脈之患；淺
深無則，而氣有上行下過之非。故高則因其來勢之
坦緩者，乃陽落也。湊入毬簷五七寸，以受正氣，不可
緩，緩則脫脈主黑爛矣。蓋穴不怕高，但要藏風聚氣，
故曰：「乘風則散。」低則因其來勢之雄急者，乃陰落也。
拋出毬簷五七寸，以受正氣，不可湊，湊則傷龍，主白
爛矣。蓋穴不怕低，但要不過界限，故曰「界水則止。」假
如高山結穴，開金井，止與小明堂相並，不可太深，深
則氣從上行，故宜淺矣。假如平地結穴，開金井，深過
小明堂尺許，不可太淺，淺則氣從下過，故宜深「矣。急緩既有其方，淺深亦有其則，又當辨其龍之強弱，穴之厚薄，砂之明暗，水之寬緊。用心著眼，挨生棄死，如是則放棺無所差，而葬法無以加矣。」吁！是書乃曾、劉、
胡、李四人當時受國師筠松楊先生之祕傳，今與有
聞焉，予之幸也。茲予讀其書，誦其詩，特述其所知大
概，書於其後，貽諸子孫，以為傳「家之寶」云。《括蒼劉基
書》。

得穴，固難立向，尢難京口費侍郎祖塋，自府幹龍華
蓋山，頓起一小金星，落脈委蛇，活動重重，借幹龍橈
棹為護送，以竇氏湖為明堂，白兔山為朝應，辛脈到
頭，作戌山辰向，一發即衰，以龍局論，非暫福之象。余
察之向差耳，上砂本重，一作「戌辰」，愈就上砂，而下砂
反寬。且龍從左轉，宜左耳受氣，今反右耳受氣，後特
分樂砂一股，今空而不坐，使作酉山卯向，既避上砂
之竄，理氣又與辛龍相合，受氣亦貫左耳矣。砂水勻
而後樂正，即貴未必加尊，而後未必若是凌替之速
也，此龍真穴而作向差也。謝註《雪心賦》引解未當，
趨避砂水吉凶，其法在定穴立向之先矣。然葬後收
拾，關係匪輕，穴之前後左右，禍福之先見而立效者
也。今人不知趨避之法，立向點穴，已自茫然，掘壙結
堆之後，以為能事畢矣。不知龍真穴的，或有一水一
砂，不能收，不能避，則有裁制之妙法，在在人施其巧
耳。否則得穴不發，發而有不全美之事。如太平、新豐
二甲王家，葬一墳不發，名師張宗道為四圍打牆，惟
中留一門，透見秀峰，其後方發，至今殷盛。東陽義門
鄭氏賴公為下一墳，葬後樹牌二道，一正樹，一斜樹。
祝曰：「斜樹者，尢妙如龍方活。」其家大發財，賦人丁，三
朝不分家。至我太祖過而詢之，方取入仕途者數人，
分為二十四分，碑斜樹而龍活。其說不通。蓋上露秀
峰，而下遮凶水，以是愚人耳目耳。

董德彰下新安王氏一地，酉山卯向，葬後令鋤去右
砂一臂。《留記》云：「越打越發，不打不發，欲放水到堂耳。」其家遵之，每打即發。是年打至已上長生水到，因犯
都天宗人，因官事發配，止而不打，其家不發。又打至
辰，遇赦文水，其人赦回。

穴在水中有之，而不知穴內有水。涇縣九都查氏祖
墳，美女撒尿形，穴前流水不止，其家富貴不絕。近一
族人盜葬祖墳之側，其人驟富，族眾知而起去，棺中
淋淋水出，未久其人即窮。由此觀之，穴中有水，不妨
發福也。

相地不特面前砂水呈秀，龍真穴的四畔皆當留心。
泰州陳少卿祖塋結在平垟，穴前地淺，即是大河直
流，河外橫岡攔於前，又無外垟，前無脣髯，傍無月角，
一片糢糊，無一砂一水可觀。至穴後一望，蓮花池團
聚，瀦蓄大水汪洋，池外屏山正應穴後，豁目快心，以
後有情，故穴直靠後岸。

富貴發達有時，山川遷徙不一，如福建省城係郭公
所遷，《留鉗》云：「南臺砂合，橋口路通，先出狀元，後出宰相。」壬辰前數年，南臺砂漲出十餘里，是科翁青陽發
大元。又十五年丁未，葉臺山大拜景純，距今若而年，
其《鉗記》始驗。

形勢水法有難拘者。《餘姚鉗記》云：「坐不正之山，朝無情之水，無常富之翁，無久貧之子。」不正之山可坐，無
情之水可朝乎？然餘姚一邑，家家皆發，倏發倏消。大
抵龍貴砂水，皆不足憑，不悠久，則又不正無情之疵
矣。

《樹木榮盛可徵山有氣至朱侍郎祝禧寺祖塋》，先是
植木皆枯，人疑為不祥。乙未前，樹木忽皆蔥蒨如油。
公發大魁。

「山有鳴者，氣之盛而鼓動也。」山陰周山吳氏祖塋，乃
木星結仰高穴出。吳公兌官至尚書，久而不發。至萬
曆乙卯年，祖塋山忽鳴數夜，是科文武發科者十餘
人。餘姚馬堰徐氏宅山，庚子年鳴。辛丑徐公應登登
進士。上虞蘭芎山左有黃山，乃嘉興項氏遠祖塋，每
​
鳴則上虞水漲，項氏必發，項氏不知也。羅康洲、朱金
庭、張陽和某公四公讀書會稽山中，或先後至，未俱
集。一夜，四公同至，山忽鳴。後羅公、張公大魁，朱公大
拜，某公亦仕至太守，皆山鳴之應。方播酋未滅之先，
塋碑忽鳴，此又妖孽之變。

上虞下蓋湖一墩，名練樹，湖干有陳氏巨族陽宅，凡
有人葬是墩，則陳氏廚竈屋梁皆折。曾有人以三骨
上下葬之，陳氏起其一梁，折如故。又起之，又折，又起
盡則已，至今無人敢葬。其龍自蘭漚山分來，至驛亭
跌斷，起小越又大斷，兩傍皆湖，龍從中出，至福奇山
跌落，湖中陰砂四圍圍聚，遠山照應，所以佳也。
餘姚《高山》一地，有葬者，聞虎作怒聲而止。又有葬者，
一山竹皆爆響，今遂無敢葬者。以上諸地，未必皆絕
粹，而葬之非其人，則有是異徵，信乎有緣非人，可強
求也。

無錫華氏祖塋，原結在水中，此固天地之深藏，珍祕
以待積德之人。華氏之先為仇人誣以人命，獄卒憐
其枉，欲為斃其仇人，華公力止之，云：「我成獄未必即典刑，我謀彼，先殺一命矣。」是夜夢土神告之曰：「汝積德如斯，與汝一地在鵝肫蕩。」後華公果為仇穽，十餘
年出獄，偶有堪輿流落無知者，華公遇而延至其家，
館糓之。堪輿欲覓一地報公，不得。歲暮辭歸，將俟再
至，公復厚為齎發。堪輿行遇大霧，泊舟河干，見霧中
一處氣獨清。頃霧收，往登之，果大地，但穴沉水底。堪
輿回舟告公，公初遲疑，詢其處，乃「鵝肫蕩」也。因與夢
符，遂信之。堪輿方踟躕，無葬法，適有木排失風，打至
蕩中，買木四圍，下樁中實，以土覆挖，至是處葬之。後
出學士洪山公，科第幾三十人，至今鼎盛。造化留之
以報盛德。吾人卜地，可不留以還造化乎？

「地貴來龍」，而龍貴傳變局看砂水，而朝案尢，其所重
也。余友徐三泖於真州青山卜地葬妻，後龍重重開
帳，斷而復斷，到頭結一小金星，穴高而陰砂交會於
前。然帳多而龍身無特達之星辰，則帳反洩氣，陰砂
雖交而無專對之朝案，則主以無客而不尊。況後龍
帳皆是水星，金星結穴，金生水中，稚弱而未經鍛煉，
金又生水，子能令母弱，是不旺之象也。生金者土，土
制水濫，使中有一土星，則力重矣，此間星所以貴也。
主星既弱，結穴又高，砂水低，堂局寬，內無近案，外無
特朝，非全美之地。一葬，余謂生育艱，三泖余契友也，
不余信。今十年餘，未得孫，尚可施工力，否則後主貴
者不富而艱嗣，富者不貴而多子。

「地貴，審其所廢，不可不詳。揚州閻方伯祖墓來，龍從府幹龍分起，盤古山，出仙帶脈，頓起廟山，右分一枝，攔轉作下首，從中跌斷，復起主星，中吐一脈結穴，本身下首又生一股，曲掬過穴作案，穴在高山，既有兜堂，用抱兒葬法方是，宜就案點穴，今脈止不下，即點穴於上，兜堂反寬而無力矣。」余方疑之。余友曾詢土
人，因築去一段來脈為地，故于龍脈盡處點穴，方伯
非其應也。惜哉！此地妙在從岡變巃，外垟句，城塘寬
廣可愛。《經》云：「從來高穴少明堂，惟看兜堂與外垟」者，
此也。

京口東汝山，人傳為劉裕祖墳，即所謂「京口丹徒之後山，卻被劉王斬一關」是也。余往驗前事，龍從常山
起白兔山，生大獨山，從新豐過河，平地頓起大山數
十里，右一枝去結黃衢，左一枝入鞋谿，去結圌山。此
則逆上一枝，粗雄，未跌斷，未脫卸，到頭起東汝山，純
皆是石，山下吐出一線，土脈委蛇，細嫩可愛，不過十
「數丈，結一金星圓墩，乃拋穴也。傍即生土岡，兩枝隨龍委蛇，貼身作護，以順杖葬之，非斬關也。左有老鼠成捲旗形，右有龍王廟墩成頓鼓形。捲旗頓鼓，非王侯之象，乃偽賊之砂。來龍盡是高山獨行，無護無從，惟山下自放低岡為橈棹耳。來龍殺重，惟到頭一節剝換，堂局不廣，無王者規模，種種非」是。因思宋南渡
時，亦有劉豫，金人所立偽主，形與人合，所謂斬關。《府
志》所載「府基為漢荊王墓，有王廟今存焉。漢，劉姓也，府後橫龍，宜用斬關。」前賢之言，庶不悖耳。

秦樗里子卒，將葬渭南章臺。先曰：「後一百歲，當有天子之宮夾我墓。」漢興，長樂宮在其東，未央宮在其西，
武庫正當其墓。樗里子即青烏仙，其言驗如此。必以
形勢卜之，何？藏形之不善，毋亦數歟？

張士誠祖墳在草堰、丁溪二鹽場之中。其龍沿海而
行，平垟地面突起平岡，到頭分枝布爪如龍形，龍首
頓起。一埠高不丈餘，後坐虛即是大海，面朝內河，下
砂遠關，不足為奇。惟是沿海皆黃砂白土，此埠獨是
紅土，則奇耳。今剖而為二枝腳，葬者皆貴。兩場相隔
七里，姻戚相聯。每歲春首，兩場相鬥於此埠之前，以
鬥勝為一年之利徵，雖至戚不顧也。猶此埠之殺氣
未盡歟！

靈寶許氏祖塋出父子四尚書中，一子拜相，皆加官
保，子孫多盛，科第不絕且賢。其龍自秦中來，即縣幹
龍，先結此地，而縣治反為下臂，大帳大峽到頭頓起
​
玉屏土星，發出五枝，結穴於中。一枝之盡，兩旁蔭腮
二泉合流於小明堂上砂作案，案上突起印臺，弘農
稠桑二澗橫於前，秦嶺秀峰作朝老君原三台作靠。
諸峰羅列，中條山排列下首，惟內右下砂少缺。許氏
將發，其山忽崩，卸下一臂，補足右砂，其家遂發，
土色有不定者。顧少宰云：其岳家王氏一老僕妻死，
卜一地葬之，掘下皆黑滋泥，隨主之任期，迫不得已
葬之。葬後，子皆平安。十餘年老僕死，其子啟穴同葬，
悉變成乾黃土，想氣之到不到耳。

南京吳尚書祖墳，自石子岡橫開大帳，中落變成小
土星，抽出平岡，至岡盡將近平地結穴，後特生一枝
作托，前開平田作明堂，遠山雙金作朝，左即帳腳諸
山作土砂，右惟陰砂一股作下砂。砂外大江，江外江
浦諸山排列登局，只見上重下輕，漫無可觀，不知龍
氣既貴，結穴又低正《雪心賦》云：「若見土牛隱伏水纏」，
便是山纏水外，要四山來護此地，直取大江遠山配
成大局，發貴所以大也。然一發即敗，子孫不振，又下
砂太低太寬之病。

陰龍陰向，發福者多矣。間有不合，反發大貴。如南京
宋西寧侯祖塋庚酉辛龍轉離落脈，作辰山戌向，於
理氣不合甚矣。惟以幹龍到頭委蛇細嫩，活動可愛，
落脈清細，左旗右鼓，砂水分明，隔江雙峰作朝，故兄
弟皆侯，富貴數百年。陰龍陰向，果可拘乎。

杭州張氏螺螄吐肉形，葬後只發二春。「元尚書公祖地，乃劉誠意」所下，濱西湖北地穴尚未正。諸書妄傳，
侈為美談，可笑也。

孫權祖塋在天子岡，迎七星灘之水，人傳未葬正穴，
是以偏安。凡有盜葬者，則天不雨土，人覓而掘毀之。
凡存心欲謀此地者，至則雲霧障隔。此所謂「禁穴」是
也。人可妄圖招禍哉？

前賢名墓，不可謀葬，多招奇禍。揚州高尚書大鵬展
翅形，乃董德彰所卜。後葬時，其親夢朱衣紗帽人云：
「我秦少游也，令親欲用我地，前後皆可發福，不可在我之上。」開穴，果見一棺。俗師云：「官上加官。」遂葬，後遘
凶禍。先有仙人摘掌形，祖地大發，葬此頓歇。慈谿劉
主簿墳，葬時亦夢緋衣人云：「前數尺可發，不可動我穴點」穴後，劉公移前一柩葬之，子孫科第不絕。
山西楊嶼嶓冢宰，先葬祖於中條山，啟穴得石碣，上
寫「條山正脈。」葬後年餘，啟穴合葬。夫人見氣噴出，托
柩浮而離地，速以夫人柩塞入，不論方向，以土掩之，
後發三代尚書科第不絕。南京姚大參塋，啟穴合葬，
氣亦噴出，科第不絕。

先文定公葬揚州句城塘，先葬祖母十年餘，啟穴氣
如籠蒸，乃平。岡上皆黃土，穴中反淡青色，中皆白，圓
圈如錢式。葬不四十年，發百餘丁，科第，方興未艾。
杭州幹龍自天目起祖，遠不能述，從黃山大嶺過峽
後一枝起南高峰，從石屋過錢糧司嶺，起九曜山、越
王山，過慈雲嶺，起御教場、勝果山、鳳凰山，過萬松嶺，
起吳山入城。「一枝起北高峰」，從桃園嶺青芝塢跌斷，
起岳墳後烏石山，從智果山保叔塔入城。來龍沿江
而下，皆自剝星巒遮護，隔江諸峰遠映護龍，直從蕭
山至海門，生天弧天角星，從別子門石骨渡江，起皋
亭諸山，作下砂兜轉。右界水自嚴州桐廬流入錢塘
江，左界水自餘杭西溪流入官河，惜兩界分流未合，
城中諸河塞阻穢濁。脈絡不清。西湖之水又從昭慶
左分出。流斷北龍非宜。

《來龍之石》，龍之威權曜殺也。辛酉年，杭州智果山為
海寧陳氏建園鑿石，城中大火二次，焚十萬餘家，皆
北龍之地也。後燒出城外，將近智果山而止，可見來
龍不可輕動。

壒村祖塋，乃寒家發福之地。先曾祖不知地理於來
脈，蓋造享堂下樁之時，塋上樹出火光。先祖京師是
日鼻衂血一碗，遂致政。歸後拆去，始復發科第。
壒村曹氏陽宅一井，水沸則發。乙卯年，壒村先塋湧
出古井，村中二百年無井矣。是科華兒發科。

莆田縣西有石室巖，一巨石長數十丈，如舌向城，內
有寺宇遮隔不見。嘉靖壬戌，寺焚石現，倭遂破城。
福建省城閩君瑤原建都山中，後遷出，就橫塘，江水
瀦聚於前峽江，雙峰對峙，關鎖門戶。布政司前對五
虎山，石勢巉巖，故中門常閉，門開則禍立至。

餘姚來龍，從上虞五桂山發羅巖，而從豐山入城。河
之南則自四明烏瞻峰而發，因呂文安公建城於河
之南，遮隔明堂秀峰，科第寥落。「水口竹山，攔阻龍鳳二山對峙，鹽池大會，屈曲大轉，此水口之至佳者也。」恐不專為餘姚，有禁穴存焉。

餘姚城南有黃山，從平田大斷而起，低平土岡中自
分支曲折，呂文安公祖塋在焉，其中發貴六十餘人。
上虞縣龍，北一枝從五桂山落過河，發數埠，龍勢不
振；南一枝從長者山入城，龍勢大旺，皆為金壘觀而
然。長者山成飛鳳之勢，觀結冠山前有葫蘆砂，此魏
伯陽昇仙之處。右之餘氣鋪下人民居止，故上虞城
​
中，富貴者少。

慈谿縣，龍自四明至上虞分餘姚後，龍從餘姚之北
轉至定海，逆上結縣餘氣至餘姚九壘山止，五星歸
垣，前有獅子諸山平田小峰如印如誥，成天清之形，
極貴。又前逆砂直至丈亭三十里，兩江互遶於前，來
龍高山之上，起石柱峰，巨石凌空，但頭斜不正耳。
紹興越舊建都於平水，自禹而傳已久。范蠡謂「四山太高，受制於人，遷出建都，而城中生山出焉。」龍從新
昌天姥而來，遠不能述。自亭山入城，起城隍廟，山逆
轉而結，坐虛向實。前以秦望、方屏為朝，蒼翠可愛。後
坐鏡湖八百里，惜廢為民出，不能見汪洋澄靜之勢
耳。然遷出越一霸而遂亡，水口淺也，平原遂致煙迷
霧失矣。

「禹穴」自天姥同紹興府龍而來，從南鎮高山過峽，石
巒排空，入首莊嚴，龍虎齊分雙股曲掬。眾山中露尖
峰，作朝端拱，凝立郡城，反為用神遠塞。下砂遶門、陶
堰諸山後，龍分出為水口，皆小巧秀麗。登穴只覺眾
山有情，層巒疊嶂環護，信為名區也。

湖州來龍，自天目至孝豐過幽嶺，遠不能述。近自霞
霧山斷向起赤山，斷而復起棲賢山，從金斗山渡河
起弁山，「一枝分康山為右護，一枝分白雀雞塞沈洞為左護。起仁王山，左落籟山，右落籠山，夾照跌落平垟入城，苕溪為右界，霅溪為左界。二水相交，山勢既雄壯，而夾山西峰諸漾水復瀦澤為貴南道場山，一」枝，自妙善內分為朝應，從道山頭跌下起長超山、毘
山移岸西，余諸小峰水中作水口。仁王山跌下生籠
山，又在水口對峙，但水中欠尊星，而太湖、洞庭遠映
山水兩全之地，然城中富貴不絕，而將相則罕。沈相
公又生於馬要，而大拜於武林，城中無公侯甲第也。
長興從南幹大龍而分，遠不能述。從冠子山正出馬
鞍山，跌落穿田，起白石山，斷而起大復山、雞籠山、五
峰山，起靈山，則陳王之祖陵在山，皆小而秀。從靈山
之左轉入長興，弁山，遠障下首，太湖瀦於前，烏瞻諸
峰列於後，包洋、顧渚為左界，畫溪、霅溪為右界。可貴
者，霅溪自霅水橋分而逆五十餘里，遶於前而入太
湖，則後主興王之地也。陳王生於六匯頭，六水相匯
之處。

武康，從幽嶺之右峰稍嶺分初落也。分楊墳一枝至
金龍山、樂山為外護，中跌斷穿田而起德清、德清，山
秀水清，五星到頭相生而從西門入城腰結也。又穿
田數十里，平地頓起寒山，為嘉興之少祖。跌落平垟，
至真如從鴛鴦湖中入城，平砂簇擁，眾流環遶煙雨
湖水瀦聚澄泓，於《巽》方來龍清麗，此所以貴也。
凡平洋之地，突起一山，到頭最貴。如無錫惠山，從錫
山入城，結縣治，凡惠山之北有一脈落，即發一貴。常
熟虞山，平地突起，結縣治，山之南有一脈落，發一貴。
山頂浮脈委蛇，從南一角天池中石骨，落脈縣治後，
龍轉身兜作護砂，直至山麓平坡前開一湖，汪洋團
聚，應穴則嚴文靖公祖墓也。

大龍大帳，大峽到頭，不結郡邑，其結富貴之地必多。
如德興長塘，《見圖》未至其地。若南京牛首之龍，自瓦
屋山起，東廬山至溧水蒲里，生橫山、雲臺山、吉山、祖
堂山而起牛首，雙峰特峙，成天財土星。左分一枝，生
吳山，至西善橋止，復於肘後逆上，生大山、小山。右分
一枝，生翠屏山，從爛石岡落變作岡龍，至麻田止，中
抽將軍山，過黃泥岡，起祝禧寺，至安德門，生雨花臺
前至架岡門上方門而止。雖為鍾山，應龍打水，歸聚
明堂，其中結宋西寧，兄弟皆侯，又結周尚書、吳尚書、
顧尚書、王尚書、許會元、朱狀元、姚進士，其中發貴者
不可勝數。左右二枝，亦多貴穴。麻田倪尚書祖墓在
其地，未發未葬者，尚有遺珠。而來龍不過十餘里之
內也。

洛陽，即今之河南府也。從嵩山而來，過峽石而北，變
作岡龍，入首後分一枝，結《北邙山》，托於後山，雖不高，
蜒蜿而長，頓起首陽山，遠映下首，至鞏縣而止於黃
河之中。嵩山抽中幹，起皇陵山，分出一枝，至黑石關
為水口，中擴為堂局，而四山緊拱，前峰秀峙，伊、洛瀍
澗，匯於前龍之右界水也。稠桑、弘農、好陽諸澗，乃左
界水流入黃河，遶於北邙之後。洛河悠揚至鞏縣而
與黃河合，一大聚會也。

後龍不可輕動，而《囊金篇》中有石山帶土者打斷，反
為出貴之應。讀之心切疑其非。詢知浙江義烏鎮多
發武貴，幾六七十人，初因鎮後八寶山出礦，為處州
礦賊所據，官兵不能勝。義烏一人倡勇，一夜而殺盡
諸賊。戚南塘知其勇而用之，後遂有義烏兵之名，實
由打開八寶座山而發也。

蘭溪范氏，十子九登科，墳圖具諸書。而穴結於二片
巨石交錯之中，則甚奇。然內堂之圓聚，九峰之秀麗，
莫出其右。其一子未登科者，又為名賢范香溪也。九
峰之旁有一小尖峰，其斯之應乎？

湖州韓狀元祖塋，從羅山頂落平岡突起三石，從中
​
巨石橫落一線土脈，石首圓淨可愛，脈長不過二三
十丈，細嫩而秀，乃亥龍也。右首一臂橫攔過穴，左首
下砂遠關前有夾山漾外諸山帳，內貴人作朝，宜作
乾山巽向，今作子山午向，又將右臂開去一段平作
神路。前朝山既不端正，右砂開去又不與左砂相交，
右砂之頭，開直順竄。此韓公雖發大元，而官階未尊，
聞韓公先世更無佳塋，葬此公已三歲，其秉間氣而
生此地，為貴人之助乎。

凡得龍得穴，而乘氣不正，作向不正，不害，為發福，但
不悠久，或貴不尊，余屢驗之。

徽州程丞相祖墓，在府治之西，過化臺路傍，賴布衣
初至，訪其處，詢之農夫，農夫妄認為祖，以試其驗，賴
公遂以席帽浪袍山為「箬帽蓑衣山」許之，為農夫所
嗤，故有「我來不識丞相墳，我去留心在飛布」之語。其
龍發自臨金，從巃變岡左分結畢太常、畢京兆、唐狀
元祖墳。此則從右起三台，跌落平田數里來。龍隱伏
低平，到頭隆起，一墩微高，左即龍行不止，高岡為護，
右則隨龍，溪水一條，更無纏護，看之似偏而不偏。何
也？龍在平田，穴情隱伏，水纏便山纏，況有溪外遠山
高映，溪與高岡相配，一陰一陽，一雌一雄，最貴之格。
亥龍入首，作壬山丙向，本身右砂兜轉，前面左砂逆
生，橫岡作案，亦陰陽交護，案外諸峰高聳，似壓而不
壓，朝山金水頭身上掛下枝條，若衣褶然，似亂而不
亂。大溪水遶於前，天門開而地戶扄，內氣聚而外氣
長，信大貴之地也。然非細察，雖布衣名公亦為所誤。
