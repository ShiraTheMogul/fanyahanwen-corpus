武當山部藝文三

天柱峰歌　　　　　　　　宋高本宗
[
编辑
]

祥風自天來，吹我遊紫清。高高著天起，巍然一柱連
天撐。巖有三十六，澗有二十四，隱映七十二朵芙蓉
青。丹梯貫鐵鎖，十二樓五城。壓穿鯨鰲背，幻出龍鳳
形。鸞鶴亦馴擾，猿猱不能經。於菟式長嘯，我來一時
鳴。古來仙人據其上，往往白日皆飛昇。我來適清和，
雲朗天亦晴。初望一天門，碧澗水落冰泠泠。再登二
天門，瑤草葳蕤雜敷榮。三登三天門，雲霧翕欻飄金
莖。須臾望絕頂，身在空中行。西望崑崙，黃河一線天
瓢傾。東望蓬島，半勺綠水浮滄溟。手撚日月彈丸子，
足踏震霆巖下驚。夫人若果住天上，附耳若可低低
聲。華嵩恆泰，左右先後若朋輩。諸山㟝嶁，在下何伶
仃。八表望不極，因之望神京。神京遙遙幾千里，雙目
掣電心懸旌。神君端居面東瀛，黃金鑄屋玉作楹。赤
蛇鼓鬣，黑龜效靈。旌旗招搖，森然列星。敬將一瓣香，
上訴神君聽。

太和山　　　　　　　　　　元虞集
[
编辑
]

雪樹生香滿佩巾，紫霄最上集仙真。苔荒鶴跡渾無
路，花暗笙聲不見人。瑤圃月寒通白曉，丹臺雲暖駐
長春。莫教流水前村去，恐似桃源客問津。

《前題》
揭傒斯
[
编辑
]

太子巖吞獅子峰，洞深雷響半虛空。黑龍去作人間
雨，白鶴來棲澗上松。日吐金芒朝五老，煙橫玉帶遶
三公。七星旗展飆輪降，時有天香下九重。

磨劍澗　　　　　　　　　　羅霆震
[
编辑
]

帝真合是鎮元天，奉敕鎔金冶紫煙。三尺展開橫海
嶽，肅清宇內一龍泉。

桂籍殿　　　　　　　　　　　前人
[
编辑
]

職聯上相主文昌，積行名賢席寵光。到此即登蟾窟
內，高枝攀動九天香。

鐘樓　　　　　　　　　　　　前人
[
编辑
]

擎天立柱駕梁虹，發越鯨音氣量洪。如法大鳴應大
扣，金聲玉振九霄中。

繫馬峰　　　　　　　　　　　前人
[
编辑
]

待詔金門陟翠微，玉驄停駐踏朝暉。劃然雲路牽騏
驥，得意朝天去似飛。

武當歌　　　　　　　　　明王世貞
[
编辑
]

「黑帝不臥元冥宮，再佐真人燕薊中。乾坤道盡出壬午，日月重朗開屯蒙。人間大小七十戰，一勝業已歸神功。久從北極受尊號，卻向西方稱寓公。」《武當》萬古
鬱未吐，得吐居然壓華嵩。是時豈獨疲荊襄，雍豫梁
益皆為忙。少府如流下白撰，蜀江截雲排豫章。太和
絕頂化城似，玉虛彷彿秦阿房。南巖宏奇紫霞麗，甘
泉九成差可當。十年二百萬人力，一一捨置空山傍。
嗚呼！英雄御世故多術，卜鬼探符皆恍忽。不聞成祖
帝王鬚，曾借元天師相髮。漢武空邀王母過，高真不
顯宋宣和。功名雖盛毋乃晚，混沌時來當奈何。

茅阜峰　　　　　　　　　　　前人
[
编辑

茅君顧我笑，誰校從宮多。欲語「囊中祕，其如大耳何。」健人峰　　　　　　　　　　　前人
[
编辑

繫馬峰　　　　　　　　　　　前人
[
编辑

天馬走長空。茲峰偶一繫。萬象欲現時。神將繫吾意。

隱仙巖　　　　　　　　　　　前人

编辑

一滴一露珠，病渴猶恨少。倘借行雨缾，郊村成浩淼。

编辑

太上流沙去不還，猶餘真氣在函關。不知元始真人

编辑

淺碧泓停一鏡開，探瓢欲酌更遲徊。孤峰倒插青蓮

疊字峰　　　　　　　　　　　前人

编辑

编辑

朵朵傲風雲葉，層層薄日霜華。傳得彭翁餐法，移來

​
不學《淮南》雞犬，一時相隨上天。試問叢祠受賽，何如

一泓蟹眼吐沫，雙澗燕尾分流。人道渭清涇濁，信從

编辑

急淙瀑布千丈，飛雲冒絮百重。更許餐霞煮石，山人

天池　　　　　　　　　　　　前人
[
编辑
]

天上莫疑銀漢，池底亦自青天。白雲徐動玉皺，明月

太和山　　　　　　　　　　李東陽
[
编辑
]

「神仙宮府事何如，親見分符上紫虛。」山擁帝宮三十
六，地屯兵衛五千餘。人言才大難為用，我愛官閑好
讀書。臨別與君堪一博，肯將青紱換緋魚。

登太和山　　　　　　　　　　劉丙
[
编辑
]

翠倚晴空石磴斜，一層高更一層加。山從雲上應生
路，人向天邊卻作家。徑滑濃飄千種葉，巖香常帶四
時花。禮餘玉帛經行處，只在仙宮護彩霞。

淨樂宮　　　　　　　　　　　賈詠
[
编辑
]

淨樂宮幽遠市朝，誕真福地紫雲饒。南瞻大嶽凌霄
漢，北望神州近斗杓。物外乾坤容我到，壇前風雪自
天飄。果然乞得長生術，為禮仙官不憚遙。

登太和山　　　　　　　　　杜海亨
[
编辑
]

重疊山頭一覽空，人間天上許誰同。碧桃楊柳朝含
雨，翠竹蒼松夜吼風。鐘磬音隨香篆杳，修真人與道
心通。紅蓮碧藕天遺種，元妙原非斧鑿工。

登太和山次韻　　　　　　　李宗木
[
编辑
]

七十二峰宿雨晴，諸宮羅列蕊珠明。乾坤新幻蓬壺
影，霄漢時傳鐘鼓聲。漱石泉從雲裏聽，振衣身在斗
邊行。奇遊到此飜成媿，何用浮名絆此生。

太和山　　　　　　　　　　孫應鰲
[
编辑
]

天柱開金闕，虹梁綴玉墀。勢雄中漢表，氣渾太初時。
日月低雙璧，神靈肅萬儀。名山遊歷遍，誰似此山奇。

松蘿峰　　　　　　　　　　　前人
[
编辑
]

幕地翠宮滿，松蘿拾作衣。憑衿不盡興，凝眺淡忘歸。

七星峰　　　　　　　　　　　前人
[
编辑

《輿地紀勝》：「關尹喜號文始先生。當周之末，大道將隱，預占紫氣西邁，當有有道者過之。遂出為函谷關令尹。未幾，太上度關，喜執弟子禮迎拜於前。太上授《道》《德》二經，約後會於蜀之青羊肆。尹喜遂托疾不仕，隱居谷內。後入蜀，復自蜀歸，棲於武當山三天門石壁之下。」今石門、石室，喜之所居也。古有銅床玉案，今無
之矣，以其所居名曰「尹喜巖」，澗曰「牛漕澗，青羊澗，皆太上訪喜之地​《太平御覽》：「漢武帝遣殿上將軍戴生之武當山採仙藥，後遂得道不返。」《甄異傳》：「歷陽謝允，字道通，年十五，為蘇峻賊軍王免所掠，賣之東陽蔣鳳家。嘗行山中，見虎檻中狗，竊念狗餓，當以飯飴之。及入檻，方見是虎，攀木仰視，允謂虎曰：『此檻木為汝施我，憫汝死其中。汝不殺我，我放汝』。乃開檻出虎。賊平之後，允詣縣別良善。時烏程令張球不為申理，桎梏栲楚。允夜夢神人曰：『此中易入難出，汝有慈心，當救汝急』。」次日見一少年，通身黃衣，
遙在柵外，時進獄中，與允言語。獄吏知是異人，由是
不敢枉允。蒙理還都，西上武當山。太尉庾公聞而愍
之，給其糧資，隨致襄陽。見道士說吾師戴先生孟盛
子非世間人也，嘗囑吾曰：若有西上欲見我者，可將
來。允因隨去，入武當山，齊戒三日，進見先生，乃是昔
日所夢人也。問允復見黃童不，因賜以神藥三丸，服
之便不飢渴，無所思欲，先生亦無常處，時有祥雲紫
氣覆其上，或聞芳香之氣徹于山谷。

《宋史陳摶傳》：「摶字圖南，亳州真源人。始四五歲，戲渦水岸側，有青衣媼乳之，自是聰悟日益。及長，讀經史百家之言，一見成誦，悉無遺忘，頗以詩名。後唐長興中，舉進士不第，遂不求祿仕，以山水為樂。自言嘗遇孫君仿、麞皮處士二人者，高尚之人也，語摶曰：『武當山九室巖可以隱居』。摶往棲焉。因服氣辟穀，歷二十」餘年，但日飲酒數杯。

《貴耳集》均州武當山，真武上昇之地，其靈應如響。均
州未變之前，韃至聖降筆曰：「北方黑煞來，吾當避之。」繼而真武在大松頂現身三日，民皆見之。次年有范
用吉之變，韃犯武當，宮殿皆為一空，有一百單五歲
道人首殺之，則知神示人有去意矣。先者，均州城壕
忽出一坐鐵佛，高三丈。武當山東舊有鐵佛寺，其僧
請歸本寺，百餘軍輿之不動，軍帥禱之，許以草創小
寺安奉，只用三五十輩小兒，輿之即行。後差老巫媼
奉事，凡有病告者，飲佛水即安。端平四年，韃圍攻武
當，砲聲震天，鐵佛為之撼戰。後韃攻定城，韃人以砲
坐罩鐵佛於其下，光州遂失。《左傳》云：「國將興，聽于人；國將亡，聽于神。」即此意也。

《太和山志》：宋張士遜，光化人，少孤貧，讀書武當山。有
道士見而異之曰：「子有道氣，可隨我學仙，公不欲。」道
士曰：「不然，亦位極人臣。」至雍熙中登科甲，位至宰相。
後竟隱武當山去。

謝天地者，不知姓名。住武當山，絕粒不食，步履如飛。
居南巖更衣臺下石室中，石壁萬仞，下臨絕澗，凡人
莫能往來。公飛行自若，人有啟問，但應之曰：「謝天地。」餘無他語。人以是名之。所居之巖，人亦以是名。後仙
去，不知所在。

孫寂然，名元政，號寂然子。嗣業茅山清真觀，得上清
五雷諸法之妙，遍禮福庭。時汴湖龍去江漢罹金兵
之厄，武當殿宇為之一空。紹興辛酉，首登武當，興復
五龍，開闢基緒。以符水禳禬為民除疾，眾皆歸之。數
年之間，殿宇悉備。高宗詔赴闕庭，以符水稱旨，敕度
道士十人。後還山，無疾而逝，藏其脫於桃源之東。
鄧真官名道安，孫寂然之弟子也。自幼隨師開復武
當，首蒙恩賜，盡得其師上清五雷諸法之妙，遠邇疾
患皆奔趨之。繼奏敕住五龍，興建正殿，頑石壁立，鑱
鑿甚苦，默施神用，一夕雷雨，為破其石，度弟子數人。
嘉泰中，預告徒眾，奄然而逝。

吉志通，郃陽人。幼穎悟，博學洽聞。居武當山，十年不
火食，但餌黃精蒼朮，精神澄澈，行步若飛。一日召弟
子，戒以「珍重道教」，言訖而逝。元中統甲子也。

汪貞常，名思真。生於安慶，嗣全真教法，入武當山。至
元乙亥，領徒眾六人開復五龍。荊榛塞途，黑虎為之
引導，興建殿宇，四方師禮之。度徒任本宮提點，吉凶
預知。後無疾而蛻，俗民多夢其步紫雲而北去。
魯洞雲，名大宥，幼入武當學道，遍歷南北。至元乙亥，
偕汪貞常開復武當，住紫霄巖。年八十餘，以道著點
墨片紙，可以療疾，度徒眾百餘人，解化之日，面若童
顏。

武當太和張真人，嗣「清微法。」凡有祈禱，無不感應。
李孤雲，河南人。洪武初來武當五龍宮，與鄉人李幽
巖為方外友。壽九十有二，冠劍藏於桃源洞。

《雍州記》：「陰長生，漢光武陰后之族，鄧州人，馬明生之弟子也。得師太陽神丹之訣，同隱武當。丹成馭氣飛行，周遊六合，後至中州仙都，白日上昇。」《真誥》：「謝允字道通，歷陽人。少英毅，歷仕羅邑宰，博覽群書，道學尤精，政事廉能，恆有遯世脫塵之志。晉太康中上表辭官入道，許之。遂西上武當，至襄陽，見一道士語之曰：『吾師戴先生孟盛子非世間人。諭我曰：『若有西上欲見我者，可與俱來，得無君乎』。因與俱至山，見戴先生坐於石上，神彩洞徹，授以鍊神沖虛之』」道，俄失公所在。於是結茅石室，不數年得沖寂之妙，
能飛行絕壁，自號曰「謝羅山」，蓋謝脫羅邑之宰也。後
仙去，莫知所之。

唐呂純陽，父姓李，母姓呂，本唐宗冑，中進士狀元及
第，因武后殲唐子孫，乃從母姓。先隱太華山中。道明
三元，苦心救世。上帝選群仙，詔為天仙狀元，又命為
傳教祖師。嘗遊武當，居紫炁峰。
孫思邈，華原人，七歲日誦千言，獨孤信見之，曰：「聖童也，顧器大難為用耳。」及長，好談《老》《莊》，隱於太白山，學
道鍊氣養神，求度世之術，洞曉天文，精究醫藥。偶見
牧童傷一小蛇，血出，思邈脫衣贖而救之。旬餘出遊，
見一白衣少年，下馬拜謝曰：「吾弟蒙道者所救。」復邀
思邈至家，易以己馬，偕行如飛。至一城郭，花木盛開，
金碧炳燿，儼若王者居。見一人袷帽絳衣，侍從甚眾，
忻喜趨接，謝曰：「深蒙厚恩，故遣兒子相迎。」因指一青
衣小兒云：「前者此兒獨出，為牧豎所傷，賴道者脫衣贖救，得有今日。」乃令青衣小兒拜謝。思邈始省昔日
救蛇事，潛問左右曰：「此為何所？」對曰：「此涇陽水府也。絳衣王者」命設酒饌妓樂宴思邈。思邈辭以辟穀服
氣，惟飲酒耳。留連三日，乃以輕綃金珠相贈，思邈堅
辭不受。乃命其子取《龍宮奇方》三十首與思邈曰：「此可以助道者濟世救人。」思邈歸，以是方歷試皆效，乃
編入《千金方》中。遍遊各山，歷武當，隋文帝徵為國子
