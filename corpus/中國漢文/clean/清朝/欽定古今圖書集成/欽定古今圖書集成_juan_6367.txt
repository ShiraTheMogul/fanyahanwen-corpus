乾象典第八十三卷

雨部藝文三
〈詩詞〉
[
编辑
]

初雨　　　　　　　　　　　宋韓琦
[
编辑
]

乍覺塵香動，風前細若繅。無聲猶似雪，得潤已如膏。
美利存南畝，餘滋付小桃。誰知青皞德，意不為嬉遨。

次韻和子淵學士春雨　　　　　前人
[
编辑
]

天幕沈沈淑氣溫，雨絲輕軟墜雲根。洗開春色無多
潤，染盡花光不見痕。寂寞畫樓和夢鎖，依微芳樹過
人昏。堂虛坐密珠簾下，試問淳于醉幾樽。

北塘春雨　　　　　　　　　　前人
[
编辑
]

《葉葉》輕雲帳薄羅，坐看膏澤灑庭柯。風前芳杏紅香
減，煙外垂楊綠意多。聲落檐牙飛短瀑，點勻池面起
圓波。晴來西北憑闌望，拂黛遙峰濯萬螺。

喜雨　　　　　　　　　　　歐陽修
[
编辑
]

大雨雖滂沛，隔轍分晴陰。小雨散浸淫，為潤廣且深。
「浸淫苟不止，利澤何窮已。無言雨大小，小雨農尤喜。宿麥已登實，新禾未抽秧。及時一日雨，終歲飽豐穰。夜響流霡霂，晨暉霽蒼涼。川原淨如洗，草木自生光。童穉喜瓜芋，耕夫望陂塘。誰云田家苦，此樂殊未央。」
夏雨　　　　　　　　　　　梅堯臣
[
编辑
]

林梅初弄熟，密雨閉重關。潤裛衣巾上，涼生竹樹間。
水聲通遠澗，雲色暝前山。野鳥寂無語，公庭盡晝閒。

細雨　　　　　　　　　　　　劉敞
[
编辑
]

小雨滿前軒，濃陰不時卷。隨風氣潛潤，竟日花微泫。
池光慘澹昏，樓色依微辨。寒添夕景長，坐逼秋容晚。
楚客歌《泬寥》，吟懷孰云淺。

===暴雨　　　　　　　　　　　　徐積===
​
玉女投壺天大笑，千尋火炬當空照。老龍行遲天忽
怒，雷車壯士鍧連鼓。黑鱗鐵甲十萬許，急把銀河傾
作雨。

次韻章傳道喜雨　　　　　　　蘇軾
[
编辑
]

去年夏旱秋不雨，海畔居民飲鹹苦。今年春暖欲生
蝝，地上戢戢多於土。預憂一旦開兩翅，口吻如鋒那
肯吐。前時渡江入吳越，布陣橫空如項羽。農夫拱手
但垂泣，人力區區固難禦。僕緣騣尾困牛馬，啗齧衣
服穿房户。坐觀不救亦何心，秉畀炎火傳自古。荷鋤
散掘誰敢後，得米濟饑還小補。常山山神信英烈，麾
「駕雷公呵電母。應憐郡守老且愚，欲把瘡痍手摩撫。山中歸時風色變，中路已覺商羊舞。夜窗騷騷鬧松竹，朝畦泫泫流膏乳。從來蝗旱必相資，此事吾聞老農語。庶將積潤掃餘孽，收拾豐歲還明主。縣前已窖八千斛，率以一升完一畝。更看蠶婦過初眠，未用賀客來傍午。」先生筆力吾所畏，蹙踏鮑謝誇徐庾。偶然
談笑得佳篇，便恐流傳成樂府。陋邦一雨何足道，吾
君盛德九州普。中和樂職幾時作，試向諸生選何武。

連雨漲江二首　　　　　　　　前人
[
编辑
]

越井岡頭雲出山，牂牱江上水如天。床床避漏幽人
屋，浦浦移家蜑子船。龍卷魚蝦並雨落，人隨雞犬上
牆眠。只應樓下平階水，長記先生過嶺年。

又

「急雨蕭蕭作晚涼，臥聞榕葉響長廊。微明燈火耿殘夢，半濕簾帷浥舊香。」高浪隱床吹甕盎，闇風驚樹擺
琳琅。先生不出晴無用，留向空階滴夜長。

時雨　　　　　　　　　　　孔武仲
[
编辑
]

空車輾雷，幟摧電，千里冥冥甘雨遍。元豐嘉號卜長
年，太乙真人宅畿甸。齋宮夜禱回天聽，美澤朝流慰
人願。豆苗蓬蓬粟低垂，土脈舒蘇蝗不飛。野老謳歌
忘帝力，夕陽相與荷鋤歸。

雨　　　　　　　　　　　　郭祥正
[
编辑
]

林林銀燭注潺湲，迸玉跳珠亂壑間。不惜倚闌襟袖
濕，為君吟出「雨中山。」
喜雨　　　　　　　　　　　　張耒
[
编辑
]

手種五芭蕉，意待聴秋雨。南風扇旱雲，破葉萎不舉。
滂沱未終夕，綠潤遽如許。秀色入書幃，已覺青鸞舞。

雨後　　　　　　　　　　　李昭𤣱
[
编辑
]

苦雨幾十日，滿庭多土花。行螺上牆屋，倒竹臥泥沙。
澄景生涼吹，晴雲變晚霞。卻愁秋夜夢，無計逐池蛙。

晚雨　　　　　　　　　　　　楊時
[
编辑
]

斷霞明滅天日黝，雨意晴暉爭好醜。浮雲冉冉無定
姿，白衣忽變如蒼狗。悲風激烈河漢翻，雨腳如麻飛
霰寒。山深氣腥豺虎亂，乾坤四合誰云寬。溪頭野客
懶成癖，怯寒手攣面如墨。把杯強吞僵立歌，閉門獨
愁天已黑。

小雨　　　　　　　　　　　　李綱
[
编辑
]

「小雨晚初急，暝雲深不收。霏霏暗煙舍，索索響篷舟。」山色增遠翠，漁蓑生暮愁。凄涼蘇季子，寒覽敝貂裘。

春雨　　　　　　　　　　　李彌遜
[
编辑
]

濛濛煙雨網春暉，南陌清明二月時。細草養泥留燕
子，好花藏蜜待蜂兒。

《前題》
孫覿
[
编辑
]

細雨破春昏，清風洗瘴氛。霏微花上見，蕭瑟夜深聞。
獨笑關幽事，酣歌倚半醺。羈懷不堪寫，危坐對爐芬。

雨　　　　　　　　　　　　陳與義
[
编辑
]

沙岸殘春雨，茅簷古鎮官。一時花帶淚，萬里客憑闌。
日晚薔薇重，樓高燕子寒。惜無陶謝手，盡力破憂端。

《前題》
前人
[
编辑
]

雲起谷全暗，雨晴山復明。青春望中色，白澗晚來聲。
遠樹鳥群集，高原人獨耕。老夫逃世久，堅坐聽陰晴。

細雨　　　　　　　　　　　　曾幾
[
编辑
]

「霡霂無人見，芭蕉報客聞。」潤能添硯滴，細欲亂爐薰。
竹樹驚秋半，衾裯愜夜分。何當一傾倒，趁取未歸雲。

雨　　　　　　　　　　　　　朱松
[
编辑
]

摵摵初鳴竹，涓涓稍滴簷。忽然憂夢斷，更覺曉寒添。

又
[
编辑
]

纖纖花入麥，漫漫雨黃梅。泥徑無人度，風簾為燕開。

久雨　　　　　　　　　　　鄭綱中
[
编辑
]

山嵐變濃雲，地氣洩冬熱。急雨春風顛，十日聲不絕。
舍中流水入，牆外古溝咽。塊然簷下雀，狀若木雞拙。
我亦類禪定，癡坐萬慮歇。廚兵忽相報，謂已糝藜蕨。
隨緣就一飽，再看《柏香》爇。

雨　　　　　　　　　　　　張九成
[
编辑
]

已止還復作，瀉簷聲更長。苔錢添晚翠，梅子試新黃。
屋裏圖書潤，庭前蘭芷香。倚闌閒覓句，水閣夜生涼。

小雨　　　　　　　　　　　　陸游
[
编辑
]

細細濕春光，霏霏破夕陽。臥聞驚倦枕，起看入虛堂。
映葉鶯猶囀，爭泥燕正忙。閒愁無遣處，誰與共飛觴。

雨　　　　　　　　　　　　　前人
[
编辑
]

映空初作繭絲微，掠地俄成箭鏃飛。紙帳光遲饒曉
​
夢，銅爐香潤覆春衣。池魚鱍鱍隨溝出，梁燕翩翩接

翅歸。惟有落花吹不去，數枝紅濕自相依。

雨聲　　　　　　　　　　　　前人
[
编辑
]

暑氣滿天地，薄暮加煩促。清風吹急雨，集我北窗竹。
竹聲蕭蕭固自奇，况得雨聲相發揮。令人忽憶雲門
寺，半夜長松墮雪時。

聴雨　　　　　　　　　　　　沈說
[
编辑
]

耳根聽不歇，滴滴冷於秋。疑是山翁醉，岩前枕瀑流。

久雨　　　　　　　　　　　宋伯仁
[
编辑
]

暗數春來雨，曾無兩日晴。樹連山莫辨，橋與水俱平。
閉户惟便懶，逢人且問耕。「海棠花落盡，顦粹幾流鶯。」
聽雨　　　　　　　　　　　胡仲參
[
编辑
]

聽盡燈前細雨聲，聲聲總是別離情。何時斷得閒煩
惱，一任芭蕉滴到明。

夜雨　　　　　　　　　　　徐集孫
[
编辑
]

夜半倏驚覺，狂風攪秋鳴。掣電起迅雷，驟雨翻盆傾。
逆知造物意，揫斂萬寶成。天威不竟夕，須臾山月明。

鹿田聽雨　　　　　　　　　　方鳳
[
编辑
]

禪棲投倦客，山雨起更闌。窗葉散幽響，石林生峭寒。
洞深猶暗瀑，江遠忽風湍。想像雲蘿外，應宜晚色看。

喜雨　　　　　　　　　　　朱淑真
[
编辑
]

赤日炎天燒八荒，田中無雨苗半黃。天公不放老龍
懶，掣電驅雷雲四方。瓊瑰萬斛瀉碧落，陂湖池沼皆
泱泱。高田低田盡沾澤，農喜禾無枯槁傷。我皇聖德
布寰宇，六月青天降甘雨。四海咸蒙滂沛恩，九州盡
