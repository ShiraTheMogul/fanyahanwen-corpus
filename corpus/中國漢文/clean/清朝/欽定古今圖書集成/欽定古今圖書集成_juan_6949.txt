顧璘
[
编辑
]

按《江寧府志》：「顧璘，字華玉，上元人。弘治丙辰進士，歷進工部尚書，改南刑部。融朗闊達，精於吏理，能激昂任事，為文不事險刻，必古人為師。詩矩矱唐人，而劖芟陳爛，時出奇峭。樂府歌詞，不失漢魏風格云。」按弇州山人槁華玉書，翩翩有晉人意。

按《書史會要》：「璘善行草，筆力高古。」
按《金陵瑣事》，東橋真草，皆清徹可愛。

顧𤩰
[
编辑
]

按《列朝詩集小傳》：「顧𤩰，字英玉，華玉之從父弟也。正德甲戌進士，授南京工部主事，歷官河南副使。罷歸，橐蕭然無以給，昕夕臨街一小樓，扁曰『寒松』，訓蒙童數人以自給。」
按《金陵瑣事》，「英玉真草，皆有晉人風味。」
鄭善夫
[
编辑

按《名山藏》：「鄭善夫字繼之，閩縣人。初為戶部主事，劉瑾用事，告歸。築少谷草堂，巖居六載。起為禮部員外郎，復告歸。嘉靖改元，薦起吏部郎中。」
按：《五雜組》，善夫署書，倣晦翁而自得。

按《書史會要》：「善夫書法入神，真行斟酌聖教，狂草奔放，縱橫爛熳，顛素而下弗論也。」
陳沂
[
编辑

按《名山藏》：陳沂初字宗魯，後字魯南，鄞人。正德十二
年進士，改庶吉士，除編修。嘉靖中以行太僕卿致仕，
好蘇氏學，自號曰「小坡。」與顧璘、王韋稱「金陵三俊。」按《金陵瑣事》：沂書學蘇長公，㫄及篆隸繪事，皆稱能
品。

楊珂
[
编辑
]

按《紹興府志》：「楊珂，字汝鳴，餘姚諸生。從王文成學，隱居祕圖山，養母以孝聞。為詩瀟灑不群，書得晉人筆法。」　又按《志》：「王可寇元美跋其所書雜詩云：『余初入比部時，同舍郎吳峻伯論書法，輒云：故人楊祕圖珂者，今之右軍也』。余購得此卷，不勝喜，以示峻伯。峻伯為之解云：『此非右軍而何』？余時心不能服，然無以辨之。」又數載，稍稍識書法。一日檢故卷出而更閱之，蓋
楊生平不見右軍佳石刻，僅得今關中諸王邸翻搨
十七帖，其結構盡訛，鋒勢都失，別作一種細筆，而臨
摹不已，遂成《鎮宅符》，又似雨中聚蚓耳。然詩語亦得
一二佳者。今聞其人尚在，多作狂草，或從左，或從下
起，或作偏傍之半而隨益之，其書益弱而多譌，然自
負日益甚，詩亦日益下。第其為人瀟灑，食貧，有遺世
之度，可念也。

按《藝苑巵言》：「楊珂初亦習二王，後益放逸，柔筆疏行，了無風骨，所謂南路體也。」

按《甘泉先生墓志銘》，「湛若水，字元明，初名露，字民澤，避祖諱改今名。居廣之增城甘泉都，學者稱甘泉先生。從游，陳白沙以斯文屬之。弘治乙丑進士，選庶吉士，授編修。嘉靖中為兵部尚書。」
按：《藝苑巵言》，「若水倣陳白沙，天然不及也，惟署書差有骨。」
魏校
[
编辑

按《分省人物考》：「魏校字子才，號莊渠，崑山人。弘治乙丑進士。世廟初，以太常少卿監國子祭酒，諡恭簡。著《六書精蘊》。」
按《簣齋文集》：「太常卿莊渠魏公常著《六書精蘊》，因古文以正小篆之偽，又參大篆及擇小篆之可者以補古文之闕。」
顧應祥
[
编辑
]

按《弇州山人槁》：「顧應祥，初名夢麟，字惟賢，長洲人，家吳興。舉進士，授饒州府推官，累遷南京刑部尚書，贈太子少保。詩似白少傅，書似趙吳興。」
陸深
[
编辑
]

按《桂洲文集》：「陸深，字子淵，號儼山，華亭人。弘治乙丑舉進士，改庶吉士，授編修。嘉靖中為詹事致仕，贈禮部侍郎，諡文裕。書法妙逼鍾、王，比於趙松雪而遒勁過之。」
按《龍江集儼山陸公行狀》云：「國初吾松多以書學名天下，久已絕響。公近奮起，遂凌蹴前人而處其上。」張
電以書學際遇，實出公所指授，識者謂公趙文敏後
一人，非諛詞也。

按《莫廷韓集》：陸文裕自言：「吾與吳興同師北海，海內人以吾為取法於趙，是意不安於趙也。」究論其風力，
實出吳興之上。

按《畫禪室隨筆》：「陸宮詹以書名家，雖率爾作應酬字，俱不苟且，曰：『即此便是學字，何得放過』？」
按《續文獻通考》：「陸文裕少時，作小楷精謹，自謂有黃庭遺教意，然不能離趙吳興也。行草法李北海，而亦出入吳興，晚節尤妙。」
按《雲間志略》：「陸深真草行書，如鐵畫銀鉤，遒勁有法，頡頏北海，而伯仲子昂，一代之名筆。」
邵銳
[
编辑
]

按《列卿紀》：「邵銳，仁和人。正德戊辰進士。改庶吉士，授編修。嘉靖十一年為太僕寺卿。諡康僖。」
按：《弇州續槁名賢遺墨》有邵銳書。

周金
[
编辑
]

按《荊川文集》：「周金字子庚，號約菴，武進人，徙南京。正德戊辰進士，擢給事中。嘉靖時為南京戶部尚書。善字書，有晉人風骨。贈太保，諡襄敏。」
許成名
[
编辑
]

按《分省人物考》：「許成名字思仁，聊城人。正德辛未進士，選庶吉士，授編修。嘉靖初為禮部左侍郎。書初學逸少，已沈酣吳興，小變之，遒逸飛動，為海內鑒賞。」按《藝苑巵言》：「成名作真行，筆頗簡勁，然結構疏而醜。」
韓玉
[
编辑
]

按《空同集》：「韓玉字廷瑞，通許人。舉於鄉，拜郯城知縣。棄官歸，稱寄傲子，嗜古詩奇字。嘉靖二年七十歲矣，尚作蠅頭楷字，即片紙未見一畫苟也。」
徐江山
[
编辑
]

按《杭州府志》：「徐江山，字六橋，錢塘人。正德辛未進士，官尚寶卿。工真草法。世宗愛其書，御製詩文必命江山書之。」
何瑋
[
编辑

按《寧波府志》：「何瑋，字叔田，工篆書而精于書，學通《易》理，考功豐坊之師。」
