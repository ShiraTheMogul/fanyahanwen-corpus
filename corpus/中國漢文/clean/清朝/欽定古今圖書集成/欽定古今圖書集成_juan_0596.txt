蘭部藝文二
〈詩詞〉
[
编辑
]

《猗蘭操》
周孔子
[
编辑
]

《琴操》曰：孔子歷聘諸侯，諸侯莫能任，隱谷之中，見薌蘭獨茂，喟然嘆曰：「蘭當為王者香，今乃與眾草為伍。」 止車援琴鼓之，自傷不逢時，託辭於蘭云。

習習谷風，以陰以雨。之子于歸，遠送于野。何彼蒼天，
不得其所。逍遙九州，無所定處。時人闇蔽，不知賢者。
年紀逝邁，一身將老。

《怨篇》
漢·張衡
[
编辑
]

猗猗秋蘭，植彼中阿。有馥其芳，有黃其葩。雖曰幽深，
厥美彌嘉。之子云遠，我勞如何？

《古樂府》
闕名
[
编辑
]

蘭草自然香，生於大道傍。腰鐮八九月，俱在束薪中。

《酒會詩》
晉·嵇康
[
编辑
]

猗猗蘭藹，植彼中原。綠葉幽茂，麗蕊濃繁。馥馥惠芳，
順風而宣。將御椒房，吐薰龍軒。瞻彼《秋草》，悵矣惟騫。

《幽蘭》
宋·鮑照
[
编辑
]

傾輝引暮色，孤景留思顏。梅歇春欲罷，期渡往不還。

又

簾委蘭蕙露，帳含桃李風。攬帶昔何道，坐令芳節終。

又

結佩徒分明，抱梁輒乖忤。華落知不終，空愁坐相誤。

又

眇眇蛸挂網，漠漠蠶弄絲。空慚不自信，怯與君畫期。

又

陳國鄭《東門》，古今共所知。長袖暫徘徊，駟馬停路岐。

《紫蘭始萌》
梁·武帝
[
编辑
]

《種蘭》玉臺下，氣暖蘭始萌。芬芳與時發，婉轉迎節生。
獨使金翠嬌，偏動紅綺情。二遊何足懷，一顧非傾城。
羞將芩芝侶，豈畏鶗鴂鳴。

《賦得蘭澤多芳草》
元·帝
[
编辑
]

春蘭本無艷，春澤最葳蕤。燕姬得夢罷，尚書奏事歸。
臨池影入浪，從風香拂衣。當門已芬馥，入室更芳菲。
蘭生不擇逕，十步豈難稀。

《蘭》
宣帝
[
编辑
]

折莖聊可佩，入室自成芳。開花不競節，含香委微霜。

《賦得蘭生野徑》
陳張正見
[
编辑
]

披襟出《蘭畹》，命酌動幽心。鋤罷還開路，歌喧自動琴。
華燈共影落，芳杜雜花深。莫言「閒逕裡，遂不斷黃金。」《猗蘭操》
隋·辛德源
[
编辑
]

奏事傳青閣，拂除乃陶嘉。散條凝露彩，含芳映日華。
已知香若麝，無怨直如麻。不學芙蓉草，空作眼中花。

《芳蘭》
唐·太宗
[
编辑
]

春暉開紫苑，淑景媚蘭場。映庭含淺色，凝露泫浮光
​
日麗參差影，風傳輕重香。會須君子折，佩裡作芬芳。

《蘭》
李嶠
[
编辑
]

虛室重招尋。忘言契斷金。英浮漢家酒，雪灑楚王琴。
廣殿輕香發，高臺遠吹吟。河汾應擢秀。誰肯訪山陰。

《感遇》
陳子昂
[
编辑
]

《蘭若》自春夏，芊蔚何青青。幽獨空林色，朱蕤冒紫莖。
遲遲白日晚，嫋嫋秋風生。歲華盡搖落，芳意竟何成。

《園中時蔬盡皆鋤理惟秋蘭數本委而不顧彼雖一物有足悲者遂賦二章》
張九齡
[
编辑
]

場藿已成歲，園葵亦向陽。蘭時獨不偶，露節漸無芳。
旨異菁為蓄，甘非蔗有漿。人多利一飽，誰復惜馨香。
幸得不鋤去，孤苗守舊根。無心羨旨蓄，豈欲近名園。
遇賞寧充佩，為生莫礙門。幽林芳意在，非是為人論。

《贈友》
李白
[
编辑
]

蘭生不當戶，別是閒庭草。夙被霜雪欺，紅榮已先老。
謬接瑤華枝，結根君王池。顧無馨香美，叨沐春風吹。
餘芳若可佩，卒歲長相隨。

《古風》
前人
[
编辑
]

孤蘭生幽園，眾草共蕪沒。雖照陽春輝，復悲高秋月。
飛霜早淅瀝，綠艷恐休歇。若無清風吹，香氣為誰發。

《古意》
賀蘭進明
[
编辑
]

崇蘭生澗底，香氣滿幽林。采采欲為贈，何人是同心。
日暮徒盈把，裴徊幽思深。慨然紉雜佩，重奏《丘中琴》。

《令狐相公見示新栽蕙蘭二草之什兼命同作》
[
编辑
]

劉禹錫

上國庭前草，移來漢水潯。朱門雖易地，玉樹有餘陰。
艷彩凝還泛，清香絕復尋。光華童子佩，柔軟美人心。
惜晚含遠思，賞幽空獨吟。寄言知音者，一奏《風中琴》。

《猗蘭操》
韓愈
[
编辑
]

蘭之猗猗，揚揚其香。不採而佩，於蘭何傷。今天之旋，
其曷為然？我行四方，以日以年。雪霜貿貿，薺麥之茂。
子如不傷，我不爾覯。薺麥之茂，薺麥之有。君子之傷，
君子之守。

余昔自西濱得蘭數本移藝於庭亦既逾歲而芃然蕃殖自余遊者未始以芳草為遇矣因悲
[
编辑
]

「夫物有厭常而返，不若混然者有之焉，遂寄情於此　　　　　　　　　　　。」 《溫庭筠》

寓賞本殊致，意幽非我情。吾常有疏淺，外物無重輕。
各言藝幽深，彼美香素莖。豈為賞者設，自保孤根生。
易地無赤株，麗土亦同榮。賞際林壑近，泛餘煙露清。
余懷既鬱陶，爾類徒縱橫。妍蚩苟不信，寵辱何為驚。
真隱諒無跡，激時猶簡名。幽叢靄綠畹，豈必懷歸耕。

《詠蘭》
唐·彥謙
[
编辑
]

清風搖翠環，涼露滴蒼玉。美人胡不紉，幽香藹空谷。

又

「謝庭漫芳草，楚畹多綠莎。」於焉忽相見，歲晏將如何。

《種蘭》
陳陶
[
编辑
]

「種蘭幽谷底，四遠聞馨香。春風長養深，枝葉趁人長。智水潤其根，仁鋤護其芳。蒿藜不生地，惡鳥弓已藏。椒桂夾四隅，茅茨居中央。左鄰桃花塢，右接蓮子塘。一月薰手足，兩月薰衣裳。三月薰肌骨，四月薰心腸。幽人饑如何，採蘭充餱糧。幽人渴如何，醞蘭為酒漿。地無青苗租，白日如羲皇。不嘗仙人藥，端坐紅霞房。」日夕望美人，佩花正煌煌。美人久不來，佩花徒生光。
刈穫及葳蕤，無令見雪霜。清芬信神鬼，一葉豈可忘。
舉頭愧青天，鼓腹詠時康。下有賢公卿，上有聖明王。
無階答風雨，願獻蘭一筐。

《幽蘭》
崔塗
[
编辑
]

幽植眾寧知，芬芳只暗持。自無君子佩，未見國香衰。
白露沾常早，春風到每遲。不如當路草，芬馥欲何為。

《詠蘭》
釋無可
[
编辑
]

蘭色結春光，氛氳掩眾芳。過門階露葉，尋澤逕連香。
畹靜風吹亂，亭秋雨引長。靈均曾採擷，紉佩挂荷裳。

《蘭》
宋·梅堯臣
[
编辑
]

楚澤多蘭人未辨，盡以清香為比擬。蕭茅杜若亦莫
分，唯取芳香襲衣美。

《朱朝議移法雲蘭》
王安石
[
编辑
]

幽蘭有佳氣，千載閟山阿。不出「《阿蘭》若，豈遭乾闥婆。」《題楊次公春蘭》
蘇軾
[
编辑
]

春蘭如美人，不採羞自獻。時聞風露香，蓬艾深不見。
丹青寫真色，欲補《離騷傳》。對之如靈均，冠佩不敢燕。

《種蘭》
蘇轍
[
编辑

蘭生幽谷無人識，客種東軒遺我香。知有清芬能解
穢，更憐細葉巧凌霜。根依密石秋芳早，叢倚修筠午
蔭涼。欲遣蘼蕪共堂下，眼前長見「《楚詞》章。」《次韻答人幽蘭》
前人

编辑
]

幽花耿耿意羞春，紉佩何人香滿身。一寸芳心須自
保，長松百尺有為薪。

《答琳長老寄幽蘭》
前人

编辑

谷深不見蘭生處，追逐微風偶得之。解脫清香本無

《幽蘭花》
前人
[
编辑

李徑桃蹊次第開，穠香百和襲人來。春風欲擅秋風

珍重幽蘭開一枝，清香耿耿聽猶疑。定應欲較香高

《蘭》
陸游
[
编辑
]

「南巖路最近，飯已時散策。香來知有蘭，遽求乃弗獲。」「生世本幽谷，豈願為世娛。無心託階庭，當門任君鋤。」《次韻溫伯種蘭》
范成大
[
编辑
]

《靈均》墮荒寒，采采紉蘭手。九畹不留客，高丘一回首。
崢嶸路孔棘，悽愴肘生柳。遂令此粲者，永與窮愁友。
不如湯子遠，情事只詩酒。但知愛國香，此外付烏有。
栽培帶苔蘚，披拂護塵垢。孤芳亦有遇，灑濯居座右。
君看深林下，埋沒隨藜莠。

《詠蘭》
楊萬里
[
编辑
]

健碧繽繽葉，斑紅淺淺芳。幽香空自祕，「風肯祕幽香。」《蘭花》
前人
[
编辑
]

雪徑偷開淺碧花，冰根亂吐小紅芽。生無桃李春風
面，名在山林處士家。政坐國香到朝市，不容霜節老
雲霞。江蘺圃蕙非吾耦，付與騷人定等差。

《謝人送蘭》
朱熹
[
编辑

《左傳》：宣公三年冬，鄭穆公卒。初，鄭文公有賤妾曰燕
姞，夢天使與己蘭，曰：「余為伯鯈，余而祖也，以是為而子。」以蘭有國香，人服媚之如是。既而文公見之，與之
蘭而御之。辭曰：「妾不才，幸而有子，將不信，敢徵蘭乎？」公曰：「諾。」生穆公，名之曰蘭。公逐群公子，公子蘭奔晉，
從晉文公伐鄭。石癸曰：「吾聞姬、姞耦，其子孫必蕃。姞」，
吉人也，后稷之元妃也。今公子蘭，姞甥也。天或啟之，
必將為君，其後必蕃。先納之，可以亢寵與？孔將、鉏侯
宣多納之，盟于大宮而立之，以與晉平。穆公有疾，曰：
「蘭死，吾其死乎？吾所以生也。」刈蘭而卒。

《採蘭雜志》：「蘭待女子，同種則香，故名待女。」《聞見後錄》：蘭有二種，細葉者春花花少，闊葉者秋花
花多。黃魯直《蘭說》云：「楚人滋蘭之九畹，樹蕙之百畝，蘭以少故貴，蕙以多故賤。」予以為非是，蓋十二畝為
畹，則九畹、百畝亦相等矣。又云：一榦一花而香有餘
者蘭，一榦五七花而香不足者蕙。是以細葉為蘭，闊
葉為蕙，亦非也。楚人曰：蕙，今零陵香也。又云：「薰和」，謂
一薰一蕕者也。唐人但名鈴鈴香，亦名鈴子香，取其
花倒懸枝間，如小鈴也。近時附入《本草》，云出零陵郡，
亦不詳。《本草》自有薰草條，亦名蕙草，甚明，零陵為重
出云。

蕙，香草也，或謂之薰。《左傳》曰「所謂一薰一蕕」者是也。
凡氣薰則惠和，暴則酷烈，故於文惠草為蕙。《詩》曰：「南風之薰兮，可以解吾民之慍兮。」薰，惠和也，故可以解
民之慍。《莊子》曰「薰然慈仁，謂之君子。」蓋取諸此。今惠
亦通於蕙。揚雄曰：「蹂惠圃，踐蘭唐」是也。《傳》曰：「天子鬯，諸侯薰，大夫蘭芝，士蕭，庶人艾」，大夫併言。蘭芝者，上
大夫蘭，下大夫芝也。蓋凡摯，諸侯圭，大夫羔鴈，士雉，
庶人鶩，此見生者之摯也。天子以鬯，諸侯薰，大夫蘭
芝，士蕭，庶人艾，此見死者之摯也。《禮》曰：「凡摯，天子鬯，諸侯圭，卿羔，大夫鴈，士雉，庶人匹。」此相備也。天子言
鬯，諸侯而下言見生者之摯，蓋言之法也。先儒以為
諸侯薰，謂未得圭瓚之賜，以此和酒，則於《王制》資鬯
之說害矣。且此諸草類皆燒以降神云爾，蓋非煮以
和酒。故《博雅》曰：「天子祭以鬯，諸侯以薰。」而漢之隱君
子以為薰以香自燒，膏以明自銷也。香草之類，大率
多異名，所謂蘭蓀，蓀，今菖蒲是也；蕙今零陵香是也；
茝，今白芷是也；芸今七里香是也。葉類豌豆，作小叢
生，其花極芬香，秋則葉間微白如粉汙，辟蠹殊驗。

蕙大抵似蘭，花亦春開。蘭先而蕙繼之者柔，荑其端
作花蘭，一荑一花蕙，一荑五六花，香次於蘭。大抵山
林中一蘭而十蕙。故黃太史曰：「光風轉蕙氾崇蘭。」《離
騷》：「蘭九畹，蕙百畝。」以是知楚人賤蕙而貴蘭矣。按《離
騷》：「滋蘭九畹，植蕙百畝，畦留彝與揭車，雜杜衡與芳芷。」王逸《章句》曰：「十二畝曰畹，或曰田長二百四十步」為畝，十二畝為畹。然則蘭得一百八畝，蕙百畝，留彝、
揭車合百畝，則多少亦不相遠矣。若以《說文》言之，田
三十畝曰畹，則蘭得二百七十畝，多於蕙兩倍，留彝、
揭車各五十畝，多於兩草一倍，亦多少之差。然言蘭
者每及蕙，畹蘭而畝蕙也，氾蘭而轉蕙也。蕙殽，蒸蘭
藉也。蕙雖不及蘭，勝於餘芳遠矣。《楚辭》又有「菌閣蕙樓。」蓋芝草榦杪敷華，有閣之象。而蕙華亦於榦杪重
重累積，有樓之象云。

《補筆談》：零陵香本名蕙，古之蘭蕙是也，又名薰。《左傳》
曰：「一薰一蕕，十年尚猶有臭。」即此草也。唐人謂之鈴
鈴香，亦謂之鈴子香，謂花倒懸枝間，如小鈴也。至今
京師人買零陵香，須擇有鈴子者，鈴子乃其花也。此
本鄙語，文士以湖南零陵郡，遂附會名之。後人又收
入《本草正經》，自有「薰草」條，又名蕙草，注釋甚明，南方
處處有之。《本草》傅會其名，亦出零陵郡，非也。
