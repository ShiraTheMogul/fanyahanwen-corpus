桂部藝文三
〈詩詞〉

编辑
]

《木樨》
金·酈權
[
编辑
]

「菊小未堪摘，荒池悴芙蕖。窮秋不慰眼，幽獨將焉如。殷勤蕊宮子，種桂庭之除。乘閒弄餘花，散落荒山隅。從茲雲月裔，漂泊生江湖。娟娟耐凍枝，便與群芳殊。琉璃翦芳葆，蛾黃拂仙裾。唾袖花點碧，漱金粟生膚。好花一披拂，九里香縈紆。蘭蕙不敢友，荃蓀正僮奴。妄意此尢物，化工異吹噓。不然九天香，安得獨付渠。託物寄深蘊，古今一三閭。收攬名草木，自比君子徒。惟茲不挂口，無乃聖不居。抑夫古簡編，斷絕秦火餘。君看齊魯臣，史筆逸其書。惜哉不可曉，臨風為嗟吁。尤憐元祐前，不及附歐蘇。末路益可惜，例進宣和初。仙根豈易致，百死不一甦。昔遊汴離宮，識此傾城姝。摩娑三品石，尚想狎客娛。卻後十五」年，微霜半黏鬚。
一枝再經眼，相對憐羈孤。不知苦何事，玉骨乃爾癯。
故人憐我老，尺書遠招呼。要趁秋香濃，共此碧玉壺。
遙知嬋娟客，與我一笑俱。

《元氏桂軒為敏之賦》
王萬鍾
[
编辑
]

簾捲堂前桂子涼，一軒燈火夜初長。月中春好元無
價，天上風來別有香。棠棣一家同映秀，詞林百世繼
餘芳。閒花野草空無數，掩盡人間獨擅場。

《古意》
元·劉祁
[
编辑
]

庭前有桂樹，綠葉尚離披。秋風動地起，飄落將安歸。
高飛入青雲，下飛入汙泥。貴賤既偶爾，孰為喜與悲。

《木樨》
方夔
[
编辑
]

下土花中第一流，移根自笑此生浮。獨依上略清虛
府，滿貯青冥沆瀣秋。稜葉風翻低散亂，蒼皮蟲蝕老
雕鎪。醉來逕向高寒處，自駕青鸞擁玉虯。

又

蒼蒼珠樹俯寒流，析木津頭戲拍浮。褐鳳摶風朝紫
極，硯蟾滴露瀉清秋。返魂香倩羅裳貯，礙月枝憑玉
斧鎪。夜景未闌清入骨，瀟瀟鱗甲臥癡虯。

《木樨花》
前人
[
编辑
]

曾住仙山九折巖，夜涼蘿荔挂衣衫。月窺尊裏如相
伴，人立花邊自不凡。叢綠聯環瑲玉珮，殘花瑣骨現
金函。枝空蟾窟今誰記，猶道東陵繫舊銜。

《冬日見桂花》
李孝光
[
编辑
]

北風吹倒碧瑯玕，金粟棲枝露未乾。翠氣遙連仙掌
曉，天香微墮玉壺寒。明蟾照影臨丹闕，青女銷香著
畫闌。可是天翁露消息，小春先得一枝看。

《月中桂花》
謝宗可
[
编辑
]

金粟如來夜化身，嫦娥留得護冰輪。枝橫大地山河
影，根老層霄雨露春。長有天香飛碧落，不教仙子種
紅塵。折來何必吳剛斧，還我凌雲第一人。

《玉山亭館分題得金粟影》
顧瑛
[
编辑
]

「飛軒下瞰芙蓉渚，檻外幽花月中吐。天風寂寂吹古香，清露泠泠濕秋圃。雲梯萬丈手可攀，居然夢落清虛府。庭中擣藥玉兔愁，樹下乘鸞素娥舞。瓊樓玉殿千娉婷，中有癯仙淡眉宇。問我西湖舊風月，何似東華軟塵土。寒光倒落影娥池，的皪明珠承翠羽。但見山河影動搖，獨有清輝照今古。覺來作詩思茫然，金」粟霏霏下如雨。

===
《桂花》
倪瓚
===
​
「桂花留晚色，簾影淡秋光。靡靡風還落，菲菲夜未央。」玉繩低缺月，金鴨罷焚香。忽起故園想，泠然歸夢長。

《桂枝詞》
張雨
[
编辑
]

桂樹叢生枝婀娜，糝粟黃雲欲成朵。薰醒秋衣嬾下
床，金蟾囓斷燒香鎖。

《紅木樨》
明·太祖
[
编辑
]

月宮移向日宮栽，引得輕紅入面來。好向煙霞承雨
露，丹心一點為君開。

又

秋入幽巖桂影圓，香心粟粟照林丹。應隨王母瑤池
宴，染得朝霞下廣寒。

《宜秋軒桂》
楊基
[
编辑
]

《宜秋軒詩敘》云：「予去官結小軒自適，軒近秦淮，清曠幽寂，與秋相宜，故號宜秋軒。東古桂一株，花已爛漫，人無知者。偶夜聞香自東來，且起訪之，得于荒庭廢苑中。余既嘆其不為人所賞識，而復嘉其不以無人而不香也。繞樹嗟悼，慰之以詩。」《宜秋軒東一株桂》，「香葉婆娑擁寒翠。秋堂夜靜風滿簾，時覺幽芳來拂鼻。清晨曳履訪幽獨，一徑青苔雙戶閉。離離嫩蕊𦊰蟲絲，簌簌輕花落深砌。麩金泫露濃更密，苞粟凝珠疏復細。半粒能含萬斛香，一枝解奪千株麗。當年此地競攀折，月戶雲窗敞秋霽。金樽灔泛綠色酒，翠袖涼簪寶妝髻。西風幾度人跡絕，獨」有幽花能點綴。村荒地僻霜露繁，摧折紅蘭彫紫蕙。
瞥然一見眾憂失，不意孤懷得佳味。更深月出擬再
來，明日紛紛嗟滿篲。

《芳桂塢》
高啟
[
编辑
]

欲攀淮南樹，人去山寂寞。嫋嫋涼風生，疏花月中落。

《涼夜》
前人
[
编辑
]

一聲遠笛數聲砧，月滿江城夜正深。坐據胡床愛涼

《直房聞桂香》
史謹
[
编辑
]

松陰池館晝偏涼，何處飄來桂子香。起傍雕闌看秋
色，廣寒宮殿近昭陽。

《飲錢二孔周宅桂花下》
王寵
[
编辑
]

「嘉樹蔭團團，團團露華白。本自招搖山，植君青霞宅。不意凌寒姿，占此瑤墀隙。高枝挂珠網，卑條敷綺席。萋萋布葉陰，茸茸吐花積。風飄遠近香，月映盈虧魄。既集佳麗人，亦招隱淪客。幸承金樽薦，親勞玉腕摘。歌曲出玲瓏，舞袖隨寬窄。條繁每𦊰釵，花落常點額。戲羽必成雙，棲禽無單隻。及此芳菲時，荷君千金惜。」不醉且淹留，看朱已成碧。

《和陶飲酒》
陳憲章
[
编辑
]

木樨冷於菊，更後十日開。清風吹芳香，芳香襲人懷。
千回嚥入腹，五內無一乖。雖靡鸞鳳吟，亦有鷦鷯棲。
昔者東籬飲，百榼醉如泥。那知此日花，復與此酒諧。
一曲盡一杯，酩酊花間迷。赤腳步明月，酒盡吾當回。

《月桂自白石移來》
前人
[
编辑
]

「金粟初分我，花仙不吝人。」煙霞三畝宅，草木百年身。
影入青霄舊，香傳白石新。為誰工態度，本自惜精神。
翠竹旁通徑，緋桃正隔津。生憂兒女狎，莫摘老夫嗔。
坐久風迴席，行遲露在巾。當時尊玉茗，平地隱冰輪。
收斂還真性，生成荷大鈞。相逢山水地，一笑武陵春。

《月桂》
李東陽
[
编辑
]

一月一花開，花開應時節。未須誇雨露，慎與藏冰雪。

《紅木樨》
瞿佑
[
编辑
]

滴露研朱染素秋，輕黃淡白總包羞。量空金粟知難
買，擊碎珊瑚惜未收。仙友自傳丹竈術，狀元須作《錦
衣遊》。一枝擬向嫦娥乞，管取花神暗點頭。

《月下看桂》
吳孔嘉
[
编辑
]

西風吹綻一林黃，玉露漙漙金粟香。蟾冷不分天上
影，兔肥應戀月中光。飄來少女明河淨，掇去仙郎秋
苑長。坐久衣裾清夜濕，小山疑種「廣寒旁。」《題桂花》
陳淳
[
编辑
]

《金粟花》開日，天香散玉墀。嫦娥解人意，折贈最高枝。

《桂花》
沈周
[
编辑
]

高攀才子沾衣綠，爭插佳人壓鬢黃。誰向蟾宮分得
種，年來人月滿庭芳。

又

丹桂迎風蓓蕾開，折來斜插竟相偎。清香不與群芳
並，仙種原從月裏來。

《木樨》
文嘉
[
编辑
]

黃金宮闕鬱嵯峨，萬斛清芬散綺羅。吳下高枝原有
種，天香莫怪屬君多。

《丹桂》
張新
[
编辑
]

金風飄處識天香，清影分明載魄光。莫向高枝輕易
折，須知紅是狀元郎。

《仙桂曲題月娥帖和蓀谷韻》
崔孤竹
[
编辑
]

碧落迢迢鸞路長，天風吹送桂花香。玉簫歸去瑤壇
上，羅襪寒生一寸霜。

===
《詠桂》
郭鯤溟
===
​
