方氏，周大夫方叔之後，以字為氏。《風俗通》云：「方，雷氏之後。」漢有方賀，唐有詩人方干，嚴州人。宋朝方姓為
著姓，閩中為多，望出河南。

方望
[
编辑

按《後漢書隗囂傳》：囂季父崔起兵應漢，以囂素有名，
推為上將軍。囂遣使聘請平陵人方望，以為軍師。望
至，說囂曰：「足下欲承天順民，輔漢而起，今立者乃在南陽，王莽尚據長安，雖欲以漢為名，其實無所受命，將何以見信於眾乎？宜急立高廟，稱臣奉祠，所謂神道設教，求助人神者也。」囂從其言。

方儕

编辑

方儲
[
编辑
]

按《尚友錄》：儲字聖公，歙人，其地在今淳安。講孟氏《易》，
精通圖讖。建初間，舉賢良方正，對策為天下第一，拜
議郎，轉洛陽令。後贈尚書令，封黟縣侯，世傳其仙去。
兄儕、弟儼，俱有學行。儲為郎中，章帝使文郎居左，武
郎居右，儲正住中，曰：「臣文武兼備，在所施用。」上嘉其
才，以亂絲付儲使理，儲拔佩刀三斷之，對曰：「反經任勢，臨事亦然。」

頗陋，又兔闕，而喜陵侮，嘗謁廉帥，誤三拜，人號「方三拜。」晚遇醫補其脣，又號為「補脣先生。」其詩多警句，門
人私諡曰「元英先生。」

方慎言
[
编辑
]

按《莆田縣志》：「慎言字應之。父延範。慎言舉咸平三年進士，知信豐、蘭溪二縣，號稱神明。祥符初，以殿中丞受詔往淄、青數郡，均給蠶賦，使還稱旨，擢屯田員外。仁宗即位，改侍御史，請便郡，知泉州，歲飢，奏免丁稅，全活者眾。歷兩浙轉運使，改知潭州，入為諫議大夫。會擇重臣鎮南越，遂以朝請大夫知廣州。卒贈開府​儀同三司。方慎從[编辑]按《萬姓統譜》：「慎從字惟之，慎言弟也。景德二年登進士甲科，授祕書省祕書郎，歷知弋陽、懷寧、同安、懷安、導江、蘭溪六縣，通判饒州、荊南府，知潮、漳、嘉三州。再知漳州，改都官郎中，以老歸卒。慎從所至，有德于民。在導江日，有楠木連理、嘉禾九穗之祥，璽書褒異。守漳日，適慎言守泉州，旌麾相望，二州人榮之。及再至」，
漳人夾道歡呼曰：「吾父復來矣。」子諫臣侍慎從官于
漳，手斷《合水孽蛟》死。漳人憐而祠之，得封清水侯。

方偕
[
编辑
]

按《宋史方偕傳》，「偕字齊古，興化莆田人。及進士第，為溫州軍事推官，遷祕書省著作佐郎，歷知福清、資陽縣，累遷尚書屯田員外郎，為御史臺推直官，知雜事。龐籍薦為御史裏行，再遷侍御史，為開封府，通判江南安撫。三司歲出乳香、綿綺下州郡配民，偕奏罷之。更鹽鐵判官，遷兵部員外郎，改度支副使，擢天章閣」待制、江淮制置發運使、知杭州，遷刑部郎中，偕以吏
事進，治杭州，有能聲。喜飲酒，至酣宴無節，數月暴中
風。以太常少卿分司西京，遷光祿卿，卒。

方僑
[
编辑
]

按《萬姓統譜》：僑字次山，莆田人。景祐初，第進士。歷知
循州。陰察不法吏數人流之，郡中肅然。移潮州，民喜
曰：「循州方君也。不教而服。」兩州皆為立祠。

方次彭
[
编辑
]

按《萬姓統譜》：「次彭字公述，興化人。皇祐初進士，出知梅州，民甚愛之。在州六年，兩被褒詔。」元祐初，賜三品
服，引老歸。從弟公袞，元豐中進士，嘗以布衣被薦，條
奏十事，神宗嘉納之。從子醇道知南劍州，以諒謹自
持，有《杜陵詩評》十卷。

方圭
[
编辑
]

按《萬姓統譜》：圭好為惡詩。仁宗朝，宋庠知揚州，圭來
謁，燕於平山堂，圭誦詩不已，適見野外有牛就木磨，

方宙
[
编辑

按《萬姓統譜》：「宙，莆田人，僑之子。熙寧中進士，召對，除司農丞。章惇、蔡確、蔡京交薦之，將處以臺閣。宙恥之，力請外補，得京西提舉常平，奏乞給還程頤舊田。范鎮子百揆在謫籍中，皆為論奏，官至轉運判官。」
方价
[
编辑
]

按《萬姓統譜》：价初名儼，慎從孫。熙寧六年進士。大觀
初，知安豐縣，用薦召赴都堂審察，蔡京以价不肯私
謁，報罷。復知候官縣。已而掛冠里居，二十餘年終。曾
孫禧為殿中侍御史。初，慎從在嘉州，手植荔枝于郡
囿，賦詩有「留取清陰待子孫」之句。至大觀中，禧持節
按蜀部，嘉州父老擁車誦慎從詩為賀。

方會
[
编辑
]

按《莆田縣志》：「會字子元，熙寧九年進士，調揚州司法參軍，以薦移建州教授，以集英殿修撰知河中府。朝廷陞十帥府，遴選守臣，以會知越州，充兩浙安撫使。繕城隍，創樓船，上水戰法。政和二年，召還入對，徽宗獎諭再四，累爵文安郡開國侯。卒贈太師。」
方澤
[
编辑

按《萬姓統譜》：澤字公悅，宋神宗朝守鄂渚，有《題南樓
晝閣》詩。山谷過之，登樓次其韻二篇，又作詩寄公悅，

方公袞
[
编辑
]

按《萬姓統譜》：公袞字汝補，次彭從弟也。元豐初，用薦
者以布衣上殿，條奏十事，曰教太子，舉實才，獎清吏，
擢恬退，禁鼓鑄，嚴荼商，恤民困，寬州縣，減丁錢，益戶
口。神宗嘉納，命以官為潮州教授，復登元豐二年進
士，擢諸王宮教授。與韓魏公相從最密，魏公語曾公
亮曰：「方公袞論事剴切，正而不阿，立己公忠，清而不撓，豈多得哉！」公袞嘗錄其言行曰《魏公遺事》。年未五
十卒。

方叔完
[
编辑
]

按《萬姓統譜》：叔完，僑之子也。宋元豐中，補知候官縣。
民以築港瀦水害懷安民田，二邑交訟，叔完往按之，
曰：「吾為令，豈私吾民耶？」乃命改築。時曾鞏以文章學
術帥郡，於人少與可，叔完獨為所信任，檄權節度推
官，且表薦之，移知祥符縣。

方蒙

按《萬姓統譜》：「蒙字逢原，桐廬人。與弟鼎俱登進士第，而蒙尢有聲元祐間為殿中侍御史，三子：元修、元若、元矩，皆有才名。元修為州判，元若為右史，元矩亦典郡。」
方軫
[
编辑
]

按《寧波府志》：「軫字克載，閩莆田人，後居鄞。登元符元年進士，授太廟齋郎。大觀元年，上書言：『蔡京睥睨社稷，心懷不軌，專以紹述熙豐之說為自謀之計。內而勢政侍從，外而帥臣監司，無非其門人親戚，又使子攸日以花木禽鳥愚陛下，使不知天下治亂。臣以為京必反也』。」上以示京，京取其疏自辯。上令御史臺進
攝，取伏辯以聞，付軫詔獄。父通，諸王府翊善，詔罷職，
敕軫貸命，追毀出身以來文字，編管嶺南，尋放歸。政
和間，復詣《登聞鼓》進狀，乞「收權獨斷，毋使國賊肆志。」上以軫長惡不悛，編管永州。後以收燕雲恩赦放歸。
靖康元年，復收敘其父，通尚在，亦敘原官。軫還鄞縣
令，貧不能歸，遂占籍於鄞。

方逢嘉
[
编辑
]

按《萬姓統譜》：逢嘉，字君會，淳安人。領漕薦，任無錫尉，
調轉船兩倉司事。凡知者累以文學政事公廉明敏
薦，俱辭不就，歸隱于馬巖山，號「巖隱。」
方聖時
[
编辑
]

按《萬姓統譜》：聖時，永嘉人。父端，以文行為歐陽公所
器重。聖時生未晬而孤，力學苦行，敝衣糲食，處之裕
如，自號愚迂翁。其友朱敏功贊之曰：「顏子之愚，仲尼之迂，既愚而迂，斯名不違。」大觀初，詔舉行義，郡以應
選，固辭不就。李季仲志其墓。

方祐
[
编辑
]

按《萬姓統譜》：祐字天貺，慎從曾孫。為人恭約好禮，嗇
己厚人，高價買產，賤價糶廩，值荒歲則傾囷無吝色。
每綸巾野服，徜徉道旁，野叟村童，歡喜出迎曰：「長者來矣。」飢食寒衣，病藥死棺，人人滿意。其孫萬，少時讀
書至己所不欲，勿施於人，祐語之曰：「此吾生平受用得力處，小子識之。」祐之存心如此，故時人以長者稱
之。年七十二卒，葬福平山，後人因以「福平長者」為號
云。

學博士。董宋臣方用事，應發與學官徐庚金等六人
伏闕言之，且曰：「宋臣不死，臣等無生不報。」補外，添差
通判建寧府，召除國子監簿。時賈似道為相，遣其幕
客諷應發為文以獻壽，不答，坐以言者罷去。起知潮
州，適潮陽盜起，應發急赴郡招撫，皆帖服聽命。知漳
州，漳賊尢猖獗，聞應發威名，皆投戈效順。德祐初，除
國子司業，累擢右文殿修撰，出為浙東提舉。景炎時，
為刑部侍郎，累陞禮部尚書，以端明殿學士充福建
招捕使，宋亡後十年卒。應發以文章進身，而排難折
衝，尢有過人者。平居孝友仁恕，恩意藹然，當事剛果
決烈，有「奇男子風。」

按《萬姓統譜》：「蒙仲名澄孫，以字行，大東子。少能文，落筆若宿構者。淳祐七年，廷對萬言，欲聚君子以續國氣脈，明公論以強國精神。又請立涪陵後，錮秦檜子孫，竄史嵩之以謝天下。」擢甲科，為邵武軍學教授，辟
淮西制置司參議官，知邵武軍。立樵川書院以廣教
養。郡最聞，增一秩。尋以祕書丞召，卒。蒙仲初年挾才
氣，既乃務為謙和，一時諸賢皆折節與之友。方大琮、
王邁、劉克莊尢愛厚之。始以文字見知賈似道。及似
道相，蒙仲獨求外補自效，終其身。

詔諸帥臣舉節行才識之士，時孟珙帥荊湖，董槐帥
湖南，皆以暹應詔。明年，特旨免文解一次，暹辭不受。
