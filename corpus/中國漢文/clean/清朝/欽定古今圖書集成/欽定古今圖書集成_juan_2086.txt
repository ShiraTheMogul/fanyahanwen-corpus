山川典第二百九十卷

西湖部藝文三
〈詩〉
[
编辑
]

游湖上　　　　　　　　　唐儲光羲
[
编辑
]

竹吹留歌扇，蓮香入舞衣。前溪多曲漵，乘興莫先歸。

《前題》
許渾
[
编辑
]

前山風雨涼，歇馬繫垂楊。何處芙蓉落，滿渠秋水香。

與從姪良遊西湖天竺寺　　　　李白
[
编辑
]

「挂席凌蓬丘，觀濤憩樟樓。三山動逸興，五馬共遨遊。」天竺森在眼，松風颯驚秋。覽雲測變化，弄水窮清幽
​
疊嶂隔遙海，當軒寫歸流。轉成傲雲月，佳趣滿吳洲。

送崔十二遊西湖天竺山　　　　前人
[
编辑
]

還聞天竺寺，夢想懷東越。每年海樹霜，桂子落秋月。
返君此地遊，已屬流芳歇。待我來歲行，相隨浮溟渤。

湖上春行　　　　　　　　　白居易
[
编辑
]

孤山寺北賈亭西，水面初平雲腳低。幾處早鶯爭暖
谷，誰家新燕啄春泥。亂花漸欲迷人眼，淺草猶能沒
馬蹄。最愛湖東行不足，綠楊陰裏白沙隄。

春題湖上　　　　　　　　　　前人
[
编辑
]

湖上春來似畫圖，亂峰圍繞水平鋪。松排山面千重
翠，月點波心一粒珠。碧毯絲頭抽早麥，青羅裙帶展
新蒲。未能拋得杭州去，一半勾留在此湖。

湖上招客送春泛舟　　　　　　前人
[
编辑
]

欲送殘春招酒伴，客中誰最解風情。兩瓶箬下新求
得，一曲《霓裳》初教成。排比管絃行翠袖，指麾船舫點
紅旌。漫牽好向湖心去，恰似菱花鏡裏行。

湖上夜飲　　　　　　　　　　前人
[
编辑
]

郭外迎人月，湖邊醒酒風。誰留使君飲，紅燭在舟中。

留別西湖　　　　　　　　　　前人
[
编辑
]

征途行色慘風煙，祖帳離聲咽管絃。翠黛不須留五
馬，皇恩只許住三年。綠藤陰下鋪歌席，紅藕香中泊
妓船。處處回頭盡堪戀，就中難別是湖邊。

西湖寄元微之　　　　　　　　前人
[
编辑
]

「上馬復呼賓，湖邊景氣新。管絃三數事，騎從十餘人。立換登山屐，行攜漉酒巾。逢花當看妓，遇草坐為茵。西日籠黃柳，東風蕩白蘋。小橋裝雁齒，輕浪甃魚鱗。畫舫牽徐轉，銀船酌慢巡。野情遺世累，醉態任天真。彼此年將老，平生分最親。高天從所欲，遠地得為鄰。雲樹分三驛，煙波限一津。翻嗟寸步隔，卻厭尺書頻。」浙地稱雄鎮，山陰委重臣。貴垂長紫綬，榮駕大朱輪。
出動鎗刀隊，歸生道路塵。雁驚弓易散，鷗怕鼓難馴。
百吏瞻相面，千夫奉擁身。自然佳興少，應負鏡湖春。

湖上夜歸　　　　　　　　　　前人
[
编辑
]

半醉閒行湖岸東，馬鞭敲鐙轡玲瓏。萬株松樹青山
上，十里沙堤明月中。樓角漸移當路影，潮頭欲過滿
江風。歸來未放笙歌散，畫戟重開蠟炬紅。

西湖晚歸回望孤山寺贈客　　　前人
[
编辑
]

柳湖松島蓮花寺，晚動歸橈出道場。盧橘子低山雨
重，棕櫚葉戰水風涼。煙波淡蕩搖空碧，樓閣參差倚
夕陽。到岸請君回首望，蓬萊宮在水中央。

孤山寺遇雨　　　　　　　　　前人
[
编辑
]

拂波雲色重，灑葉雨聲繁。水鷺雙飛起，風荷一向翻。
空濛連北岸，蕭颯入東軒。或擬湖中宿，留船在寺門。

湖亭晚歸　　　　　　　　　　前人
[
编辑
]

盡日湖亭臥，心閒事亦稀。起因殘醉醒，坐待晚涼歸。
松雨飄藤帽，江風透葛衣。柳隄行不厭，沙軟絮霏霏。

斷橋　　　　　　　　　　　　前人
[
编辑
]

望海樓明照曙霞，護江隄白蹋晴沙。濤聲夜入伍員
廟，柳色春藏蘇小家。紅袖織綾誇柿蔕，青旗沽酒趁
梨花。「誰開湖寺西南路，草綠裙腰一道斜。」
留題天竺靈隱兩寺　　　　　　前人
[
编辑
]

「在郡六百日，入山十二回。」宿因月桂落，醉為海榴開。
黃紙除書到，青宮詔命催。僧徒多悵望，賓從亦徘徊。
寺暗煙埋竹，林香雨落梅。別橋憐白石，辭洞戀青苔。
漸出松間路，獨飛馬上杯。誰教冷泉水，送我下山來。

玉泉講寺　　　　　　　　　　前人
[
编辑
]

「湛湛玉泉色，悠悠浮雲身。閒心對定水。清淨兩無塵。」手把青筇杖，頭帶白綸巾。興盡下山去，知我是何人。

浣雲池　　　　　　　　　　　前人
[
编辑
]

白雲本無心，舒卷長自潔。影落一艦空，可浣不可涅。
鳶飛魚躍間，上下俱澄澈。此意難與言，覽之自怡悅。

韜光庵有韜光禪師以詩招之　　前人
[
编辑
]

白屋炊香飯。葷羶不入家。濾泉澄葛粉。洗手摘藤花。
青芥除黃葉。紅薑帶紫芽。命師相伴食。齋罷一甌茶。

報樂天　　　　　　　　　　僧韜光
[
编辑
]

「山僧野性好林泉，每向巖阿倚石眠。不解栽松陪《玉勒》，惟能引水種金蓮。」白雲乍可來青嶂，明月難教下
碧天。城市不能飛錫去，恐妨鶯囀翠樓前。

題西湖雲林禪寺　　　　　　　張祜
[
编辑
]

「峰巒開一掌，朱檻幾環延。佛地花分界，僧房竹引泉。五更樓下月，十里郭中煙。」「後塔聳亭後，前山橫閣前。溪沙涵水靜，澗石點苔鮮。好是呼猿久，西巖深響連。」
孤山　　　　　　　　　　　　前人
[
编辑
]

樓臺聳碧岑，一徑入湖心。不雨山常潤，無雲水自陰。
斷橋荒蘚合，空院落花深。猶憶西窗月，鐘聲出北林。

下天竺講寺　　　　　　　　　前人
[
编辑
]

西南山最勝，一界是諸天。上路分巖竹，分流入寺前。
躡雲丹井畔，望月石橋邊。洞壑江聲遠，樓臺海氣連。
塔明春嶺雪，鐘散暮松煙。何處去猶恨，更看峰頂蓮。

勝果禪寺　　　　　　　　宋王安石
[
编辑
]

登高見山水，身在水中央。下視樓臺處，空多樹木蒼
​
浮雲連海氣，落日動湖光。偶坐吹橫笛，殘聲入富陽。

望湖樓　　　　　　　　　　　前人
[
编辑
]

水光山色碧浮浮，落日將歸又少留。從此祇應長入
夢，夢中還與故人遊。

僊姥墩　　　　　　　　　　　前人
[
编辑
]

綠漪堂前湖水綠，歸來正復有荷花。花前若見餘杭
姥，為道仙人憶酒家。

昭慶寺　　　　　　　　　　陳堯佐
[
编辑
]

湖邊山影裏，靜景與僧分。一榻坐臨水，片心閒對雲。
樹寒時落葉，鷗散自成群。莫問紅塵事，林間肯暫聞。

西湖春日　　　　　　　　　王安國
[
编辑
]

「爭得才如杜牧之，試來湖上輒題詩。」春煙寺院敲茶
鼓，夕照樓臺卓酒旗。濃吐雜芳薰巘崿，濕飛雙翠破
漣漪。人間幸有蓑兼笠，且上漁舟作釣師。

初夏西湖　　　　　　　　　歐陽修
[
编辑
]

積雨新晴漲碧溪，偶尋行處獨依依。綠陰黃鳥春歸
後，江蘤青苔人跡稀。萍匝汀洲魚自躍，日長欄檻燕
交飛。林僧不用相迎送，吾欲臺頭坐釣磯。

西湖戲作示同遊者　　　　　　前人
[
编辑
]

菡萏香清畫舸浮，使君寧復憶揚州。都將二十四橋
月，換得西湖十頃秋。

憶西湖舊遊　　　　　　　　　文同
[
编辑
]

西湖晴碧晚溶溶，與客常來坐好風。記得有人歌《小
玉》，月明猶在畫船中。

西湖　　　　　　　　　　　　蘇頌
[
编辑
]

三潭印月

纖雲掃跡浪花收，塔影亭亭引碧流。半夜冰輪初出
海，一湖金水欲溶秋。龍宮獻璧神光吐，鮫室遺珠瑞
氣浮。浪說影娥池上景，不知此地有僊舟。

麴院荷風

翠圍紅繞戰縱橫，似看吳宮習女兵。飛雪翻空雲影
亂，游魚吹浪水紋生。錦裳零落香猶在，銅柱攲斜露
半傾。兩腋新涼驚酒醒，畫船吹送按歌聲。

平湖秋月

曾向湖隄夜叩舷，愛看波影弄嬋娟。一塵不動天連
水，萬籟無聲客在船。赤壁未醒元鶴夢，驪宮偏惱老
龍眠。朗吟玉塔微瀾句，長笑凌空氣浩然。

南屏晚鐘

柳昏花暝暮雲生，隱隱初傳一兩聲。禪榻屢驚僧人
定，旅窗偏惱客含情。月隨逸韻入鰲嶺，風遞遺音過
鳳城。催散遊人罷歌舞，玉壺銀箭夜初更。

雷峰夕照

宜雨宜晴晚更宜，西湖端可比西施。霞穿樓閣紅光
繞，雲捲笙歌逸韻隨。山紫翠中樵唱遠，樹蒼黃外馬
歸遲。何人解畫《瀟湘景》，併與《漁村》作二奇。

斷橋殘雪

醉裏曾登白玉梯，東風吹暖又成泥。玉腰螮蝀垂天
闊，銀色樓臺夾岸迷。九井晴添新水活，兩峰濃壓宿
雲低。衝寒為問「梅花信，十里銀沙印馬蹄。」
