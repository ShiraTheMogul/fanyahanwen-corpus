易水歌　　　　　　　　　　周荊軻
[
编辑
]

「風蕭蕭兮易水寒」，壯士一去兮不復還。

荊軻　　　　　　　　　　　晉陶潛
[
编辑
]

燕丹善養士，志在報強嬴。招集百夫良，歲暮得荊卿。
君子死知己，提劎出燕京。素驥鳴廣陌，慷慨送我行。
雄髮指危冠，猛氣衝長纓。飲餞易水上，四座列群英。

漸離擊悲筑，宋意唱高聲。蕭蕭哀風起，淡淡寒波生
​
商音更流涕，羽奏壯士驚。心知去不歸，且有後世名。

登車何時顧，飛蓋入秦庭。凌厲越萬里，逶迤過千城。
圖窮事自見，豪主正怔營。惜哉劍術疏，奇功遂不成。
其人雖已沒，千載有餘情。

易水行　　　　　　　　　　陳楊縉
[
编辑
]

函關使不通，燕將重深功。長虹貫白日，易水急寒風。
壯髮危冠下，匕首地圖中。瑟聲不可識，遺恨沒秦宮。

宴中山　　　　　　　　　　唐太宗
[
编辑
]

驅馬出遼陽，萬里轉旂常。對敵六奇舉，臨戰八陣張。
斬鯨澄碧海，捲霧掃扶桑。昔去蘭縈翠，今來桂染芳。
雲枝浮碎葉，冰鏡上朝光。回首長安道，方歡宴《柏梁》。

奉和宴中山應制　　　　　　許敬宗
[
编辑
]

飛雲旋碧海，解網宥青丘。養更停八駿，觀風駐五牛。
張樂臨堯野，揚麾歷舜州。《中山》獻仙酤，趙媛發清謳。
塞門朱鴈入，郊藪紫麟遊。一舉氛霓靜，千齡德化流。

易水弔古　　　　　　　　　駱賓王
[
编辑
]

此地別燕丹，壯士髮沖冠。昔時人已沒，今日水猶寒。

燕昭王　　　　　　　　　　陳子昂
[
编辑
]

南登碣石館，遙望黃金臺。丘陵盡喬木，昭王安在哉。
霸圖悵已矣，驅馬復歸來。

燕太子　　　　　　　　　　　前人
[
编辑
]

秦王日無道，太子怨亦深。一聞田光義，匕首贈千金。
其事雖不立，千載為傷心。

郭隗　　　　　　　　　　　　前人
[
编辑
]

逢時獨為貴，歷代豈無才。隗君亦何幸，遂起黃金臺。

田光　　　　　　　　　　　　前人
[
编辑
]

自古皆有死，徇義良獨稀。奈何燕太子，尚作田光疑。
伏劎誠已矣，感我涕沾衣。

古風　　　　　　　　　　　　李白
[
编辑
]

燕昭延郭隗，遂築黃金臺。劇辛方趙至，鄒衍復齊來。
奈何青雲士，棄我如塵埃。珠玉買歌笑，糟糠養賢才。
方知「《黃鶴》舉」，千里獨徘徊。

高漸離　　　　　　　　　　　前人
[
编辑
]

「燕南壯士吳門豪。」筑中置鉛魚隱刀。感君恩重許君
命。泰山一擲輕鴻毛。

安州道中經滻水有懷　　　　劉長卿
[
编辑
]

征途逢《滻水》，忽似到秦川。借問朝天處，猶看落日邊。
映沙晴漾漾，出澗夜濺濺。欲寄西歸恨，微波不可傳。

易水詩　　　　　　　　　　　賈島
[
编辑
]

荊軻重虛死，烈節書前史。我嘆方寸心，誰論一時事。
至今《易水橋》，涼風兮蕭蕭。易水流得盡，荊卿名不泯。

荊軻　　　　　　　　　　　柳宗元
[
编辑
]

燕秦不兩立，太子已為虞。千金奉短計，匕首荊卿趨。
窮年徇所欲，兵勢且見屠。微言激幽憤，怒目辭燕都。
朔風動易水，揮爵前長驅。函首致宿怨，獻田開版圖。
炯然耀電光，掌握同征夫。造端何其銳，臨事竟沬趄。
長虹吐白日，倉卒反受誅。按劍赫憑怒，風雷助號呼。
慈父斷子首，狂走無容軀。彝域芟七族，臺觀皆焚汙。
始期憂患弭，卒動災禍樞。秦皇本詐力，事與桓公殊。
奈何效曹子，實謂勇且愚。世傳故多謬，太史徵無且。

易水有懷　　　　　　　　　　胡曾
[
编辑
]

一旦秦皇馬角生。燕丹從此送荊卿。行人欲識無窮
恨，聽取東流「《易》水聲。」
樂毅　　　　　　　　　　　宋邵雍
[
编辑
]

樂毅事燕時，其心有深旨。破齊七十城，迎刃不遺矢。
豈留「即墨莒，郤與燕有二。欲使燕遂王，天下自齊始。豈意志未伸，昭王一旦死。惠王固不知，使人代其位。強燕自此衰，何復能振起。」自古君與臣，濟會非容易。
重惜千萬年，英雄為流涕。

雪中望馬耳　　　　　　　　　蘇軾
[
编辑
]

黃昏猶作雨纎纎，夜靜無風勢轉嚴。但覺衾裯如潑
水，不知庭院已堆鹽。五更曉色來書幌，半夜寒聲落
畫檐。試掃北臺看馬耳，未隨埋沒有雙尖。

城頭初日始翻鴉，陌上晴泥已沒車。凍合玉樓寒起
粟，光搖銀海昡生花。遺蝗入地應千尺，宿麥連雲有
幾家。老病自嗟詩力退，空吟冰柱憶《劉義》。

高陽詩　　　　　　　　　　　曾布
[
编辑
]

「公事無多使客稀，雨時衙退吏人歸。沉煙一炷春陰重，畫角三聲晚照微。」桑雉未馴慚報政，海鷗相近信
忘機。只將宴坐收心念，懶向人間問是非。

南北車書久混同。河間今有楚人風。獨慚太守非何
武。已見州閭出兩龔。

《前題》
劉伯琛
[
编辑
]

棠花開遍野桃紅，榆柳中間一逕通。禽鳥不呼花鴃
盡，淄川煙雨淡濛濛。

白溝河　　　　　　　　　　文天祥
[
编辑
]

《寶符》藏山自可攻，兒孫誰是出群雄。幽燕不照中天
月，《豐沛》空歌「海內風。」趙普原無四方志，《澶淵》堪笑百
年功。《白溝》移向江淮去，止罪宣和恐未公。

過白溝河　　　　　　　　　　前人
[
编辑
]

昔時張叔夜，統兵赴勤王。東都一不守，羸馬遷龍荒
​
適過白溝河，裂眥鬚欲張。絕粒遄不死，仰天扼其吭。
群臣總奄奄，一士垂天光。讀《史》識其地，撫卷為凄涼。
我生何不辰，異世忽相望。皇圖遘陽九，天塹漏飛艎。
引軍至闕下，捧土障瀾狂。出使義不屈，持節還中郎。
六飛狩南海，金鉞將煌煌。武侯空盛心，出師驚四方。
吾屬竟為虜，世事吁彼蒼。思公有奇節，一死何慨慷。
江淮我分地，我欲投滄浪。滄浪卻不受，中原行路長。
初登項籍宮，次覽劉季鄉。涉足河與濟，回首嵩與邙。
下車撫梁門，上馬指樓桑。戴星渡一水，慘淡天微茫。
行人為我言，宋遼此分疆。懸知公死處，為公出涕滂。
恨不持束芻，徘徊官道旁。我死還在「燕，烈烈同肝腸。今我為君哀，後來誰我傷。天地垂日月，斯人未云亡。文武道不墜，我輩終堂堂。」
遂州道中　　　　　　　　　　前人
[
编辑
]

「昨日渡滹河，今日望太行。白雲何渺渺，天地何茫茫。落葉混西風，黃塵昏夕陽。牛車過不住，氈屋行相望。小兒騎蹇驢，壯士駕乘黃。高低菜萬頃，黑白草千行。村落有古風，人間無時妝。宋、遼舊分界，燕趙古戰場。蚩尤亂涿野，共工謫幽方。郭隗致樂毅，荊軻攜舞陽。臧盧互反覆，安史迭披狂。山川一今古，人物幾興亡。」江南佔。
生，往來習羊腸。天馬戴青蠅，電秣馳康莊。
適從何所來，如此醉夢鄉。感時意躊躇，惜往淚淋浪。
厲階起玉環，左計由石郎。天地行日月，萬代乘景光。
晝夜果可廢，《春秋》誠荒唐。吾生直須臾，俯仰際八荒。

登武遂城　　　　　　　　　　前人
[
编辑
]

神州英氣鬱高寒，臂斷爭教不再連。千古傷心有開
運，幾人臨死問《幽燕》。平生臥榻今如此，百萬私錢亦
可憐。咫尺白溝巳南北，區區銅馬為誰堅？

渡滹沱河　　　　　　　　　　前人
[
编辑
]

過了長江與大河，橫流數仞絕滹沱。蕭王麥飯曾倉
卒，回首中天感慨多。

風沙睢水終亡楚，草木公山竟蹙秦。始信滹沱冰合
事，世間興廢不由人。

雁足帛書　　　　　　　　　元郝經
[
编辑
]

零落風高恣所如，歸期回首是春初。《上林》天子援弓
繳，窮海孤臣有帛書。

過白溝　　　　　　　　　　　前人
[
编辑
]

易水南邊是白溝，北人為界海東頭。石郎作帝從珂
敗，便割燕雲十六州。

白溝　　　　　　　　　　　　劉因
[
编辑
]

薊門霜落水天愁，匹馬衝寒渡白溝。燕趙山河分上
鎮，遼金風物異中州。

天風臺　　　　　　　　　　　前人
[
编辑
]

昔年曾到葛洪遊，回首西風二十秋。今日唐川再經
過，野心又被白雲留。

渡滹沱河　　　　　　　　　　前人
[
编辑
]

遙臨滹水岸，回首土門關。秋色巉巖上，川形拱抱間。
分疆人自隘，設險地誰慳。欲問前朝渡，江鷗故意閒。

呈保定諸公　　　　　　　　　前人
[
编辑
]

「燕垂趙際間，人物熒珪璋。諸侯舊賓客，一郡宗賢良。士窮叫知己，人渴思蒙漿。諸公且勿嗔，賤子伸餘狂。因幼有大志，早遊翰墨場。八齡書草字，觀者如堵牆。九齡與太元，十二能文章。遨遊墳索圃，期登顏孔堂。遠攀鮑謝駕，徑入曹劉鄉。斯文元李徒，我當拜其旁。呼我劉昌谷，許我參翱翔。眼高四海士，兒子空奔忙。」俗物付脫略，壯節持堅剛。前年脫穎士，峨峨勢方颺。
欲求伸汨沒，今反墮渺茫。少小嬰憂患，痛切摧肝腸。
零丁漢孤苦，片影弔愴惶。溺身朱墨窟，人事如冰霜。
高才日陵替，壯志時悲傷。駑駘欺赤驥，䲭梟笑鳳皇。
妾婦妬逸才，浪嘴讒舌長。紛然生謗議，鋒豈不可當。
不忍六尺軀，縮項俄深藏。諸公富高義，刮垢摩我光。
去留從所適，爽氣生西廊。

過徐河橋　　　　　　　　　　前人
[
编辑
]

老岸石欄曙色分，只疑身是入山雲。十年往事不迴
顧，百里清泉如可聞。人世誰教有長路，坤靈終亦化
塵氛。興亡更遣陂塘在，幾欲悲歌酒未醺。

遂城道中　　　　　　　　　　前人
[
编辑
]

鐵城秋色入西垣，遠客還鄉易斷魂。霸業可憐燕太
子，戰樓誰弔漢公孫。冷煙衰草千秋塚，流水斜陽一
點村。慰眼西風猶有物，太行依舊壓中原。

望堯山　　　　　　　　　　　前人
[
编辑
]

神化大無外。名山能幾峰。威顏渾咫尺。天日尚雍容。
蒲坂堪饑死。重華有舊蹤。三謨讀未忘。欲此卜巢松。

舜帝廟　　　　　　　　　　　前人
[
编辑
]

四顧莽何際，威靈儼若臨。山川尚淳樸，天地自高深。
鳳鳥千年嘆，《簫韶》三月音。元功久無復，徒抱致君心。

易水懷古　　　　　　　　　　前人
[
编辑
]

《薊門》來悲風，易水生寒波。雲物何改色，游子唱《離歌》。
《燕歌》在何處？盤鬱西山阿。武陽燕下都，歲晚獨經過。
青丘遙相連，風雨墮峨峨。七十齊郡邑，百二秦山河。
學術有管樂，道義無丘軻。蚩蚩魚肉民，誰與休干戈
​
往事已如此，後來復如何。割地更石郎，曲中哀思多。

易水詩　　　　　　　　　　楊維楨
[
编辑
]

風蕭蕭易水波，高冠送客白峨峨。馬嘶燕都夜生角，
壯士悲歌力拔削。百金買匕尺八銛，函中目光射匕
尖。先生老悖不足與，灰面小兒年十三。事大謬，無足
取，先機一發中銅柱。後客不來知奈何，狗屠之交誰
比數。太傅言議謀中奇，奇謀拙速寧工遲。可憐矐目
舊時客，擊筑又死高漸離。鎬池君璧在水龍腥，忽逐
