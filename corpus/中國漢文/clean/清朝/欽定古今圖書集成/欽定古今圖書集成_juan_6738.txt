〈詩詞〉

元夕于通衢建燈夜升南樓　　隋煬帝
[
编辑
]

法輪天上轉，梵聲天上來。燈樹千光照，花燄七枝開。
月影疑流水，春風含夜梅。旛動黃金地，鐘發琉璃臺。

軒遊宮十五夜　　　　　　　唐元宗
[
编辑
]

行邁離秦國，巡方赴洛師。路逢三五夜，春色暗中期。
關外長河轉，宮中淑氣遲。歌鐘對明月，不減舊遊時。

===十五夜觀燈　　　　　　　　盧照鄰===
​
錦里開芳宴，蘭缸艷早年。縟綵遙分地，繁光遠綴天。
接漢疑星落，依樓似月懸。別有千金笑，來映九枝前。

上元夜六首　　　　　　　　　崔液
[
编辑
]

玉漏銅壺且莫催，鐵關金鎖徹明開。誰家見月能閑
坐，何處聞燈不看來。

神燈佛火百輪張，刻像圖形七寶裝。影裏如開金口
說，空中似放玉毫光。

今年春色勝常年，此夜風光最可憐。鳷鵲樓前新月
滿，鳳凰臺上寶燈然。

金勒銀鞍控紫驑，玉輪珠幰架青牛。驂驔始散《東城
曲》，倏忽還來南陌頭。

公子王孫意氣驕，不論相識也相邀。最憐長袖風前
弱，更賞新絃暗裏調。

星移漢轉月將微，露灑煙飄燈漸稀。猶惜路傍歌舞
處，踟躕相顧不能歸。

正月十五夜　　　　　　　　蘇味道
[
编辑
]

《唐新語》云：「神龍之際，京城正月望日，盛飾燈火之會，金吾弛禁，貴遊戚屬及下里工賈，無不夜遊，車馬駢闐，人不得顧王主之家，馬上作樂，以相誇競。文士皆賦詩以紀其事。作者數百人，唯味道與郭利貞、崔液三人為絕唱。」
火樹銀花合，星橋鐵鎖開。暗塵隨馬去，明月逐人來。
遊妓皆穠李，行歌盡《落梅》。金吾不禁夜，玉漏莫相催。

上元夜效小庾體同用春字　長孫正隱
[
编辑
]

薄晚嘯遊人，車馬亂驅塵。月光三五夜，燈燄一重春。
煙雲迷北闕，簫管識南鄰。洛城終不閉，更出《小平津》。

===上元夜效小庾體同用春字
〈{{{1}}}〉

今夜啟城闉，結伴戲芳春。鼓聲撩亂動，風光觸處新。
月下多遊騎，燈前饒看人。歡樂無窮已，歌舞達明晨。

上元夜效小庾體同用春字　　韓仲宣
[
编辑
]

他鄉月夜人，相伴看燈輪。光隨九華出，影共百枝新。
歌鐘盛北里，車馬沸南鄰。今宵何處好，唯有《洛陽春》。

上元夜效小庾體同用春字　　陳嘉言
[
编辑
]

今夜可憐春，河橋多麗人。寶馬金為絡，香車玉作輪。
連手窺潘掾，分頭看洛神。重城自不掩，出向小平津。

十五日夜御前口號踏歌詞
〈二首〉
張說
[
编辑
]

花萼樓前雨露新，長安城裏太平人。龍御火樹千重
艷，雞踏蓮花萬歲春。

帝宮三五戲春臺，行雨流風莫妬來。西域燈輪千影
合，東華金闕萬重開。

夜遊　　　　　　　　　　　沈佺期
[
编辑
]

今夕重門啟，遊春得夜芳。月華連晝色，燈影雜星光。
南陌青絲騎，東鄰紅粉妝。管絃遙辨曲，羅綺暗聞香。
人擁行歌路，車攢𩰚舞場。經過猶未已，鐘鼓出長楊。

上元　　　　　　　　　　　郭利貞
[
编辑
]

九陌連燈影，千門遍月華。傾城出寶騎，匝路轉香車。
爛漫惟愁曉，周遊不問家。更逢清管發，處處落梅花。

正月十五日夜應制　　　　　　孫逖
[
编辑
]

洛城三五夜，天子萬年春。綵仗移雙闕，瓊筵會九賓。
舞成《蒼頡》字，燈作法王輪。不覺東方日，遙垂御藻新。

奉和聖製十五夜然燈繼以酺宴應制
[
编辑
]

王維

「上路笙歌滿，春城刻漏長。遊人多晝日，明月讓燈光。」魚鑰通翔鳳，龍輿出建章。九衢陳廣樂，百福透名香。
仙妓來金殿，都人遶玉堂。定應偷妙舞，從此學新妝。
奉引迎三事，司儀列萬方。願將天地壽，同以獻君王。

十五夜觀燈　　　　　　　　　王諲
[
编辑
]

暫得金吾夜，通看火樹春。停車傍明月，走馬入紅塵。
妓雜歌偏勝，場移舞更新。應須盡記取，說向未來人。

上元日紫極宮門觀州民然燈張樂
[
编辑
]

羊士諤

山郭通衢隘。瑤壇紫府深。燈花助春意。舞綬識歡心。
閒似淮陽臥。恭聞《樂職》吟。唯將聖明化。聊以達飛沈。

正月十五夜月　　　　　　　白居易
[
编辑
]

歲熟人心樂，朝遊復夜遊。春風來海上，明月在江頭。
燈火家家市，笙歌處處樓。無妨思帝里，不合厭《杭州》。

正月十五日　　　　　　　　熊孺登
[
编辑
]

漢家遺事今宵見，楚郭明燈幾處張。深夜行歌聲絕
後，紫姑神下月蒼蒼。

上元唱和　　　　　　　　　溫庭皓
[
编辑
]

「九枝應並耀，五夜思悠然。」景集青山外，螢分碧草前。
輝華侵月影，歷亂寫星躔。望極高樓上，搖光滿綺筵。
