何敬容
[
编辑
]

按《梁書何敬容傳》，「敬容字國禮，廬江人也。父昌㝢，敬容以名家子，弱冠選尚齊武帝女長城公主，拜駙馬都尉。天監初，為祕書郎，歷太子舍人、尚書殿中郎、太子洗馬、中書舍人、祕書丞，遷揚州治中，出為建安內史。清公有美績，民吏稱之。還除黃門郎，累遷太子中庶子、散騎常侍、侍中、司徒左長史。普通二年，復為侍」中，領羽林監，俄領本州大中正，守吏部尚書，銓序明
審，號為稱職。四年，除為招遠將軍、吳郡太守，為政勤
恤民隱，辨訟如神。視事四年，治為天下第一。大通二
年，徵為中書令，未拜，復為吏部尚書，領右軍將軍，俄
加侍中。中大通元年，改太子中庶子。三年，遷尚書右
僕射，參掌選事。五年，遷左僕射，加宣惠將軍。大同三
年，遷中權將軍、丹陽尹。五年，入為尚書令。十一年，坐
妾弟費慧明為𣜦倉丞，夜盜官米，為禁司所執，送領
​
軍府。時河東王譽為領軍將軍，敬容以書解慧明，譽
即封書以奏，高祖大怒，詔免職。中大同元年，起為金
紫光祿大夫，未拜，又加侍中。太清元年，遷太子詹事。
二年，侯景襲京師，敬容自府移家臺內。三年正月，敬
容卒於圍內。詔贈仁威將軍。子玨，祕書丞，早卒。

何點
[
编辑
]

按《梁書何點傳》：「點字子晳，廬江灊人也。父鑠，素有風疾，無故害妻，坐法死。點年十一，幾至滅性。及長，感家禍，絕婚宦。容貌方雅，博通群書，善談論。遨遊人世，不簪不帶，或駕柴車，躡草屩，恣心所適，致醉而歸，時人號為通隱。泰始末，徵太子洗馬。齊初，屢徵中書郎、太子中庶子，並不就。性通脫，好施與，遠近致遺，一無所」逆，隨復散焉。高祖與點有舊，及踐阼，手詔賜鹿皮巾
等，點以巾褐引入華林園，高祖甚悅，賦詩置酒，恩禮
如舊。徵為侍中，辭疾不赴。天監三年卒，時年六十八。
點無子，宗入以其從弟耿子遲任為嗣。

何引
[
编辑
]

按《梁書何點傳》：「引字子季，點之弟也。年八歲，居憂，哀毀若成人。既長，好學，而縱情誕節，時人未之知也。起家齊祕書郎，遷太子舍人，出為建安太守，為政有恩信，民不忍欺。遷司徒主簿，累遷中書郎、員外散騎常侍、太尉從事中郎、司徒右長史、給事黃門侍郎、太子中庶子，領國子博士、丹陽邑中正。永明十年，領侍中」，
領步兵校尉，轉為國子祭酒。鬱林嗣位，引為后族，甚
見親待，遷左民尚書，領驍騎中書令，領臨海巴陵王
師。引雖貴顯，常懷止足。建武初，已築室郊外，號曰「小山」，至是遂賣園宅，欲入東山。未及發，聞謝朏罷吳興
郡不還，恐後之，乃拜表辭職，不待報輒去。世號點為
「大山」，引為「小山」，亦曰「東山。」永元中，徵太常、太子詹事，
並不就。高祖踐阼，詔為特進、右光祿大夫，遣領軍司
馬王果宣旨諭意，引不行。中大通三年卒，年八十六。
子撰，廬陵王辟為主簿，不就。

何炯
[
编辑
]

按《梁書何炯傳》：「炯字士光，廬江灊人也。父撙，太中大夫。炯年十五，從兄引受業一期，並通《五經》章句。炯白晳，美容貌，從兄求點每稱之曰：『叔寶神清，弘治膚清。今觀此子，復見衛、杜在目。年十九，解褐揚州主簿，舉秀才，累遷王府行參軍，尚書兵、庫部二曹郎。出為永康令，以和理稱。還為仁威南康王限內記室，遷治書』」侍御史。以父疾經旬，衣不解帶，頭不櫛沐，信宿之間，
形貌頓改。及父卒，號慟不絕聲，枕凷籍地，腰虛腳腫，
竟以毀卒。

何佟之
[
编辑
]

按《梁書何佟之傳》，「佟之字士威，廬江灊人，豫州刺史惲六世孫也。祖劭之，宋員外散騎常侍。父歆，齊奉朝請。佟之少好《三禮》，師心獨學，彊力專精，手不輟卷。起家揚州從事，仍為總明館學士，頻遷司徒車騎參軍事、尚書祠部郎。齊建武中，為鎮北記室參軍，侍皇太子講，領丹陽邑中正，歷步兵校尉、國子博士。尋遷驃」騎諮議參軍，轉司馬。中興初，拜驍騎將軍。高祖踐阼，
尊重儒術，以佟之為尚書左丞。是時百度草創，佟之
依禮定議，多所裨益。天監二年卒官，年五十五，特詔
贈黃門侍郎。所著《文章禮義》百許篇。子朝隱、朝晦。

何遜
[
编辑
]

按《梁書何遜傳》：「遜字仲言，東海郯人也。曾祖承天，宋御史中丞。祖翼，員外郎。父詢，齊太尉中兵參軍。遜八歲能賦詩，弱冠，州舉秀才。天監中，起家奉朝請，遷中衛建安王水曹行參軍，兼記室。王愛文學之士，日與遊宴。及遷江州，遜猶掌書記。還為安西安成王參軍事，兼尚書水部郎。母憂去職。服闋，除仁威廬陵王記」室。復隨府江州。未幾卒。

何思澄
[
编辑
]

按《梁書何思澄傳》：「思澄字元靜，東海郯人。父敬叔，齊征東錄事參軍，餘杭令。思澄少勤學，工文辭，起家為南康王侍郎，累遷為安成王左常侍，兼太學博士，平南安成王行參軍，兼記室，除廷尉正。天監十五年，敕太子詹事徐勉舉學士入華林，撰《遍略》，勉舉思澄等五人以應選，遷治書侍御史。久之，遷秣陵令，入兼東宮通事舍人，除安西湘東王錄事參軍。昭明太子薨，出為黟縣令，遷除宣惠武陵王中錄事參軍」，卒官，時
年五十四。《文集》十五卷。

何子朗
[
编辑
]

按《梁書何思澄傳》：「思澄宗人子朗，字世明，早有才思，工清言。周捨每與共談，服其精理。嘗為《敗冢賦》，擬莊周《馬捶》，其文甚工。世人語曰：『人中爽爽何子朗。歷官員外散騎侍郎，出為固山令，卒時年二十四。文集行於世』。」何遠
[
编辑
]

按《梁書何遠傳》，「遠字義方，東海郯人也。父慧炬，齊尚書郎。遠釋褐江夏王國侍郎，轉奉朝請。永元中，江夏王寶元於京口為護軍將軍崔慧景所奉，入圍宮城​遠豫其事。事敗，遠因降魏，入壽陽，見刺史王肅，求迎高祖。肅許之，遣兵援送，得達高祖。高祖板輔國將軍，隨軍東下。既破朱雀軍，以為建康令。高祖踐阼，為步」兵校尉。以奉迎勳，封廣興男。遷建武將軍後軍鄱陽
王恢錄事參軍。頃之，遷武昌太守，杜絕交遊，饋遺秋
毫無所受。然性剛毅，吏民多以細事受鞭罰者，遂為
人所訟。徵下廷尉，以私藏禁仗除名。後起為鎮南將
軍、武康令，愈厲廉節。高祖聞其能，擢為宣城太守，遷
樹功將軍、始興內史。天監十六年，詔陞給事黃門侍
郎。遠即還，仍為仁威長史。頃之，出為信武將軍，監吳
郡。在吳頗有酒失，遷東陽太守。遠處職疾彊，富如仇
讎，視貧細如子弟，豪右畏憚，復為受罰者所謗，坐免
歸。後復起為征西諮議參軍，中撫司馬。普通二年，卒，
時年五十二。

何之元
[
编辑
]

按《陳書何之元傳》：「之元，廬江灊人也。祖僧達，齊南臺治書侍御史。父法勝，以行業聞。之元幼好學，有才思，居喪過禮，為梁司空袁昂所重。天監末，昂表薦之，因得召見。解褐梁太尉臨川王揚州議曹從事史，尋轉主簿。及昂為丹陽尹，辟為丹陽五官掾，總戶曹事。尋除信義令。安西武陵王為益州刺史，以之元為安西」刑獄參軍。侯景之亂，武陵王以太尉承制授南梁州
長史、北巴西太守。武陵王自成都舉兵東下，之元與
蜀中民庶抗表請無行，王以為沮眾，囚之元於艦中。
及武陵兵敗，之元從邵陵太守劉恭之郡。俄而江陵
陷，劉恭卒，王琳召為記室參軍。梁敬帝冊琳為司空，
之元除司空府諮議參軍，領記室。王琳之立蕭莊也，
署為中書侍郎。會齊文宣帝薨，令之元赴弔。還至壽
春，而王琳敗，齊主以為揚州別駕。及眾軍北伐，得淮
南地，湘州刺史始興王叔陵遣功曹史柳咸齎書召
之元除中衛府功曹參軍事，尋遷諮議參軍。及叔陵
誅，之元乃屏絕人事，銳精著述。禎明三年，京城陷，乃
移居常州之晉陵縣。隋開皇十三年，卒於家。

何妥
[
编辑
]

按《隋書何妥傳》：「妥字栖鳳，西城人也。父細胡，通商入蜀，遂家郫縣。事梁武陵王紀，主知金帛，因致巨富，號為西州大賈。妥少機警，八歲遊國子學，助教顧良戲之曰：『汝既姓何，是荷葉之荷，為是河水之河』？應聲答曰：『先生姓顧，是眷顧之顧，是新故之故』。眾咸異之。十七，以技巧事湘東王。後知其聰明，召為誦書左右。江」陵陷，周武帝授太學博士，封襄城縣伯。高祖受禪，除
國子博士，加通直散騎常侍，進爵為公。妥性勁急，有
口才，好是非人物。妥子蔚為祕書郎，有罪當刑，上哀
之，減死論。是後恩禮漸薄，出為龍州刺史。在職三年，
以疾請還，詔許之。除伊州刺史，不行。尋為國子祭酒，
卒官。諡曰肅。

何稠
[
编辑
]

按《隋書何稠傳》：「稠字桂林，國子祭酒妥之兄子也。父通，善斲玉。稠性絕巧，有智思，用意精微。年十餘歲，遇江陵陷，隨妥入長安。仕周，御飾下士。及高祖為丞相，召補參軍，兼掌細作署。開皇初，授都督，累遷御府監，歷太府丞，加員外散騎侍郎。開皇末，桂州俚李光仕聚眾為亂，詔稠召募討之，遣使諭降，以勳授開府。仁」壽初，文獻皇后崩，與宇文愷參典山陵制度。稠性少
言，善候上旨，由是漸見親昵。拜太府卿。後三歲，兼領
少府監。遼東之役，攝右屯衛將軍，加金紫光祿大夫。
明年，攝左屯衛將軍。十二年，加右光祿大夫。從幸江
都，遇宇文化及作亂，以為工部尚書。化及敗，陷於竇
建德，建德復以為工部尚書、舒國公。建德敗，歸於大
唐，授將作小匠，卒。

何昌期
[
编辑
]

按《廣東通志》：「昌期，連山人。幼健捷，力制奔牛，群兒畏之。及長，能挽二石弓。天寶十四年，安祿山叛，詔郡邑​徵武士，昌期應募。郡守試其能，奇之，遂隸元戎帳下。時賊帥高秀喦來侵，河北震動，昌期時為裨將，與眾謀曰：『秀喦故哥舒翰將，驍勇有謀，陣一成，難與爭鋒，不如乘其未陣擊之』。乃先士卒，大呼陷陣，賊眾披靡」，
遂敗之，秀喦退走。有司上「其功」，累遷金牛衛上將軍，
封寧國伯。

何如瑛
[
编辑
]

按《廣東通志》：「如瑛，新興人。五世祖言，據有溪洞，為雲浮鎮將。父遊秦，寓合浦，為採珠徒長。如瑛少失怙，能自樹立，讀兵書，善騎射。從江右觀察使李勉為折衝都尉，以平盜功遷左威將軍，充桂州防遏使。盧慎微代勉節度嶺南，言如瑛與羅州首領馮季康入廣州時，多匿貨寶，遂執之。搜其家，得珠琲，乃父遊秦所遺」也，與季康皆死，觀察使徐浩為二人訟冤，代宗下詔
褒贈，厚恤其家。

何蕃
[

按《宋史陳寅傳》：「何充，漢州德陽人，祕書監耕之孫。通判黎州，攝州事，預為備禦計。及關破，充自刺不死，軍帥呼之降，充踞坐地求死，遂罷。它日又使署招民榜，充不可，自是水飲絕不入口。敵知其不可強，於是斬其首。充妻陳罵不絕口，東望再拜曰：『臣夫婦雖死，可以對趙氏無媿矣』。眾以石擊殺之，親戚同死者四十」餘人，男士麟、孫駒行、從子仲桂先充而死，惟長子士
