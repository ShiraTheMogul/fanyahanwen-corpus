竹部藝文五
〈詩詞〉
[
编辑

《題龔平甫森玉軒》
金·孟宗獻
[
编辑
]

古人借宅亦種竹，大似饕奇心未足。高齋聞有萬琅
玕，坐對懷山飲秋綠。官閒勝日無一事，尊酒不空仍
有肉。他時剝啄叩君門，高枕矮床容我宿。

《燒筍》
孫邦傑
[
编辑
]

煨茁舊聞山谷語，勸耕還憶《大蘇》詩。傳將火候無多
訣，留得天真又一奇。未放錦綳開朿縛，已看玉版證
茶毘。白麻初拜驚燒尾，見此應慚富貴癡。

《丹陽觀竹宮中移賜》
李獻能
[
编辑
]

素士如林侍紫清，紫清新許住蓬瀛。娟娟粉節霜勻
出，矗矗煙梢玉削成。福地根莖蒙化育，中天雨露借
恩榮。綠章封事朝來奏，又聽風前彩鳳鳴。

《義師院叢竹》
郭長倩
[
编辑
]

南軒移植自西壇，瘦玉亭亭十數竿。得法未應輸老
柏，植根兼得近幽蘭。雖無穠艷包春色，自許貞心老
歲寒。百草千花盡零落，請君來向此中看。

《題崞縣郝子玉此君軒》
毛端卿
[
编辑
]

桂林名姓一枝新，萬竹青青德有鄰。渭上風煙分別
派，山陽詩酒屬閒人。心期已到冰霜窟，眼界不知花
柳塵。萱背從今看，輝映嫩香新粉四時春。

《詠竹》
李俊民
[
编辑
]

瀟灑能醫俗，檀欒看上番。我寧負此腹，忍使籜龍冤。

《詠苦竹》
高士談
[
编辑
]

密葉修莖雨後新，肯因憔悴損天真。清如南國《紉蘭》
客，瘦似西山採蕨人。

《題墨竹隔溪煙雨》
龐鑄
[
编辑
]

一溪流水玉涓涓，溪上修篁接暮煙。誰倩能詩文與
可，筆端移得《小江天》。

《秋風驟雨》
前人
[
编辑
]

瀰川急雨暗秋空，無限《琅玕》淡墨中。劍甲摐摐軍十
萬，欲將貔虎戰斜風。

《春雷起蟄》
前人
[
编辑
]

千梢萬葉玉玲瓏，枯槁叢邊綠轉濃。待得春雷驚蟄
起，此中應有「葛陂龍。」
《高竹臨水上》
元·虞集
[
编辑
]

高竹臨水上，幽花在崖陰。以彼貞女姿，當此君子心。
春陽不自媚，夕露忽已深。湘妃昔鼓瑟，悵望蒼梧岑。

《寒竹篇》
傅若金
[
编辑
]

《寒竹依澗阿》，「竹生何磊磊。滋息因厚地，生成藉元宰。春陽散華景，枝葉被光彩。及茲芳歲闌，使吾憂心痗。遽悲凜節變，但恐驚塵浼。寒燠既異宜，遲暮復焉悔。淇園蔭未息，嶰谷音猶在。君子夙相好，深懷邈雲海。竹性諒靡遷，人心懼中改。願言卒封植，勿使傷樵采。」
《江上竹》
王士熙
[
编辑
]

蕭蕭江上竹，依依遍山麓。晨霞屑明金，夕月擁寒玉。
梢梢綠鳳翼，葉葉青鸞足。深叢疑立壁，高節折垂纛。
荒涼含雨露，歷亂同草木。不求筍煮羹，不求椽架屋。
搴條作長笛，吹我平調曲。

《竹山》
丁復
[
编辑
]

離離鳳食幹，綿互亙修巒。君子懷靜儀，虛貞媚蒼寒。
靈厓發潛穎，崇苞閟幽盤。筮鄰從蔣詡，永結求羊歡。

《題竹》
李孝光
[
编辑
]

翠袖臨風一悵然，雨餘草木亦娟娟。東頭夜半明月
出，照見蛟龍石上眠。

《筍》
前人
[
编辑
]

雷公躡蛇夜鼓噪，驚起龍孫觸旗纛。炎沙燒之修尾
脫，六丁控搏忽顛倒。欲落不落虎豹皮，錦綳嬰兒籠
大帽。斧斤幸貸凌雲姿，留以觀渠《歲寒操》。

《雨中移竹》
許有壬
[
编辑
]

山人聚景作池臺，移得龍孫帶雨栽。頃刻雲間晴日
上，便教陰過酒尊來
​

《竹窩》
吳鎮
[
编辑
]

阿香怒鞭籜龍尾，斑鱗蝕去痕未洗。天風吹作萬琅
玕，翠壓修林收不起。林深有客棲寒煙，玉版已悟禪
中禪。人間赤日迥不到，著我六月秋泠然。青雲欲飛
霖雨急，佩環聲裡雙蛾泣。玉簫驚起老龍眠，夜深瀟
湘半江碧。

《野竹》
前人
[
编辑
]

《野竹》野竹絕可愛，枝葉扶疏有真態。生平素守遠荊
榛，走壁懸厓穿石埭。虛心抱節山之阿，清風白月聊
婆娑。寒梢千尺將如何，渭川淇奧風煙多。

《筍》
前人
[
编辑
]

綠陰晝靜南風來，晴梢拂拂煙花開。籜龍走地牙角
出，斑斑玉立橫蒼苔。長鑱穿雲石路滑，錦衣脫綳玉
版白。鳴牙未下冰雪齏，開籠先放揚州鶴。

《養竹軒歌為周莊吳逵子道賦》
華幼武
[
编辑
]

「高軒公子良不俗，不種奇花種修竹。奇花照眼一時紅，修竹虛心萬年綠。春雷擊地新筍生，龍角森森那忍觸。自鋤暖土厚栽培，手挈銀瓶細澆沃。深根掃除螻蟻窟，香葉終期鳳凰宿。日使霑濡雨露恩，歲寒豈憚冰霜酷。猗猗繞戶矗琅玕，含霧連煙比淇奧。招搖皓月金瑣碎，勾引清風聲戞玉。炎天展簟臥蒼雪，春」日聽鶯泛醽醁。可能一日暫相忘，坐對此君看不足。
君不見白樂天，「重言養竹比養賢。」又不見東坡詩，「無竹士俗不可醫。」君今有竹善培養，會看直拂青雲上。

《水竹居》
陸廣
[
编辑
]

「為愛王徵士，幽居發興新。」乾坤得清氣，風月屬閒人。
已有雙溪竹，渾無一點塵。平生隨所遇，取適任天真。

《對竹》
黃庚
[
编辑
]

門對南鄰竹，青青玉萬竿。雖然無地種，且得隔籬看。
露葉晴猶濕，風枝夏亦寒。但教休翦伐，何用報平安。

《寄題竹軒》
杜本
[
编辑
]

綠竹翛翛處，華軒楚楚深。暮留雛鳳宿，曉聽蟄龍吟。
月進窗櫺影，雲移几席陰。居然淇奧趣，莫使俗塵侵。

《題鳳浦方氏梧竹軒》
丁鶴年
[
编辑
]

鳴鳥曾聞此地過，至今梧竹滿丘阿。政懷剪葉書《周
史》，卻恨翻枝入《楚歌》。金井月明秋影薄，石壇風細晚
涼多。中郎去後知音少，共負奇才奈老何。

《竹陰》
白珽
[
编辑
]

占斷人間瀟灑地，全身水墨畫篔簹。非煙非霧一林
碧，似雨似晴三徑涼。翠袖佳人黯空谷，白鬚道士隱
南塘。數竿醉日君須記，移向西軒補夕陽。

《如鏡伐竹架過牆葡萄斷竹插地復生枝葉無住序曰瑞竹余以詩贈之》
宋·無
[
编辑
]

為引寒藤延晚翠，試栽碧玉動秋根。鳳梢依舊生虛
籟，龍籜相將添遠孫。林月過庭窺斷影，茶煙潤色到
啼痕。湯休麗藻題還遍，貝葉應多此處繙。

《題崔原亨竹深處》
〈并序〉
成廷珪
[
编辑
]

余家有竹數竿，號「居竹軒。」 原亨城西時有竹亦數竿，號「竹深處。」 余與崔君通家來往，所好同，故及之。

居竹軒中也自寬，不愁無地著琅玕。文公胸次空千
畝，李侗門前只一竿。天與老夫醫惡俗，日憑童子報
平安。崔家別墅猶高致，遲子歸來守歲寒。

《雪竹山房》
貢性之
[
编辑
]

此君節操獨凌寒，冰雪叢中更耐看。簾幕影迷金瑣
碎，珮環聲動玉闌干。只疑元圃翻瓊樹，錯訝瑤臺舞
素鸞。白戰幾時能著我，萬竿深處一憑欄。

《居竹軒》
倪瓚
[
编辑
]

翠竹如雲江水春，結茅依竹住江濱。階前迸筍從侵
逕，雨後垂陰欲覆鄰。映葉黃鸝還自語，傍人白鶴亦
能馴。遙知靜者忘聲色，滿屋清風未覺貧。

《過許生茅屋看竹》
前人
[
编辑
]

舟過山西已夕曛，許生茅屋遠人群。鑿池數尺通野
水，開牖一規留白雲。煮藥煙輕衝竈出，碓茶聲遠隔
溪聞。可憐也有王猷興，階下新移少此君。

《雨竹》
楊維楨
[
编辑
]

倚石看新筍，爭妍個個添。佳人聽春雨，笑隔水晶簾。

《遵道竹枝》
張雨
[
编辑
]

篔簹谷口白雲生，雲裡琅玕萬玉聲。驚破幽人春枕
夢，一窗斜月半梢橫。

《盆竹》
僧善住
[
编辑
]

瓦缶不多土，娟娟枝葉蕃。豈知幺鳳尾，元是古龍孫。
蒼雪灑禪榻，細香浮酒尊。王猷來此見，應亦為銷魂。

《筍》
鄭氏允端
[
编辑
]

竹林春雨過，瘦筍迸苔長。坐待成高節，清標出短牆。

《綠竹引賜都督孫忠》
明·宣宗
[
编辑
]

薊門八月霜華濃，何時種竹能成叢。鳳城之陽禁苑
東，琅玕萬樹凌青空。光搖太液波心月，高出三山頂
上松。祥飆拂拂來天上，鳴金戛玉聲玲瓏。蓬萊宮中
日如年，高柯密葉霏雲煙。春陽挺秀百花表，秋月增
輝仙桂邊。九夏繁陰覆靈囿，祥麟瑞鶴相周旋。六花
凝寒群卉老，清標轉覺生光妍。軒皇昔日初製律，截
​
筒來自崑崙谷。江心磻石桃竹枝，斬根剝皮誇紫玉。
何如蓬萊宮中竹，雨露偏多生意足。盤根固節千萬
年，遠勝猗猗淇水奧。上林花木熙青春，靈芝瑞草爭
芳芬。愛此蒼蒼太古色，竹邊幾度停遊輪。世云鳳凰
食竹實，又云「鳳凰棲竹枝。鳳笙九奏《太平曲》，鳳兮鳳兮今來儀。」予將拭目而觀之。

《師子林修竹谷》
高啟
[
