〈詩〉

登勝果寺南樓雨中望嚴協律　唐錢起
[
编辑
]

微雨侵晚陽，連山半藏碧。林端陟香榭，雲外遲來客。
孤村凝片煙，去水生遠白。但佳川原趣，不覺城池夕。
更喜眼中人，清光漸咫尺。

杪秋南山西峰題準上人蘭若　　前人
[
编辑
]

「向山看霽色，步步豁幽性。」反照亂流明，寒空千嶂淨。
石門有餘好，霞殘月欲映。上詣遠公廬，孤峰懸一徑。
雲裏隔窗火，松間下山磬。客到兩忘言，猿心與禪定。

華仙遊寺
〈有龍潭穴秦女祠〉
　元結
[
编辑
]

捨事入樵逕，雲山深谷口。萬壑移晦明，千峰轉前後。
嶷然龍潭上，石勢若奔走。開折秋天光，崩騰夏雷吼。
靈豁自茲去，紆直互紛糾。聽聲靜復喧，望色無更有。
冥冥翠微下，高殿映杉柳。滴滴洞穴中，懸泉響相扣。
昔時秦王女，羽化年代久。日暮松風來，簫聲生左右。
早窺神仙籙，願結芝朮友。安得羨門方，青囊繫吾肘。

題玉山觀禪師蘭若歌　　　　　韓翃
[
编辑
]

玉山宴坐移年月，錫杖承恩詣丹闕。先朝親與會龍
華，紫禁鳴鐘白日斜。宮女焚香把經卷，天人就席禮
袈裟。禪林久臥虎谿水，蘭若初開鳳城裏。不出囂塵
見遠公，道成何必青蓮宮。朝持藥缽千家近，暮倚繩
床一室空。掖垣揮翰君稱美，遠客陪遊問真理。薄宦
深知誤此心，迴心願學雷居士。

題精舍寺　　　　　　　　　郎士元
[
编辑
]

石林精舍虎溪東，夜扣禪扉謁遠公。月在《上方》諸品
靜，僧持半偈萬緣空。蒼苔古道行應遍，落木寒泉聽
不窮。更憶雙峰最高頂，此心期與故人同。

登聖善寺閣　　　　　　　　褚朝陽
[
编辑
]

飛閣青霞裏，先秋獨早涼。天花映窗近月桂拂簷香。
華岳三峰小，黃河一帶長。空閒指歸路，煙際有垂楊。

登廬山峰頂寺　　　　　　　劉眘虛
[
编辑
]

孤峰臨萬象，秋氣何高清。天際南郡出，林端西江明。
山門二緇叟，振錫聞幽聲。心照有無界，業懸前後生。
徒知真機靜，尚與愛網并。方首金門路，未遑參道情。

===寄閻防
〈防時在終南豐德在讀書〉
前人===
​
青冥南山口，君與緇錫鄰。深路入古寺，亂花隨暮春。

紛紛對寂寞，往往落衣巾。松色照空水，經聲時有人。
晚心復南望，山遠情獨親。應以修往業，亦惟立此身。
深林度空夜，煙月資清真。莫歎文明日，彌年徒隱淪。

同韓員外宿雲門寺　　　　　　嚴維
[
编辑
]

小嶺路雖近，仙郎此夕過。潭空觀月定，澗靜見雲多。
竹翠煙深色，松聲雨點和。萬緣俱不有，對境自垂蘿。

奉和獨孤中丞遊雲門寺　　　　前人
[
编辑
]

絕壑開花界，耶溪極上源。光輝三石座，登陟五雲門。
深木鳴騶馭，晴山曜《武賁》。亂泉親坐臥，疏磬發朝昏。
蒼翠新秋色，莓苔積雨痕。上方看度鳥，後夜聽吟猿。
異跡焚香對，新詩酌茗論。歸來還捨俗，諸老莫攀轅。

鄱陽大雲寺一公房　　　　　　顧況
[
编辑
]

盡日陪遊處。斜暉竹院清。定中觀有漏。言下證無生。
色界聊傳法。空門不用情。欲知相去近。鐘鼓兩聞聲。

[
编辑

招提精舍好，石壁向江開。山影水中盡，鳥聲天上來。
一燈傳歲月，深院長莓苔。日暮雙林磬，泠泠送客回。

春日陪李庶子遵善寺東院曉望　盧綸
[
编辑

映竹水田分，當山起鴈群。陽峰高對寺，陰井下通雲。
雪晝唯逢鶴，花時此見君。由來禪誦地，多有謝公文。

编辑

古砌碑橫草，陰廊畫雜苔。禪宮亦銷歇，塵世轉堪哀。
