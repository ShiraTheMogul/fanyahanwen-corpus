張訥妻劉氏
〈孫氏姚氏華氏劉氏附〉
[
编辑
]

按《元史列女傳》：「張訥妻劉氏，藍田人。訥為監察御史，早卒，劉守志不二。河東受兵，劉氏二子衡、衍俱以事出外，度不能自脫，遂與二婦孫氏、姚氏決死，盡發貲囊分給家人，婦姑同縊焉。有華氏者，大同張思孝妻，為貊高兵所執，以不受辱見殺。其婦劉氏僵壓姑屍​大罵不已，兵併殺之。後家人殮其屍，婦姑之手猶相」持不捨。

觀音奴妻卜顏的斤
〈王氏附〉
[
编辑
]

按《元史列女傳》：觀音奴妻卜顏的斤，蒙古氏，宗王黑
閭之女。大都被兵，卜顏的斤謂其夫曰：「我乃國族，且年少，必不容於人，豈惜一死以辱家國乎！」遂自縊而
死。時張棟妻王氏語家人曰：「吾為狀元妻，義不可辱。」赴井死。其姑哭之慟，亦赴井死。

安志道妻劉氏
[
编辑
]

按《元史列女傳》：「安志道妻劉氏，順州人。志道及劉氏之弟明理並登進士第。劉氏避兵匿巖穴中，軍至欲污之，劉氏曰：『我弟與夫皆進士，我豈受汝辱乎』？軍士以兵磨其體，劉大罵不輟聲，軍怒，乃鉤斷其舌，含糊而死。」
宋謙妻趙氏
〈諸婦妾附〉
[
编辑
]

按《元史列女傳》：宋謙妻趙氏，大都人。兵破大都，趙氏
子婦溫氏、高氏，孫婦高氏、徐氏皆有姿色，合謀曰：「兵且至矣，我等豈可辱身以苟全哉！」趙即自經死，諸婦
四人，諸孫男女六人，眾妾三人，皆赴井而死。

齊關妻劉氏
[
编辑
]

按《元史列女傳》：齊關妻劉氏，河南人。關應募為千夫
長，戰死澤潞間，劉氏貧無所依，守志不奪。有來強議
婚者，劉氏紿曰：「吾三月三日有心願，償畢當從汝所言。」是日徑往彰德天寧寺，登浮圖絕頂，祝天曰：「妾本河南名家劉氏女，遭世亂，適湖南齊關為妻。今夫已死，不敢失節也。」遂投地而死。

王宗仁妻宋氏
[
编辑
]

按《元史列女傳》：「王宗仁妻宋氏，進士宋褧之女也。宗仁家永平，永平受兵，宋氏從夫避于鏵子山，夫婦為軍所擄，行至玉田縣，有窺宋氏色美，欲害宗仁者，宋氏顧謂夫曰：『我不幸至此，必不以身累君』。言訖，遂攜一女投井死，時年二十九。」

[
编辑

按《元史列女傳》：徐猱頭妻岳氏，大都人。兵入都城，岳
氏告其夫曰：「我等恐被驅逐，將奈何？」其夫曰：「事急惟有死耳，何避也！」遂火其所居，夫婦赴火以死。其母王
氏，二女一子，皆抱持赴火死。

〈女附〉

编辑

按《元史列女傳》：金氏詳定使四明程徐妻也。京城既
破，謂其女曰：「汝父出捍城，我三品命婦，汝儒家女，又進士妻，不可受辱。」抱二歲子及女赴井死。

曹泰財妻劉氏
[
编辑
]

按《輟耕錄》：「劉氏，冀之衡水人，通古文、孝經、小學諸書。適同郡曹泰財紅巾陷河朔，因避兵聊城村。賊掩至，大掠，見劉居群人中，特妍整，持刀驅之行。劉曰：『吾婦人，惟知從夫而已，不從賊也』。賊欲移其心，乃盛陳金玉珠璣，仍用錦繡衣服被其身。劉裂碎之，強擁上馬，墮地者數四。賊怒，繩其項，就馬上曳之。劉以手爪地」，
以頭觸石流血，罵賊不絕聲，遂遇害。

李哥
[
编辑
]

按《輟耕錄》：「河南理幕沈易云，霸州倡女李哥，年十二三時，母教之歌舞，哥泣曰：『女率有匹繄，我獨為此乎？母告以業不可廢。哥曰：『若此聽母，母亦當從我好，否則有死而已』。母陽許之，因是不粉澤，不茹葷，所歌多仙曲道情。有召者，必先詢主客姓名，然後往。人亦預相戒，毋戲狎。哥凝立筵前，酒行歌闋，目不流盼，與之』」酒勿飲。州判官嘗忤哥，徑還，誓不與見。孟津縣達魯
花赤厚賂哥母，夜扺舍，哥懷利刃閉臥內，罵之曰：「汝職在牧民，而狗彘之，不若可急去，不且血汙吾刃矣。」赤慚怒以回。明日，知州聞之，歎曰：「州有貞女，而吾不知，是一失也。吾次子明經舉秀才，真若配以禮聘娶之。」未幾，紅巾入寇，夫婦被執，見哥妍麗，將殺其夫。哥
走前抱夫項大呼曰：「吾斷不從汝求活。」寇并殺之。

藺氏
[
编辑
]

按《輟耕錄》：陳友諒部屬稱：鄧平章者，陷江西某縣，有
婦藺氏，其夫以財雄一鄉，因賂鄧之帥某，丐免剽戮。
帥聞藺有殊色，輒殲其家，獨生藺及四歲嬰，將納之，
藺曰：「帥貴人，妾事之無恨。然吾良人以禮幣聘妾為婦若干年，與生二子，妾不忍即背恩。軍中禮不備，請持一月喪服，乃為帥婦未晚。」帥許之。服未終，移兵別
縣。帥曰：「吾如汝約，今夕諧吾婚乎？」藺曰：「諾。」既而帥上
馬他之，使二卒守之。藺曰：「為取雞酒，具香火，今夕吾為帥婦，敢告先良人！」靈卒俱出，乃先殺嬰，嚙指血書
壁曰：「涇渭難分濁與清，此身不幸厄紅巾。孤兒未忍更他姓，烈婦何曾嫁二人。白刃自揮心似鐵，黃泉欲到骨如銀。荒村日落猿啼處，過客聞」之亦慘神。書罷
​
即自刎。帥返驚歎，訊二卒，欲罪之。卒指壁間題，倩人
讀其詩，馳白鄧。鄧聞之陳，陳為立廟旌表云。

章瑜妻傅氏
[
编辑
]

按《輟耕錄》：「傅氏，紹興諸暨人。年十八，適同里章瑜。瑜為苛吏脅軍興期會，迫死道上。訃至，傅氏蒲伏抱屍歸，號泣三日夜，不忍入櫬，屍有腐氣，猶依屍呵琀冀甦。既入棺，至嚙其棺成穴。及葬，投其身壙中，母強挽以出。未百日，母欲敓志，語聞，遂大慟，連日不食。母囑侍婢謹視之。閱數日，紿婢理沐具俟浴，既而失所在。」明日，婢汲井，見二足倒植井中，乃傅氏也。楊維禎嘗
贊之曰：「余讀古節婦事，至青陵臺及祝英氏，以為後無繼者，今瑜妻乃爾。謂世降德薄者信歟？夫婦倫與君臣等，世之稱臣子者，獨不能以瑜妻之義于夫者義其君歟噫？」
崔賓妻尚氏
[
编辑
]

按《畿輔通志》：尚氏，定興人，崔賓妻。元季盜起中原，遠
近繹騷，氏被擄，污之不從。賊以刃刦曰：「若從吾則生，否則死。」氏厲色罵曰：「吾恨不斬汝萬段以謝天下，死即死耳，肯為汝賊污耶？」遂遇害。

王世明妻李氏
〈女安奴附〉
[
编辑

按《畿輔通志》：李氏，名寨兒，房山人，王世明妻。至正末，
竹真軍至縣，李與女安奴皆被執，謂女曰：「寧死勿受辱。」女曰：「母先殺我。」李即以軍所遺刀殺女，復自殺。竹
軍嘆而葬之。

官奴

按《畿輔通志》：「官奴，晉州人，趙恭女。父官中書管勾。元末明兵入城，祖母解氏及父恭俱縊死。官奴方大哭，適鄰嫗數輩相率力挽出避，女不從，曰：『人生百歲，亦須一死，何必避為』？」乃潛入中堂，解衣帶自經。

劉氏女
[
编辑

按《威縣志》：「劉氏女，宗城人。幼有志操，許字李御史子，未歸，李子亡，泣告父母，欲往送殯。父母憐而許之，遂披髮號泣，送至墓所，林木陰深，潛于塚後自縊，遂合葬。有司奏聞，旌表。」

[
编辑

按《開州志》：姜氏，谷有源妾，開州人。元末，有源判薊州，
遘疾且死，語妻妾曰：「吾病必不起，汝輩肯予從乎？」姜
氏曰：「諾。」及夫卒，自縊合葬。事聞，旌表。

文宗信妾白氏
[
编辑
]

按《遼陽州志》：白氏，文宗信妾。夫病篤，氏昏旦潛禱于
神，至忘寢食。夫語之曰：「汝年方二十，我死汝將奈何？」氏應曰：「妾不獨生，夫死迨殮。」氏盡出箱篋分給親戚，
沐浴告別主母，自縊而死。

閔本妻程氏
〈二女附〉
[
编辑
]

按《懷慶府志》：程氏，閔本妻，河內人。本為集賢殿學士，
有一子二女。明師至北平，謂程曰：「國事至此，愧不能報。男少當歸河內，二女吾不得而保矣。」程曰：「君能死忠，妾安愛其身乎？」夫婦並自縊，二女悲號，亦縊于其
旁。少男遂歸河內。

按《南陽府志》：「雷氏，順陽人，孛朮魯遠妻。遠以父廕調祕書郎，轉襄陽縣尹，須次居南陽。賊起，遠以忠義自奮，傾財募壯丁，得千餘人，與賊拒戰。俄而賊大至，遠被害。雷為賊所執，賊欲妻之，乃詆賊曰：『我魯參政冢婦，縣令嫡妻。夫死于義，肯從汝狗彘以生乎』？賊醜其言，將辱之，雷號哭大罵見殺。」
李思齊妾鄭氏
[
