鄭命賢妻黃氏
[
编辑
]

按《麻陽縣志》：「黃氏，生員鄭命賢妻。賢少負才名，以應恩選沒於鄂。氏年十九，聞訃，即誓死。越半月，櫬歸，氏啟棺撫屍痛哭，殮祭畢，隨自經死。」
李思乾妻張氏
[
编辑
]

按《麻陽縣志》：「張氏，李思乾妻。年二十喪夫，無子，孀苦六十年。萬曆庚戌，有司旌之。」
羅文繡妻聶氏
[
编辑
]

按《衡州府志》：「聶氏，常寧羅文繡妻，父廷鳳，幼嘗授以《女則》《女誡》諸篇，悉能解悟。萬曆戊戌春，羅」妻經月
蒲蹶於河，聶挽之不及，亦投水中。舟人亟舉篙往援，
不受，遂死。越七日，兩尸并浮，顏色如生。縣令表其地。

黃琥妻雷氏
[
编辑
]

按《衡州府志》：雷氏，黃琥妻，藍山人。家貧，拮据以資夫
學。夫尋喪，氏哭之痛，勺水不進者七日。娣姒強慰之，
氏曰：「夫存與存，夫亡與亡，吾志決矣。」俄檢緗，帙盡焚，
遂自刎而死。群鳥環集其廬，悲鳴不去，人咸異之。

曾三聘妻陳氏
[
编辑
]

按《祁陽縣志》：陳氏，祁陽儒生曾三聘妻，尚書陳公薦
女。十歲失母，晨昏依祖母膝下。十六歸曾姑，束濕異
常，兒女悉累之。陳敬順無違，罄其奩之所有以悅姑，
無驕心吝色。翁姑後先繼喪，倒囊以成，厚斂曰：「送死大事，無留憾也。」人稱孝婦。未幾夫亡，觸棺垂斃。以夫
窀穸未營，子方幼，穉未可以死。泣血三年，口不嘗五
味，身不衣裘帛。服除之明日，沐浴危坐，旬日不食而
死。事聞，旌之。

[
编辑

按《江華縣志》：「趙向貞，太平鄉民趙志倫女。年十八，為亂兵所獲，不從矢口大罵，拔賊佩刀刺賊，賊怒，斷其手足棄去。邑令申請旌其家，仍為立祠祀之。」
夏氏
[
编辑

按《桂陽州志》：夏氏，文學汪泮妻。事舅姑盡孝，勉夫力
學，足不越閫。泮捐館，夏慟過甚，姑慰曰：「『已矣！有弱息在，何乃爾』？夏曰：『當俟姑地下』。」遂七日不食死。

萬氏女
[
编辑
]

按南昌郡乘萬氏女，名會貞，新建萬國隆女。幼許南
昌胡欽恭，後欽恭患痘死，女痛哭不欲生，易縞衣將
臨其喪，母阻之。及聞殯，曰：「何不待我憑棺一哭耶？」自
是以死自決，家人防之甚周。一日，佯理髮整衣，示以
不疑，遣婢出，潛登樓自經。時年十七。萬曆間旌其門。

萬氏女
[
编辑
]

按南昌郡乘萬氏女，名考英。新建萬建言：「女幼許閔士毅，會士毅病篤，考英求侍湯藥，父母難之。及聞訃，慟哭幾絕，易縞衣，願隨父往奠，不可，痛哭益甚。諸母勸慰多方，竟詣密室自縊死。」萬曆間旌其門。

聶莊妻潘氏
[
编辑
]

按《南昌郡乘》：潘氏，豐城聶莊妻。莊客泗州，病沒，潘聞
訃，號哭幾絕，舅姑促令改嫁，適驟雨，溝中漲滿，氏整
衣赴水死。

黃廷繼妻陳氏
[
编辑
]

按《南昌郡乘》陳氏，南昌黃廷繼妻。于歸半載，廷繼客
遊南畿，家徒壁立。陳事績紝，以供菽水三年。既而訃
至，慟哭七日，潛自縊以殉。萬曆間，旌其門。

李壽妻鄧氏
[
编辑
]

按南昌郡乘鄧氏，進賢李壽妻。壽亡，鄧年十七，哭泣
誓死。葬後，自縊以殉。萬曆間旌其門。

易氏女
[
编辑
]

按南昌郡乘易氏女，名妹貞，高安易濱。女幼許聘弋
陽府儀賓楊漳子鐶，未婚。鐶死，妹貞年十七，聞訃墜
樓幾死，持服奔喪。舟至漳江之岸，索木主，如親迎禮，
以輿載主而入，隨至柩前。行禮畢，朝夕哭奠。期年一
夕，焚香自縊於鐶柩側。事聞旌表。

葉氏女
[
编辑
]

按《南昌郡乘》，葉氏女，名兆姺，南昌葉相女。幼許字新
建李光庭，未婚而庭沒。葉年十三，先期夢光庭縞衣
乘白馬入其室。越數日聞訃，誓不改節。父母憐其幼，
強更聘，姺即於密室整衣自縊死。

樊昱女
[
编辑
]

按《南昌郡乘》，樊昱女，字鳳英，南昌人，許字新建萬尚
​
弘。未婚，尚弘病，鳳英為廢寢食。及病亟，昱往視之，三
日不歸。鳳英計尚弘已死，白母欲往治喪。母曰：「待爾父歸。」抵暮，悲不自禁，登樓潛縊死，與尚弘合葬城頭
山。萬曆間，旌其門。

蕭一和妻劉氏
[
编辑
]

按南昌郡乘劉氏，蕭一和妻。一和沒，劉年二十九，觸
棺死而復甦，赴河護救。越四日，家人防稍懈，乃沐浴
告靈，返室嚼舌而沒。萬曆間，旌其門。

郭婦吳氏
[
编辑
]

按《南昌郡乘》，吳氏，名順貞，貢士吳如揆女。年十四，贅
蘄水郭吏部長孫某。未三月，遇李賊於水次，掠之不
從，怒髡共髮，以刃裂其頸，幸不死。及歸郭後，山賊猖
亂，殺郭生，并擄吳上馬。吳口嚙賊指，遂殺之。

徐公一妻廖氏
[
编辑
]

按《奉新縣志》：廖氏，徐公一妻。公一客死吳城。氏聞訃
泣，命家人曰：「吾不能獨生矣，當同穴葬我。」遂投繯死。

劉日懋妻彭氏
[
编辑
]

按《奉新縣志》：彭氏，劉日懋妻。年十六于歸時，日懋已
抱疾，合巹僅七日。日懋就醫外舍，七閱月而日懋亡。
氏躄踊絕粒，徒步臨夫墓，泣曰：「幸虛一抔土以待我。」及期，果痛悼死，合葬。

溫捷生妻涂氏
[
编辑
]

按《寧州志》：涂氏，上坑溫捷生妻。生亡，氏金石白況，䌟
績不輟。乙卯冬，賊攻城，氏攜女菊貞及子奇梧，自上
坑走「高塅。賊忽奔出，炮聲如雷，母子驚散。氏抱女潛匿於南姑橋深茅溝。圍城八日，四山搜巡，氏恐出被賊污，忍饑以死。賊退，有樵夫見之，歸報溝內兩死人，端坐如生。塘兵溫維賢同眾往觀，即其嬸也。舁出而」葬，見者殞涕。

劉良坤妻王氏
[
编辑

按《南康府志》：「王氏，星子劉良坤妻。有殊色，通書史。歸良坤，事姑以孝。萬曆二年，劇賊何鳳掠其家，見氏欲污之，不從，恐以刃，無懼色，大呼家人殺賊。日向晡，聞官兵至，乃引劍刺氏腹，氏以手按劍，遙拜其姑，抽劍而死，年二十四。觀者如堵，莫不痛哭而去。巡方使者題請建坊。」
朱氏女
[
编辑
]

按《九江府志》：朱氏女，德化人。許字勞欽亮子，未婚而
勞子沒。女年十六，富室爭求之。父母將許，女曰：「死生易節，吾不能安。」驀奔喪所自縊。聞者傷之，合葬南薰
門外。萬曆間，請於朝，建坊旌表。

===鄒東妻姚氏===
​
按《德安縣志》：姚氏，鄒東妻。年十八，夫亡，歸依母家。會
兵從建昌來，擄去婦女七十餘口，主將恐兵辱之，即
審明發回。氏曰：「聞婦女不出閨門，一出便當死矣。」遂
自縊。

桂登魁妾繆氏
[
编辑
]

按《德安縣志》：繆氏，桂登魁妾。年十七，被兵擒，欲污之，
不從。扶之上馬，不得命役舁之行，亦不許。哭曰：「事至今日，止一死耳。」遂奪刀自刎。
