李士翀妻徐氏
[
编辑

按《金谿縣志》：「徐氏，諸生李士翀妻，孝廉徐日光女。少寡不嫁，鄉里並稱奇節。」
張司南妻吳氏
[
编辑
]

按《金谿縣志》：「吳氏，小字金英，張司南妻。年二十，夫亡，篤志自守，事翁姑至孝，撫姪必大為嗣，教養成立，名著黌宮。氏年五十九卒。」
唐存仁妻李氏
〈樂氏附〉
[
编辑
]

按《金谿縣志》：李氏，唐存仁妻。仁早世無嗣，李誓死靡他。舅姑老，遺弱子，存質命鞠之。自襁褓既長，以其外大父大參孫女樂氏為配，娣姒雅相得。樂生一子，從姑命育於李，遂名公李。未幾，存質與舅姑俱歿，時公李甫二歲。李謂樂曰：「『舅姑雖逝，我實足以撫爾子，爾志云何』？樂泣曰：『姒無子尚然，豈有子而反萌他志？願』」 共撫此子，繼唐氏宗祧。李弟渭思宦遊，欲李攜甥同往，李不可。及令建安，又強之，李曰：「兒能讀書矣。」 遂往焉，渭思即以其女為甥配。未幾，渭思雉經孤城。初，李欲與難，弟曰：「姊亟逃，姊死，甥焉恃？」 遂輾轉流離，挾公李出，萬死一生以歸。悉披其先世遺書，篝燈親教之，而公李遂以成名。李樂卒，進士張士任為詩弔之。

周洛濱妻危氏
[
编辑
]

按《金谿縣志》：危氏，周洛濱妻。生子京元甫二歲。洛濱喪，氏哀痛欲殉，姑泣諭曰：「我已老，汝更從夫，如孤子何？」 氏勉從姑命，親操井臼，勤紡績，以事舅姑，備嘗諸苦。京元後官光祿寺丞。

黃明復妻鄧氏
[
编辑
]

按《金谿縣志》：「鄧氏，諸生黃明復妻，鄧文恪公嗣女。年十八，歸明復。姑老多疾，氏湯藥必親。明復歿，氏年二十五方娠，長子長庚甫歲餘，氏欲以身殉，賴姑勸止。越四月，產遺腹子長泰。孀居三十年如一日。進士張士任為詩弔之。」
曾曰唯繼妻徐氏
[
编辑

按《金谿縣志》：「徐氏，小字孕蓮，徐含章女，長興太學生曾曰唯繼妻。舅姑歿，事死如生，養妾姑尤善。年二十三，夫亡，服闋，父問所志，答曰：『不事二夫。前妻子女藐弱無恃，徐視如己出，延師訓迪，以督其成。雖家計蕭然，而執志愈堅，內外咸服』。」
曾震亨妻鄭氏
[
编辑
]

按《金谿縣志》：「鄭氏，郡庠生曾震亨妻。年二十五，夫將死，囑善事舅姑。及歿，生事死葬，一如夫命。經歷荒亂，孀居六十餘載。及卒，聞者莫不泣下。」
陳一夔妻傅氏
[
编辑
]

按《金谿縣志》：「傅氏，貢士傅鯤化妺也。幼習女紅，以供衣服，坐不偏，立不跛，溫慎寡言，出於天性。年十七，事陳一夔。二十四，夫亡。絕粒十餘日，號慟嘔血。父母哀其苦，強歸寧，痛哭不從，獨處一室，雖家人罕見其面。親操井臼，事姑至孝。後二十年，姑亡，氏亦相繼而卒。兄鯤化為之銘。」
吳周妻王氏
[
编辑
]

按《金谿縣志》：王氏，吳周妻。年十八適吳，纔八月，周死，無子。父母憐其少微，叩其意，氏泣曰：「烈女不更二夫，此身豈可復辱。」 卒以死自誓。撫幼叔及諸猶子如己出，終身不改。年七十終。直指旌其閭。

李名郁妻周氏
[
编辑
]

按《金谿縣志》：周氏，庠生廷梓女。年十九歸李，名郁。年二十，郁以飲椒致病，殆不起。氏方有身七月，泣問夫曰：「養姑與死孰難？」 曰：「養姑不易。」 又問。
​

曰：「撫孤與死孰難？」 曰：「撫孤難。」 氏曰：「敢不為其難者。」 郁曰：「若是吾瞑目矣。」 聞者莫不淚下。姑劉年八十，疾幾於廢，而飲食未衰。氏奉几奉杖，十年如一日。姑死盡哀，逾年亦卒。

張一之妻饒氏
[
编辑
]

按《金谿縣志》：饒氏年十七，歸邑文學張一之。越二年夫亡。一之臥病時，氏衣不解帶者半載。後母欲奪其志，舅姑亦以氏無子，聽之。氏前泣曰：「婦非敢苟活，顧相從地下，使人以漁色議我夫，是重夫子以不德也。必欲強以不義，請從此辭。」 遂闔戶自經，以救免。撫二遺姪，備盡教養事姑，進退唯命。後以壽終。

徐璧妻吳氏
[
编辑
]

按《金谿縣志》：吳氏，名瑤英，吳文莊公孫女，適中憲大夫徐日光之孫璧。年十九，璧病革，與吳訣曰：「無子奈何？」 吳泣曰：「若有子而守，安足云節。」 及亡，氏年十八，椎髻紡績，以事舅姑。祖母楊氏寢疾一載，吳旦夕侍側，嘗藥進飯，不少倦。其天性如此。後年百歲，無疾終。

周顏妻胡氏

李能妻吳氏
[
编辑

按《金谿縣志》：「吳氏，古竹吳貴女，田西李能妻也。年二十而寡，守節終身如一日，事翁姑以孝，撫兩孤勤儉。子既長，篤志詩書，盡交天下賢士，以著母之節。氏年九十，視聽不衰，諸孫亦俱以文顯。」
龔一龍妻鄭氏
[
编辑

按《金谿縣志》：鄭氏，諸生龔一龍妻。龍早亡，鄭年十九，方龍疾篤，囑鄭曰：「子幼家貧，無以為生，吾死當改適。」 鄭痛哭不已，剪髮納棺中，示不可奪。年七十九，邑令上其事，直指旌之。

姑以孝聞。丙戌兵變，善為兵所殘。子泰纔三歲，傅撫教之，九歲即受知於督學使者，有「神童」 之號。無何，泰復夭，僅遺百日。子天祐，傅偕媳胡氏盡瘁撫孤，備嘗艱苦。縣令旌其閭。

車雲舉妻洪氏
[
编辑
]

按《金谿縣志》：洪氏，諸生車雲舉妻。年二十一夫亡，子軾甫二歲，氏旬日不食，欲從夫地下。姑曰：「煢煢藐孤，其誰撫之？」 語云：「死節易，撫孤難。汝欲為其易而遺我以難乎？盍善為宗祧計也。」 洪乃斷髮自誓，延師訓軾成名。孀居四十年，都人誦之不衰。

嚴而昌妻王氏
[
编辑
]

按《金谿縣志》：王氏，幼聰慧，頗知書。及笄，適清江諸生嚴而昌，篝燈佐讀，嘗勵其夫曰：「大丈夫志在天下，勿以溫飽累其心。」 事舅姑極得其歡，尊
​

卑內外待之，各以其道。昌歿，僅遺三女；王砥節孀居，數十年如一日；撫三女，俱克遣嫁。

按《金谿縣志》：「張氏，小字國英，黃子尚妻。于歸喪舅，事姑惟謹。子尚出就外傅，氏奉滫瀡無失，宗族咸稱賢孝。年二十四，子尚以棘闈不利，抱憤而死。氏鞠育諸孤，俱克成立。非至戚往來經月，戶常閉。慎於閑檢，不稍自適。姑歿，營葬與夫喪並舉，鄉黨稱之。」
陶宗侃妻劉氏
〈徐氏附〉
[

按《金谿縣志》：「劉氏，諸生陶宗侃妻。性淑慧，有姿容，年十七于歸。十九夫歿。子四歲不育，或諷之嫁，則怒形於色。事姑盡孝，教子有成。年八十七，事聞於朝，有」
詔旌表。鄰婦徐氏新寡，過劉出一香囊示之。《繡宗侃》

二字曰：「吾以此鑑心六十年矣。」 鄰婦感其言，亦苦節終身。
