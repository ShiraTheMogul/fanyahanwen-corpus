劉摰
[
编辑
]

按《宋史劉摯傳》：「摯字莘老，永靜東光人。擢甲科，歷冀州南宮令。縣賦甚重，摰援例旁郡，請轉運使告于朝。三司使包拯奏從其議，民懽呼至泣下，曰：『劉長官活我』！是時摯與信都李沖、清河黃莘皆以治行聞，人稱為河朔三令。用韓琦薦，得館閣校勘，王安石一見器異之，擢檢正中書禮房，月餘，為監察御史裡行。入見」神宗面賜褒諭，因問：「卿從學王安石邪？」安石極稱卿
器識。對曰：「臣東北人，少孤獨學，不識安石也。」退而上
疏，論率錢助役官自雇人有十害。謫監衡州鹽倉。久
之，簽書南京判官。會司農新令盡斥賣天下祠廟，往
見留守張方平，方平瞿然，托摯為奏。元豐初，改集賢
校理，為開封推官，除禮部郎中。哲宗即位，擢侍御史。
時蔡確、章惇在政地，與司馬光不相能，摰因久旱上
言「願進忠良，通壅塞，以答天戒。」又疏確過惡，大略有
十，論惇凶悍輕侻，無大臣體，皆罷去。元祐元年，擢御
史中丞，遷門下侍郎。六年，拜尚書右僕射。摯性峭直，
有氣節，觸機輒發，不為利怵威誘。自初輔政至為相，
修嚴法憲，辨白邪正，然持心少恕，勇於去惡，竟為朋
讒奇中，以觀文殿學士罷知鄆州。紹聖初，奪職知黃
州。四年，陷邢恕之謗，貶鼎州團練副使、新州安置，數
月，以疾卒。子跂，能為文章，遭黨事，家居避禍，以壽終。

劉庠
[
编辑
]

按《宋史劉庠傳》：「庠字希道，彭城人。中進士第，為高密廣平院教授。英宗求直言，庠上書論時事，除監察御史裡行。帝不豫，儲嗣未正，庠拜疏謂：太子天下本，潁王長且賢，宜使日侍禁中，閱四方章奏行之。」神宗立，
遷殿中侍御史，為右司諫，奉使契丹。故事，兩國忌日
不相避。契丹張宴白溝日，當英宗祥祭，庠丐免，契丹
義而聽之。除集賢殿修撰、河東轉運使，進天章閣待
制、河北都轉運使。契丹侵霸州土場，或言河北不可
不備。庠上五策，料其必不動，已而果然。太河東流，議
者欲徙而北。庠請遲以歲月，徐觀其勢而順導之，朝
​
廷是其議。移知真定府，又為河東轉運使。召知開封
府，不肯屈，事王安石。安石欲見之，竟不往，奏論《新法》。
會與蔡確爭廷參禮，遂以為龍圖閣直學士、知太原
府。遭母喪，服終，知成都府，徙泰州。坐失舉，降知虢州，
移江寧府、滁州，徙永興軍。元祐初，加樞密學士、知渭
州，卒。

劉惟簡

[
编辑

按《宋史劉易傳》：「易，忻州人，性介烈，博學好古，喜談兵。韓琦知定州，上其所著《春秋論》，授太學助教、并州州學說書，不能屈志仕進，寓居於虢之盧氏，習辟穀術。趙抃復薦其行誼，賜號退安處士。易作詩，琦每為書之石，或不可其意，輒滌去，琦亦再書之。尹洙帥渭，延致尊禮，狄青代洙，遇之亦厚，治平末卒。」劉瑾
[
编辑
]

按《宋史劉瑾傳》：「瑾字元忠，吉州人，沆之子也。第進士，為館閣校勘，遷集賢校理，通判睦州，為淮南轉運副使。召修起居注，加史館修撰，河北轉運使，拜天章閣待制，知瀛州，改鎮廣州。與樞密院論戍兵不合，改虔州戰櫂。都監楊從先奉旨募兵不至，擅遣其子懋糾諸縣巡檢兵集郡下，瑾怒責之。懋訴瑾於朝，遂廢於」家。踰年，復待制、知江州。歷福州、秦州、成德軍，卒。

劉闃
[
编辑

按《宋史劉闃傳》，「闃字靜叔，青州北海人。以拳力為軍校，從文彥博討貝州，功第一，擢虎翼指揮使，累遷辰州團練使。韓絳宣撫陝西，詔闃自河東為掎角，至鐵冶溝，夏人大集，眾懼，闃自殿後率銳驍搏戰，飛矢蔽體，不為卻敵，解去，為冀州駐泊總管，以左金吾大將軍致仕，卒。」劉庭式
[
编辑
]

按《宋史劉庭式傳》：「庭式，字得之，齊州人，舉進士，蘇軾守密州，庭式為通判。初，庭式未第時，議娶鄉人之女，既約未納幣，庭式乃及第。女以病喪明，女家躬耕，貧甚，不敢復言。或勸納其幼女，庭式笑曰：『吾心已許之矣，豈可負吾初心哉』！卒娶之，生數子。後死，庭式喪之，逾年，不肯復娶。軾問之曰：『哀生於愛，愛生於色。今君愛何從生？哀何從出乎』？」庭式曰：「吾知喪吾妻而已。吾若緣色而生愛，緣愛而生哀，色衰愛弛，吾哀亦忘，則凡揚袂倚都市，目挑而心招者，皆可以為妻也耶？」軾
深感其言。庭式後監太平觀，老於廬山，絕粒不食，目
奕奕有紫光，步上下峻坂如飛，以高壽終。

劉鑄
[
编辑
]

按《萬姓統譜》：鑄字季冶，長興人。性素剛鯁，淹貫經史。
幼孤，鞠於伯父。比長，報以父禮，李潛稱為純德士。平
生交遊多名流，讀書天竺山，從學者百餘人。母死，廬
於墓側，孝心篤至。有仕族賢之，欲妻以女，鑄曰：「吾窶夫而得仕族，女必不肯提甕出汲，以修婦道，井臼之責，鑄委之誰耶？」竟謝卻之。既沒，鄉人追悼，有為之流
涕者。有《燕石編》傳家。

劉衍
[
编辑
]

按《萬姓統譜》：衍字成之，龍溪人。治平間及第，授英州
推官。應材識兼茂科，諷及新法報罷。後知潮陽縣，歲
大飢，衍發縣帑，傾家資，運廣米，民得不飢。改知新州，
以禦妖賊功，特授朝奉郎。秩滿詣京師，會知杭州，與
趙抃同日引見，議青苗不合，安石叱之曰：「汝等不讀書故耳。」抃未能對，衍曰：「三皇五帝所讀者何書？」安石
嘿然。力乞致仕。累辟不起。

劉几
[
编辑
]

按《宋史劉溫叟傳》：「溫叟子煜，煜子几，字伯壽，以煜任為將作監主簿，第進士，范仲淹辟通判邠州。孫沔薦其才，換如京使，知寧州。儂智高犯嶺南，几上書願自效，以為廣東、西捉殺。道聞蔣偕、張忠戰沒，疾馳至長沙，見狄青大戰於歸仁鋪，几以右軍搏鬥，自辰至巳，勝負未決。几言於青，出勁騎五千擣其中堅，賊駭潰。」進皇城使、知涇州。陛見，命領恆州刺史。曾公亮薦之，
為太原、涇原路總管。神宗即位，轉四方館使、知保州，
治狀為河北第一，踰六年，即請老。元豐三年，祀明堂，
大臣言几知音，詔詣太常定雅樂，再加通議大夫，卒。
几議樂律最善，以為律主於人聲，不以尺度求合。嘗
游佛寺，聞鐘聲，曰：「聲澌而悲，主者且」不利。是夕主僧

死。在保州聞角聲曰：「宮微而商離。」至秋，守臣憂之。及
​
期几遇疾，然所學頗雜《鄭》《衛》云。

劉恕
[
编辑
]

按《宋史劉恕傳》：「恕字道源，筠州人。父渙，字凝之，為潁上令，以剛直不能事上官，棄去，家於廬山之陽，環堵蕭然，而無戚戚意，以壽終。恕少穎悟，未冠舉進士，調鉅鹿主簿、和川令。發強擿伏，一時能吏，自以為不及。篤好史學，司馬光編次《資治通鑑》，召為局僚，遇史事紛錯難治者，輒以諉恕，恕考證差謬，最為精詳。王安」石與之有舊，欲引寘三司條例，恕以「不習金糓」為辭。
安石怒，恕不少屈，或稠人廣坐，抗言其失，無所避，遂
與之絕。以親老，求監南康軍酒以就養，得風攣疾，苦
學如故。少間輒修書，病亟乃止。官至祕書丞，卒。死後
七年，《通鑑》成，追錄其勞，官其子義仲為郊社齋郎。次
子和仲，有超軼材，作詩清奧刻厲，亦蚤死。

劉述
[
编辑
]

按《宋史劉述傳》：「述字孝叔，湖州人。舉進士，為御史臺主簿，知溫、耀、真三州，提點江西刑獄，累官都官員外郎。神宗立，召為侍御史，兼判刑部。安石爭謀殺刑名，述不為是。及敕下，述封還中奏，執不已。安石白帝，詔開封府推官王克臣劾述罪。於是述率御史劉琦、錢顗共疏安石首建財利，務為容悅，願早罷逐，以慰安天下元元之心。」乃貶為通判。帝不許，以知江州。踰歲，
提舉崇禧觀，卒。

按《宋史劉琦傳》：「琦字公玉，宣城人，博學強覽，立志峻潔。以都官員外郎通判歙州，召為侍御史，既貶，通判鄧州而卒。」劉永一
[
编辑
]

按《宋史劉永一傳》：「永一，陝州夏縣人。孝友廉謹。熙寧初，巫咸水溢入縣城，民多溺死。永一持竿立門前，見他人物流入者，輒擿出之。有僧寓錢數萬於其室，無何而僧死，永一詣縣，出言請以錢歸其弟子。鄉人負債不肯償，立焚其券。行事類此。兄大為醫助教，居親喪，不飲酒食肉，終三年。」司馬光傳之，以為今士大夫
所難。

劉彝
[
编辑
]

按《宋史劉彝傳》：「彝字執中，福州人。幼從胡瑗學，瑗稱其善治水，凡所立綱紀規式，彝力居多。第進士，為邵武尉，調高郵簿，移胊山令。熙寧初，為制置三司條例官。屬以言新法非便罷。神宗擇水官，以彝悉東南水利，除都水丞，為兩浙轉運判官，知處州，加直史館，知桂州。交阯陷欽、廉、邕三州，除名為民。元祐初，復以都」水丞召還，病卒於道。

劉紹能

按《宋史劉紹能傳》：「紹能，字及之，保安軍人。世為諸族巡檢。父懷忠，元昊叛，力戰死。錄紹能右班殿直，為軍北巡檢，擊破夏人。熙寧中，累遷英州刺史，鄜延兵馬都監。元豐西討，命統兩軍進討。紹能世世邊將，為敵所忌，每設疑以間之。帝獨明其不然。守邊圉四十七年，大小五十戰，以皇城使、簡州團練使卒。」劉仲武
[
编辑
]

按《宋史劉仲武傳》：「仲武，字子文，秦州成紀人。熙寧中，為涇原將，遷皇城使，復湟川，進東上閤門使，知河州。吐蕃趙懷德、狼阿章叛，仲武遣二將伏兵敗之，復西寧州。未幾，懷德、阿章降，累進客省使、滎州防禦使，副高永年西征。永年敗，仲武自劾，以為西寧都護。童貫招誘羌王子僕哥，僕哥索質，仲武即遣子錫往挈與」歸，貫掩其功，仲武亦不自言。徽宗訪得之。子九人，悉
命以官，錫，閤門祗候。仲武歷拜瀘州軍節度使，以老，
提舉明道宮，再起為熙州，卒於官。

劉奉世
[
编辑

按《宋史劉敞傳》：「敞子奉世，字仲馮，天資簡重，有法度，中進士第。熙寧三年，以太子中允居吏房，改刑房，進直史館。元祐初，歷度支左司郎中、起居郎。七年，拜樞密直學士。章惇當國，乞免去。紹聖元年，以端明殿學士知成德軍，改定州。踰年，知成都府，貶隰州團練副使。徽宗立，盡還其官職。崇寧初，再奪職，以赦得歸。政」和三年，復端明殿學士，薨。

劉民先
[
编辑
]

按《萬姓統譜》：民先字聖任，其先崇安人。五世祖幹，當
五季之亂，避地入閩，遂居崇安之五夫里。熙寧初，累
與計，偕至禮部，輒不合，慨然曰：「吾親老矣，不可闕養。」於是屏居潭溪，作一枝堂，朝夕奉養唯謹。後以特奏
釋褐，民先謂人曰：「吾豈貪一命者哉？願因是可榮親耳。」及母暨夫人年九十，果以恩封崇安縣太君，時以
為榮。

「今觀疏駁者之設意，大與古人用心不同，從古惟聞死中求生，不聞生中求死，托疾而歸。」劉航
[

===劉正夫===
​
按《宋史劉正夫傳》：「正夫，字德初，衢州西安人，為太學錄、太常博士。母服闋，御史中丞石豫薦之，除左司諫，遷中書舍人，進給事中，禮部侍郎。蔡京據相位，正夫附翼之。京罷，正夫又與鄭居中陰援京。京憾劉逵次骨，而逵善正夫。京雖賴其助，亦惡之，出之成都，入辭，留為翰林學士，京愈不能平。中以事，改龍圖閣直學」士、知河南府，召為工部尚書，拜右丞，進中書侍郎。政

民，徽猷閣待制。

按《宋史劉豫傳》：「豫字彥游，景州阜城人也。世業農。豫始舉進士，政和二年，召拜殿中侍御史。二和六年，除河北提刑。金人南侵，豫棄官避亂。建炎二年，用張慤薦，除知濟南府。時盜起山東，豫不願行，執政惡之，不許，豫忿而去。是冬，金人攻濟南，啗豫以利，豫懲前忿，遂納款。兀術徙豫知東平府。四年，冊為皇帝，國號大齊，都大名府。」紹興二年，豫遷都汴，因奉祖考於宋太
廟。是日，暴風捲旗，屋瓦皆震，士民大恐。四年，豫聞岳
飛取襄、鄧，遂乞師於金人，分道南侵。帝親征豫，告急
於金主亶，金主遣兀術提兵黎陽以觀釁。豫籍民兵
三十萬，分三道入寇：子麟總中路，猊東路。楊沂中遇
猊兵藕塘，大破之，猊遁，麟聞，亦拔砦走。金人聞敗，詰
豫罪狀，有廢豫意。金主先令撻辣兀術偽稱南侵，至
汴，宣詔責豫，以鐵騎數千圍宮門，迫之行，併其子麟
徙於臨潢，封豫為曹王。紹興十三年卒。
