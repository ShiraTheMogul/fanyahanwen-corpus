劉懷肅
[
编辑
]

按《宋書劉懷肅傳》，「懷肅，彭城人，高祖從母兄也。初為寧朔府司馬，聞高祖起義來奔，以功封東興縣侯。義熙三年卒，無子，弟懷慎以子蔚祖嗣。蔚祖卒，子道存嗣。景和中，為義恭從事中郎。義恭敗，以黨與下獄死。懷肅次弟懷敬，金紫光祿大夫。懷敬子真道，為梁、南秦二州刺史。元嘉十八年，氐賊楊難當侵寇漢中，真」道討破之。坐破仇池，斷割金銀諸雜寶貨，下獄死。

劉懷慎
[
编辑
]

按《宋史劉懷慎傳》，「懷慎，彭城人，左將軍懷肅弟也。少謹慎質直。始參高祖軍事，屢戰克捷，加輔國將軍。義熙十一年，進北中郎將，封南城縣男。十三年，高祖北伐，以為中領軍，徵為度支尚書。永初元年，以佐命功，進爵為侯。景平元年，遷護軍將軍。二年卒，諡曰肅侯。子德願嗣。永光中，為廷尉，與柳元景厚善，元景敗，下」獄誅。懷慎庶長子榮祖，以戰功賜爵都鄉侯。德願弟
興祖，青州刺史。懷慎弟懷默，江夏內史。懷默子道球，
巴東、建平二郡太守。道球弟孫登，武陵內史。孫登子
亮，梁益二州刺史。孫登弟道隆，歷衛將軍、中護軍，賜
死。

劉道憐
[
编辑
]

按《宋書長沙景王道憐傳》：「道憐，高祖中弟也。義熙元年，領堂邑太守，戍石頭。明年，封新興縣五等侯。江陵平，以為荊州刺史。高祖受命，封長沙王。永初三年薨。六子：義欣、義慶、義融、義宗、義賓、義綦、義欣嗣。元嘉十六年薨，諡曰成。子瑾，字彥瑜，官至太子屯騎校尉，為元凶所殺。子粲，早夭。粲弟纂，官至步兵校尉。瑾弟祗」，
謀應晉安王子勛為逆，伏誅。祗弟楷，祕書郎，為元凶
所殺。楷弟瞻，與子勛同逆，伏誅。瞻弟韞，謀反，伏誅。韞
弟弼，亦與子勛同逆，伏誅。弼弟鑑，員外散騎侍郎，早
卒。鑑弟勰，字彥龢，吳興太守。勰弟顥，字彥明，左衛將
軍。顥弟述，黃門郎，與從弟秉同逆，伏誅。義融封桂陽
縣侯，卒，子覬嗣，為元凶所殺。無子，弟襲以子晃繼封
​
謀反，國除。襲字茂德，封臨灃縣侯。卒，子旻嗣。襲弟彪、
寔並早卒。寔弟爽，海陵太守。義宗幼為高祖所愛，字
曰「伯奴」，賜爵新渝縣男。卒，子玠嗣，為元凶所殺。無子，
弟秉以子承繼封。秉字彥節，歷任為尚書令，與袁粲
謀攻齊王，事覺，與二子承俁並死。秉弟謨，謨弟遐，字
彥道，官吳郡太守。義賓，封新野縣侯。卒，子綜嗣。卒，子
憲嗣。綜弟琨，晉平太守。義綦，封營道縣侯。卒，子長猷
嗣。

劉道規
[
编辑
]

按《宋書臨川烈武王道規傳》：「道規字道則，高祖少弟也。少倜儻有大志，高祖奇之。桓元時，桓弘鎮廣陵，高祖克京城，道規亦以其日與劉毅共斬弘，收眾濟江，進平京邑，以為義昌太守，封華容縣公，遷使持節都督荊寧秦梁雝六州司州之河南諸軍事，領荊州刺史。義熙八年薨。高祖受命，追封臨川王。無子，以長沙」景王第二子義慶為嗣。永初元年，襲封臨川王。性簡
素，足為宗室之表。元嘉二十一年薨。子煜，字景舒，為
元凶所殺。子綽，字子流，昇明三年反，伏誅，國除。

劉遵考
[
编辑
]

按《宋書營浦侯遵考傳》：「遵考，高祖族弟也。曾祖淳，祖巖，父涓子。遵考始為振武參軍，隨高祖北伐南還，除遊擊將軍。高祖即位，封營浦縣侯。景和元年，出督南豫州諸軍事。太宗即位，以為侍中。元徽元年卒，諡曰元公。子澄之。澄之弟琨之為竟陵王誕主簿。誕作亂，以為中兵參軍，不就，殺之。遵考從弟思考，歷清顯，泰」始元年，卒於散騎常侍、金紫光祿大夫。

劉穆之
[
编辑
]

按《宋書劉穆之傳》，「穆之字道和，小字道民，東莞莒人，漢齊悼惠王肥後也。世居京口，少好書傳，博覽多通。高祖克京城，須府主簿，馳信召焉。從平京邑，諸大處分皆倉卒立定，遂委以心腹之任，動止咨焉。穆之亦竭節盡誠，無所遺隱。遷尚書祠部郎，領堂邑太守。高祖入輔，從征廣固，還拒盧循，常居幕中畫策，決斷眾」事。轉中軍太尉司馬，遷尚書右僕射。穆之內總朝政，
外供軍旅，決斷如流，事無擁滯。性奢豪，食必方丈，旦
輒為十人饌。好賓客，未嘗獨餐。十三年卒，追封南康
郡公，諡曰文宣。子慮之嗣。卒，子邕嗣。邕嗜食瘡痂，以
為味似鰒魚。卒，子彤嗣。大明四年，以弟彪紹封。穆之
中子式之，字延叔，累遷至左衛將軍、吳郡太守，卒，諡
曰恭。子敳。敳弟衍。衍弟瑀，字茂琳，為吏部尚書，卒，諡
曰剛。子卷，南徐州別駕。卷弟藏，尚書左丞。穆之少子
貞之，寧朔將軍、江夏內史，卒官。子裒，始興相。

劉敬宣
[
编辑
]

按《宋書劉敬宣傳》，「敬宣字萬壽，彭城人，漢楚元王交後也。祖建，征鹵將軍。父牢之，鎮北將軍。敬宣起家為王恭參軍。隆安三年，王恭起兵於京口，牢之時為恭前軍司馬，遣敬宣率高雅之等還京襲恭，恭一時散潰。元顯以敬宣為諮議參軍。元興元年，南討桓元。牢之以道子昏闇，元顯淫凶，慮平元之日，亂政方始，假手於元，誅除執政，然後乘元之隙，可得志於天下。」詣
元降，元以牢之為征東將軍。牢之與敬宣謀共襲元，
期以明旦。值大霧，府門晚開。日旰，敬宣不至，牢之自
縊死。敬宣奔洛陽，又奔鮮卑慕容德。會高祖平京口，
手書召敬宣。敬宣還，以為輔國將軍、晉陵太守。遷建
威將軍、江州刺史，尋除冠軍將軍。義熙五年，高祖伐
鮮卑，除中軍諮議參軍，從擊，大破之。出為使持節、督
北青州軍郡事、北青州刺史，尋領冀州司馬。道賜者，
晉宗室之賤屬也，為敬宣參軍，謀反，殺敬宣子祖嗣。

劉鍾
[
编辑
]

按《宋書劉鍾傳》，「鍾字世之，彭城人也。隆安四年，高祖伐孫恩，鍾從攻句章、海鹽、婁縣，皆摧堅陷陣，有戰功，甚見愛信。義旗將建，版鍾為郡主簿，轉鎮軍參軍。桓歆寇歷陽，鍾助魏詠之討之。除南齊國內史，封安縣五等侯，除振武將軍，領廣川太守。盧循逼京邑，鍾率麾下拒賊。循南走，鍾追斬之。補寧朔將軍、下邳太守」，
領石頭戍事。隨朱齡石伐蜀，為前鋒。平成都，封永新
縣男，遷給事中、太尉參軍事、龍驤將軍，領石頭戍事。
十二年，高祖北伐，復留鎮居守。元熙元年卒，子敬義
嗣，官至馬頭太守。卒，子國重嗣，齊受禪，國除。鍾次子
高昌男敬順卒，子國須嗣。卒，無子，國除。

劉榮祖
[
编辑
]

按《南史劉懷肅傳》，懷肅弟懷慎，庶長子榮祖，少好騎
射，為武帝所知。及盧循攻逼，時賊乘小艦入淮拔柵，
武帝宣令三軍不得輒射賊，榮祖不勝憤怒，冒禁射
之，所中應弦而倒，武帝奇焉。以戰功參太尉軍事，從
討司馬休之，陷陣身被數創。及帝北伐，轉鎮西中兵
參軍，大破魏軍于半城。帝大享將士，謂榮祖曰：「卿以寡剋眾，攻無堅城，雖古名將，何以過此。」永初中，為輔
國將軍，追論半城功，賜爵都鄉侯。榮祖為人輕財貴
義，善撫將士。卒於官。

劉義真
[
编辑
]

按《宋書廬陵孝獻王義真傳》：「義真初封桂陽縣公。及關中平定，高祖以義真行都督事，委以關中之任。沈田子既殺王鎮惡，王修又殺田子。義真年少，賜與左右不節，修常裁減之。義真使左右殺修，人情離駭。高祖使義真輕兵疾歸，永初元年，封廬陵王。高祖崩，徐羨之等以少帝失德，密謀廢立，次第應在義真。以義」真輕訬，不任社稷，因奏廢之，殺於徙所。無子，太祖以
第五子紹為嗣，襲封廬陵王。無子，以南平王鑠第三
子敬先為嗣，為前廢帝所害。無子，太宗泰始元年，以
世祖子晉熙王子輿字孝文為紹嗣，為太宗所殺，更
以桂陽王休範子德嗣紹後。廢帝元徽二年，與休範
俱伏誅，國復絕。三年，復以臨澧忠侯襲。子暠，字淵華。
繼紹又無子，國除。

劉義恭
[
编辑
]

按《宋書江夏文獻王義恭傳》：「義恭，高祖子。元嘉元年，封江夏王。九年，徵為南兗州刺史，鎮廣陵。十六年，進位司空。二十七年，魏人寇豫州，太祖以義恭總統群帥，出鎮彭城。魏退，義恭震懼，不敢追降，號驃騎將軍。元凶肆逆，世祖入討，義恭單馬南奔。世祖即祚，授太尉，錄尚書六條事。世祖嚴暴，義恭慮不見容，乃卑詞」曲意，盡禮祗奉。前廢帝即位，狂悖無道。義恭等謀欲
廢立。永光元年，廢帝率羽林兵於第害之。

劉義康
[
编辑
]

按《宋書彭城王義康傳》：「義康年十二，高祖入輔，代鎮壽陽。永初元年，封彭城王。元嘉三年，授都督荊湘等八州軍事，荊州刺史。義康少而聰察，及居方任，職事修理。六年，與王弘共輔朝政。弘既多疾，且每事推謙，自是內外眾務一斷之。義康由是朝野輻輳，勢傾天下。十七年，收劉湛等，義康上表遜位，改授江州刺史」，
出鎮豫章。二十二年，范蔚宗謀反，事逮義康，免為庶
人。二十八年，賜死，葬安成。六子：允肱、珣、昭方、曇辨。允
初封泉陵縣侯，食邑七百戶。昭方並早夭，允等留安
成，元凶得志，遣殺之。方字阜陵。

劉義宣
[
编辑
]

按《宋書南郡王義宣傳》：「義宣元嘉元年封竟陵王，出為荊州刺史。元凶弒立，義宣即時起兵。世祖即位，改封南郡王。在鎮十年，兵強財富，臧質陰有異志，欲假手為亂，以成其奸。密說義宣，孝建元年舉兵反。上遣豫州刺史王元謨擊敗之。義宣西奔至江陵，竺超民迎之。義宣不復自立，將士逃散，超民載送獄自盡。子」十八人，愷、恢、惔、惇並於江陵墓所賜死，餘並為朱修
之所殺。恢字景度，拜世子，為右衛將軍。義宣反，恢子
善藏與恢俱死。愷字景穆，封宜陽縣侯，恢封臨武縣
侯，悰封湘南縣侯，憬封祁縣侯。

劉湛
[
编辑
]

按《宋書劉湛傳》，「湛字弘仁，南陽涅陽人也。祖耽，父柳，並晉左光祿大夫。湛出繼伯父淡，襲封安眾縣五等男。高祖領鎮西將軍，以湛為功曹。高祖入受晉命，以第四子義康留鎮壽陽，湛為長史。廬陵王義真出為南豫州，湛又為長史。景平元年，召拜尚書吏部郎，遷右衛將軍。江夏王義恭鎮江陵，以湛為持節南蠻校」尉，領撫軍長史。先是，王華既亡，曇首又卒，領軍將軍
殷景仁以時賢零落，白太祖徵湛。八年，召為太子詹
事。湛與景仁素款，又以其建議徵之，甚相感說。及俱
被時遇，猜隙漸生，以景仁專管內任，謂為間己。時彭
城王義康專秉朝權，而湛昔為上佐，遂以舊情委心
自結，欲因宰相之力，傾出景仁，獨當時務，上不能平，
嘗謂所親曰：「劉班初自西還，吾與語，嘗看日早晚，慮其當去；比入，吾亦看日早晚，慮其不去。」湛小字班虎，
故云班也。十七年，詔收付廷尉。子黯及二弟亮、儼並
從誅。

劉瑜
[
