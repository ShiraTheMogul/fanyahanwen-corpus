皇清十二

舒獻臣妻余氏
[
编辑
]

按南昌郡乘余氏，靖安廩生舒獻臣妻。臣「亡守節，中丞表其閭。」
盛氏女
[
编辑
]

按《南昌郡乘》盛氏女，字善才，仁和盛文郁女孫也。許聘同邑潘有成，未歸而有成亡，女奔赴，會水沒，漂其屍，女痛絕，矢志不嫁。招有成魂葬之，歲時祭，必慟哭。撫弟遺孤如海、如江，俱克成立。年七十卒，葬石窩山。

祝氏女
[
编辑
]

按《南昌郡乘》祝氏女，寧州人。許聘同里盧榮，年二十未歸。榮病革，女聞欲往視，家人阻之，不聽。榮沒，女斷一指，自誓立嗣。撫之日勤紡績，屏足不出戶庭。一日謂諸婦曰：「我將浴，若等且去。」 浴竟更衣，無疾而逝。至今稱其墓為「貞女墳。」
蔣氏女
〈嫂陳氏附〉
[
编辑
]

按《南昌郡乘》，蔣氏女，名愛貞，武寧人。幼納徐貢陳聘未歸而貢陳亡。愛貞破鏡從葬，誓不適人。富民爭欲娶之，兩訟於官，俱不能奪。兄曰貴早世，嫂陳年十九，與愛貞同志。窮簷茅屋，紡績相依，里人爭羨之。蔣年六十七，陳年六十五終。

黃良輔妻謝氏
[
编辑
]

按《南昌郡乘》謝氏，南昌黃良輔妻。年二十夫亡，孀居撫孤，歷五十年。《直指》旌其廬。

胡桂萼妻熊氏
〈姪婦周氏附〉
[
编辑
]

按《南昌郡乘》熊氏，南昌諸生胡桂萼妻。年二十喪夫，食貧守志，五十年如一日，戚里憐之。桂萼姪良煃妻周氏，亦年十九夫亡，孀居垂老，冰蘗自持，與熊無異。

陳基通妻鄧氏
[
编辑
]

按《新建縣志》：「鄧氏，陳基通妻。嫁踰年，夫沒。氏年十八，矢志不渝，日勤針黹，博升斗以養老姑。凡其夫生平未竟之事，皆拮据成之。立姪孫以主宗祀，俾不墜家聲。」
熊登獻妻聶氏
[
编辑
]

按《新建縣志》：「聶氏，文學熊登獻妻。獻早死，聶甘貧守節，撫三子成立。年八十九卒。」
涂廷弼妻羅氏
[
编辑
]

按《新建縣志》：羅氏，諸生涂廷弼妻。年十九，夫亡，子幼家貧，父母欲奪其志，羅以死誓令歸。羅曰：「未亡人，不客宿，餓死當與翁姑共耳。」 嗣是日食糠秕，以饘粥奉二親，鄉族咸苦其節。後家亦稍裕，會歲饑，煮粥以餉。年九十一卒。

程泗源妻熊氏
[
编辑

按《新建縣志》：「熊氏，程泗源妻。夫早亡，氏方妊八月，生子，黻撫之，長延師課之。後舉丁酉孝廉，手口卒。瘏教五孫皆成立。」
劉良鎮妻熊氏
[
编辑
]

按《新建縣志》：「熊氏，劉良鎮妻。良鎮慷慨有大志，早亡。熊年二十四，矢志自守，茹苦如飴。壬子，氏臥病，子思敬方試，熊歷言闈中得失，謂思敬必售。後揭曉果然。逾月卒，遠近異之。」
歐陽吉生妻王氏
[
编辑

按《新建縣志》：「王氏，文學歐陽吉生妻，古田王公錫女。夫病，王年十八，刲股進之，請以身代。及沒，絕粒數日。家人以姑老無子，勸之，乃強起，立伯氏次子為後。經年，足不踰閫，後病終。」
莊維煌妻閔氏
[
编辑

按《新建縣志》：「閔氏，莊維煌妻。事舅姑以孝聞。姑病劇，晨夕禱天，願以身代。尋割股以進，姑賴以復生。後夫病，又賴割股得痊。未幾，夫歿，無嗣，撫姪為後，守之終身。」

胡嶔妻萬氏
〈婦李氏熊氏附〉
[
编辑

按《新建縣志》：「萬氏，胡嶔妻。年二十夫亡，二子皆在襁褓。父母以家貧子幼，勸再適，不從。姑病篤，刲股以愈，直指旌之。長子祖聖娶李氏，次子祖」​

賢娶熊氏，兄弟俱蚤夭，各遺一子，而熊氏子又早殤，熊哭之喪明。二世三孀，戚里咸悼。縣令表其閭。

杜范妻李氏
[
编辑
]

按《新建縣志》：李氏，文學杜范妻。戊子之亂，范挈家避西山，憂悸疾作。李時歸寧，聞報遄歸，晝夜不寢，以侍湯藥。一夕，范與訣曰：「『汝良苦矣，吾素知汝志，老母弱息，惟汝善全』。李慟不能對，欲以死殉。既而曰：『三世一身，孰當其難』？」 遂止。及范沒，李獨扃一室，甘旨而外，自奉僅饘粥而已。兵燹後，圖籍十不一存，族人欲併戶籍以漁利，李曰：「黠奴以我無知，妄詐錢耳。吾習已久，豈能欺乎？」 事遂寢。子稍長，課讀不加姑息。年五十八終。
