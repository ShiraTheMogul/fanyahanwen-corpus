楊處綱
[
编辑
]

按《隋書楊處綱傳》：「處綱，高祖族父也。生長北邊，少習
騎射。在周嘗以軍功拜上儀同。高祖受禪，贈其父鍾
葵為柱國尚書令、義城縣公，以處綱襲焉。授開府，督
武候事，尋為太子宗衛率，轉左監門郎將。後數載，起
授右領軍將軍。處綱雖無才藝，而性質直，在官彊濟，
亦為當時所稱。尋拜蒲州刺史，吏民悅之。進位大將」
軍，後遷秦州總管，卒官，諡曰恭。

楊處樂
[
编辑
]

按《隋書楊處綱傳》：「處綱弟處樂，官至雒州刺史。漢王
諒之反也，朝廷以為有二心，廢錮不齒。」

楊瓚
[
编辑
]

按《隋書滕穆王傳》：「瓚字恆生，一名慧，高祖母弟也。周
世，以太祖軍功，封竟陵郡公，尚武帝妹順陽公主。自
右中侍上士遷御伯中大夫。保定四年，改為納言，授
儀同。瓚羙姿儀，好書愛士，甚有令名，時人號曰『楊三
郎。宣帝即位，遷吏部中大夫，加上儀同。高祖作相，遷
大將軍，尋拜大宗伯，典修禮律，進位上柱國、邵國公』。」
瓚，見高祖執政，群情未一，恐為家禍，陰有圖高祖之
計，高祖每優容之。及受禪，立為滕王。後拜雍州牧，坐
事去牧，以王就第。開皇十一年，從幸栗園，暴薨，時年
四十二。

楊爽
[
编辑
]

按《隋書衛昭王傳》：「爽字師仁，小字明達，高祖異母弟
也。周世，以太祖軍功，封同安郡公，為內史上士。高祖
執政，拜大將軍、秦州總管。未之官，轉授蒲州刺史，進
位柱國。及受禪，立為衛王。尋遷雍州牧，領左右將軍，
俄遷右領軍大將軍。歲餘，進位上柱國，轉涼州總管。
爽美風儀，有器局，治甚有聲，以爽為行軍元帥。遇沙」
缽略可汗於白道，接戰，大破之，高祖大悅。六年，復為
元帥，出合州，突厥遁逃而返。明年，徵為納言，高祖甚
重之。未幾，爽寢疾，上使巫者薛榮宗視之，云「眾鬼為
厲。」爽令左右驅逐之。居數日，有鬼物來擊榮宗，榮宗
走下階而斃。其夜爽薨，時年二十五。贈太尉、冀州刺
史。

楊弘
[
编辑
]

按《隋書河間王傳》，「弘字辟惡，高祖從祖弟也。祖愛敬，
早卒。父元孫，少孤，隨母郭氏養於舅族。及武元皇帝
與周太祖建義關中，元孫時在鄴下，懼為齊人所誅，
因假外家姓為郭氏。元孫死，齊為周所并。弘始入關，
性明悟，有文武幹略，數從征伐，累遷開府儀同三司。
高祖為丞相，委以心腹。高祖詣周趙王宅，將及于難」，
弘以衛高祖。尋加上開府，賜爵永康縣公。及上受禪，
拜大將軍，進爵郡公。其年，立為河間王，拜右衛大將
軍。歲餘，進授柱國，出拜寧州總管，進位上柱國。弘在
州，治尚清淨，甚有恩惠。後數載，徵還京師。未幾，拜蒲
州刺史。在官十餘年，風教大洽。煬帝嗣位，徵還，拜太
子太保。歲餘薨。大業六年，追封郇王。

楊子崇
[
编辑
]

按《隋書楊子崇傳》：「子崇，高祖族弟也。父盆生，贈荊州

刺史。子崇少好學，開皇初，拜儀同，以車騎將軍恆典
​
宿衛。後為司門侍郎。煬帝嗣位，累遷候衛將軍，坐事

免。未幾，復令檢校將軍事。從帝幸汾陽宮，出為離石
郡太守，治有能名。朔方梁師都、馬邑劉武周等各稱
兵作亂，子崇患之，將還京師，輜重半濟，遇河西諸縣」，
各殺長吏，叛歸師都，道路隔絕，子崇退歸離石。後數
日，義兵夜至城下，城中豪傑復出應之。城陷，子崇為
讎家所殺。

楊勇
[
编辑
]

按《隋書房陵王傳》，「勇字睍地伐，高祖長子也。周世以
太祖軍功封博平侯。及高祖輔政，立為世子，拜大將
軍、左司衛，封長寧郡公。出為雒州總管、東京小冢宰，
總統舊齊之地。後徵還京師，進位上柱國、大司馬，領
內史御正。高祖受禪，立為皇太子。勇頗好學，解屬詞
賦，性寬仁和厚，率意任情，無矯飾之行。勇嘗文飾蜀」
鎧，上見而不悅，恐致奢侈之漸。勇多內寵，昭訓、雲氏
尤稱嬖幸。勇妃元氏無寵，嘗遇心疾，二日而薨。獻皇
后意有他故，甚責望勇。自是雲昭訓專擅內政，后彌
不平，頗遣人伺察，求勇罪過。晉王知之，彌自矯飾，皇
后由是薄勇，愈稱晉王德行。其後晉王知皇后意移，
始構奪宗之計，因引張衡定策，遣褒公宇文述深交
楊約，令喻旨于越國公素。勇頗知其謀，憂懼，計無所
出，於後園作庶人村，屋宇卑陋，時於中寢息，布衣草
褥，冀以當之。高祖使楊素觀勇，素還，言勇怨望皇后，
又遣人伺覘東宮，構成其罪。高祖惑於邪議，遂疏忌
勇，廢為庶人，移于內史省。立晉王廣為皇太子，仍以
勇付之，復囚於東宮。高祖寢疾於仁壽宮，徵皇太子
入侍醫藥，而姦亂宮闈，事聞於高祖。高祖抵床曰：「枉
廢我兒。」因遣追勇。未及發使，高祖暴崩，祕不發喪，偽
為高祖《敕書》，賜庶人死，追封房陵王，不為立嗣。勇有
十男雲：昭訓生長寧王儼、平原王裕、安城王筠，高良
娣生安平王巖、襄城王恪，王良媛生高陽王該、建安
王韶，成姬生《潁川王煚》，後宮生孝實、孝範。

楊俊
[
编辑
]

按《隋書秦孝王傳》：「俊字阿祗，高祖第三子也。開皇元
年，立為秦王，拜上柱國、河南道行臺尚書令、雒州刺
史，加右武衛大將軍。三年，遷秦州總管。俊仁恕慈愛，
崇敬佛道。六年，遷山南道行臺尚書令。伐陳之役，以
為山南道行軍元帥。陳將周羅㬋降，授揚州總管，四
十四州諸軍事，鎮廣陵。歲餘，轉并州總管、二十四州」
諸軍事。初頗有令問，後漸奢侈，違犯制度，出錢求息，
民吏苦之。遇疾，徵還京師，上以其奢縱，免官，以王就
第。俊慚怖，疾篤，復拜上柱國。二十年六月，薨於秦邸。
子浩庶子曰湛。煬帝即位，立浩為秦王，以奉孝王嗣。
封湛為濟北侯，後以浩為河陽都尉。楊元感作逆之
際，左翼衛大將軍宇文述勒兵討之，至河陽，修啟於
浩，浩復詣述營，兵相往復。有司劾浩以諸侯交通內
臣，竟坐廢免。宇文化及殺逆之始，立浩為帝。化及自
僭偽號，因而害之。湛驍果，有膽烈。大業初，為滎陽太
守，坐浩免，亦為化及所害。

楊秀
[
编辑
]

按《隋書庶人秀傳》：「秀，高祖第四子也。開皇元年，立為
越王。未幾，徙封於蜀，拜柱國、益州刺史，總管二十四
州諸軍事。二年，進位上柱國、西南道行臺尚書令，歲
餘而罷。十二年，又為內史令、右領軍大將軍，尋復出
鎮於蜀。秀有膽氣，多武藝，甚為朝臣所憚。及太子勇
以讒毀廢晉王廣為皇太子，秀意甚不平。皇太子恐」
秀終為後變，陰令楊素求其罪而譖之。仁壽二年，徵
還京師，付執法者治之。太子陰作偶人書，上及「漢王」
字姓，縛手釘心，令人埋之華山下，令楊素發之。又作
《檄文》，指期問罪，置《秀集》中。因以聞。于是廢為庶人，幽
內侍省，不得與妻子相見，後復聽與其子同處。煬帝
即位，禁錮如初。宇文化及之弒逆也，欲立秀為帝，群
議不許，于是害之，并其諸子。

楊諒
[
编辑
]

按《隋書庶人諒傳》：「諒字德章，一名傑。開皇元年，立為
漢王。十二年為雍州牧，加上柱國右衛大將軍。歲餘，
轉左衛大將軍。十七年，出為并州總管。遼東之役，以
諒為行軍元帥，遇疾疫，不利而還。以太子讒廢，居常
怏怏，陰有異圖。王頍者，梁將王僧辯之子也，少倜儻，
有奇略，為諒咨議參軍。蕭摩訶者，陳氏舊將。二人俱」
不得志，每鬱鬱思亂，並為諒所親善。及蜀王以罪廢，
諒愈不自安。會高祖崩，徵之不赴，遂發兵反。楊素擊
之，諒窮蹙，降于素。百寮奏諒罪當死，帝曰：「朕終鮮兄
弟，情不忍言。」欲屈法恕諒一死。於是除名為民，絕其
屬籍，竟以幽死。子顥因而禁錮。宇文化及弒逆之際
遇害。

楊綸
〈弟坦　猛　溫　詵〉
[
编辑
]

按《隋書膝穆王瓚傳》：「瓚薨，子綸嗣。綸字斌籀，性弘厚，
美姿容，頗解鍾律。高祖受禪，封邵國公，拜邵州刺史。
綸以穆王之故，當高祖之世，每不自安。煬帝即位，尤
被猜忌。綸憂懼不知所為，呼術者王琛而問之。有沙
​
門惠恩、崛多等頗解占候，綸每與交通，常令此三人
為度星法。有人告綸怨望咒詛，除名為民，徙始安，諸」
弟散徙邊郡，大業七年，復徙朱崖。及天下大亂，為賊
林士弘所逼，攜妻子竄于儋耳，後歸大唐，為懷化縣
公。綸弟坦，字文籀，初封竟陵郡公，坐綸徙長沙。坦弟
猛，字武籀，徙衡山。猛弟溫，字明籀，初徙零陵。溫好學，
解屬文，既而作《零陵賦》以自寄，其辭哀思，帝見而怒
之，轉徙南海。溫弟詵，字弘籀，前亦徙零陵。帝以其修
謹，襲封滕王，以奉穆王嗣。大業末，薨於江都。

楊靜
[
编辑
]

按《隋書道悼王傳》：「靜字賢籀，滕穆王瓚之子也。出繼
叔父嵩。嵩在周代，以太祖軍功，賜爵興城公，早卒。高
祖踐位，追封道王，諡曰宣，以靜襲焉。卒，無子，國除。」

楊集
[
编辑
]

按《隋書衛昭王爽傳》：「爽薨，子集嗣。集字文會，初封遂
安王，尋襲封衛王。煬帝時，諸侯王恩禮漸薄，猜防日
甚，集憂懼不知所為，乃呼術者俞普明章醮，以祈福
助。有人告集咒詛，于是除名為民，遠徙邊郡。遇天下
大亂，不知所終。」

楊智積
[
编辑
]

按《隋書蔡王傳》：「智積，高祖弟整之子也。整，周明帝時
以太祖軍功，賜爵陳留郡公，尋授開府車騎大將軍，
從武帝平齊，至并州，力戰而死。及高祖受禪，追封蔡
王，諡曰景，以智積襲焉。又封其弟智明為高陽郡公，
智才為開封縣公。尋拜智積為開府儀同三司，授同
州刺史，以修謹聞。開皇二十年，徵還京第，無他職任」，
闔門自守，非朝覲不出。大業七年，授弘農太守，委政
寮佐，清淨自居。及楊元感作亂，軍至城下，智積登陣
詈辱之。宇文述等援軍至，合擊破之。十二年，從駕江
都，寢疾。帝時疏薄骨肉，智積每不自安。及遇患，不呼
醫。臨終謂所親曰：「吾今日始知得保首領沒於地矣。」
時人哀之。有子道元。

楊雄
[
编辑
]

按《隋書觀德王傳》：「雄初名惠，高祖族子也。父納，仕周，
歷八州刺史、儻城縣公，賜姓叱呂引氏。雄美姿儀，有
器度，雍容閑雅，進止可觀。周武帝時，為太子司旅下
大夫。帝幸雲陽宮，衛王直作亂，雄逆拒破之，進位上
儀同，封武陽縣公，累遷右司衛上大夫。大象中，進爵
邗國公。高祖為丞相，雍州牧、畢王賢謀作難，雄知其」
謀，以告高祖，賢伏誅。以功授柱國、雍州牧，進位上柱
國。高祖受禪，除左衛將軍，遷右衛大將軍，參預朝政。
進封廣平王。雄寬容下士，朝野傾矚。高祖惡其得眾，
陰忌之。不欲其典兵馬，乃拜為司空。雄無職務，乃閉
門不通賓客。尋改封清漳王。仁壽初，改封安德王。大
業初，授太子太傅、懷州刺史，尋拜京兆尹。帝親征吐
谷渾，詔雄總管澆河道諸軍。及還，改封觀王。遼東之
役，檢校左翊衛大將軍，出遼東道，次瀘河鎮，遘疾而
薨，時年七十一。賜諡曰德，贈司徒、襄國武安渤海清
河上黨河間濟北高密濟陰長平等十郡太守。子恭
仁，位至吏部侍郎。恭仁弟綝，性和厚，頗有文學，歷義
州刺史、淮南太守、司隸大夫。綝弟續，仕至散騎侍郎。

楊達
[
编辑
]

按《隋書觀德王雄傳》：「雄弟達，字士達，少聰敏，有學行。
仕周，官至儀同內史下大夫、遂寧縣男。高祖受禪，拜
給事黃門侍郎，進爵為子。時吐谷渾寇邊，詔上柱國
元楷為元帥，達為司馬。軍還，加開府。歲餘，轉內史侍
郎，出為鄯、鄭、趙三州刺史，俱有能名。平陳之後，擢拜
工部尚書，加位上開府。煬帝嗣位，轉納言。遼東之役」，
領右武衛將軍，進位左光祿大夫。卒于師，時年六十
二。贈吏部尚書、始安侯，諡曰「恭。」

楊慶
[
编辑
]

按《隋書河間王弘傳》，「弘薨，子慶嗣。慶傾曲善候時變，
累遷滎陽太守，頗有治績。及李密據洛口倉，滎陽諸
縣多應密，慶勒兵拒守，歲餘，城中糧盡，兵勢日蹙。密
因遺慶書，慶遂降于密，改姓郭氏。密為王世充所破，
復歸東都，更為楊氏，越王侗不之責也。及侗稱制，拜
宗正卿。世充將篡，慶首為勸進。世充既僭偽號，降爵」
郇國公。慶復為郭氏。世充以兄女妻之，署滎州刺史。
及世充將敗，慶欲將其妻同歸長安。其妻謂之曰：「國
家以妾奉箕箒於公者，欲以申厚意，結公心耳。今公
不顧婚姻，孤負付屬，為全身之計。妾願得送還東都，
君之惠也。」慶不許，其妻遂仰藥而死。慶歸大唐，為宜
州刺史、郇國公，復姓楊氏。其嫡母元太妃王世充以
慶叛己而斬之。

稱「護兒反。」元感遂入黎陽縣，閉城，大索男夫，以「討護
兒」為名，各令發兵，從亂者如市。河南贊治裴弘策拒
之，戰敗，遂進逼都城。帝遣武賁郎將陳稜、武衛將軍
屈突通、左翊衛大將軍宇文述發兵繼進，護兒復來
赴援，元感軍頻北，宇文述等諸軍躡之，至弘農宮，留
攻之三日，城不下。追兵至，元感獨與十餘騎竄林木
間，至葭蘆戍，窘迫，獨與弟積善步行，謂積善曰：「我不
能受人戮辱，汝可殺我。」積善抽刀斫殺之，因自刺不
死，為追兵所執，與元感首俱送行在所，磔其屍于「東
都市。」
