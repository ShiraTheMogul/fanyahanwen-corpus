早渡蒲津關　　　　　　　　唐元宗
[
编辑
]

「鐘鼓嚴更曙，山河野望通。」鳴鑾下蒲坂，飛斾入秦中。
地險關逾壯，天平鎮尚雄。「春來津樹合，月落戍樓空。馬色分朝景，雞聲逐曉風。」所希常道泰，非復候。

奉和詠日午　　　　　　　　　褚亮
[
编辑
]

曦車日亭午，浮箭未移暉。日光無落照，樹影正中圍。
草萎看稍靡，葉燥望疑稀。晝寢慚經笥，暫解入朝衣。

奉和詠日午　　　　　　　　虞世南
[
编辑
]

高天淨秋色，長漢轉曦車。玉樹陰初正，桐圭影未斜。
翠葢飛圓彩，明鏡發輕花。再中良表瑞，共仰璧暉賒。

凌晨早朝　　　　　　　　　　前人
[
编辑
]

萬瓦宵光曙，重簷夕霧收。玉花停夜燭，金壼送曉籌。
日暉青瑣殿，霞生結綺樓。重門應啟路，通籍引王侯。

奉和月夜觀星應令　　　　　　前人
[
编辑
]

《早秋》炎景暮，初弦月彩新。清風滌暑氣，零露淨囂塵。
薄霧銷輕糓，鮮雲卷夕鱗。休光灼前耀，瑞彩接重輪。
緣情摛聖藻，並作命徐陳。宿草誠渝濫，吹噓偶縉紳。
天文豈易述，徒知仰北辰。

野望　　　　　　　　　　　　王績
[
编辑
]

東皋薄暮望，徙倚欲何依。樹樹皆秋色，山山唯落暉。
牧人驅犢返，獵馬帶禽歸。相顧無相識，長歌懷《采薇》。

山夜調琴　　　　　　　　　　前人
[
编辑
]

促軫乘明月，抽弦對白雲。從來山水韻，不使俗人聞。

早行　　　　　　　　　　　　楊炯
[
编辑
]

敞朗東方徹，闌干北斗斜。地氣俄成霧，天雲漸作霞。
河流纔辨馬，巖路不容車。阡陌經三歲，閭閻對五家。
露文沾細艸，風影轉高花。日月從來惜，關山猶自賒。

夜飲東亭　　　　　　　　　宋之問
[
编辑
]

春泉鳴大壑，皓月吐層岑。岑壑景色佳，慰我遠遊心。
暗芳足幽氣，驚棲多眾音。高興《南山曲》，長謠橫素琴。

散關晨度　　　　　　　　　　王勃
[
编辑
]

關山凌旦開，石路無塵埃。白馬《高譚》去，青牛真氣來。
重門臨巨壑，連棟起崇隈。即今揚策度，非是棄繻回。

寒夜思友三首　　　　　　　　前人
[
编辑
]

久別侵懷抱，他鄉變容色。月下調鳴琴，相思此何極？
雲問征思斷，月下歸愁切。鴻雁西南飛，如何故人別。
朝朝翠山下，夜夜蒼江曲。復此遙相思，清尊湛芳綠。

早發苦竹館　　　　　　　　　李嶠
[
编辑
]

合沓巖障深，朦朧煙霧曉。荒阡下樵客，野猿驚山鳥。
開門聽潺湲，入徑尋窈窕。棲鼯抱寒木，流螢飛暗篠。
早霞稍霏霏，曉月猶皎皎。行看遠星稀，漸覺遊氛少。
我行撫《軺傳》，兼得傍林沼。貪翫水石奇，不知川路渺。
徒憐野心曠，詎惻浮年少。方解寵辱情，永言出塵表。

晚景悵然簡二三子　　　　　　前人
[
编辑
]

「楚客秋悲動，梁臺夕望賒。」梧桐稍下葉，山桂欲開花。
氣引迎寒露，光收向晚霞。長歌《白水曲》，空對綠池華。

夜宴安樂公主新宅　　　　　閻朝隱
[
编辑
]

鳳凰鳴舞樂昌年，蠟炬開花夜管絃。半醉徐擊珊瑚
樹，已聞鐘漏曉聲傳。

早期　　　　　　　　　　　韋元旦
[
编辑
]

《震》維芳月季，宸極眾星尊。珮玉朝三陛，鳴珂度九門
​
挈壺分早漏，伏檻耀初暾。北倚蒼龍闕，西臨紫鳳垣。
詞庭草欲奏，溫室樹無言。鱗翰空為忝，長懷聖主恩。

岳州夜坐　　　　　　　　　　張說
[
编辑
]

炎洲苦三伏，永日臥孤城。賴此閒庭夜，蕭條夜月明。
獨歌還太息，幽感見餘聲。江近鶴時叫，山深猿屢鳴。
息心觀有欲，棄知返無名。五十知天命，吾其達此生。

夜宴安樂公主新宅　　　　　　岑羲
[
编辑
]

金牓重樓開夜扉，瓊筵愛客未言歸。銜杯不覺銀河
曙，盡醉那知玉漏稀。

和崔正諫登秋日早朝　　　　沈佺期
[
编辑
]

雞嗚朝謁滿，露白禁門秋。爽氣臨旌戟，朝光暎冕旒。
河宗來獻寶，天子命焚裘。獨負池陽議，言從《建禮》遊。

和韋舍人早朝　　　　　　　　前人
[
编辑
]

閶闔連雲起，巖廊拂霧開。玉珂龍影度，珠履雁行來。
《長樂》宵鐘盡，明光曉奏催。一經推舊德，五字擢英才。
儼若神仙去，紛從霄漢迴。千春奉休曆，分禁喜趨陪。

夜宴安樂公主宅　　　　　　武平一
[
编辑
]

王孫帝女下仙臺，金牓珠簾入夜開。遽惜瓊筵歡正
洽，唯愁銀箭曉相催。

早朝　　　　　　　　　　　　王維
[
编辑
]

「皎潔明星高，蒼茫遠天曙。」槐霧暗不開，城鴉鳴稍去。
始聞高閣聲，莫辨更衣處。銀燭已成行，金門儼騶馭。

山居秋暝　　　　　　　　　　前人
[
编辑
]

「空山新雨後，天氣晚來秋。」明月松間照，清泉石上流。
竹喧歸浣女，蓮動下漁舟。隨意春芳歇，王孫自可留。

和賈舍人早朝大明宮之作　　　前人
[
编辑
]

絳《幘雞》，人送。
〈一作報〉
《曉籌》。尚衣方進翠雲裘。九天閶闔

傍袞龍浮。朝罷須裁五色詔。佩聲歸向鳳池頭。

家園夜坐寄郭微　　　　　　　祖詠
[
编辑
]

前階微雨歇，開戶散窺林。月出夜方淺，水涼池更深。
餘風生竹榻，清露薄衣襟。遇物遂遙歎，懷人滋遠心。
依稀成夢想，影響絕徽音。誰念窮居者，明時嗟陸沈。

[
编辑

夏日南亭懷辛大　　　　　　孟浩然
[
编辑
]

山光忽西落，池月漸東上。散髮乘夕涼，開軒臥閒敞。
荷風送香氣，竹露滴清響。欲取鳴琴彈，恨無知音賞。
感此懷故人，中宵勞夢想。

秋宵月下有懷　　　　　　　　前人
[
编辑
]

秋空明月懸，光彩露霑濕。驚鵲棲未定，飛螢捲簾入。
庭槐寒影疏，鄰杵夜聲急。「佳期曠何許，望望空佇立。」夜歸鹿門歌　　　　　　　　　前人
[
编辑
]

山寺鳴鐘晝已昏，漁陽渡頭爭渡喧。人隨沙路向江
村，余亦乘舟歸鹿門。鹿門月照開煙樹，忽到龐公棲
隱處。巖扉松徑是寂寥，唯有幽人夜來去。

宿業師山房待丁公不至　　　　前人
[
编辑

夕陽度西嶺，群壑倏已暝。松月生夜涼，風泉滿清聽。
樵人歸欲盡，煙鳥栖初定。之子期宿來，孤琴候蘿逕。

閒園懷蘇子　　　　　　　　　前人
[
