薛大義
[
编辑
]

按《漳州府志》：「薛大義，漳浦人。貧賤，力田供子職。父母病篤，割股為羹噉之。沒無以營葬，負土壘石成墳，廬居墓側，人稱其墓為孝子墓。」
姚仲敬
[
编辑
]

按《漳州府志》：「姚仲敬，漳浦人。性至孝，在親側無疾言遽色。父喪，哀毀骨立。家貧養母，結蓑供食。母疾，祈療無應，割股和酒粥紿母食之，疾尋愈。」
方一略　陳貞
[
编辑
]

按《漳州府志》：「方一略，平和人，不知書，家貧力養。母危病，禱於神，割股奉之，而母病愈。又有陳貞者，亦以割股事繼母，著俱為縣令旌獎云。」
王糸弼
[
编辑
]

按《漳州府志》：王糸弼，龍巖人。與同邑林京謀要賊。京
被執死，度力不支，與兄用興匿山中。賊恨其謀，必欲
殺之。糸弼訣於兄曰：「今吾兄弟勢不可以俱全，而父母又年老，吾有子三長矣；兄子尚幼，吾死之。」其兄不
忍。次日糸弼乃私自出，犯賊而死，其兄乃得免。鄉人
以為糸弼能盡弟義也，處義之謂孝。

盧元
[
编辑
]

按《漳州府志》：「盧元，漳浦人。父卒，家貧弗克葬，鬻其子於過客，既授以直而未攜去。一日，元採薪山中，得金二錠以充葬，原直悉還，子得完聚。人以為誠孝動天，其亦埋兒賜金之應云爾。」
林初
[
编辑
]

按《漳州府志》：「林初，長泰人，業農。父適田所，遇虎，初望見，直前以身衛父，虎懼而退，父得全歸，鄉人異之。有司以聞，詔旌其孝，因改其里曰『旌孝』。」
林端
[
编辑
]

按《漳州府志》：「林端，詔安東路人。幼喪母。父娶繼室，生三子，父即沒，端貧窮好學，事繼母孝，御諸弟友。值母衰病彌年，端孝養倍篤，承順親意，甘旨之供，無不備具。母病熱，思食甜瓜，時非瓜期，端遍求諸處，忽獲之，良峰山陽掛錢於園籬中，攜瓜歸進母，母食，病為少瘳。人以為孝感所至。」
蕭壆
[
编辑

按《漳州府志》：「蕭壆，龍溪人，給事中璿之子。性純孝，事三母如一。嫡母陳氏病癰，壆吮之愈。庶母阮氏楚撻，承顏跪受，阮終感悟，慈愛如己出。遇風雨，至父墳哀號。西鄰失火，將及父司諫坊仰天號訴，火遂滅。郡守張鵬以其事聞。」
文盛

编辑

按《福寧州志》：「文盛，字用質。母黃氏疾篤，剪左腕肉糜之以進，粥沸異常，母疑之，不敢以實對，家人亦無知之者，後見腕痕，乃得狀。父嗜鱸，見鱸輒流涕，必致以薦，有終身之慕焉。」
陳照

编辑

按《福寧州志》：「陳照，少孤貧。母病劇，醫弗效，夜籲天乞減己年以延母壽。後刲其胸，取肉調粥以進，母啖而甘之。病痊，照竟以創歿，年二十四。」
林琦
[
编辑

按《福寧州志》：「林琦，字宗韓，州人，思齊子。性純孝，母病，侍湯藥，不解衣履逾月，趾因以腐，緣母病而諳醫。督學者重其行，試居首，攜至省。八郡入試者，命謁琦聽講。舉鄉試，知高淳縣。」
李然
[
编辑
]

按《福寧州志》：「李然，字子炎，州三十五都人。自幼孝謹，父每入城，必出二三里迎之。父雖暮未返，然亦不歸。弱冠時，父患臀瘡，苦甚，然晝夜侍左右，供飲食，遍求醫藥膿汁，手敬承之。父病篤，割股肉和粥，父食之，輕爽。數日，父沒。母晚年病痹，八九年扶持浣滌不少懈。及沒，躬負土石營葬。」

编辑

授僊居訓導，四年以母老歸養。母卒，喪葬盡禮。有鷹
日棲軒樹，人謂孝感所致，扁曰「馴鷹。」

按《福寧州志》：「繆文昺，州人。母陳氏，孀居六旬，疾篤甚，旬日莫能食。文昺告天，割左股煨粥母食即愈。壽八十一。文昺初無子，已立嗣。至五十連生二男，壽亦八十三。」
周珉
[
编辑

按《福寧州志》：「周珉，字勝玉，州人璞之弟。性至孝，少喪父，哀毀如成人，事兄猶事父，日侍兄食，每更衣則親為束帶，解帶至白首以為常。為新昌虹縣學官​陳喜[编辑]按《福寧州志》：「陳喜，字希和，州人。積學能文，而渾樸若椎魯者。早喪父，獨事母至老不衰。母年高多病，喜躬侍母寢，晨昏溫凊，自衣服飲膳櫛髮盥洗，至牏廁瑣猥，未嘗假手他人。兩兒婦謂翁已老，奈何自苦如此，請代之，喜不聽。母年九十四始歿，益服勞二十餘年如一日，喜壽八十。」

周大賢

编辑

按《福寧州志》：「周大賢，五圖人。在妊三月，父亡。成童依依母側不少離，夜必拜斗祝母壽。第世隸戎籍，嘗戍海上，夜哀思，淚漬枕席。當道得其情，為脫籍，且白其母之節，旌之。知州史起欽嘉其孝，厚加賞賚。」
阮貢
[
编辑
]

按《福寧州志》：「阮貢三歲孤。母卓氏力貧守志，貢事之盡孝。母病，湯藥必親嘗，目不交睫者逾月，籲天乞減己壽以延母壽。母八十卒，居喪盡禮，蔬食水飲百餘日，臥起棺旁，朝夕哀慟，群鳥集其屋者三。既葬，刻木為母像，事之如生。有遺髮寶藏，不忍棄所居。延火，貢惟奉母像及遺髮以避，貧益甚，奉像益謹，三十年如」一日。州判李長為之市屋給粟，且躬禮焉。

按《福寧州志》：「林子隱，七都東坑人。事親溫凊定省，承顏順志。居喪哀毀踰常，喪葬以禮，三年不飲酒食肉，哀慕之情，終身不衰。」
李都

编辑

按《福寧州志》：「李都，字世美，廩生。十歲能文，性行端卓，事親曲盡孝養。居喪毀瘠，作哀萱百感，至今讀者悲愴。廬墓梅湖，著有《梅湖集》。」
彭驥
〈弟騰〉
[
编辑

按《福寧州志》：彭驥，字德華，弟騰，字德高，科正之子，異

遠回，驥迓於石壁嶺，相持悲歌交至。驥或鄉歸，情亦
如之。年並八十，終不分異。

按《福寧州志》：「鄭仁，字克己，性純篤，事親孝。年六十喪母。是時父年八十，出入扶持，冬夜以身溫席，夏月揮扇，躬濯廁牏，不離左右，承顏順志。踰八年，父歿，祭葬如禮。」
龔松
[
编辑
]

按《福寧州志》：龔松，字堅夫。數歲喪父母，哀慕不已。稍
長，痛父母嘗罹饑困，繪像懸中堂，每食必先獻之，雖
瓜果之微，不獻。父母不分，其姊不輒食。既冠，或勸其
娶，泣曰：「二親未歸土，忍言娶乎？」越數年，葬畢始娶。兄
死非命，孤姪患惡瘡，躬為扶抱洗滌侍藥。其妻恐相
染，松曰：「兄僅有此子，但得存活，雖相染，命也。」

按《大田縣志》：「郭奇逢，字際時，幼以孝順聞，稟資穎異​過目成誦。數奇不第，膺貢，大廷除授江西饒州通判。政尚仁恕，士民德之。丁父母憂，哀毀骨立，水漿不入口者數日。家人進薄粥一甌，奇逢泣而卻之。終喪獨處一室，不御酒肉。凡六年祀事必齋戒愨謹，墓祭雖遠，必躬與，勿以衰老懈云。」
陳輝世

按《大田縣志》：「陳輝世，邑學生，遭喪遇寇，出父柩於鋒鏑之下，賊被感動，不忍刃，卒全父柩。又嘗遇火災，出母於烈焰中，天為反風。育弟恤憐，名多里閈，府縣舉孝廉。」

按《廣東通志》：「廖貴，事親至孝，不樂從仕，蔬水承歡，家庭藹如，隱居不仕。其子孫皆孝友敦睦，人稱為世孝云。」
陳文蕃
[
编辑
]

按《尢溪縣志》：陳文蕃，三都東華山人。兄卒，止一子，為
鄧賊所執，索重幣，貧無以應。蕃曰：「姪死，兄無後矣。」遂
赴賊壘，賂守者，陰縱其姪，文蕃遇害。今苗裔身列雍
序，足見報施不爽云。

紀大振

编辑

按《尤溪縣志》紀大振，五十都葛竹人。十歲喪父，事母
克盡孝道。母病，藥餌無效，振乃焚香籲天，刲股肉調
羹以進，母病遂痊。事聞，縣令旌曰：「真孝格天。」
朱忠民
[
编辑

按《沙縣志》：朱忠民，事親聚順，繼母弟竊母衣簪以事
摴蒱，母恐父知憂，廢寢食，忠民詢其故，命工如製以
奉，於母無難色。父晚年好施，忠民曲承父志。邑令廉
狀以上，巡按旌曰：「竭力事親，仍給以粟帛。」
官應龍

编辑

按《沙縣志》：官應龍，事母至孝。兄弟五人，應龍居長，以
家自任，竟不分箸，以免弟累。母年八十五卒，哀慟幾
絕，廬墓三年。學諭江梅聞于督學胡，旌曰：「孝友兩全。」
麻育才

编辑

按《沙縣志》：「麻育才，父早逝，母踰九十，旦夕不離左右，忍饑以豐膳。先意承志，敬事兄長，撫育幼弟，還將分產盡讓于弟。邑令康以孝友特旌。」
蕭賓
[
