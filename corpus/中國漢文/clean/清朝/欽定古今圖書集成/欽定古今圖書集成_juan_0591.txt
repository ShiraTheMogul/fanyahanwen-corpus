深秋采之，日「乾和穀。」煮食如苧，清香可愛。

舜芒穀圖

《舜芒穀考》
[
编辑
]

俗名「紅落藜」，生田野及人家舊莊，窠上多有之。科苗
高五尺餘，葉似灰菜葉而大，微帶紅色。莖亦高麤，可
為拄杖。其中心葉甚紅，葉閒出穗，結子如粟米顆，灰
青色，味甜。

救饑

採嫩苗葉曬乾，揉去皮，煠熟，油鹽調食子，可磨麪做
燒餅蒸食。

銀條菜圖

​

《銀條菜考》
[
编辑
]

所在人家園圃多種，苗葉皆似萵苣，長細，色頗青白，
攛葶高二尺許，開四瓣淡黃花，結蒴似蕎麥蒴而圓，
中有小子，如油子大，淡黃色。其葉味微甘，性涼。

救饑

採苗、葉煠熟，水浸淘淨，油、鹽調食，生揉亦可食。

火焰菜圖

《火焰菜考》
[
编辑
]

人家園圃多種，苗葉俱似菠菜，但葉稍微紅，形如火
燄，結子亦如菠菜子。苗葉味甜，性寒冷。

救饑

採苗、葉，煠熟，水淘洗淨，油鹽調食。

山蔥圖

《山蔥考》
[
编辑
]

一名「隔蔥」，又名「鹿耳蔥。」生輝縣太行山山野中，葉似
玉簪，葉微團，葉中《攛葶似蒜葶，甚長而澀，稍頭結蓇
葖似蔥蓇葖微開白花，結子黑色。苗味辣》。

救饑

《採苗、葉》，煠熟，油、鹽調食。生醃食亦可。

背韭圖

《背韭考》
[
编辑
]

生輝縣太行山山野中，葉頗似韭葉而甚寬大，根似
蔥根，味辣。

救饑

《採苗、葉》，煠熟，油、鹽調食。生醃食亦可。

水芥菜圖

《水芥菜考》
[
编辑
]

水邊多生苗，高尺許，葉似家芥菜葉極小，色微淡綠。
葉多花，又莖叉亦細，開小黃花，結細短小《角兒》葉。味
微辛。

救饑

採苗、葉煠熟，水浸去辣氣，淘洗過，油鹽調食
​

遏藍菜圖

《遏藍菜考》
[
编辑
]

生田野中下濕地，苗初塌地，生葉似初生菠菜葉而
小，其頭頗團，葉間攛葶分叉上結莢兒，似榆錢狀而
小。其葉味辛香微酸，性微溫。

救饑

採葉煠熟，水浸取酸辣味，復用水淘淨作虀，油鹽調
食。

牛耳朵圖

《牛耳朵菜考》
[
编辑
]

一名「野芥菜」，生田野中，苗高一二尺，苗莖似萵苣，葉
似《牛耳朵》形而小，葉間分《攛葶叉》開白花，結子如粟
粒大。葉味微苦辣。

救饑

採苗、葉，淘洗淨，煠熟，油鹽調食。

山白菜圖

《山白菜考》
[
编辑
]

生輝縣山野中，苗葉頗似家白菜，而葉莖細長。其葉
尖𧣪，有《鋸齒叉》。又似「《莙薘菜》葉而尖瘦亦小，味甜微
苦。」

救饑

採苗、葉，煠熟，水淘淨，油鹽調食。

山宜菜圖

《山宜菜考》
[
编辑
]

又名「山苦菜」生新鄭縣山野中，苗初塌地生，葉似薄
荷葉而大，葉根兩傍有叉，背白，又似青莢兒菜葉亦
大，味苦。

救饑

採苗、葉，煠熟，油鹽調食。

黃鵪菜圖

​

《黃鵪菜考》
[
编辑
]

生密縣山谷中，苗初塌地生，葉似初生山萵苣葉而
小，葉腳邊微有花叉，又似「《孛孛丁》葉而頭頗團」，葉中
攛生葶叉，高五六寸許，開小黃花，結小細子，黃茶褐
色。葉味甜。

救饑

採苗、葉，煠熟，換水淘浸，油鹽調食。

《燕兒菜考》
[
编辑

頭微團，味苦。

救饑

柴韭圖

《柴韭考》
[
编辑
]

生荒野中。苗葉形狀如韭。但葉圓細而瘦。葉中攛葶
開花如韭花狀。粉紫色。《苗葉味辛》。

救饑

採苗、葉，煠熟，水浸淘淨，油、鹽調食。生醃食亦可。

灰菜圖

《灰菜考》
[
编辑
]

生田野中處處有之。苗高二三尺，莖有紫紅線楞。葉
有灰。
〈音勃〉
結青子成穗者甘，散穗者微苦，性暖。生牆
下樹下者，不可用。

救饑

採苗、葉，煠熟水浸淘淨，去灰氣，油、鹽調食，曬乾煠食
尤佳。穗成熟時，採子搗為米，磨麪作餅，蒸食皆可。

苦。

甘露兒圖

《甘露兒考》
[
编辑
]

人家園圃中多栽，葉似地瓜兒葉，甚闊，多有毛澀。其
葉對節生，色微淡綠。又似薄荷葉，亦寬而皺，開紅紫
花。其根呼為「甘露兒」，形如小指，而紋節甚稠，皮色黲
白，味甘。

救饑

採根洗淨煠熟，油、鹽調食，生醃食亦可。

元扈先生曰：「又一種與甘露同，而根作直枝無節者，
名銀條菜。」
