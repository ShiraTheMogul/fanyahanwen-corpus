《淋池歌》
漢·昭帝
[
编辑
]

昭帝始元元年，穿淋池，廣千步。帝時命水嬉，令宮人歌曰：

秋素景兮泛洪波，揮纖手兮折芰荷。涼風凄凄《揚櫂
歌》，雲光開曙月低河，萬歲為樂豈云多。

《芙蓉池作》
魏·文帝
[
编辑
]

乘輦夜行遊，逍遙步西園。雙渠相灌溉，嘉木繞通川。
卑枝拂羽蓋，修條摩蒼天。驚風扶輪轂，飛鳥翔我前。
丹霞夾明月，華星出雲間。上天垂光彩，五色一何鮮。
壽命非松喬，誰能得神仙。遨遊快心意，保己終百年。

《遊西池》
宋·謝瞻
[
编辑
]

悟彼《蟋蟀》倡，信此勞者歌。有來豈不疾，良遊常蹉跎。
逍遙越城肆，願言屢經過。迴阡被陵闕，高臺眺飛霞。
惠風蕩繁囿，白雲屯曾阿。景昃鳴禽集，水木湛清華。
褰裳順蘭沚，徙倚引芳柯。美人愆歲月，遲暮獨如何。
無為牽所思，南榮戒其多。

《曲池之水》
齊·謝脁
[
编辑
]

緩步遵莓渚，披襟待惠風。芙蕖舞輕帶，苞筍出芳叢。
浮雲自西北，江海思無窮。鳥去能傳響，見我綠琴中。

《首夏泛天池》
梁·武帝
[
编辑
]

薄遊朱明節，泛漾天淵池。舟楫互容與，藻蘋相推移。
碧沚紅菡萏，白沙青漣漪。新波拂舊石，殘花落故枝。
葉軟風易出，草密路難披。

《山池》
簡文帝
[
编辑
]

「日暮芙蓉水，聊登鳴鶴舟。」《飛艫飾羽》，
長幔覆緹油
​
停輿依柳息，住蓋影空留。古樹橫臨沼，新藤上挂樓。
遊魚向闇集，戲鳥逗楂流。

《山池應令》
庾肩吾
[
编辑
]

閬苑秋光暮，金塘收潦清。荷低芝蓋出，浪湧燕舟輕。
逆湍流櫂唱，帶谷聚笳聲。野竹交臨浦，山桐迥出城。
水逐雲峰闇，寒隨殿影生。

《北寺寅上人房望遠岫翫前池》
王筠
[
编辑
]

安期遂長往，交甫稱高讓。遠跡入滄溟，輕舉馳崑閬。
良由心獨善，兼且情遊放。豈若尋幽棲，即目窮清曠。
激水周堂下，屯雲塞檐向。閉牖聽奔濤，開窗延疊嶂。
前階復虛沿，濔迤成洲漲。雨點散圓文，風生起斜浪。
游鱗互瀺灂，群飛皆哢吭。蓮葉蔓田田，菱花動搖漾。
浮光曜庭廡，流芳襲帷帳。匡坐足忘懷，詎思江海上。

《山池應令》
鮑至
[
编辑
]

《望園光景暮》，林觀歇氛埃。荷疏不礙楫，石淺好縈苔。
風光逐榜轉，山靄向橋開。樹交樓影沒，岸暗水光來。

《前題》
王臺卿
[
编辑

「歷覽周仁智，登臨歡豫多。」穿渠引金谷，闢道出銅駝。
長橋時跨水，曲閣乍臨波。巖風生竹樹，池香出芰荷。
石幽銜細草，林末度橫柯。

[
编辑

[
编辑

靈沼蕭條望，遊人意緒多。終南雲影落，渭北雨聲過。
蟬噪金隄柳，鷺飲石鯨波。珠來照似月，織處寫成河。

编辑

徒自臨濠渚，空復撫鳴琴。莫知流水曲，誰辨遊魚心。

《元圃濬池》
北周·王褒
[
编辑

長洲春水滿，臨汎廣川中。石壁如明鏡，飛橋類飲虹。
垂楊夾浦綠，新桃緣徑紅。對樓還泊岸，迎波蹔守風。
漁舟釣欲滿，蓮房採半空。於茲臨北闕，非復坐牆東。

《奉和山池》

[
编辑

日落含山氣，雲歸帶雨餘。

碎珠縈斷菊，殘絲繞折蓮。落花催斗酒，栖烏送一絃。

编辑

《秋日遊昆明池》
隋·薛道衡
[
编辑
]

灞陵因靜退，靈沼暫徘徊。新船《木蘭》楫，舊宇豫章材。
荷心宜露泫，竹徑重風來。魚潛疑刻石，沙暗似沈灰。
琴逢鶴欲舞，酒遇菊花開。羈心與秋興，陶然寄一杯。

《秋遊昆明池》
元·行恭
[
编辑
]

旅客傷羈遠，樽酒慰登臨。池鯨隱舊石，岸菊聚新金。
陣低雲色近，行高鴈影深。攲荷瀉圓露，臥柳橫清陰。
衣共秋風冷，心學古灰沉。還似無人處，幽蘭入雅琴。

编辑

桂楫滿中川，絃歌振長嶼。豈獨《汾河曲》，方為歡宴所。

《和許侍郎遊昆明池》
李百藥
[
编辑
]

神池望北極，滄波接遠天。儀星似河漢，落景類虞泉。
年深平館宇，道泰偃戈船。差池下鳧鴈，掩映生雲煙。
浪花開已合，風文直且連。稅馬金堤外，橫舟石岸前。
羽觴傾綠蟻，飛日落紅鮮。積水浮深智，明珠曜雅篇。
大鯨方遠擊，沉灰獨未然。知君嘯儔侶，短翮徒聯翩。

《安德山池宴集》
前人
[
编辑
]

朝宰論思暇，高宴臨方塘。雲飛鳳臺管，風動令君香。
細草開金埒，流霞泛羽觴。虹橋分水態，鏡石引菱光。
上才同振藻，小技謬連章。懷音自蘭室，徐步返山莊。

《和東觀群賢七夕臨泛昆明池》
任希古
[
编辑
]

秋風始搖落，秋水正澄鮮。飛眺牽牛渚，激賞鏤鯨川。
岸珠淪曉魄，池灰斂曙煙。汎查分瀉漢，儀星別構天。
雲光波處動，日影浪中懸。驚鴻結蒲弋，遊鯉入莊筌。
萍葉疑江上，菱花似鏡前。長林代輕幄，細草即芳筵。
文華開翠瀲，《筆海》空清漣。不挹蘭樽聖，空仰桂舟仙。

《凝碧池侍宴看競渡應制》
李懷遠
===
​
「上苑清鑾路，高車重豫遊。」前對芙蓉沼，旁臨杜若洲。

地如元扈望，波似洞庭秋。列筵飛翠斝，分曹戲鷁舟。
湍高櫂影沒，岸近榜歌遒。舞曲依鸞殿，簫聲下鳳樓。
忽聞天上樂，疑逐海查流。

《興慶池侍宴應制》
蘇瓌
[
编辑
]

金闕平明宿霧收，瑤池式宴俯清流。瑞鳳飛來隨帝
輦，祥魚出戲躍王舟。帷齊綠樹當筵密，蓋轉緗荷接
岸浮。如臨竊比微臣懼，若濟叨陪聖主遊。

宋·之問
[
