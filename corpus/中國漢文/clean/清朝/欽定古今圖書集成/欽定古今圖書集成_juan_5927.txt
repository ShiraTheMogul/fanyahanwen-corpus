〈詞〉
[
编辑
]

蝶戀花　　　　　　　　　　宋謝逸
[
编辑
]

豆蔻梢頭春色淺。新試紗衣，拂袖東風軟。紅日三竿
簾幙捲。畫樓影裡雙飛燕。攏鬢步搖青玉碾。缺樣
花枝，葉葉蜂兒顫。獨倚闌干凝望遠。一川煙草平如
翦。

南鄉子　　　　　　　　　　　前人
[
编辑
]

淺色染春衣。衣上雙雙小燕飛。袖捲藕絲寒玉瘦，彈
棋。贏得尊前酒一巵。冰雪拂胭脂。絳蠟香融落日
西。唱徹《陽關》人欲去，依依。醉眼橫波翠黛低。

玉樓春　　　　　　　　　　　前人
[
编辑
]

箇中懷抱誰排遣。惻惻輕寒風翦翦。細看梅蕊晚香
濃，爭似柳梢春色淺。嬌譌道字歌聲軟。醉後微渦
回笑靨。都無卓氏《白頭吟》，只有盧郎年少感。

花心動　　　　　　　　　　　前人
[
编辑
]

風裡楊花輕薄性，銀燭高燒心熱。香餌懸鉤，魚不輕
吞，辜負釣兒虛設。桑蠶到老絲長絆，鍼刺眼淚流成
​
血。思量起，拈枝花朵，果兒難結。海樣情深忍撇。似
夢裡相逢，不勝歡悅。出水雙蓮，摘取一枝，可惜並頭
分折。猛期月滿會姮娥，誰知是初生新月。折翼鳥，甚
日于飛時節。

如夢令　　　　　　　　　　　前人
[
编辑
]

花落鶯啼春暮。陌上綠楊飛絮。金鴨晚香寒，人在洞
房深處。無語。無語。葉上數聲疏雨。

憶舊遊　　　　　　　　　　周邦彥
[
编辑
]

「記愁橫淺黛，淚洗紅鉛，門掩秋宵。墜葉驚離思，聽寒螿夜泣，亂雨蕭蕭。鳳釵半脫雲鬢，窗影燭花搖。」漸暗
竹敲涼，疏螢照曉，兩地魂消。迢迢。問音信，道「徑底花陰，時認鳴鑣。也擬臨朱戶，歎因郎顦顇，羞見郎招。舊巢更有新燕，楊柳拂河橋。」但滿眼京塵，東風竟日
吹露桃。

鳳來朝　　　　　　　　　　　前人
[
编辑
]

逗曉看嬌面。小窗涼、弄明未辨。愛殘妝宿粉雲鬟亂。
最好是、帳中見說，夢雙蛾微斂。錦衾溫、獸香未斷。
待起難𢬵捨。任日炙，畫樓暖。

南鄉子　　　　　　　　　　　前人
[
编辑
]

晨色動妝樓。短蠟熒熒悄未收。自在開簾風不定，颼
颼。池面冰澌趁水流。早起怯梳頭。欲綰雲鬟又卻
休。不會沉吟思底事，凝眸。兩點春山滿鏡愁。

一斛珠　　　　　　　　　　　前人
[
编辑
]

茸金細弱。秋風嫩桂花初著。蕊珠宮裡，人難學。花染
嬌荑羞映翠雲幄。清香不與蘭蓀約。一枝雲鬢巧
梳掠。夜深輕撼薔薇萼。香滿衣襟，月在鳳凰閣。

蝶戀花二首　　　　　　　　　前人
[
编辑
]

美盼低迷情宛轉。愛雨憐雲，漸覺寬金釧。桃李香苞
秋不展。深心黯黯誰能見。宋玉牆頭纔一覘。絮亂
絲繁，苦隔春風面。歌板未終風色便。夢為蝴蝶留芳
甸。

葉底尋花春欲暮。折遍柔枝，滿手珍珠露。不見舊人
空舊處。對花惹起愁無數。卻倚闌干吹柳絮。粉蝶
多情，飛上釵頭住。若遣郎身如蝶羽。芳時爭肯拋人
去。

長相思慢　　　　　　　　　　前人
[
编辑
]

夜色澄明，天街如水，風力微冷簾旌。幽期再偶，坐久
相看纔喜，欲歎還驚。醉眼重醒。映雕欄修竹，共數流
螢。細語輕輕，儘銀臺、挂蠟潛聽。自初識伊來，便惜
妖嬈豔質，美盻柔情。桃溪換世，鸞馭凌空。有願須成。
遊絲蕩絮，任輕狂、相逐牽縈。但連環不解，難負深盟。

秋蕊香　　　　　　　　　　　前人
[
编辑
]

乳鴨池塘水暖，風緊柳花迎面。午妝粉指印窗眼，曲
裡長眉翠淺。聞知社日停針線，探新燕。寶釵落枕
夢魂遠，簾影參差滿院。

浣溪紗　　　　　　　　　　　前人
[
编辑
]

爭挽桐花兩鬢垂。小妝弄影照清池。珠簾踏襪趁蜂
兒。跳脫添金雙腕重，琵琶破撥四絃悲，夜寒誰肯
翦春衣。

蘇幕遮　　　　　　　　　　　前人
[
编辑
]

鬢雲鬆眉葉聚。一闋離歌，不為行人駐。檀板停時君
看取。數尺鮫綃，半是梨花雨。鷺飛遙天尺五。鳳閣
鸞坡，看即飛騰去。今夜長亭臨別處。斷梗飛雲，盡是
傷情緒。

浣溪紗慢　　　　　　　　　　前人
[
编辑
]

水竹舊院落，櫻筍新蔬果。嫩英翠幄，紅杏交榴火。心
事暗卜，葉底尋雙朵。深夜歸青瑣。燈盡酒醒時，曉窗
明、釵橫鬢嚲。怎生那，被間阻時多。奈愁腸數疊，幽
恨萬端，好夢還驚破。可怪近來傳語也無箇。莫是嗔
人呵。真箇若嗔人，卻因何、逢人問我。

虞美人　　　　　　　　　　　前人
[
编辑
]

金閨平帖春雲㬉，晝漏花前短。玉顏酒解豔紅消，一
晌捧心啼困不成嬌。別來新翠迷行徑。窗鎖玲瓏
影。砑綾小字夜來封，斜倚曲闌凝睇、數歸鴻。

阮郎歸　　　　　　　　　　　前人
[
编辑
]

冬衣初染遠山青。雙絲雲鴈綾。衣寒袖濕欲成冰。都
緣珠淚零。情黯黯，悶騰騰。身如秋後蠅。若教隨馬
逐郎行。不辭多少程。

南唐浣溪紗　　　　　　　　　陳克
[
编辑
]

《鬆》漫梳頭淺畫眉。亂鶯殘夢起多時。不道小庭花露
濕，翦酴醾。簾額好風低燕子窗油，晴日打蜂兒。翠
袖粉牋閒弄筆，寫新詩。

謁金門　　　　　　　　　　　前人
[
编辑
]

花滿院。飛去飛來雙燕。紅雨入簾寒不卷。曉屏山六
扇。翠袖玉笙悽斷。脈脈兩蛾愁淺。消息不知郎近
遠。一春長夢見。

菩薩蠻　　　　　　　　　　　前人
[
编辑
]

池塘淡淡浮鸂𪆟。杏花吹盡垂楊碧。天氣度清明。小
園新雨晴。綠窗描繡罷。笑語荼蘼下。圍坐賭青梅。
困從雙臉來。

===浣溪紗　　　　　　　　　　　前人===
​
淺畫香膏拂紫綿。牡丹花重翠雲偏，手挼梅子並香

肩。病起心情終是怯，倦來體態不勝憐，旋移鍼線
小姑前。

虞美人　　　　　　　　　　　前人
[
编辑
]

小山戢戢盆池淺，芳樹陰陰轉。紅闌干上刺薔薇，蝴
蝶飛來飛去、兩三枝。繡裙斜立腰肢困，翠黛縈新
恨。「風流蹤跡使人猜。過了鬥雞時節、《合歸來》。」
小重山　　　　　　　　　　呂渭老
[
编辑
]

雲護柔條雪壓枝。斜風吹絳蠟，點胭脂。薔薇揉水麝
分臍。園林晚，脈脈帶斜暉。深閣繡簾低。寶匳勻淚
粉，晚妝遲。一枝屏外對依依。清宵永，誰伴破寒巵。

生查子　　　　　　　　　　　前人
[
编辑
]

雙鬟綠髮齊，多笑嫣紅落。穿竹過西齋，問字時偷學。
嬌慵不慣羞，同倚闌干角。屈指數元宵，燈火堪行
樂。

憶王孫　　　　　　　　　　　前人
[
编辑
]

晚妝新試碧衫涼。金鴨猶殘昨夜香。柳際風來月滿
廊。一雙雙。人對鴛鴦浴小塘。

鷓鴣天　　　　　　　　　　　前人
[
编辑
]

微點胭脂暈淚痕。更衣整髻立黃昏。春風攪樹花如
雨，夕靄迷空燕趁門。題往事，錦迴文。春心無定似
行雲。深屏繡幌空愁獨，明月梨花殢一尊。

千秋歲　　　　　　　　　　　前人
[
编辑
]

寶香盈袖。約腕金條瘦。裙兒細襉如眉皺。笑多簪髻
側。語小絲簧奏。洞房晚。千金未直橫波溜。緣短歡
難又。人去春如舊。枝上月，誰攜手。宿雲迷遠夢。淚枕
中殘酒。怎奈向、繁陰亂葉梅如豆。

握金釵二首　　　　　　　　　前人
[
编辑
]

風日困花枝，晴蜂自相趁。晚來紅淺香盡。整頓腰肢
暈殘粉。絃上語，夢中人，天外信。青杏已成雙，新尊
薦櫻筍。為誰一晌銷損。數著佳期又不穩。春去也，怎
當他，清晝永。

向晚小妝勻，明窗倦裁翦。見花清淚遮眼。開盡繁花
又春晚，心下事，比年時都較嬾。蝴蝶入簾飛，鶯聲
似簧囀。見來無計拘管。心似芭蕉乍舒展。歸去也，夕
陽斜紅滿院。

玉樓春　　　　　　　　　　　王寀
[
编辑
]

《秋閨》思入江南遠。簾幕低垂閒不捲。玉珂聲斷曉屏
空，好夢驚回還起嬾。風輕只覺香煙短。陰重不知
天地晚。隔窗人語退朝歸，旋整宿妝勻睡臉。

點絳脣　　　　　　　　　　　何籀
[
编辑
]

春雨濛濛，淡煙深鎖垂楊院。㬉風輕扇。落盡桃花片。
