澤州部藝文二
〈詩〉

编辑

《題澤州石佛閣》
唐·李華
[
编辑
]

覽勝詩千首，登高酒一壺。此情誰管領，分付石《浮圖》。

《高平東私路》
李賀
[
编辑
]

侵侵槲葉香，木花滯寒雨。今夕山上秋，永謝無人處。
石磎遠荒澀，棠實懸辛苦。古者定幽尋，呼君作私路。

《長平箭頭歌》
前人
[
编辑
]

漆灰骨末丹水砂，淒淒古血生銅花。白翎金簳雨中
盡，直餘三春殘狼牙。我尋平原乘兩馬，驛東石田蒿
塢下。風長日短星蕭蕭，黑旗雲濕懸空花。左魂右魄
啼肌瘦，酪瓶倒盡將羊炙。蟲棲鴈病蘆筍紅，迴風送
客吹陰火。訪古汍瀾收斷鏃，折鋒赤璺曾刲肉。南陌
東城馬上兒，勸我將金換簝竹。

《石樓山見月》
李益
[
编辑
]

紫塞連年戍，黃沙磧路窮。故人今夜宿，見月石樓中。

《石佛谷》
皇甫曙
[
编辑
]

漫澶太行北，千里一塊石。平腹有壑谷，深廣數百尺。
土僧何為者，老草毛髮白。寢處容身龕，足膝隱成跡。
金仙琢靈像，相好倚北壁。花座五雲扶，玉毫六虛射。
文人留紀述，時事可辨析。鳥趾巧均分，龍骸極癯瘠。
枯松闊槎枿，猛獸恣騰擲。蛣𧌑蟲食縱，懸垂露凝滴。
精藝貫古今，窮巖誰愛惜。託師禪誦餘，勿使塵埃積。

《宿王屋天壇》
馬戴
[
编辑
]

星斗半沉蒼翠色，紅霞遠照海濤分。折松曉拂天壇
雪，投簡寒窺玉洞雲。絕頂醮迴人不見，深林磬度鳥
應聞。未知誰與傳《金籙》，獨向仙祠拜老君
​

《琵琶泓》
宋·楊謨
[
编辑
]

晉城出郭十里餘，嫩柳山花滿巖麓。蒼苔蹭蹬步亦
艱，百丈懸崖掛層屋。老僧正睡門不開，習習陰風起
幽谷。耳聵不聞琵琶聲，但見一泓春水綠。

《古詩》
黃廉
[
编辑
]

「河東人物氣勁豪，澤州學者如牛毛。大家子弟弄文墨，其次亦復跨弓刀。去年較射九百人，五十八人同賜袍。今年兩科取進士，落釣連引十三鰲。邇來習俗宜趨善，家家門戶爭相高。驅兒市上買書讀，寧使田間禾不薅。我因行縣飽聞見，訪問終日忘勤勞。太平父老知此否，語汝聖世今難遭。欲令王民盡知教，先」自鄉里烝群髦。古云將相本無種，從今著意鞭兒曹。

《遊石壁》
金·郝天挺
[
编辑
]

絕壁秋雲勝，荒牆冷氣清。野僧遲客飲，山鳥𦊰人鳴。
已極登臨興，無窮今古情。浩歌入樽酒，四海共昇平。

《碧落寺》
李俊民
[
编辑
]

「浮雲翳炎景，長夏愜幽事。相陪林下友，共造金碧地。」清流漱寒玉，老槐聳蒼翠。何人開《山祖》，妙處發天祕。
悠悠歲月深，剝落磨崖字。遨遊興不淺，有酒留客醉。
幽鳥背人飛，不慣聞鼓吹。抵暮出山門，溪風送歸騎。

《遊青蓮寺》
前人
[
编辑
]

閒攜方外友。同謁梵王宮。山吐三更月。松搖萬壑風。
流年飛鳥過。浮世落花空。不有歸來興。何能見遠公。

《題郝文忠公墓》
李晏
[
编辑
]

仗節江南羡此行，真州猶稔使君名。隹城鬱鬱埋西
滸，恨不生還蘇子卿。

《沁水山中雜詠》
元·王惲
[
编辑
]

石徑穿雲曲又斜，蒼松影裏見仙家。一溪流水清如
玉，送出山中自落花。

馬頭隨路對峰巒，吟倚征鞍盡日看。澗底泉聲穿石
細，松梢嵐氣襲衣寒。

懸崖怪石欹將壞，出岫閒雲懶自安。旅食僧房清未
足，香薇短飣薦盤餐。

《旌忠廟弔後唐裴約》
明·王堅
[
编辑
]

「嬴秦破洪荒，末運開五季。乾綱倒狂瀾，龍虎恣吞噬。毒流滄溟深，虐焰乾坤熾。誰為柱石臣，力挽迴天勢。桓桓裴將軍，名節期砥礪。伏事李嗣昭，騫騰賈英氣。夾寨守餘年，忠誠舊昭義。嗣昭領元戎，甘苦同軍吏。一朝解重圍，汴水驚鼎沸。周旋二紀餘，相親若肝肺。南轅守澤城，鎮靜得專制。《髫齦》巷有歌，夜月龐不吠。」翠華重親征，賜姓神堯裔。誓將雪昭陵，問罪興漢熾。
大勳以垂成，元戎忽先逝。繼韜固隹兒，胡為反徼利。
柩中肉未寒，略不君親視。巍巍基霸功，上黨固屏蔽。
一朝與仇讎，割斷河東臂。銜枚汴軍來，此邦可無備。
酬恩寧死忠，臨危敢攜二。裹瘡夜巡陴，顧與城俱斃。
期將先軫元，碎作睢陽厲。情鍾唐帝「懷，死獲將軍志。當時一武臣，英烈乃如是。嗟嗟馮大師，曾不知垂涕。朝為仇敵人，暮作君臣契。累朝位三公，亙古羞犬彘。請觀公之為，九萬見飛鷙。」堂堂歐陽公，直筆著清議。
官崇刺史封，廟錫旌忠諡。芳名重山丘，富貴誠夢寐。
我來守此邦，雨暘賴神惠。朝廷饈特牲，春秋謹時祭。
衣冠儼容儀，黍稷加精糦。廣庭聞苾芬，旋飆肅鳴騎。
觚稜暈朱甍，豐碑勒《雄記》。始知先聖王，垂教重名器。
向如始皇君，今日皆魑魅。再拜瞻廟容，斯文亙天地。

《長平戈頭歌》
劉基
[
编辑
]

長平戰骨煙塵飄，歲久遺戈金不銷。野人耕地初拾
得，土花清出珊瑚色。邯鄲小兒強解事，枉使泥沙埋
利器。四十萬人非少弱，勇怯賢愚一朝棄。陰壑血漬
秋復春，朽壞蝕盡蒼苔痕。沉埋長愧杜郵劎，廢墜空
憶樁餱人。故堞中宵鬼神入，雲窗月暗戈應泣。當時
豈無牧與頗，戈乎不遇可奈何！

《弔藺相如》
高啟
[
编辑
]

危計難成五步間，置君虎口卒全還。世人莫笑三閭
懦，不勸懷王會《武關》。

《登星軺驛樓》
于謙
[
编辑
]

驛樓高架與雲齊，曉日登臨思不迷。捲幕全無三伏
暑，憑闌轉覺眾山低。閒花故向吟邊落，野鳥偏於靜
處啼。十六年來成一夢，後人誰為繼新題。

《道經沁水憫農》
前人
[
编辑
]

《無雨》農怨嗟，有雨農辛苦。老夫出門荷犁鋤，村婦看
家事縫補。可憐小女年十餘，赤腳蓬頭衣藍縷。提筐
朝出暮時歸，青菜挑來半活土。茅簷風急火難炊，旋
爇山柴帶根煮。夜歸夫婦聊充飢，食罷相看淚如雨。
淚如雨，將奈何！有口難訴辛苦多，嗟爾縣官當撫摩。

《宿東烏嶺》
前人
[
编辑

蕭然山館似僧房，三尺寒檠一炷香。風捲松濤清入

功施唐世建行祠，景仰英風一弔之。碑寫《嶽書》銘在

​
落遲。廟古山迴人跡少，虯松黛柏掛蛛絲。

《六柳莊》
楊一清
[
编辑

小搆茅廬背石樓，繞門楊柳蘸溪頭。尋詩正合添明

《登鹿臺山》
李瀚
[
编辑
]

誰謂雲霄遠，躋攀有路通。山川皆禹跡，勤儉屬唐風。
佛屋洪崖半，人家邃谷中。重華耕稼處，翹首見遺宮。

《漢天子嶺》
〈漢光武追銅馬過此〉
喬宇
[
编辑
]

縣西石嶺高巃嵷，羊腸詰曲蹊徑通。將軍提兵討河
北，王室正在崎嶇中。中原《赤符》歸白水，豹虎遁藏銅
馬死。道傍過者仰遺蹤，猶說神靈漢天子。

《端氏城》
李夢陽
[
编辑
]

繫馬荒城下，空翠圍峰巒。一聞《端氏名》，懷古生長歎。
憶昔晉茅土，珍重天王頒。大綱漸頹廢，宗社尋凋殘。
誰能有其國，三家趙魏韓。常聞享世祿，況復叨其官。
忍使冠裳鬼，蒸嘗血不殘。相與封其子，乃有尺土安。
乾坤互消長，日月跳彈丸。秦兵恣吞食，列國同凄酸。
周室亦淪沒，其餘何以觀。屹屹端氏城，秋菊還春蘭。
上有雲霧濛，下有茗葛盤。行人無限恨，深夜月明寒。

《馬邑城》
〈白起牧馬處〉
前人
[
编辑
]

白起小豎子，謀猷憚諸國。駐軍太行西，裂地大河北。
牧馬玆山陽，築城鑿溝淢。抱河背太山，峻絕失人色。
并吞勢已雄，獨抗事相逼。廉頗真將軍，收精抵堅壁。
秦人心已寒，孰謂趙非敵？間言讋孝成，斗印書生得。
膠柱鼓其絃，相如真有識。矢石既交接，甲械尋棄擲。
可憐無罪民，遘此長平厄。暴秦不足言，衰趙亦可惜。
祇憐一頗身，係此興衰跡。天王簡賢俊，嬴氏奚蠶食。

《武安城》
〈白起封武安君即此今屯壘尚在有廟〉
前人
[
编辑
]

「孤城突如塊，據山瞰流水。誰能經營之，無乃秦白起。」東北連長平，遙遙數千里。想是擊趙時，卜茲御旌壘。
鳴鼓收降旗，一坑萬人死。耀武滋暴君，貪功泣冤鬼。
白骨蔽丘原，霜風慘陰晦。進爵食武安，聲名播青史。
迄今千百年，此城名尚爾。先王重民命，師行非得已。
何納來降民，屠戮比螻蟻。坐驅文武民，盡入虎狼齒。
《春秋》誅亂臣，功罪不相擬。善戰服上刑，聞諸孟夫子。

《王離城》
〈秦王離伐趙屯兵於此〉
何景明
[
编辑
]

「王輿東不返，國步何其頻。群雄角謀智，大柄歸強秦。韓盧恣吞噬，近攻無完脣。逢惡者誰子，范睢真不仁。貔虎下河北，三晉飛煙塵。據險築城壘，當此山嶙峋。四壁真如削，百雉傍無鄰。養銳絕窺覬，出奇邁等倫。王離實為之，為國思委身。撚指忘趙魏，回首無秦人。但留城土在，塊然秋復春。苔溪唱樵牧，暮雨收荊榛。」哀哉戰爭年，塗炭皆我民。見此重悽愴，過客停雙輪。

《岳將軍巖》
前人
[
编辑
]

欃槍弄芒天改色，汴京失守乘輿北。鄂王唾手復中
原，兩河豪傑皆奮力。刊山築巖聲裂空，和議誤國隳
成功。千秋英魄或遊此，森森草樹生悲風。

《杏谷》
前人
[
编辑
]

東風滿山開杏花，杏林十里如蒸霞。武陵桃源解迷
客，何如種杏作生涯。人家半住山霞裏，滿院落花寒
食雨。春香撲雪春酒酣，長遣行人問山主。

《西烏嶺》
前人
[
编辑
]

「《嶺》樹鬱鬱雲深深，青山無雨雲陰陰。」山雲日夕千變
化，青山有色雲無心。仙翁久伴白雲住，家在白雲最
深處。嶺頭日暮鋤耘歸，破笠輕蓑衝雨去。

《寄題白石樓》
康海
[
编辑
]

我聞白石樓，乃在太行下。丹機凌紫霄，朱甍接巖罅。
盤鬱橫汾曲，崔嵬紫金叉。夕煙靄洄潏，朝暉輝簷庌。
兩溪互縈帶，千峰隨晦冥。屏障萬翠列，花柳四時明。
平生喜遊眺，詎可如孫登。春中過函谷，遂有渤澥行。
徒懷南莊老，安能愜初盟。人事苦迫促，三日滯虞卿。
惟有泛舟趣，卻無曾點狂。回想王官谷，新詩滿素牆。
不識蕩溪姓，徒羨詩思長。何當與握手，於時共徜徉。
同遊頌其名，知是《南莊》子。故家有若人，私為南莊喜。
遨遊翰墨場，倏忽踰四紀。不為英妙姿，尚在秦晉里。
便擬登此樓，醉汝賢喬梓。三歎發朝邑，彌月興猶起。
感君寄書至，展轉愛君才。欲見不可見，空望白雲隈。
吾有雙黃鵠，飛飛自天來。因逢王子晉，借之遊蓬萊。
一去竟千載，寥寥不可回。回時坐鶴背，挈子臨高臺。
先過崑崙頂，後瞰弱水湄。徐訪紫華君，持其雙玉芝。

《澤州志》：「高平縣西北五十里，發鳩山有鳥，狀如烏，文首白喙赤足。說者謂炎帝少女曰女娃，遊東海溺死，化為此鳥，銜西山木石以堙東海。」
大程子宰晉城時，有富民張氏子，父死。未幾，晨起，見
老父立門外，問之，曰：「我，汝父也，今來就汝居。」張氏子
驚疑莫測，詣縣請辨之。老父曰：「業醫，提囊遠出，妻生子，貧不能養，以與張氏，某年月日某攜抱去。」先生詰
曰：「歲久記何詳？」老父曰：「某歸知之，則書於《藥法策》後。」遂探懷取策進之。記云：「年月日某抱兒與張三翁家。」先生問：「張氏子爾年幾何？」曰：「三十六。」「爾父而在年幾何？」曰：「七十六。」謂老父曰：「是子生其父，年纔四十，人已謂之三翁乎？」老父驚駭服罪。

宋左藏睍嘗言，家故澤州，有第宅園圃，牆角下係古
塚，因治地發之，得一石志，題曰「郡守李公之墓。」壘石
為藏棺，中無他物，而棺之側斲石為乳婢抱哺一嬰
兒，不知其何為也。

王屋天壇，《道書》云：「黃帝禮天處，壇之方隅，陳八玉鏡」，
儒家疑焉。元豊中，有登天壇，得方玉如鏡者，濮陽杜
毅主王屋簿，曾親見之。

金皇統中，李宴同舉子六七輩赴都試，憩息上黨韓
店。俄有一道士，遍視七人者，獨執宴手曰：「公富貴壽考，他年當建節於此。值水大敗，道賴公治之。」語畢不
見。宴果是年登第，歷官中丞。歸老後，復起昭義節度。
韓店水忽敗道，老父請宴修治，歡然從之。即今石閘
也。

楊貞肅繼宗未第時，作石屋白巖山寺前，讀書其中，
冬夜獨處，虎蹲於戶，公咿唔達旦，恬不為懼。今舊跡
猶存。

王尚書國光精識鑒。一日在高平，劉令一相座，劉出
其子鴻訓及同學生二孫一張并館師王五人文質
之，蒙宰覽竟，驚曰：「皆公輔才，安得萃處一室？」王文雖
工惜福，差不及諸子。後孫公居相，官司農，鼎官中丞；
張公慎言官太宰，鴻訓官東閣大學士。館師王家礎，
壬辰登進士，選涇陽知縣，未任而卒，皆如其言。
尚書白公所知。家居時，室內忽地磚墳起，數日漸高
​
視其下產一芝，大如斗，金色炫爛，莫不驚異。未幾，公
召起奉常衛公一鳳守青州時，一獄官女為魅所憑，
廨中數火起，獄官懼，請於魅，魅曰：「衛尚書坐堂上，殊礙出入，非出爾女於外不可。」女出而火熄。又澤州某
氏高樓有鬼，人不敢登。侯公璡未遇時，請以身試之。
至夜分，果有物將登，竊語曰：「侯尚書在，盍亟避二公。」後皆如其官。

明崇禎戊辰夏，陽城西隅民家見一龍，頭面如羊，俯
飲甕中水，飲訖乘霧上升，形漸長大。將近屋脊，鄰婦
新產，豋樓望之，龍蜿蜒不能去，垂首簷際者數刻。忽
大雷一聲，火光爛爛，始入雲際。《語》云：「龍忌產婦。其信然乎？」
明崇禎庚辰秋，析城山樹頭遍掛蟲殼，如人形，長三
寸，綠色衣冠，襟袖宛然，兩腋下穿黑絨線，如傀儡繩
繫狀。山中取贈人，懸室內。至春時，綠殼開裂，中飛出
一蝴蝶，絕可觀。

項王屋山下一人解柿樹木心紋理，作一佛像，眉目
手指纖悉分明。

閻守典，陽城貢士士衡次子。九歲病股不能起，身不
滿三尺，僵臥床榻間，讀書為《古文辭》，頗有意。尚書白
公引謙，命鈔其文，序而傳諸人。

陵川邑西蔡家坪頹廟古柏二株，相傳明成化時植，
霜皮黛色，翹然特異，里人爭欲居奇，既而議售值以
補縣令平鄗《鼎代》墊舊逋。令不可永，約勿伐，改其顏
曰「存柏」，俾後之人毋效宋江夏王義恭「芟夷孔廟柏」故事。平自為文記之。

沁邑南鄉村名後麻園者，里人劉光岳七十餘口，五
世同居，忍讓一如張公。藝桁設長衣，出者輒衣之，無
定主。中有一人頗蓄私囊，眾知不言。後因事破家，議
析居私蓄者，泣曰：「吾不類曩有藏貲，願出公之居，不必析也。」遂聚處如初。

沁水韓王村玉女祠內，有樹一株，老榦婆娑，每當春
秋，開花二次。春則紅，秋則黃，花有異「香。歷年既久，人莫知其何名。」
劉國川者，鄉之惡人也。萬曆壬寅夏六月六日，與子
往耕於田。時霽日無雲，忽片雷起自西北，其子謂其
父將有雨，勸父回家避雨。國川行轉崚下，少憩，聞石
中啾啾，意其為寶也，揮鋤劚之，忽霹靂一聲，火龍自
土中起，提國川於空。其子哀鳴求免，乃墜國川於二
里外，頭以下皆燋爛，惟兩腿骨少存耳。

《登選鳥異》澤邑中有鳥曰「老鸛」，每歲遇大比，來棲於
庠之殿舍，其數幾何，士之登科者亦如之。鄉人每占
為預報。其最異者，莫如嘉靖丁酉科，是歲有老鸛者
五來集於庠，須臾一鸛飛於西南。是科中式者本庠
四名，而閻承光為澤學生，而高平其原籍也。鳥之徵
異如此。

魏允貞撫晉時，提學僉事杜葉先行部至澤州守許
維新事之，無失禮。僉事豪奢自用，撻其吏，許怒，停傳
給凡三日，僉事窘，馳還申院云：「州乏供具，僅食一母雞。」魏批云：「食雞有何不足，而尚以為慢，露筆作罪案耶？」杜大媿，引疾去。

崇禎十六年，豹自南門入城。

十六年，南城外牆投以石，嘖嘖有聲。搖鞭又打城又
叫：「從南來箇翻山鷂。」流賊高傑混名也。

明澤州有一石神，妖物也。婦人凡求子，不別貴賤，往
輒妊。嘉靖初，陳御史郊謫判於此，令民碎之。

朱衣鳥，出澤州，形如瓦雀，毛羽類丹砂，善鳴。張希周
攜歸，陳繼儒以為即古之赤鷃也。

平陽許沖亮，與甘肅生沖明友善。崇禎間，相約汗漫
遊，至高平，遇牛公子某，留憩南關道院。牛倏遘家變，
以千金付許曰：「事急矣，東西南北不可必，脫有遇需此金以濟，而生不知也。」居高平十餘年，渺無音信。一
日，聞牛更名青，入監，用教習考知縣。許方知牛某尚
在，告生曰：「吾守此地，負遊約者，徒以公子金耳。今公子在都門，需此必急。」於是齎金偕往，見公子，抱許痛
哭。既而曰：「某不肖，家私灰燼，意中久無此金，願奉為買山資。」許大恚云：「亮若利此，安待今日？幸勿汙我牛！」改容謝許遂去。陟嵩岳，不知所終。或曰：許邂逅宋中
一巨公，棲遲沒生，亦不食死。

康熙三年四月，東鄉人誘豫客至家，繆為盟，夜半約
同入市貿布。行草，徑推入眢井，復下磚石聽之，聲聲
皆中。日初升，行人聞井有呼救聲，且曰：「我早行，失足者縋上訊其故，當集眾縛兇詣公庭吐實。」問布客，則
云：「初下，見亡祖抱井旁坎中，其磚石中牛皮上耳。」官
怒，立斃兇仗下。

處士孔辰象，家人八百指，五世同居。其與尚光裕友
人，不知為二姓子孫四輩，爾汝忘形。有詡《金石交》者。

《舊志》：扶風馬孺子言，年十五六時，在澤州與群兒戲
郊亭上，頃然有奇女墜地，光爛然，被緅裘白紋之裏，
首步搖之冠，貴遊年少駭且悅之，稍狎焉。奇女頩爾
怒曰：「吾故居鈞天帝宮，下上星辰，呼吸陰陽，薄蓬萊，羞崑崙，而不即。帝以吾心侈，大怒謫之，來七日當復，今雖辱塵土中，非若儷也，吾復且害若。」眾恐而退，遂
入居佛寺講室。及期，取杯水飲之，噓成雲氣，五色翛
翛也。因取裘反之，化為白龍，迴翔騰舉，莫知所終。
萬曆己丑，懷慶有民秦萬言者，因父遺妾，移遞家貲，
與之角口，妾母因而致死。萬言驚惶，畏妾之父刁橫，
求救於郡之掌刑豪書于，自知韓陽夢，乃以白金十
兩托韓，而轉浼於于，懇求活罪。豈期于素與萬言不
合，雖得數金，竟以抵案，坐萬言死罪，萬言遂憤恨而
死，于亦未幾云亡。又數年，韓以贓私脫逃至高平，變
易姓名為田某者，往來邑之平頭、丹水、姬萬等村，日
以訓蒙為業，人不知其為韓也。至丁未夏四月間，無
故語諸童子曰：「余韓姓陽，夢其名也。二十年前，于自知事發了，秦萬言在陰曹告我為頭名犯人。」乃謂妻：
「家中做飯，與眾公差用我寫訴狀一紙候審。」妻與眾
各驚訝。至初八日，忽又曰：「老爺勾追至矣，若與于相辨。」而對泣者。咽倒地不語。移時，在地為受刑狀，呻吟
之聲，眾不忍聞。眾因焚《訴狀》，跪地求免。須臾忽起曰：
「老爺審理，與我無干，自知抵罪。」萬言解放矣。眾見韓
之兩股青腫，為受夾者兩三月，臥床未愈，鄉人互傳，
以為驚異。邑之城隍廟，丙夜時，有士人忽聽廟庭有
數人對理言，似與前脗合，問之，即四月八日也。
澤南郊枯井，上下乘涼，人語呼應。六月，有童子下井
死，父下救亦死，鄰人下視復死，一人攘臂曰：「此井從未陷人，我觀之。」眾曰：「今立斃三命，必欲下繫腰，以繩脫，不利，可急救。」如法甫至半，其人昏眩上良久始甦，
云：「見執簿衣緋者，叱速回，汝不在數內。」語訖，已為援
上矣。報聞太守，委州墓相驗，穿井旁別道，勾三屍出
之。

康熙年間，沁生竇子吉，家奉關侯極虔。一日出門，遇
數男婦引登舟，過沁，走三十餘里，至林村嶺。時已暮，
見門庭軒敞，燈燭輝煌，盛供饌以待。吉甫就席，忽見
侯神叱云：「孽祟已久，收復誘害人耶？」遂提刀立殺，男
婦等錚錚有聲。吉昏仆，夜半始甦，則在荒棘中迷所
向，待天明，方覓路而歸。

康熙四十四年五月三日，峪底村農民崔某同甥避
雨樹下。雨霽，甥在田若夢，尋視舅儼然在望，即之則
倒已無骨矣，呼家人立瘞。
