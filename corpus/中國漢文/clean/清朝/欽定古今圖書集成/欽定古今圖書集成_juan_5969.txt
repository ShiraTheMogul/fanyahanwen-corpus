吳某妻歐氏
[
编辑
]

按《衡州府志》：「歐氏，桂陽州吳某妻。夫病，百藥不效，氏誓曰：『天苟不祐吾夫，必以身殉』。」及沒，治殮畢，氏竟自
縊死。嘉靖間，旌其門。

劉鵬妻盧氏
[
编辑
]

按《黃州府志》：「盧氏，黃岡劉鵬妻。鵬病篤，氏先期自盡。嘉靖中，旌其廬。」
張氏女
[
编辑
]

按《德安府志》：「張氏女，安陸市民張佩女也。嘉靖己未，年十六，許聘朱鶚子比未嫁，比亡，女於是夜即自縊死。中丞汪道昆奏表其墓。」
龔天保妻牛氏
[
编辑
]

按《德安府志》：「牛氏，安陸龔天保妻。夫亡，誓偕夫死，跪夫柩側，不食十七日。歙人程明著贈棺槥，鄉人爭以美棺至，皆不受，尋絕。性端靜，每勸女婦修行。初，夫貧欲嫁之，至死不從。及是有司為治墓，立祠祀焉。」
劉自義妻李氏
[
编辑
]

按《德安府志》：「李氏，安陸諸生劉自義妻，高躬村人。年十九，適自義。義病革，與妻訣曰：『吾已矣，父母暨三子惟汝在』。李泣曰：『君有兄嫂，可勿慮』。」亡何，劉歿，李一慟
仆地，起視含殮畢，即謁辭翁姑，水漿不入口，歷十有
八日死。部使者具聞，旌之。

李之喬妻曹氏
[
编辑
]

按《枝江縣志》：「曹氏，生員李之喬妻。流寇肆掠，同妻被執不屈，慷慨罵賊而死。氏見夫被害，索刃欲自殺，亦斃焉。」
黃昌妻蔡氏
[
编辑
]

按《長沙府志》：「蔡氏，寧鄉黃昌妻。年二十六，夫亡，哀毀數絕。父兄以藐孤勸之，不從。一夕自縊死。是日黃生塚裂，遂合葬焉。里中士大夫為勒石於道。」
王道純妻譚氏
[
编辑
]

按《長沙府志》：「譚氏，茶陵人，王道純妻。夫病痰，手足拘攣不能動，譚每夜焚香，祈以身代，卒不起。手製一衣藏之。及夫歿，乃服前衣，自刎夫側。有司旌之。」
張逵妻王氏
[
编辑
]

按《長沙府志》：「王氏，安化人，張逵妻。嘉靖元年八月，逵為賊所執，欲并執王，乃以首飾投賊，脫去。俄報逵被拷死，曰：『夫死，吾生何為』！遂自沉屋後池中，人不及救。」
張明儒妻向氏
〈二田氏向晚女附〉
[
编辑
]

按《辰州府志》：「向氏，張明儒妻向焦女。嘉靖二十三年，蠟爾苗叛，剽掠鄉村。氏與婦廷表妻、姪婦廷相妻、二田氏及向晚女共驚走，藏甕池灘頭崖穴中。頃之，邏卒過灘，恐不免，至深湍同投水死。脫者還道其事，苗退，家人求其屍，悉獲焦女猶抱兒不釋。時盛暑踰日，面色如生，縣令立碑致祭。萬曆九年，余夢呂為建四節祠。」
眭炯燿妻艾氏
[
编辑

按《永州府志》：「艾氏，零陵諸生眭炯燿妻。兵亂，縱橫山谷間，執艾欲污之。艾曰：『我身終當屬爾，然對眾辱我，異日何以為爾婦？願且乘爾馬涉水』。執者信之，氏馳馬深流，赴水死。」〈眭按零陵縣志作時〉

编辑

按《道州新志》：「義氏女，名奎珠，永明義天誥女也。嘉靖戊戌，為流寇所擄，抗罵不污，遂遇害。」
楊俊妻謝氏
[
编辑
]

按《南昌郡乘》，謝氏，南昌楊俊妻。年十八適俊，家甚貧，
婚甫踰月，隨父客蜀。謝家居，奉姑至孝，備嘗辛苦三
年。俊歸，抵吳城，溺水死。謝聞之，悲號幾絕，引斧碎額，
娣姒驚救，得甦。及夕，自縊死。

===周珍妻吳氏===
​
按《南昌郡乘》吳氏，豐城周珍妻。年十八適珍。二年，珍
沒，吳以死誓。殮畢，入寢室自縊。合葬登仙鄉。

胡關七妻李氏
[
编辑
]

按《南昌郡乘》李氏，南昌胡關七妻。七亡，送葬扶靈歸。
有聚而觀之者，氏問曰：「彼觀者何人？」侍者曰：「叔氏已許嫁爾矣。」李曰：「烈婦無二夫。」乃痛哭夫靈，付孤於叔，
投水死。

閔邦粲妻萬氏
[
编辑
]

按南昌郡乘萬氏，南昌閔邦粲妻。年二十，歸邦粲，甫
半載，邦粲客游三年，歸，墮湖死。萬聞慟哭，自期必死。
舅姑勸之，不從，復延其母諭之，萬佯諾，眾以為信，防
護稍疏。一夕，具服從容自縊。

蔣欽妻黎氏
[
编辑

按《南昌郡乘》黎氏，豐城蔣欽妻。嘉靖辛酉，廣寇肆掠，
黎恐被污，遂投池死。

舒銓妻余氏
[
编辑
]

按《南昌郡乘》余氏，南昌舒銓妻，早寡。寇至，欲污之，余
自墜溝中，厲聲罵賊曰：「我名家子，寧死豈受爾辱！」罵
不絕口，賊怒，殺之。

余陽妻張氏
[
编辑

按南昌郡乘張氏，奉新余陽妻。年二十一，華林賊入
境，張被掠。行至後坪旅店，賊欲污之，張厲聲曰：「有死而已！」賊遂殺之。至死罵不絕口。

朱朝濟妻羅氏
[
编辑

按南昌郡乘羅氏，豐城朱朝濟妻。父早喪，母欲更適，
羅泣諫曰：「父死他適，不如攜子女同死。」及歸朱二年，
而朝濟歿。殮畢，遂自縊。嘉靖間旌其門。

编辑

按《南昌郡乘》：「鄒氏，豐城宋聰一妻。聰一沒及殯，鄒令工作雙壙，歸即自經。」
易功廉妻江氏
[
编辑
]

按南昌郡乘江氏，奉新易功廉妻。年二十五，遇華林
賊被執。賊愛其姿，驅令同行，至西岡，段氏據地不起，
賊怒，遂斷其首而去。

余繼妻熊氏
[
编辑
]

按《南昌郡乘》熊氏，字譽奴，豐城余繼妻。孝事舅姑，克
盡婦道。繼疾，度不能起，令備後事。氏泣謂繼曰：「設不幸，吾當與俱，不能獨生也。」繼亡，殮畢，聞家人議焚棺，
即衣所紉衣，期赴火死。家人察其意，防之，俟少懈，遂
自縊。

饒宇棨妻張氏
[
编辑
]

按《進賢縣志》：張氏，大學士張位孫女，尚寶丞大朴女。
年十七，歸諸生饒宇棨，事翁姑孝謹，宗黨內外翕然
稱之。戊子秋，偕夫避兵河東，被執。兵將加夫以刃，氏
盡出釵釧求贖，兵卒害之。氏搶地悲慟，以敝蓆覆屍，
兵促與俱去，氏曰：「吾相門女尚書子婦，豈從汝行乎？」遂觸石死，兵嘆息而去。三水縣令羅儀則為文紀之。

熊惟燮妻何氏
[
编辑

族中喻恭人以烈死，慟哭嗟嘆曰：「今世變不可測，恭人吾師也。」至是果盡節。

史氏女
[
编辑
]

按《饒州府志》：史氏女，名長姜，古埠史儼女也。年十六，
將嫁儼被酒殺僕，罪當坐死。儼因誣僕犯長，姜當讞，
姜實其誣，儼遂免死。異日，姜泣曰：「自誣以救父，義也；污名而偷生，恥也。」椎膺而死。縣令立石表其墓。

按《歙縣志》：「劉氏，父守位，向杲人，適鮑潭鮑大賓。大賓早死，劉年十八，痛絕廢食。祖姑與姑持之，哭極哀，願相倚為命。劉強起，事二姑甚謹。祖姑歿，姑病，伏枕八載，劉侍飲食，躬運污穢不怠。姑死，絕粒三日，輿至夫墓，以灰識其處而歸，越十日卒。事聞，詔旌表。」

黃天秩妻程氏
[
编辑
]

按《休寧縣志》：程氏，倫堂黃天秩妻，霞阜人。天秩臥病
四十日，寖劇，母卜之不吉，哭曰：「『決不獨生』。程跪曰：『姑少寬，願先死以代夫』。」及夕，潛自縊。天秩夜半得大下，
病良已。

按《休寧縣志》：「戴氏，朱村葉時昭妻。讀書通史。年二十一，昭客死，無子。氏囚首幽居，俟柩歸葬，絕食四日死。」
張尚俸妻汪氏
[
编辑
]

按《休寧縣志》：汪氏，張尚俸妻。夫貧甚，性苛急，氏不少
怨，易奩具勸之賈病歸。將死，汪竭力具大棺，再自經，
皆捄解，遂絕飲食。或勸為父母留，曰：「出嫁從夫，身非親有。」為老姑留，曰：「有子而獨，姑之命也。」姑強飲之，復
哇出，凡五日夜乃絕，年甫二十。

编辑

按《休寧縣志》：「曹氏，高梘汪橫妻。汪有癩疾，曹事之甚謹。汪自謀欲死，謂曹曰：『善事後人』。」氏誓不獨生。汪晨
起醉酒，歸與訣，曹知飲酖不可救，屬作大棺自縊死。

===夏大經妻徐氏===
​
按《休寧縣志》：「徐氏，夏大經妻。夫病兩載，竭力治不起，乃自刎，復自縊，俱不得死，遂絕食而斃。」
程氏女
[
编辑

按《休寧縣志》：「程氏女，北村人，許字居安汪應詔。汪病，女欲往，父母不可，潛自縊死。詔聞訃，匍匐往，哭而絕，合葬焉。」
