宮殿部藝文四
〈詩〉

编辑
]

《新成安樂宮》
梁·簡文帝
[
编辑
]

遙看雲霧中，刻桷映丹紅。珠簾通曉日，金華拂夜風。
欲知歌管處，來過安樂宮。

《上巳侍宴林光殿曲水》
同前
[
编辑
]

芳年留帝賞，應物動天襟。挾苑連金陣，分衢度《羽林》。
帷宮對廣掖，層殿邇高岑。風旗爭曳影，亭皋共生陰。
林花初墮蔕，池荷欲吐心。

《侍林光殿曲水宴》
沈約
[
编辑
]

宴鎬鏘玉鑾，遊汾舉仙軷。榮光泛彩旄，修風動芝蓋。
淑氣婉登晨，天行聳雲斾。帳殿臨春籞，帷宮繞芳薈。
漸席周羽觴，分墀引迴瀨。穆穆元化深，濟濟皇階泰。
將御遺風軫，遠侍瑤臺會。

《侍華光殿曲水宴》
劉孝綽
[
编辑
]

薰祓三陽暮，濯禊元巳初。皇心睠樂飲，帳殿臨春渠。
豫遊高夏諺，凱樂盛周居。復以焚林日，丰茸花樹舒。
羽觴環階轉，清瀾傍席疏。妍歌已嘹亮，妙舞復紆餘。
九成變絲竹，百戲起龍魚。

《行幸甘泉宮歌》
劉孝威
[
编辑
]

漢家迎夏畢，避暑甘泉宮。棧車鳴里鼓，駟馬駕相風。
校尉烏桓騎，待制樓煩弓。後旌猶五柞，前笳度九嵕。
才人豹尾內，御酒屬車中。輦迴百子閣，扇動七輪風。
鳴鐘休衛士，披圖召後宮。材官促校獵，涼秋戲射熊。

《長安道》
庾肩吾
[
编辑
]

桂宮延複道，黃山開廣路。遠聽平陵鐘，遙識新豐樹。
合殿生光彩，離宮起煙霧。日落歌吹還，塵飛車馬度。

《新成安樂宮》
陳陰鏗
[
编辑
]

新宮實壯哉，雲裡望樓臺。迢遞翔鶤仰，連翩賀燕來。
重簷寒霧宿，丹井夏蓮開。砌石披新錦，梁花畫早梅。
欲知安樂盛，歌管雜塵埃。

《帝王所居篇》
張正見
[
编辑
]

崤《函》雄帝宅，宛雒壯皇居。紫微臨複道，丹水亙通渠。
沈沈飛雨殿，藹藹承明廬。兩宮分概日，雙闕並凌虛。
休氣充青瑣，榮光入綺疏。霞明仁壽鏡，日照凌雲書。
鳴鸞背鳷鵲，詔蹕幸儲胥。長楊飛玉輦，御宿徙金輿。
柳葉飄緹騎，槐花影屬車。薄暮歸平樂，歌鐘滿玉除。

《重陽殿成金石會竟上詩》
前人
[
编辑
]

「周王興路寢，漢后成甘泉。共知崇壯麗，迢遰與雲連。抗殿疏龍首，峻陛激天泉。東西跨函谷，左右矚伊瀍。百常飛觀竦，三休複道懸。拱烏遙造日，攑虯遠架煙。雲棟疑飛雨，風窗似望僊。玉女臨芳鏡，金璫映彩椽。梅梁橫發蕊，藻井倒披蓮。雲光開御宿，佳氣屬祈年。霜鴈排空斷，寒花映日鮮。負扆憑霄極，台司列象躔。」登臺諠大夏，御氣響鈞天。北斗承三獻，南風入五絃。
鸞歌鳷鵲右，獸舞射熊前。翔鶤仰不逮，燕雀徒聯翩。

《詠雙闕》
江總
[
编辑
]

象闕連馳道，天宇照方疏。刻鳳棲清漢，圖龍入紫虛。
屢逢膏露灑，幾遇祥煙初。競言百尺麗，寧方萬丈餘。

《侍宴臨芳殿》
前人
[
编辑
]

鐘箭自徘徊，皇堂薦羽杯。橋平疑水落，石迥見山開。
林前暝色靜，花處近香來。西嵫傷撫夕，北閣濫遊陪。

《侍宴瑤泉殿》
前人
[
编辑
]

水亭通枍詣，石路接堂皇。野花不識采，旅竹本無行。
雀驚疑欲曙，蟬噪似含涼。何言金殿側，亟奉瑤池觴。

《從駕幸金墉城》
北魏·溫子昇
[
编辑
]

茲城實佳麗，飛甍自相並。膠葛擁行風，岧嶢閟流景。
御溝屬清洛，馳道通丹屏。湛淡水成文，參差樹交影。
長門久已閉，離宮一何靜。細草緣玉階，高枝蔭桐井。
微微夕渚暗，肅肅暮風冷。神行揚翠旗，天臨肅清警。
伊臣從下列，逢恩信多幸。康衢雖已泰，弱力將安騁。

《過舊宮》
明·帝
[
编辑
]

玉燭調秋氣，金輿歷舊宮。還如過白水，更似入新豐
​
秋潭漬晚菊，寒井落疏桐。舉杯延故老，今聞歌《大風》。

《乾陽殿受朝》
隋·煬帝
[
编辑
]

新邑建嵩嶽，雙闕臨洛陽。圭景正八表，道路均四方。
碧空霜華淨，朱庭皎日光。纓珮既濟濟，鐘鼓何鍠鍠。
文戟翊高殿，彩旄分修廊。

《江都宮樂歌》
同前
[
编辑
]

揚州舊處可淹留，臺榭高明復好遊。風亭芳樹迎早
夏，長皋麥隴送餘秋。淥潭桂楫浮青雀，果下金鞍躍
紫騮。綠觴素蟻流霞飲，長袖清歌樂戲州。

《乾陽殿受朝應詔》
牛弘
[
编辑
]

恭己臨萬㝢，宸居御八埏。作貢菁茅集，來朝圭黻連。
司儀三揖盛，掌禮九賓虔。重欄映如璧，複殿繞非煙。

《帝京篇》
唐·太宗
[
编辑
]

秦川雄帝宅，函谷壯皇居。綺殿千尋起，離宮百雉餘。
連甍遙接漢，飛觀迥凌虛。日月隱層闕，風煙出綺疏。

《奉和春日幸望春宮》
張說
[
编辑
]

別館芳菲上苑東，飛花淡蕩御筵紅。城臨渭水天河
靜，闕對南山雨露通。遶殿流鶯凡幾樹，當蹊亂蝶許
多叢。春園既醉心和樂，共識皇恩造化同。

《奉和春日幸望春宮應制》
蘇頲
[
编辑
]

東望望春春可憐，更達晴日柳含煙。宮中下見南山
盡，城上平臨北斗懸。細草偏承迴輦處，飛花故落舞
觴前。宸遊對此歡無極，鳥弄歌聲雜管絃。

《奉和春日幸望春宮》
崔湜
[
编辑
]

淡蕩春光滿曉空，逍遙御輦入離宮。山河降望雲天
外，臺榭參差煙霧中。庭際花飛錦繡合，枝間鳥囀管
絃同。即此歡娛齊鎬宴，唯應率舞樂《薰風》。

《奉和幸上陽宮侍宴應制》
宗楚客
[
编辑
]

紫庭金鳳闕，丹禁玉雞川。似立蓬瀛上，疑遊崑閬前。
鳥將歌《合囀》，花共錦爭鮮。湛露飛堯酒，薰風入舜絃。
水光搖落月，樹色帶晴煙。向夕迴琱輦，佳氣滿巖泉。

《麟趾殿侍宴應制》
宋·之問
[
编辑
]

北闕層城峻，西宮複道懸。乘輿歷萬戶，置酒望三川。
花柳含丹日，山河入綺筵。欲知陪賞處，空外有飛煙。

《冬夜寓直麟閣》
前人
[
编辑
]

直事披三省，重關祕七門。廣庭憐雪淨，深屋喜爐溫。
月幌光虛馥，風窗竹暗喧。東山白雲意，茲夕寄琴樽。

《晚出左掖》
杜甫
[
编辑
]

晝刻傳呼淺，春旗簇仗齊。退朝花底散，歸院柳邊迷。
樓雪融城濕，宮雲去殿低。避人焚《諫草》，騎馬欲雞棲。

《春夜宴左省》
前人
[
编辑
]

花隱掖垣暮，啾啾棲鳥過。星臨萬戶動，月傍九霄多。
不寐聽金鎖，因風想玉珂。明朝有封事，數問夜如何。

《宣政殿退朝晚出左掖》
前人
[
编辑
]

天門日射黃金榜，春殿晴薰赤羽旗。宮草霏霏承委
珮，爐煙細細駐遊絲。雲近蓬萊常五色，雪殘鳷鵲亦
多時。侍臣緩步歸青瑣，退食從容出每遲。

《紫宸殿退朝》
前人
[
编辑
]

戶外昭容紫袖垂，雙瞻御座引朝儀。香飄合殿春風
轉，花覆千官淑景移。晝漏稀聞高閣報，天顏有喜近
臣知。宮中每出歸東省，會送夔龍集鳳池。

《奉和賈舍人早朝大明宮》
前人
[
编辑
]

五夜漏聲催曉箭，九重春色醉仙桃。旌旗日暖龍蛇
動，宮殿風微燕雀高。朝罷香煙攜滿袖，詩成珠玉在
揮毫。欲知世掌絲綸美，池上於今有鳳毛。

《奉和賈舍人早朝大明宮》
岑參
[
编辑
]

雞鳴紫陌曙光寒，鶯囀皇州春色闌。金闕曉鐘開萬
戶，玉階仙仗擁千官。花迎劍佩星初落，柳拂旌旗露
未乾。獨有鳳凰池上客，《陽春》一曲和皆難。

《西省即事》
前人
[
编辑
]

西掖重雲開曙色，北山疏雨點朝衣。千門柳色連青
瑣，三殿花香入紫微。平明端笏陪鵷列，薄暮垂鞭信
馬歸。官拙自悲頭白盡，不如巖下掩荊扉。

《奉和太常王卿酬李舍人中書寓直春夜對月見寄》
盧綸
[
编辑
]

露如輕雨月如霜。不見星河見鴈行。虛暈入池波自
泛。滿輪當苑桂偏香。春臺幾望黃龍闕。雲路寧分「白玉廊。」「是夜」「巴歌」應「金石。」豈殊螢影對清光。

《奉酬李舍人秋日寓直見寄》
張南史
[
编辑
]

秋日金華直。遙知玉佩清。九重門更肅。五色詔初成。
槐落宮中影。鴻高芳遠聲。翻從魏闕下。江海寄幽情。

《宮中行樂詞四首》
李白
[
编辑
]

柳色黃金嫩，梨花白雪香。玉樓巢翡翠，金殿鎖鴛鴦。
選妓隨雕輦，徵歌出洞房。宮中誰第一？《飛燕》在昭陽。

又

《盧橘》為秦樹，葡萄出漢宮。煙花宜落日，絲管醉春風。

漢司馬相如《上林賦》，「高廊四注，重坐曲閣，華榱璧璫，輦道纚屬，步簷周流，長途中宿，夷嵕築堂，纍臺增成，巖窔洞房，俯杳眇而無見，仰攀橑而捫天，奔星更於閨闥，宛虹拖於輴軒，青龍蚴蟉於東廂，象輿婉僤於西清，靈圄燕於閒館，偓佺之倫，暴於南榮。」
《長門賦》「正殿塊以造天兮，鬱並起而穹崇。間徙倚於東廂兮，觀夫靡靡而無窮。擠玉戶以撼金鋪兮，聲噌吰而似鐘音。刻木蘭以為榱兮，飾文杏以為梁。羅丰茸之游樹兮，離樓梧而相撐。施瑰木之欂櫨兮，委參差以槺梁。時髣髴以物類兮，象積石之將將。五色炫以相耀兮，煥爛煜而成光。緻錯石之瓴甓兮，象瑇瑁」之文章。張羅綺之幔帷兮，垂楚組之連綱。撫《枉楣》以
從容兮，覽《曲臺》之央央。

班固《西都賦》：「其宮室也，體象乎天地，經緯乎陰陽。據坤靈之正位，放太紫之圓方。樹中天之華闕，豐冠山之朱堂。因瑰材而究奇，抗應龍之虹梁。列棼橑以布翼，荷棟桴而高驤。雕玉瑱以居楹，裁金璧以飾璫。發五色之渥彩，光爓朗以景彰。於是左墄右平，重軒三階。閨房周通，門闥洞開。列鐘簴於中庭，立金人於端」闈，仍增崖而衡閾，臨峻路而啟扉。徇以離宮別寢，承
以崇臺閒館，煥若列宿，紫宮是環，清涼宣溫，神仙長
年，金華玉堂，白虎麒麟，區宇若茲，不可殫論。增盤業
蛾，登降照爛，殊形詭制，每各異觀，乘茵步輦，唯所息
宴。後宮則有掖庭椒房，后妃之室，合歡增城，安處常
寧，𦶜若椒風，披香發越。蘭林蕙草，鴛鸞飛翔之列。昭
陽特盛，隆于孝成。屋不呈材，牆不露形，裛以藻繡，絡
以綸連。隋侯明月，錯落其間。金缸銜璧，是為列錢。翡
翠火齊，流耀含英，懸藜垂棘，夜光在焉。於是元墀釦
砌，玉階彤庭。碝磩綵緻琳珉，青熒珊瑚碧樹，周阿而
生。紅羅颯纚，綺組繽紛。精曜華燭，俯仰如神。
〈又〉
「周廬千列，徼道綺錯，輦路經營，修塗飛閣，自未央而連桂宮，北彌明光而亙長樂，陵磴道而超西墉，掍建章而連外屬，設璧門之鳳闕，上觚稜而棲金爵。內則別風《嶕嶢》，眇麗巧而聳擢，張千門而立萬戶，順陰陽以開闔。爾乃正殿崔巍層構，厥高臨乎未央，經駘盪而出馺娑，洞枍詣以與天梁。上反宇以蓋戴，激日景而納光。神明鬱其特起，遂偃蹇而上躋。軼雲雨於大半，虹霓迴帶於棼楣。雖輕迅乎僄狡，猶愕眙而不能階。攀井幹而未半，目眩轉而意迷。捨櫺檻而卻倚，若顛墜而復稽。魂怳怳以失度，巡迴途而下低。既懲懼於登望，降周流以徬徨。步甬道以縈紆，又杳窱而不見陽。排飛闥而上出，若遊目於天表，似無依而洋洋。」張衡《西京賦》：「爾乃覽秦制，跨周法。狹百堵之側陋，增九筵之迫脅。正紫宮於未央，表嶢闕於閶闔。疏龍首以抗殿，狀嵬峨以岌嶪。亙雄虹之長梁，結棼橑以相接。蔕倒茄於藻井，披紅葩之狎獵。飾華榱與璧璫，流景耀之韡曄。彫楹玉磶，繡栭雲楣。三階重軒，鏤檻文㮰。右平左墄，青瑣丹」墀刊層。平堂設砌，厓隒坻崿鱗
眴，棧齴巉嶮，襄岸夷塗，修路峻險，重門襲固，姦宄是
防。仰福帝居，陽曜陰藏，洪鐘萬鈞，猛虡趪趪，負筍業
而餘怒，乃奮翅而騰驤。朝堂承東，溫調延北，西有玉
臺，聯以昆德，嵯峨崨嶪，罔識所則。若夫長年神仙，宣
室玉堂，麒麟朱鳥，龍興含章，譬眾星之環北極，叛赫
戲以輝煌。正殿路寢，用朝群辟。大廈耽耽，九戶開闢。
嘉木樹庭，芳草如積。高門有閌，列坐金狄。內有常侍
謁者，奉命當御。外有蘭臺金馬，遞宿迭居。次有天祿，
石渠，校文之處，重以處威章溝，嚴更之署，徼道外周，
千廬內附。衛尉八屯，警夜巡晝。植鎩懸。𤟢「用戒不虞。」後宮則昭陽飛翔，增成合驩，蘭林披香，鳳凰鴛鸞，群
窈窕之華麗，嗟內顧之所觀。故其館室次舍，采飾纖
縟，裛以藻繡，文以朱綠，翡翠火齊，絡以美玉，流懸黎
之夜光，綴隨珠以為燭。金戺玉階，彤庭煇煇，珊瑚琳
碧，瓀珉璘彬，珍物羅生，煥若崑崙。雖厥裁之不廣，侈
靡踰乎至尊。於是鉤陳之外，閣道穹窿。屬長樂與明
光，徑北通於桂宮。命般爾之巧匠，盡變態乎其中。於
是後宮不移，樂不徙懸；門衛供帳，官以物辦。恣意所
幸，下輦成燕。窮年忘歸，猶弗能遍。瑰異日新，殫所未
見。惟帝王之神麗，懼尊卑之不殊。雖斯宇之既坦，心
猶憑而未攄。思比象於紫微，恨阿房之不可廬。
「往昔之遺館，獲林光於秦餘。處甘泉而爽塏，乃隆崇而弘敷。」既新作于迎風，增露寒與儲胥，託喬基於山岡
​
直墆霓以高居，通天訬以竦峙，徑百常而莖擢，上斑

華以交紛，下刻陗其若削，翔鶤仰而弗逮，況青鳥與
黃雀，伏櫺檻而頫聽，聞雷霆之相激。柏梁既災，越巫
陳方，建章是經，用厭火祥。營宇之制，事兼未央。圜「闕竦以造天，若雙碣之相望。鳳鶱翥於甍標，咸愬風而欲翔。閶闔之內，別風嶕嶢，何工巧之瑰瑋，交綺豁以疏寮，干雲霧而上達，狀亭亭以岧岧。神明崛其特起，井幹疊而百增，峙遊極於浮柱，結重欒以相承。累層構而遂躋，望北辰而高興。消雰埃於中宸，集重陽之清澂。瞰宛虹之長鬐，察雲師之所」憑。上飛闥而仰眺，
正睹瑤光與玉繩。將乍往而未半，怵悼慄而聳兢。非
都盧之輕趫，孰能超而究升。馺娑駘盪，燾奡桔桀。枍
詣承光，睽罛庨豁。增桴重棼，鍔鍔列列。反宇業業，飛
檐巘巘。流景內照，引曜日月。天梁之宮，實開高闈。旗
不脫扃，結駟方蘄。櫟輻輕騖，容於一扉。長廊廣廡，連
閣雲蔓。閈庭詭異，門千戶萬。重閨幽闥，轉相逾延。望
䆗窱以徑廷，眇不知其所返。既乃珍臺蹇產以極壯，
磴道邐倚以正東。似閬風之遐坂，橫西洫而絕金墉。
城尉不弛柝，而內外潛通。

《東京賦》「乃新崇德，遂作德陽，啟南端之特闈，立應門之將將，昭仁惠於崇賢，抗義聲於金商，飛雲龍于春路，屯神虎于秋方，建象魏之兩觀，旌六典之舊章，其內則含德章臺，天祿宣明，溫飭迎春，壽安、永寧，飛閣神行，莫我能形，濯龍芳林，九谷八溪，芙蓉覆水，秋蘭被涯，渚戲躍魚，淵游龜蠵。永安離宮，修竹冬青，陰池」幽流，元泉洌清。鵯鶋秋棲，鶻鵰春鳴，瞗鳩鸝黃，關關
嚶嚶。於南則「前殿靈臺，和驩安福，謻門曲榭，邪阻城洫，奇樹珍果，鉤盾所職。西登《少華》，亭候修敕，九龍之門，實曰嘉德。西南其戶，匪雕匪刻，我后好約，乃宴斯息。」於東則洪池清籞，淥水澹澹，內阜，川禽外豐，葭菼，
獻鱉蜃與龜魚，供蝸蠯與菱芡。其西則有平樂都場
示遠之觀。龍雀蟠蜿，天馬半漢，瑰異譎詭，燦爛炳煥。

結雲閣之崔嵬，植神木與靈草，紛蓊蔚以參差。爾
乃置天臺於辰角，列執法於西南，築舊章之兩觀，綴
長廊之步欄，重閨禁之窈窕，造華蓋之幽深，儉則不
陋，奢則不盈，黎民子來，不督自成，於是天子乃具法
服，戒群僚，鐘鼓隱而雷鳴，警蹕嘈而響起，晻藹低徊

韋誕《景福殿賦》：「瞻大廈之穹崇，結層構而高驤。修棟迪以虹指，飛甍竦而鳳翔。榱桷駢逼以星羅，軒檻曼延而悠長。伏應龍於反宇，乘流蘇以飄揚。於是周覽升降，流目評觀。叢楹負極，飛檻承欒。桁梧綺錯，楶梲鱗攢。芙蓉倒植，藻井懸川。望舒涼室，羲和溫房。元冬則煖，炎夏則涼，總寒暑於區宇，制天地之陰陽。又有」外城金狄，詭貌殊姿，列於應門，肅有容威。若乃離殿
別館，粲若列星，安昌延休，清晏永寧。美百號之特居，
嘉休祥之令名，步雕輦以逍遙，時容與於蘭庭。又有
教坊講肆，才士布列，新詩變聲，曲調殊別。吟清商之
激哇，發角徵與《白雪》，音感靈以動物，超世俗以獨絕。

夏侯惠《景福殿賦》「周步堂宇，東西眷眄。彩色光明，燦爛流延。素壁皜瀁，赫奕倩練。爾乃察其奇巧，觀其微形。嶔崟紆曲，盤牙攲傾。或夭矯而雲起，或詰屈而環縈。眾木附枝以連注，欒梧倚亞而相經。若乃仰觀綺窗，周覽芰荷。流彩的皪，微秀發華。纖莖葳蕤，順風揚波。含光內燿，婀娜紛葩。曾櫨外周，榱桷內附。或因勢以連接，或邪詭以盤構。於是乎飛閣連延，馳道四周。高樓承雲，列觀若浮。挹朝露之華精，漱醴泉之清流。」唐李白《明堂賦》：「勢拔五嶽，形張四維。軋地軸以盤根，摩天倪而創規。樓臺崛岉以奔附，城闕嶔崟而蔽虧。珍樹翠草，含華揚蕤。目瑤井之熒熒，拖玉繩之離離。㨖華蓋以儻漭，仰太微之參差。擁以禁扃，橫以武庫。獻房心以開鑿，瞻少陽而舉措。採殷制，酌夏步，雜以代室。重屋之名，括以《辰次》火木之數。壯不及奢，麗不及素。層簷屹其霞矯，廣廈鬱以雲布。掩日道，遏風路。陽烏轉影而翻飛，大鵬橫霄以側度。」近則萬木森下，

青蔥，吐祥煙之鬱嵂。九室窈窕，五闈聯綿。飛楹磊砢，
