江寧府
[
编辑
]

玉兔泉　在上江兩縣儒學二門內。秦檜未仕時宿
學，夜見白兔入地，掘之得泉。

卓錫泉　在江浦縣東北二十里，定山寺山門之右。
梁時僧達摩晏坐石巖，思西域水，以錫杖卓石，遂得
泉。

珍珠泉　在江浦縣東北二十里定山西南山麓。其
地有泉，噴出若散珠，遂以為名。東流一里，合卓錫泉，
溉田數十頃，通於江。

湯溝泉　在江浦縣北三十里駱駝峰，北流入三汊
河，溉田數十頃，通於江。

蘇州府
[
编辑
]

「石井泉」，　在虎丘山，今名「陸羽泉。」羽嘗以此泉為天
下第三。

「六品泉」，　在吳江縣南五里，張又新品為東南第六
泉。清澈甘冽，烹茶極佳。

常州府
[
编辑
]

陸子泉，　在無錫縣慧山寺南，廡石穴，源出若冰洞。
陸羽品天下水味，以廬山谷簾泉為第一，此居次，今
扁曰「天下第二泉。」令聶載原云：「泉味甚甘，異於他感錫之氣耳。」金泉，　在宜興縣西南小心山，即君山西峰下金砂
泉。《輿地志》云「金剛承小心」，謂此。

玉泉　在宜興縣張公洞側會仙巖下，寒冽淵澄，極
旱不竭，側有莽地約畝餘。明御史聞人詮命闢之，得
宋淳祐間石刻「玉泉」二字，因建亭於上。

善利泉　在江陰縣東十里綺山之側，清冽甘美。
「解崇泉」　在江陰縣東十八里真山西幽谷中，湛潔
靚深，飛埃不到，且巖嶠峻阻，林木蓊密，造者皆斂肅
焉。

淮安府
[
编辑
]

分泉，　贛榆縣西北七十里，水出石頂上，高尺餘，東
西分流，鎮名「分水」，上有龍王廟。

揚州府
[
编辑
]

第五泉　在江都北大明寺前。唐張又新《煎茶水記》
載劉伯芻謂「水之宜茶者七，揚大明寺井第五泉也。」安慶府
[
编辑
]

讓泉　在府西門外，汲者爭則竭，讓則湧。

「呂泉」，　在桐城。呂洞賓拔《劎劚泉》濟孝婦處。
「天泉」，　在桐城。明季寇圍城，城中渴甚，有小兒戲掘
一井，泉忽大湧，因連掘十數穴，皆湧泉，全城賴以存
活。

鶴泉　在潛山縣，「白鶴道人止處，鶴起泉流。」摩圍泉　在潛邑山谷寺。黃魯直最愛飲，號「摩圍老子。」應夢泉　在潛山縣西真源宮。唐元宗嘗夢遊於此，
因賜名。

靈龜泉　在潛山縣皖山西有大石，龜出泉。黃庭堅
有銘。

徽州府
[
编辑
]

聖泉　在休寧縣蓀田葉巖下。相傳明高皇訪汪院
​
判，馬蹄所觸出也。

《天井山泉》　在休寧縣西村，山二石奇峭，有數井，泉從
地湧，清深不測，為蛟龍窟。

龍泉　在婺源縣北七十里。俗傳有龍潛其下，旱禱
即應。唐呂洞賓大書「飛龍巖」三字刻於石。

洗心泉　在婺源縣西五十里，昔無水，有高僧卓錫
湧泉，湛甘泉講學於此。

薛公泉　在黟縣城內，有九井，唐少保薛稷所鑿。

池州府
[
编辑
]

南泉　在貴池縣舞上三保，地有三泉，大旱不竭，民
賴其利。

東坑泉　在府城西一百里毛嶺北。發源僅濫觴流
出，漸大而行，東注玉鏡潭，隨地作堰一十五所。
真珠泉　在青陽縣東三十里，有泉纍纍而出如珠。
「碧玉泉」　在少微峰北石巖上。世傳費拾遺烹茶於
此。

靈竇泉，　在銅陵縣。泉出石穴。

鳳陽府
[
编辑
]

漢泉　在定遠縣西五十里，源出楚泉，二泉並行，自
南而西，合流入洛，達於淮。

咄泉　在壽春縣北十里。人至其旁，大叫則大湧，小
叫則小湧，咄之則泉彌甚。

靈泉　在鳳陽縣西南清隱院內。唐元桓作《靈泉贊》。
白龜泉，　在懷遠縣荊山東南。宋蘇軾詩：「龜泉木杪出，牛乳石池漫。」「聖泉」，　在懷遠縣塗山西，阻絕之處。

磬泉　在旴眙縣，古離宮西南，有石刻曰「磬泉」，俗名
「七眼井。」徐州
[
编辑
]

拔劎泉　在徐州。世傳漢高帝入彭城，嘗軍於此，為
楚所困，漢兵渴乏，帝以劎插地，拔，即泉湧出，至今不
溢不枯，土人呼為「龍湫。」滁州
[
编辑
]

庶子泉　在瑯琊山寺，唐庶子李幼卿得名，王禹偁
有詩。

六一泉　在醉翁亭側。滁守歐陽修晚號「六一居士」，
故名。舊名「玻璃泉。」紫微泉，　在豐山，舊名「幽谷。」歐陽公建《豐樂亭》其上。
白龍泉，　在瑯琊山。歲旱禱雨輒應。

真珠泉　在滁州城西，遊者鼓掌泉側水濺射如珠，
因名。

「黑龍泉」　在全椒縣南烏龍山。泉出石竇，潦旱無盈
涸。

和州
[
编辑
]

「馬跑泉」　在含山北十五里，即昭關之泉也。

飛錫泉，　在含山縣南六十里，有太湖寺。昔無用禪
師當山腋鑿一孔出水，日取千瓢，不竭，一瓢不溢。禪
師有真身塔。

卓刀泉　在含山西七十五里，在東關嶺，有卓刀泉、
「飲馬池」，謂關公卓刀飲馬於此。

廣德州
[
编辑
]

不老泉　在州南四十里，大旱不竭，有古碑，刻「不老泉」三字。

沸泉，　在建平縣東十里。其味甘，冬溫夏涼。

妙泉　在建平縣南九十里大巖山下。

《浙江通志》
[
编辑
]

杭州府
[
编辑
]

甘露泉　在府羊市東，慈雲寺後。

周公惠泉　在湖墅下閘。宋乾道三年，周安撫淙重
修，邦人德之，故名。

沁雪泉　在錢塘縣大佛身右壁，棠陵方思道題。
「僕夫泉」　在錢塘縣，元僧芳洲所鑿也。先是智圓居
孤山，有僕夫藝竹得泉，遂號僕夫泉。後徙寺茲山，藉
葛井以汲，寺僧艱之，芳洲鑿地得此，遂名。

參寥泉　在錢塘縣智果寺。蘇軾《應夢記》云：「僕在黃州，參寥子自吳中來訪。一夕，夢參寥子賦詩，覺而記兩句：『寒食清明都過了，石泉槐火一時新』。後七年，僕守錢塘，而參寥子始卜居西湖智果院，有泉出石縫間，甘冷宜茶。寒食之明日，僕與客汎湖，自孤山來謁。參寥子汲泉鑽火，烹黃糵茶，忽憶夢兆於七年之前。眾」客皆嘆《傳記》所載，非虛語也。

六一泉　在錢塘縣孤山後巖。東坡守杭時，泉出，有
「懷六一翁」，因名，乃敘而銘之，久廢。成化丙申，南京大
理寺卿夏時正訪得於榛穢中，命掃薙而濬發之，泓
然故物也。

玉泉　在錢塘縣九里松北淨空院。齊建。元末，靈悟
大師曇超說法，龍君來聽，為撫掌出泉。今龍祠前小
方池，深不尋丈，清澈可鑒，異魚數百泳游其中。旱不
涸，潦不盈，灌溉田三千餘頃。淳祐八年，趙與𥲅甃治
龍潭，增築為二池。元末兵燹，寺燬而泉如舊。至嘉靖
間，郡守陳仕賢為亭其上。寺之後有細雨泉
​
武林泉。　西漢及晉《地理志》云：「錢塘有武林山，武林水所出，東入於海。」晏元獻《輿地志》云：「武林山，錢塘泉所出。」顧彝吾《山川記》：「自南徂東，臨浙江，一派謂之靈隱浦。」冷泉　在靈隱寺外。面飛來峰，即石門澗水浦。先時
深廣，可以通舟。宋紹興間，有善堪輿者言「靈隱，火山也，得水可以禳災。」乃建石閘以蓄水。明弘治中，山水
橫發，閘崩而浦澀。

定光泉　舊名「錫杖泉」，在西山長耳相院西定光菴
側。相傳，定光在山修行，因歲旱無水，乃以杖引泉，故
有是名。今山腰有泉，盤迴飛流，濺沫可愛。淳祐丁未
亢旱，此泉不竭，寺僧用筧引泉供廚焉。

真珠泉　在錢塘縣集慶寺內。周顯德間，泉自地迸
出，寺僧因甃為方池，聞「剝啄聲則泉益湧，纍纍如貫珠。」宋景祐中，官家取以釀酒，遂以名酒。雷峰路口張
園亦有真珠泉。

筲箕泉　在錢塘縣赤山之陰，合於惠因澗。元時有
黃子久公望者，號大癡，卜居泉上。子久善畫，有《山水
訣》傳於世。

劉公泉　在錢塘縣南高峰下出石竇間，清澈可玩。
宋常平劉常甃池，因篆書「劉公泉」三字於石。

水樂洞泉　「在錢塘縣煙霞嶺西，石洞雙啟，穹若大廈，水源左發右出，冷齧肌骨，清照毫髮，甘寒無出。其右，洞深窅無極，入數十步，空洞曠邈，投之石，鏗鍧有聲，莫知涯際。」蓮花泉　在錢塘縣飛來峰頂，石巖無土，清而可啜。
「虎跑泉」　在錢塘縣西南十里大慈山上。泉清渫而
甘寒，與龍井、玉泉相伯仲。郡城則郭婆井、吳山泉為
最。茲五泉者，杭之聖水也。

涌泉　在錢塘縣霍山清心院前山坡上。宋紹興間，
高宗日遣人取之瀹茗，寺僧護以朱欄。泉從石罅中
流出廟前，折入黃山橋小河，味極清甘，亢旱不竭。
「惠泉」　在錢塘縣長壽鄉大老山，泉自地湧出，亢旱
不涸，有寺以「泉」為名。

丹泉　在餘杭縣。此泉之源最高，歷天柱山而下，始
聞殷殷若雷。至大滌洞西百餘步乃出，甘冽不竭，有
方池瀦焉。天宇清明，則有赤色，四旁苔蘚皆為紫暈。
桃花泉，　在餘杭縣龍蛻洞之西，自石罅橫注入溪，
昔人每見有桃花片流出。張公弼詩有「洞裏有春藏未得，春風春雨泛桃花」，指此。

撫掌泉　在餘杭縣洞霄宮內。舊傳錢武肅王至宮，
有雙鶴翔舞其上，因撫掌招之，鶴下而泉湧。宋陳堯
佐按部至此，詢羽士，答曰：「昔仙人撫掌，而泉脈自湧，公撫掌亦然。」宋高宗亦嘗酌此。

龍孔泉　在昌化縣南金山玉嶺之麓。石竅中寒泉
湧出，冬夏不涸，每巨魚出遊必雨，居民賴之，為水利。
天井泉　在昌化縣西五十里，石竅深窅叵測，其中
若列梯級，可通上下寒泉涓涓灌注石面，凝結如脂，
為寒水石。昔有人執燭而入，光彩奪目。或以絲繫石
下度之，其聲鼕鼕如鼓。相傳竅通朱浪村之長潭。

湖州府
[
编辑

玉竇泉　在長興縣西南六十五里洛塢。色紺，味甘。
唐處士鄭遨與道士李道殷、羅隱築室泉上，號「三隱。」宋侍郎錢伯言作《碑記》。

半月泉　在德清縣北慈相寺中。相傳昔有梵僧曰：
「此地有泉。」因鑿之，泉出石罅間，形如半月。

蒙泉　在安吉州西，泉上有亭，味甘冽。

寧波府
[
编辑
]

昌黎泉　在府治二里南倉基內。宋紹興間，守韓仲
通建亭其上，故名。

西山「雙乳泉」　在鄞縣西三十五里資教寺北，味甘
色白。

透瓶泉　在奉化縣東三里大溪東岸。其水注以磁
器，則滲液於外。

紹興府
[
编辑
]

清白泉　在府治內清白堂側。范文正公記：「西巖下獲廢井，泉甘而色白，淵然丈餘，引不可竭。」三汲泉　在府臥龍山麓。泉淺不過，有水數斗，然汲
盡復滿不涸。

玉帶泉　在山陰縣琵琶山陽和嶺下。泉味甘而冽，
色微白，故謂之「玉帶嶺。」上有張氏墓，因後裔文恭、張
陽和鍾祥於此，遂名其嶺。

鄭公泉　在會稽縣若耶溪東，去葛仙翁釣磯不遠。
《水經注》：「泉方數丈，漢太尉鄭弘宿居潭側，因以名泉。」《輿地志》：「弘雖居台輔，常思故居。曾病困，思得此泉水。家人馳取，飲少許，便差。」《惠泉》　在會稽縣太平山，大旱不涸。

菲飲泉，　一名菲泉，在會稽縣大禹廟側，可數十步
​
真珠泉，　在會稽縣少微山，齊祖之《家山十詠泉》其
一也。

龍泉　在餘姚縣龍泉山之趾。宋高宗飲之甘，因取
十甕以去。

「杖錫泉」　在新昌縣沃洲山下。唐僧靈徹之故跡。

台州府
[
编辑

神應泉，　在新貴縣北一百二十里，地名「巴香。」出於
兩石之間，水不恆注，汲者至擊石數聲，則涓涓流出，
隨器而滿，足則復竭。

聖泉　在貴筑縣城西八里，一名「百盈」，一名「漏汋。」自
山麓涌出，晝夜百盈百竭，應刻漏之數，似有橐籥，莫
測其端。明鎮遠侯顧成甃石為池，覆以亭。池中立石，
以驗消長。旁有寺，郡人歲時遊觀。

呼應泉：　在龍里，縣城南五十里。人每呼之，水輒應
聲涌出。

珠泉　在貴定縣西三十里。泉列池中，分六七道而
出，纍纍如貫珠之不絕。

濟行泉：　在貴定縣新添關鋪，有二源出高連山穴，
行者藉此以濟渴。

馬跑泉　在關索嶺畔。相傳：索從丞相武侯征南，開

龍泉　在府城東五里。清澈，大旱不竭。

既濟泉　在鎮寧州城東北。其地極熱，而此水獨涼，
故名。

豐泉　在鎮寧州城西三里白崖山下。四時不涸，可
以灌溉。

清泉　在鎮寧州城西三里。林木森陰，一泓清瀉，中
產異蟹，或赤或紫，色極鮮妍。

白鹿泉　在安南縣南里許。水甚甘冽，四時不涸。
聖泉　出安平縣西門百步，平岡之下，忽闢石井，泉
從石罅中流出，淙淙有聲。一時之內，再增再減，盈縮
以時，曾不少輟。春時，詞人遊女，或置香花，或插簪珥，
再拜祈請，泉隨淜湃涌溢，魚蝦併出。前匯一大池，芳
潔清洌，真可濯纓。

珍珠泉　在安平縣城西，沙作鋪路傍。深數尺，寬廣
如之。泉水清澈，微作澄碧色。客至喧譁鼓掌，則數千
百珠迸逗而出，或左右大小不一。又頃則合浦夜光，

馬家泉：　在府治南十二里。泉自山麓流出，勢如瀑
布，俗稱「白水泉。」稽公泉　在府南稽公山下。蓋稽公垂釣處。有小魚
每以夏四月潛於泉底，至明年雷動乃出，漁人網之。
龍泉，　在婺川縣東二十里，其泉一日三漲，名曰「二潮。」水消則澄清，漲則混濁，人莫能測。居人資以灌溉，
田畝不病其旱。
