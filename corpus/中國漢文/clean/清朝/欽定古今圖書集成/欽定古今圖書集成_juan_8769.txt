太祖開平元年立四廟追上尊諡
[
编辑
]

按《五代史梁本紀》，開平元年秋七月己亥，追尊祖考
為皇帝，妣為皇后。皇高祖黯諡曰宣元，廟號肅祖；祖
妣范氏諡曰宣僖；曾祖茂琳諡曰光獻，廟號敬祖；祖
妣楊氏諡曰光孝；祖信諡曰昭武，廟號憲祖；祖妣劉
氏諡曰昭懿；考誠諡曰文穆，廟號烈祖，妣王氏諡曰
文惠。　按《太祖母文惠皇后王氏傳》：大順二年秋，后
疾，卜者曰：「宜還故鄉。」乃歸，卒於午溝。太祖即位，立四
廟，追尊皇考為文穆皇帝，后曰文惠皇后。

莊宗同光元年追上祖考妣諡號合唐一祖三宗為七廟
[
编辑
]

按《五代史唐本紀》：「同光元年夏閏四月，追尊祖考為皇帝，妣為皇后。曾祖執宜、祖妣崔氏皆諡曰昭烈，廟號懿祖；祖國昌、祖妣秦氏皆諡曰文景，廟號獻祖；考諡曰武，廟號太祖，立廟於太原。自唐高祖、太宗、懿宗、昭宗為七廟。」
同光三年上太后曹氏尊諡。

按《五代史唐本紀》，不載。　按《太祖正室劉氏次妃曹
氏傳》：莊宗即位，冊尊曹氏為皇太后，而以嫡母劉氏
為皇太妃。同光三年五月，太妃薨，七月，太后崩，諡曰
「貞簡」，而太妃無諡。

明宗天成二年追上四代諡號
[
编辑
]

按《五代史唐本紀》：「天成二年冬十二月丙午，追尊祖考為皇帝，妣為皇后。高祖聿諡曰孝恭，廟號惠祖，祖妣劉氏諡曰孝恭昭；曾祖敖諡曰孝質，廟號毅祖；祖妣張氏諡曰孝質；順祖琰諡曰孝靖，廟號烈祖；祖妣何氏諡曰孝靖穆；考諡曰孝成，廟號德祖，妣劉氏諡曰孝成懿，立廟於應州。」
天成四年，追上唐哀帝諡。

按《唐書哀帝本紀》：「天祐四年，皇帝遜於位，徙於曹州，號濟陰王。梁開平二年，諡曰哀帝。」後唐明宗追諡「昭宣光烈孝皇帝。」
按《五代史唐本紀》：明宗天成四年，追諡少帝曰「昭宣光烈孝皇帝。」
長興元年追冊夏氏為皇后諡昭懿
[
编辑
]

按《五代史唐本紀》，不載。　按《明宗家人傳》：「和武憲皇后曹氏生晉國公主，昭懿皇后夏氏生秦王從滎。」「夏氏無封爵，明宗未即位前卒，明宗天成元年，封楚國夫人曹氏為淑妃，追封夏氏晉國夫人。長興元年，立淑妃為皇后，而夏氏所生二子皆已王，乃追冊為皇后，諡曰昭懿。」
廢帝清泰二年追尊魏氏為皇太后諡宣憲
[
编辑
]

按《五代史唐本紀》，廢帝清泰二年春二月，追尊魯國
太夫人魏氏為皇太后。　按《明宗家人傳》，「宣憲皇后魏氏，初適平山民王氏，生子十歲矣。明宗為騎將，掠平山，得其子母以歸。居數年，魏氏卒，葬太原，其子是為潞王從珂。從珂已王，乃追封魏氏為魯國夫人。廢帝即位，追尊魏氏為皇太后，議建陵寢。而太原石敬塘」反，乃於京師河南府東立寢宮。清泰三年六月丙
寅，遣工部尚書崔儉奉上皇太后寶冊，諡曰《宣憲》。

高祖天福二年追上高祖以下考妣諡號
[
编辑

按《五代史晉本紀》：「高祖天福二年，追尊祖考為皇帝，妣為皇后。高祖璟諡曰孝安，廟號靖祖；祖妣秦氏諡曰孝安元；曾祖彬諡曰孝簡，廟號肅祖；祖妣安氏諡​曰孝簡恭；祖昱諡曰孝平，廟號睿祖；祖妣來氏諡曰孝平獻；考紹雍諡曰孝元，廟號獻祖，妣何氏諡曰孝元懿。」
天福五年，追上唐莊宗、愍帝二后諡。

按《五代史晉本紀》，不載。　按《唐太祖家人傳》：「莊宗神閔敬皇后劉氏。莊宗崩，后與李存渥等焚嘉慶殿，擁百騎出師子門，后於馬上以囊盛金器寶帶，欲於太原造寺為尼。在道因與存渥姦。及至太原，乃削髮為尼。明宗入立，遣人賜后死。晉天福五年，追諡曰神閔敬皇后。」　按《唐明宗家人傳》：愍帝哀皇后孔氏，后有
賢行，生四子。愍帝即位，立為皇后。未及冊命而難作。
愍帝出奔，后病子幼，皆不能從。廢帝入立，后及四子
皆見殺。晉高祖立，追諡曰「哀。」

太祖天顯元年上太祖尊諡
[
编辑
]

按《遼史太祖本紀》，天顯元年春三月「甲申，幸天福城。秋七月甲戌，次扶餘府。上不豫。辛巳上崩。年五十五。壬午，皇后稱制，權決軍國事。八月甲午，皇后奉梓宮西還。丁卯，梓宮至皇都，權殯於子城西北。己巳，上諡昇天皇帝，廟號太祖。」　按《禮志》上諡冊儀，「先一日，於菆塗殿西廊設御幄并臣僚幕次。大樂令展宮懸於殿」庭。協律郎設舉麾位。至日北，南面，臣僚朝服。昧爽
赴藂塗殿。先置冊寶案於西廊下，閤使引皇帝至御
幄，服寬衣皂帶，臣僚班齊，分班引入嚮殿，合班立定，
引冊案上殿，至褥位，寶案次之，設於西階。閤使引皇
帝自西階升殿，初行樂作，至位立樂止。宣徽使揖皇
帝鞠躬再拜，陪位者皆再拜。翰林使執臺琖以進，皇
帝再拜，引至神座前，跪奠三，樂作，進奠訖，復位，樂止，
又再拜，陪位者皆再拜。引皇帝於神座前北面立。捧
冊函者去蓋，進前跪，冊案，退置殿西壁下。引讀冊者
進前，俛伏跪。自通全銜臣讀諡冊，讀訖，俛伏，興，復位。
捧冊函者置於案上。捧寶函者進前跪，讀寶官通銜
跪讀訖，引皇帝至褥位，再拜，陪位者皆再拜。禮畢，引
皇帝歸御幄。《初行樂》作，至御幄，樂止，引臣僚分班出。
若皇太后奠酒，依常儀。

太宗天顯九年上太皇太后諡
[
编辑
]

按《遼史太宗本紀》：天顯八年冬十一月辛丑，太皇太
后崩。九年春二月「戊寅，葬太皇太后於德陵，後追諡宣簡皇后，詔建碑於陵。」
天顯十年，上皇后諡。

按《遼史太宗本紀》：天顯九年「秋八月壬午，自將南伐。冬十二月壬辰，皇后不豫。是月，駐蹕百湖之西南。十年春正月戊申，皇后崩於行在。二月戊寅，百僚請加諡，不許。夏五月甲午朔，始製服行后喪。丙午，葬於奉陵。上自製文，諡曰彰德皇后。」
世宗天祿元年上皇考尊諡
[
编辑
]

按《遼史世宗本紀》，「世宗孝和莊憲皇帝，讓國皇帝長子，太宗愛之如子。大同元年二月，封永康王。四月丁丑，太宗崩，戊寅，即皇帝位。九月丁卯，行柴冊禮，大赦。改大同元年為天祿元年。追諡皇考曰讓國皇帝。」

聖宗統和元年上景宗諡
[
编辑

按《遼史聖宗本紀》不載　按《景宗本紀》，統和元年正
月「壬戌，上尊諡孝成皇帝，廟號景宗​統和二十六年秋七月，增太祖、太宗、讓國皇帝、世宗諡，仍諡皇太弟李胡曰『欽順皇帝』。」

重熙二十一年加上太祖之祖考以下帝后尊諡
[
编辑
]

按《遼史興宗本紀》：「重熙二十一年秋七月壬子，追尊太祖之祖為簡獻皇帝，廟號元祖；祖妣為簡獻皇后；太祖之考為宣簡皇帝，廟號德祖，妣為宣簡皇后。九月己未，謁懷陵。庚申，追上嗣聖皇帝、天順皇帝尊諡，及更諡彰德皇后曰靖安，癸亥，諡齊天皇后曰仁德皇后。甲子，謁祖陵，增太祖諡『大聖大明神烈天皇帝』」，
更諡貞烈皇后曰淳欽，恭順皇帝曰「章肅」，后蕭氏諡
曰「和敬。」冬十月辛丑，謁乾陵。十一月壬寅朔，增諡文
獻皇帝為「文獻欽義皇帝」，及諡二后曰「端順」、曰「柔貞。」復更諡世宗孝烈皇后為「懷節。」丁未，增孝成皇帝諡
曰「孝成康靖皇帝」，更諡聖神宣獻皇后為睿智。　按
《太祖本紀》，重熙二十一年九月，加諡大聖大明神烈
天皇帝。　按《太宗本紀》，重熙二十一年九月，增諡「孝武惠文皇帝。」　按《穆宗本紀》，應曆十九年，帝遇弒，年
三十九，廟號穆宗，後附葬懷陵。重熙二十一年，諡曰
「孝安敬正皇帝。」　按《景宗本紀》，重熙二十一年，加諡
孝成康靖皇帝。

太祖建隆元年上高曾祖考帝后尊諡
[

太平興國八年八月辛亥，增《諡法》。

按《宋史太宗本紀》云云。　按《禮志》定諡，「王公及職事官三品以上薨，本家錄行狀上尚書省考功移太常禮院議定。博士撰議，考功審覆，判都省集合省官參議，具上中書門下宰臣判準，始錄奏聞。」敕付所司，即
考功錄牒，以未葬前賜其家省官，有異議者聽具議
聞。蘊德丘園，聲實明著，雖無官爵亦奏賜諡曰「先生。」太平興國八年，詔增《周公諡法》五十五字，美諡七十
一字為一百字，平諡七字為二十字，惡諡十七字為
三十字，其沈約、賀琛《續廣諡》盡廢後以直史館胡旦
言：「舊制，文武官臣僚皆以功行上下各賜諡法，近朝以來，遂成闕典。建隆以後，臣僚三品以上合賜諡者百餘人，望令史館編錄行狀，送禮官定諡，付館，修入國史。」詔：今後並令禮官取行狀定諡，送考功詳覆，關
送史館，永為定式。直集賢院王皞言：「諡者，行之表也，善行有善諡，惡行有惡諡。蓋聞諡知行以為勸戒。《六典》：太常博士掌王公以下擬諡，皆跡其功德，為之褒貶。近者臣僚薨卒，雖官該擬諡，其家自知父祖別無善政，慮定諡之際，斥其繆戾，皆不請諡。竊惟《諡法》自周公以來，垂為不刊之典，蓋以彰善癉惡，激濁揚清，使其身沒之後，是非較然，用為勸懲。今若任其遷避，則為惡者肆志而不悛。乞自今後不必候其請諡，並令有司舉行。」如此，則隱慝無行之人，有所沮勸。若須
行狀申乞，方行擬諡。考諸方冊，別無明證。惟衛公叔
文子卒，「其子戌請諡。臣謂《春秋》之時，禮壞樂闕。公叔之卒，有司不能明舉舊典，故至將葬始請諡於君。且《周制》，太史掌小喪賜諡，小史掌卿大夫之家賜諡請誄。以此知有司之職，自當舉行明矣。」詔下有司詳定，
如皞請焉。

而為新制不必有諡，豈非誣哉！又有故闕禮，追遠請
諡，皆違禮《經》，何順之有？國家給諡，一用唐令，然請諡
之家，例供尚書省官酒食，撰議官又當有所贈遺，故
或闕而不請。景祐四年，宋綬建議，令官給酒食，其後
又罷贈遺，自此既葬請諡者甚眾。「歲月浸久，官閥行跡，士大夫所不能知，子孫與門生故吏志在虛美隱惡，而有司据以加諡，是廢聖人之法而徇唐庸有司之議也。」詔：「自今得諡者，令葬前奏請。或其家不請，則尚書、太常合議定諡，葬前牒史館及付其家。若徇私諡不以實論，如選舉不」以實法。既葬請諡者不定諡。

寧殿，諡曰「憲文肅武宣孝皇帝，廟號英宗。」　按《神宗
本紀》，治平四年正月丁巳，英宗崩，帝即皇帝位。「夏四月庚戌，請大行皇帝諡於南郊，秋七月，告英宗憲文肅武宣孝皇帝諡於天地、宗廟、社稷，上寶冊於福寧殿。」
神宗元豐三年上太皇太后諡
[
编辑
]

按《宋史神宗本紀》：「元豐二年，太皇太后崩。三年，上太皇太后諡曰『慈聖光獻』。」
元豐六年，加上仁宗、英宗諡。

按《宋史神宗本紀》，元豐六年十二月，加上仁宗諡曰
「體天法道極功全德神文聖武睿哲明孝皇帝」，英宗
曰「體乾應曆隆功聖德憲文肅武睿神宣孝皇帝。」按《禮志》，神宗元豐六年五月，改加上尊諡，作「奉上徽號。」十一月二日，奉上仁宗徽號曰「體天法道極功全德神文聖武睿哲明孝皇帝」，又上英宗徽號曰體乾
應「曆隆功聖德憲文肅武睿神宣孝皇帝。」
元豐八年，上「大行皇帝」諡。

按《宋史神宗本紀》，元豐八年三月，上崩於福寧殿，皇
太子即皇帝位，上大行皇帝諡曰「英文烈武聖孝皇帝，廟號神宗。」　按《哲宗本紀》，元豐八年九月，「以神宗英文烈武聖孝皇帝之諡，告於天地宗廟、社稷，上寶冊於福寧殿。」
哲宗元祐八年上太皇太后諡
[
编辑

按《宋史哲宗本紀》：「元祐八年九月，太皇太后崩。十二月，上太皇太后諡曰『宣仁聖烈皇后』。」
紹聖二年加上神宗諡
[
编辑
]

按《宋史哲宗本紀》：紹聖二年九月，加上神宗諡曰紹
天法古運德建功英文烈武欽仁聖孝皇帝。　按《禮
志》，哲宗紹聖二年正月，帝謂輔臣曰：「祖宗諡號各加至十六字。神宗皇帝今止初諡，尚未增加，宜考求典故以聞。」宰臣章惇等對曰：「祖宗加諡，歲月不定，真廟初加八字，是天聖二年。今神宗祔廟已十年，故事，加徽號必在南郊前，謹如聖旨討閱以聞。」四月二十七
日，詔加上神宗皇帝徽號，於大禮前三日行禮。九月
十六日，奉上冊寶曰《神宗紹天法古運德建功英文
烈武欽仁聖孝皇帝》。

政和三年追上崇恩太后貴妃劉氏並加神宗哲宗諡
[
编辑

按《宋史徽宗本紀》，政和三年四月，上崇恩太后諡曰
「昭懷」，九月追冊貴妃劉氏為皇后，諡曰「明達。」冬十一
月饗太廟，加上神宗諡曰「體元顯道法古立憲帝德王功英文烈武欽仁聖孝皇帝」，改上哲宗諡曰「憲元繼道世德揚功欽文睿武齊聖昭孝皇帝。」　按《禮志》，
政和三年十一月五日加上神宗、哲宗徽號，前二日，
皇帝御大慶殿，奉神宗冊、寶授太師、魯國公蔡京，載
以玉輅；奉哲宗冊、寶授少師、太宰何執中，載以金輅；
並詣太廟幄殿奉安以俟。四日，皇帝詣景靈宮行禮，
赴太廟宿齋五日，服袞冕，恭上神宗冊、寶於本室，曰
「體元顯道法古立憲帝德王功英文烈武欽仁聖孝皇帝。」又上哲宗冊寶於本室，曰「憲元繼道世德揚功欽文睿武齊聖昭孝皇帝。」次行朝享禮畢。赴南郊青
