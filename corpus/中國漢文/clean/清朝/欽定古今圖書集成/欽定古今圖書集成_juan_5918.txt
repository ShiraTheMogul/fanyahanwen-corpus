《獨不見》
唐·楊巨源
[
编辑
]

東風艷陽色，柳綠花如霰。競理同心鬟，爭持合歡扇。
香傳賈娘手，粉離何郎面。最恨卷簾時，含情獨不見。

《大堤曲》
前人
[
编辑
]

二八嬋娟大堤女，開壚相對依江渚。待客登樓向水
看，邀郎卷幔臨花語。細雨濛濛濕芰荷，巴東商旅駐
帆多。自傳芳酒翻紅袖，誰調妍妝回翠蛾。珍
華鐙
​
夕陽後，當壚理瑟矜纖手。月落星微五鼓聲，春風搖
蕩窗前柳。歲歲逢迎沙岸間，背人多整綠雲鬟。無端
嫁與五陵少，離別煙波傷玉顏。

《春閨思》
令狐楚
[
编辑
]

戴勝飛晴野，凌澌下濁河。春風樓上望，誰見淚痕多。

《遠離別二首》
前人
[
编辑

『楊柳黃金穗，梧桐碧玉枝。春來消息斷，早晚是歸時』。
玳織鴛鴦履，金裝翡翠篸。畏人相問著，不擬到城南。

《青青水中蒲三首》
韓愈
[
编辑
]

青青水中蒲，下有一雙魚。君今上隴去，我在與誰居。
青青水中蒲，長在水中居。寄語浮萍草，相隨我不如。
青青水中蒲，葉短不出水。婦人不下堂，行子在萬里。

《閨人贈遠四首》
王涯
[
编辑
]

遠戍功名薄，深閨年貌傷。妝成對春樹，不語淚千行。
鶯啼綠樹深，燕語雕梁晚。不省出門行，沙場知近遠。
形影一相別，煙波千里分。君看望君處，只是起行雲。
花明綺陌春，柳拂御溝新。為報遼陽客，流光不待人。

[
编辑

《秋思贈遠二首》

[
编辑

當年只自守空帷，夢裏關山覺別離。不見鄉書傳鴈
足，唯看新月吐蛾眉。

厭攀楊柳臨清閣，閒採芙蕖傍碧潭。走馬臺邊人不

《春閨思》
前人
[
编辑

《古意》
陳羽
[
编辑
]

「十三學繡羅衣裳，自憐紅袖聞馨香。人言此是嫁時服，含笑不刺雙鴛鴦。」郎年十九髭未生，拜官天下聞
郎名。車馬駢闐賀門館，自然不失為公卿。是時妾家
猶未貧，兄弟出入雙車輪。繁華全盛兩相敵，與郎年
少為婚姻。郎家居近御溝水，豪門客盡躡珠履。雕盤
酒器常不乾，曉入中廚妾先起。姑嫜嚴肅有規矩，小
「姑嬌憨意難取。朝參暮拜白玉堂，繡衣著盡黃金縷。妾貌漸衰郎漸薄，時時強笑意索寞。知郎本來無歲寒，幾回掩淚看花落。妾年四十絲滿頭，郎年五十封公侯。男兒全盛日忘舊，銀床羽帳空颼飀。庭花紅遍蝴蝶飛，看郎佩玉下朝時。歸來略略不相顧，卻令侍婢生光輝。郎恨婦人易衰老，妾亦恨」深不忍道。看郎
強健能幾時，年過六十還枯槁。

《公子行》
前人
[
编辑
]

《金羈白馬》郎，何處踏青來。馬驕郎半醉，躞蹀望樓臺。
似見樓上人，玲瓏窗戶開。隔花聞一笑，落日不知回。

《汝川行》
毆陽詹
[
编辑
]

汝墳春女蠶忙月，朝起採桑日西沒。輕綃裙露紅羅
襪，半蹋金梯倚枝歇。垂空玉腕若無骨，映葉朱唇似
花發。相歡誰是遊冶郎，蠶休不得岐路旁。

《採菱行》
〈并引一作採芰女〉
劉禹錫
[
编辑
]

武陵俗嗜芰菱。歲秋矣，有女郎盛遊於馬湖，薄言採之，歸以御客。古有《採菱曲》，罕傳其詞，故賦之以俟採詩者。

白馬湖平秋日光，紫菱如錦綵鴛翔。蕩舟遊女滿中
央，採菱不顧馬上郎。爭多逐勝紛相向，時轉蘭橈破
輕浪。長鬟弱袂動參差，釵影釧文浮蕩漾。笑語哇咬
顧晚暉，蓼花綠岸扣舷歸。歸來共到石橋步，野蔓繫
船萍滿衣。家家竹樓臨廣陌，下有連牆多估客。攜觴
薦芰夜經過，醉踏《大隄》《相應歌》。屈平祠下沅江水，月
照寒波白煙起。一曲南音此地聞，長安北望三千里。

《同樂天和微之春深》
〈二十首錄二〉
前人
[
编辑
]

何處深春好，春深少婦家。能偷新禁曲，自剪入時花。
追逐同遊伴，平章貴價車。從來不墮馬，故遣髻鬟斜。
何處深春好，春深幼女家。雙鬟梳頂髻，兩面繡帬花。
妝壞頻臨鏡，身輕不占車。鞦韆爭次第，牽拽綵繩斜。

《古意》
前人
[
编辑
]

「蕩子守邊戍，佳人莫相從。」去來年月多，苦愁改形容。
上山復下山，踏草成古蹤。徒言採蘼蕪，十度一不逢。
鑒獨是明月，識志唯寒松。井桃始開花，一見悲萬重。
人顏不再春，桃色有再濃。捐氣入空房，無憀乍從容。
