火鉞妻葉氏
[
编辑
]

按《江都縣志》：「葉氏，名肅貞，揚州衛舍人火鉞妻。夫亡，守節終身。」劉昊妻許氏
[
编辑
]

按《江都縣志》：「許氏，劉昊妻。孀居六十年，撫子棟，為滑縣尉。次繼成，郡諸生。孫惟珍，寶坻縣尉，皆許氏力也。」許某妻周氏
[
编辑
]

按《江都縣志》：「周氏，名貞卿，郡諸生許某妻。年二十二歸許。二年，許亡，無子，以姪某為後。卒年八十。」李廷用妻陳氏
[
编辑
]

按《儀真縣志》：陳氏，李廷用妻。性貞靜嚴潔，嚬笑不苟。
生二子未丱角而廷用即世。陳年二十九，哀毀已絕
復蘇。既而曰：「死則死耳，匪所以存吾孤也。」遂苦節撫
孤，有剉薦畫荻之風。卒年七十七。同里黃秋谷誌其
墓。

謝朝恩妻劉氏
[
编辑
]

按《儀真縣志》：劉氏，謝朝恩妻，豫章梓溪世家女也。生
子早殤，年二十九，恩亡，劉哭曰：「吾不忍謝氏無後。」撫
四歲嗣子士英，愛之過於己出。年八十，郡縣旌之。

李杞妻張氏
[
编辑
]

按《儀真縣志》：張氏，李杞妻。年三十，杞死，家無生產，子
女各二，齒俱穉。母家令改節，張曰：「不敢以子女重傷高堂心，遺地下憾。」躬䌟纑以教其子。姑久病，晝夜不
離左右三月，歷苦節四十年如一日。

侯詔妻高氏
[
编辑
]

按《儀真縣志》：「高氏，侯詔妻。年二十詔死，教子惟光、惟墉成立。守志六十餘年，冰霜之操如一日。縣令旌表。」萬煥妻張氏
[
编辑
]

按《儀真縣志》：「張氏，字少姬，萬煥妻，義士張東溪女。年十七，生子培方二齡。煥沒，姊適王，先孀。少姬感泣，告父母曰：『吾姊妹俱失所天，姊無出，尚不貳志。兒幸有子，復何求哉』！遂一意撫孤，以薑桂性，勵松柏操，三十餘年教子成立。」賀一梅妻侯氏
[
编辑
]

按《儀真縣志》：侯氏，賀一梅妻，侯維亮女。年十六適梅，
期年梅亡，誓不更適。止一子復殀，屢勸改適，輒泣謝
曰：「天能奪吾嗣，不能奪吾志。」聞者皆泣下。貧無聊生，
針刺自給，年七十二終。

侯于衛妻顧氏
[
编辑
]

按《儀真縣志》：顧氏，侯于衛妻。年二十五衛死。或以家
貧諷之，則曰：「與子女共生死耳。」家無立錐，嘗枵腹無
怨，教孤耕桑，以營衣食婚嫁。年七十有四，每憶往事，
輒復惘然。

姜起周妻陳氏
[
编辑
]

按《儀真縣志》：「陳氏，太學生嘉禾女，民部濟孫。幼嫺家訓，事繼母極孝，適姜起周，年三十而寡。教二子：長里望，有美德，以目眚廢書；次士望，成進士，官祕書，膺敕命贈孺人，遷天官，又敕命為安人。」蔣文宰妻俞氏

编辑

按《儀真縣志》：「俞氏，蔣文宰妻。年二十七，文宰死，遺子汝昌甫二歲，家窘甚，或勸他適，不聽。年八十二卒。禮部尚書林欲楫旌其門。汝昌後以武功著。」劉君用妻徐氏
[
编辑
]

按《儀真縣志》：「徐氏，劉君用妻。幼事母孝。年十六，薦股肉以愈母疾。十八適君用，已失舅姑，無妯娌。越七年，用亡。遺孤二，長芳名，四歲，次彌月，氏誓即同穴，觸棺仆地，母陳以兩孤切諭之，乃不死。家值中落，䌟纑自給，親族勸從權，徐大呼哭，死復甦。至夜分，投溺池中，以救免。自後無復敢言。及病將訣，芳名遠賈數百里」，
忽心動，并日而至，得見母面。苦守五十二年。年七十
有八。

李埴妻張氏
[
编辑

按《儀真縣志》：「林氏，陳洪振妻。年十九適振。二十八振亡，遺二孤皆在提抱，氏守之後教之讀書，充聞見。逮成人，以局幹著，苦節五十六年。八十四卒。有司旌之。」詹大化妻戴氏

按《儀真縣志》：「楊氏，黃瀹妻。年二十四瀹亡，遺孤僑甫半歲，鞠育教誨，食貧四十七年，內外咸憚之。嘉靖中，詔旌表。」王寶繼妻吳氏
[
编辑

按《儀真縣志》：「吳氏，王寶繼妻。正德十一年，寶亡，吳年二十有五，生遺腹子如孝，茹苦勵節，以死自矢，撫孝克盡義方。後孝任河南經歷，遷判夔州，迎養於官，卒年七十有四。嘉靖間，以狀聞，詔旌其門。」許承鸞妻鮑氏
[
编辑
]

按《興化縣志》：「鮑氏，許承鸞妻。年二十，鸞亡，毀形自矢，紡績而食，撫遺孤成立。建坊旌表。」宗氏女
[
编辑
]

按《興化縣志》：「宗氏女，兵馬指揮宗部女也。許字陳必堯。必堯讀書高郵，倭寇至縱火，堯死焉。女年十八，聞之，誓以死殉。母寡居，哭勸曰：『吾母子相依為命，汝死吾亦死』。乃稍進粥。久之，堯父母俱死，里中聞其賢，爭求婚，女曰：『吾示以有歸，則眾望絕矣』。」遂奔喪成禮而
返。居數年，有道士來曰：「我陳必堯也。」鄉人聚而觀之，
果是，言昔事甚詳，必堯小指尖缺一。驗之果然。女曰：
「吾心如石，即今在已，於我無與。」道士嗟歎而去。至年
五十餘，聞於朝，下禮部，命有司給粟帛旌之。御史康
某又檄發贖鍰為治第。第成，縣令擇日請移居，盛服
鼓樂迎之。女拜簾內，令拜簾外，士女往觀罷市，莫不
感悅。
