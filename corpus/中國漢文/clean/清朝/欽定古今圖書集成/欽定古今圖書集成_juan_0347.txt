鸛鳴于垤。

〈傳〉
垤，螘塚也。
〈正義〉
此蟲穴處輦土為塚以避濕，將欲陰雨，水泉上潤，故穴處者先知之，是螘避濕而上塚。鸛是好水之鳥，知天將雨，故長鳴而喜也。
〈朱註〉
鸛，水鳥似鶴者也。垤，蟻塚也。將陰雨，則穴處者先知，故蟻出穴而鸛就食之，遂鳴於其上也。

鸛鷒鶝鶔，如鵲，短尾，射之，銜矢射人。

〈註〉

《鸛鳴于垤》
[
编辑
]

鸛鸛雀也，似鴻而大，長頸、赤喙，白身、黑尾，翅。樹上作
巢，大如車輪，卵如三升杯。望見人按其子令伏，徑舍
去。一名「負釜」，一名「黑尻」，一名「背竈」，一名「皁裙」，又泥其
巢。一傍為池，含水滿之，取魚置池中，稍稍以食其雛。
若殺其子，則一村致旱災。

按：《詩攷異字》云：「鸛鳴于垤。」 《說文》云：「小爵也。」 想即《爾雅》所謂「鸛鷒」 、鶝鶔也。《郭圖讚》云：「鸛鷒之鳥，一名嫷羿。應弦銜鏑，矢不著地。逄蒙縮手，養由不睨。」 此鳥捷勁異常，與《本草》意義不合，不知伯厚何據？

《鸛》
[
编辑
]

鸛，形狀略如鶴，其性甘帶，每遇巨石，知其下有蛇，即
於石前如術士禹步，其石阞然而轉。南方里人學其
法者，伺其養雛緣木，以篾緪縛其巢，鸛則作法解之，
乃於木下鋪沙，印其足跡而倣學之。天將雨，則長鳴
而喜，蓋知雨者也。又喜群飛，薄霄激雨，雨為之散，作
巢大如輪，卵如三升杯，擇礜石以嫗卵。鸛，水鳥也，伏
卵時數入水，卵則不毈，取礜石周圍繞卵，以助煖氣，
故方術家以鸛煖巢中，礜石為真物也。又泥其巢一
傍為池，以石宿水，今人謂之鸛石。飛則將之取魚置
池中，稍稍以飼其雛。俗說「鵲梁蔽形，鸛石歸酒。」又曰：
「礜石溫，鸛石涼」，故能使卵不毈水，不臭腐也。「鸛鳴于垤，婦嘆干室。」垤，蟻塚也。鸛知天將雨，有見於上；蟻知
地將雨，有見於下。鸛鳴于垤，將雨之候也。將雨，則征
夫之至，不必如期，故婦嘆于室也。且行百里者半九
十，言永路之難也，則於是時遇雨為尤苦。故詩人道
此以序其情。而《序》曰：「三章言室家之望女也。」《禽經》曰：
「鸛俯鳴則陰，仰鳴則晴。仰鳴則晴，是有見於上也；俯鳴則陰，是有見於下」也。夫文雚見為「觀」，蓋取諸此。《拾
遺記》曰：「鸛聚水巢上，故人多聚鸛鳥，以禳卻火災。」《爾雅翼》
[
编辑
]

《鸛》
[
编辑
]

鸛，似鴻而大，長頸赤喙，白身黑尾翅，別名黑尻、皁裙，
負釜背竈，以背尾、翅黑為名也。木上作巢，大如車輪，
卵如三升杯泥。其巢一傍為池，含水滿之，畜魚其中，
以哺其子。故楊震有「鸛銜三鱣魚墮講堂」，以為升進
之象也。巢中水有礜石，養之故不竭，得之者可為藥
用。性好旋飛，古者有鵝鸛之陣，今江南謂群鸛旋飛
為鸛井。惟鶴亦然，其旋飛必以風雨。鸛是好水之鳥，
知天將雨，則長鳴而喜。《詩》曰：「鸛鳴于垤，婦嘆于室。」天
之將雨，則蟻封土為垤，而鸛又鳴其上，則零雨其濛
者至矣。此思婦所以為歎也。然見人探其子則捨去，
能致數十里旱。以其群飛激雲，雲散雨歇故也。《禽經》
曰：「鸛生二子，一為鶴；鳩生三子，一為」鶚，言萬物之相
變也。《易》之《中孚》九二：「鳴鶴在陰，上九，翰音登於天。」說
者以為鸛者別於鶴也。震為鶴，陽鳥也。巽為鸛，陰鳥
也。鶴感於陽，故知夜半；鸛感於陰，故知風雨。鸛生鶴
者，巽極成震，極陰生陽之謂也。今人通呼鸛為鸛鶴，
《說文》則以鳴于垤者為鸛。鸛，小鵲也，與《毛詩》說異。

《雚經》

《象乳》
[
编辑
]

文象聿興，爰倣「鳥蹄。」《沮》《誦》「《倉頡》，作大《慧觀》。」「《八九》既還，極妙窮實。」斯殊體矣。

蔣德璟曰：「鸛贅。」《誤萑》非。
「妖」，今從古文作「雚。」《別名》
[
编辑
]

一名嫷羿，見《爾雅注》。一名鶤雞，見《穆天子傳注》。一名
冠雀，見《華嶠漢書》。一名負釜，見陸璣《疏》。一名負金，以
其喜負日飛，日色如金，見《詩考》。一名黑尻，一名背竈，
一名皂裙，見陸璣《疏》。一名旱群，以天旱則群飛，見《合
璧事類》。亦名皂帔，見《博雅》。

《國言》
[
编辑
]

於方，則北荒謂之「老雚」，亦曰「鸞鳥。」《南京通語》曰「雚」，河
南謂曰「雚兒」，陳魏之間亦曰「皁帔。」自關而西謂之「冠雀」，浙江、蘇、松之間或曰「烏童雚」，福建謂之烏尾雚。兩
粵之會郊曰「灰鶴」，出新會。

《形表》
[
编辑
]

《綠觜》，修頸皓身，黑翅赤腳，皂帔胸，釜背竈短尾，高大
類鶴，而頂不丹。

雚不善唳，喙相戞而鳴，鳴則反頸擊喙，其鳴轉搖其
頸，聲如砧聲。

《陶貞白論》：「雚有兩種：似鶴而巢樹者，曰白雚，黑色曲頸者，曰烏雚。」《東筦記》：雚毛、灰白二種，粵西名「灰鶴。」《鳳微》
[
编辑
]

《天老》曰：「鳳象雚顙，鴛思。」蔣德璟曰：「庶鳥四千五百，鳳王之雚。得鳳之顙，曰羽霸。」《性俎》
[
编辑
]

雚善飛搏，其飛也奮層霄上，落處不知幾千里。
《日札》曰：「雚善符。」《考異郵》曰：「雚鵒者，飛行屬之陽，外裔之鳥，穴居於陰也。」短腳多伏，長腳多立。雚夜棲亦立。

《水鳥咮》圓善唼，陸鳥咮銳善啄。雚，陸鳥也，而生涯於
水。

雚以喙鳴。

《禽經》：震為鶴，陽鳥。巽為雚，陰鳥。故鶴知夜半，雚知風
雨。

《雚》仰鳴晴，俯鳴陰；鳩雄鳴晴雌鳴陰。

《埤雅》：「雚知天，蟻知地。」魚出水而《鱉神》守之，蟻出垤而《雚喜》鳴之。

雚影交，鶴聲交。

《禽蟲述雚》「擇礜石，嫗卵以助暖，營小池，養魚以飼雛。」《孕珤》

「雚好旋飛，旋飛必雨」，古法以為陣。

《羽霸》
[
编辑

《爾雅》：「雚鷒鶝鶔射之，銜矢射人。」雚遺火畢，方銜火。

諺云：「雚巢莫睹，神維白虎。」《丹稗》
[
编辑

《淮南畢萬術》曰：「天雄雚胎，日行千里。」《抱朴子》：「雚血塗金丹一丸，內衣中，以指物隨口變化。」《方筌》
[
编辑

《神農本經》「雚骨，味甘，無毒。主鬼蠱，諸疰毒，五尸，心腹疾。」《陶隱居》曰：「宜用白者。」雚骨有小毒。殺樹木禿人毛髮，沐湯中下少許，髮盡

《虀臣》
[
编辑

《野菜譜》：「老雚觔，二月采之，熟食。亦可作虀。」《斿貢》
[
编辑
]

鳳陽府、「歲辦雚翎四千根」《帘招》
[
编辑
]

《酒譚》曰：「樹雉之招者利倍，鳶之招者倍差，雚之招者倍三。」蔣德璟曰：「貝隺諸經。未嘗策事。《筍海棠之譜》。策事又何哤雜也。雚事上泝圖紀。近迄聖代。天真則伯。」​

夭水羽，佛祖則達摩尸婆，臆採未奢，諧怪斯貴。迺若須江邑瑞，應在石梁，惇史可徵，璟不敢諱而不列。唯《農經》緝於方筌，偏荒副於《鞮史》，《災占》編於《異緯》，事岐派分，無取殽置若其儉。
俟博雅焉。

《釋名》
[
编辑
]

李時珍曰：「鸛」字篆文象形，其背尾色黑，故陸璣《詩疏》
有「皂君」諸名。

《集解》
[
编辑
]

陶弘景曰：「鸛有兩種，似鵠而巢樹者，為白鸛；黑色曲頸者，為烏鸛。今宜用白者。」寇宗奭曰：「鸛身如鶴，但頭無丹，項無烏帶。兼不善唳，止以喙相擊而鳴，多在樓殿吻上作窠。嘗日夕觀之，並無作池養魚之說。」李時珍曰：鸛似鶴而頂不丹，長頸赤喙，色灰白，翅尾
俱黑，多巢於高木。其飛也，奮於層霄，旋遶如陣，仰天
號鳴，必主有雨。其抱卵以影，或云以聲聒之。《禽經》云：
「鸛生三子，一為鶴。巽極成震，陰變陽也。震為鶴，巽為鸛也。」《正誤》
[
编辑
]

陳藏器曰：「人探巢，取鸛子六十里旱，能群飛，激散雨也。其巢中以泥為池，含水滿中，養魚蛇以哺子。鸛之伏卵恐冷，取礜石圍之，以助煖氣。」李時珍曰：寥郭之大，陰陽升降，油然作雲，沛然下雨，
區區微鳥，豈能以私忿使天壤赤旱耶？況鸛乃水鳥，
可以候雨乎？作池取石之說，俱出自陸璣《詩疏》、張華
《博物志》，可謂愚矣。

《骨氣味》
[
编辑
]

甘大寒，無毒。

陳藏器曰：「有小毒。入沐湯浴頭，令髮盡脫，更不生也。又殺樹木。」《主治》
[
编辑

庭下，各杖之，然後振翼飛鳴而去。

《莊子齊物論》：「民食芻豢，麋鹿食薦，蝍蛆甘帶，鴟鴉耆鼠，四者孰知正味。」《易林》：「怒非其願，因物有遷。貪妬腐鼠，而呼鴞鳶。自合失餌，倒被困患。」《抱朴子·雜應篇》：「鳶飛轉高，則但直舒兩翅子不復扇搖之而自進者，漸乘剛炁故也。」《鹽鐵論》：「南方有鳥名鵷鶵，非竹實不食，非醴泉不飲。飛過太山，太山之鴟俛啄腐，鼠見鵷鶵而嚇。今公卿以其富貴，笑儒者為之常行，得無若太山之鴟嚇鵷鶵乎？」《續博物志》：「視鴟制柁。」今之紙鳶，引絲而上，令兒張口望視，以洩內熱。
《譚子化書》：「虎居於林，蛇遊於澤」，非鴟鳶之讎，鴟鳶從
而號之，以其蓄異心之故也。

《列僊傳》：「季仲甫夜臥床上，或為鴟鳥，後至沓縣巨山上，候北風當飛渡。南海上有羅鷹者，羅得鴟，視之，仲甫也。後更留三年，自云往崑崙山。」《異苑》：「河內司馬元引，元嘉中為新釜令。喪官月旦設祭，柑化而為鳶。」《獨異志》：梁武帝太清三年，侯景反，圍臺城，遠近不通。
簡文與太子大器為計，縛紙鳶飛空，告急於外。侯景
謀臣謂景曰：「此必厭勝術。」令左右射之，及墮，皆化為
禽鳥飛去，不知所在。
