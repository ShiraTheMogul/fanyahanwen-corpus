《荊州歌》
晉·夏侯湛
[
编辑
]

悠悠兮遠征，倏倏兮暨南荊。南荊兮臨長江，臨江兮
討不庭。江水兮浩浩。長流兮萬里，洪浪兮雲轉。陽侯
兮奔起。驚翼兮垂天。鯨魚兮岳峙。蘼蕪紛兮被皋陸，
修竹鬱兮翳崖趾。望江之南兮遨目桂林，桂竹蓊蔚
兮鶤雞。揚音凌波兮願濟，舟楫不具兮江水深沉。嗟
迴盼兮於北夏，何歸軫之難尋。

《江陵夜行塗中》
陶潛
[
编辑
]

閒居三十載，遂與塵世冥。詩《書》敦宿好，林園無俗情。
如何捨此去，遙遙至南荊。叩枻新秋月，臨流別友生。
涼風起將夕，夜景湛虛明。昭昭天宇闊，皛皛川上平。
懷役不遑寐，中宵尚孤征。《商歌》非吾事，依依在耦耕。
投冠旋舊墟，不為好爵縈。養真衡茅下，庶以善自名。

《從建平王遊紀南城》
梁·江淹
[
编辑
]

恭承此嘉惠，永官至南荊。斂衽承光彩，端笏奉仁明。
再逢綠草合，重見翠雲生。江甸知禮富，漢渚聞教清。
君王淡以思，樹羽望楚城。年積衣劍滅，池遠宮館平。
錦帳終寂寞，綵瑟祕奇英。《丹沙》信難學，黃金不可成。
遷化每如茲，安可貴空名。流巖慘中懷，凝意方自驚。
願借若木景，長照幽人情。

《別荊州吏民》
隋·文帝
[
编辑
]

玉節居分陝。金貂總上流。麾軍如舉扇。作賦且登樓。
年灮遍原隰，春色滿汀洲。日華三翼舸。風轉七星斿。
向解青系纜。將移丹桂舟。

编辑

「神仙久留滯。清切重飛翻。忽佐南方牧。何時西掖垣。」高車自蘭省。便道出荊門。不見河梁別。空銷郢路魂。

陳子昂
[
编辑

輶軒鳳凰使，林藪鶡雞冠。江湖一相許，雲霧坐交歡。
興盡崔亭伯，言忘釋道安。秋光稍欲暮，歲物已將闌。
古樹蒼煙斷，虛亭白露寒。琴中山水曲，今日為君彈。

前人

编辑

野戍荒煙斷，深山古木平。如何此時恨，噭噭夜猿鳴。

编辑

稍發仙人履，將題別駕輿。明年徵拜入，《荊玉》不藏諸。

《西陵峽》
楊炯
[
编辑
]

絕壁聳萬仞，長波射千里。盤薄荊之門，滔滔南國紀。
楚都昔全盛，《高丘》烜望祀。秦兵一旦侵，彝陵火潛起。
四維不復設，關塞良難恃。洞庭且忽然，《孟門》終巳矣。
自古天地闢，流為峽中水。行旅相贈言，風濤無極已。
及余踐斯地，瑰奇信為美。江山若有靈，千載伸知己。

《送友人使彝陵》
崔翹
[
编辑

猿鳴三峽裡，行客舊霑裳。複道從茲去，思君不暫忘。
開襟春葉短，分手夏條長。獨有幽庭桂，年年空自芳。

《九日陪樊尚書龍山宴集》

[
编辑

《孟嘉從燕地》，千乘復登臨。緣危陟高步，憑曠寫幽襟。
黃花玩初馥，翠物喜盈斟。雲雜組繡色，樂和山水音。
斾搖秋吹急，筵卷夕光沈。都人瞻騎火，猶知隔寺深。

[
编辑

衰顏憂更老。淑景望非春。禊飲豈吾事，聊將偶俗塵。

《登荊州城望江》
前人
[
编辑

滔滔大江水，天地相終始。經閱幾世人，復歎誰家子。
東望何悠悠，西來晝夜流。歲月既如此，為心那不愁。

始興南山下有林泉嘗卜居焉荊州臥病有懷
[
编辑
]

《此地　　　　　　　　　　　　前》人。

出處各有在，何者為陸沉。幸無迫賤事，聊可祛迷襟。
世路少彝坦，孟門未崎嶔。多慚入火術，常惕履冰心。
一跌不自保，萬全焉可尋。行行念歸路，眇眇惜光陰。
浮生如過隙，先達已吾箴。敢忘丘山施，亦云年病侵。
力衰在所養，時謝良不任。但憶舊棲息，願言遂窺臨。
雲間目孤秀，山下面清深。蘿蔦自為幄，風泉何必琴。
歸此老，吾老還當日千金。

《寓荊州登郡樓》
前人
[
编辑
]

「天宇何其曠，江城坐自拘。層樓百餘尺，迢遞在南隅。暇日峕登眺，荒郊臨故都。纍纍見陳跡，寂寂想雄圖。古往山川在，今來郡邑殊。北疆雖入鄭，東距豈防吳。幾代傳荊國，當時敵陜郛。上流空有處，中土復何虞。枕席彝三峽，關梁豁五湖。承平無異境，守隘莫論夫。自罷金門籍，來參竹使符。端居向林藪，微尚在桑榆。」直似王陵戅，非如甯武愚。今茲對南蒲。乘雁與雙鳧。

《九日登龍山》
前人
[
编辑
]

「郡庭常窘束，涼野求昭廣。」楚客凜秋時，桓公舊臺上。
「清明風日好，歷落江山望。極遠何蕭條，中留坐惆悵。東彌夏首闊，西拒荊門壯。夷險雖異時，古今豈殊狀。先賢渺不接，故老猶可訪。登弔傷昔人，揮斤感前匠。自為本疏散，未始忘高尚。際會非有欲，往來是無妄。為邦復多幸，去國殊遷放。且泛籬下菊，還聆郢中唱。」灌園亦何為，於陵乃迯相。

前人
[
编辑

《巴陵早秋寄荊州崔司馬吏部閻功曹舍人》
[
编辑
]

賈至

「謫居瀟湘渚，再見洞庭秋。」極目連江漢，西南浸斗牛。
滔滔蕩雲夢，淡淡搖巴丘。曠如臨渤海，窅疑造瀛洲。
君山麗中波，蒼翠長夜浮。帝子去永久，《楚詞》尚悲秋。
我同長沙行，時事加百憂。登高望舊國，北馬滿東周。
宛葉遍蓬蒿，樊鄧無良疇。獨攀青楓樹，淚灑滄江流。
故人西掖寮，同扈岐陽蒐。差池盡三黜，蹭蹬各南州。
相去雖地近，不得從之遊。耿耿雲陽臺，迢迢王粲樓。
跂予暮霞裏，誰謂無輕舟。

《青山峽口泊舟懷狄侍御》
岑參
[
编辑
]

峽口秋水壯，沙邊且停橈。奔濤振石壁，峰勢如動搖。
九月蘆花新，彌令客心焦。誰念在江島，故人滿天朝。
無處豁心胸，憂來醉能消。往來巴山道，三見秋草凋。
狄生新相知，才調凌雲霄。賦詩柝造化，入幕生風飆。

把筆判甲兵，戰士不敢驕。皆云梁公後，遇鼎還能調
​
一別倏經時，音塵殊寂寥。何當見夫子，不歎鄉關遙。

《曉行巴東》
王維
[
编辑
]

際曉投巴峽，餘春憶帝京。晴江一女浣，朝日眾禽鳴。
水國舟中市，山橋樹杪行。登高萬井出，眺迥二流明。
人作殊方語，鶯為舊國聲。賴多山水趣，稍解別離情。

《送蕭員外之荊州》
孟浩然
[
编辑

亭樓明落照，井邑秀通川。澗竹生幽興，林風入管絃。
再飛鵬激水，一舉鶴沖天。佇立三荊使，看君駟馬旋。

《峴山亭送朱大遊巴東》
前人
[
编辑

蹉跎遊子意，眷戀故人心。去矣勿淹滯，巴江猿夜吟。

荊州府部紀事一
[
编辑
]

《府志左傳》：巴蔓子，巴東人，為巴國將，請師於楚，許以
三城。楚王業已救之，使人請其城，蔓子曰：「藉楚之靈，克濟禍難，誠許楚王，城可持我首以償城，不可得也。」遂自刎。使者持首以獻楚王，楚王曰：「使吾得臣如巴蔓子者，需城何為？」乃以上卿之禮葬之。巴人亦葬骸
如其禮。

伍舉一曰湫，舉，參之子，為楚大夫。靈王為章華之臺，
與舉升焉，曰：「臺美。」舉曰：「美而亡政。」王會諸侯於申以
舉，言用桓公禮。王有驕色，舉諫之。

初，靈王為令尹，王旌以田申無宇斷之，曰：「一國兩君，其誰堪之？」及靈王時，無宇執亡人于章華之宮，諫曰：
「棄疾在外，鄭丹在內，君其少戒！」
屈原有賢姊，聞原放逐，亦來歸，喻令自寬。其鄉人冀
其見從，因名姊歸，即《離騷》所謂「女嬃嬋媛以詈余」也。
原廟東北有嬃廟。

野辯女昭氏之妻也。鄭簡公使大夫聘於荊，至狹路，
有一婦人乘車與大夫轂擊，而折大夫車軸，大夫怒
​
將執而鞭之。婦人曰：「君子不遷怒，不貳過。今於狹路之中，妾避之已亟矣，而子大夫之僕不肯少引，是以敗子大夫之車而反執妾，豈不遷怒哉？既不怒僕而反怒妾，豈不貳過哉？」
建武中，公孫述遣田戎據荊州，漢將兵會岑彭伐蜀，
破其浮橋，遂入江關，留守彝陵。

《後漢書劉昆傳》：光武建武二十二年，昆為江陵令。時
江陵有火災，昆輒向火叩頭，降雨止風。後為弘農守，
崤澠驛道多虎災，行旅不通。昆仕至三年，仁化大行，
虎負子渡河。徵代杜林為光祿勳，召問昆曰：「『前在江陵，反風滅火，後守弘農，虎北渡河。行何德政而致是』？昆對曰：『偶然耳』。帝嘆曰：『此長者之言也』。」
《郭賀傳》：賀字喬卿，光武建武中，拜荊州刺史，百姓歌
之曰：「厥德仁明郭喬卿，忠正朝廷上下平。」顯宗至南
陽，特見嗟嘆，賜以三公服黼黻冕旒，敕行部去襜帷，
令人見其容服，以章有德。

《謝彝吾傳》：彝吾字堯卿，舉孝廉，遷荊州刺史。行郡始
到南陽，會章帝巡狩，駕幸魯陽，有詔敕荊州刺史入
傳錄見囚徒，誡長史勿廢舊儀，朕將覽焉。上臨西廂
南面，彝吾處東廂，分帷隔中央。彝吾所決三百餘事，
事與上合。上嘆息曰：使州刺史盡如此者，朕不憂天
下矣。

《楊震傳》：震字伯起，安帝永初中，大將軍鄧騭聞其賢，
舉茂才，四遷至荊州刺史，屢彰政績，改東萊守，道經
昌邑，時令王密乃前荊州所舉茂才也，夜懷金遺之，
震曰：「故人知君，君何不知故人？」密曰：「暮夜無知。震曰：『天知地知，子知我知，何謂無知？密慚而去』。」
《李固傳》：「固字子堅，南鄭人，司徒郃之子也。永和中，荊南盜起，以固為荊州刺史。固到郡，遣使勞問境內，赦其舊釁，與之更始。賊帥夏密等斂其魁黨六百餘人，自縛歸首，固皆原之遣還，使自相招集，開示威法。半歲間，餘黨悉降，州內宴然。」
《胡爽傳》：「爽為南郡主簿。延熹五年冬十月，武陵蠻反，寇江陵，太守李肅走，爽叩馬諫曰：『蠻見郡無備，故敢乘間而進。明府為國大臣，連城千里，舉旗鳴鼓，應聲十萬，奈何委符守之重為遁逃之人乎？肅殺爽而走。後徵肅棄市，復爽門閭，拜家一人為郎』。」
《趙岐傳》：「『岐字邠卿，後改字臺卿。漢獻帝興平元年，詔書徵岐，會帝當還洛陽，先遣衛將軍董承修理宮室，岐謂承曰：今海內分崩，唯有荊州，境廣地勝，西通巴蜀，南當交趾。年糓獨登，兵人差全。岐雖迫大命，猶志報國家，欲自乘牛車，南說劉表，可使其身自將兵，來衛朝廷，與將軍并心同力，共獎王室』。承即奏遣岐使」荊督租糧。岐至，劉表即遣兵詣洛陽，助修宮室，軍資
委輸，前後不絕。後以老病，遂留荊州。

《胡騰傳》：延熹七年冬十月，帝如章陵。時公卿貴戚，車
騎萬計，徵求費役，不可勝紀。騰時為護駕從事，言曰：
「天子無外，乘輿所幸，即為京師。臣請以荊州刺史比司隸校尉，臣自同都官從事。」帝從之，自是肅然，莫敢
干擾。

《度尚傳》：「延熹五年，寇大起，尚書朱穆舉尚才，擢為荊州刺史。尚擊賊大敗之，降者數萬人。其渠帥逃入山谷，尚欲窮其巢穴，而兵士鹵獲既多，皆驕怠不可用。尚乃令軍中恣聽射獵，兵士喜，盡出從禽。尚密遣人焚營，盡燔其所積，因深自咎責，復慰之曰：『賊帥寶貨甚多，儻能進攻，可盡得也』。眾乃憤踊，秣馬蓐食，徑赴」賊屯，遂大破之。出兵三年，群寇悉定。

《府志》：「獻帝建安初，荊州童謠作謠曰：『八九年間始欲衰，至十三年無孑遺』。占為應。在劉表，華容女子妖言作，忽啼呼曰：『有大喪』。後劉表果死。又歌吟云：『不意李立為貴人』。無幾，曹公以涿郡李立為荊州刺史。劉表在荊州，與王粲登障山，見一岡不生百草，粲曰：『此必古塚，其人在世，服生礜石，熱蒸出外，故草木焦滅。鑿』」看果墓礜石滿塋。

《後漢書蒯越傳》：「劉表為荊州刺史，時盜賊縱橫，道路梗塞，表入宜城，聞其經略，辟越及蒯良與謀。表謂越曰：『宗賊雖盛而眾未附，若袁術因之，禍必至矣。吾欲徵兵，其策焉出』？越曰：理平者先仁義，理亂者先權謀。兵不在多，貴乎得人。袁術驕而無謀，賊眾率多貪暴，使人怵之以利，必率眾來。使君誅其無道，用其才能，威德既行，襁負而至矣。兵集眾附，南據江陵，北守襄陽，荊州八郡，可傳檄而定。公路雖至，無能為。」表曰：「善。」乃使越誘宗賊及江夏賊張虎悉降，州境遂平。
《杜夔傳》：夔以知音為雅樂郎，世亂奔荊州。劉表命與
孟曜為漢主合雅樂。樂備，表欲庭觀之，夔諫曰：「今將軍號為天子，合樂而庭作之，無乃不可乎？」表納其言
而止。

《蜀志》：「廖立，武陵臨沅人。先主領荊州牧，辟為從事。年未三十，擢為長沙太守。先主入蜀，諸葛亮鎮荊土，孫權遣使通好於亮，因問士人誰相經緯者，亮答曰：『龐統、廖立，楚之良材，當贊興世業者也。建安二十年，權​遣呂蒙奄襲南三郡，立脫身走，自歸先主。先主素識待之，不深責也，以為巴郡太守』。」
先主入蜀，廖化為前將軍，隨遣鎮荊州。孫權襲荊州，
化為所得，乃佯死，夜攜老母西行，會先主於秭歸，見
之，命為宜都太守。

先主自樊南渡，遣關羽乘船數百艘會江陵。公引兵
收江南諸郡，主以公為襄陽太守。及孫權以荊州借
主，權欲進取益州，主止之，權不聽，遣孫瑜率水軍至
夏口，主不令軍過，使公屯江陵，截止權軍。二十年，主
入蜀，權令諸葛瑾求還荊州，主不肯，權遂置長沙、零
陵、桂陽三郡，公率兵盡逐之，權怒，遣呂蒙復置。主自
蜀親至公安，屯兵油口。公屯兵益陽，與爭三郡。魯肅
將萬人拒公，邀公相見，各駐兵百步外，公單刀赴會，
卒分湘水為界，以解長沙、江夏、桂陽以東屬權，南郡、
零陵以西屬蜀漢。二十四年，操遣曹仁與孫權相拒，
公襲攻仁於樊，仁使于禁、龐德等屯樊北。八月，大霖
雨，漢水大溢，平地數尺。公乘船就攻之，禁等七軍皆
沒，窮迫出降，斬龐德以徇。公威震華夏。操議避其銳，
徙許都。

張飛從先主入荊州曹操破襄陽追先主至當陽之
長坂棄妻子走使飛將二十騎殿後飛據水斷橋瞋
目橫矛叱之曰：「我張翼德也。可來共決死戰」無敢近
者先主定江南以飛為宜都太守。

《吳志》：「魯肅為吳奮武校尉，嘗屯兵監利，至今名其地為魯洑。」
陸抗，吳人遜之子。晉泰始九年為荊州牧。先是治樂
鄉，都督信陵、西陵、彝道、公安諸軍事，上陳時宜十七
疏，吳主不納。及步闡叛，據城降晉，晉遣將為闡援，抗
敕西陵諸軍築嚴圍，內以圍闡，外以禦晉兵，拔取西
陵，誅闡等十餘人，援兵皆引軍還。吳主加抗都督。九
年，以抗為荊州牧。十年，抗病，上疏言：「臣死之後，乞以西方為屬，諸王幼沖無用，以妨要害。」及卒，吳使其子
宴景等分將其兵。

《晉書羊祜傳》：「祜字叔子，泰山南城人，蔡邕外孫也。晉武帝代魏，以祐為都督荊州諸軍事，甚得江漢間心。降者欲去，皆聽之，墾田八百餘頃。始至軍，無百日糧，及季年乃有十年之積。在軍嘗輕裘緩帶，身不披甲，鈴閣之下，侍衛不過十數人。時自石城以西盡為晉有，人有掠吳中兒為俘者，祜遣送還其家。每會眾江」沔遊獵，常止晉地。若禽獸先為吳人所傷而為晉兵
所得者，皆封還之。於是吳人稱為「羊公」，不之名也。又
其都督荊州時，長史喪官，後人皆惡舊府而毀壞之。
祜以死生有命，非由居室，普加斷禁。

《杜預傳》：羊祜卒，拜預鎮南大將軍，都督荊州諸軍事。
預在鎮講武修學，置屯據要，激水灌田，多方設施，公
私俱蒙其利，庶眾賴之，相與號曰「杜父。」
《王濬傳》：「『咸寧四年，濬為巴東監軍，自表伐吳。濬先作大筏數十，方百餘步，縛草為人，被甲持杖，令善水者以筏先行，遇吳人所置鐵錐，輒著筏去。又作火炬長丈餘，大數十圍，灌以麻油，遇鎖，融液斷絕。二月庚申，遂剋西陵荊門等道。濬至西陵，杜預曰：濬已得建平，則順流長驅，不宜受制於我』。遂與書曰：『足下既摧其西藩，便當徑取建業，討累世之逋寇，釋吳人於塗炭，振旅還都，亦曠世一事也』。」分兵益濬濬，士卒八萬，方
舟百里，鼓譟入於石頭，吳主皓降。

《劉弘傳》：「弘字和季，沛國人。太安中，持節南蠻校尉、荊州刺史，討張昌，斬之。時流民在荊州者十餘萬戶，羈旅貧乏，多為盜賊，弘大給其田及種糧，擢其賢才，隨資敘用，流民遂安。永興二年，陳敏據江東，太宰顒以張光帥步騎討敏，弘遣陶侃屯夏口，應詹督水軍繼之。侃與敏同郡，又同歲舉吏。或謂弘曰：『侃脫有異志，則荊州無東門矣』。」弘曰：「侃之忠能，吾得之已久，必無是也。」侃聞之，遣子詣洪以自固，弘引為參軍，資而遣
之，曰：「匹夫之交，尚不負心，況大丈夫乎！」時天下大亂，
弘專督江漢，威行南服，事成，則曰「某人之功。」如敗，則
曰「老子之罪。」每有興廢，輒手書丁寧款密，人皆感悅，
爭赴之，咸曰：「得劉公一紙書，賢於十《部從事》。」
《周訪傳》：「元帝大興二年，訪為荊州刺史。先是王敦以從弟廙刺荊州，將吏不服，遂迎杜曾等以叛。建武元年，訪討平之。廙至荊，多殺將佐，責皇甫方回不詣己，收斬之，士民怨望。帝徵廙為散騎常侍，以訪代王敦忌訪威名，欲自領荊州，以手書譬解，並遺玉碗玉環，以申厚意。訪投之地曰：『吾豈賈豎，可以寶悅耶？訪知』」敦有不臣之心，私常切齒，欲陰圖之。敦由是終訪之
世，未敢為逆。

《陶侃傳》：「侃字士行，鄱陽人。時新野王歆督荊州，為政嚴急。義陽蠻張昌聚黨為亂，荊州都督劉弘以侃為大都護，討昌破之。侃在州無事，輒朝運百甓於齋外，暮運於齋內。人問其故，答曰：『吾方致力中原，過爾優逸，恐不堪事，故習勞耳。及敦敗，侃復鎮荊州，士女相慶，侃終日斂膝危坐，軍府眾事，檢攝無遺，未嘗少閒​《羅含傳》：「含字君章，耒陽人。康帝間，為荊州功曹，後遷宜都太守。含幼孤，養於叔母朱氏。嘗晝夢五色文鳥飛入口中，自玆藻思日新。太守謝尚稱為湘中之琳琅，桓溫亦謂其為江左之秀。含在官，有百鳥棲於庭。及歸荊州，宅階庭忽蘭菊叢生，人謂德行之感。」《桓溫傳》：「初庾翼病，表子方之為荊州刺史」，委以後任。及卒，朝議以諸庾世在西藩，人情所向，欲從其請。何充曰：「『荊楚，國之西門，戶口百萬，得人則中原可定，失人則社稷可憂，陸抗所謂存則吳存，亡則吳亡』者也，豈可以白面少年當之哉！」桓溫英略過人，有文武器
幹，西夏之任無出溫者，乃以溫都督荊、梁等州軍事。

《府志》：「桓石民為荊州，鎮上明，百姓忽作歌曰：『黃曇英，揚州大佛來上明』。」頃之，石民死，王忱為荊州。忱小字
佛大。

殷仲堪在荊州，童謠作曰：「芒籠目，繩縛腹。殷當敗，桓當復。」後殷敗，桓元遂有荊州。

《晉書魏詠之傳》：太元中，詠之為荊州主簿。嘗見桓元
既出，元鄙其精神不雋，謂坐客曰：「神庸而貌偉，不成令器。」竟不調而遣。詠之早與劉裕遊款，及元篡位，協
贊議謀。元敗，尋轉荊州刺史。

《殷仲堪傳》：孝武時，仲堪為荊州刺史，鎮江陵。先是，仲
堪遊江濱，見流棺葬之。旬日間，溝起，忽為岸，有人自
稱徐伯元，仲堪問故，對曰：「水中有岸，其名為洲，君其為荊州乎？」及刺荊，病者嘗自為診脈分藥，值歲儉脫
粟自甘，不治肴核，每誡子弟曰：勿以我任方州，失故
步也。貧者士之常，不得登枝而損其本。

《羅企生傳》：「孝武太元中，殷仲堪鎮江陵，引企生為功曹。桓元攻仲堪，更以企生為諮議參軍。仲堪多疑少決，企生謂弟遵生曰：『殷侯仁而無斷，事必無成，成敗天也，吾當死生以之』。仲堪走，唯企生從焉。遵生謂曰：『家有老母，將欲何之？企生揮淚曰：『今日之事，我必死之。汝第奉養，不失子道，一門之中，有忠與孝，亦復何恨』！遵生抱之愈急，仲堪於路待之，企生遙呼曰：『生死是同，願少見待』』。」仲堪見企生無脫理，策馬而去。兀至
荊州，人士無不詣者，企生獨不往，而營理仲堪家。
