沈倫
[
编辑
]

按《宋史沈倫傳》，「倫字順儀，開封太康人。周顯德初，太祖領同州節度，留幕府。及受禪，自宋州觀察推官召為戶部郎中。建隆三年遷給事中。開寶六年，拜中書侍郎、平章事，集賢殿大學士。太平興國初，加右僕射。六年，加開府儀同三司。雍熙四年卒，諡恭惠。」
沈承禮
[
编辑
]

按《宋史吳越世家》：「沈承禮，湖州烏程人。錢鏐辟置幕府。鏐子元瓘以女妻之，出為台州刺史。元瓘卒，子佐嗣，以承禮掌親兵。俶襲位，命知威武軍節度事，充兩浙都鈐轄使。王師征江南，俶遣承禮率水陸數萬人助平毗陵，因攻潤州，丹陽平，遂率兵抵建業。李煜歸朝，錄其功，真授福州節制。太平興國初，俶盡獻浙右」地，徙承禮鎮密州。八年，卒。

沈正
[
编辑
]

按《宋史邢神留傳》：「端拱初，泰州海陵人沈正父，使酒毆平人死。正中塗見父，恐慴，即號呼褫衣，就毆其屍。巡警者捕送官，獄具，怡然就死，聞者悲之。」
沈繼宗
[
编辑
]

按《宋史沈倫傳》：「倫子繼宗，字世卿。倫為樞密副使，以廕補西頭供奉官。倫作相，授水部員外郎，歷遷光祿少卿。大中祥符五年卒。子惟溫、惟清、惟恭並為將作監主簿。惟溫後至祕書丞，惟清至內殿承制。」
沈播
[
编辑
]

按《萬姓統譜》：「播，武康人。天聖二年，以進士起家楚州司法參軍，再調知池州貴池縣。嘗攝銅陵縣事，有兄弟爭財者，為辨其曲直，而卒使之感悟，讓財相與同居。其去也，兩縣人追送涕泣。平居事生嚴，喪死哀，終身好書，未嘗一日不讀。循道以守官而不諂其上，故仕嘗有去志。年三十六，以疾卒於京師。子四，皆舉進」士。

沈邈
[
编辑
]

按《宋史沈邈傳》：「邈字子山，信州弋陽人。進士及第，知候官縣，累遷都官員外郎。慶曆初，為侍御史。論夏竦陰交內侍劉從愿，其言甚切，轉兵部員外郎，使京東。歲餘，入為侍御史，知雜事。未幾，擢天章閣待制，知潭州，徙河北都轉運使，又徙陝西，知延州，卒。」
沈遘
[
编辑
]

按《宋史沈遘傳》：「遘字文通，錢塘人。以廕為郊社齋郎，舉進士，通判江寧府。歸奏《本治論》，除集賢校理，遂知制誥。以父扶坐事免，求知杭州。為人疏雋博達，明於吏治，令行禁止。召知開封府，遷龍圖閣直學士，士大夫交稱其能。拜翰林學士，判流內銓。丁母憂，歸蘇州。既葬，廬墓下，服未竟而卒。」
沈遼
[
编辑
]

按《宋史沈遘傳》：「遘弟遼，字叡達，用兄任監壽州酒稅。熙寧初，分審官，建西院，以為主簿，故受知於王安石。安石當國，遼與之議論，寖咈意日益見疏，於是罷去。元豐末卒。」
沈括
[
编辑
]

按《宋史沈遘傳》：「遘從弟括，字存中，以父任為沐陽主簿，擢進士第，為館閣校勘，遷太子中允，提舉司天監，遷太常丞，擢知制誥，為河北西路察訪使。遼蕭禧來理河東黃嵬地，遣括往聘。契丹相楊益戒來就議，凡六會，不可奪。還拜翰林學士，出知延州，以功加龍圖閣學士。元祐初，以光祿少卿分司，居潤八年卒。」
沈立
[
编辑

按《宋史沈立傳》，「立字立之，歷陽人。舉進士，提舉商胡埽。采摭大河事跡、古今利病，為書曰《河防通議》，治河者悉守為法。遷兩浙轉運使，召為戶部判官，遷京西​北轉運使，知滄州，進右諫議大夫，判都水監，出為江淮發運使，知越州、杭州、審官西院、江寧府，徙宣州，提舉崇禧觀，卒。」
沈嚴
[
编辑

按《萬姓統譜》：「嚴字德寬，德清縣人。監洪州武寧茶場，兼領縣事，吏畏其廉，民懷其愛。及卒，貧不能葬，太守滕元發為葬於德清之永和鄉。」
沈起
[
编辑
]

按《宋史沈起傳》：「起字興宗，明州鄭人。進士高第，調滁州判官，遷知海門縣。包拯舉為監察御史，以論興國鐵官事不合，出通判越州，改知蘄、楚二州。熙寧三年，為陝西都轉運使，罷知江寧府，入知吏部流內銓。六年，拜天章閣待制，知桂州。坐邊議貶團練使，安置郢州，徙秀而卒。」
沈初
[
编辑
]

按《萬姓統譜》，初字子深，無錫人。熙寧六年進士。文詞
典麗，時爭效之。元祐尚詞賦，朝廷嘗以「沈初、林希與詞賦頒天下」為格，初賦後流至西夏，夏人織為文錦。
其稱賞如此。官終國子直講。

沈畸
[
编辑

按《宋史沈畸傳》：「畸字德侔，湖州德清人。第進士，崇寧中為尚書議禮局編修官，召對，擢監察御史，進殿中侍御史。蔡京興蘇州錢獄，株逮死者甚眾。帝遣畸至蘇，即日決釋無佐証者七百人。京大怒，削畸三秩，貶信州酒稅，未幾卒。子濬，官至右正言。」
沈積中

按《宋史沈積中傳》：「積中，常州人，賜進士出身，為辟雍正戶部員外郎，至祕閣修撰，河北轉運使，召拜戶部侍郎，進尚書，知河間真定府，提舉上清寶籙宮，卒。」
沈與求
[
编辑
]

按《宋史沈與求傳》：「與求，字必先，湖州德清人。登政和五年進士第，累遷至御史中丞。與求知無不言，前後幾四百奏，其言切直。移吏部尚書，出為荊湖南路安撫使，知潭州。引疾丐祠。四年，出知鎮江府，復以吏部尚書召除參知政事。金人將入寇，與求贊上親征。五年，權知樞密院事。時張浚視師江上，以行府為言，從」之。與求不能平，遂丐祠罷，出知明州。七年，上在平江，
召見，從至建康。遷知樞密院事。薨，諡忠敏。

沈晦
[
编辑
]

按《宋史沈晦傳》：「晦字元用，錢塘人，翰林學士沈遘孫。宣和閒進士，除校書郎。金人攻汴京，從肅王樞出質，還為給事中。高宗即位，除集英殿修撰，知信州，移守婺州。尋知宣州，移知建康府，以御史常同論罷。紹興四年，起知鎮江府，兩浙西路安撫使，尋提舉臨安府洞霄宮，起為廣西經略，召赴行在，除知衢州，改潭州」，
提舉太平興國宮，卒。

沈莊可
[
编辑
]

按《萬姓統譜》：莊可，分宜人。宣和間進士，知錢塘縣事。
嗜菊，庭植嘗數百本。晚年退居，益放情於菊，後以九
月九日死。朱熹哭之詩曰：「愛菊平生不愛錢，此君原是菊花仙。正當地下修文日，恰值人間落帽天。生與唐詩同一脈，死隨陶逕葬千年。如今忍向西郊哭，東野無兒真可憐。」
沈希稷
[
编辑
]

按《萬姓統譜》：「希稷，字濟叔，溫州人。宣和元年，知龍泉。三年，睦賊洪載入寇，諸邑皆陷，民情洶洶，希稷毅然為守禦計。賊至，與戰，大破之。事平，朝廷嘉其功，增秩一等。在邑五年，去之日，送者涕泣，為立三賢堂。」
===沈周===
​
按《萬姓統譜》：「周知泉州，治尚簡易，訟有可已者，輒諭以義，使歸思之，獄以故少。州舊多盜，日暮市門盡閉，禁民勿往來。周至，除其禁而盜亦止。」
沈時升
[
编辑
]

按《萬姓統譜》：時升，霅川人。宣和末，令慈谿，誠心撫字，
愛民如子，俗咸化之，無敢梗政。既去，父老請立祠於
治內，名「沈公堂」，其子該為丞相。

沈杞
[
编辑

按《萬姓統譜》：「杞紹興初知廉州。時本州科舉附雷州，閔士子遠涉鯨波，奏請自置科場，詔從之。由是士益奮志，得人為盛。後立祠於學宮，像而祀之。」
沈昭遠
[
编辑
]

按《萬姓統譜》：昭遠紹興間知袁州。初，民輸義倉米，倉
吏違制倍斂，昭遠力為減其半。時四邑歲以羨餘錢
米上邑，不下數十萬。昭遠曰：「此非天降地出，無非虐取於民。」盡卻之，民皆感悅。

沈大廉
[
编辑
]

按《萬姓統譜》：大廉字元簡，瑞安人。登建炎第，後為樞
密院詳議官。紹興更化，除監察御史。遇事敢言，無所
顧望。給事中周葵以封駁忤旨去職，大廉既陳其不
可，俄而中書舍人凌景夏相繼去，大廉復言之，俱不
報。自以不得其言，力求補外，除直祕閣，福建提刑，一
時公議翕然歸重。越明年卒。王十朋挽之曰：「能將一誠字，了卻百年身。則其充拓所學者有素矣。」子季豐，
登科。

沈度

沈復

编辑

按《萬姓統譜》：復，字德之，德清人。舉進士，乾道初為太
常簿。賜對稱旨，除宗正丞，累遷至樞密院事。所著有
《四益齋集》。真德秀嘗序其文，謂「其議論不少詘，有古大臣之體。」
沈煥

按《明外史沈鯉傳》：鯉字仲化，歸德人。祖瀚，建寧知府。

宮，鯉為講官。比即位，用宮寮恩，進編修，旋進左贊善。

郎。尋改吏部，進左侍郎。萬曆十二年，拜禮部尚書。《會

嘗與交。及官愈高，益無所假借。中貴大怨，數以事間
於帝。帝漸不能無疑，累加詰責。鯉自是有去志。屢疏
引疾歸。二十九年，趙志皋卒，沈一貫獨當國。廷推閣
臣，詔鯉以故官兼東閣大學士，入參機務。三十二年，
敘皮林功，加太子太保。尋以秩滿，加少保，改文淵閣。

後憂，密傾之。帝亦嫌鯉方鯁，因鯉乞休，遽命與一貫
同致仕。卒，諡文端。

===沈思孝===
​
按《明外史沈思孝傳》：「思孝，字純父，嘉興人。舉隆慶二年進士，又三年選番禺知縣。萬曆中，舉卓異人，為刑部主事。張居正父喪，奪情疏諫，廷杖，戍神電衛。居正死，召復官，進光祿少卿，遷太常少卿，尋遷順天府尹。被劾，調南京太僕卿。未幾，謝病歸。吏部尚書陸光祖起為南京光祿卿，尋進右僉都御史，巡撫陝西寧夏。」召為大理卿。進工部左侍郎，又進右都御史，協理戎

奧援。給事中楊東明、鄒廷彥相繼疏劾。帝以廷彥受
東明指，謫東明奪廷彥俸。思孝素以直節高天下，然
氣好勝，動輒多忤，頗被物議。引疾歸，久之卒。

按《明外史沈一貫傳》：「一貫，字肩吾，鄞人。隆慶二年進士，選庶吉士，授檢討。萬曆二年，充日講官、吏部左侍郎，假歸。二十二年，起南京禮部尚書。有旨推舉閣臣，吏部舉一貫名以上，詔以尚書兼東閣大學士，入閣預機務，進太子太保、戶部尚書、武英殿大學士。自一貫入內閣，朝政已大，非數年之間，礦稅四出，為民害。」其所誣劾逮擊者，悉滯獄中。吏部疏請起用建言廢
黜諸臣，并考選科道官。久抑不下，中外多以望閣臣。
一貫等數諫不省。及帝有善意，一貫骫骳不能持。後
繫獄及言事者因他人言，稍釋用一二，而礦稅之害
遂終神宗世。始都御史溫純劾御史于永清及給事
中姚文蔚，語稍涉一貫，給事中鍾兆斗為一貫論純，
御史湯兆京復劾兆斗而直純。純十七疏求去，一貫
已揭留純。至歲乙巳，大察京朝官，純主其事，錢夢皋、
鍾兆斗皆在黜中。一貫怒，言於帝，盡留給事、御史之
被察者，且許純致仕去。於是一貫不為公論所與，彈
劾日眾，因謝病不出。三十四年，給事中陳嘉訓、御史
孫居相復連章劾其奸貪，一貫憤，益求去。帝為黜嘉
訓，奪居相俸，允一貫歸。一貫在位，累加少傅、吏部尚
書、建極殿大學士。家居十年卒，諡「文恭。」
