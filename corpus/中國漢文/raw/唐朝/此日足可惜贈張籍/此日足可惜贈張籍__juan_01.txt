念昔未知子，孟君自南方。
[

我名屬相府，

]
欲往不得行。
[

思之不可見，百端在中腸。
[

維時月魄死，
[

]
冬日朝在房，
[

驅馳公事退，聞子適及城。
[

]

命車載之至，引坐於中堂，

開懷聽其說，往往副所望。

孔丘歿已遠，仁義路久荒，

紛紛百家起，詭怪相披猖。

長老守所聞，後生習為常。

少知誠難得，純粹古已亡。
[
10
]

譬彼植園木，有根易為長。

留之不遣去，館置城西旁，

歲時未云幾，浩浩觀湖江。
[
11
]

眾夫指之笑，謂我知不明，

兒童畏雷電，魚鱉驚夜光。

州家舉進士，選試繆所當，
[
12
]

馳辭對我策，章句何煒煌。

相公朝服立，工席歌《
鹿鳴
》。

禮終樂亦闕，相拜送於庭。

之子去須臾，赫赫流盛名。

竊喜復竊嘆，
[
13
]
諒知有所成。

人事安可恒，奄忽令我傷。

聞子高第日，正從相公喪，
[
14
]

哀情逢吉語，惝怳難為雙。
[
15
]

暮宿偃師西，
[

]
徒展轉在床。
[

]

夜聞汴州亂，
[

]
繞壁行仿徨。

我時留妻子，
[
19
]
倉卒不及將，

相見不復期，零落甘所丁。

驕女未絕乳，念之不能忘。

忽如在我所，
[

]
耳若聞啼聲。

中途安得返，一日不可更。

俄有東來說，我家免罹殃，

乘船下汴水，東去趨彭城。
[

[

[

[

日西入軍門，羸馬顛且僵。

主人願少留，
[
25

卑賤不敢辭，忽忽心如狂。

飲食豈知味，絲竹徒轟轟。
[

黃昏次汜水，

[

日念子來遊，子豈知我情？

別離未為久，辛苦多所經。

對食每不飽，共言無倦聽。

連延三十日，晨坐達五更。

我友二三子，
[

宦遊西在京，

東野窺禹穴，
[

淮之水舒舒，楚山直叢叢，

子又舍我去，我懷焉所窮？
