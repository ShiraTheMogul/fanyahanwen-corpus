# CATEGORY: 唐朝
# WORK_BASE_TITLE: 南山詩
# PAGE_TITLE: 南山詩

吾聞京城南，茲維群山囿。

東西兩際海，
[
1
]
巨細難悉究。

山經及地誌，茫昧非受授。

團辭試提挈，掛一念萬漏。
[
2
]

欲休諒不能，粗敘所經覯。

嘗昇崇丘望，
[
3
]
戢戢見相凑。

晴明出稜角，縷脈碎分繡。

蒸嵐相澒洞，
[
4
]
表裏忽通透。

無風自飄簸，融液煦柔茂。

橫雲時平凝，點點露數岫。

天空浮脩眉，
[
5
]
濃綠畫新就。

孤撐有巉絕，
[
6
]
海浴褰鵬噣。
[
7
]

春陽潛沮洳，
[
8
]
濯濯吐深秀。
[
9
]

巖巒雖嵂崒，
[
10
]
軟弱類含酎。
[
11
]

夏炎百木盛，蔭鬱增埋覆。

神靈日歊歔，
[
12
]
雲氣爭結構。

秋霜喜刻轢，
[
13
]
磔卓立癯瘦。
[
14
]

參差相疊重，剛耿陵宇宙。

冬行雖幽墨，冰雪工琢鏤。
[
15
]

新曦照危峨，億丈恒高袤。
[
16
]

明昏無停態，頃刻異狀候。
[
17
]

西南雄太白，突起莫閒簉。
[
18
]

藩都配德運，
[
19
]
分宅占丁戊。
[
20
]

逍遙越坤位，
[
21
]
詆訐陷乾竇。
[
22
]

空虛寒兢兢，風氣較搜漱。

朱維方燒日，陰霰縱騰糅。
[
23
]

昆明大池北，
[
24
]
去覿偶晴晝。

緜聯窮俯視，倒側困清漚。
[
25
]

微瀾動水面，踴躍躁猱狖。
[
26
]

驚呼惜破碎，仰喜呀不仆。
[
27
]

前尋徑杜墅，坌蔽畢原陋。
[
28
]

崎嶇上軒昂，始得觀覽富。

行行將遂窮，嶺陸煩互走。
[
29
]

勃然思坼裂，擁掩難恕宥。

巨靈與誇蛾，
[
30
]
遠賈期必售。
[
31
]

還疑造物意，固護蓄精祐。

力雖能排斡，雷電怯呵詬。

攀緣脫手足，蹭蹬抵積甃。

茫如試矯首，堛塞生怐愗。
[
32
]

威容喪蕭爽，近新迷遠舊。

拘官計日月，欲進不可又。

因緣窺其湫，凝湛閟陰獸。
[
33
]

魚蝦可俯掇，神物安敢寇。

林柯有脫葉，欲墮鳥驚救。

爭銜彎環飛，投棄急哺鷇。
[
34
]

旋歸道迴睨，達枿壯復奏。
[
35
]

籲嗟信奇怪，峙質能化貿。
[
36
]

前年遭譴謫，
[
37
]
探歷得邂逅。

初從藍田入，
[
38
]
顧眄勞頸脰。
[
39
]

時天晦大雪，
[
40
]
淚目苦矇瞀。
[
41
]

峻塗拖長冰，直上若懸溜。

褰衣步推馬，
[
42
]
顛蹶退且復。
[
43
]

蒼黃忘遐睎，所矚纔左右。

杉篁咤蒲蘇，
[
44
]
杲耀攢介胄。

專心憶平道，脫險逾避臭。
[
45
]

昨來逢清霽，宿願忻始副。
[
46
]

崢嶸躋冢頂，
[
47
]
倏閃雜鼯鼬。
[
48
]

前低劃開闊，
[
49
]
爛漫堆眾皺。
[
50
]

或連若相從，或蹙若相鬭；

或妥若弭伏，或竦若驚雊。

或散若瓦解。或赴若輻凑。
[
51
]

或翩若船遊。
[
52
]
或决若馬驟。

或背若相惡。或向若相佑。

或亂若抽筍。或嵲若炷灸。
[
53
]

或錯若繪畫。或繚若篆籀。

或羅若星離。或蓊若雲逗。

或浮若波濤。或碎若鋤耨。

或如賁育倫，賭勝勇前購。

先強勢已出。後鈍嗔䛠譳。
[
54
]

或如帝王尊。叢集朝賤幼。

雖親不褻狎。雖遠不悖謬。

或如臨食案，肴核紛飣餖。

又如遊九原。墳墓包槨柩。

或纍若盆甖。或揭若㽅梪。

或覆若曝鱉。或頹若寢獸。

或蜿若藏龍。或翼若搏鷲。

或齊若友朋。或隨若先後。

或迸若流落。或顧若宿留。

或戾若仇讎。或密若婚媾。

或儼若峨冠。或翻若舞袖。
[
55
]

或屹若戰陣。或圍若蒐狩。

或靡然東注。或偃然北首。

或如火熺焰。
[
56
]
或若氣饙餾。
[
57
]

或行而不輟，或遺而不收。
[
58
]

或斜而不倚，或弛而不彀。

或赤若禿鬝，
[
59
]
或燻若柴槱。
[
60
]

或如龜坼兆，或若卦分繇；
[
61
]

或前橫若剝，
[
62
]
或後斷若姤。
[
63
]

延延離又屬，夬夬叛還遘。

喁喁魚闖萍，
[
64
]
落落月經宿；

誾誾樹墻垣，巘巘架庫廄；
[
65
]

參參削劍戟，煥煥銜瑩琇。
[
66
]

敷敷花披萼，闟闟屋摧霤。
[
67
]

悠悠舒而安，兀兀狂以狃。

超超出猶奔，蠢蠢駭不懋。
[
68
]

大哉立天地，經紀肖營腠。

厥初孰開張？僶俛誰勸侑？

創茲樸而巧，戮力忍勞疚。

得非施斧斤？無乃假詛咒？

鴻荒竟無傳，功大莫酬僦。
[
69
]

嘗聞於祠官，芬苾降歆齅。
[
70
]

斐然作歌詩，惟用贊報酭。
[
71
]

註釋

本唐朝作品在全世界都属于
