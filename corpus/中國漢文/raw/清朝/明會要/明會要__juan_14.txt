# NATION: 清朝

經筵日講

洪武三年二月，上御東閣。學士宋濂、待制王禕講《大學》。

十六年八月，上御謹身殿，命東閣大學士吳沈等進講《周書立政。》

十八年九月，上御華蓋殿。大學士朱善以《周易》進講。(已上《禮通考》。 )

洪武中，令儒臣更番入禁中，每日輪一員進講侍直，誤者罪之。如大學士吳沈嘗坐進講遲誤被劾。(《殿閣詞林記》。 )

永樂二年六月朔，御文華殿。大學士楊士奇以《大學》講義進，上覽其文，善之。遂命翰林、春坊諸臣，分撰諸經講義，與閣臣再閱。有未當處，悉與改正，然後呈講。

宣德二年二月己酉，御文華殿，召翰林進講《離婁篇》。三年二月，進講《舜典》，因命左右出菜茗以賜講官。(已上《禮通考》。 )

宣德以前，儒臣進講無定日，亦無定所。正統元年三月，楊士奇、楊榮、楊溥請開經筵，並擇老成識達大體者數人，以供侍講之職。太皇太后然之，命士奇、榮、溥及侍講學士王直等爲經筵官，以月之二日、十二日、二十二日會講文華殿。餘日仍令講讀官四人入講經史。(《三編》。 )

正統初選經筵官，閣臣悉以翰林院官充選。時章后在内，批云：「如何不見居外賢良？」以旨付宏文館，於是劉球諸人自部屬進次經筵。(陸釴《病逸漫記》。 )

景泰元年二月癸未，初開經筵。上每臨講幄，輒命中官擲金錢於地，任講官遍拾之，號恩典。文臣與者，内閣高穀等，外惟儀銘、俞山、俞綱、萧鎡、趙琬數人而已。(《儀銘傳》。 )

八月，御經筵。先是御史許仕達上言：「經筵之講，一暴十寒，聖學何以有成？正統間，上下蒙蔽，無敢言者。願陛下於經筵之外，日召儒臣講論經史。稽之於古，驗之於今，以應無方之變。」優詔褒答。(《實錄》。 )

故事：勳臣不知經筵，閣臣俱同知經筵。至李賢，以首輔與勳臣俱知經筵，遂以爲例。(《春明夢餘錄》。 )

成化五年
八月，復御經筵。先是劉定之請：「經筵兼講太祖御製諸書，斥異端邪教，勿令害政耗財。」上留其疏，至是乃詔行之。(《憲章錄》。 )

弘治元年
三月，吏部侍郎楊守陳請遵祖制，開大小經筵。略言：「大經筵但如舊制。若小經筵，當擇端介博雅之臣，以次進講。凡前朝典籍，祖宗謨訓，百官章奏，皆當貯文華後殿，退朝披覽。日令内閣一人，講官二人，居前殿右厢，有疑輒問。一日間，居文華殿之時多，處乾清宫之時少，則欲寡心清，臨政不惑，而出治之本立矣。」帝遂於月之丙子開經筵。翼日丁丑，命儒臣進講。(《楊守陳傳》。 )

七月，文華殿日講畢，賜講官程敏政等各織金緋衣金帶。上皆呼「先生」而不名。(王圻《通考》。 )

諭德王華在講幄最久，孝宗甚眷之。李廣貴幸，華講《大學衍義》，至唐李輔國與張后表裹用事，指陳甚切。帝命中官賜食勞焉。(《王守仁傳》。 )

五年二月，定經筵俱用吉服。(《大政記》。 )

十年三月，有詔以下旬御經筵。給事中楊廉言：「故事：經筵一月三舉。苟以月終起，以月初罷，則進講有幾？且經筵起而後日講繼之；今遲一日之經筵，即輟一日之日講也。」報聞。(《儒林楊廉傳》。 )

侍講學士王鏊充講官。中貴李廣導帝游西苑。鏊講：「文王不敢盤於游田，」反覆規切，帝爲動容。講罷，謂廣曰：「講官指若曹耳！」(《王鏊傳》。 )

正德元年三月丁亥，大學士劉健等言：「自開講以來，不時傳旨暫免者，多以兩宫朝謁爲詞。近又云：擇日乘馬。臣等愚見，以爲乘馬等事，似與講學兩不相妨。至於慈宫問安，往來不過頃刻。且兩宫以宗社爲念，見皇上勤於講學，亦必喜動顏色。今以頃刻之問安，而廢一日之學業，恐非所以慰聖顏，承慈意也。伏乞日勤聽講，除舊例假日外，其餘尋常之日，不暫停免。使臣等得以少效涓埃，則聖德日隆，聖治日新矣。」報可。

九月戊寅，上御經筵。先是經筵既開，以暑月停免。至八月，劉健等以爲請。時上方大婚，命俟九月。至是，司禮監復傳旨，欲免午講。健等以：「先帝故事，日再進講。伏乞聖明少留數刻，使臣等照舊每日二次進講。庶幾盡保傅之責，以免曠職之愆。」(已上《實錄》。 )

二年三月，上御經筵。詹事楊廷和、學士劉忠直講。講畢，因致規諫語。上退，語劉瑾曰：「經筵講書耳，何添出許多話來？」瑾曰：「二人可令南京去。」於是並遷南侍郎。(《昭代典則》。 )

嘉靖元年五月，命經筵輟講。林俊舉祖宗勤學故事以諫，不聽。(《林俊傳》。 )

六月丁丑，大學士楊廷和等上言：「近以暑日，傳旨經筵日講俱暫免，又免午奏。臣等職司輔導，實有未安。伏乞宫中無事，不廢讀書。其《大學》、《尚書》，容臣等接續前日所講讀者，量進起、止。仍不時御文華殿召見臣等，俯賜訪問。」上是之。已而編修湛若水亦以爲言，俱報聞。(《實錄》。 )

六年六月，上諭：講官日輪一員，將經書《通鑑》撮其有关君德者，直錄其義以進。楊一清言：「經書淵微，《通鑑》浩繁、請日講《大學衍義》。」從之。(《通紀》。 )

是月，定講《大學衍義》儀。每月初三、初八、十三、十八日，用經筵講官二員進講，内閣學士一員侍班。講畢，賜茶酒飯，俱如日講儀。(《五禮通考》。 )

經筵講官及執事官失儀，舊制：許令出班請罪，得面宥。世宗以經筵乃講學親賢之地，一切差誤，令侍儀科道退而具奏，免其自請。(《春明夢餘錄》。 )

八年三月，上御經筵。國子祭酒陸深進講，言：「經筵講章必送内閣裁定，是其意盡出閣臣，講官不過口宣之耳。此於大義未安，而感孚之道亦甚相遠。請容臣等各陳所見，因以觀臣等之深淺。更請自訓詁衍繹之外，凡天下政事典章，得依經比義，條列陳奏，以裨聖學。」上以深欺罔，詔降一級，謫延平同知。(《通紀》。 )

十年，定無逸殿講儀。(《五禮通考》。 )

十二年五月，召講官廖道南進講《論語·高宗諒陰》節。吏部尚書汪鋐求大學士張孚敬改題，以其有「君薨，聽於冢宰」句。道南執不肯，孚敬遂具揭帖以進。上批云：「前日徐縉講《孟敬子章》，撤去二節『人之將死』不講。夫死生，人道之常，何諱之有？如卿等言，則忠讜之論何由得聞？還命道南照舊進講。」(王圻《通考》。 )

隆庆六年，定：每日早講畢，帝進暖閣少憩，閱章奏。閣臣等退西厢房。久之，率講官再進午講，講《通鑑節要》及《贞觀政要》。講畢，帝還宫。凡三、六、九视朝日，暫免講讀。(《禮志》。 )

神宗即位，張居正請定三、六、九日视朝，餘日御文華殿講讀。(《三編》。 )

万历初，御經筵畢，覽《贞觀政要》，曰：「唐太宗多有惭德，魏徵大節有亏。」命以後講《禮記》，其《贞觀正要》停講。(《春明夢餘錄》。 )

二年十二月，講讀畢，問張居正：「元夕鳌山烟火，祖制乎？」对曰：「非也。成化間，以奉母后。當時諫者，不独言官，即翰林亦有三四人上疏。糜费無益，所當節损。」上曰：「然。」明年元夕，罷烟火鳌山。(同上。 )

是年，定經筵春講，以二月十二日起，至五月初二日止；秋講以八月十二日起，至十月初二日止。(《禮志》。 )

六年十二月甲辰，張居正以聖學方新，經筵日講，遠稽古訓，不若近事之可徵；上溯先王，不若家法之易守。乃屬儒臣將太祖、列聖《實錄》、《宝訓》分类編辑，以經筵日進講。上嘉纳之。(《春明夢餘錄》。 )

十五年二月，罷日講。申時行請免日講，仍進講章，以备觀覽。自後爲故事，講筵遂永罷。(《申時行傳》。 )

熹宗初御講筵，内閣戒講官宜简要，講畢勿多献。孙承宗曰：「主上幼冲，正宜详明切直，博引曲譬。若講官聽中堂爲芟改，中堂又视中官爲忌諱，則講筵爲無人矣。」講官李光元亦言：「講章不宜芟改。」上書争之。(《春明夢餘錄》。 )

天启二年十月，文震孟上《勤政講學疏》。略言：「經筵日講，臨御有期。學非不講，然侍臣進講，铺叙文辞，如蒙师诵说已耳。祖宗之朝，君臣相对，如家人父子，咨訪军國重务，闾阎隐微，情形畢照，奸诈無所藏。左右近习，亦無缘蒙蔽。若仅尊严如神，上下拱手。經傳典謨，徒习故事。安取此正笏垂绅、展書簪笔者爲？」(《震孟傳》。 )

時有詔停經筵日講。給事中周朝瑞等言：「此果出聖意，輔臣當引争。如輔臣阿中涓意，則其過滋大。且主上冲龄，志意未定，独赖朝講不輟，諸臣得一觐天顏，共目指鹿之奸。今常朝已渐傳免，傥並講筵廢之，九阍既隔，無謁見時。司馬门之報格不入，吕大防之贬不及知，國家大事去矣。」會禮部亦以爲言，乃命曰講如故。(《朝瑞傳》。 )

崇禎元年，文震孟官中允，充日講官，在講筵最严正。時大臣數逮系，震孟講《鲁論》「君使臣以禮」一章、反覆規讽。帝即降旨出尚書乔允升、侍郎胡世赏於狱。帝嘗足加於膝，适講《五子之歌》，至「爲人上者奈何不敬，」以目视帝足。帝即袖掩之，徐爲引下。時称「真講官。(《震孟傳》。)三年，日講官罗喻義呈講章於政府。温體仁今改，不從。體仁怒，上言：「故例：唯經筵進規，多於正講。日講則講多規少。今喻義以日講用經筵之例，令删改不從。」乃下吏部议。喻義奏辩曰：「講官於正文外，旁及時事，亦舊制也。臣展转敷陳，冀少有裨益。體仁删去。臣诚恐愚忠不获上達，致忤輔臣。今稿草具在，望聖明省覽。」部议：革職闲住。(《喻義傳》。 )

十五年，倪元璐以大司农充講官，講「生財有大道」一節，極言加派聚敛之害。上震怒，謂：「边饷匮乏，部中未見有長策，徒作此皮面語。」元璐徐曰：「臣儒者，所陳虽是書生語，然不敢怀利以事君。」上默然。次日謂閣臣曰：「講筵有問难而無诘責。昨日之言，朕甚悔之。」(《春明夢餘錄》。 )

東宫出閣講學

洪武元年
十月，建大本堂。命魏觀侍太子说書及授諸王經。又選國子生國琦、王璞、張杰等十餘人，侍太子讀書禁中。琦等入对謹身殿。帝謂殿中侍御史郭淵文等曰：「諸生於文艺习矣。然與太子處，當端其心术，不流浮靡。」(《紀明》。 )

初，太祖命學士宋濂授皇太子諸王經於大本堂，後於文華後殿。世宗改爲便殿，遂移殿東厢。(《禮志》。 )

濂傅太子，先後十餘年，凡一言動，皆以禮法讽劝，使归於道。至有关政教及前代兴亡事，必拱手曰：「當如是，不當如彼。」皇太子每敛容嘉纳，言必称「师父」云。(《宋濂傳》。 )

天顺二年四月乙丑，皇太子出閣講讀。上語廷臣曰：「東宫講讀宜在文華殿，朕欲移居武英殿，但早晚朝見太后不便。」乃以左廊居東宫。(《昭代典則》。 )

成化十八年
十二月，《文華殿大訓》成。書凡二十八卷，列綱四：曰《進學》，曰《养德》，曰《存伦》，曰《明治》。帝親制文弁其首，命詹事彭花、中允周經等進講於太子。太子每起立拱聽。万安以爲勞，謂講官宜請坐聽。華與經不從，竟得如禮。(《三編》。 )

弘治十一年
三月己亥，皇太子出閣讀講。東宫宦竖不欲太子近儒臣，數以事間之。詹事吳宽上疏曰：「東宫講學，寒暑风雨則止，朔望令節則止。一年不過數月，一月不過數日，一日不過數刻。是進講之時少，輟講之時多，岂容復以他事妨之？古人八岁就傅，即居宿於外，欲令離近习，親正人。庶民且然，况太子天下本哉？」(《吳宽傳》。 )

十五年，尚書馬文升奏：「皇太子當進學之時，虽日出讀書，止在左春坊與二三内閣翰林等官相接。且去處颇狭，未甚從容。古者帝王之教太子，左右前後，罔非正人，是以教諭而德成。臣愚請皇太子照皇上御經筵故事，每月三次，初六、十六、二十六，出御文華殿，令六部、都察院、諸卿、掌印官同内閣大臣、東宫講讀等官侍班讀書，庶皇太子收敛身心。相接日久，自然識見益廣。」疏入，帝不纳。(《明臣奏议》。 )

嘉靖二十五年，皇太子生十一年，犹未出閣講學。御史周冕極言諭教不可缓，請早降纶音，慎選侍從。帝怒，謫云南典史。(《周冕傳》。 )

万历二十年正月，給事中李献可偕六科諸臣疏請豫教。言：「元子年十有一矣，豫教之典，當及首春舉行。傥謂内廷足可诵讀，近侍亦堪輔導，則禁闼幽間，岂若外朝之清肃，内臣忠敬，何如师保之尊严？」(《李献可傳》。 )

二十二年，皇長子常洛出閣講學，時已十四岁。帝手諭閣臣，令议出閣講學禮儀。兵部請护卫，工部奏儀仗，禮部進儀注，皆留中。令止豫告奉先殿，朝謁兩宫，他禮皆廢。給事中張贞觀等言：「禮官议：『御门受贺。』皇長子見群臣之禮，载在舊儀。即諸王加冠，亦以成禮而贺，贺畢謁見。元子初出，乃不當諸王一冠乎？且謁谢止兩宫，而缺然於陛下及中宫母妃之前，非所以教孝。贺靳於二皇子，而漠然於兄弟長幼之間，非所以序别。」疏入忤旨，夺俸一年。(《張贞觀傳》。 )

三十七年二月，大學士叶向高請令東宫講學。時東宫輟講者五年，廷臣屡請，不得命。至是，向高擇吉以請，亦不報。自是，岁春秋必恳請，帝不纳。(《向高傳》。 )

景等爲講讀官。皇太子進執事諸臣及賜酒馔，皆称「先生」；進对進仿，敏妙合法。中外大悦。然一講而輟，後不復更舉矣。(《三編》。 )

崇禎十一年二月，太子出閣。十五年正月关講。閣臣條上講儀。七月，改慈庆宫爲端本宫。慈庆，懿安皇后所居也。時太子年十四，议明岁選婚，故先爲置宫，而移懿安後於仁寿殿。(《諸王傳》 )

冠禮

太子、皇孙年十二或十五始冠。天子自爲主，擇三公、太常爲宾赞。凡三加冠、一祝醴。成化間始定祝詞、醮詞、勒戒詞。其諸王冠、祝醮詞，皆洪武間定。(《會典》。 )

洪武元年，定皇太子冠禮。(《通典》。 )始加折上巾，再加遠游冠，三加九旒冕。(陸釴《病逸漫記》。 )二十六年，定親王冠禮。(《會典》。 )

永樂九年十一月，立皇長子瞻基爲皇太孙，冠於華蓋殿。冕服如皇太子，玉圭如親王。(《三編》。 )景泰四年二月乙未，皇太子冠。(《大政記》。 )

成化十四年三月，續定皇太子冠禮：初加翼善冠，再加皮弁，三加冕旒。(《會典》。 )甲子，皇太子冠。(《大政記》。 )二十三年，更定親王冠禮。(《會典》。 )

弘治九年三月乙亥，皇太子冠。(《大政記》。 )

嘉靖二十四年，穆宗在東宫，方十岁，欲行冠禮。大學士严嵩、尚書费采初皆难之，後遂阿旨，以爲可行，而請稍简烦儀，止取成禮。帝以冠當具禮，至二十八年始行之。(《禮志》。 )

三十一年三月癸未朔，裕王、景王行冠禮。宾自致祝，不再宣祝官。(《會典》。 )隆庆元年十一月，定東宫加冠儀注。宏孝殿、神霄殿亦當预告。

万历三年正月，帝擇日長发，命禮部具儀。張居正等言：「禮重冠、婚。皇上前在東宫，已行冠禮、三加弥尊，執爵而。巨禮既成，可略其细，不必命部臣拟议。第先期至奉先殿、宏孝殿、神霄殿以長发告。禮畢，诣兩宫皇太后，行五拜三叩头禮。随御乾清宫受贺。」帝是之，遂著爲令。(《通典》。 )

二十四年，禮部奏：』皇長子出閣在迩，合先行冠禮，以見講官。但尚未册立；既不可遽用東宫之儀，又不可下同親王之服。姑令暫著常服出講，以待册立之日，再行冠禮，如敕奉行。」禮科給事中楊天民奏：』皇長子已及十有五岁，加冠、選婚，正當其候。乞諭禮部擇吉具儀，及時並舉，則於大典有光。」(《典汇》。 )

二十九年，禮部尚書冯琦言：「舊制：皇太子冠，設冠席、醴席於文華殿内。今文華殿爲皇上臨御遣官之地，則皇太子冠、醴度應移於殿之東序。又：親王冠，舊設席於皇極门之東庑，今皇太子移席於殿東序，則親王應移席於殿西序。」從之。(《禮志》。 )

天启元年正月，上行冠禮。科臣成明極爲規以献。(《通紀》。 )

品官冠禮：始加缁布冠，再加進賢冠，三加爵弁。(《會典》。 )

○婚禮

洪武元年，令：民間婚娶，並依《朱子家禮》。又令：男女婚姻各以其時。或有指腹、割衫襟爲親者，並行禁止。(《會典》。 )十二月，定皇太子親王士庶婚禮。(《大政記》。 )

五年，詔曰：「古之婚禮，结兩姓之欢，以重人伦。近世以來，专論聘財，习染奢侈。宜令中書省集议，定制颁行，务從節俭，以厚风俗。违者，論罪如律。」(《會典》。 )

十七年十二月，翰林院待詔朱善上疏，論昏姻律。曰：「民間姑、舅及兩姨子女，法不得爲婚。仇家诋讼，或已聘見绝，或既婚復離。甚至儿女成行，有司逼夺。按舊律：『尊長卑幼相與爲婚者，有禁。』蓋謂母之姊妹與已之身，是爲姑、舅、兩姨，不可以卑幼上匹尊屬。若姑、舅、兩姨子女，無尊卑之嫌。成周時，王朝相與爲婚者，不過齐、宋、陳、杞，故称異姓大國曰伯舅，小國曰叔舅。列國齐、宋、鲁、秦、晋，亦各自爲甥舅之國。後世晋王、谢，唐崔、卢、潘、楊之睦，朱、陳之好，皆世爲婚媾。温峤以舅子娶姑女，吕榮公夫人張氏即其母申國夫人姊女。古人如此甚多。願下群臣议，驰其禁。」從之。(《朱善傳》。 )

二十六年正月，重定諸王、公主婚禮。(《大政記》。 )

永樂十四年四月，定皇太孙婚禮。儀仗如親王，降皇太子一等，而用象辂。(同上。 )深泽知县王源劝民及時嫁娶，革其争財之俗。(《王源傳》。 )

明兴，諸帝即位後，行册立禮。正統七年，英宗大婚，始定儀注。(《禮志》。 )

天顺八年，憲宗即位。有司以遗詔請大婚。南京吏部侍郎章纶言：「山陵尚新，元朔未改。百日從吉，心宁自安。陛下践阼之初，當以孝治天下。三綱五常，實原於此。乞俟來春舉行。」议虽不從，天下感重其言。」(《章纶傳》。 )

成化十八年十一月，禁諸王府不得與親屬爲婚。(《大政記》。 )

正德元年七月，帝將大婚，詔取太仓银四十万兩。御史趙佑言：「左右以婚禮爲名，將肆無厌之欲。计臣惧祸而不敢阻，閣臣避怨而不敢争。用如泥沙，坐致耗國。」韩文亦连疏請，命减四之一。(《趙佑傳》。 )

嘉靖元年九月乙巳，以大婚期近。遣徐元祚告天地，郭勳告太庙。刑部尚書林俊上言：「今日之最急者，惟取法祖宗，躬行節俭。兹大婚届期，六禮之儀，固不可缺，中外赏犒，爲费尤多。時绌舉赢，其何能济？願一切罷省，崇節俭以爲天下先。」詔褒纳之。(《實錄》。 )

舊制：立後謁内庙而已。嘉靖十三年正月，立皇后方氏，下禮臣议庙見禮。於是群臣议，以天子立三宫以承宗庙，《禮經》有庙見之文。乃考据《禮經》，参稽《大明集禮》，拟儀注以上。至期，帝率後謁太庙及世庙。(同上。 )

三十二年正月，詔裕王、景王出邸，同日婚。禮部尚書欧阳德以裕王储贰，不當出外，疏言：「曩太祖以父婚子，諸王皆處禁中。宣宗孝宗以兄婚弟，始出外府。今事與太祖同，請從初制。」帝不許。德又言：「《會典》醮詞，主器則曰『承宗』，分藩則曰『承家』，今裕王當何從？」帝不悦，然終諒其诚，婚亦竟不同日。(《欧阳德傳》。 )

万历六年，帝大婚届期，以張居正充纳采、問名副使，吉服從事。給事中李涞言：「大婚重典，而使居正變服從吉，骇觀聽，不宜。乞别简用。」不聽。(《三編》。 )

十年议准：宗室奏選正配，仍奏請封號。俟有成命，方許成婚。若成婚在未封之先者，謂之擅婚。所生之子，止許請名，不許請封。(王圻《通考》。 )

又议准：宗室子女年十五以上，奏行本境内官军、军民之家及居官入籍年久者選擇婚配。虽系重结王親，亦必服屬無碍，方准題請授封成婚。(同上。 )

二十四年四月，以諸皇子婚，詔取太仓银二千四百万兩。户部告匮，命严核天下积储。(《本紀》。 )

○乡饮酒禮

洪武初，詔中書省详定乡饮酒禮。使民岁時宴會，习禮讀律。期於申明朝廷之法，郭叙長幼之節。遂爲定制。

五年四月戊戌，詔天下行乡饮酒禮。每岁孟春孟冬，有司與學官率士大夫之老者，行於學校。民間里社以百家爲一會，或粮長里長主之。年最長者爲正宾，餘以齿序。每季行之。讀律令，則以刑部所編申明戒諭書兼讀之。武職於每月朔日，以大都督府所編戒諭書率僚佐讀之。(已上《會典》。 )

是年，魏觀出知苏州府，聘耆民周寿谊、楊茂、林文友，行乡饮酒禮。(《魏觀傳》。 )十四年二月，申明乡饮酒禮。(《大政記》。 )

十六年，颁行《乡饮酒禮圖式》。其儀：以府州县長吏爲主，以乡之致仕官有德行者爲亻巽；擇年高有德者爲宾，其次爲介，又其次爲三宾，又其次爲众宾，教職爲司正。赞禮、赞引、讀律皆使能者。(《會典》。 )

十八年，重定乡饮酒禮。叙長幼、論賢良、别奸顽、異罪人。其坐席間：高年有德者居於上，高年纯笃者居於次，餘以齿序。其有曾违條犯令之人，列於外坐，同类者成席，不許杂於善良之中。(同上。 )

二十二年，定乡饮酒禮，以善恶分列三等爲坐次，不許混淆。如有不遵序坐及有過之人不赴饮者，以违制論。(《會典》。 )○禁逾侈

洪武元年十二月，諭中書省臣曰：「帝王之治天下，必定禮制，以辨貴贱，明等威。是以汉高初兴，即有衣锦绣绮、操兵、乘馬之禁。历代皆然。近代风俗相沿，流於奢侈。闾里之民，服食居處，與公卿無異。貴贱無等，僭禮败度。此元之所以失也。宜明立禁條，颁示中外，俾各有所守，以正名分。」(《聖政記》。 )

三年八月己卯，申禁官民器服僭用。(《大政記》。 )

十八年九月庚午，諭户部曰：「足食在於禁末作，足衣在於禁華靡。宜申明天下：四民各守其業，不許游食；庶民之家，不許衣锦绣。」(《大訓記》。 )

二十六年六月辛丑，申严公侯制是度僭侈之禁。(《大政記》。 )

三十年八月，上御奉天殿，見散骑舍人衣極鲜丽，問：「制用幾何？」对曰：「五百贯。」上曰：「五百贯，农夫十數口之家一岁之资也。尔乃费之於一衣，岂非暴殄？」命切責之。(《昭代典則》。 )

宣德四年二月乙未，諭行在禮部尚書胡濙曰：「朝廷之禮，最先正名。尊卑等級，不可僭差。凡内外官員士庶，服饰儀從，皆有定制。近多越禮犯分。其揭榜申明定章，使無僭越。」(《大訓記》。 )

成化六年十二月，禁奢侈，從給事中王宏請也。(《大政記》。 )弘治十一年十二月庚子，禁中外奢靡逾制。

正德元年六月辛酉，禁吏民奢靡。十四年二月丁未，禁冠服非制。嘉靖九年二月丁丑，禁官民服舍器用逾制。十四年二月丁未，禁冠服非制。(已上《本紀》。 )

二十四年闰正月，詔中外严禁奢靡。(《大政記》。 )

二十七年四月，給事中奏請申明禮制。凡饮食、宴會、服舍、舆馬、器用之类，悉差爲等第，令不得逾越。(《憲章錄》。 )

万历五年六月戊辰，禁廷臣奢僭。(《本紀》。 )沈鲤爲禮部尚書，念時俗侈靡，稽先朝典制，自丧、祭、冠、婚、宫室、器服率定爲中制，颁天下。(《沈鲤傳》。 )

崇禎十六年十月十六日敕：「朕浣衣减膳，已有逾旨。今用锡、木、磁器，以示俭约。其金银各器，系关典禮者留用；餘貯库以备赏赉。内外文武諸臣，俱宜省约。贼平之後，照舊。(《春明夢餘錄》。)旌表明初，凡有孝行節義，由各地方申報，风憲官核實奏聞，即與旌表。其後止許布衣編民，委巷妇女得以名聞，其有官職及科目出身者，不與焉。(《會典》。)洪武二十七年九月，命禮部定旌表例。時日照民江伯儿以母病，杀其三岁子祀岱岳。有司以孝聞。帝怒其减绝伦理，杖百，戍海南。因命禮部定旌表孝行事例。尚書任亨泰议曰：「人子事親：居則致其敬，养則致其樂，有事則謹其医药。卧冰、割股，事非恒經。割股不已，至於割肝，割肝不已，至於杀子。违道伤生，莫此爲甚！堕宗绝祀，尤不孝之大者，宜严行戒諭。傥愚昧無知，亦聽其所爲，不在旌表之例。」詔曰：「可。」(《任亨泰傳》。 )

徐宗實爲苏州通判，請旌元節妇王氏。禮部以前朝事，不當允。宗實言：「武王封比干墓，独非前朝事乎？」遂得旌。(《徐宗實傳》。 )

宣德元年五月，总旗卫整女，母病笃，割肝煮液。母饮之而愈。禮部特爲請旌。帝曰：「孝親有道。部腹割肝，岂可爲孝？若因此伤生，其罪益大。女子無知，不必加罪。所請不允。」(《大訓記》。 )
