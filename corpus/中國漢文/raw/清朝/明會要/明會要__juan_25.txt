國學
〈
蔭監詳職官任子
〉

太祖乙巳九月丙辰朔，置國子學。以故集慶路學為之。(《大政記》。 )

洪武元年，令品官子弟及民間俊秀通文義者，並充學生。尋詔擇府、州、縣學諸生，入國子學。又擇年少舉人趙惟一等，及貢生董㫤等，入學讀書。命於諸司先習吏事，謂之𢟍事監生。取其中尤英敏者李扩等，入文华、武英堂说書，謂之“小秀才”。其才學优赡、聪明俊伟之士，使之博极群書，講明道德通經之學，以期大用，謂之“老秀才”。(《選舉志》。 )

洪武二年，太祖諭中書省臣曰：“太學育賢之地，所以興禮荣、明教化，賢人君子之所自出。古之帝王建國君民，以此為重。朕承困弊之余，首建太學，招徕師儒。今學者日眾，斋舍卑隘，不足以居。其令有司增益學舍。”(《大訓記》。 )

是年，擇國子生，試用之巡行列郡。舉其職者，竣事复命，即擢行省左右参政、各道按察使、佥事及知府等官。五年，以國子生王铎摄監察御史。(已上王圻《通考》。 )

八年，選國子生林伯去等三百六十六人，分教北方。(《大政記》。 )

十五年五月己未，新建太學成，改為國子監，分六堂以館諸生，曰：率性、

道、誠心、正義、崇志、廣業。庚午，命刘仲质立學規二十条，合钦定九条，頒赐諸生。(《紀明》。 )

太祖幸太學还。馬皇后问生徒几何？帝曰：“數千。”後曰：“人才眾矣。諸生有廪食，妻子将何所仰給？”於是立红板仓，積粮赐其家。太學生家粮自此始。(《馬皇后傳》。 )

十七年四月，增筑國子學舍。(《本紀》。 )

十九年，命祭酒、司業，擇監生千余人送吏部，授知州、知縣等職。二十年，擢監生李慶署右佥都御史。(已上王圻《通考》。 )

二十一年十一月，命禮部給赐國子生钞。在監三年以上者，五锭；二年，人二锭；俾制是冬衣。复命工部，於國子監前造别室一区，以處諸生之有疾者，令膳夫二十人給役。(《世法錄》。 )

二十三年，令本監辟射圃，給監生弓矢，習射。(《會典》。 )

二十四年，選監生方文等六百三十九人，命行御史事，稽核天下百司案牒。

二十五年，擢監生師达、墨麟等為監案御史，夏原吉為户部主事。(已上王圻《通考》。 )

二十六年十月壬辰，除監生二百四十一人為教諭等官。既又擢監生刘政、龙镡等六十四人，為行省布政、按察兩使及参政、参議、副使、佥事等官。(《大政記》。 )

初，以北方喪亂之余，人鮮知學，遣國子生林伯云等三百六十六人，分教各郡，後乃推及他省，擇其壮歲能文者為教諭等官。(《選舉志》。 )

时國子生殷敏選入武英殿紀事，監察御史。蓋其时储養國學，有出使历事之任，又有大本堂讀書、武英殿紀事等清要之責，故賢才輩多出其中。二十九年，擢監生卢祥為刑部郎中。(王圻《通考》。 )

建文二年十月，更定历事監生選法。凡历事一年為滿，考分三等：上者授官；次、下者再历一年复考，上者授官，次量材選授，下还監肄業。(《昭代典則》。 )

永樂二年，始以北平府學為北京國子監。八年，重建左監、右學、南雍六堂。(王圻《通考》。 )仁宗初，擢監生徐永溍等二十人，為給事國。(《本紀》。 )

宣德二年七月，汰監生一千九百余人，南京汰監生千五百余人，為民。

四年九月，放免南北監生年老無成者，二百五十三人。(已上《大政記》。 )

北京國子監助教王仙言：“學校教養人材，固当講習經史；至於書灵敏之學，亦当用心。近年生員止記育文字，以备科貢；其於字學、算法，略不通曉。乞令兼習，從提调正官按祭司巡按御史考試。”從之。(《通紀》。 )

七年四月己酉，增建國子監學舍。諸生有家室者，給月粮如南京例。(《大政記》。 )

正統三年十一月，南京國子監祭酒陳敬宗上書言：“舊制：諸是生以在監久近，送諸司历事。此年有因事予告者，迁延累歲，至拨送之期始赴，實长奸惰。請以肄業多寡為次第。又近有愿就雜職之例，士风卑陋，誠非细故，請加禁止。”從之。(《陳敬宗傳》。 )

景泰五年三月，户部侍郎孟鉴言：“國子生二千余人俱仰給官廪，有名無實。請留年深者千余人，余悉放歸。”從之。(《通紀》。 )

成化四年，吏部尚書李秉等奏：“近来，監生記名听選者八千余名，逐年起送到部者，尤多於听之數。先後積滞，賢否混淆。兹欲将该選監生考選：‘身’‘言’‘書’‘判’四事俱可了以者，居优等選用。三事、二事可取者，量才授任。其無可取而年貌衰老者，令冠帶閑住。”從之。(《昭代典則》。 )

六年五月，命袭封衍聖公孔宏泰朔望随班朝参，在監讀書一年，乃許歸。(同上。 )

九年二月，南京吏部尚書崔恭奏：“南雍監生历事滿，必抵北紀選，而还卒業。其中有貧乏者，病於往复，率多淹滞。請即紀選於南吏部。”從之。(《實錄》。 )

弘治八年，定國子監生分拨历事期。凡历事：吏部四十一名，户部五十三名，禮部十三名，大理寺二十八名，通政司五名，行人司四名，五軍都督府五十名，謂之正历。三月上選，滿日增减不定。又有諸司写本：户部十名，禮部十八名，兵部二十名，刑部十四名，工部八名，都察院十四名，大理寺、通政司俱四名，随御史出巡四十二名，謂之雜历。一年滿，改上選。(《三編》。 )

禮部尚書李时言：“國初，監生俱由廣業堂積漸升率性堂，始得積分。故天順以前，監生必作養十余年，然後拨历。後積滞人多，节将拨历歲量减。至弘治八年，國子監有坐班人少，不敷拨历之期。本部尚書倪岳題稱：‘权宜救弊之法有二：增貢額以足坐班生徒，議差历以久坐班歲月。’今國學缺人，视弘治為甚。所有前项事例，似应参酌舉行。”詔從之。(《春明夢余錄》。 )

嘉靖八年，廷議复申三途並用之例。於是以舉人監生阮徽、歲貢監生张澍為監察御史。(王圻《通考》又云：國初太學生，皆貢自郡邑，選鄉學之秀者充之。其後乃有各省鄉試舉人。时進士之科未盛，内而台諫，外而藩臬，率以授學生之成材者。自制科既重，太學生成材者与天下賢士尽入搜罗。於是内外要重之司，皆歸進士。而舉貢所稱監生者，則有遺賢。銓入高等，不过授以省、府幕僚、郡佐、州正。而台諫、藩臬則必待其历官有誉而後得之。然亦千百而什一耳。 )

舉監〓
洪武十八年，令會試下第舉人，送監卒業。(《明史選舉志》：“舉人入監，始於永樂。”但於洪武时，明言“擇年少舉人趙唯一等入學讀書。”則又兩歧。兹據《會典》。 )

三十一年，試寄監下第舉人，次第授教官。(《大政記》。 )

永樂二年六月，命翰林院更試下第舉人，擇文词优等者，得张铉等六十人。上召見，皆赐冠帶，送國子監肄業。(《宪章錄》。 )四年三月，亲試下第周翰等四十二人，送監進學。

十三年三月，再試下第舉人朱瑛等二十四人，赐冠帶，入國學。(已上《大政記》。 )

宣德七年，取下第胡概、金庠等十余人，送監讀書。(《

八年三月，帝命禮部尚書胡濙与大學士揚士奇、揚荣選副榜舉人龙文等二十四人，送監進學。(《大政記》。 )正統二年，令：副榜舉人不愿就教職者，入監卒業。

成化十四年，令：南方舉人愿入南監者听。(已上《會典》。 )嘉靖十七年二月，詔許应天中式送國子學。(《明政統宗》。 )

萬历十三年，奏定：凡舉人下第，及中副榜不愿就教者，尽數分送兩京國子監肄業。不許假借名色，呈請順天应給引回籍。順天府亦不許径自給引。違者参究。(《會典》。 )

祭酒吕楠言：“舉人在監，本以观光皇极，薰陶德性。今查在監實數，天下之廣，仅止二三十人。蓋自會試之後，支稱他故回籍，荒廢學業。及試期，方迫監簿计水程，用規拨历。未仕如此，居官可知。敕该部将入監告回舉人，移文行取，申明‘違限作旷，计月加旷，不許會試’之条。庶士类知儆，眾向於學。”(《春明夢余錄》。 )

貢監〓一日，歲貢。洪武初，命各學歲貢一人，謂之歲貢。其後，例屬更。弘治、嘉靖間，定：府學歲二人，州學二歲三人，縣學歲一人；遂為永制。一日，選貢。弘治中，從南京祭酒章懋言。於常貢外，令提學行貢之法。不分廪膳、增廣生員，通行考選。务求學行兼优，年富力强，屡試优等者，乃以充貢。通计天下之廣，約取五六百人，三、五年一行。此選貢所由始也。一日，恩貢。國家有慶典，或登极詔書，以当貢者充之。一日，纳貢。视例監稍优，其實相仿也。(《選舉志》。 )

洪武十六年正月，司諫关賢上言：“迩来都邑所司非人，師道不立，及至選貢，賢愚混淆。其甚者，将俊秀生員，黜充承差，有乖育才之意。”禮部尚書任昂奏定學校歲貢士法。(《任昂傳》。 )

二月丙申，命天下府、州、縣學，自明年始，歲貢生員各一人。正月至京，從翰林院試經義、《四書》各一道，判语一条。中式者，入監讀書。不中者，罰為吏。(王圻《通考》。 )

正統十四年，令南直隶歲貢生俱送北監。(《會典》。 )

天順五年，令天下生員年四十以上者，考選，送國子監肄業。(王圻《通考》。 )成化十四年，奏定：南直隶歲貢生仍还南監。

弘治十七年，奏定：歲貢生愿就教者，听禮部考試。不中者，分送南北監肄業。(已上《會典》。 )

萬历中，工科郭如心言：“選貢非祖制。其始欲补歲貢之乏，其後遂妨歲貢之途。請停其選。”神宗以為然。至崇禎时，又常行之。(《選舉志》。 )

祭酒吕楠疏：“歲貢入監，即古鄉舉、里選六德、六行、六艺之士，故《禮》稱‘四十强仕’。近年有歲貢二十上下者，其德行焉考？甚且禮儀未娴。各提學惟取词章，不顾行检。遂使质朴沦坠。乞敕该部，转行提學官，当歲貢期，於食廪年深二、三名内，遵照祖宗卧碑，参取德行。必注其平日某德、某行，以副敦崇實學之至意。(《夢余錄》。 )

(《明史舉志》載會試副榜，未載鄉試副榜。按《永春州志》：天启元年，凡鄉試副榜，廪准監，增附准廪。至崇禎己卯，皆准貢。《史稿》略而不書，然犹見故家藏有是科鄉試副榜全錄，与《永春志》合。據以备考。 )

例監〓景泰四年四月己酉，令生員纳粟為國子生。初洪武中，監生与荐舉人材参用，故其时大學生最盛。迨荐舉既廢，進士日重，而監生轻。至是纳粟例开，不久即止。然其後或遇歲荒，或因边警，或大興工作，率據前例行之。而軍民子弟亦得援生員之例以入監，謂之“民生”，亦謂之“俊秀”，或竟謂之“例監”，而監生日益轻矣。(《三編》。 )

成化二年，南京大饥，守臣建議，欲令官員軍民子孫纳粟送監。禮部尚書姚夔言：“太學乃育才之地。近者直省起送四十歲生員，及纳草、纳馬者，动以萬计，不胜其滥。且使天下以货為賢，士风日陋。”帝以為然，為却守臣之議。(《選舉志》。 )

十年十月，禮部議：“科貢入監，乃祖宗舊典。纳粟，實一时权宜。况纳粟送監，其复班之日，多在科貢者入監之先。若仍缘舊規，以次取拨，是使纳粟者得以遂捷取之愿，而科貢者不能無淹困之嗟。宜敕國子監，於此兩途，酌其多寡，分序拨历。”上，從之。(《昭代典則》。 )

弘治五年，吏部尚書王恕奏：“自纳粟等项事例既开，雜進者日多一日。以致正途監生壅滞不得出身，候選至十五六年以上，才得一官。年紀日衰，谁肯尽心職業？况此等既以财進身，他日豈能以廉律己？伉财害民，天下治安何由而得？今後各處灾伤，任從巡撫等官多方区画。再有奏开前项事例，听從本部並科道官纠劾治罪。”(《通紀》。 )

十五年，令纳粟諸项監生，放回依亲讀書。其未冠者，提學並教官严加考核。以入監日為始，扣滿十年，方准起送赴部复監。(《會典》。 )

嘉靖中，祭酒吕楠疏：“請飭部，将依亲例貢，行各提學官考行業类报。其逃監，及患病，給假三月之外，許臣查治。重則削其名籍。”(《夢余錄》。 )

崇禎五年十二月，詔：纳粟输赀，原於正途之外，以此鼓舞俊秀。乃近年事例频开，吏途纷雜。有赀即可博官，才品俱所勿論。甚而俨然民牧，掊克取偿，贻害滋甚。朕欲慎稽流品，撫恤疒同

。而开纳不除，則源之不清，流何能洁？兹諭尔户工二部，從今為始，将近年新开各项事例，尽行停止。其以前曾經纳过者，照例銓選；此後不得再行援纳。仍将議停款目，奏請裁定。(同上。 )

勋戚入監〓洪武二年四月，令功臣子弟入學。(《本紀》。 )五年三月，令：将官子弟承袭年幼者入國學。(《會典》。 )十年八月癸丑，選武臣子弟讀書國子監。(《本紀》。 )

十四年正月，命公侯子弟入國學。(《會典》。 )

十六年，上慮武臣子弟頑梗，绳愆厅不能扑罰，命李文忠兼領監事。(王圻《通考》。 )

成化十年九月，國子司業耿裕言：勋戚子弟当先束身禮法。乃采辑古諸侯貴戚言行可師者，人授一編。上聞而稱善。乃詔侯、伯及驸馬年少者，皆入國子監讀書習禮。不率者奏聞(《通紀》。 )

弘治六年，副都御史张敷华奏准：公、侯、驸馬、伯子孫年十五以上三十以下者，送監；照依監生，讀書習禮。

嘉靖元年，題准：公、侯、伯未經任事，年三十以下，遵照累朝舊典，送監讀書。命祭酒、司業用心訓誨、試驗。是歲，公侯入監者凡八人。九年，題准：公、侯、伯未任事送監者二十二人。

十五年，祭酒吕楠奏准：“公、侯、伯子孫，舊規每日在監。後偶從宽简，定以二、八日期。近年到監，止二三人，余多不至。乞敕该部转行各爵，戒飭子孫。今後有違例久旷者，許臣等参劾。”

十九年五月丙申，國子司業王祖同請敕兩京公、侯、伯子弟，凡未仕者，悉入成均。俟學有成，方請蔭叙。不率者，本監奏聞区處。上從之。(已上《通考》。 )

土司入監〓洪武二十一年，播州宣慰使揚鏗，並所屬宣撫司官，各遺其子来朝，請入太學。帝敕國子監官，善訓导之。

二十三年，烏撒土知府阿能、烏蒙芒部土官，各遣子弟入監讀書。建昌土官安配遣子僧保等四十二人，入監讀書。

永樂二年，天全招討使高敬让来朝，遣其子虎入國子學。(已上《土司傳》。 )

外蕃入監〓洪武五年，高丽國王請遣子入太學。(《朝鮮傳》。 )

二十五年，琉球、中山貢使，以其王從子及寨官子偕来，請肄業國學。從之。其冬，山南王亦遣從子及寨官子入國學。(《琉球傳》。 )

成化十八年四月，琉球國中山王尚真奏，乞以陪臣子蔡宾等五人，於南監讀書。許之。(《昭代典則》。 )

○府州縣學

洪武二年十月，詔天下府、州、縣立學。諭中書省臣曰：“學校之設，名存實亡。兵变以来，人習战争。朕惟治國以教化為先，教化以學校為本。京師虽有太學，而天下學校未興。宜令郡縣皆立學。”於是設學官，令生員專治一經，以禮、樂、射、御、書、數，設科分教。(《昭代典則》。 )

初，太祖改婺州為宁越府，以王宗顯知府事。宗顯故儒者，博涉經史。开郡學，聘叶儀、宋濂為五經師，戴良為學正，吳沈、徐源為訓导。自兵興，學校久廢，至是始聞弦誦之聲。(《王宗顯傳》。 )

十三年八月，命在京，府學生員六十人；在外，府學四十人，州學三十，縣學二十人；日給廪膳。免其差徭二丁。(王圻《通考》。 )

十五年，頒禁例十二条於天下學校。鐫勒“卧碑”，置明倫堂之左。其不遵者，以違制論。(《會典》。 )

十七年十一月庚午，命辽东立學校。上諭禮部曰：“或言：‘边境不必建學。’夫聖人之教，犹天也。天有风雨霜露，無所不施。聖人之教，亦無往不行。昔箕子居朝鮮，施八条之約，故男遵禮義，女尚贞信。管宁居辽东，講詩書，陳俎豆，饰威儀，明禮让，而民化其德。曾謂边境之民不可以教乎？况武臣子弟久居边境，鮮聞禮教，恐漸移其性。今使之誦詩書，習禮義，非但造就其才，他日亦可资用。”(《昭代典則》。 )

二十年，令增廣生員，不拘數。(王圻《通考》。 )

二十六年，定學官考课法，專以科舉為殿、最。九年任滿，核其中式舉人，府九人，州六人，縣三人者，為最。舉人少者為平等。至少、全無者為殿。(《選舉志》。 )

永樂二年，禮部奏：北方歲貢生員，入學十年，考不中式者，例当充吏。帝曰：“責人之功，当量其力。論人之罪，当明其情。北方近三四年，兵戈扰攘。諸生舍俎豆而事軍旅，飞刍挽粟之劳，奔走流离之苦，奚暇為學？今考不中式者，可发回原學肄業，以俟再試。不中，如例處之。”(《大訓記》。 )

正統十二年三月，凤阳知府揚瓒言：“民間子弟可造者多，請增廣生員，毋限額。”禮部采瓒言，考取附學。天下學校之有附學生，由瓒議始。(《揚瓒傳》。 )

天順六年，令廪膳有缺，於增廣内選补。

嘉靖二年，令增順天府學廪膳生員二十名。三年，令增应天府學廪膳增廣生員，順天府學增廣生員，各二十名。

十一年，奏准：承天府學廪膳增廣六十名。(已上王圻《通考》。 )

○宗學

萬历中，定：宗室子十歲以上，俱入宗學。於宗室中，推舉一人為宗正，領其事。尋增宗副二人。子弟入學者，每歲就提學官考試，衣冠一如生員。已，复令一體鄉試，許得中式。其後宗學{宀浸}多，頗有致身兩榜，起家翰林者。(《選舉志》。 )

镇國中尉睦楔為周藩宗正，領宗學。約宗生以三、六、九日，午前講《易》、《詩》、《書》，午後講《春秋》、《禮記》。虽盛寒、暑不輟。(《周王傳》。 )

社學

洪武八年正月，詔天下立社學。(《三編》。 )方克勤知济宁府，立社學數百区。(《克勤傳》。 )十六年，詔民間立社學，有司不得干预。(《會典》。 )

吳良守江阴，暇則延儒生講論經史。新學宫，立社學。(《吳良傳》。 )

二十年，令民間子弟，兼讀御制《大诰》及律令。(《會典》。 )

宣德时，王翱巡按四川，奏州、縣及土司遍設社學。(《王翱傳》。 )

正統元年，令各睡提學官及司、府、州、縣官，严督社學，不許廢馳。其有俊秀向學者，許补儒學生員。(《會典》。 )

成化初，揚继宗為嘉興知府，大興社學。民間子弟八歲不就學者，罰其父兄。(《继宗傳》。 )南安知府张弼毁淫祠百數十区，建為社學。(《张弼傳》。 )

弘治十七年，令各府、州、縣建立社學，選擇明師。民間幼童年十五以下者，送入讀書，講習冠、婚、喪、祭之儀。(《會典》。 )

嘉靖中，徐阶為延平府推官，摄郡事，创鄉、社學。(《徐阶傳》。 )

萬历中，林培為新化知縣。縣僻陋，廣置社學教之。(《馬經纶傳》。 )○武學

洪武二十年
七月，禮部請立武學、开武舉。不許，曰：“是歧文、武為二也。”(《昭代典則》。 )宣德十年，英宗即位，詔天下衛所皆立學。

正統六年，設京衛武學。除教授一員、訓导六員，教習勋衛子弟。以兵部司官提调。七年，設南京武學。(已上《大政記》。 )

自正統以来，天下軍衛子弟多習儒業。其勋戚子孫袭爵者，習禮肄業於國子監。至各衛幼官暨子弟未袭職者，在兩京並建武學，如京府儒學之制。(《會典》。 )

成化元年四月，申定武學規，凡十五則。(《大政記》。 )

三年，令設衛學。四衛以上，軍生八十人；三衛以上，軍生六十人；二衛、一衛，軍生四十人；不及者不拘。有司儒學，軍生二十人。(王圻《通考》。 )

九年，命都司衛所应袭子弟，年十歲以上者，提學官選送武學讀書。無武學者，送衛學或附近儒學。

十三年，敕所司，歲终，考試入學武生。十年以上，學無可取者，黜退送操。(已上《會典》。 )

弘治六年三月，從兵部尚書馬文升言，刊《武經七書》，分散兩京武學及应袭舍人。(《大政記》。 )

嘉靖十五年
四月，改建武學於皇城西隅大興隆寺舊地。(同上。 )

二十一年，題准：直隶金山衛學，添設廪膳二十名；貴州普定等十三衛，各添設廪膳生員二十名。(王圻《通考》。 )

萬历中，兵部言：武庫司專設主事一員，管理武學。(孫承澤《春明夢余錄》。 )御史左光斗請增畿南真、順、廣、大四府武學。(同上。 )

崇禎十年，令天下府、州、縣學皆設武學生員，提官一體考取。(《選舉志》。 )
