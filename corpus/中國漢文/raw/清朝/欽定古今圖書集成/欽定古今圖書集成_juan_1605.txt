宋二

编辑
]

厲昭慶
[
编辑
]

按《圖畫見聞志》：「厲昭慶，建康豐城人。工畫人物，事江南為翰林待詔。後隨李從主至闕下，授圖畫院祇候。」按《聖朝名畫評》：「昭慶工佛像，尢長於觀音。凡畫古今人物，至於衣紋生熟，亦能分別，前輩殆不及。每欲揮筆，必求虛靜之室無塵埃處，覆其四面，止留尺餘，始肯命意。」其專謹如此。人有問者，以陸探微去梯之事
答之，故其筆精色澤，久而如新。

郝處
[
编辑
]

按《圖畫見聞志》：「郝處，江南人，工畫佛道鬼神，兼長寫貌。本一商賈，酷好圖畫，因而家產蕩盡，唯學畫耳。」
王曉
[
编辑
]

按《聖朝名畫評》：「王曉，泗水人，善畫翎毛，酷好郭權輝鷂子，卒至於妙，而精神筋骨，尤近於郭。」
按《宣和畫譜》：「王曉，泗州人。善畫鳴禽、叢棘、俊鷹等。師郭乾暉。雖若未至，而就其擊搏飛揚之狀，至為卑棲群噪者之所警，其亦雄俊已哉！」蓋傳於世者絕少矣。
按《圖繪寶鑑》：「曉師郭乾暉而遊其藩，亦能畫人物，極古拙，嘗於李成《讀碑圖》上見之。」
傅文用
[
编辑
]

按《聖朝名畫評》：「傅文用，京師人，俗以三翁目之。每見禽鳥飛立，必凝神詳視，都忘他好，遂精於畫。其為鶉鵲，能分四時毛羽，頗有黃筌風概，至有誤收者。今畫院寮屬嘗議曰：『傅三翁翎毛渾得生意，較其真者，如​鑑中見之』。」
按《圖畫見聞志》：「文用，京師人，工畫花竹翎毛，有黃氏之風，特精野雉鵪鶉，能辨四時毛彩。」
母咸之
[
编辑

按畫繼母咸之，江南人，工畫《朝雞》，妙絕一時。

按《圖繪寶鑑》：「咸之畫雞，毛色明潤，瞻視清爽，大有生意。」
夏侯延祐
[
编辑

按《圖畫見聞志》：「夏侯延祐，蜀郡人。工畫花竹翎毛。師黃筌，粗得其要。始事孟蜀，為翰林待詔。既歸朝，拜真命為圖畫院藝學，有圖軸傳於世。」
按田錫《延平集》：「延祐，宋初翰林圖畫待詔，為廬州巢縣令。」

[
编辑

按《圖畫見聞志》：「張戡，瓦橋人，工畫蕃馬，居近燕山。得胡人形骨之妙，盡戎衣鞍勒之精。然則人稱高名，馬虧先匠，今時為獨步矣。」
陳皋
[
编辑
]

按《圖繪寶鑑》：「陳皋，漠州人，長於蕃馬，頗盡胡態，張戡之甥也。」
顧大中
[
编辑
]

按《宣和畫譜》：顧大中，江南人也。善畫人物牛馬，兼工
花竹。嘗於南陵巡捕司舫子臥屏上畫杜牧詩：「南陵水面漫悠悠，風緊雲繁欲變秋。正是客心孤迥處，誰家紅袖憑江樓。」殊有思致，見者愛之。而人初不知其
名，未甚嘉重。後為過客宿舫中，因竊去，乃更歎息。然
其他畫在世者不多有，顧閎中亦善畫，疑其族屬也。

湯子昇
[
编辑
]

按《宣和畫譜》：「湯子昇，蜀人也。畫山水人物頗工。志慕高逸，多繪方外事。作《文簫彩鸞圖》，飄飄然仙風道骨，與夫煙雲縹緲之狀，便覺西山爽氣，恍然在目。有《鑄鑑圖》傳於世。至理所寓，妙與造化相參，非徒為丹青而已者。」
劉永
[
编辑
]

按《圖畫見聞志》：「劉永，京師人。工畫山水。始師僧德符畫松石，後遍求諸家山水，採其所長而傚之。及見荊浩之蹟，乃知諸家有所未盡。一日復睹關同畫，俄歎曰：『是乃得名至藝者乎！向所謂登東山而小魯』。遂捐棄餘學，專法關氏。果遂升堂，馳名當代矣。有《瀑泉屏風》《四時山水》《山居詩意》等圖傳於世。」
祁序
[
编辑
]

按《圖畫見聞志》：「祁序，江南人。工畫花竹翎毛，兼長水牛，鬱有高致。」
按《宣和畫譜》：祁序，一作「嶼」，江南人。善工畫花竹禽鳥，
又工畫牛，人或謂有戴嵩遺風。至於畫貓，近世亦罕
有其此貓與牛者，皆人之所常見，每難為工。昔人有
畫𩰚牛者，眾稱其精，獨有一田夫在傍，乃指其瑕，既
而問之，乃曰：「我見𩰚牛多擫尾，今揭其尾，非也。」畫者
惘然，因服其不到。序亦有𩰚牛，甚奇。

孫可元
[
编辑
]

按《宣和畫譜》：「孫可元，不知何許人，好畫吳越間山水，筆力雖不至豪放，而氣韻高古，喜圖高士幽人巖居漁隱之趣。嘗作《春雲出岫》，觀其命意，則知其無心於物，聊游戲筆墨以玩世者，所以非陶潛、綺皓之流，不見諸筆下。」
陸瑾
[
编辑
]

按《宣和畫譜》：「陸瑾，江南人。善畫江山風物，落筆瀟灑，殊無塵埃。作四時圖繪，春則山陰曲水，夏則茂林泉石，秋則風雨溪壑，冬則雪橋野店，鋪張點綴，歷歷可觀。至於捕魚運石，水閣僧舍，布置物像，無不精確，可以追蹤名手，但傳於世不多耳。」
按《圖繪寶鑑》：「陸瑾筆法布置，大抵宗王維，而娬媚過之。」
王凝
[
编辑
]

按《宣和畫譜》：「王凝，不知何許人也。嘗為畫院待詔。工畫花竹翎毛，下筆有法，頗得生意。又工為鸚鵡及獅貓等，非山林草野之所能。不唯責形象之似，亦兼取其富貴態度，自是一格。苟不能焉，終不到也。」
朱羲
[
编辑
]

按《宣和畫譜》：「朱羲，江南人，朱瑩，其族屬也。皆以畫牛得名。作斜陽芳草，牧笛孤吹，村落荒閒之景，而無市朝奔逐之趣。雖望戴嵩為不及，而亦後來名家。」
朱瑩
[
编辑
]

按《宣和畫譜》：「朱瑩，江南人，與朱羲同族，亦善畫牛馬得名，尤工人物。作牧牛圖，極臻其妙。飲水齕草，蓋牛之真性，非筆端深造物理，而徒為形似，則人人得以專門矣。獨瑩與羲，殆若知之者。」
甄慧
[
编辑
]

按《宣和畫譜》：「甄慧，睢陽人。善畫佛像帝釋，脫落世間形相，具天人之威儀，故以此得名於時。亦工畫牛馬，而留意甚精。至於穿絡真性，固已失之矣。而鞭繩之​所制畜，亦有見於警策者也。畫雖末技，而意之所在，故有進於妙者。」
劉夢松
[
编辑
]

按《圖畫見聞志》：「劉夢松，江南人。善畫水墨花鳥，隨宜取象，如施眾形。」
按《宣和畫譜》：「劉夢松，江南人。善以水墨作花鳥，於淺深之間，分顏色輕重之態，互相映發，雖綵繪無以加也，自成一種氣格耳。又作《紆竹圖》，甚精緻。蓋竹本以直為上，修篁高勁，架雪凌霜，始有取焉。今夢松乃作紆曲之竹，不得其所矣。或造物賦形，不與之完，或有所拘閡而不遂其性，又或以所托非其地而致此，皆」物之不幸者，將以著戒焉。

楊斐
〈宣和畫譜作棐〉
[
编辑
]

按《聖朝名畫評》：「楊斐，京師人，性不拘，有氣概。多游江浙間，後居畫院，攻畫佛像，宗吳生筆。於泗州普光王寺畫鬼神於方丈，其容色威勢，有足觀者。」
按《宣和畫譜》：「楊棐，京師人也。客游江浙，後居淮楚。善畫釋，典學吳生，能作大像。嘗於泗濱普照佛剎為二神，率踰三丈，質幹偉然，凜凜可畏。又作鍾馗亦工。」按
鍾馗近時畫者雖多，考其初，或云明皇病瘧，夢鍾馗
舞於前，以遣瘧癘。其後傳寫形似於世，世始有鍾馗。
然臨時更革，態度大同而小異，唯丹青家緣飾之如
何耳。又說嘗得六朝古碣於墟墓間，上有「鍾馗」字，似
非始於開元也。卒無考據。

按《圖繪寶鑑》：「楊斐善畫道釋人物，學吳生，尢於觀音，得名天下。」

按《圖繪寶鑑》：「孫知微用筆放逸，不蹈襲前人筆墨畦畛，時輩稱服。描法甚老，黃筌不能過也。」
按《聞見後錄》：蜀人重孫知微畫筆，東坡獨曰：「工匠手耳。」
按《宣和畫譜》：「知微字太古，眉陽人也。世本田家，天機穎悟，善畫，初非學而能。清淨寡慾，飄飄然真神仙中人。不茹婦人所饌食，有密以驗之者，皆不可逃所知。喜畫道釋，用筆放逸，不蹈襲前人筆墨畦畛。嘗於成都壽寧院壁圖九曜落墨已，乃令童仁益輩設色侍從，中有持水晶缾者，因增以蓮花。知微既見，謂缾所」以鎮天下之水，吾得之《道經》，今增以花，失之遠矣。故
知知微之妙，豈俗畫所能到也。蜀人尤加禮之，得畫
則珍藏十襲。知微多客寓寺觀，精黃老瞿曇之學，故
畫道釋益工，而蜀中寺觀尤多筆迹焉。
