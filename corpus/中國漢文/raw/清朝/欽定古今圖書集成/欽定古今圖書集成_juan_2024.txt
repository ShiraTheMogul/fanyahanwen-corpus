臨河歌　　　　　　　　　　周孔子
[
编辑
]

孔子適晉，臨河不濟，歎而作《歌》曰：

秋水衍兮風揚波，舟楫顛倒更相加。歸來歸來胡為
斯，

渡黃河　　　　　　　　　　梁范雲
[
编辑
]

河流迅且濁，湯湯不可淩。檜楫難為榜，松舟纔自勝。
空庭偃舊木，荒疇餘故塍。不睹行人跡，但見狐兔興。
寄言河上老，此水何當澄。

公無渡河　　　　　　　　　劉孝威
[
编辑
]

《請公無渡河》，河廣風威厲。檣偃落金烏，舟傾沒犀枻。
紺蓋空嚴祠，白馬徒生祭。銜石傷寡心，崩城掩孀袂。
劍飛猶共水，魂沈理俱逝。君為川后臣，妾作江妃娣。

濟黃河應教　　　　　　　　　謝微
[
编辑
]

積陰晦平陸，凄風結暮序。朝辭金谷戍，夕逗黃河渚。
赤兔徒聯翩，青鳧詎容與。淚甚聲難發，悲多袖未舉。
虛薄謬君恩，方嗟別宛許。

公無渡河　　　　　　　　陳張正見
[
编辑
]

金堤分錦纜，白馬渡蓮舟。風嚴歌響絕，浪湧榜人愁。
櫂折桃花水，颿橫竹箭流。何言沈璧處，千載偶陽侯。

濟黃河　　　　　　　　　　　江總
[
编辑
]

蔥山淪外域，鹽澤隱遐方。兩源分際遠，九道派流長。
未殫所聞見，無待驗詞章。留連嗟《太史》，惆悵踐黎陽。
導波縈地節，疏氣耿天潢。憫周沈用寶，嘉晉肇為梁。

奉和濟黃河應教　　　　　北齊蕭慤
[
编辑
]

大蕃連帝室，驂駕奉皇猷。未明驅羽騎，淩晨方畫舟。
津城渡維錦，岸柳夾緹油。鐘聲颺別島，旗影照滄流。
早光生蒯劍，朝風起節樓。滔滔細波動，裔裔輕舷浮。
迴橈避近磧，放舳下前洲。全疑上天漢，不異謁蓬丘。
望知雲氣合，聽識水聲秋。從君何等樂，喜共神仙遊。

渡北河　　　　　　　　　隋薛道衡
[
编辑
]

連旌映漵浦，疊鼓沸沙洲。桃花長新浪，竹箭下奔流。
塞雲臨遠艦，胡風入陣樓。劍拔蛟將出，驂驚黿欲浮。
鴈書終立效，燕相果封侯。勿恨關河遠，且寬邊地愁。

黃河　　　　　　　　　　　唐太宗
[
编辑
]

河源發崑崙，連乾復浸坤。波渾經鴈塞，聲振自龍門。
岸裂新衝勢，灘餘舊落痕。橫溝通海上，遠色盡山根。
勇逗山峰折，雄標四瀆尊。灣中秋景樹，闊外夕陽邨。
沫亂知魚呴，槎來見鳥蹲。飛沙當白日，凝露接黃昏。
潤可資農畝，清能表帝恩。雨吟堪極目，風渡想驚魂。
顯瑞龜曾出，陰靈伯固存。盤渦寒漸急，淺瀨暑微溫。
『九曲終柔勝，常流可暗吞。人間無博望，誰復到窮源』。

早發成皋望河　　　　　　　劉孝孫
[
编辑
]

清晨發巖邑，驅馬走轘轅。迴瞰黃河上，惝怳屢飛魂
​
鴻流導積石，驚浪下龍門。仙槎不辨處，沈璧想猶存。

遠近洲渚出，颯沓鳧鴈喧。懷古空延佇，歎逝將何言。

詠河　　　　　　　　　　　　李嶠
[
编辑
]

源出崑崙中，長波接漢空。桃花來馬頰，竹箭入龍宮。
德水千年變，榮光五色通。若披蘭葉險，漢使敢云功。

晚渡黃河　　　　　　　　　駱賓王
[
编辑
]

千里尋歸路，一葦亂平源。通波連馬頰，迸水急龍門。
照日榮光淨，驚風瑞浪翻。棹唱臨風斷，樵謳入聽喧。
岸迥秋霞落，潭深夕霧繁。誰堪逝川上，日暮不歸魂。

渡河　　　　　　　　　　　　王維
[
编辑
]

汎舟大河裏，積水窮天涯。天波物開折，郡邑千萬家。
行復見城市，宛然有桑麻。迴瞻舊鄉國，森漫連雲霞。

夜到洛口入黃河　　　　　　儲光羲
[
编辑
]

河洲多青草，朝暮增客愁。客愁惜朝暮，枉渚暫停舟。
中宵大川靜，解纜逐歸流。浦漵既清曠，沿洄非阻修。
登艫望落月，擊楫悲新秋。倘遇乘槎客，永言星漢遊。

公無渡河　　　　　　　　　　李白
[
编辑
]

黃河西來決崑崙，咆哮萬里觸龍門。波滔天，堯咨嗟。
大禹理百川，兒啼不窺家。殺湍堙洪水，九州始桑麻。
其害乃去，茫然風沙。被髮之叟狂而癡，清晨臨流欲
奚為。旁人不惜妻止之，公無渡河苦。渡之，虎可搏，河
難馮，公果溺死流海湄。海湄有長鯨，白齒若雪山。公
乎公乎掛𦊰于其間，箜篌所悲竟不還。

自鞏洛舟行入黃河即事寄府縣僚友
[
编辑
]

韋應物

「綠水蒼山路向東，東南山豁大河通。寒樹依微遠天外，夕陽明滅亂流中。孤村幾歲臨伊岸，一鴈初晴下朔風。」為報洛橋遊宦侶，扁舟不繫與心同。

河出滎光　　　　　　　　　張良器
[
编辑
]

引派崑山峻，朝宗海路長。千齡逢聖主，五色瑞榮光。
隱映浮中國，晶明助太陽。坤維連浩漫，天漢接微茫。
丹闕清氛裏，函關紫氣旁。位尊常守伯，道泰每呈祥。
習《坎》靈逾久，居卑德有常。龍門如可涉，忠信是舟梁。

河出榮光　　　　　　　　　無名氏
[
编辑
]

符命自陶唐，吾君應會昌。千年清德水，九折滿滎光。
極岸浮佳氣，微波照夕陽。澄輝明貝闕，散彩入龍堂。
近帶關雲紫，遙連日道黃。馮夷矜海若，漢武貴宣房。
漸浸孤槎影，仍呈一葦航。撫躬悲未濟，作頌喜時康。

自淇涉黃河途中作三首　　　　高適
[
编辑
]

南登滑臺上，卻望河淇間。竹樹夾流水，孤村對遠山。
念茲川路闊，羨爾沙鷗閒。長想別離處，猶無音信還。

其二

「東入黃河水，茫茫汎紆直。」北望太行山，峨峨半天色。
山河相映帶，深淺未可測。自昔有賢才，相逢不相識。

其三

茲川方悠悠，雲沙無前後。古塔對河堧，長林出淇口。
獨行非吾意，東向日已久。憂來誰得知，且酌樽中酒。

黃河曲　　　　　　　　　　　前人
[
编辑
]

皤皤河濱叟，相遇似有恥。輟榜聊問之，答言盡終始。
一生雖貧賤，九十年未死。且喜對兒孫，彌慚遠城市。
結廬黃河曲，垂釣長河裏。「溟漫望雲海，蕭條聽風水。所思強飲食，永願在鄉里。萬事吾不知，其心只如此。」
得臨邑舍弟書至苦雨黃河泛濫隄防之患簿

「領所憂」 ，因寄此詩，用寬其意　　　。杜甫

二儀積風雨，百谷漏波濤。聞道洪河坼，遙連滄海高。
職司憂悄悄，郡國訴嗷嗷。舍弟卑棲邑，防川領簿曹。
尺書前日至，版築不時操。難假黿鼉力，空瞻烏鵲毛。
燕南吹畎畝，濟上沒蓬蒿。螺蚌滿近郭，蛟螭乘九皋。
徐關深水府，碣石小秋毫。白屋留孤樹，青天失萬艘。
吾衰同泛梗，利涉想蟠桃。倚賴天涯釣，猶能掣巨鼇。

黃河二首　　　　　　　　　　前人
[
编辑
]

黃河北岸海西軍，椎鼓鳴鐘天下聞。鐵馬長鳴不知
數，胡人高鼻動成群。

其二

黃河西岸是吾蜀，欲須供給家無粟。願驅眾庶戴君
王，混一車書棄金玉。

送襄陽盧判官奏開河事　　　　錢起
[
编辑
]

千里趨魏闕，一言簡聖聰。河流引關外，國用贍秦中。
有詔許其策，隨山興此功。連雲積石阻，計日安波通。
飛棹轉年糓，利人勝歲豐。言歸漢陽路，拜首蓬萊宮。
「紫殿賜衣出，青門酣酌同。晚陽過微雨，秋水見新鴻。坐惜去車遠，愁看離館空。因思郢川守，南楚滿清風。」
同薛侍御登黎陽城樓眺黃河　楊巨源
[
编辑
]

「倚檻恣流目，高城臨大川。」九回紆白浪，一半在青天。
氣肅晴空外，光翻曉日邊。開襟值佳景，懷抱更悠然。

泛黃河　　　　　　　　　　　孟郊
[
编辑
]

誰開黃河源，流出混沌河。急雨飛作風，驚龍噴為波。
湘瑟颼颼絃，《越賓》嗚咽歌。有恨不可洗，虛此來經過。

與永樂諸公夜泛黃河作　　　　閻防
[
编辑
]

煙深載酒入，但覺暮川虛。映水見山火，鳴榔聞夜漁。
愛茲山水趣，忽與世人疏。無暇燃官燭，中流有望舒
​

黃河　　　　　　　　　　　　羅隱
[
编辑
]

莫把阿膠向此傾，此中天意固難明。解通銀漢應須
曲，纔出崑崙便不清。高祖誓功衣帶小，仙人占斗客
槎輕。三千年後知誰在，何必勞君報太平。

河流　　　　　　　　　　　　徐夤
[
编辑
]

洪流盤砥柱，淮濟不同波。莫訝清時少，都緣曲處多。
遠能通玉塞，高復接銀河。大禹成門嶮，為龍始得過。

黃河　　　　　　　　　　宋歐陽修
[
编辑
]

河水激箭險，誰言航葦遊。堅冰馳馬渡，伏浪捲沙流。
樹落新摧岸，湍驚忽改洲。鑿龍時退鯉，漲潦不分牛。
萬里通槎漢，千帆下漕舟。怨歌今罷築，故道失難求。
灘急風愈響，川寒霧不收。詎能窮禹跡，空欲問張侯。

黃河　　　　　　　　　　　　邵雍
[
编辑
]

誰言為利多于害，我謂長渾未始清。西至崑崙東到
海，其間多少不平聲。

黃河　　　　　　　　　　　　蘇軾
[
编辑

===稠桑道中望黃河　　　　　　齊之鸞===
​
「桃林蟠土山，谷入昧所出。地底無傍風，天際有中日。仰視畊穫人，轉折忽相失。仄登蟻緣枝，幽盤蠹閉帙。僕夫虞殞傷，反汗更股栗。伊予慕昔賢，馭吏屢遭叱。徑盡躡河壖，黃流過箭疾。踰關勢彌雄，四齧奔馬逸。不知真宰意，何貴砥柱窒。汜濫民其魚，豈止桑田溢。三門中古開，神禹功誰匹。至今沮洳場，盡作秔稻窟。」吾生髮半蒼，世路十不一。及茲瞻華嵩，眼豁心神翐。
向來險遠虞，茲晨憂已釋。

之間孝所鍾，呱呱之聲禹弗子。萬水之患河為雄，鑿
開積石流河通。龍門之下功未竟，安得河聲流向東。
我瞻廟貌駿奔走，黍稷馨香酬二卣。山空玉佩珊瑚
鳴，聖德神功真不朽。九山既旅九川空，四隩既宅四
海同。六府三事允已治，嗚呼，萬世永賴誰之功。
