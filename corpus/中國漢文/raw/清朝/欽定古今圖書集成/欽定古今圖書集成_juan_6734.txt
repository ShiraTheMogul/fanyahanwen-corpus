元會　　　　　　　　　　魏陳思王
[
编辑
]

《漢正會禮》，「正旦，公侯以下升殿稱萬歲，作樂燕饗。」初歲元祚，吉日惟良。乃為嘉會，宴此高堂。衣裳鮮潔，
黼黻元黃。珍膳雜遝，充溢圓方。俯視文軒，仰瞻華梁。
願保茲善，千載為常。歡笑盡娛，樂哉未央。皇室榮貴，
壽考無疆。

答程曉　　　　　　　　　　晉傅元
[
编辑
]

奕奕兩儀，昭昭太陽。四氣代升，三朝受祥。濟濟群后，
峨峨聖皇。元服肇御，配天垂光。伊周作弼，王室惟康。
顒顒兆民，蠢蠢戎蠻。率土充庭，萬國奉蕃。皇澤雲行，
神化風宣。六合咸熙，遐邇同歡。赫赫明明，天人合和。
下罔遺滯，焦朽斯華。矧我良朋，如玉之嘉。穆穆雝雝，
興頌作歌。

又

羲和運玉衡，《招搖》賦朔旬。嘉慶形三朝，美德揚初春。

聖主加元服，萬國望威神。伊周敷元化，並世霑天人
​
洪崖歌山岫，許由嗟水濱。

失題　　　　　　　　　　　　前人
[
编辑
]

元正始朝享，萬國執珪璋。枝燈若火樹，庭燎繼天光。

正旦大會行禮歌四首　　　　　前人
[
编辑
]

天鍳有晉。世祚聖皇。時齊七政。朝此萬方。
鐘鼓斯震。九賓備禮。正會在朝。穆穆濟濟。

煌煌三辰，實麗於天。君后是象，威儀孔虔。

卒禮無愆，莫非「邁德。」儀刑聖皇，萬邦惟則。

上壽酒歌　　　　　　　　　　前人
[
编辑
]

「於赫明明，聖德龍興。」三朝獻酒，萬壽是膺。敷佑四方，
如日之升。自天降祚，元吉有徵。

正旦大會行禮歌　　　　　　　荀勖
[
编辑
]

「於皇元首，群生資始。履端大享，敬御繁祉。肆覲群后，爰及卿士。欽順則元」，允也天子。

王公上壽酒歌　　　　　　　　前人
[
编辑
]

踐元辰，延顯融。獻羽觴，祈令終。我皇壽而隆，我皇茂
而嵩。本支奮百世，休祚鍾聖躬。

王公上壽酒　　　　　　　　　張華
[
编辑
]

稱元慶，奉聖觴。「后皇延遐祚，安樂撫萬方。」食舉東西廁樂詩六首　　　　　前人
[
编辑
]

明明在上，丕顯厥繇。翼翼三壽，蕃后惟休。群生漸德，
六合承流。三正元辰，朝慶鱗萃。華夏奉職貢，八荒覲
殊類。黻冕充廣庭，鳴玉盈朝位。

濟濟朝位，言觀其光。儀序既以時，禮文煥以彰。思皇
享多祜，嘉樂永無央。

九賓在庭。臚讚既通。升瑞奠贄。乃侯乃公。穆穆天尊。
隆禮動容。履端承元吉。介福御萬邦。

泰始開元，龍升在位。四隩同風，燮寧殊類。五韙來備，
嘉生以遂。凝庶績，臻大康。申繁祉，裔無疆。本支百世，
繼緒不忘。繼緒不忘，休有烈光。永言配命，惟晉之祥。
朝元日，賓王庭。承宸極，當盛明。衍和樂，竭祗誠。仰嘉
惠，懷德馨。游淳風，泳淑清。協億兆，同歡榮。建皇極，統
天位。運陰陽，御六氣。殷群生，成性類。王道浹，治功成，
人倫序，俗化清。虔明祀，祗三靈。崇禮樂，式儀刑。
慶元吉，宴三朝。播金石，詠泠簫。奏《九夏》，舞《雲韶》。邁德
音，流英聲。八紘一，六合寧。六合寧，承聖明。王澤洽，道
登隆。綏函夏。總華戎。齊德教。混殊風。混殊風，康萬國。
崇夷簡。尚敦德。弘王度，遠遐則。

泰清。百辟朝三朝，彧彧明儀刑。濟濟鏘鏘，玉振金聲。

同平南弟元日思歸　　　　　陳後主
[
编辑
]

至德掩羲黃，成功邁禹湯。儀刑先四海，來庭盛萬方。
鳴玉觀升降，擊石乃鏗鏘。三春氣色早，九疑煙霧長。
浮雲斷更續，輕花落復香。北宮瞻遠岫，南服阻遙江。
爾言想伊洛，我思屬瀟湘。

奉和元日　　　　　　　　北齊蕭慤
[
编辑
]

帝宮通夕燎，天門拂曙開。瑞雲生寶鼎，榮光上露臺。
華山不凋葉，宜城萬壽杯。遙見飛鳧下，懸知葉縣來。

正旦蒙趙王賫酒　　　　　北周庾信
[
编辑
]

正旦辟惡酒，新年長命杯。柏葉隨銘至，椒花逐頌來。
流星向碗落，浮蟻對春開。成都已噀火，蜀使何時迴。

奉和從叔光祿愔元日早朝　　隋李孝貞
[
编辑
]

銅渾變春節，玉律動年灰。曖曖城霞旦，隱隱禁門開。
眾靈輳仙府，百神朝帝臺。葉令雙鳧至，梁王駟馬來。
戈鋋暎林闕，歌管沸塵埃。保章望瑞氣，《尚書》滅火災。
冠冕多秀士，簪裾饒上才。誰憐張仲蔚，日暮返蒿萊。

元旦　　　　　　　　　　　唐太宗
[
编辑
]

高軒曖春色，邃閣媚朝光。彤廷飛綵斾，翠幌曜明璫。
恭己臨四極，垂衣馭八荒。霜戟列丹陛，絲竹韻長廊。
穆矣薰風茂，康哉帝道昌。繼文遵後軌，循古鑒前王。
草秀故春色，梅艷昔年妝。巨川思欲濟，終以寄舟航。

正旦臨朝　　　　　　　　　　同前
[
编辑
]

條風開獻節，灰律動初陽。百蠻奉遐賮，萬國朝未央。
雖無舜禹迹，幸欣天地康。車軌同八表，書文混四方。
赫奕儼冠蓋，紛綸盛服章。羽旄飛馳道，鐘鼓震巖廊。
組練輝霞色，霜戟曜朝光。晨宵懷至理，終愧撫遐荒。

元日退朝觀軍仗歸營　　　　　德宗
[
编辑
]

獻歲視元朔，萬方咸在庭。端旒揖群后，回輦閱師貞。
綵仗宿華殿，退朝歸禁營。分行左右出，轉斾風雲生。
歷歷趨複道，容容映層城。勇餘矜捷技，令肅無喧聲。
眷此戎旅節，載嘉良士誠。順時傾宴賞，亦以助《文經》。

===奉和正日臨朝　　　　　　　顏師古===
​
七政璿衡始，三元寶曆新。負扆延百辟，垂旒御九賓。
肅肅皆鵷鷺，濟濟盛簪紳。天涯致重譯，西域獻奇珍。

元旦部選句
[
编辑
]

漢馮衍《顯志賦》「開歲發春兮，百卉含英。」〈又〉
《銘》「元正上日，百福孔靈。」班固《東都賦》：「春王三朝，會同漢京。是日也，天子受四海之圖籍，膺萬國之貢珍，內撫諸夏，外綏百蠻。」張衡《東京賦》：「孟春元日，群后旁戾。百僚師師，于斯胥洎。蕃國奉聘，要荒來贄。」魏程曉《贈傅休奕詩》：「三光飛景，玉衡代邁。龍集甲子，四時成歲。權輿授代，除陳蕩穢。元服初嘉，萬福來會。赫赫應門，嚴嚴朱闕。群后揚揚，庭燎晳晳。」晉正會，大享歌「慶隨百禮合，壽與三朝并。」荀勖《食舉樂東西廂歌》「封建厥福，駿發其祥。三朝習吉，終然允臧。」庾闡《揚都賦》「歲惟元辰，陰陽代紀。履端歸餘，三朝告始。萬國鳴鑾，有客戾止。」宋謝靈運詩，「開春獻初歲，白日出悠悠。」鮑照《春日行》：「獻歲發，吾將行，春山茂，春日明。」梁《三朝雅樂歌》。「四氣新元旦，萬壽初今朝。」《北齊元會大享歌》：「夏正肇旦，周物充庭。」《隋煬帝獻歲讌宮臣詩》：「三元建上京，六佾宴麗城。朱庭容衛肅，青天春氣明。」《唐太宗》詩：「送寒餘雪盡，迎歲早梅新。」《丁仙芝》詩：「開正獻歲酒，千里間庭闈。」《韋述詩》：「初歲開韶月，田家喜載陽。」李華《含元殿賦》「獻歲元辰，東風發春。懸法象魏，與人維新。」《李嘉祐》詩：「入京當獻歲，封事更聞天。」《張籍詩》：「長思歲旦沙堤上，得從鳴珂傍火城。」白居易《元日對酒》詩：「三杯藍尾酒，一楪膠牙餳。」〈又〉
