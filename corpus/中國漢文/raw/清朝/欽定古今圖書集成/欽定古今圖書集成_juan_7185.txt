凌立
[
编辑
]

按《杭州府志》：「凌立，錢塘人。少孤，事母以孝聞。嘉靖癸丑進士，官至建昌太守，多惠政，為僚黨所忌，罷歸。立奉母色養備至，老而彌篤。母沒，一慟骨立，數月竟卒。」
周浩
[
编辑
]

按《杭州府志》：「周浩，字養正，仁和人。嘉靖四十一年進​士，知衡州府，一切苞苴請托不行。講道石鼓書院，倡明正學，善政洋溢。衡人德之，立生祠與白石蔡公配享。累遷按察使。服官二十年，清節如一日。時江陵輔幼主，書百官名於御屏，大計方岳，召賢能官賜宴以寵其行，浩兩與焉。浩奉母孝，母聞民罹法，蹙額不怡」，
浩輒長跪候母，色喜乃已。故能推孝治民，罔不盡善。
曾孫逢源篤行誼，能紹其學。

黃驥
[
编辑
]

按《紹興府志》：「黃驥，字德良，餘姚人。副使肅之子。七歲喪母，畫像事之，感時悲慟，見者惻然。奉繼母亦以孝聞。父病，徬徨嘗糞。及其沒也，造墳不資人力，躬自負土。丙舍成雙，鵲巢其梁上，有自來野犬，為之巡警。一夕，虎銜豕置於庭而去。嘉靖十七年，有司以聞，表為孝子。驥初學於王守仁，晚而語人曰：『陽明先生始所』」學亦未粹，因從遊者眾，互相劘切，所以成就。蓋教學
相長如是也。按其言行，惜載籍不盡傳。

陳一貞
[
编辑
]

按《溫州府志》：「陳一貞，字德靖，永嘉人。母麻氏病篤，刲股以進。兄沒，撫其子女如己出。領嘉靖戊午鄉薦，仕上津令，終滁州知州。」
馮履祥
[
编辑
]

按《寧波府志》：「馮履祥，字君德，慈谿人。生七八歲，即警悟好讀書。嘉靖壬子，補邑庠弟子員。歲丙辰，四月十一日，倭賊犯縣，履祥隨父出奔。賊逼斷父左手，且裂其背，履祥以身蔽之，泣訴曰：『此吾父也，願無加害，寧殺我』。賊竟刃之死。其妻袁氏遁於靈山，時孕已彌月。迨十七日，夜夢一紅面神告之曰：『爾夫為父死，不可使無後，吾當與爾一子，產時無恐』。」次日歸，果生一子。
又值倭寇將入，賊馬皆止，策之亦不前，賊不越境而
回。一方稍輯，皆靈山驃騎大將軍神威之庇，與得兒
夢符，蓋履祥孝感所致云。

聞宗時
[
编辑
]

按《寧波府志》：「聞宗時，鄞人。教授聞理子。宗時，性至孝，幼喪母，奉繼母陳，承順篤至。嘉靖丙辰，倭賊突至，舉家竄避。宗時扶父出而遇賊脅取金錢不得，拔刀欲殺父。宗時以身蔽，泣求自代，遂飲刃而死，尸諸田間，父遂得釋。時家奴李三抱宗時幼子，不忍舍去，亦被賊刀截左耳，併刲其面，屢死屢甦，人共傷之。」
李道宗
[
编辑
]

按《寧波府志》：「李道宗，字文奎，年七歲，父世顯以吏員入京，坐事戍甘肅，踰二十載。道宗既長，補弟子員。念其父，日夜西望，號泣，告大父及母，欲往尋之。時值嘉靖辛酉鄉試，弗顧也。萬里徒步，歷三年，始抵玉關。夜宿武安祠，夢神告曰：『不出二日，當於涼州界見爾父矣』。時世顯為邊帥記室，於塗中聞道宗語，問曰：『汝南人乎』？」對曰：「然。」遂相㩦入酒罏，貰酒敘鄉曲，言所從來，
知為父子，抱頭相向泣。甘肅巡撫中丞知之，試以文
題，為《竊負》而逃，遵海濱而處。道宗文不屬，草呈焉。中
丞曰：「一字一淚，佳士也。」欲以其父戍籍留應甲子秋
試。世顯亦欲留，道宗長跪曰：「大父與吾母望父者，二十餘年矣。兒行時，囑謂見父宜早歸。今既遇而淹留，非初意也。」中丞知不可，強釋世顯戍籍，捐俸助之南
還。

姜國望
[
编辑
]

按《寧波府志》：「姜國望，字道卿，邑庠生。為人端敏退讓，篤於孝友。嘉靖丙辰，島寇突入，居民遯逃。母陸氏，初喪在殯，國望抱棺痛哭，誓不相離。賊至，柩前將舉火，忽聞門外哨聲，輒投火去，如是者三。抵暮亟出，糾眾遷柩，得免於難。觀風使者至，鄉閭欲舉節孝，國望力辭之，且以死自誓而止。」
鄭十三孝子
[
编辑
]

按《寧波府志》：「鄭十三孝子，翁洲東山里人也。鄭氏家東山，稱世族。嘉靖間，倭犯其境，族人皆奔走避難。孝子請其父偕去，父猶顧慮不急行。已而孝子偕其父西馳，為倭所及，遂刃其父。孝子抱父尸大哭，并為所執。憐其年少，欲生之，驅之偕行。孝子伏地大慟，不肯去，倭怒，并刃之，棄尸道上。越數日，族人歸而收其尸」，
孝子身首異處，而右手猶抱其父，牢不可解。翁洲人
至今稱之曰《鄭十三孝子》云。

丘統
[
编辑
]

按《寧波府志》：「丘統，字繼充，甫數歲，生母黃氏為嫡母所逐，轉適他所。人或詔以故，輒欷歔不禁。年十五，父卒，事嫡母甚篤。母病劇，嫡兄經、弟綸俱客京師，統獨侍湯藥惟謹，衣不解帶。母感其孝，與訣曰：『我死，汝毋忘若母』。統泣承之。時黃氏他適已二十年，杳不可跡。一夕，夢神告之曰：『君之母蓋在台州』，因之台遍覓不」可得。已而知在僊居，復之僊居，覓之又不可得。轉而
之縉雲蒼嶺下，又之玉碧川，果遇焉。蓋其母初適包
氏，再適李、吳二氏，至是為陳翁婦矣。遂迎母及翁歸，
為築別室奉之。翁死，請母入己室，率妻子晨夕饋食，
怡怡如也。性篤友愛，其兄與弟嘗粟入仕籍。至析產
​
時，眾議量算其貲統曰：「苟若是，何言乎一體者哉？」卒
不許。嘉靖辛卯，邑令趙民順疏二事於朝，命旌為孝
子，表宅里焉。

劉晉
[
编辑

按《寧波府志》：「劉晉，昌國人。嘉靖三十二年，倭賊入城，其祖老疾不能行，家人各挈妻子走，惟晉負其祖而逃。賊將及，祖曰：『我老，甘死，汝宜速去』。晉不忍，遂俱被殺。」
沈良十
[
编辑
]

按《寧波府志》：「沈良十，嘉靖乙卯四月間，倭賊至鳴鶴鎮，時年已七十餘，尚有九十餘母。良十負母至五里外，力竭不能行，息山舍中。賊追至，乃跪拜請死，願貸其母。賊見母子俱皤髮頹老，舍之而去。賊繼至者又舍之。良十憐母饑渴，方圖飲食。賊又至，或舉刃欲斫其母，良十以身覆蔽，號哭被殺，而母竟得全。」
向敘
[
编辑
]

按《寧波府志》：「向敘，字叔禮，慈谿人，獻令七世孫。幼慧而有高志，舉動擬步古人。年十六，入府庠，文藻驟發，而操履端謹，人益器之。嘉靖丙辰，海寇突入境，敘掖母而逃。遇寇東溪，踣敘仆地，直前砍其母，敘急起，抱母頸，疾呼曰：『寧殺我，寧殺我』！賊舍其母，殺敘而去。巡按御史上其事，詔旌其門。」
張世榜
[
编辑
]

按《台州府志》：「張世榜，字廷曉，縣學生。嘉靖戊午，倭寇登陸，世榜扶父避匿，道遇賊，欲殺其父。世榜哀懇，祈以身代，賊不從。世榜脫巾擲地，戟手大罵，奮前欲擊，賊遂遇害。袁令應祺上其事於按臺。」
陸鰲
[
编辑
]

按《嘉興府志》：「『陸鰲，字子任。九歲頓悟理一分殊』之旨，稱小象山。痛父早世，思肖像奉朝夕，忽見父狀，繪之不爽毫髮。母病，剪左股肉，爇香籲天，病隨愈。嘉靖中，領鄉薦，倅臨江，單騎諭降。江盜，釐去部儲使者例金，使者怒，排鰲闥，囊橐蕭然，歎服而去。秩滿，佐南康，民德之。以子萬垓貴，贈都御史。」
竇卿
[
编辑
]

按《嘉興府志》：「竇卿，素以孝聞。嘉靖間，部使者下郡邑旌其門。父嘗病足癰，卿浣拭舐吮。母病，走叢祠密禱，乞減己齡益之，父母並壽九十。」
許梧
[
编辑
]

按《嘉興府志》：「許梧，字來鳳，事父母孝，父病疽，籲天以身代，竟獲甦。苦志博學，不第，以鄉貢司訓通州。第四子爚，嘉靖中進士，以其直亮足繼其志，遂疏病乞歸，杜門吟詠，歲賓鄉飲。」
王葑
[
编辑
]

按《處州府志》：「王葑，字德敷，麗水人。苦心力學，天性孝友。尢清操介立，秋毫不苟。嘉靖戊午、己未連捷，初放榜便以忠廉自矢。觀政刑部，接丁內外艱，廬于墓側者五年，片字不入公門，跬步不入私室，致有馴鹿之瑞，人皆以孝廉稱之。竟以哀毀搆疾而終。咸惜其不究于用。後入祀鄉賢。」
楊山
[
编辑
]

按《餘姚縣志》：「楊山，字伯鎮，幼讀書，至入孝出弟。問其父若何而可謂孝弟。父釋其義，曰：『吾知所從事矣』」，便
言若成人。已娶妻谷氏，家貧，必為父母營辦殽味。山
出外歸家，常使兩親檢括囊中，三分之致二弟歲宴
享，谷氏亦必以其簪瑱先之。二娣嘉靖丙午舉於鄉，
授泰安知州，其友愛終身如故。

孫堪
[
编辑
]

按《餘姚縣志》：「孫堪，字志健，燧長子。燧死難，堪奔喪，慟絕復甦，致耳瞶，廬墓側。靈芝一莖九葩數本，產塚上。嘉靖四年，蔭錦衣衛千戶。明年，中武舉第一，官都督僉事。時弟墀入史局，陞官翰林。堪迎養母于京邸，二十年，承顏盡樂。母沒，扶柩南還，柴毀骨立，抵杭卒，贈都督同知，旌曰『孝行之門』。」堪能詩文，旁通雜藝，繪事
亦見稱。

沈之章
[
编辑

按《烏程縣志》：「沈之章，嘉靖乙卯，倭寇雙林，掠其繼父思賢以去。之章赴倭壘，父將就刃，之章悲號奮擲，願以身代，倭俱釋之。後思賢有子，竟歸本宗，不受寸土。子汝法為諸生。」
孫濟
[
编辑
]

按《歸安縣志》：「孫濟，字以道，歸安人。嘉靖己丑進士。性至孝，早孤，家貧，事母奉養備至，常割股肉和丸醫母疾。母亡，廬墓終喪。生平接人謙厚，儉約如寒士。所著有《苕溪集》行世。」
吳滄
[
编辑
]

按《東陽縣志》：「吳滄，幼失父，其母陳甘貧撫滄。比長，竭力事母。母沒，廬墓三年。又以早孤，不得廬父墓，復補三年。嘉靖初，北上乞表母節，行至揚子江，值颶風大作，舟欲覆，滄泣曰：『吾死不足惜，吾母之節泯矣』。叩頭籲天，風稍息，忽有一大舟乘風來，邇滄舟，繫其尾，得​免。及疏上，朝廷鑒其懇切，賜表其母。後士民復以滄」行舉呈當道，奏聞，旌表焉。

翁遂
[
编辑
]

按《壽昌縣志》：「翁遂，字德進，清泉人。早喪母，事父至孝，冬夏溫凊，朔望必禱。有疾則親奉湯藥而先嘗之。妻亡，不再娶。父沒，居喪廬墓三年畢。每遇忌，且持香拜於墓下，雖雨雪不廢。有司上其事，嘉靖二年，例錫冠帶以榮之。」
舒哲
〈子璘〉
[
编辑
]

按《玉山縣志》：舒哲，字天貽。家貧，事母至孝，母病，不解
衣者三月，邑人稱其孝。由歲貢授會稽訓。躬行率士，
品藻尤精。歿於官，諸生咸痛悼之。櫬歸，多造其廬而
哭。緒山錢某謂「其生則盡人之倫，死則致人之哀，可謂無忝所生者。」嘉靖中，督學檄祀鄉賢。子璘，事哲孝。
哲嘗孝母，鄉先生為之修《怡萱集》。縣令扁其門曰「世孝之門。」
楊密
[
编辑
]

按《蕭山縣志》：「楊密，幼失父，事母嚴氏至孝。母疾危，刲股和藥療之，尋愈。嘉靖初奏聞，詔旌其門，祀鄉賢祠。」
楊瀚
[

[
编辑
]

按《南陽縣志》：劉田，南陽人，天性純孝，少讀書至天明
地察，掩卷歎曰：此殆非可以誦讀了事者也。經曰：「孝弟之至，通于神明。」神明者心耳，心惟其誠，不惟其偽。
人能誠于盡孝，自承顏順志以及定省奉養，無一毫
虛假，則可以慰親心，即可以動天地，感鬼神。故曰：「天地明察，神明彰矣。」此徹上徹下之道也。人能盡得此
道，斯成個人，纔教個立身行道，故《孝經開宗明義》章
即揭出個「身」字來，見得完全，此身無非是孝。天子以
孝治天下，諸侯以孝治其國，卿大夫以孝治其家，庶
人以孝治其身。雖事有大小不同，而道則一也。讀此
一經而不自識至性，即不曾讀。塾師大其器，識田，自
此孝彌篤。事二親，雞鳴起，即檢點一日菽水之具，凡
所以奉親者，必自視之然後進。一日，見其父有憂色，
田悚慄，終日不食。至晚，從容進曰：「父志不愉，子職之咎也。」其父以時事告，乃退，猶經夜不能寐。至晨問起
居，見其父有喜色，乃食。其順親心類如此。嘉靖間舉
進士，家居終養。或有勸之仕者，田笑而應曰：「家貧親老，子以孝道愛我，宜」爾，然三牲之養，不如雞豚之逮
吾親也。余謬登賢書，家有薄田數頃，可奉二人，志足
矣。及其父母歿，田哀毀骨立，廬墓三年。朝野感動，為
建孝子坊。故至今人知其為孝子而不知其為進士
云。
