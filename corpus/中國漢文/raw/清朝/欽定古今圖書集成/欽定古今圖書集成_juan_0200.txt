神異典第二百卷

僧部藝文六
〈詩〉
[
编辑
]

《送僧遊山》
唐·熊孺登
[
编辑
]

雲身自在山山去，何處靈山不是歸。日暮寒林投古
寺，雪花飛滿水田衣。

《送僧遊天台》
鮑溶
[
编辑
]

金嶺雪晴僧獨歸。水文霞采衲禪衣。可憐石室燒香
夜，江月對心無是非。

《秋夜懷紫閣寺僧》
前人
[
编辑
]

滿山雨色應難見，隔澗經聲又不聞。紫閣夜深多入
定，石臺誰為掃秋雲。

《送貞實上人歸杭州天竺》
姚合
[
编辑
]

石橋寺裏最清涼，聞說茅庵寄上方。林外猿聲連院
磬，月中潮色到禪床。他生念我身何在，此世唯師性
亦忘。九陌相逢千里別，青山重疊樹蒼蒼。

《送僧歸富春》
鄭巢
[
编辑
]

憶過僧禪處，遙山抱竹門。古房關蘇色，秋徑掃潮痕。
石靜聞泉落，沙寒見鶴翻。終當從此望，更與道人言。

《送琇上人》
前人
[
编辑
]

「古殿焚香外，清羸坐石稜。」茶煙開瓦雪，鶴跡上潭冰。
孤磬侵雲動，靈山隔水登。白雲歸意遠，舊寺在廬陵。

《贈蠻僧》
前人
[
编辑
]

南海何年過，中林一磬微。病逢秋雨發，心逐暮潮歸。
久臥前山寺，猶縫故國衣。近來慵步履，石蘚滿柴扉。

《送無相禪師入關》
章孝標
[
编辑
]

九衢車馬塵，不染了空人。暫舍中峰雪，應看內殿春。
齋心無外事，定力見前身。聖主方崇教，深宜謁紫宸。

《贈僧雲棲》
張祐
[
编辑
]

麈尾與筇杖，幾年離石壇。梵餘林雪後，棋罷嶽鐘殘。
開卷喜先悟，漱瓶知早寒。衡陽寺前鴈，今日到長安。

《贈禪師》
前人
[
编辑
]

坐見三生事，宗傳一衲來。已知無法說，心向定中灰。

《送僧遊溫州》
朱慶餘
[
编辑
]

夏滿隨所適，江湖非繫緣。卷經離嶠寺，隔葦上秋船。
水落無風夜，猿啼欲雨天。石門期獨往，謝守有遺篇。

《送僧》
前人
[
编辑
]

「客行皆有為，師去是閒遊。野望㩦金策，禪棲寄石樓。」山深松翠冷，潭靜菊花秋。幾處題青壁，袈裟濺瀑流。

《尋僧》
前人
[
编辑
]

吟背春城出草遲，天晴紫閣赴僧期。山邊樹下行人
少，一派新泉日午時。

《寄宗靜上人》
雍陶
[
编辑
]

世上方傳法，山中未得歸。閑花飄講席，馴鴿污禪衣。
積雨誰過寺，殘鐘自掩扉。寒來垂頂帽，白髮剃應稀。

===
《懷無可上人》
前人
===
​
山寺秋晴後，僧家夏滿時。清涼多古蹟，幾處有新詩。

《贈南嶽僧》
李遠
[
编辑
]

「曾住衡陽嶽寺邊，門開江水與雲連。數州城郭藏寒樹，一片風帆著遠天。」猿去不離行道處，客來皆到臥
床前。今朝惆悵紅塵裏，惟憶閒塘盡日眠。

《大夢上人自廬峰回》
杜牧
[
编辑
]

行腳尋常到寺稀，一枝藜杖一禪衣。開門滿院空秋
色，新向爐峰過夏歸。

《贈終南蘭若僧》
前人
[
编辑
]

北闕南山是故鄉，兩枝仙桂一時芳。休公都不知名
姓，始覺禪門氣味長。

《還俗老僧》
前人
[
编辑
]

雪髮不長寸，秋寒力更微。獨尋一徑葉，猶挈衲殘衣。
日暮千峰裏，不知何處歸。

《晨別翛然上人》
許渾
[
编辑
]

吳僧誦經罷，敗衲倚蒲團。鐘韻花猶斂，樓陰月向殘。
晴山開殿響，秋水捲簾寒。獨恨孤舟去，千灘復萬灘。

《贈閑師》
前人
[
编辑
]

近日高僧更有誰？宛陵山下遇閑師。東林共許三乘
學，南國爭傳五字詩。初到庾樓紅葉墜，夜投蕭寺碧
雲隨。秋江莫惜題佳句，正是磷磷見底時。

《乘月棹舟送大曆寺靈聰上人不及》
[
编辑
]

前人

萬峰秋盡百泉清，舊鎖禪扉在赤城。楓浦客來煙未
散，竹窗僧去月猶明。杯浮野渡魚龍遠，錫響空山虎
豹驚。一字不留何足訝，白雲無路水無情。

《送太昱禪師》
前人
[
编辑
]

禪床深竹裏，心與徑山期。結社多高客，登壇盡小師。
早秋歸寺遠，新雨上灘遲。別後江雲碧，南齋一首詩。

《白馬寺不出院僧》
前人
[
编辑
]

禪心空已寂，世路任多岐。到院客長見，閉關人不知。
寺喧聽講絕，廚遠送齋遲。牆外洛陽道，東西無盡時。

《贈僧》
前人
[
编辑
]

心法本無住，流沙歸復來。錫隨山鳥動，經附海船回。
洗足柳遮寺，坐禪花委苔。惟將一童子，又欲上《天台》。

《送無夢道人先歸甘露寺》
前人
[
编辑
]

「飄飄隨晚浪，杯影入鷗群。」萍凍千船雪，巖陰一寺雲。
夜燈江北見，寒磬水西聞。鶴嶺煙霞在，歸期不羨君。

《寄敬上人》
前人
[
编辑
]

萬山秋雨水縈迴，紅葉多從紫閣來。雲冷竹齋禪衲
薄，已應飛錫過天台。

《奉寄安國大師兼簡子蒙》
李商隱
[
编辑
]

憶奉蓮花座，兼聞《貝葉經》。巖光分蠟屐，澗響入銅瓶。
日下徒推鶴，天涯正對螢。魚山羨曹植，眷屬有文星。

《憶住一師》
前人
[
编辑
]

無事經年別遠公。帝城鐘曉憶西峰。爐煙銷盡寒燈
暗。童子開門雪滿松。

《別臻師》
前人
[
