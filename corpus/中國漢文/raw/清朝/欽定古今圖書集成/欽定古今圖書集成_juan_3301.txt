《過攔江磯》
〈即茶房石在陽邏江中〉
[
编辑
]

明陶安

朝來東北好風生，吹得雲帆似葉輕。穩向攔江磯嘴
過，怒濤噴薄不須驚。

《泊新生洲》
前人
[
编辑
]

中流突起新生洲，南岸猶稱下矮劉。熟睡不須愁夜
雨，曉看黃鶴立雲頭。

《望蘄州》
楊基
[
编辑
]

未見蘄州城，已見蘄州山。諸山初不高，蒼石礪且頑。
想當至正時，民物庶以繁。大江從西來，萬里不閉關。
茲山獨儲英，群雄出其間。遂為禍亂階，滋蔓莫可芟。
憶我聞亂初，我方總兩鬟。侍立父母旁，聽說國步艱。
焉知三十年，見此童與菅。骨肉亦已零，安得髮不斑。
披榛欲弔古，豺虎愴我顏。蒼茫望茅宇，日落孤舟還。

《環翠亭》
高啟
[
编辑
]

環翠亭開紫霞裡，更掖麟峰并雉水。千崖秀色傍窗
浮，萬壑濤聲從座起。煙消日出天溶溶，玉壺倒插金
芙蓉。鉤簾相對坐長夏，灑然冰雪生心胸。

《赤壁歌》
方孝孺
[
编辑
]

東夏口，西武昌，赤壁峭絕當中央。奸雄將軍氣蓋世，
敗卒零落慚周郎。得鱸魚，沽美酒，孰若黃州蘇子瞻。
謫向江湖動星斗，噫吁嚱！曹公氣勢，蘇子文章。人物
銷鑠，塵跡荒涼。惟有江山，千古萬古共流長。

《詠赤壁》
藍潤
[
编辑
]

「長江西來雨如霧，赤壁蒼蒼風雨暮。草木猶疑橫槊時，塵沙尚想焚舟處。烏林渡口下舳驢，曹瞞已料無全吳。陣前部曲走劉備，眼前談笑輕周瑜。君臣謀合士鼓勇，玉帳旌旗亦飛動。」樓櫓晴空煙焰高，魚龍白
日波濤湧。荊門牢落駐殘兵，野曠不聞鼙鼓聲。戰骨
秋埋胡地草，捷書夜報石頭城。雄圖霸氣兩消歇，地
老天荒秋一葉。石上殘碑過客題，沙中古劍漁人得。
漢王祠枕碧山隅，諸葛臺荒野鳥呼。千年忠義《出師
表》，萬古江山《八陣圖》。

《竹樓》
何喬新
[
编辑
]

「黃岡使君文中虎，勁氣英英隘寰宇。西清東觀莫容身，又擁朱幡守江渚。江雲山雨晝冥冥，使君對此若為情。驚濤厭見蛟黿舞，老樹愁聞猿狖鳴。平生才名冠當世，每吐忠言裨國是。哆呫竊笑奸謟排，一身南北長如寄。使君知命不解愁，竹樓鬨起江之陬。笑呼斗酒酬前哲，風帆沙鳥任沉浮。仙遊今在蓬萊島，陳」跡荒涼凄蔓草。我來不見樓中人，自酌寒泉薦頻藻。

《定惠院步蘇公海棠詞韻》
邵寶
[
编辑
]

草堂三間倚林木，如魯靈光巋然獨。當時坡老賦《海
棠》，遂使荒丘頓超俗。乾坤俯仰五百年，多少高陵變
深谷。愛人及物自古然，甘棠在野烏在屋。誰將蔬圃
一治之，彼哉鄙夫徒食肉。今之太守關西豪，友盡今
人猶未足。況逢別駕是同鄉，前日臺端望尤淑。登臨
弔古每賦詩，萬丈虹光吐便腹。清標既逼雪堂雪，雅
韻還宜《竹樓竹》。我持憲節東南行，偶陟黃岡一遊目。
高山仰止同此懷，如睹巍峨在西蜀。雄篇可讀不可
和，白雪渺渺天邊鵠。一株培植兩侯心，酌酒酹公歌

我曲。願言折竹作新籬，等閑莫遣羚羊觸
​

《至李坪驛始見竹筏上居民連亙三十餘家云隨流上下作䉡治板行販》
王世貞
[
编辑
]

「何必問故鄉」，浮家任儂住。一夜便風來，盡呼鄰里去。

《過弘化庵四首》
茅瑞徵
[
编辑
]

「閑行郊外遊，載酒山前寺。」幾處寒雲生，雲臥人時至。

又

蕉影橫窗綠，鐘聲引梵長。坐看秋色老，簾外月如霜。

又

「曲徑風敧竹，前軒月轉廊。」此中栖託好，清興得誰嘗。

又

寒到清谿水，長吟《白社詩》。還同《真率會》，剩有酒盈卮。

《過孔子問津處》
前人
[
编辑
]

驅車循四履，晴巒來遠曙。一水不容刀，征人戒勿遽。
褰裳往從之，下流苦沮洳。試扣此何為，云是問津處。
在昔鳳戢羽，深心嚮誰語。屏營岐路側，所遇溺與沮。
避世不避人，相對一何倨。千載憑遺跡，山川應何㨿。
我來出其傍，茲行豈游豫。六翮阻高飛，九折空叱馭。
雖馳雲外想，已作粘泥絮。仰止步荒祠，低回不能去。

《由清泉過茶泉建亭其上》
卓世彥
[
编辑
]

浠水多泉瀑，茲泉獨擅名。先賢風漸遠，而我感常生。
煮茗何年事，開亭此日情。枯腸煩渴久，一掬有餘清。

《寄題清泉寺函三閣》
屠隆
[
编辑
]

一代文章萬古希。山川賴爾亦增輝。狂夫若問西來
意。孤鶴橫江赤壁磯。

《蘭溪江晚》
周延奇
[
编辑
]

西日赤烘天，晴江疋練懸。歸舟紛打岸，野寺暝生煙。
鳥迅棲巢樹，漁遲別浦川。如何客遊子，征騎尚翩翩。

《九日登聚寶山》
鄧雲程
[
编辑
]

寶山山畔一停車，風雨歸來笑敝廬。赤腳紅雲僧送
酒，斷崖絕磴鳥傳書。數莖愁髮垂垂白，累劫名根漸
漸除。唱晚踏莎舒老眼，江湖留得幾樵漁。

《登赤壁酹江亭》
向古
[
编辑
]

羽客何年去不歸，白鷗煙艇望依稀。雲深絕壑迷樵
徑，水落前灘長釣磯。古閣荒涼人已遠，殘碑偃臥草
空肥。登臨重話興亡憾，搔首江天醉落暉。

《題木蘭寺》
郭正域
[
编辑
]

丹梯翠殿俯穹蒼，萬仞千盤接渺茫。山勢欲凌碧落
近，香煙直與紫霄長。南瞻鄂渚通王氣，北顧中原鎖
帝鄉。為憶《木蘭》當日事，眼前誰是鐵衣郎。

《黃岡山莊雜興十章》
王廷陳
[
编辑
]

老夫諳稼穡，次第葺園廬。對酒唯田父，呼門絕里胥。
桑麻經雨後，花竹宛秦餘。如此生涯足，何勞薦《子虛》。

又

「事去心愈壯，年來跡轉孤。濯纓臨漢沔，安枕荷《黃虞》。」「春澗偏魚鳥，秋窗近竹梧。出逢鄰叟飲，醉倩野童扶。」
又

「避人開石戶，覽物坐山堂。」湘岫寒增色，江蘺晚更香。
卜居悲楚客，招隱憶淮王。寂寞吾甘守，浮沉念總忘。

又

計拙堪時棄，謀生托野人。鶯花無約束，木石有比鄰。
溪上龍思蟄，林閒鳥學呻。逢人無一面，語契即相親。

又

「天地一虛舟，浮沉雙白鷗。半生從失計，萬事不關愁。」山月杯中映，江雲几上流。狂歌人莫測。吾興屬《滄洲》。

又

圃坐晴逾麗，畦行晚更宜。客從蘿逕入，自笑葛巾攲。
果熟山禽戀，林馴野鹿隨。憑欄契物理，衛足頗欽葵。

又

樹古村墟僻，江寒邑里秋。過雲頻送目，累月不梳頭。
廢禮緣多病，求仁未寡尤。呼兒問網罟，明發上漁舟。

又

葉減山爭出，林秋景故偏。候虫喧冷砌，過雁影晴川。
月酌沾松露，楓吟雜澗泉。何人會幽興，寂寞自鳴絃。

又

「物換竟誰使，朋來非我期。曙光隨日薄，秋籟入雲悲。速婦開新釀，從兒誦《古詩》。」自為真率飲，忘卻髮成絲。

又

蘿軒時散帙，苔澗亦垂綸。翠竹供詩遍，蒼林佐酒頻。
岫重遲見旭，源曲易迷津。早契沉冥理，難為俗子陳。

《定惠院宴集》
〈二首〉
前人
[
编辑
]

石磴接巖扉，行行上翠微。賓朋花下至，雲鳥竹邊飛。
韶景度欲盡，《舊遊》存苦稀。蘇公何可作，今古一沾衣。

又

結侶乘暄出，憑高望眼開。閭閻深負渚，阡陌曲侵臺。
展席春雲映，歸軒夕鳥催。回看遽陳跡，相送轉徘徊。

《柯山園》
〈四首〉
吳國倫
[
编辑
]

買舟三百里，江上見柯山。古徑雙橋外，方塘萬木間。
入門花石喜，留客水雲閒。若與王猷共，山陰那得還。

又

「性僻耽幽勝，風雲奈汝何。」「寄情都不淺，乘興一相過。」宛轉看亭榭，陰森坐薜蘿。移樽從所適，山鳥自為歌
​

又

藂篁開作徑，灌木不知年。未解亭相錯，翻疑地屢遷。
烹葵支舊鼎，種樹續新編。總失干時計，端居亦晏然。

又

「散步出幽籬，群芳送酒卮。隔城嚴漏下，近寺暝鐘遲。」秉燭雲生榻，停歌月滿池。不禁酣欲臥，敢謂老能詩。

《過龍眼磯》
〈在蘄州江心〉
前人
[
编辑
]

片石亂流中，巋然抗佛宮。諸天龍樹表，萬象蜃樓空。
花雨都成雪，濤驚不為風。孤僧容膝處，應與海門通。

《題浮玉亭》
前人
[
编辑

陶淵明賦《歸去來》，有其詞而無其聲。余治東坡，築雪堂於上，人俱笑其陋，獨鄱陽董毅夫過而悅之，有卜鄰之意。乃取《歸去來》詞稍加檃括，使就聲律以遺毅夫，使家僮歌之。時相從於東坡，釋耒而和之，扣牛角而為之節，不亦樂乎！

「為米。折腰因酒，棄家口體交相累。歸去來誰不遺君歸。覺從前、皆非今是。露未晞。征夫指予歸路。門前笑語喧童稚。嗟舊菊都荒，新松暗老，吾年今已如此。但小窗容膝閉柴扉。策杖看孤雲暮鴻飛。雲出無心，鳥倦知還，本非有意。噫。歸去來兮，我今忘我兼忘世。親戚無浪語，琴書中有真味。步翠麓崎嶇，泛溪窈窕，涓」涓暗谷流春水。觀草木欣榮，幽人自感，吾生行且

張志和《漁父詞》云：「西塞山邊白鳥飛，桃花流水鱖魚肥。青篛笠，綠蓑衣，斜風細雨不須歸。」 蘄水散花洲之對岸，即西塞山也。余增數語，以《浣溪沙》歌之。
