社日部藝文一

编辑

祝社文　　　　　　　　　後漢蔡邕
[
编辑
]

元正令午，時惟嘉良。乾坤交泰，太簇運陽。乃祀社靈，
以祈福祥。

社賦序　　　　　　　　　　晉嵇含
[
编辑
]

社之在於世尚矣。自天子至於庶人，莫不咸用。有漢
卜日丙午，魏氏擇用丁未。至於大晉，則社孟月之酉
日，各因其行運，三代固有不同，雖共奉社而莫議社
之所由興也。

祝社文　　　　　　　　　　　應碩
[
编辑
]

元首肇建，吉酉辰良。五政敷惠，四教初揚。萬類資新，
英穎擢章。谷風滌穢，日和時光。命於嘉賓，宴茲社廂。
敬享社君，休祚是將。嘉餚綺錯，白茅薦恭。有肉如坻，
有酒如江。社君既眷，祗肅威容。

社日部藝文二
〈詩詞〉
[
编辑
]

《春可樂　　　　　　　　　　》。《晉王廙》

吉辰兮上戊，明靈兮惟社。伯仲兮畢集，祈祭兮樹下。
濯卵兮葅韭，齧䔉兮擗鮓。縹醪兮浮蟻，交觴兮並坐。
氣和兮體適，心怡兮志可。

春祈社諴夏　　　　　　　　隋牛弘
[
编辑
]

厚地開靈，方壇崇祀。達以風露，樹之松梓。句萌既申，
芟柞伊始。恭祈粢盛，載膺休祉。

秋報社諴夏　　　　　　　　　前人
[
编辑
]

北墉申禮，單出表誠。豐犧入薦，華樂在庭。原隰既平，
泉流又清。如雲已望，高廩斯盈。

秋社日崇懷園宴得新字　　　唐蘇頲
[
编辑
]

鳴爵三農稔，勾龍百代神。運昌叨輔弼，時泰喜黎民。
樹缺池光近，雲開日影新。生全應有地，長願樂交親。

社日　　　　　　　　　　　韋應物
[
编辑
]

山郡多暇日，社時放吏歸。坐閣獨成悶，行塘閱清輝。
春風動高柳，芳園掩夕扉。遙思里中會，心緒悵微微。

社日二首　　　　　　　　　杜甫
[
编辑
]

九農成德業，百祀發光輝。報效神如在，馨香舊不違。
南翁巴曲醉，北鴈塞聲微。尚想東方朔，詼諧割肉歸。
陳平亦分肉，太史竟論功。今日江南老，他時渭北童。
歡娛看絕塞，涕淚落秋風。鵷鷺迥金闕，誰憐病峽中。

社前遭田父泥飲美嚴中丞　　　前人
[
编辑
]

「步屧隨春風，村村自花柳。田翁逼社日，邀我嘗春酒。
酒酣誇新尹，畜眼未見有。迥頭指大男，渠是弓弩手。
名在飛騎籍，長番歲時久。前日放營農，辛苦救衰朽。
差科沒則已，誓不舉家走。今年大作社，拾遺能住否？
叫婦開大瓶，盆中為吾取。感此氣揚揚，須知風化首。
語多雖雜亂，說尹終在口。朝來偶然出，自卯將及酉。」
久客惜人情，如何拒鄰叟。高聲索果栗，欲起時被肘。
指揮過無禮，未覺邨野醜。月出遮我留，仍嗔問升斗。

二月二十七日社兼春分端居有懷簡所思者
[
编辑
]

權德輿

清晝開簾坐。風光處處生。看花詩思發。對酒客愁輕。
社日雙飛燕，春分百囀鶯。所思終不見。還是「一含情。」

賽神　　　　　　　　　　　　韓愈
[
编辑
]

白布長衫紫領巾，差科未動是閒人。麥苗含穗桑生
葚，共向田頭樂社神。

吳楚歌詞　　　　　　　　　　張籍
[
编辑
]

庭前春鳥啄林聲，紅夾羅襦縫未成。今朝社日停鍼
線，起向朱櫻樹下行。

社日關路作　　　　　　　　白居易
[
编辑
]

晚景函關路，涼風社日天。青巖新有燕，紅樹欲無蟬。
愁立驛樓上，厭行官堠前。蕭條秋興苦，漸近《二毛》年。

===嘉興社日　　　　　　　　　劉言史===
​
消渴天涯寄病身，臨卭知我是何人。今年社日分餘
肉，不值陳平又不均。

郊行逢社日　　　　　　　殷堯藩
[
编辑
]

酒熟送迎便，村村慶有年。妻孥親稼穡，老稚效漁畋。
紅樹青林外，黃蘆白鳥邊。稔看風景美，寧不羨《歸田》。

將發循州社日於所居館宴送　裴夷直
[
编辑
]

浪花如雪疊江風，社過高秋萬恨中。明日便隨江燕
去，依依俱是故巢空。

社日村居　　　　　　　　　　張演
〈一作張蠙〉
[
编辑
]

鵝湖山下稻粱肥，㹠穽雞棲對掩扉。桑柘影斜春社
散，家家扶得醉人歸。

春社從李昉乞酒　　　　　　宋李濤
[
编辑
]

社公今日沒心情，為乞《治聾》酒一瓶。惱亂玉堂將欲
遍，依稀巡到第三廳。

春社　　　　　　　　　　　梅堯臣
[
编辑
]

「年年迎社雨，淡淡洗林花。」樹下賽田鼓，壇邊伺肉鴉。
春醪酒共飲，野老暮相譁。燕子何時至，長皋點翅斜。

社日獨坐　　　　　　　　　范成大
[
编辑
]

海棠雨後沁臙脂，楊柳風前撚綠絲。香篆結雲深院
靜，去年今日燕來時。

春日田園雜興　　　　　　　　前人
[
编辑
]

社下燒錢鼓似雷，日斜扶得醉翁迴。青枝滿地花狼
籍，知是兒孫𩰚草來。

社日諸人集西岡　　　　　　　朱熹
[
编辑
]

「郊原愛芳物，細雨青春時。」前岡遐敞地，登覽情無遺。
農畝懷歲功，壺漿祝神釐。「我慚里居氓，十載勞驅馳。
今朝幸休閒，追逐聊嘻嘻。笑語歡成舊，盡醉靡歸期。」

乙酉社日偶題　　　　　　　楊萬里
[
编辑
]

「愁邊節裏兩相關，茶罷呼兒檢曆看。社日雨多晴較
少，春風晚暖曉猶寒。也知散策郊行去，其奈緣溪路
未乾。」綠暗紅明非我事，且尋野蕨作蔬盤。

春社　　　　　　　　　　　　陸游
[
编辑
]

太平處處是優場，社日兒童喜欲狂。且看參軍喚蒼
鶻，京都新禁舞《齋郎》。

社雨　　　　　　　　　　　　前人
[
编辑
]

開歲纔幾時，春社忽已及。茫茫草色深，蕭蕭雨聲急。
扶犁行白水，不惜芒屨濕。村童更可憐，赤腳牛背立。

社鼓　　　　　　　　　　　　前人
[
编辑
]

酒旗三家市，煙草卜里陂。林間鼓鼕鼕，迨此春社時。
飲福父老醉，嵬峨相扶持。君勿輕此聲，可配「《豐年》詩。」

社酒　　　　　　　　　　　　前人
[
编辑
]

農家耕作苦，雨暘每關念。種黍蹈麴糵，終歲勤收斂。
社瓮雖草草，酒味亦醇釅。長歌《南陌頭》，百年應不厭。

社肉　　　　　　　　　　　　前人
[
编辑
]

社日取社豬，燔炙香滿村。飢鴉集街樹，老巫立廟門。
雖無牲牢盛，古禮亦略存。醉歸懷餘肉，霑遺遍諸孫。

社飲　　　　　　　　　　　　前人
[
编辑
]

東作初占嗣歲宜，蠶官又近乞靈時。傾家釀酒無遺
力，到社迎神盡及期。先醉後醒驚老憊，路長足蹇歎
歸遲。西村漸過新塘近，宿鳥歸飛已滿枝。

社日僧舍風雨　　　　　　　　劉宰
[
编辑
]

借蔬香積共晨炊，客裏良辰總不知。孺子從渠均胙
肉，南翁無處聽《巴詞》。神鴉得志飽終日，巢燕無心來
及時。風雨聒人聾轉甚，半鍾濁酒可能治。

今朝當社日　　　　　　　　戴復古
[
编辑
]

今朝當社日，明日是花朝。佳節惟宜飲，東池適見招。
綠深楊柳重，紅透海棠嬌。自笑鬢邊雪，多年不肯消。

社日　　　　　　　　　　　　方岳
[
编辑
]

燕子今年掯社來，翠瓶猶有去年梅。「丁寧莫管杏花
俗，付與春風一道開。」

社前　　　　　　　　　　　　謝翱
[
编辑
]

無家借燕住，離別又經年。客館依山上，春分到社前。
雨來換宿水，雲起暗晴川。颯颯吹衣帶，因風問去船。

社日　　　　　　　　　　　李公麟
[
编辑
]

千尋占櫟笑聲中，此日春風屬社公。開眼已憐花壓
帽，放懷聊喜酒治聾。攜刀割肉餘風在，《卜瓦》傳神俚
俗同。聞說已栽桃李徑，隔溪遙認淺深紅。

社日二首　　　　　　　　金施宜生
[
编辑
]

濁澗迴湍激，青煙弄晚暉。緣隨春酒熟，分與故山違。
社鼓喧林莽，孤城隱翠微。山花羞未發，燕子喜先歸。
割少詼諧語，分均宰制功。靈祗依古樹，醉叟泥村童。
萬里開耕稼，三時順雨風。行春從此樂，著意酒盃中。

社日城南　　　　　　　　元戴表元
[
编辑
]

「社日年年雨，江花處處春。漸成垂白老，不見踏青人。」
「榆柳邊聲雜，龍蛇歲事新。端來近城郭，猶自厭風塵。」

社日　　　　　　　　　　　　郭鈺
[
编辑
]

甲子頻書入短篇，細推五戊卜春田。讀書未有《平戎
策》，止酒聊輸祭社錢。紅樹花穠春向晚，畫橋柳暝雨
如煙。舊來歌舞今誰是，燕子茅檐只自憐。

社日　　　　　　　　　　　明甘瑾
[
编辑
]

楓樹林邊雨腳斜，兒童祈賽競喧譁。雞豚上戊家家
​
酒，鶯燕東風處處花。野徑歸時扶醉客，叢祠祭罷集
神鴉。瀕湖生意愁多潦，預祝汙邪載滿車。

春社詞　　　　　　　　　　　瞿佑
[
编辑
]

十日一風五日雨，社前拜祝神已許。瓦盆瀲灩斟濁
醪，高俎縱橫薦肥羜。嗚嗚笛聲坎坎鼓，俚曲山歌互
吞吐。老巫狡獪神有靈，傳得神言為神舞。祭餘分肉
巫自與，醉裏狂言相爾汝。小兒覓餅大兒扶，頭上神
花付鄰女。

社中四首　　　　　　　　　陳憲章
[
编辑
]

桑林伐鼓酒如川，秋社錢多春社錢。盡道昇平官長
好，五風十雨更年年。

社屋新成燕子來，山丹未落野棠開。三三兩兩兒童
戲，弄水扳花日幾回。

社酒開顏一百家，春風先動長官衙。東君也解遊人
意，紅白交開樹樹花。

社日年年會飲同，東原西埭鼓《鼕鼕》。無人不是桃花
面，笑殺河陽樹上紅。

社日　　　　　　　　　　　　石瑤
[
编辑
]

春風簾幕駐晴雲，社酒盃深我對君。燕子未來花不
語，綠蕪寒雀共斜曛。

社日出遊　　　　　　　　　方太古
[
编辑
]

「邨邨社鼓隔溪聞，賽祀歸來客半醺。水緩山舒逢日

《周禮》：「地官：州長，以歲時祭祀州社。」
〈訂義〉
賈氏曰：上云「歲
時」，皆謂歲之四時，此云「歲時」，惟春、秋二時耳。春祭社
以祈膏雨，望五穀豐熟；秋祭社以百穀豐稔，所以報

《史記封禪書》：「高祖初起，禱豐枌榆社。天下已定，詔御
史令豐謹治枌榆社，常以四時春以羊彘祠之。」
《西京雜記》：「高祖既作新豐，併移舊社，衢巷棟宇，物色
惟舊。」

《史記陳丞相世家》：里中社平為宰，分肉食甚均。父老
曰：「善！陳孺子之為宰。」平曰：「嗟乎！使平得宰天下，亦如
是肉矣。」

《盩庢縣志》：漢董龍家貧，與里人共祀社，眾買牲牢，龍
撰文以祭，祭畢分胙，眾不平，逐龍出，龍造泥飯以祭
於樹下。將焚文，有白鼠御文入地穴掘之，獲白金一
斗。龍不自私，率眾首官。縣令賢之，奏聞，表其閭曰「義
士。」

《後漢書應劭傳》：「中興初，有應媼者，生四子而寡，見神

至瑒七代通顯。」

《武陵先賢傳》：潘京為州辟，進謁值社會，因得見次及
探得不孝，刺史問曰：「辟士為不孝耶？」京舉版答曰：「今
為忠臣，不得復為孝子。」其機辯如此。

《四民月令》：「二月祀太社之日，薦韭卵于祖禰。」

《長沙傳》：魏長沙郡久雨，太守呂虔令戶曹掾齋戒在

果然。

《魏志王修傳》：「修年七歲喪母，母以社日亡。來歲鄰里

《世說》：阮修，字宣子。伐社樹，有人止之。宣子曰：「社而為
樹，伐樹則社亡；樹而為社，伐樹則社移矣。」

王肅《魏臺訪議》：帝問：「何用未社丑臘？」對曰：「王者各以
其行，盛日為社，衰日為臘。漢火德衰于戌，故以戌日
為臘。魏，土也，土畏木，丑之明日便寅，寅，木也，故以丑
臘。土成于未，故以歲始未社也。」

《北史李士謙傳》：士謙髫齔以孝聞，伯父瑒稱：「此兒吾
家顏子也。」李氏宗黨豪盛，每春秋二社，必高會極宴，
無不沈醉喧亂。嘗集士謙所，盛饌盈前，而先為設黍，
謂群從曰：「孔子稱黍為五穀之長，荀卿亦云：『食先黍
稷，古人所尚，寧可違乎』？」少長肅然，無敢弛惰。退而相
謂曰：「既見君子，方覺吾徒之不德也。」

《唐會要》：「開元十九年正月三十日，詔州縣社惟用酒
脯。」

《詩經大雅生民章》：「載謀載惟。」傳：「嘗之日，涖卜來歲之

〈疏〉

社文在嘗、獮之下，謂秋獮祭社也。嘗在孟秋，獮社俱

者，卜者自問吉凶於龜，不由嘗社所祭之神。

〈疏〉
序本其多獲所由，
言其作頌之意。經則主說年豐，故其言不及籍社，所

《石林詩話》：世言社日飲酒治聾，不知其何據。五代李

時為翰林學士，有日給內庫酒，故濤從乞之。則其傳

皆稱小字。濤性疏達不羈，善諧謔，與朝士言，亦多以

宰相。
