金二

完顏希尹
[
编辑
]

按《金史完顏希尹傳》：「希尹本名谷神，歡都之子也。金
人初無文字，太祖命希尹撰本國字，備制度。希尹乃
依倣漢人楷字，因契丹字制度合本國語，製女直字。
天輔三年，字書成，太祖命頒行之。其後熙宗亦製女
直字，與希尹所製字俱行用。希尹所撰，謂之女直大
字，熙宗所撰，謂之小字。」宗翰襲遼帝於五院司，希尹
為前驅，所將纔八騎，與遼主戰，一日三敗之。及大舉
伐宋，希尹為元帥右監軍。熙宗即位，希尹為尚書左
丞相兼侍中，加開府儀同三司。希尹為相，有大政，皆
身先執咎。天眷元年，乞致仕，不許，罷為興中尹。二年，
復為左丞相兼侍中，俄封陳王。三年，賜希尹死，并殺
希尹子同修國史把答、符寶郎漫帶。皇統三年，贈希
尹儀同三司、邢國公。天德三年，追封豫王。正隆二年，
例降金源郡王。大定十五年，諡「貞憲。」

完顏銀朮可
[
编辑
]

按《金史銀朮可傳》：「銀朮可，宗室子。太祖嗣位，使蒲家
奴如遼取阿疏，事久不決，乃使習古迺、銀朮可繼往。
當是時，遼主荒于政，上下解體。銀朮可等還，具以遼
政事人情告太祖，且言遼國之狀。太祖決意伐遼，蓋
自銀朮可等發之。銀朮可凡九陷陣，輒戰而出，大敗
遼軍，攻黃龍府，敗遼兵萬餘。遼主西奔天德，銀朮可」
以兵絕其後，遼主遂見獲。後從宗翰伐宋，圍太原，敗
宋黃迪兵于西都谷。進攻宋制置使姚古軍于隆川
谷，大敗之，殲宋軍于五臺。會兵攻汴城，克之。天會十
年，為燕京留守。十三年，加保大軍節度使、同中書門
下平章事，遷中書令，封蜀王。天眷三年薨，年六十八。
以正隆例，贈金源郡王，諡武襄，配享太祖廟庭。子《彀
英》。

完顏麻吉
[
编辑
]

按《金史麻吉傳》：「麻吉，銀朮可之母弟也。年十五，隸軍
中，從破高麗兵，下寧江州，平係遼女直，克黃龍府，皆
身先力戰，以功為謀克。繼領猛安，戰于高州境上，伏
​
矢射之中目，遂卒。麻吉大小三十餘戰，所至皆捷。皇
統中，贈銀青光祿大夫，諡毅敏。子沃側。」

完顏拔离速
[
编辑
]

按《金史拔离速傳》：「拔离速，銀朮可弟。天會四年，克太
原，拔离速為管勾太原府路兵馬事，復與婁室敗宋
兵于文水，遂從宗翰圍汴，襲揚州，入建康。天會十五
年，遷元帥左都監，再定河南、陝西，加金吾衛上將軍，
卒諡敏定。」

完顏斡魯古
[
编辑
]

按《金史斡魯古傳》：「斡魯古勃菫，宗室子也。太祖伐遼，
使斡魯古阿魯撫諭斡忽、忽賽兩路。天輔六年，討賊
于牛心山，道病卒。天眷中，贈特進。天德二年，配享太
祖廟庭。大定十五年，諡莊翼。」

完顏闍哥
[
编辑

按《金史斡魯古傳》：「闍哥，亦宗室子也，代斡魯古治咸
州。」

完顏酬斡
[
编辑
]

按《金史斡魯傳》：「燭偎水部寔里古達殺酬斡僕忽得，
斡魯分胡剌古、烏蠢之兵討之。酬斡，宗室子，魁偉善
戰，年十五，隸軍中，多見任用。以兵五百敗室韋，獲其
民眾，及招降燭偎水部，以功為謀克。天會十五年，遷
元帥左都監。陝西平，遷元帥左都監軍，加金吾衛上
將軍。卒諡敏定。」

完顏婆盧火
[
编辑
]

按《金史婆盧火傳》：「婆盧火，安帝五代孫。太祖伐遼，使
婆盧火徵迪古乃兵。天輔五年，摘取諸路猛安中萬
餘家，屯田於泰州。婆盧火為都統，後為平陽尹，西南
路招討使。婆盧火守邊屢有功。天會十三年，加同中
書門下平章事。天眷元年，駐烏骨迪烈地，薨，贈開府
儀同三司，諡剛毅。子剖叔襲猛安。天眷二年，為泰州」
副都統。子斡帶，廣威將軍；婆速，官特進。

完顏阿魯補
[
编辑
]

按《金史阿魯補傳》：「阿魯補，治訶之子。為人魁偉，多智
略，勇於戰，襲遼主，下義州。宗望伐宋，與郭藥師戰於
白河，宗望命阿魯補以二謀克先登奮戰，賞賚特異。
天會十五年，詔廢齊國。明年，特除歸德尹，取亳、宿等
州，阿魯補功最。皇統五年，為行臺參知政事，授世襲
猛安，改元帥右監軍，婆速路統軍，歸德軍節度使。」其
在汴時，常取官舍材木，構私第于恩州。至是事覺，遂
論死，年五十五。阿魯補以將家子從征伐，屢立功，歷
官有惠愛，得民心。及死，人皆惜之。大定三年，贈儀同
三司。

完顏骨𧹞
[
编辑
]

按《金史骨𧹞傳》：「骨𧹞，冶訶子，善騎射，有材幹。從討桓
𧹞散達烏春、窩謀罕留可之叛，皆有功。從太祖伐遼，
以力戰受賞。宗翰伐宋，骨𧹞凡四戰皆破之。天眷初，
為天德軍節度使。致仕，累遷開府儀同三司，卒年八
十五。子喜哥襲猛安，加宣武將軍。」

完顏訛古乃
[
编辑
]

按《金史訛古乃傳》：「訛古乃，冶訶子。資質魁偉。年十四，
隸秦王宗翰軍中，常領兵行前為偵候。皇統元年，以
功授寧遠大將軍，豪剌唐古部節度使。九年，再遷西
南路招討使。天德四年，遷臨洮尹，加金紫光祿大夫。
卒官，年五十三。」

完顏蒲查
[
编辑
]

按《金史蒲查傳》：「蒲查自上京梅堅河徙屯。天德初，為
元帥府扎也。使于四方，稱職，按事能得其實，領猛安、
開遠軍節度副使。大定二年，領行軍萬戶，充邳州刺
史，卒。蒲查性廉潔忠直，臨事能斷，凡被任使，無不稱
云。」

完顏突合速
[
编辑
]

按《金史突合速傳》：「突合速，宗室子，拏罕塞人。嘗領偏
師破雲中諸山寇盜。及伐宋，在宗翰軍以八謀克破
石嶺關屯兵數萬，殺戮幾盡。及再舉伐宋，突合速沃
魯以五百騎為前驅，先據黃河津，宋兵萬餘背水陣，
進擊敗之，遂降河陽，汴京平。天眷初，除彰德軍節度
使。天德間，封定國公，授世襲千戶。卒年七十二。正隆」
二年，贈應國公。

完顏宗亨
[
编辑
]

按《金史習不失傳》：「習不失子宗亨，本名撻不也，性忠
謹。天輔初，以宗室子充護衛，歷登州刺史、定國軍節
度使。海寧庶人南伐，以本職領武陽軍都總管。過淮，
世宗即位，以手詔班賜宗亨。宗亨得詔即入朝。大定
二年，授右宣徽使。未幾，為西北路兵馬都統，以討契
丹失利，降為寧州刺史。」

完顏蠻睹
[
编辑
]

按《金史宗室傳》：「景祖子麻頗，麻頗子蠻睹襲父猛安。
蠻睹卒，子掃合襲。掃合卒，子撒合輦襲。撒合輦卒，子
惟鎔襲。惟鎔本名沒烈，字子鑄，駢脅多力，喜周給人。
至寧初，守楊文關，有功，兼都統，護漕運。貞祐三年，破

紅襖賊，遷邳州經略使。卒，子從傑襲猛安，累功遙授
​
鎮南軍節度副使。」

完顏晏
[
编辑
]

按《金史完顏晏傳》：「晏本名幹論，景祖之孫，阿离合懣
次子也。明敏多謀略，通契丹，字天會。初授左監門衛
上將軍，為廣寧尹，入為吏、禮兩部尚書。皇統元年，為
北京留守，改咸平尹，徙東京。天德初，封葛王，入拜同
判大宗正事，進封宋王。海陵遷都，晏留守上京，累封
豫王、許王，又改越王。貞元初，進封齊。正隆二年，例削」
王爵，改西京留守，未幾，為臨潢尹，致仕。世宗為東京
留守，將士皆自淮南來歸，晏之子恧里乃亦自軍前
率眾來歸。上既即位，遣使召晏，既又遣晏兄子鶻魯
補馳驛促之。晏遂率宗室數人入見，即拜左丞相，封
廣平郡王，宴勞彌日。未幾，兼都元帥。大定二年，進拜
太尉，復致仕，還鄉里。是歲薨。

完顏宗峻
[
编辑
]

按《金史世紀》，景宣皇帝，本諱繩果，太祖第二子，母曰
聖穆皇后，唐括氏。太祖元妃宗峻，在諸子中最嫡。「天
輔五年，襲遼主于鴛鴦濼。遼主走陰山，耿守忠救西
京，擊走之，遂下西京。太祖崩，帝與兄宗幹率宗室群
臣立太宗。天會二年薨。熙宗即位，追上尊諡曰『景宣
皇帝』。」

完顏宗幹
[
编辑
]

按《金史遼王宗幹傳》：「宗幹本名幹，本太祖庶長子。太
祖伐遼，宗幹等下金山縣，從都統杲取中京。太宗即
位，宗幹為國論勃極烈，與斜也同輔政。天會三年，獲
遼主於應州西余曙谷。始議禮制度，正官名，定服色，
興庠序，設選舉，治曆明時，皆自宗幹啟之。熙宗即位，
拜太傅，與宗翰等並領三省事。天眷二年，進太師，封」
梁、宋國王。皇統元年，薨。上哭之慟，輟朝七日。海陵篡
立，追諡「憲古弘道文昭武烈章孝睿明皇帝」，廟號德
宗。大定二年，除去廟號，改諡明肅皇帝。二十二年，追
削明肅帝號，封為皇伯、太師、遼王，諡忠烈。子充、亮、兗、
襄、袞。

完顏宗望
[
编辑
]

按《金史宋王宗望傳》：「宗望本名斡魯補，又作斡离不，
太祖第二子也。每從太祖征伐，常在左右。上聞遼主
在大魚濼，自將精兵萬人襲之，宗望率兵四千為前
鋒，晝夜兼行，及遼主于石輦驛，遼主遯去，兵遂潰。太
祖已定燕京，襲遼主于陰山青塚之間，宗望婁室、銀
朮可以三千軍分路襲之。時遼主往應州，其嬪御諸」
女欲奔，命騎下執之。遼主自金城來決戰，宗望以千
兵擊敗之，獲其子趙王習《泥烈》及傳國璽。張覺，奔宋，
入于燕京。宗望責宋人納叛人，且徵軍糧，久不聞問。
聞童貫、郭藥師治軍燕山，宗望奏請伐宋。至三河，破
郭藥師兵，藥師降。遂取燕山府，破真定，克信德府，次
邯鄲。四年正月己巳，諸軍渡河，取滑州。八月，宗望會
諸將發自保州。宋种師閔軍四萬人駐井陘，宗望大
破之，遂克真定，自真定趨汴。十一月戊辰，宗望至河
上，降魏縣，克汴州，薨。天會十三年，封魏王。皇統三年，
進許國王，又徙封晉國王。天德二年，贈太師，加遼燕
國王，配享太宗廟庭。大定三年，改封宋王，諡桓肅。子
齊、《京文》。

完顏宗堯
[
编辑
]

按《金史世紀》，「睿宗立德顯仁啟聖廣運文武簡肅皇
帝，諱宗堯。初諱宗輔，本諱訛里朵。大定上尊諡追上。
今諱。魁偉尊嚴，人望而畏，性寬恕好施惠，尚誠實。天
會五年，帝為右副元帥，駐兵燕京，伐宋。帝徇地淄青，
降滑州，取開德，攻大名，克之。河北平，定陝西，班師朝
京師，立熙宗為諸班勃極烈，帝為左副元帥。十三年」
薨，年四十。陪葬睿陵。追封潞王，諡襄穆。皇統六年，進
冀國王。正隆二年，改封許王。世宗即位，追上尊諡，改
葬於大房山，號景陵。

完顏宗弼
[
编辑
]

按《金史梁王宗弼傳》，「宗弼本名斡啜，又作兀朮」，亦作
「斡出，或作晃。斡出，太祖第四子也。宗望伐宋，宗弼從
軍，取湯陰縣，降其卒三千人，以三千騎薄汴城。宗望
薨，宗輔為右副元帥，徇地淄青，攻大名府。宗弼軍復
先登，破其城。河北平，宋主奔於江南。宗弼等分道伐
之，自江寧取廣德軍路，追襲宋主於越州，遂攻杭州」
取之。宋主奔明州。宗弼留攻明州，克之，宋主奔溫州。
宗弼軍自杭州，遂取秀州、平江。宋韓世忠以舟師扼
江口，宗弼乃因老鸛河故道，開三十里，通秦淮，一日
一夜而成。宗弼乃得至江寧，以火箭射世忠舟，殲焉。
宗弼渡江北還，遂從宗輔定陝西。天會十五年，為右
副元帥，封瀋王。宋岳飛、韓世忠分據河南州郡要害，
復出兵涉河東，駐嵐、石、保德之境，以相牽制。宗弼率
眾取亳州及順昌府、嵩、汝等州，相次皆下，還軍於汴。
皇統三年，為太師、領三省事，都元帥，領行臺尚書省

常勝、查剌，特思鞫不以實，故出之矣。」熙宗以為然，使
唐括辯、蕭肄按問特思，特思自誣服，故出常勝罪，于
是乃殺常勝及其弟查剌，并殺特思。海陵乘此并擠
阿楞，殺之。阿楞弟撻楞，熙宗本無意殺之，海陵曰：「其
兄既已伏誅，其弟安得獨存？」又殺之。海寧篡立，追封
常勝、查剌、阿楞官爵，親臨葬所致祭。
