明二

夏寅
[
编辑
]

按《明外史》本傳：「寅字正夫，華亭人。正統末舉進士，授南京吏部主事。杜門力學，為文以宏奧稱，進郎中。成化初，考滿入都，上言臣頃歷徐州，見旱澇之後，民不聊生。此州壤接山東，素產豪傑。今饑餒切身，必為盜賊。乞特遣大臣鎮撫，蠲其田租，發廩賑貸。又見沿途貢船，丁夫不足，役及老稚，而所載官物僅一箱，餘皆私齎，乞嚴行禁絕。淮安、徐州、濟寧實兩京咽喉，宜各設文武官鎮守，訓兵屯田，常使兩京聲勢聯絡，則倉猝可以制變。」章下所司，惟不設文武官，餘皆議行。遷
江西副使，提督學政。其教務先德行士，經激勸者，後
多為聞人。進浙江右參政，恩信大孚。處州民有苦虐
走聚山谷者，招之不應，曰：「須夏公來，吾屬乃歸耳。」寅
檄至，眾果解散。久之，進山東右布政使。弘治改元，言
官或言其老，遂致仕歸。寅清直無黨援，為郎官二十
年，副使十年，始進秩，未嘗以淹屈介意。嘗語人曰：「君子有三惜：此生不學，一可惜；此日閒過，二可惜；此身一敗，三可惜。」世傳為名言。初，在南曹，與工部主事吳
人劉昌並有詩名。昌幼穎悟絕人，嘗避雨染肆，閱其
簿籍，已而染肆火書以畀之，不失毫髮。年十九，舉鄉
試第一，登進士。博學工詩。寅每見其作，累月不下筆，
必求勝之。昌後歷廣東左參政。

曾翬
[
编辑
]

按《廣西通志》：「翬，字時升，泰和人。景泰初，以參政分司右江。思明之變，翬與副使劉仁宅奉巡撫李棠檄往治其獄。𤣾聞二人治行急，遣所親信賂之道中。翬與仁宅計定，陽用好言謝遣去。已而分道疾驅，不數日，仁宅執球等南寧，翬亦就潯得𤣾，送棠所下之獄。及𤣾遣人入京，獄解，仁宅謂翬曰：『禍將作矣。盍去諸？翬』」曰：「見罪而執，法也；蒙赦不問，恩也。彼安能禍我？且士各行其志而已。」仁宅竟棄官去，翬以職業自樹。太平
府有永樂中所積監餉，征交者，歲苦校覆，官至，逮守
者償所損，復坐之法。翬為奏罷其役，人甚德之。後官
至刑部侍郎。

陶魯
[
编辑
]

按《廣東通志》：「魯字伯強，鬱林人。以父成浙江僉事死事廕。景泰初，授新會丞，遷知縣，有平寇功，累進兵備僉事、按察使。時高、雷、廉、肇流賊攻掠無完聚，魯設方略，擒斬賊首，奪回擄掠，修築城堡，招募義勇，諸賊悉平。乃奏立新寧、從化、龍門縣治，又平後山、瀧水及潯、梧、荔浦、府江、田州諸盜，悉殲之。下詔褒勵。累官湖廣」布政使，仍兼廣東兵備副使，轄治廣西蠻寇，人呼為
​
「三廣公」云。陳獻章曾贈詩，有「指揮戎馬，表裏山河」之
句，蓋多其功也。其後嘉靖中，命守臣建祠廣州，祀其
父子，子孫遂家焉。

陳𠊨
[
编辑
]

按《蘇州府志》：「𠊨字汝翼，鎰從子。弱冠從遊京師，景泰辛未，第進士，除南京河南道御史，理鹽筴。早有賢稱，擢四川僉事。天順時，敘南九箐山都長土獠，聚眾數萬，出沒長寧，肆掠猖獗。𠊨甫至，即提兵往視形勢，曰：『賊怙眾憑勢，未可以孤軍克也』。乃請濟師，命都督同知許貴統卒五萬討之。𠊨遂前驅入，破其寨門十餘，兩月不解甲。建議敕吏治修戰備，蒐乘補伍，更設關堡，以規久遠。更請免邊邑民兵松潘之戍，以戍長寧戎伍；罷建昌鹽井之餽及諸庸調，使得專征伐，為經長之計。」事下所司，不盡行。壬午，夾江花溪之盜乘間
又起，而漢州、德陽在在擾動。巡撫陳泰以𠊨為能，檄
之行，至即討平之。功未報，而敘南猶弗靖，詔下切責，
巡撫汪浩復強僎往，會貴帥議。軍士還，舟覆溺於敘
南江中，朝野痛悼。

和維
[
编辑
]

按《開封府志》：「維字振綱，河陰人。景泰辛未進士，擢浙江按察司僉事，召至便殿賜宴，又賜寶鏹以行。時藩臬吏多私養馬卒，雖妻妾巾襪襦履絲絮，悉養馬卒出，他不法稱是。維遂發以聞。上覽奏，悉按不法者坐之。由是搆隙，卒為所讒。先是，浙販絲民有值劫者，亡其刀，獨鞘在，權貴遂誣機戶姜魯等行劫，殊無左驗。」維召販者曰：「若絲何驗？」曰：「囊上印『《廣昌郡》』字。」乃密遣
邏旁邑。至海寧，插秧人褌上隱隱有字，執訊之，具服
刀所在，曰：「在新官橋下。」驗之，果販者刀也。權貴大慚。
又嘗江行，聞哭聲，蓋寡婦兒為人所掠賣也。立廉致
還之。性善酒，所著書并詩數十百卷行於世。

張祚
[
编辑
]

按《松江府志》：「祚字永錫，華亭人。景泰甲戌進士，授御史，遷廣東按察僉事。廉慎精密，嶺表信服之。會韓襄毅雍進討蠻寇，以祚有才識，深知地利，檄使從征，大破靈山縣及高、廉二州諸賊，歸所掠男女五千餘人，有金綺之賜。祚雖用兵，不樂以武節見。新興、新會間民多通盜，又東莞豪潘普倡亂，皆解散之，誅首惡而」已。滿六載，擢河南副使。尋致仕歸。

張畹
[
编辑
]

按《松江府志》：「畹字茂蘭，華亭人。景泰甲戌進士，除南京刑部主事。時旱饑，獄卒有食草死者，畹曰：『重囚尚給衣糧，卒何罪』？以囚飯通給囚卒，獄無枉死。陞四川僉事，會蜀盜授首，又仙泉、永通竈丁五千餘，盜官鹽吏，不可禁，眾議出兵，畹單騎至盜所，諭之曰：『汝等盜官物，法當贖，在為首者自詣理訴耳。渠首果出，餘悉』」杖遣之，眾感更生。分守建昌等六衛，清糧餉。舊額奪
於豪右者悉復之。番族數十年讎殺，悉聽辨理，漸復
華風。畹有軍功，輒不上，曰：「行陣之士出死力，吾儕忍分其功？」公論偉之。後忤執政意，致政歸，卒於家。

朱貞
[
编辑
]

按《江寧府志》：「貞字惟正，旗手衛籍。天順元年，知磁州。時中官取异魚，民為所苦，丞以下率避去。貞恐益累百姓，乃禱於河，魚涌至，境內以安，改鄧州。至即疏革陝西等處驛夫，與州民更番走遞，以甦土著。成化丙戌，襄盜起，軍興孔棘。將次鄧，貞夙戒諸生有幹局者分主供餉，士卒無敢以非禮加諸生，民賴以不擾。進」四川參議，督松潘儲。地故險遠，轉輸者多侵牟，甚則
逋逃以為常。貞勤以率下，飛輓有方，宿弊盡洗。且善
撫禦西羌，剽掠者不入境，黑虎寨恃頑不服，貞與總
戎計平之。事聞，行賞。貞以老乞休。貞性篤實，痛親早
逝，每享祀輒泣下。歸與里中士大夫為真率會，優游
十有五年而卒。

沈鍾
[
编辑
]

按《江寧府志》：「『鍾，字仲律，上元人。為諸生時，宿學舍，閉戶讀書，敝縕自甘。成天順庚辰進士，歸省父病侍踰年卒。居廬三年，未嘗言笑。服闋，授吏部主事。疏乞就養，改南禮部，俸資必跪奉其母。侍郎章綸嘗入賀，欲委之同列。鍾曰：『臣子事君，可與人較乎』？章揖謝。所友惟章楓山懋、羅彝正倫等，時稱十君子』。尋拜按察僉」事，考績擢副使，督學湖廣。時座主尹公旻秉政，當候
見。鍾問所居，李文正顧坐客曰：「今之不識相門者，仲律一人耳。」改督學山東，為諸生，改《五經》文。後子為楚
府儀賓，遂乞致仕。歸金陵無所栖息，毫不介意。平生
賦詩萬首，文字之外，世事無所聞。年八十，弟鎧舉成
化壬辰進士。

袁江
[
编辑
]

按《開封府志》：「江，字自岷，祥符人。讀書過目輒成誦。年十九，領天順壬午鄉薦，明年成進士，授戶部主事，監督徐州倉糧，出納嚴慎。時有中貴倚勢乾沒，奏斥之。歷兩淮鹽運使，規畫課程，次第疾徐，以至公行之，貴戚歛跡，商竈稱快焉。入覲，白塌巡檢某以金寶貯酒​中，曰：『此祕方藥酒也，可卻病』。」延年笞而遣之。巨商劉
武，錦衣舍餘也，暮夜懷黃金二錠為贐，叩首畢，拋金
速出，追還，叱卻之。擢四川右參政，督理糧儲，簡書嚴
重。抵蜀，巡行郡邑，滌祛奸弊，未歲餘，察出隱蔽官賦
及夙逋在民者若干萬。督屬徵完，盡解部。大司徒題
奏旌獎，以勵天下之職餉者。未幾，卒於官。江為人坦
易，以清慎自將。歷官三十年，典司財賦，無所點汙。年
僅下壽，用不究才，識者惜之。

袁凱
[
编辑
]

按《廣西通志》：「凱字舜舉，華亭人。天順間，以按察僉事治兵潯、梧。凱善兵，每督戰，身輒疾馳，為士卒先。賊屯長洲村，官兵遙望有懼色，凱麾兵前，賊驚引去。屬阻水還戰，諸兵奮擊，無不一當百，餘悉俘斬以歸。葉盛上其功，有中沮者，韓雍復以為言，乃超遷按察使。凱性簡質，不為人所喜，故僉事十年始遷。從按察，擢雲」南左布政使。未至，道卒。其在蒼梧，收已故上海人周
昇所遺男長壽，載之歸。及長，妻以甥女。里人莫不高
凱行誼。

甯良
[
编辑
]

按《祁陽縣志》：「良字元善。父嗣宗，應洪武庚午辟薦，歷上林長官司，撫綏有恩，邊境懷之。良生而爽愷，博雅能詩，登進士第，擢行人，積有歲年，以才猷遷刑曹。時天順復辟，曹石恃功驕橫，頗陷善類。良仁恕明敏，多所建白，曰：『主上意在省刑，我等頭顱可斷，官守不可移。誓不受權貴指使，細心挽救，所保全不少。大司寇』」深知良，以是久於西署，秩滿陞浙省大參政。良以吳
越名區，官其土者，視聽半在潮聲蜃氣間，期了公事。
我思兩浙人才淵藪，政當使潮海之文，拔起於濤山
浪屋，雷擊霆砰之外，以觀其吞天浴日之勢也。因試
觀風於別院，果於諸生中得謝遷、王華等，浙士大服。
轉廣東廉使，振揚風紀。尋遷歷浙江左右藩。均節賦
役，汰其浮羨，役以均平。謝、王相繼大魁，天下「知人」之
鑒歸焉。

林錦
[
编辑
]

按《明外史》本傳：「錦字彥章，連江人。景泰初，由鄉貢授合浦訓導。時徭寇充斥，內外無備，錦條具方略，悉中機宜。巡撫葉盛異之，檄署靈山縣事。時城毀於賊，錦因形便為柵以守，廣設戰具，賊不敢逼。滿秩去官，民曰：『公去，賊復至，誰當禦者』？悉逃之山。盛以狀聞。詔即以錦為知縣，馳驛之官。民聞之復來歸。適歲饑，諸猺」益肆剽掠無虛日。錦單騎詣壘，譬以禍福，猺感悟，附
縣二十五部咸聽命，其不服者則討之。天順六年破
賊羅禾水，再破之黃姜嶺，又大破之新莊。先後斬獲
千餘級，還所掠人口，賊悉平，乃去柵，築土城。盛及監
司屢薦其才。成化改元，會連州為賊所陷，乃以錦為
試知府。歲復大飢，賊四出劫掠。錦諭散千餘人，誅梗
化者，而綏輯其流移，境內悉平。四年，上官交薦，請改
授憲職，令耑備欽、廉群盜。乃以為按察僉事，益勤於
政。十年賜敕旌異。久之，進副使。錦以所部屢有盜警，
思為經久計。乃設團河營於西，設新寮營於南，而別
設洪崖營以杜諸寇出沒路。寇遂屏息。念靈山土城
不可久，更城之，高墉亙五百丈，卒為岩邑。十四年，兵
部上其撫輯功，被賚錦。前後雖在兵間，未嘗不以教
化為務。靈山尚鬼，則禁淫祠，修學校，勸農桑，治廉欽，
皆大飭學宮，振起文教。為人誠實，洞見肺腑，猺蠻莫
不愛信。其行軍，與士卒同甘苦，有功輒推以與人。以
故士多效死，所在祠祀之。

瞿俊
[
编辑
]

按《明外史》本傳：「俊字世用，常熟人，成化五年進士。由崇仁知縣召為御史。鄰縣祝獻知其貧，遺百金治裝，俊卻不納，益之。俊怒，欲執其吏，吏乃亟馳去。巡按廣西、雲南，所至持風紀，遷廣東按察副使。黎人故時出寇掠，俊戒約群吏，修軍政，遂讋服不敢出。常行，見市箒者，呼入分給諸僚，有一僚倍給之，問其故，曰：『君庭多穢耳』。」常暮至瓊州官舍，從官白：內有怪，夜半，光如
疋練起，庭樹上有聲。俊叱之即已。明旦伐樹，怪遂絕。
以給由赴部，道病還臥家。廣東巡按御史王哲上言：
「俊賢吏，不宜聽其休退。」竟不能起。所居敝陋，比舍皆
漁戶，時相從歡飲。每入郭，率晨候載菱小舟歸，仍附
之。善為詩酒，間可數百言。

劉俊
[
