《國公女生日席上命賦》
金·吳激
[
编辑
]

「雪射瑤階月，春回玉女扉。雲中三秀草，石上六銖衣。」酒熟鵝兒色，身輕燕子飛。客槎還汎斗，誰解卜搘機。

《烏夜啼》
宇文虛中
[
编辑
]

「汝琴莫作歸鳳鳴，汝曲莫裁《白鶴怨》。」明珠破璧掛高
城，上有烏啼人不見。堂中蠟炬紅生花，門前紺幰七
香車。博山夜長香爐冷，悠悠蕩子留倡家。妾機尚餘
​
數梭錦，織恨傳情還未忍。城烏為我盡情啼，知道單
棲淚盈枕。

《春愁曲》
高士談
[
编辑
]

壓花曉露萬珠冷，金井咿啞轉纖綆。寶階寂寂苔紋
深，東風搖碎湘簾影。芙蓉帳暖春眠重，窗外啼鶯喚
新夢。推枕起來嬌翠顰，一線沈煙困金鳳。游絲飛絮
俱悠颺，慵倚繡床春晝長，郎馬不嘶芳草暗，半篩急
雨飛橫塘。

《閱見八首》
邊元鼎
[
编辑
]

君居淄右妾河陽，平白相逢惹斷腸。蠟燭已殘歌欲
闋，并教離恨繞飛梁。

蕭史吹笙《鳳女臺》，月高霜冷鳳笙哀。不堪好酒沈沈
夜，又遣青鸞獨自來。

鳳紙銜封玉鏡臺，《繡鸞傳記》已相猜。傾城笑臉千金
樣，莫對閒人一例開。

笑裏低眉引醉波，《閬風》秋月一聲歌。明知畫燭無情
物，何事樽前淚更多。

笑不成歡歌斂眉，景陽鐘動酒闌時。此情卻羨《牽牛
會》，一歲相過可是遲。

牛女佳期歲一過，都緣迢遞隔銀河。可憐馬上香車
畔，只隔珠簾更不多。

雙鸞夾鏡鳳橫釵，捧額黃梅小鴈排。為報阿環休調
戲，雙成西母總相猜。

膩髮堆雲鏡舞鸞，五雲仙洞接清歡。歸來失卻吹簫
伴，腸斷崑山昨夜寒。

《閨情二首》
劉著
[
编辑
]

天邊北斗又回春，愁絕龍沙任酒醺。萬里巫山歸夢
斷，不知何處覓行雲。

蕙帳金爐冷篆煙，故山春草幾芊芊。只今惟有「瀟湘月，萬里相隨照不眠。」
《蘇州宴》
任詢
[
编辑
]

蘇州女兒嫩如水，髻聳花籠青鳳尾。十二紅裳釅梳
洗，植立唱歌煙霧裏。一人丰穠玉手指，袖挽翠雲彈
《綠綺》。落花一片天上來，隨人直渡西江水。曲終宴闋
歌一觴，行人南遊道路長。明日松江千萬頃，煙波雲
樹春茫茫。

《樓前曲》
劉迎
[
编辑
]

樓前山色秋橫碧，樓下水光秋漫白。眼看對此千里
愁，樓下長歌《古離別》。蕭蕭郎馬何時歸，鴈奴去作斜
行飛。灞橋過客夕陽遠，渭城行人朝雨微。玉淒花冷
令人瘦，日暮倚樓雙翠袖。蕙炷猶殘鸂𪆟香，麴塵半
著鴛鴦繡。五雲飛過芙蓉城，洞天冷落雲間笙。妾身
有願化春草，伴君長亭仍短亭。

《采蓮曲》
王庭筠
[
编辑
]

南北湖亭競采蓮，吳娃嬌小得人憐。臨行折得新荷
葉，卻障斜陽入畫船。

《無題》
毛麾
[
编辑
]

小顰對起石州山，楊柳分青入髻鬟。乍識春風眼如
鶻，為誰無語獨憑闌。

《擬回文》
蕭貢
[
编辑
]

萋萋碧草連天遠，杳杳行人幾日迴。淒雨晚涼空坐
久，淚妝殘暈濕紅腮。

《古意》
雷琯
[
编辑
]

美人傷獨宿，窈窕春閨深。素手卷翠被，當窗調玉琴。
危絃奏苦調，清歌抗哀音。絃絕歌復咽，起作《薄命吟》。
妾如朱槿花，含英愁晏陰。郎如青銅鏡，照面不照心。
不怨不照心，但惜飛光沈。且留連理枕，莫捲合歡衾。
儻君回餘輝，歡盟尚可尋。

《學古體》
侯冊
[
编辑
]

桐風吹月烏啼井，蟾波溼露沈雲影。素絲牽玉轉泉
華，美人睡覺燕支冷。銀鉤挂簾北窗曉，翠鬟臨鏡雙
鸞小。黃衫少年望不來，寂寂庭階滿春草。

《寄遠吟》
王鬱
[
编辑
]

一封征人書，秋帆瀟湘岸。當君高樓醉，憶妾《空閨歎》。

《倦繡》
李俊民
[
编辑
]

心情猶在未收時，卻顧花間影漸移。不道春來添幾
線，日長只與睡相宜。

《春望》
前人
[
编辑
]

半似羞人半忍寒，風和時拂玉闌干。門前不見歸軒
跡，強把花枝冷笑看。

《怨別》
前人
[
编辑
]

書來未報幾時還，終日昏昏醉夢間。別易會難長自
歎，不堪重過望夫山。

《西樓曲》
元·好問
[
编辑
]
