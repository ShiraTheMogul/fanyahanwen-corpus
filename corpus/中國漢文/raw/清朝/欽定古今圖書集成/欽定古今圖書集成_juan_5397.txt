趙延壽
[
编辑
]

按《遼史趙延壽傳》：「延壽本姓劉，恆山人。父邟，令蓨。梁開平初，劉守文陷蓨，其裨將趙得鈞獲延壽，養以為子。唐明宗先以女妻之，及即位，拜駙馬都尉，出為宣武軍節度使。清泰初，與其父俱降。會同初，晉人背盟，帝親征，延壽為先鋒，下貝州，授魏博等州節度使，封魏王，遷中京留守、大丞相。世宗即位，以翊戴功，授樞」密使。天祿二年薨。

趙思溫
[
编辑
]

按《遼史趙思溫傳》：「思溫字文美，盧龍人。隸燕帥劉仁恭幕。李存勖問罪於燕，思溫統偏師拒戰，為存勖所擒，授平州刺史。神冊二年，太祖遣大將經略燕地，思溫來降。及伐渤海，以思溫為漢軍都團練使，力戰，拔扶餘城。太宗即位，以功擢檢校太保，保靜軍節度使。天顯十一年，改南京留守，尋改臨海軍節度使。會同」二年卒。子延昭、延靖，官至使相。

趙安仁
[
编辑
]

按《遼史趙安仁傳》：「安仁字小喜，深州樂壽人。自幼被俘。統和中，為黃門令，秦晉國王府祗候。王薨，授內侍省押班御院通進。重熙初，授左承宣監門衛大將軍，充契丹、漢人、渤海內侍都知。後不知所終。」
趙徽

编辑

按《遼史趙徽傳》：「徽，南京人。重熙五年擢甲科，累遷大理正，歷繁劇，有能名，遷翰林學士承旨。咸雍初，為度支使。三年拜參知政事，出為武定軍節度使。後同知樞密院事，兼南府宰相門下侍郎平章事。致仕，卒諡文憲。」

趙廷美
[
编辑
]

按《宋史魏王廷美傳》，「廷美，字文化，太祖兄弟五人，兄光濟早亡，宋興，追封曹王；弟光贊幼亡，追封岐王。建隆元年，授廷美嘉州防禦使。太宗即位，加中書令，開封尹，封齊王。從征太原，進封秦王。七年，或告廷美有​陰謀，罷開封尹，授西京留守。會趙普再相，廉得盧多遜與廷美交通事，上怒，勒歸私第，降為涪陵縣公，房」州安置。雍熙元年卒，追封為涪王，諡曰悼。徽宗即位，
改封魏王。子十人：德恭、德隆、德彝、德雍，德鈞，德欽，德
潤、德文、德愿、德存。德鈞子承簡，襲封徐國公，諡和懿。
承簡既薨，德雍子承亮，襲封秦國公，奉廷美祀。薨，諡
恭靜，子克愉嗣。克愉卒，子叔牙嗣。德恭字復禮，封安
定郡侯，端拱元年進封郡公，景德初卒。子承慶、承壽。
承慶官至和州團練使。子六人：克繼，定武軍節度觀
察留後；承壽，終南作坊使。子四人，克己，終右千牛衛
大將軍。子叔韶，字君和，賜進士及第，終和州防禦使。
克修，字子莊，終成州團練使。子叔充，卒官唐州防禦
使。德隆，字日新，雍熙三年，卒，官沂州守。子承訓，官至
順州刺史，卒。德彝，字可久，封長寧郡侯，大中祥符八
年卒，諡安簡。子承謨，前卒。承矩，終莊宅使。承勗，至供
奉官。承範、承拱，並西京作坊使。承衎，內殿崇班。承錫，
供奉官。德雍，字仲達，終天平軍節度觀察留後。子承
睦、承亮。承睦終虔州觀察使。德鈞，字子正，至右監門
衛大將軍，卒。子承震，早卒。承緒，供奉官。承偉、承雅、承
裔、承鑑、承則，並西京作坊使。承裕，禮賓副使。承翊，內
殿崇班。承簡，襲徐國公。承幹，終懷州防禦使。子克敦，
以宣州觀察使卒。德欽，字丕從，右羽林將軍。子承遵，
西京作坊使。德潤，字溫玉，右羽林將軍。德文，字子矼，
慶曆四年，封東平郡王。六年薨，諡恭裕。子承顯，官至
昭化軍節度使，薨。德愿，字公謹，為左武衛大將軍，卒。
德存字安世，左羽林將軍。子承衍，禮賓副使。

趙贊
[
编辑
]

按《宋史趙贊傳》，「贊字元輔，本名美，後改焉，幽州薊人。祖德鈞，後唐盧龍節度。父延壽，忠武軍節度。贊幼聰慧，明宗甚愛之，賜童子及第。清泰末，晉祖起并門，德鈞父子降晉，契丹主盡錮之北去，贊獨與母留西洛。天福三年，晉祖命贊奉母歸薊門，契丹署為金吾將軍。開運末，延壽從契丹北歸，贊留鎮河中。漢祖起，贊」奉表勸進，入朝，即命為左驍衛上將軍。周世宗南征，
命為淮南道行營左廂排陣使。淮南平，以戰功多，授
保信軍節度。贊入視事，盡去苛政，務從寬簡，居民便
之。宋初，移忠正軍節度。開寶二年，為河東道行營都
虞候。四年，改鎮鄜州。太宗即位，進封衛國公。太平興
國二年，卒。

趙晁
[
编辑
]

按《宋史趙晁傳》：「晁，真定人。周祖鎮鄴中，晁委質麾下。周祖開國，轉作坊使。世宗嗣位，領賀州刺史。從征劉崇，轉虎捷右廂都指揮使。及征淮南，為緣江步軍都指揮使。壽春平，拜檢校太保，河陽三城節度。恭帝即位，加檢校太傅。宋初，加檢校大尉。未幾，以疾歸京師，卒。」

趙普
[
编辑
]

按《宋史趙普傳》：「普字則平，幽州薊人。父迴，徙常山，又徙河南洛陽。普沈厚寡言，太祖拔滁州，宰相范質奏為軍事判官。太祖受禪，以佐命功，授右諫議大夫。建隆三年，拜樞密使。乾德二年，以普為門下侍郎平章事。普為政頗專，廷臣多忌之。時官禁私販秦隴大木，普嘗遣親吏詣市屋材，吏因之竊鬻都下。又以隙地」私易尚食蔬圃，又營邸店規利。太祖怒，出為河陽三
城節度。太平興國初，入朝，頗為盧多遜所毀。會柴禹
錫等告秦王廷美將有陰謀，帝召問，普言「願備樞軸，以察姦變。」退又上書，自陳預聞顧託之事，辭甚切至。
太宗感悟，召拜司徒。八年，出為武勝軍節度，帝作詩
以餞之。雍熙四年，移山南東道節度使。表求入覲，冊
拜太保。上表求致仕，以為西京留守、河南尹。淳化三
年，拜太師，封魏國公。卒，諡忠獻。子承宗，羽林大將軍、
知潭、鄆二州，皆有聲。承煦，成州團練使。弟固安易，固
至都官郎中。

趙安易
[
编辑
]

按《宋史趙普傳》：「普弟安易，字季和，建隆初，攝府州錄事參軍，再遷河南府推官。會普居相位，十年不赴調。太平興國中，歷華、邢二鎮掌書記，部芻糧，至太原城下，拜監察御史。九年，拜宗正少卿，知定州，徙為通判，未幾代歸，歷知襄、廬二州，歸朝，復領卿職。安易略涉書傳，性強狠，好談世務，而疏闊不可用，景德二年卒。」子承慶，為國子博士，孫從政，為太常寺奉禮郎。

趙上交
[
编辑
]

按《宋史趙上交傳》：「上交，涿州范陽人。本名遠，避漢祖諱，以字稱。祖光鄴，鄂州錄事參軍。父簡章，涿州司馬。上交美風儀，善談論，南游洛陽，與中官馬紹宏善。紹宏領制置大使，表為判官。秦王從榮開府，以上交為虞部員外郎。從榮不遵禮法，好昵群小，上交從容言​之，從榮怒，出之。從榮及禍，僚屬皆坐斥，上交由是知」名。晉初，召為左司郎中，歷拜御史中丞，彈舉無所阿
避。周廣順初，拜禮部侍郎。顯德二年，拜吏部侍郎。多
請告不朝，時出游別墅，免官。宋初，起為尚書右丞，建
隆二年卒。

趙逢
[
编辑
]

按《宋史趙逢傳》，「逢字常夫，媯州懷戎人。父崇，事劉守光為牙校。漢乾祐中，逢求舉進士，擢登甲科，解褐授祕書郎、直史館。周廣順中，歷左拾遺、右補闕。世宗嗣位，遷禮部員外郎、史館修撰。宋初，拜中書舍人。太祖征澤潞，逢規避行役，貶房州司戶。乾德初，召赴闕，授都官郎中、知制誥。二年，改判昭文館。未幾，充樞密直」學士。蜀平，出知閬州，代還，遷給事中。開寶八年卒。子
極，為三班借職。

趙延進
[
编辑
]

按《宋史趙延進傳》，「延進，澶州頓丘人。父暉，周太子太師。延進頗親學。王景崇反，暉為都招討使擊之，延進屢當軍鋒，授鳳翔牙內指揮使。周世宗征淮南，召見，授右千牛衛將軍。宋初，遷右羽林軍將軍。太平興國中，大軍平并州，討幽薊，皆為攻城八作壕砦使。以功遷右監門衛大將軍，知鎮州，徙知相州，改知鄧州。淳」化初，還，判右金吾街杖事。咸平二年卒。延進姿狀秀
整，涉獵經史。子昂，太平興國二年，登進士第，至戶部
郎中、直昭文館。

趙孚
[
编辑
]

按《宋史趙安仁傳》：「安仁父孚，字大信，周顯德初，舉進士。乾德中為永寧令，民懷其惠，擢宗正丞。開寶中，初置衣庫，令孚主之，俄坐事連逮抵罪。太宗即位，為國子監丞，知袁州，召拜祕書丞，遷監察御史，出知舒州，改殿中侍御史。雍熙中卒。」
趙玭
[
编辑
]

按《宋史趙玭傳》：「玭，澶州人。家富於財。晉天福中，以納粟助邊用，補集賢小史，調濮州司戶參軍。會契丹構難，秦帥何重建獻地於蜀，孟知祥署高彥儔秦州節度，成為支郡，因署玭秦成階等州觀察判官。周顯德初，玭以城歸世宗，授郢州刺史，歷汝、密、澤三州刺史。建隆中，入為宗正卿。乾德初，出為秦州刺史。二年，改」左監門衛大將軍，判三司。玭狂躁悻直，多忤上旨，太
祖頗優容之。嘗廉得宰相趙普私市秦、隴大木事，潛
以奏白，然懼普知，因稱足疾，求解職。六年，詣闕納所
授告命，詔勒歸私第。踰年，伺普入朝馬前，揚言其短。
上聞之，召玭及普於便殿，面質其事，玭大言詆普。王
溥等奏玭誣罔大臣，上令御史鞫於殿庭，普為營救，
得寬其罰，黜為汝州牙校。太平興國三年，卒。

趙鄰幾
[
编辑
]

按《宋史趙鄰幾傳》：「鄰幾字亞之，鄆州須城人，家世為農。鄰幾少好學，能屬文。周顯德二年舉進士，解褐祕書省校書郎，歷許州、宋州從事。太平興國初，召為左贊善大夫，直史館，改宗正丞，遷左補闕，知制誥，數月卒。」
趙文度
[
编辑
]

按《宋史北漢世家》，「趙文度，薊州漁陽人。父玉，嘗客滄州，依節度判官呂兗。劉守光破滄州，收兗親屬盡戮之。兗子琦年十四，玉負之以逃，燕趙之士，翕然稱之。清泰中，琦為給事中、端明殿學士，玉已卒矣。文度入洛，舉進士，琦薦於主司，擢甲科，歷徐、兗、陳、許四鎮從事。漢初，為河東掌書記。文度捷給，善戲謔，劉崇雅愛」之。及稱帝，累官至門下侍郎。與郭無為不協，出知汾
州，徙嵐州。太祖開寶二年親征晉陽，文度請降，授檢
校太傅、安國軍節度。歲餘，徙華州，又徙耀州，卒。

趙延溥
[
编辑
]

按《宋史趙晁傳》：「晁子延溥，周顯德中以父任補左班殿直。宋初為鐵騎指揮使。太宗即位，遷散指揮都虞候，領思州刺史。從平太原，略地燕、薊。師還，遷內外馬步軍都軍頭，領本州防禦使。坐遣親吏市竹木，矯制免算，責授登州團練使。帝北巡，至大名，復以延溥為本州防禦使。雍熙二年，改蔚州觀察使，判冀州。會命」曹彬等北征，為幽州西北道行營都監。師還，命知貝
州，改滑州。四年，再知貝州，卒。子承彬，至內殿崇班。承
彬子咸一，為虞部員外郎、知宗正丞事。咸熙，天聖八
年，進士及第。

趙修己
[
编辑
]

按《宋史趙修己傳》：「修己，開封浚儀人，少精天文推步之學。晉天福中，李守真領滑州節制，表為司戶參軍，留門下。漢乾祐中，守真陰懷異志，修己屢以禍福諭之，不聽，遂辭疾歸鄉里。明年，守真叛，幕吏多伏誅，獨修己得免，朝廷知其能，召為翰林天文。周祖鎮鄴，奏參軍謀。會隱帝誅楊邠、史弘肇等，且將害周祖，修己」知天命所在，密與決渡河之計。即位，以為鴻臚少卿，
遷司天監。顯德中，累加檢校戶部尚書。宋初，遷太府
卿，判監事。建隆三年卒

趙德昭
[
