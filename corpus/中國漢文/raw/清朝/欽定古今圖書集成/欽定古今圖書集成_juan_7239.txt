编辑

按《嘉興府志》：「林雨天性慷慨，鄰多藉以舉火，弟病痰，悉以產讓之。其族父無歸者，咸為割產析居。博物洽聞，由明經授溧水博士，遷代府教授。」馮敏功
[
编辑
]

按《嘉興府志》：「馮敏功，字忠卿，七舉不第，杜門著書。父諫議汝弼，素敦族誼，功推其意，置義屋義田。至於施棺藥，賑粟帛，捐金不恡。嘗渡江，中流颶作，舟幾覆，賦詩自若。」李琡
[
编辑
]

按《嘉興府志》：「李琡，字仲素。早歲嗜學，聲稱籍甚。事父母愉色婉容，兄弟無間言。尤慷慨好施，值歲祲穀貴，首發粟賑貸，里黨效之，全活甚眾。貧不能葬者葬之，鰥寡不獲養者養之，戚族賴以舉火，間有橫逆相加，不與之較。舉鄉飲賓。年八十二卒。」周萃
[
编辑
]

按《寧波府志》：「周萃，號水心，負性伉直，時為人解紛排難，事有不平，一言即決。嘗晨入郡城，拾金一囊，中有賦牒，亟跡其人還之。弟兄三人友愛無間，遺命同墳而葬。子任，字子重，樸素儒雅，類其父。中年棄諸生，受子應賓封，布衣蔬食，不改其舊。年七十三卒。兩世皆以應賓貴，贈吏部右侍郎。」李樸
[
编辑
]

按《寧波府志》：「李樸，字質夫，為諸生，好學有文行，善事祖父母。常赴溫州臬司招，道遇老婦遠為子訟冤者，憫之，讓所乘舟，與婦徒步百里抵溫，力白其誣而脫之。初艱於嗣，以兩弟未娶，義不置妾。年五十，舉一子尚默，乃嫡出也。年踰八十卒。以子貴，贈監察御史。」===張忭===
​
按《寧波府志》：「張忭，字汝懷。父緒，以忠厚待物，有故傭歲盜其米粟及諸所藏物。一日，忽自憶曰：『盜入而厖不吠，且不盡其藏，宜非生盜也』。乃潛跡傭家，得其物，不發而歸。兄子早孤，字而婚之，析產與己子均。忭，其季子也。生而溫恭顓愨，與族黨處，無少長貴賤，一接以禮。每廣坐群譁，獨斂容正色，恬不為動。人有爭鬥」，
婉言譬之，咸唯唯而解。聚族子弟教肄之，因才飭迪，
使各知義方。臨取予，必捐己以裕人。中夜或聞父母
咳唾，雖盛寒，必攝衣往省。比卒，家貧，躬負築以葬。家
殖日落，敝衣蔬食，居之裕如，於世物絕無所好。日與
其子嚴課誦，督責靡少假。比子時徹貴顯，澹薄如故，
足跡不干有司。後屢受封贈，至兵部侍郎。

范億
[
编辑
]

按《寧波府志》：「范億，字懷素。七歲，父客死於贑，母楊撫之，煢煢相倚。年十五，喟然請迎父骸，遂赴贑流，棺纍纍弗能識。夜夢父慰之曰：『我安茲土，慎勿遷』。乃慟哭而還。途遇一人授之醫，遂行其術。尤善攻瘧痢，所予藥，貧者弗責直，愈者弗祈報。嘗見逋糧者，械繫過門，憫之，代為輸。有以訟致鬻妻，得三十金，令還其金，如」數予之，婦得留，迎養外父母，經紀其後事，撫育姊子
三人，咸授之室。善行多類此。

高𦒎
[
编辑
]

按《寧波府志》：「高𦒎，字長倩，號玉陽，以諸生補國子員，好學能文，例授光祿寺署丞。以子斗樞貴，累封至副都御史。好行其德，歲饑，首倡捐賑之法，隨地煮糜，全活甚眾。有盜鬻其產者，願以女償，折券叱之，仍恐其他鬻，今呼其婿歸之。他若周親睦族，養老恤孤，無不備至。性不問財帛，雖處勢重，甘守儉素，絕意干謁。居」恆盛暑必衣冠溫和謙下，未嘗有貴盛態。待臧獲亦
必以禮，縉紳士庶無不推為長者。七舉鄉飲大賓，其
子在官，嘗勉以忠義，至署不令取一物，卒為廉吏。流
寇圍鄖陽十年，始得歸侍。父子鵠髮相隨，里人榮之，
以為「盛德之報。」卒年八十有八。

孫志達
[
编辑
]

按《寧波府志》：「孫志達，字兼甫，雪窗裔也。生有異表，不類凡兒。七歲就外傅，師事姚賡虞。姚故博學通儒，見志達穎悟，盡出其業授之。弱冠從鄭南凡游，質重端嚴。鄭館其家二載，未嘗見其忿怒歎曰：『吾學顏子，半生日覺泮渙，今心折於子矣』。祖父早喪，奉兩世嫠母，備極孝養。性好周急，冬月命家人紉舊綿，綴鶉衣，熱」饘粥以給凍餒。有故人負債遭辱，志達謀諸婦，捐簪
珥代償焉。減糧收佃，增量貸人，人咸德之。喜延接英
雋，遇文行之士，必設酒脯，極歡而去。或談及名利，則
不悅也。嘗曰：「子弟當令志氣遠大，一涉名利，便非豪傑。」晚年家益貧，處之怡然。居恆恂恂，和氣溢於眉宇，
鄉黨稱為善人。子簬，別有傳。

秦垠
〈子鐸〉
[
编辑
]

按《寧波府志》：「秦垠，字汝際，少學舉業，一試不偶，輒棄去，隱於耕。性端方，寡言笑，持論侃侃，雖宗老文人，見之凜如。每宗祠燕享，垠在坐，眾皆拱默。他日鄰媼聞讙語，輒詫曰：『秦君不在耶？何嘈嘈耶』？其信于宗黨如此。父病，雪夜獨行訪醫藥，虎伏道左，不知也。有弟頗傲，愈憐愛之，無幾微見詞色，人服其孝友。子鐸，以明」經教授里中，學者稱為道鳴先生。幼失恃，事繼母以
孝聞。生而嗜學，《六經》子史諸書無不手自銓纂。嘗客
檇李某氏家塾，偶犬銜刺繡履墮床下，主見之，疑其
妻有私，恚甚，手利刃，夜挾妻潛叩門，門啟，將殺之，妻
亦無以解也，慨然請行。鐸詈曰：「安得婦女聲至此？」急
呼取火，主皇遽去。旦日詰之，但唯唯謝罪。已，問知其
故，即日去，終其身不遠遊。垠季子鈁，登進士，別有傳。

鄔振英

编辑

按《寧波府志》：「鄔振英，字君瑜。好讀書，聞子姪咿唔聲輒喜。事親至孝，兄早沒，總家二十年不治。私奉嫠嫂，訓諸孤，情義交至。性好施予，有求輒應。子鑑明、銓明相繼領鄉薦。」俞有良
[
编辑
]

按《寧波府志》：「俞有良，字慕池。存心坦易，人有過容之，絕不與較。家居不甚富，而人有求者，輒與之，不責其償。至義所不當受，雖一縷一錢若浼焉。中年喪偶，遂終身不娶。人或勸之續，則曰：『吾有二子，可免不孝之罪，何復娶也？惟留心耕讀，課子督孫。享年八十卒。孫廷瑞，登進士第』。」俞學禮
[
编辑
]

按《寧波府志》：「俞學禮，字朝會，孝友性植。十歲失母，哀毀無間。善事父，扇枕飽蚊，一軌於度。為邑諸生，誦讀之餘，兼躬耕稼穡，生養終送，竭力盡禮，制行端方。有鄉人貸穀若干石者，往取償，其婦艾邀入室，具酒食，詰其夫，則已外出矣，即正色拒之，焚券趨歸。家世分居縣東西街，有族子為盜所扳，官捕之急，連宗老，欲」繫之庭。宗老固東族，而罹法者西族人也。因慨然曰：
「余族子弟事，奚可以累他人？」對隸卒曰：「宗老吾是，彼​固無與也。」邑令聞，嘆其賢，竟不問。生平以忍耐勝人，
犯而不校。律躬儉勤，而歲時薦享則必致腆潔。生二
子，長食餼，次成進士。終以儒素自安。論者謂嗇取類
狷，容受類柔，任真類朴，約能守滿能持誠。《實錄》云：「卒年六十六。」邵招賢
[
编辑
]

按《寧波府志》：「邵招賢，字文達，奉父母至孝，食必具甘旨。性醇謹，閭里有不平事，多往質之，片言而解。一夕，盜踰垣入，家人捕得之，招賢與之酒，諭令改行，盜悔謝去，卒為良民。後以子景堯貴受封。」杜常
[
编辑
]

按《寧波府志》：「杜常，字守經，孝友天至，逮事王父母，極誠共奉，而竭力窀穸之事，即其父亦不知費所由辦也。有弟三人，悉推世業與之，獨肩養生送死諸務。平生不妄言笑，不輕與人交。御家莊而有禮，女婦皆勤治蠶織饋餉事，戶庭之內，肅不聞聲。子姓稍踰禮節，即疏遠亦撻之。每與人言惓惓，以慈孝仁讓為勗。他」家有相爭隙者，必自悔曰：「杜長公得無非乎？」初為奉
化功曹，同曹掾有患痢疫者，眾徙以避。常曰：「夫同舍中兄弟也，急乃棄之乎？」躬親湯藥，或竟夕不還。其人
有妾而弗避也，眾頗疑之。每常往，必與其僕偕，明燭
達旦，久之，人始服其至誠云。後移役蘭谿，道拾遺金，
往跡其人而還之。其人以十金謝，固辭不受。蘭谿章
文毅公懋深器重之，謂客曰：「此其人素行合於聖賢，非可以掾吏小之。」已而授廣西龍江驛丞。有以毒藤
自殺者，誣冤家殺之，郡守具獄上，當死，司憲移常覆
訊，乃出之。守惡其反而笞之，常曰：「吁嗟天乎！辯冤而死可矣，笞何憾耶？」後征蠻事起，臺憲檄之督兵，以此
嬰疾，卒于邸舍。

劉津
[
编辑
]

按《寧波府志》：「劉津母孫氏，以遺腹得之。津事母，先意承志，終身不令母有慍色。讀書晝夜不輟，遂成鴻儒。平生操行不苟，一日負米而舂，鄰嫗憐其不勝，欲為佐舂，津亟引避，其戒嚴于納履如此。苕中嚴氏延為塾師，欽其師範。將歸，于脩脯外溢數遺之。度其性介，潛納行李以歸。歸而得金，立趣蒼頭返之。以布衣疏」聞母節，奉旨旌表，名重諸紳。子廷寅亦純孝，事嫡母
曲盡子道，卒令嫡母忘非己出，蜚聲膠庠，戶屨常滿。
有《贊化集》《素隱編》《詩經發蒙》諸書。以子憲寵貴，津、廷
寅俱贈如其官。

陳文誼
[
编辑
]

按《寧波府志》：「陳文誼，字明卿，倜儻不群，數奇弗偶。已援例禮部，列儒士高等。天性孝友，惓惓以母嫠弟幼，弗忍離膝下。拮据甘旨外，一意課弟。文謨，卒成進士。遂躍然起曰：『吾母已得祿養，而吾鄉未得安枕，奈何』？遂偕生員洪應乾等詣闕，疏便民五事。朝議允其三：一准糧輸定海，一蠲各縣借端；一定守城兵餉。當事」勒石紀之，至今永賴。

虞一稷
[
编辑
]

按《寧波府志》：「虞一稷，字仲參。天性淳樸，以力田致豐饒。值歲饑，里人多藉之以給朝夕。壽終於家，遺命訓長子二球，諄諄以學宮傾圮為念。其後二球督學江南歸，因修葺而更新之，遵先志也。以子貴，封如其官，崇祀鄉賢。」楊忠
[
编辑
]

按《寧波府志》：「楊忠，戴獻可之僕。戴氏世雄于財，獻可子伯簡，方弱冠，與里中惡少遊，盡破其家，惟昌國魚鹽竹木之利，為忠所主，得存，伯簡往依焉。忠籍其貲以獻，伯簡大喜，謂我固有之物，恣雎如故。忠哭諫不聽。一日，伯簡與其徒會飲呼蒱，忠挺刃而前，執其尢者，捽首頓之地，數曰：『我事主人三十年，郎君年少，爾輩誘為不善，家產掃地。幸我保此別業，汝必欲使靡有孑遺邪？我斷汝首，告官請死，報主人于地下』。」其人
哀號伏罪。忠噤齗良久，收刃卻立，曰：「如此，貸爾命。」遂
出綵帛曰：「可負此，亟去。」其人疾走，忠揮淚謝罪曰：「老奴驚犯郎君請，今改前所為，但聽老奴不二三年，舊業可復也。若再與此輩游，老奴當焚資自沈于海，不忍見郎君餓死，貽主人門戶羞也。」伯簡慚泣，自是謝
絕不往，一聽忠所為。三年，果盡復田宅，忠事之彌謹
焉。

方德初
[
编辑
]

按《寧波府志》：「方德初，字孟仁。四世百口共炊。子二人，從子十一人，以其貲產均分之，凶年為粥以食餓者。鄰人鄭氏家貧，鬻女為人婢，德初贖還之。其自奉甚薄，而性樂施予多如此。與弟德全並美。德初年八十八，德全年九十九卒。」姚瀾
[
编辑
]

按《寧波府志》：「姚瀾，字維觀，起家衛掾，歷廣東九峰巡宰。時從父鏌總制兩廣，瀾深自斂飭，絕無借炫。家居守身畏法，急人之難，不辭艱險。衣冠揖讓，訓子弟惟謹。嘗山行，眾方逐虎，虎突出左右，眾驚逸，瀾惟見一​僧，不知為虎。又夜行谷中，思得一伴。俄一人至，相從二十里，近郭忽不見。邑人張憲使謙嘗有文贈之云：『虎為之寢形，鬼為之引導』。」年八十九卒。

王汝林
[
编辑
