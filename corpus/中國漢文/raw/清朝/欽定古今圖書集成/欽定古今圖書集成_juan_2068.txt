江上泛歌　　　　　　　　晉夏侯湛
[
编辑
]

悠悠兮遠征，倏倏兮暨南荊。南荊兮臨長江，臨長江
兮討不庭。江水兮浩浩。長流兮萬里，洪浪兮雲轉。陽
侯兮奔起。驚翼兮垂天，鯨魚兮岳峙。蘼蕪紛兮被皋
陸，修竹鬱兮翳崖趾。望江之南兮遨目桂林，桂林蓊
鬱兮鶤雞揚音。凌波兮願濟，舟楫不具兮江水深沈。
嗟迴盼于北夏，何歸軫之難尋。

登江中孤嶼　　　　　　　宋謝靈運
[
编辑
]

江南倦歷覽，江北曠周旋。懷新道轉迥，尋異景不延。
亂流趨正絕，孤嶼媚中川。雲日相輝映，空水共澄鮮。
表靈物莫賞，蘊真誰為傳。想像崑山姿，緬邈區中緣。
始信《安期》術，得盡養生年。

之宣城郡出新林浦向板橋　　齊謝朓
[
编辑
]

江路西南永，歸流東北騖。天際識歸舟，雲中辨江樹。
旅思倦搖搖，孤遊昔已屢。既歡懷祿情，復協滄洲趣。
囂塵自茲隔，賞心於此遇。雖無元豹姿，終隱南山霧。

江皋曲　　　　　　　　　　　王融
[
编辑
]

「林斷山更續，岸盡江復開。」雲峰帝鄉起，水源桐柏來。

泛舟橫大江　　　　　　　梁簡文帝
[
编辑
]

滄波白日暉，遊子出王畿。旁望重山轉，前觀遠帆稀。
廣水浮雲吹，江風引夜衣。旅鴈同洲宿，寒鳧夾浦飛。
行客誰多病，當念早旋歸。

新安江水至清淺深見底貽京邑遊好
[
编辑
]

沈約

眷言方舟客，茲川信可珍。洞澈隨清淺，皎鏡無冬春。
千尋寫喬樹，百丈見游鱗。滄浪有時濁，清濟涸無津。
豈若乘斯去，俯映石磷磷。紛吾隔囂滓，寧假濯衣巾。
願以潺湲水，霑君纓上塵。

泛永康江　　　　　　　　　　前人
[
编辑
]

長枝萌紫葉，清源泛綠苔。山光浮水至，春色犯寒來。
臨睨信永矣，望美曖悠哉。寄言幽閨妾，羅袖勿空裁。

江上酬鮑幾　　　　　　　　　吳均
[
编辑
]

振棹出江湄，依依望九嶷。欲謁蒼梧帝，過問沅湘姬。
折荷縫作蓋，落羽紡成絲。吾行別有意，不為君道之。

初發新林　　　　　　　　　　何遜
[
编辑
]

伊昔負薪暇，慕義遊梁楚。短翮忘連翩，追飛散容與。
優游沐道教，漸漬淹寒暑。大德本無酬，輕生竊自許。
舟歸屬海運，風積如鵬舉。浮水暗舟艫，合岸喧徒侶。
凜凜窮秋暮，初寒入洲渚。鐃吹響清江，懸旗出長嶼。
危檣迥不進，㳫浪高難拒。回首泣親賓，中天望宛許。
帝城猶隱約，家國無處所。去矣方悠悠，含意將誰語。

江行　　　　　　　　　　　　江洪
[
编辑
]

日沒風光靜，遠山清無雲。潮落晚洲出，浪罷沙成文。
挾琴上高岸，望月彈明君。「去家未千里，斷絕怨《離群》。」
奉和泛江　　　　　　　　　王臺卿
[
编辑

春江下白帝，畫舸向黃牛。錦纜迴沙磧，蘭橈避荻洲。
「濕花隨水泛，空巢逐樹流。建平船柹下，荊門戰艦浮。岸社多喬木，山城足迥樓。日落江風靜，龍吟迴上游。」

[
编辑

高軒臨不測，清江窮廣深。天邊生岸影，水上結雲陰。
風來白華起，潮滿黃沙沉。

[
编辑

编辑

奉和晚日揚子江應制　　　　　柳𧦪
[
编辑
]

詰旦金鐃發，驂駕出城闉。鮮雲臨葆蓋，細草藉班輪。
千里煙霞色，四望江山春。梅風吹落蕊，酒雨減輕塵。
日斜歡未畢，睿想良非一。風生疊浪起，霧卷孤帆出。
掞藻麗繁星，高論光朝日。空美鄒枚侶，終謝淵雲筆。

奉和晚日揚子江應教　　　　　前人
[
编辑

未睹纖羅動，先聽遠濤聲。空濛雲色晦，浹疊浪華生。
欲知暮雨歇，當觀飛斾輕。

编辑

编辑

入蜀秋夜宿江渚　　　　　　陳子良
[
编辑

我行逢日暮，弭棹獨維舟。水霧一邊起，風林兩岸秋。

编辑

[
编辑

天晴上初日，春水送孤舟。山遠疑無樹，潮平似不流。
岸花開且落，江鳥沒還浮。羈望傷千里，長歌遣《四愁》。

[
编辑

江林皆秀發，雲日復相鮮。征路那逢此，春心益渺然。
興來祇自得，佳處莫能傳。薄暮津亭下，餘花落客船。

[
编辑

浦樹遙如待，江鷗送若迎。津途別有趣，況乃濯吾纓。

编辑

「長林何繚繞，遠水復悠悠。盡日餘無見，為心那不愁。」憶將親愛別，行為主恩酬。感激空如此，芳時屢已遒。

望水知柔性，看山欲斷魂。縱情猶未已，迴馬欲黃昏。

编辑

岸花明水樹，川鳥亂沙洲。羈眺窮千里，勞歌動四愁。

编辑

湍似黃牛去，濤如白馬來。英靈已傑出，誰識卿雲才。

行背青山郭。吟當白露秋。風流無屈宋。空詠古《荊州》。

六

晚來漁父喜，罾重欲收遲。恐有長江使，金錢願贖龜。

七

去指龍沙路，徒懸象闕心。夜涼無遠夢，不為偶聞砧。

八

霽雲疏有葉，雨浪細無花。穩放扁舟去，江天自有涯。

九

好日當秋半，層波動旅腸。已行千里外，誰與共秋光。

十

潤色非東里，官曹更建章。宦遊難自定，來喚櫂船郎。

十一

夜江清未曉，徒惜月光沈。不是因行樂，堪傷老大心。

十二

「翳日多喬木，維舟取束薪。」靜聽江叟語，俱是厭兵人。

十三

箭漏日初短，汀煙草未衰。雨餘雖更綠，不是采蘋時。

十四

山雨夜來漲，喜魚跳滿江。岸沙平欲盡，垂蓼入船窗。

十五

渚邊新雁下，舟上獨凄涼。俱是南來客，憐君綴一行。

十六

牽路沿江狹，沙崩岸不平。盡知行處險，誰肯載時輕。

十七

雲密連江暗，風斜著物鳴。一杯真戰將，笑爾作愁兵。

十八

柳拂斜開路，籬邊數戶村。可能還有意，不掩向江門。

十九

不識桓公渴，徒吟《子美詩》。「江清唯獨看，心外更誰知。」
二十

憔悴異《靈均》，非讒作逐臣。如逢「《漁父問》，未是獨醒人。」
二十一

水涵秋色靜，雲帶夕陽高。詩癖非吾病，何妨吮短毫。

二十二

登舟非古岸，還似阻西陵。箕伯無多少，回頭詎不能。

二十三

帆翅初張處，雲鵬怒翼同。莫愁千里路，自有到來風。

二十四

秋雲久無雨，江燕社猶飛。卻笑舟中客，今年未得歸。

二十五

佳節雖逢菊，浮生正似萍。故山何處望，荒岸小長亭。

二十六

行到楚江岸。蒼茫人正迷。祇知秦塞遠。格磔《鷓鴣啼》。

二十七

月下江流靜，村荒人語稀。鷺鷥雖有伴，仍共影雙飛。

二十八

斗轉月未落，舟行夜已深。有村知不遠，風便數聲砧。

二十九

櫂驚沙鳥迅，飛濺夕陽波。不顧魚多處，應防一目羅。

三十

漸覺江天遠，難逢故國書。可能無往事，空食鼎中魚。

三十一

岸草連荒色，村聲樂稔年。晚晴初穫稻，閑卻採蓮船。

三十二

灘淺爭遊鷺，江清易見魚。怪來吟未足，秋物欠《紅蕖》。

三十三

蛩響依莎草，螢飛透水煙。夜涼誰詠史，空泊運租船。

三十四

睡穩葉舟輕，風微浪不驚。任君蘆葦岸，終夜動「秋聲。」
三十五

自念平生意，曾期一郡符。豈知因謫宦，斑鬢入江湖。

三十六

煙渚復煙渚，畫屏休畫屏。引愁天末去，數點暮山青。

三十七

水天涼夜月，不是惜清光。好物隨人祕，秦淮憶建康。

三十八

古來多思客，搖落恨江潭。今日秋風至，蕭疏獨沔南。

三十九

暎竹疑村好，穿蘆覺渚幽。漸安無曠土，薑芋當農收
​

四十

秋風動客心，寂寂不成吟。飛上危檣立，啼烏報好音。

四十一

見底高秋水，開懷萬里天。旅吟還有伴，沙柳數枝蟬。

四十二

「九日自佳節，扁舟無一杯。」「曹園舊尊酒，戲馬憶高臺。」
四十三

兵火有餘燼，貧村纔數家。無人爭曉渡，殘月下寒沙。

四十四

渚禽菱芡足，不向稻粱爭。靜宿涼灣月，應無失侶聲。

四十五

輕雲未護霜，樹杪橘初黃。信是知名物，微風過水香。

四十六

渺渺望天涯，清漣浸赤霞。難逢星漢使，烏鵲日乘槎。

四十七

「土曠深耕少，江平遠釣多。」生平皆棄本，金革竟如何。

四十八

「海月非常物，等閑不可尋。」披沙應有地，淺處定無金。

四十九

風晚冷颼颼，蘆花已白頭。舊來《紅葉寺》，堪憶《玉京秋》。

五十

風好來無陣，雲閒去有蹤。釣歌無遠近。應喜罷《艨艟》。

五十一

吳疆連楚甸，楚俗異吳鄉。漫把尊中物，無人啄蟹筐。

五十二

岸綠野煙遠，江紅斜照微。撐開小漁艇，應到月明歸。

五十三

雨餘江始漲，漾漾見流薪。曾歎河中木，斯言憶古人。

五十四

葉舟維夏口，煙野獨行時。不見《頭陀寺》，空懷《幼婦碑》。

五十五

晚泊武昌岸，津亭疏柳風。數株曾手植，好事憶陶公。

五十六

墜露曉猶濃，秋花不易逢。涉江雖已晚，高樹搴芙蓉。

五十七

舟航依浦定，星斗滿江寒。若比陰霾日，何妨夜未闌。

五十八

近戍離金落，孤岑望火門。唯將知命意，瀟灑向「乾坤。」
五十九

叢菊生堤上，此花長後時。有人還採掇，何必在春期。

六十

夕景殘霞落，秋寒細雨晴。短纓何用濯，舟在月中行。

六十一

堤壞漏江水，地坳成野塘。晚荷人不折，留取作《秋香》。

六十二

左宦終何路，攄懷亦自寬。襞牋嘲「白鷺」，無意喻梟鸞。

六十三

樓空人不歸，雲似去時衣。黃鶴無心下，長應笑令威。

六十四

「白帝朝驚浪，潯陽暮暎雲。」等閑生險易，世路祇如君。

六十五

櫓慢開輕浪，帆虛帶白雲。客船雖狹小，容得庾將軍。

六十六

風雨正甘寢，雲霓忽晚晴。放歌雖自遣，一歲又崢嶸。

六十七

靜看秋江水，風微浪漸平。人間馳競處，塵土自波成。

六十八

風勁帆方疾。風回櫂卻遲。較量人世事。不校一毫釐。

六十九

咫尺愁風雨，匡廬不可登。祇疑雲霧窟，猶有六朝僧。

七十

幽思正遲遲，沙邊濯弄時。自憐非博物，猶未識鳧葵。

七十一

曾有煙波客，能歌《西塞山》。落帆唯待月，一釣紫菱灣。

七十二

千頃水紋細，一拳嵐影孤。君山寒樹綠，曾過洞庭湖。

七十三

光闊重湖水，低斜遠雁行。未曾無興詠，多謝沈東陽。

七十四

晚菊繞江壘，忽如開古屏。莫言時節過，白日有餘馨。

七十五

秋寒鷹隼健，逐雀下雲空。知是江湖闊，無心擊塞鴻。

七十六

日落長亭晚，山門步障青。可憐無酒分，處處有「旗亭。」
七十七

江草何多思，冬青尚滿洲。誰能驚鵬鳥，作賦為沙鷗。

七十八

遠岸無行樹，經霜有半紅。停船搜好句，題葉贈江楓。

七十九

身世比行舟，無風亦暫休。敢言終破浪，唯願穩乘流。

八十
​
數畝蒼苔石，煙濛鶴卵洲。定因詞客遇，名字始風流。

八十一

興閑停桂楫，路好過松門。不負佳山水，還開酒一尊。

八十二

幽懷念煙水，長恨隔龍沙。今日《滕王閣》，分明見落霞。

八十三

短楫休敲桂，孤根自駐萍。自憐非劍氣，空向斗牛星。

八十四

「江流何渺渺，懷古獨依依。」漁父非賢者，蘆中但有磯。

八十五

「高浪如銀屋，江風一發時。」筆端降《太白》，才大語終奇。

八十六

細竹漁家路，晴陽看結繒。喜來邀客坐，分與折腰菱。

八十七

幸有煙波興，寧辭筆硯勞。緣情無怨刺，卻似反《離騷》。

八十八

《平湖五百里》，江水想通波。不奈扁舟去，其如決計何。

八十九

數峰雲斷處，去岸暎高山。身到韋江日，猶應未得閑。

九十

「一灣斜照水，三版順風船。」未敢相邀約，勞生祇自憐。

九十一

江雨正霏微，江村晚渡稀。何曾放釣艇，更待得魚歸。

九十二

沙上獨行時，高吟到《楚詞》。難將垂岸蓼，盈把當江蘺。

九十三

新野舊樓名，潯陽勝賞情。照人長一色，江月共淒清。

九十四

「願飲西江水，那吟《北渚》愁。」莫教留滯跡，遠比蔡昭侯。

九十五

湖口分江水，東流獨有情。當時好風物，誰伴謝宣城。

九十六

潯陽江畔菊，應似古來秋。為問幽棲客，吟時得酒不。

九十七

高峰有佳號，千尺倚寒松。若使鑪煙在，猶應為上公。

九十八

萬木已清霜，江邊村事忙。故溪黃稻熟，一夜夢中香。

九十九

楚水苦縈迴，征帆落又開。可緣非直路，卻有好風來。
