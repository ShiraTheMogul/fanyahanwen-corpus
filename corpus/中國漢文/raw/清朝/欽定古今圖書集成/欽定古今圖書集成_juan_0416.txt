禽蟲典第九十六卷

馬部藝文五
〈詩〉
[
编辑
]

《大宛二馬》
元·郝經
[
编辑
]

二馬飄飄萬里來，玉花蕭颯上金臺。風生兩耳雲霄
近，電掣雙瞳日月開。渥水虎文連朔氣，《大宛》龍種絕
氛埃。將軍正欲成勳業，看汝驍騰展驥才。

《老馬》
前人
[
编辑
]

百戰歸來力不任，消磨神駿老駸駸。垂頭自惜千金
骨，伏櫪仍存萬里心。歲月淹延官路杳，風塵荏苒塞
垣深。短歌聲斷銀壺缺，常記當年《烈士吟》。

《御驃出廐圖》
王惲
[
编辑
]

「何人拂絹素，寫此房駟精。」一馬老伏櫪，志在千里行。
二馬騁踶齧，角壯猶龍騰。一馬方滾塵，海岸翻鯤鯨。
畫師慘淡意，落筆矜多能。我觀寓所感，國制貴有經。
唐人重馬政，分屯列郊坰。當時百萬匹，肅肅羅天兵。
東封與西蕩，歲用不可勝。嗣王獵其餘，尚足開中興。
乃知三軍本，匪馬將奚憑。《聖經》說備豫，萬古為世程。
倉卒事亦辦，未免眾目驚。我思立仗間，振鬣伸長鳴。
所言固芻蕘，聖經其可輕。

《戲題出洗馬》
趙孟頫
[
编辑
]

《齧膝》覂駕雖能御，駑蹇紛紛何足顧。青絲絡首錦障
泥，鞭箠空勞怨長路。明窗戲寫《乘黃姿》，洗刷歸來氣
如怒。不須對此苦嘆嗟，男兒自昔多徒步。

《鞭馬圖》
袁桷
[
编辑
]

生駒萬里意，所向知無前。圉人忌其德，未試先加鞭。
要令俛首馴，使我常相憐。伯樂去已久，此道不復傳。
駕車困泥途，伏櫪老歲年。所用非所養，誰能別媸妍。
畫師逐時好，謂爾誠當然。披圖重嘆嗟，我意何由宣。

《裝馬曲》
前人
[
编辑
]

綵絲絡頭百寶裝，猩血入纓火齊光。鍚鈴交驅八風
轉，東西夾翼雙龍岡。伏日翠裘不知重，珠帽齊肩顫
金鳳。絳闕蔥曨旭日初，逐電迴飆斗光動。寶刀羽箭
鳴玲瓏，雁翅卻立朝重瞳。沈沈棕殿雲五色，法曲初
奏歌《薰風》。酮官庭前列千斛，萬甕葡萄凝紫玉。駝峰
熊掌翠釜珍，碧實冰盤行陸續。須臾玉巵黃帕覆，寶
訓傳宣爭頫首。黑河夜渡辛苦多，畫戟雕閎總勳舊。
龍媒嘶風日將暮。宛轉琵琶前起舞。鳴鞭靜蹕宮門
閉，長跪齊聲呼《萬歲》。

《子昂逸馬圖》
前人
[
编辑
]

神駿飄飄得自閒，天池飛躍下塵寰。青絲絡首誰收
得，留與春風十二閑。

《神馬歌次韻陳元之》
楊載
[
编辑
]

《神馬來自崑》。崘西，有足未始行沙泥。朝趨欲出飛鳥
上，夕逝直與奔星齊。綠鬃半散插雙耳，赤汗交流攢
四蹄。風神秀猛陿天地，豈顧燕蔡并渠黎。時時牽浴
臨清谿，對人誇煞黃鬃奚。玉山之禾中芻秣，不嚙堤
頭枯草稊。與君側耳聽長嘶，凡馬不聞生駃騠。

《曹將軍下槽馬圖》
揭傒斯
[
编辑
]

《曹霸畫馬》真是馬，宛頸相摩槽櫪下。卓犖權奇果如
此，豈有世上無知者。朱絲不是凡馬韁，天閑十二皆
龍驤。曾從天子平四方，畫圖彷彿餘驪黃，華山之陽
春草長。

《韓幹馬》
前人
[
编辑
]

韓幹畫出曹將軍，幹惟畫肉猶逼真。昂藏四顧欲飛
去，老奚安知馬有神。想當此馬未畫時，朝刷吳越暮
燕秦。頓轡長鳴風動地，不數驊騮與騏驎。當時用舍
那知許，粉墨蕭條尚雄武。千金駿骨何足論，萬世長
留群玉府。

《畫馬》
薩都剌
[
编辑
]

漢水揚波洗龍骨，房星墮地天馬出。四蹄蹀躞若流
星，兩耳尖修若削筆。天閑十二連青雲，生長出入黃
金門。鼓鬃振尾恣偃仰，食粟何以酬主恩。豈堪碌碌
同凡馬，長鳴噴沬奚官怕。入為君王駕鼓車，出為將
​
軍靜邊野。將軍與爾同死生，要令四海無戰爭，千古
萬古歌《太平》。

《上都詐馬大讌》
貢師泰
[
编辑
]

紫雲扶日上璇題，萬騎來朝隊仗齊。織翠轡長攢孔
雀，鏤金鞍重嵌文犀。行迎御輦爭先避，立近天墀不
敢嘶。十二街頭人聚看，傳言丞相過沙堤。

《題二馬圖》
前人
[
编辑
]

《鐵喙騧》，連《錢驄》。何年墜影江水中，蒲梢西來八尺龍。
天閑十二為爾空，五花雲錦吹東風。

《劉舍人桃花馬歌》
迺賢
[
编辑
]

青絲駿馬桃花色，翠鞍玉轡黃金勒。奚奴牽出不敢
騎，道上行人爭愛惜。往時曾遇李將軍，汗流如血氣
如雲。朝刷黃河暮南粵，沙場百戰成奇勳。歸來無心
伏槽櫪，頓轡長鳴思奮力。東家白面繡衣郎，千金買
去遊南陌。昨朝校獵向城隅，萬人爭說天下無。夜歸
不怕霸陵尉，玉鞭醉打蒼頭奴。畫燭銀屏歡徹曙，一
朝金盡賓朋去。可憐驕馬屬誰家，斷韁猶繫階前樹。
君不見西家款段三十年，青芻滿櫪菽滿田。老翁不
識城下路，騎看射獵南山邊。

《觀內廐洗馬》
朱德潤
[
编辑
]

黃雲灑雨沙場秋，灘高水平凝不流。曉霜襲透蒼駝
裘，圉人浴馬津水頭。綠驃連錢雙驊騮，日光射波脂
膩浮。青絲脫鞚黃金鉤，輕爬短刷濕未收。三花剪𩯣
平且柔，籋雲駿氣將無儔。束芻斗豆豈馬羞，茫茫豐
草生林丘。霜蹄胡為踏長楸，振鬣一躍期天遊。

《題張參政所藏驄馬滾塵圖》
前人
[
编辑
]

盛唐太僕王毛仲，八坊分隊三花動。當時畫馬稱曹
韓，尺素幻出真龍種。玉花照夜爭新妍，一馬滾塵騣
尾鮮。昂頭不受金絲絡，汗血轉沙生晝煙。翰林妙寫
不減古，名駒染出青毫素。延祐君王賞駿材，金盤賜
帛開當宁。時清處處生驪騧，何必漢朝稱渥洼。王良
幸勿嗔踶囓，一躍天衢千里沙。

《題趙仲穆揩癢馬圖》
前人
[
编辑
]

渥洼天馬骨如龍，散步春郊苜蓿中。揩遍玉騣塵未
落，日斜宮樹影搖風。

《題畫馬》
薛漢
[
编辑
]

渥洼龍媒少人識，世上駑駘日充斥。班生畫馬畫兩
匹，駿骨雄姿殊未得。赭袍烏幘坐奚官，似出春風十
二閑。掩圖不語三太息，我方垂耳鹽車間。

《桃花馬歌》
張憲
[
编辑
]

「房星下飲瑤池清，神光夜化花龍精。東風滿背騎不得，冰痕淨洗黃魚腥。斑斑朱英點精雪，滴滴真珠汗凝血。高蹄蹴蹋花雨香，仰面嘶春春正熱。周家穆滿遊懸圃，萬里西馳覲王母。青絲繫樹搖玉珂，錦繡叢中五雲舞。歸來復入元都觀，紫陌韶華正零亂。天閑不數連錢驄，路人只作文彪看。天台九曲溪流芳，解」鞍春水浮丹光。劉郎牽入落花去，撲面玉鞭蝴蝶忙。
風流自許王武子，未信叔癡癡不語。千年駿骨作銅
聲，燕昭臺高金似土。

《二月八日遊皇城西華門外觀嘉孥弟走馬歌》
[
编辑
]

前人

春風壓城紫燕飛，繡鞍寶勒生光輝。軟莎青青平似
鏡，花雨滿巾風滿衣。潛蛟雙綰玉抱肚，朱鬣分光散
紅霧。金龍五爪蟠綵袍，滿背真珠撒秋露。生猨俊健
雙臂長，左腳撥鐙右蹴韁。銅鐃四扇遶十指，玉聲珠
碎金琅璫。黃蛇下飲電掣地，錦鷹打兔起復墜。袖雲
突兀鞍面空，銀甕駝囊兩邊縋。西宮綵樓高插天，鳳
凰繚繞排神仙。玉皇拍闌誤一笑，不覺四蹄如迸煙。
神駒長鳴背凝血，郎君轉面醉眼纈。天恩剪下五色
雲，打鼓歸來汗如雪。

《立仗馬》
前人
[
编辑
]

照夜玉狻猊，霜毛鐵鑿蹄。春風金絡腦，小雨錦障泥。
御駕馳天上，軍封受海西。日供三品料，緘口不聞嘶。

《文紀行贈以小步馬》
楊奐
[
编辑
]

洛水西頭路，桃花夾岸香。偏宜紅叱撥，小試紫遊韁。
雨徑沙初軟，春山草正長。杖藜猶過我，此別莫相忘。

《韓左軍馬圖卷》
錢選
[
编辑
]

韓公胸次有神奇，寫得天閑八尺駒。曾為岐王天上
賜，不隨都護雪中驅。霜蹄奮迅追飛電，鳳首昂藏似
渴烏。春草青青《華山曲》，三邊今日巳無虞。

《畫馬》
范梈
[
编辑
]

一自房星墮渥洼，龍媒多在玉皇家。赤尾灑血微生
汗，黑暈團雲整作花。不待老能知失道，固應來自涉
流沙。如今豈少真神駿，猶有丹青紙上誇。

《天馬》
郭翼
[
编辑
]

四年遠涉流沙道，筋骨權奇舊肉騣。曉秣龍堆寒蹙
雪，晚經月窟怒追風。漢文千里知曾卻，曹霸丹青貌
不同。拂拭金鞍被來好，幸陪天廐玉花驄。

《和李長吉馬詩九首》
前人
[
编辑
]

肉礧錦纏騣，流雲汗似紅。太平無戰伐，驂驔走沙蓬。

其二
​
龍性非凡質，騰波出紫雲。檀溪飛過日，應識漢將軍。

其三

龍印留官字，霜華剝暗毛。長鳴愁過影，祇憶九方皋。

其四

霞口縷銜塞，霜蹄削玉寒。曉看《經邏些》，暮已驀《樓蘭》。

其五

梁昭明太子，《七契君子》曰：「千里之駒，出自余吾，伯樂所選，伏波所模，通肩合相，平腹應圖，激電比速，躡景競驅，騰黃弗敢擬駿，赤兔莫與爭途，異態蹥踡，奇姿猗倚，逸足驟反，遊雲移駛，形函遊華，日不暇徙，乃飾金」羈之昭晰，加以玉鞍之輝煥。連乾麗靡，輕蘇燦爛。
逸氣既為勝矚，美飾重成壯觀。蹄蹶紅塵，膺流絳汗。
風起龍驤，灰聲鳥散。自古迄今，人誰不玩，逸士能就
