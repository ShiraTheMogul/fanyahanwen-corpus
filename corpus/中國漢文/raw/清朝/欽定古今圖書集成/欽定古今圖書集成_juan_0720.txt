梅部藝文三
〈詩〉

编辑
]

《梅花落》
宋·鮑照
[
编辑
]

《中庭雜樹多》，偏為梅咨嗟。問君何獨然，念其霜中能
作花，露中能作實。搖蕩春風媚春日。念爾零落逐寒
風，徒有霜華無霜質。

《贈范蔚宗詩》
陸凱
[
编辑
]

《荊州記》曰：「陸凱與范蔚宗交善，自江南折梅花一枝，詣江北與蔚宗。兼贈詩曰」 ：

《折花》逢驛使，寄與隴頭人。江南無所有，聊贈一枝春。

《詠落梅》
齊·謝脁
[
编辑
]

新葉初冉冉，初蕊新菲菲。逢君後園燕，相隨巧笑歸。
親勞君玉指，摘以贈南威。用持插雲髻，翡翠比光輝。
日暮長零落，君恩不可追。

《雪裏覓梅花》
梁·簡文帝
[
编辑
]

絕訝梅花晚，爭來雪裏窺。下枝低可見，高處遠難知。
俱羞惜腕露，相讓到腰羸。定須還剪綵，學作兩三枝。

《春日看梅花》
同前
[
编辑
]

《昨日看梅花》，新花已日生。今旦聞春鳥，何啻兩三聲。
凍解池開淥，雲穿天半晴。遊心不應動，為此欲逢迎。

《詠梅》
元·帝
[
编辑
]

梅含今春樹，還臨先日池。人懷前歲意，花發故年枝。

《同蕭左丞詠摘梅花》
庾肩吾
[
编辑
]

窗梅朝始發，庭雪晚初消。折花牽短樹，攀叢入細條。
垂冰溜玉手，含刺𦊰春腰。遠道終難寄，聲香徒自饒。

《梅花落》
吳均
[
编辑
]

終冬十二月，寒風西北吹。獨有梅花落，飄蕩不依枝。
流連逐霜彩，散漫下冰澌。何當與春日，共映芙蓉池。

《梅花》
前人
[
编辑
]

《梅》性本輕蕩，世人相凌賤。故作負霜花，欲使羅綺見。
但願深相知，千摧非所戀。

《揚州法曹梅花盛開》
何遜
[
编辑
]

兔園標物序，驚時最是梅。銜霜當路發，映雪擬寒開。
枝橫郤月觀，花繞凌風臺。朝灑《長門泣》，夕駐《臨邛》杯。
應知早飄落，故逐上春來。

===
《和孔中丞雪裏梅花》
王筠
===
​
水泉猶未動，庭樹已先知。翻光同雪舞，落素混冰池。

今春競時發，猶是昔年枝。惟有長顦顇，對鏡不能窺。

《詠梅花》
鮑泉
[
编辑
]

可憐階下梅，飄蕩逐風迴。度簾拂羅幌，縈窗落梳臺。
乍隨纖手去，還因插鬢來。客心屢看此，愁眉斂詎開。

《梅花落》
陳後主
[
编辑
]

春砌落芳梅，飄零上鳳臺。拂妝疑粉散，逐溜似萍開。
映日花光動，迎風香氣來。佳人早插髻，試立且徘徊。

又

楊柳春樓邊，車馬飛風煙。連娉烏孫伎，屬客單于氈。
鴈聲不見書，蠶絲欲斷絃。欲持塞上蕊，試立將軍前。

《雪裏梅花》
陰鏗
[
编辑
]

春近寒雖轉，梅舒雪尚飄。從風還共落，照日不俱消。
葉開隨足影，花多助重條。今來漸異昨，向晚判勝朝。

《梅花落》
徐陵
[
编辑
]

對戶一株梅，新花落故栽。燕拾還蓮井，風吹上鏡臺。
「娼家怨思妾，樓上獨徘徊。啼看竹葉錦，簪罷未能裁。」
《梅花落》
張正見
[
编辑
]

《芳樹映雪》野，發早覺寒侵。落遠香風急，飛多花徑深。
周人嘆初摽，魏帝指前林。「邊城少灌木，折花自悲吟。」
《梅花落》
江總
[
编辑
]

「縹色動風香，羅生枝已長。妖姬墜馬髻，未插江南璫。」「轉袖花紛落，春衣共有芳。羞作秋胡婦，獨採《城南桑》。」
又

胡地少春來，三年驚落梅。偏疑粉蝶散，乍似雪花開。
可憐香氣歇，可惜風相催。《金鐃》且莫韻，玉笛幸徘徊。

《梅花落》
前人
[
编辑
]

臘月正月早驚春，眾花未發梅花新。可憐芬芳憐玉
臺，朝攀晚折還復開。長安少年多輕薄，兩兩共唱梅
花落。滿酌金卮催玉柱，落梅樹下宜歌舞。金谷萬株
連綺甍，梅花密處藏嬌鶯。桃李佳人欲相照，摘葉牽
花來並笑。楊柳條青樓上輕，梅花色白雪中明。橫笛
短簫凄復切，誰知柏梁聲不絕。

《早梅》
謝燮
[
编辑
]

迎春故早發，獨自不疑寒。畏落眾花後，無人別意看。

《梅花落》
蘇子卿
[
编辑
]

中庭一樹梅，寒多葉未開。祇言花是雪，不悟有香來。
上郡春恆晚，高樓年易催。織書偏有意，教逐錦文回。

《梅花》
北周·庾信
[
编辑
]

常年臘月半，已覺梅花闌。不信今春晚，俱來雪裏看。
樹動懸冰落，枝高出手寒。早知覓不見，真悔著衣單。

《看梅》
隋·侯夫人
[
编辑
]

砌雪無消日，捲簾時自顰。「庭梅對我有憐意，先露枝頭一點春。」
又

香清寒豔好，誰惜是天真。玉梅謝後陽和至，散與群
芳自在春。

《梅花落》
唐·楊炯
[
编辑
]

窗外一株梅，寒花五出開。影隨朝日遠，香逐便風來。
泣對銅鉤障，愁看玉鏡臺。行人斷消息，春恨幾徘徊。

《梅》
李嶠
[
编辑
]

《大庾》斂寒光。南枝獨早芳。雪含朝暝色。風引去來香。
妝面迴青鏡。歌塵起畫梁。若能遙止渴。何暇泛瓊漿。

《庭梅詠》
張九齡
[
编辑
]

芳意何能早，孤榮亦自危。更憐花蔕弱，不受歲寒移。
朝雪那相妒，陰風已屢吹。馨香雖尚爾，飄蕩復誰知。

《和常州崔使君詠後庭梅》
孫逖
[
编辑
]

聞唱梅花落，江南春意深。更傳千里外，來入越人吟。
弱幹紅妝倚，繁香翠羽尋。庭中自公日，歌舞向芳陰。

又

「梅院重門掩，遙遙歌吹邊。」庭深人不見，春至曲能傳。
花落彈碁處，香來薦枕前。使君停五馬，行樂此中偏。

《江梅》
杜甫
[
编辑
]

梅蕊臘前破，梅花年後多。絕知春意早，最奈客愁何。
雪樹元同色，江風亦自波。故園不可見，巫岫鬱嵯峨。

《和裴迪登蜀州東亭送客逢早梅相憶見寄》
[
编辑
]

前人

東閣官梅動詩興，還如何遜在揚州。此時對雪遙相
憶，送客逢春可自由。幸不折來傷歲暮，若為看去亂
鄉愁。江邊一樹垂垂發，朝夕催人自白頭。

《早梅》
張謂
〈一作戎昱〉
[
编辑
]

一樹寒梅白玉條，迥臨村路傍溪橋。不知近水花先
發，疑是經春雪未銷。

《官舍早梅》
前人
[
编辑
]

階下雙梅樹，春來畫不成。晚時花未落，陰處葉難生。
摘子防人到，攀枝畏鳥驚。風光先占得，桃李莫相輕。

《梅花落》
劉方平
[
编辑
]

新歲芳梅樹，繁花四面同。春風吹漸落，一夜幾枝空。
少婦今如此，長城恨不窮。莫將遼海雪，來比《後庭中》。

《江濱梅》
王適
[
编辑
]

忽見寒梅樹，開花漢水濱。不知春色早，疑是《弄珠》人
​

《山路梅》
錢起
[
编辑
]

莫言山路僻，還被好風催。行客凄涼過，村籬冷落開。
晚溪寒水照，晴日數蜂來。重憶江南酒，何因把一杯。

《早梅》
柳宗元
[
编辑
]

早梅發高樹，迥映楚天碧。朔風飄寒香，繁霜滋曉白。
欲為萬里贈，杳杳山水隔。寒英坐銷落，何用慰遠客。

《春雪間早梅》
韓愈
[
编辑
]

梅將雪共春，彩艷不相因。逐吹能爭密，排枝巧妒新。
誰令香滿座，獨使淨無塵。芳意饒呈瑞，寒光助照人。
玲瓏開已遍，點綴坐來頻。那是俱疑似，須知兩逼真。
熒煌初亂眼，浩蕩忽迷神。未許瓊華比，從將玉樹親。
先期迎獻歲，更伴占茲辰。願得長輝映，輕微敢自珍。

《賦得春雪映早梅》
庾敬休
[
编辑
]

清晨凝雪彩，新候變庭梅。樹愛春榮遍，窗驚曙色催。
寒光添素壁，積潤履青苔。分明六出瑞，隱映幾枝開。
聞笛花疑落，揮琴興轉來。曲成非寡和，長詠思悠哉。

《華林園早梅》
鄭述誠
[
