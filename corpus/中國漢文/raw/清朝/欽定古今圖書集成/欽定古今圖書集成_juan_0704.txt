《秋竹曲》
齊·謝朓
[
编辑
]

㛹娟綺窗北，結根未參差。從風既裊裊，映日頗離離。
欲求《棗下吹》，別有《江南枝》。但能凌白雪，貞心蔭曲池。

《詠竹》
前人
[
编辑
]

窗前一叢竹，青翠獨言奇。南條交北葉，新筍雜故枝。
月光疏已密，風來起復垂。青扈飛不礙，黃口得相窺。
但恨從風籜，根株長別離。

《賦得竹》
元·帝
[
编辑
]

《嶰谷》管新抽，淇園節復脩。作龍還葛水，為馬向并州。
柯亭臨絕澗，桃枝夾細流。冠學芙蓉勢，花堪威鳳游。
邛王若有獻，張騫應拜侯。

《簷前竹》
沈約
[
编辑
]

萌開籜已垂，結葉始成枝。繁陰上蓊茸，促節下離離。
風動露滴瀝，月照影參差。得生君戶牖，不願夾華池。

《詠竹》
吳均
[
编辑
]

嬋娟鄣綺殿，繞弱拂春漪。何當逢採拾，為君笙與箎。

《望廨前水竹答崔錄事》
何遜
[
编辑
]

蕭蕭藂竹映，澹澹平湖淨。葉側漣漪文，水漾檀欒影。
相思不會面，相望空延頸。遠天去浮雲，長墟斜落景。
幽痾與歲積，賞心隨事屏。鄉念一邅迴，白髮生俄頃。

《枯葉竹》
劉孝威
[
编辑
]

枯楊猶更綠，臥柳尚還生。勿嫌鳳不至，終當待聖明。

《詠竹》
劉孝先
[
编辑
]

竹生荒野外，梢雲聳百尋。無人賞高節，徒自抱貞心。
恥染湘妃淚，差入上宮琴。誰當製長笛，當為吐《龍吟》。

《見江邊竹》
虞羲
[
编辑
]

挺此貞堅性，來樹朝夕池。秋波漱下趾，冬雪封上枝。
葳蕤防曉露，蔥蒨集羈雌。含風自颯颯，負霜亦猗猗。
金明無異狀，玉洞良在斯。但恨非《嶰谷》，伶倫未見知。

《和新浦侯齋前竹》
江洪
[
编辑
]

本生出高嶺，移賞入庭蹊。檀欒拂桂橑，蓊蔥傍朱閨。
夜條風析析，曉葉露淒淒。籜紫春鶯思，筠綠寒蛩啼。
不惜凌雲茂，遂聽群雀棲。願抽一莖實，試看翔鳳來。

《侍宴賦得夾池竹》
陳陰鏗
[
编辑
]

夾池一叢竹，垂翠不驚寒。葉醞宜城酒，皮裁薛縣冠。
湘川染別淚，衡嶺拂仙壇。欲見葳蕤色，當來兔苑看。

《賦得山中翠竹》
張正見
[
编辑
]

修竹映巖垂，來風異夾池。複澗藏高節，重林隱勁枝。
雲生龍未上，花落鳳將移。莫言棲嶰谷，伶倫不復吹。

籜，階前疏葉強來風。欲知抱節成龍處，當於山路葛

《賦得風生翠竹裡應教》
前人
[
编辑

《金風起燕觀》，翠竹夾梁池。翻花疑鳳下，颺水似龍移。
帶露依深葉，飄寒入勁枝。聊因萬籟響，詎待伶倫吹。

《賦得夾池脩竹》
賀循
[
编辑
]

綠竹影參差，葳蕤帶曲池。逢秋葉不落，經寒色詎。移
來風韻晚逕，集鳳動春枝。所欣高蹈客，未待《伶倫》吹。

《詠竹》
北齊·蕭放
[
编辑
]

懷風枝轉弱，防露影逾濃。既來丹穴鳳，還作葛陂龍。

《賦得臨池竹》
唐·太宗
[
编辑
]

貞條障曲砌，翠葉貫寒霜。拂牖分龍影，臨池待鳳翔。

《古意》
王績
[
编辑
]

《竹生大夏谿》，蒼蒼富奇質。綠葉吟風勁，翠莖犯霄密。
霜霰封其柯，鵷鸞食其實。寧知軒轅後，更有伶倫出。
刀斧俄見尋，根株坐相失。裁為十二管，吹作雄雌律。
有用雖自傷，無心復招疾。不如山上草，離離保終吉。

《賦得臨池竹》
虞世南
[
编辑
]

蔥翠梢雲質，垂彩映清池。波泛含風影，流搖防露枝。
龍鱗漾嶰谷，鳳翅拂漣漪。欲識凌冬性，惟有「歲寒知​《與東方左史虯脩竹篇》〈并書〉陳子昂[编辑]東方公足下：文章道弊，五百年矣，漢魏風骨，晉宋莫傳，然而文獻有可徵者。僕嘗暇時觀齊、梁間詩，彩麗競繁，而興寄都絕，每以永嘆，思古人常恐邐逶頹靡，風雅不作，以耿耿也。一昨于解三處見明公《詠孤桐篇》，骨氣端翔，音情頓挫，光英朗練，有金石聲，遂用洗心飾視，發揮幽鬱。不圖正始之音，復睹于茲，可使建安。作者相視而笑。解君云：「張茂先、何敬祖、東方生與其比肩」 ，僕亦以為知言也。故感歎雅製，作《脩竹詩》一首，當有知音以傳示之。

「龍種生南嶽，孤翠鬱亭亭。峰嶺上崇崒，煙雨下微冥。夜聞鼯鼠叫，晝聒泉壑聲。春風正淡蕩，白露已清泠。哀響激金奏，密色滋玉英。歲寒霜雪苦，含彩獨青青。豈不厭凝洌，羞比春木榮。春木有榮歇，此節無凋零。始願與金石，終古保堅貞。不意伶倫子，吹之學鳳鳴。」遂偶雲和瑟，張樂奏《天庭》。妙曲方千變，簫《韶》亦九成。
信蒙雕斲美，常願事仙靈。驅馳翠虯駕，伊鬱紫鸞笙。
結交嬴臺女，吟弄昇天行。攜手登白日，遠遊戲赤城。
低昂元鶴舞，斷續彩雲生。永隨眾仙逝，三山遊玉京。

《綠竹引》
宋·之問
[
编辑
]

青溪綠潭潭水側，修竹嬋娟同一色。徒生仙實鳳不
遊，老在空山人詎識。妙年秉願逃俗氛，歸臥嵩丘弄
白雲。含情傲睨慰心目，何可一日無此君。

[
编辑

高簳楚江濆，嬋娟含曙氛。白花搖鳳影，青節動龍文。
葉掃東南日，枝梢西北雲。誰知湘水上，流淚獨思君。

编辑

為重凌霜節，能虛應物心。年年承雨露，長對紫庭陰。

《答李伯魚桐竹》

[
编辑

落花朝滿岸，明月夜披林。竹有龍鳴管，桐留鳳舞琴。
奇聲與高節，非吾誰賞心。

高節人相重，虛心世所知。鳳凰佳可食，一去一來儀。
