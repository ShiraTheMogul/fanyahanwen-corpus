順天府部藝文八
〈詩詞〉
[
编辑
]

夏日游通惠河　　　　　　　　徐階
[
编辑
]

「頗憶三江遠，乘流意若何。」水深秋氣入，樹密雨聲多。
熟果當尊落，驚禽拂棹過。柳陰催繫纜，欹枕聽漁歌。

金臺　　　　　　　　　　　　林爚
[
编辑
]

黃金鎖盡獨空臺，雲水蒼蒼紫翠堆。鴉噪夕陽歸畫
堞，碑連暮靄翳蒼苔。平河水落蘆溝遠，古峽人從鳥
道回。聖代祇今多稷契，紛紛誰數樂生才。

報國寺松　　　　　　　　　　陳鳳
[
编辑
]

偶共菩提樹。同生般若林。蛟龍各殊狀。霜霰詎能侵。
空樂風前度。天花雨外深。閒來再攀賞。三宿媿茲心。

昌平道中作　　　　　　　　　侯恪
[
编辑
]

再入昌平道，凄涼事不同。兵戈纏殺氣，鼓角動秋風。
野色千林白，嵐光片日紅。長陵蒼莽外，極目送飛鴻。

宿昌平　　　　　　　　　　　周詩
[
编辑
]

晨發都城門，暮宿昌平境。地折雙溪流，天開萬重嶺。
月榭露微明，楓林墮初暝。謬此陪秋嘗，齋心動遐省。

普濟寺詩　　　　　　　　　唐順之
[
编辑
]

「宛轉雲峰合，微茫鳥路通。閒來竹林下，醉臥石房中。」陰磵泉先凍，陽崖蕊尚紅。攀蘿探虎穴，憩石俯鮫宮。
上客思留帶，山僧不避驄。夜深清嘯發，流響入寒空。

金臺行　　　　　　　　　　　前人
[
编辑
]

君不見七雄割據勢相均，得士者富失士貧。燕昭信
義明日月，不惜千金買駿骨。郭卿談笑吐深謀，海內
賢豪競馳突。就中樂生尤奇絕，按劍魏朝人豈知。一
朝遇主同心腹，親屈君王為推轂。指揮燕兵百餘萬，
蹴踏齊城七十六。於今六合無并吞，寂寞古臺空復
存。少年未上麒麟閣，且學陸沉金馬門。

登懷柔城　　　　　　　　　　前人
[
编辑
]

塞下孤城古白檀，半臨平野半依山。秋來亭堠無烽
火，官馬千家苜蓿間。

元明宮　　　　　　　　　　　劉節
[
编辑
]

弱草芊芊臥斷碑，殘陽脈脈柳條衰。《瑤函》寶籙今安
在，華屋修廊更屬誰。孤兔祇看啼故穴，風雲那復動
靈旗。行人下馬譚遺事，惟有蒼涼野老知。

天壽山　　　　　　　　　　　石珤
[
编辑
]

銀峰翠壁峙諸孫，嶽勢雄開祖宅尊。關塞正當山右
臂，風雷近接海西門。龍過古澗多成雨，虎撼長松半
出根。隱隱五陵佳氣在，欲攀弓劍泣深恩。

直沽櫂歌　　　　　　　　　無名氏
[
编辑
]

天妃廟對直沽開，津鼓連船柳下催。釃酒未終舟子
報，柁樓黃蝶早飛來。

雲帆十幅下津門，日落潮平不見痕。葦甸茫茫何處
泊，一燈明處有漁村。

蘼蕪楊柳綠依依，檣燕檣烏立又飛。賺得南人歸思
緩，白魚紫蟹四時肥。

良鄉縣學　　　　　　　　　　趙渢
[
编辑
]

儒宮宜地僻，竟日有餘清。殿古碑仍在，庭空草自生。
風高時落木，雲重欲摧坡。客興已瀟灑，秋堂更雨聲。

李園小集　　　　　　　　　劉同升
[
编辑
]

「小橋行過柳溪灣，為訪園亭竟日閒。」出郭已知依綠
水，登樓更喜見青山。寒泉落木疑丘壑，瘦馬深衣自
往還。剩采東籬尋舊約，君應無夢到塵寰。

龍華寺　　　　　　　　　　吳惟英
[
编辑
]

「去年花外客，今復到長堤。」淺水兼天闊，新蒲與岸齊。
鐘傳高閣遠，柳覆小橋低。指點村煙起，歸心促馬蹄。

燕臺　　　　　　　　　　　　蔡經
[
编辑
]

燕王本意築金臺，祇謂能收濟世才。何事荊軻終遠
去，空憐樂毅不歸來。平沙古嶂河山在，落日鳴琴草
木哀。《三輔》雲晴瞻北極，九重宮闕自天開。

居庸晚眺　　　　　　　　　　劉侃
[
编辑
]

別館岧嶢一注顏，天空木葉繞重關。千峰嵐氣青霄
​
上，九折泉聲翠壁間。瀚海旌旗無日罷，玉門車馬幾
人還。皇州咫尺浮雲隔，明發崢嶸何處攀。

登妙應寺迴眺京邑　　　　　　何棟
[
编辑
]

不上西峰望，誰知帝宅雄。星河圍紫極，龍虎抱金宮。
王氣千年在，朝宗萬國同。皇圖天共久，形勝陋關中。

招賢里　　　　　　　　　　　桑悅
[
编辑
]

公卿薦士久不作，此地舊有《招賢》名。誰知燕臺一坏
土，可直全齊七十城。魏闕遙遙楚天碧，滿眼白雲流
水急。小山叢桂不聞歌，秋空月冷黃金泣。

戒壇　　　　　　　　　　　黃輝望
[
编辑
]

坐月松枝暖，春風記昔游。露尊調《白鳳》。雪曲醉蒼虯。
古洞花難發，孤琴水漫流。惟餘西嶺色，猶向茂陵秋。

懷柔道中作　　　　　　　　王世貞
[
编辑
]

「馬足吾何限，山行稍自寬。人家梅雨色，衣袖麥秋寒。」過瀑添新徑，歸雲改故巒。斷腸沙鴈起，一一向長安。

霸水夜泊　　　　　　　　　　前人
[
编辑
]

高帆去不極，天際見人家。繫網青楓樹，藏身白荻花。
迴風喧鴈鶩，隙日出魚蝦。亦有垂綸地，兵戈敢自誇。

集韋氏水亭　　　　　　　　　前人
[
编辑
]

偶成春服始，挾侶問幽蹤。芳草近寒食，空林聞午鐘。
驚波雙鳥出，迷路一僧逢。欲竟名園賞，停杯感慨重。

龍華寺　　　　　　　　　　張佳引
[
编辑
]

地有《龍華》勝，心隨石榻清。春風一枕到，孤月萬松明。
花散諸天雨，鐘鳴不夜城。抽簪如可得，于此悟無生。

居庸關　　　　　　　　　　　徐渭
[
编辑
]

少年曾負請纓雄，轉眼青袍萬事空。今日獨餘霜鬢
在，一肩輿坐度居庸。

居庸館中作　　　　　　　　　熊卓
[
编辑
]

隘地關門擁，山樓鼓角傳。長風吹不歇，塞草自年年。

夜發靜海抵直沽作　　　　　　徐石麒
[
编辑
]

禾黍高低弄夕矄，檣燈零亂破黃昏。樹蒸夜氣三分
雨，帆掛秋風一葉雲。靜海金鉦傳古戍，直沽牙閫駐
新軍。援遼已竭東南力，何日辰韓始策勳。

涿鹿道中作　　　　　　　　周廷用
[
编辑
]

涿鹿雲橫草樹深，燕京風物晝陰陰。河山尚擁軒皇
陣，臺榭虛憐郭隗金。雨過涼生高鳥喚，天低日落暮
蟬呤。腐儒未有干時策，敢向泥塗嘆陸沉。

次涿鹿作　　　　　　　　　　李瓚
[
编辑
]

故鄉杳不見，歸路亦沾巾。匹馬燕山外，孤城涿水濱。
鶯花從客久，風雨度河春。底事南亭柳，毿毿青向人。

北留寺　　　　　　　　　　　馬之駿
[
编辑
]

宛在風光裏，悠然水木間。屢尋沿岸寺，稍見著城山。
懺佛難除懶，逢僧即共閒。淹留無不可，𢬵與暮鴉還。

東郭草亭　　　　　　　　　　王英
[

魏陳琳《武庫賦》：「弩則幽都筋角，恆山檿幹，通肌暢骨，直矢輕弦，當鋒推決，貫遐洞堅。」
陳江統《弧矢銘》：「幽都筋角，會稽竹矢，易以獲隼，詩以殪兕。」
宋范鎮《幽都賦》「過幽都以垂覽兮，觀禹跡之經營，地博大以爽塏兮，亙繩直而砥平，風俗樸茂兮，蹈禮義而服聲名。」
明王直《遊西苑記略》：「六月七日，陪少師、少保及諸學士於太液池上，詔許遊萬歲山，觀金、元遺跡。中官引自圓殿後度石橋，橋中空二丈許，用一舟實其中，以通行者。既度，入山門，門有三，中為御路，眾從左右門入山，皆奇石疊成，相傳金人取宋艮岳石為之，至元增飾，加結構焉。山趾兩旁皆有門，躡石級而上，至半」有三殿，中曰仁智，左曰延和，右曰介福，獨廣寒殿在
其頂。又有瀛洲、方壺、玉虹、金露四亭，在延和、介福之
後，昔日窮極侈麗，今猶有可觀者。山右之半有廢井，
深不可測，中人云：「下與海通，有蛟蟄焉。」山下有石曰
慶雲，奇峰萬變，蓋艮岳之絕奇者。又有康干石，康干，
國名，石乃松木，入河水浸漬久而成「者，其木理宛然。凡諸殿宇皆仍其舊，未嘗修治。」我朝列聖恭儉之德，
於此可見矣。觀畢，賜宴山下，盡醉而歸。
