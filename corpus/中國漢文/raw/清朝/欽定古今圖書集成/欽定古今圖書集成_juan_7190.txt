明十一

崔鑑
[
编辑
]

按《明外史孝義傳》：「崔鑑，京師人。父嗜酒狎娼，召與居。娼恃寵，時時凌鑑母，父又被酒，數侵辱之。一日，娼惡言詈母，母復之，娼遂擊敗母面，母不勝憤，入室伏床而泣，將自盡。鑑時年十三，自學舍歸，問之，母告以故。鑑曰：『母無死』。即走至學舍，梜刃還。娼適掃地，且掃且​鑑，即拔刃刺其左脅，立斃。乃匿刃牖下，亡走數里，忽」自念曰：「父不知我，殺媢必累我母。」急趨歸，父果訴
於官，將縶其母矣。鑑至，告捕者曰：「此我所為，非母也。」眾見其幼，不信。鑑曰：「汝等不信，請問凶器安在？」自出
刃示之，眾乃釋母縶鑑寘獄。事聞，下刑部讞。尚書聞
淵等議，鑑志在救母，且年少可矜，難拘常律。帝乃貸
其罪。

向化
[
编辑
]

按《明外史孝義傳》：「向化，靜海衛人。父上為衛指揮，坐罪憤而投海死。化沿隄號泣，求屍不得，亦投於海。忽溺屍浮出，衣服盡脫。時天方晴霽，雷雨驟作。既息，化首頂父衣徐徐浮至一處，眾皆駭異，收而葬之。」王敷政
[
编辑
]

按《明外史孝義石鼐傳》：「王敷政，潁上人。親歿廬墓。服闋，出謝其鄰。至高氏家，忽雷雨大作，遶戶震垣。敷政起席，雷忽從其坐下，穿屋成穴而出。數里村舍皆壞，惟高氏宅獨完，人稱為雷避孝子。」孫文
[
编辑
]

按《明外史孝義俞孜傳》：「孫文，餘姚人。幼時，父為族人，時行箠死。長欲報之，而力不敵，仍偽與和好，助其武斷鄉曲，時行坦然不復疑。一日，值時行於田閒，即以田器擊殺之，坐戍。未幾，遇赦獲釋。」范應龍
[
编辑
]

按《鴻苞范孝子傳》：「孝子名應龍，蘭溪人，流寓青浦。為人淳樸有至性，事父母極孝，嘗刲股以愈父疾，故邑人稱為范孝子。家貧，賣卜人所卜善，必力慫恿之，所卜不善，即得吉爻，亦委曲言其不利，有君平之風。日卜得鏹米若干，苟取足供昕夕，餘盡以賑給邑中窘者，長齋奉道。卜罷閉簾，日跪佛前，經聲朗朗出戶外」，
邑人無問老穉女子，咸知范孝子善士也。溟涬子令
青浦，聞其為人而好之。會其歸葬父蘭溪，以白金一
兩、米一石助喪，孝子受而不報謝。後嘗召之卜，溟涬
子略去部民分殊禮遇之，以果餚遺其母，而手書「為善最樂」四大字，顏其卜肆對。邑人士民每舉孝子為
勸，為人得如范孝子可矣。一日，孝子走南海，謁大士
普陀。渡甬江，道經溟涬子家，逕入中庭，望空搏顙，罷
而趨出，不自通。應門者言之，家兄急物色之，不得。孝
子之堅心苦行，類如此。

馮天孫
[
编辑

按《野史秦逵傳》：「馮天孫，歸安人。早孤，奉母至孝。母病，刲股和粥以進，得痊。詔旌其門，拜工部右侍郎，旋乞歸里。」沈孝子
[
编辑
]

《按枝山》前聞吾邑之相城有一乞兒，姓沈，年在中歲，
每詣沈隱君孟淵所請丐，凡所得，多不食，而分貯之
筒篚中。隱君初不為意，久而問焉，則曰：「將以遺老娘耳。」隱君始異之，潛令人偵其所為。丐至一岸旁坐地，
出簞中飲食整理之，擎至船邊。船雖陋而甚潔，老媼
坐其中。丐登舟陳食母前，傾酒跪而奉之，伺母接杯
乃起，跳舞而唱《山歌》，作嬉笑以樂母，母殊意安之也。
必母食盡，乃更他求，若無得，則自受餒，終不先食之
也。日日如之。凡數年，母死，丐始不見。隱君嘆詫，亦時
少周之。「此非有為而為，可謂真孝矣。」周古象
[
编辑
]

按《中洲野錄》：「周古象，蘄水人。生元末，事親孝。遭喪亂，入贅於淮，不見笑容，妻詰之，告以故，遂歸。尋母葬之，廬墓三年。妻亡，終身不娶。淮西僉事幹克莊求見不遇，留題曰：『事親未必可曾參，職分當為每愧心。今日風來飄忽動，抱琴更入白雲深』。」復為立孝里門。

梁維純
[
编辑
]

按《玉田縣志》：梁維純，號敬吾，性孝友，勤誦讀。其母張
氏臨終語之曰：「吾父張惠為壽張尹，以失誤封王，斃於獄，其屍殯於某寺西階下，此我之遺恨也。爾等奮志詩書，異日倘有官山東者，能以骸歸，吾願畢矣。」純
憶之，後以明經為滕丞，詣寺訪之，果得焉，遂具棺衾
扶歸。可謂不背親言者矣。

江一鷟
[
编辑

按《玉田縣志》：「江一鷟，字鉉儀，號念洲。生而穎異，資性邁人。十有三歲，於書肆中得《名家稿》，一覽成誦。性至孝，父西洲公寢疾，衣不解帶者年餘。服闋，家益貧，開絳帳以奉母，日與諸生發明孔孟之蘊，負笈知名者五十餘人。生平篤同氣，好施與，孀姊無依，先生奉養於家，克盡弟道，四十年如一日，姪息皆養育如己出。」郁光被
[
编辑
]

按《玉田縣志》：「郁光被，字新宇，邑庠生尚仁長子也。性情恬適，雅好詩書，每語人曰：『吾人惟忠孝大節耳。此雖根於天性，亦必從讀書中來。視族人可學者，百方誘掖，親疏弗較也。且氣宇嚴整，衣冠瞻視，毫不敢褻。然天性純孝，晨昏定省，久而益篤。其後居母喪，既葬，廬於墓側，攜小學詩書以永朝夕。親屬有勸之回家』」者，應之曰：「欲我為君子耶？欲我為眾人耶！」知其意決
​
乃不復言。迨年餘，哀毀過甚，遂卒於墓側。旌之曰：「以身殉母。」從祀鄉賢。先生舉四子：長協中，次允中，次時
中，次養中，俱庠生。

按《肥鄉縣志》：「楊鳳，號樂泉，學務本源，為邑博士弟子。父卒，兄繼歿，母鄉居數十里外，念鳳欲朝夕膝下，鳳遂舍業，備色養無倦色。後母卒，鳳哀毀骨立，既葬，廬墓側，負土成丘。時巨盜劉六，擁眾數萬，所過殺掠無遺，鄉人牽之去，鳳泣曰：『吾忍以為死而棄吾母乎』？終不去。賊至，知其故，相約毋犯。鄉人有避難於廬者，俱」得全活。時有枯樹復榮，冬月結瓜之祥，邑人稱之為
「孝感先生。」王彥
[
编辑

按《清河縣志》：王彥，字士夫，幼知孝愛，方數歲，值父豸
醉寢，彥侍左右，揮之不去。久或招之飯，曰：「候父醒。」又
一日侍父櫛，見白髮即淚下，曰：「父老矣。」事母楊氏尢
謹，昆季之間，復能友讓，食必相召，飲則同歡，自少至
老，略無乖戾。知縣表其廬曰「孝義之門。」卞孝子
[
编辑
]

按《清河縣志》：卞孝子，不知其名，世居河口。性至孝，曾
割股肉活母，人稱為卞孝子。年老矣，家貧，值其兄誕
日，謀所以上壽者不獲。蚤起過閘，見人網魚，因借網
仰祝曰：「我兄生日，求一魚上壽。」遂一舉得鯉，喜馳獻
兄，兄喜，復同之放生於河而歸飲，人以為孝友之感。

周元生
[
编辑
]

按《清河縣志》：周元生，商州守臣周公之少子，以業儒
隨父任。賊陷商州，左右趨曰「避之。」不聽。其僕牽之，亦
不聽，曰：「吾從吾父耳。」及賊入，縛至其父所，夾刃脅之，
義不降賊，遂與父同罵賊而死。商人收葬於其父塚
之側，而並祀之。
