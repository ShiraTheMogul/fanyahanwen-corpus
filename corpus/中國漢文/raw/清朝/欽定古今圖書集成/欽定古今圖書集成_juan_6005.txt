王斗維妻沈氏
[
编辑
]

按《諸城縣志》：沈氏，孝子王斗維妻。天性純孝。年二十三，土寇蜂起，斗維以廬墓被殺。氏哭曰：「子從父死，妻不當從夫死乎！」 親戚勸曰：「奈夫絕後何？不如撫孤以全夫嗣為大。」 再三強之，乃不死。撫週歲子偉，躬親教誨，備嘗艱苦。順治九年，西山土寇至，或勸之避，氏曰：「夫柩未葬，去將焉往？此吾從夫地下時也。」 寇至，氏罵賊死夫柩前。

丘志科繼妻范氏
[
编辑
]

按《諸城縣志》：范氏，庠生丘志科繼妻。志科亡，誓不獨生。幼子六生攀母號泣不捨，氏強視息撫育之。六生以癖殤，氏泣曰：「吾為夫撫子，子喪當同見夫地下，以遂吾初心。」 家人勸救不聽，自縊而死。

周浩妻馮氏
[
编辑
]

按《諸城縣志》：「馮氏，周浩妻。浩歿，氏年二十三，號泣自縊，從一而終。」王延年妻楊氏
[
编辑
]

按《諸城縣志》：「楊氏，王延年妻。天性柔順，年十九適延年，夫妻相敬如賓，事舅姑克盡孝道。延年病劇，氏衣不解帶，誓以身殉。及沒，哭泣絕粒，是夜自縊柩前。有司申請旌表。」田紹謨妻李氏
[
编辑
]

按《沂水縣志》：李氏，田紹謨妻。謨于順治十七年病亡，李年二十六，有三子，或幼穉，或襁褓。李堅撫諸孤，誓不他適。三子尋相繼殤。時夫尚未葬，李臨柩號哭泣血三年經營葬具畢，欲以身殉，家人防之甚密。將葬之日，紿守者王嫗曰：「汝急起視竈飯，轝柩人，我即起也。」 嫗甫去，隨綰髽服衰絰，縊死柩側。

張璇妻高氏
[
编辑
]

按《沂水縣志》：「高氏，張璇妻，年二十七。順治五年二月，夫婦及十歲子俱為西山土寇所執，驅行山谷中，至桃峪邨。日暮，賊疲止臥，高氏密解夫縛令逃去。自度難脫，抽賊刀自刎。賊怒，斫其屍數段。賊既去，璇收葬之。後三年，其子逃歸，訴其狀甚悉。」劉之奇妻厲氏
[
编辑
]

按《日照縣志》：「厲氏，庠生劉之奇妻。順治元年，奇病疫亡，氏即自縊屍側。」宋徽妻劉氏
[
编辑
]

按《日照縣志》：「劉氏，武生宋徽妻，榆園賊騎千餘。」​

突至濤洛，氏趨避不及，謂夫曰：「汝速走，我但有死耳！」 群賊執氏，氏大罵不從。賊猶戀戀，未忍殺氏，冀速死，復極口大罵曰：「爾不殺我，前途官軍勦爾無遺類！」 賊怒，攢鎗亂刺殺之。

丁修己繼室萬氏

编辑

按《日照縣志》：「萬氏，太學生丁修己繼室。順治八年，沂費山賊掠濤洛店，氏義不辱，同嫂陳氏罵賊，賊即戶內攢刃殺之。」鄭祥妻高氏
[
编辑
]

按《日照縣志》：高氏，庠生鄭祥妻。性至孝，居姑喪，不茹葷三年。夫遘疾將危，氏謂夫曰：「萬一不諱，吾不難相從。但恨舅氏望九之年，無所依賴耳。然亦舅之命也，吾志決矣。」 及夫沒，遂託其舅於族人，著嫁時衣自縊，年二十二。

張士諤妻魏氏
[
编辑

按《濰縣志》：「魏氏，張士諤妻。幼嫺內則，恪守母訓。年十七，歸張。逾年士諤病亡，氏自縊柩傍以殉。時順治三年公舉旌表。」王來妻張氏
[
编辑
]

按《濰縣志》：張氏，王來妻。順治六年，來欲入群盜之黨，氏泣止之曰：「汝若失身，我必死。」 來不聽，徑出，氏自縊於家而死。來夕歸見之大慟，悔悟，因改行，獲令終焉。氏死時年十九。里人蔡宗襄為作《佳婦吟》。

高自卑妻王氏
[
编辑

按《膠州志》：「王氏，高自卑妻。順治十年，叛兵劫掠，氏矢死不屈，從容投繯而死。其後有欒檀妻，即其女也。」郭士驊妻崔氏
[
编辑

按《膠州志》：崔氏，諸生郭士驊妻。生二女二子。順治十年，海逆噪叛，遍擄婦女。時驊匿他室，子女皆亡去。氏偵驊匿處，訣曰：「我年已邁，誓不見賊，但不知兒女死所。」 徘徊有頃，潛歸，自縊死。

编辑

按《膠州志》：「宋氏，諸生欒昇妻。生二子二女。順治十年，海逆橫掠氏長子方總角，長女已適人，惟幼兒、幼女為累。氏先繫繯梁間，抱兒女投繯中，乃自經。繯絕，女墮地復甦，氏與兒俱死。」劉重祥妻郭氏
[
编辑

按《膠州志》：郭氏，諸生劉重祥妻。順治十年，海鎮兵叛，氏伏匿，賊大索不得安，踉蹌出走，見路旁有井，遂躍入，乃枯井也。有老媼見氏入井，語氏：「賊來必覺。」 引之出，行數武，有水盈池，遂投水死。

[
编辑

按《膠州志》：李氏，歸孝廉趙僎子伯恭。恭英年，每試輒利，僎甚愛之。恭死，氏拜翁姑曰：「媳亦從此逝矣。」 姑曰：「兒生女，賴汝撫之。」 氏曰：「事已至此，遑問女乎？」 遂自縊。

按《膠州志》：李氏，諸生夏大亨妻。亨父從舊相國高客死東越，訃聞亨舉家號泣，氏不之戚，見者異之。氏曰：「主為君死，舅為主死，何憾為？」 及亨病亡，氏不戚如前，見者更異。氏曰：「夫為父死，妾為夫死，何憾？」 言訖，閉戶自縊。

欒瑛妻高氏
[
编辑
]

按《膠州志》：高氏年十九，適儒生欒瑛，甫六月。順治十年，海鎮兵叛，倉卒出走，至雲溪橋東岸被執。賊曰：「汝從我，為我縫衣。」 氏力拒之，賊曰：「我等」​

「義舉當從我。」 氏曰：「如此擄掠，何為義舉？」 賊怒，急促之行，氏大罵不絕，為亂刀斫死。
