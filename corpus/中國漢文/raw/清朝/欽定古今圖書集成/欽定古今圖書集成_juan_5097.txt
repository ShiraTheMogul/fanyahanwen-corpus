明五

编辑

陳景行
[
编辑
]

按《名山藏勳封記》：「固安伯陳景行，通州人，以穆宗孝
莊皇后父，隆慶元年自錦衣指揮僉事進封。」

陳于陛
[
编辑
]

按《明外史陳于陛傳》：「于陛，字元忠，大學士以勤子也。
舉隆慶二年進士，選庶吉士，授編修。萬曆初，預修世
穆兩朝實錄，充日講官，累遷侍講學士，擢詹事，掌翰
林院。疏請早建東宮。十九年，拜禮部右侍郎，領詹事
府事。明年，改吏部，進左侍郎，教習庶吉士，進禮部尚
書。于陛少從父以勤習國家故實，為史官，益究經世
學，以前代皆修《國史》，而本朝獨無疏言。我朝正史，闕
焉未講。伏睹朝野所撰次可備採擇者，無慮數百種。
倘不及時網羅，歲月浸邈，卷帙散脫，耆舊漸凋，事跡
罕據，欲成信史，將不可得。惟陛下立下明詔，設局編
輯，使一代經制典章，犁然可攷，鴻謨偉烈，光炳天壤，
豈非萬世不朽盛事哉！」詔從之。二十二年正月，遂以
于陛為副總裁。其年夏，兼東閣大學士，入參機務。以
甘肅破賊功，加太子少保。三年滿，改文淵閣，進太子
太保。時帝拒諫益甚，上下否隔，亂政亟行，于陛憂形
于色。二十四年，病卒於位。史亦竟罷。贈少保，諡文憲。

陳壽麓
[
编辑
]

按《長沙縣志》：「壽麓，隆慶恩選，仕蘭陽丞。冰蘗有聲，工
詩賦，不以五斗折腰，挂冠歸隱。著有《春秋懸旨》《左傳
旁訓》《唐詩玉林》《聽雨堂選》《頤年艸》《家禮簡要》諸集。」

陳堂
[
编辑
]

按《廣東通志》：「堂字明佐，南海人。登隆慶戊辰進士，初
仕嚴州司理，以治行最，徵拜南京湖廣道御史。屢奉
敕巡視京營，巡上下江，監兌漕糧，督修孝陵、兩監、應
天棘闈，所至激濁揚清，釐奸剔蠹。萬曆丁丑，以星變
上疏，論河套、貢市、漕河段疋諸宜興革狀，及請斥權
璫、退不法，宥諫臣，纚纚數萬言，皆切中時弊。時元輔」
張居正聞喪奪情，欲堂附會保留，堂不可。復劾大臣
之黨庇者，益與張忤。出為四川參議，竟用大計貶堂
​
歸。遂家居奉母，絕意仕進，凡九膺薦剡，不起。母終，起
復廣西僉事。大征岑湊，奏捷，晉光祿寺少卿。疏裁冗
費，又請皇太子冠婚。危言勁氣，不減居南臺時。未幾，
奉使冊封，以疾不允，遂拜南京尚寶司卿。疏再上，乃
許致仕。

陳薦
[
编辑
]

按《永州府志》：「薦，字君庸，隆慶丁卯，冠楚闈。辛未捷南
宮，授松江司理，選御史。中涓馮保忌之，家居三載，復
起兩差巡方。萬曆壬午按陝，時秦地荒旱，上疏捐振，
全活甚眾。補河南憲副，歷江西大參，四川廉使，晉雲
南大中丞，為留都操江都御史。戊戌陞左僉都御史，
陟大司徒，總督漕運，進大冢宰。壽八十餘。著《古今衷
辨》」百餘卷，藏於家。

陳履
[
编辑
]

按《廣東通志》：「履字德基，原名天澤，東莞人。隆慶辛未
進士，授蒲圻縣，移繁休寧。俗靡輕俠健訟，履一以長
厚約儉化之。補浙江崇德縣，陞蘇州府海防同知。奉
命浙江監兌，陞戶部郎中，司餉蘇州，課績為督儲第
一。擢廣西副使，備兵蒼梧。以病致仕歸。杜門謝客，結
社浮丘，日以吟詠為事。著有《懸榻齋稿》。」

陳邦傑
[
编辑

按《廣東通志》：「邦傑，徐聞人，素威武。隆慶六年，倭寇逼
城，邦傑挺身出戰，遇害。」

陳陞
[
编辑
]

按《武進縣志》：陞，字省涵。父望軒，隆慶間論戍者，例僉
里民防送。會有巨惡遣戍，黔縣掾某舉望軒防送，望
軒窘，將自盡，陞願代行，得如請。或語遠行無資，可株
連某某資之。陞曰：「吾為父死，何忍累人。」遂往。後卒歸。

陳國楨
[
编辑
]

按《延平府志》：「國楨，號調梅，南平人。由舉人授太寧諭，
陞長寧令。值山寇陳萬鍾等巨萬據九連山，國楨率
鄉勇計搗其穴，斬賊級七百，賊奔潰。萬曆癸酉，行取
考選，值內艱歸。服闋，改戶部主事，稅蕪湖歸。十年而
卒，時年七十七。國楨性仁厚，恕以接物，幼洽群書，老
而不倦。」

陳中漸
〈子與郊　與相〉
[
编辑
]

按《浙江通志》：「中漸號風山，海寧人。為名諸生，喜周人
之急，所貸予，常焚券不責償。某氏女坐怨家誣衊，不
能自明，中漸挺身白其冤。長子與郊，萬曆甲戌進士，
仕至太常少卿。次子與相，仕至貴州按察副使，兩受
貤贈，子孫登科名仕籍者三十餘人。人謂中漸陰德，
世食其報云。」

陳泰來
[
编辑
]

按《明外史于孔兼傳》：「陳泰來，字伯孚，平湖人。年十九，
舉萬曆五年進士，授順天教授，進國子博士，見執政
與言路相水火，上書規之。坐是五年不調，引疾歸。久
之，起禮部主事，進員外郎。疏請建儲，不報。踰年遂卒，
年三十六。天啟中，贈光祿少卿。」

陳禹謨
[
编辑
]

按《浙江通志》：「禹謨，字孟文，萬曆五年進士。擢監察御
史，巡兩淮鹽政，改巡江西。還京，給事中孟養浩以爭
國本杖闕下。禹謨疏力諫，上怒，并杖，乞終養。天啟元
年，遷左侍郎，得代還里，俄聞警，遽命促裝，冒暑陸行，
得陛見。以勞瘁下血，遂卒於邸。贈刑部尚書，予祭葬。
所著有《奏議》十卷。」

陳登雲
[
编辑
]

按《明外史陳登雲傳》：「登雲，字從龍，唐山人。萬曆五年
進士。除鄢陵知縣，政最，徵授御史。出按遼東，改巡山
西。還朝，會廷臣方爭建儲，謂議不早決，由貴妃家陰
沮之。十六年六月，遂因災異抗疏劾妃父鄭承憲。疏
入，貴妃、承憲皆怒，同列亦為登雲危，帝竟留中不下，
朝右皆憚之。出按河南，風裁峻厲，以久次當擢京卿」，
累寢不下。遂移疾歸。尋卒。

陳璧
[
编辑
]

按《福州府志》：「璧字道良，福清人。萬曆丁丑進士。璧初
為歸德推官，以風裁著。入為刑、禮二科給事中，為執
政所忌，出知太平府，遷廣東提學副使。秉公衡文，士
咸仰之。尋轉湖廣參政，山東按察使。尋以右布政備
兵淮揚，與璫忤，遂乞終養歸，卒。」

陳尚象
[
编辑
]

按《明外史李獻可傳》：「萬曆二十年，六科諸臣疏請豫
教。疏入，帝怒，被旨譙讓。吏科右給事中陳尚象復爭
之，坐斥為民。尚象，萬曆八年進士，都勻人。以中書舍
人為給事中，嘗劾罷尚書李鯉，為士論所非。後以直
言去，國人始稱焉。天啟中，贈光祿少卿。」

陳惟芝
[
编辑

按《河南通志》：「惟芝字德禎，孟津人。萬曆庚辰進士，官
御史，歷掌河南道。時鄭貴妃寵倖東宮，久不決，惟芝
疏請速立東宮，以定國本。後巡撫應天卒。」

陳所學
[
编辑
]

按《景陵縣志》：「所學字正甫，號志寰，萬曆庚辰進士。初
​
授刑部主事，旋陞工部虞衡，典試滇南，再轉司榷武

林，謹飭關政。陞守新安郡，政清刑簡。擢三晉提學，分
巡冀北，復轄福建右司，陞浙江右司，奉撫山西，提督
鴈門等關。時值旱蝗，邊警拮据，兵餉昕夕靡寧。旋總
督南京糧儲、戶部右侍郎，轉北京戶部左侍郎，陪侍」
經筵，加工部，轉戶部尚書。到任日，值給諫楊璉糾劾
《逆璫》事，上怒，不測所學，上書力救，不報，遂歸。

陳汝璧
[
编辑
]

按《沔陽州志》：「汝璧，字立甫，燭之嗣子也。萬曆癸未進
士，授紹興司理，拜禮曹。所著有《蘭省集》《隱園詩》行於
世。」

陳增
[
编辑
]

按《明外史陳增傳》：「增，神宗朝礦稅大監也。帝心頗好
利，左右數以利嘗之。萬曆十二年，房山縣民史錦奏
請開礦。十六年，中使祠五臺山，還言紫荊關外廣昌
靈丘有礦稅，可作銀冶。帝聞之心喜，大學士申時行
等執不可。至二十年，寧夏用兵，費帑金二百餘萬。二
十七年，播州用兵，又費帑金二三百萬。國用大匱。計
臣蒿目，礦稅由此大興。」其後言礦者爭走闕下，中使
四出。增奉敕開採山東。增始至山東，即劾福山知縣
韋國賢。帝為逮問削職。益都知縣吳宗堯抗增，被陷
幾死。巡撫尹應元奏增二十大罪，亦罰俸。已，復命增
兼徵山東店稅，與臨清稅監馬堂相爭。帝為和解，使
增稅東昌。增勢益橫，肆惡山東。十年至三十三年始
死。

陳陛
[
编辑

按《河南通志》：「陛，夏邑人。父世恩，萬曆丙戌進士，歷戶
科給事中，有聲望。陛登癸丑進士，授南戶部主事，吏

德，隆慶丁卯舉人，博文敦行。兄陞，辛丑進士，戶部郎
中，並有直聲政績。」

陳大道
[
编辑
]

按《襄陽府志》：「大道，號蘇嶺，光化人。萬曆己卯舉人，丙
戌進士，由知縣官至戶部尚書，歷階一十七轉，效忠
四十餘年，肅清綱紀，人畏其嚴，賑恤災傷，民懷其惠。
正直忠厚，無愧名臣。賜祭葬。」

陳道亨
[
编辑
]

按《明外史陳道亨傳》：「道亨，字孟起，新建人。萬曆十四
年進士。除刑部主事，歷南京吏部郎中。遭母喪，由湖
廣參政遷山東按察使、右布政使，轉福建為左。所至
不私一錢。以右副都御史提督操江。光宗立，進工部
右侍郎，總理河道。天啟二年，妖賊徐鴻儒作亂，道亨
守濟寧，扼諸要害，以衛漕舟。事平，拜南京兵部尚書」，
參贊機務。楊漣等群擊魏忠賢，被譙責。道亨憤，偕九
卿上言，不納，遂連疏求去。詔許乘傳歸。踰年卒。道亨
貞亮有守，自參政至尚書，不以家累自隨，一蒼頭執
爨而已。崇禎初，贈太子少保，諡「清襄。」子弘緒，字士業，
為晉州知州，以文名。

陳輔堯
[
编辑
]

按《揚州府志》：「輔堯，字九室，江都人。萬曆戊子舉於鄉，
屢上春官不第。謁選，授長寧令，數月邑大治。調歸善
縣，聲望益著。考最，以廉為天下第一。入覲，授膠州守。
州瀕海多盜，驕橫難治，輔堯寬嚴並濟，民皆帖服。委
往瀋陽查馬，事未竣而遼陷，輔堯拔佩刀自刎而死。
兩臺上其事，贈按察司僉事，諡忠烈。」

陳基虞
[
编辑
]

按《同安縣志》：基虞，字志華，號賓門。萬曆己丑進士。性
孝友，戅直寡諧。初除蕭山令，以忤津要左遷，後移南
雄司李，晉南刑曹郎。有大貴欲軋一異己者，基虞堅
持不可。歷守三郡，人多去思。刺彰德時，畿輔猝警，中
丞范景文、戴星入援，基虞措置軍需，咄嗟立辦。擢粵
東兵憲，以不媚權貴得調，拂衣歸。

陳幼學
[
编辑
]

按《明外史陳幼學傳》：「幼學，字志行，無錫人。萬曆十七
年進士。授確山知縣。政務惠民，調繁中牟，政績茂著。
以不通權貴，當考察拾遺，掌道御史擬斥之，其子爭，
乃已。稍遷刑部主事，以員外郎恤刑畿輔，出矜疑三
百餘人，進郎中，遷湖州知府。幼學疾惡嚴，其於細民
務安全之，諸孝子、節婦善人無所不旌揚，一郡大治。」
御史將薦之，徵其治行。推官閻世科列上三十六事。
御史以聞。詔加按察副使，仍視郡事。久之，以副使督
九江兵備。幼學年已七十，其母尚在，遂以終養歸。母
卒，不復出。天啟三年起南京光祿少卿，改太常少卿，

歸農，每百人，以安撫官護之。賊本無降意，既出棧道，
遂不受約束，盡殺安撫官五十餘人，攻掠州縣，關中
大震。巡按御史傅永淳以聞。帝怒，下詔切責。奇瑜亦
悔失計，委罪他人以自解。給事中顧國寶劾奇瑜誤
封疆，詔解任候勘。御史傅永淳復劾奇瑜「解隴州圍，
報首功不實。」詔除名，錦衣官逮訊，罪當死。有庇之者，
九年六月謫戍邊。初，奇瑜官南陽，唐王殺其世子，欲
并廢世子子聿鍵。賴奇瑜力，聿鍵得為世孫。後聿鍵
自立於閩，召奇瑜為東閣大學士；道遠，未聞命，卒於
家。
