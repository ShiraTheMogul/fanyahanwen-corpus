《彭城南樓》
宋·文同
[
编辑

百尺壓城端，飛簷欲上摶。湖光搖埤堄，山影轉闌干。
秀野含春煦，喬林擁暮寒。回頭大岷雪，千仞玉㠝岏。

《煙雨樓》
鄭俠
[
编辑
]

「仙人居處即鼇宮，更作層樓峭倚空。」群岫西來煙漠
漠，大江南去雨濛濛。花鑣柳策熙
裡，耘笠漁蓑笑
語中。別有夜楹千里月，憑闌清興與誰同。

《陳待制湖樓》
趙師秀
[
编辑
]

何處飛來縹緲中，人間惟有畫圖同。兩層簾幕垂無
地，一片笙簫起半空。巖竹倒添秋水碧，渚蓮平接夕
陽紅。遊人未達蒙莊旨，虛倚闌干面面通。

《鄂州南樓》
黃庭堅
[
编辑
]

四顧山光接水光，憑欄十里芰荷香。清風明月無人
管，併作南來一味涼。

《雨中登岳陽樓望君山》
前人
[
编辑
]

滿川風雨獨憑闌，綰結湘娥十二鬟。可惜不當湖水
面，銀盤堆裡看青山。

《疊嶂樓》
梅詢
[
编辑
]

謝公城上謝公樓，百尺欄杆掛斗牛。碧瓦萬家煙樹
密，蒼崖一檻瀑泉流。波光灔灔前溪滿，剎影亭亭古
寺幽。此地近除新太守，綠窗明月為君留。

《寓居合江樓》
蘇軾
[
编辑
]

「海上蔥蘢氣佳哉，二江合處朱樓開。蓬萊方丈應不遠，肯為蘇子浮江來。」江風初涼睡正美，樓上啼鴉呼
我起。我今身世兩相違，西流白日東流水。樓中老人
日清新，天上豈有癡仙人。三山咫尺不歸去，一杯付
與羅浮春。

《望海樓晚景二首》
前人
[
编辑

海上濤頭一線來，樓前指顧雪成堆。從今潮上君須

《聚遠樓二首》
前人
[
编辑

又

《李公擇求黃鶴樓詩因記舊所聞于馮當世者》
[
编辑
]

前人

黃鶴樓前月滿川，抱關老卒飢不眠。夜聞三人笑語
言，羽衣著屐響空山。非鬼非人意其仙，石扉三扣聲
清圓。洞中鏗鋐落門關，縹緲入室如飛煙。雞鳴月落
風馭還，迎拜稽首願執鞭。汝非其人骨腥膻，黃金乞
得重莫肩。持歸包裹弊席氈，夜穿茅屋光射天。里閭
來觀已變遷，似石非石鈆非鈆。或取而有眾忿喧，訟
歸有司今幾年。無功暴得喜欲顛，神人戲汝真可憐。
願君為考然不然，此語可信《馮公傳》。

《望海樓》
米芾
[
编辑
]

雲間鐵甕近青天，縹緲飛樓百尺連。三峽江聲流筆
底，六朝山影落樽前。幾番畫角催紅日，無事滄洲起
白煙。忽憶賞心何處是，春風秋月兩茫然。

《望湖樓晚眺》
楊時
[
编辑
]

斜日侵簾上玉鉤，簷花飛動錦文浮。湖光寫出千峰
秀，天影融成十里秋。翠鷸翻風窺淺水，片雲隨意入
滄洲。留連更待東窗月，注目晴空獨倚樓。

范成大
[
编辑

渚，蜀江無語抱南樓。燭天燈火三更市，搖月旌旗萬
里舟。卻笑鱸江垂釣叟，武昌魚好便淹留
​

前人

编辑

《宴西樓》

[
编辑

頰紅。歸路迎涼更堪愛，摩訶池上月方中。

《黃鶴樓》

[
编辑

長江巨浪拍天浮，城郭相望萬景收。漢水北吞雲夢

岸秋。黃鶴樓高人不見，卻隨鸚鵡過汀洲。

《文選樓》
李廌
[
编辑
]

申轅應楚聘，鄒枚適梁苑。藩侯喜賓客，賢賢易鷹犬。
黃綺遊漢庭，羽翼繒繳遠。秦府十八公，攀附名益顯。
昭明眾才子，文囿俾蒐選。高齋切浮雲，雉堞俯晴巘。
尚應媿《河間》，筆削非大典。

编辑

《夏曼卿作新樓扁曰瀟湘片景》
戴昺
[
编辑
]

有此一樓足，悠然萬慮忘。拓開風月地，壓斷水雲鄉。
四野留春色，千峰照夕陽。眼前無限景，何處認「瀟湘。」《秋浦樓》
趙葵
[
编辑
]

「麗譙岧嶢壯城闕，萬里關河歸目睫。雨餘漁釣玉奩開，煙外芙蓉翠屏列。吳頭楚尾二十秋，滿耳絃歌聲未絕。不才濫綴鴛鷺行，夜夢時還許歸謁。蕭晨振策來翠微，母憐吾兒倍怡悅。昔偕汝父居是邦，舊事辛苦為兒說。星星鶴髮簪霞冠，笑看朱衣擁金節。一門和氣皆君恩，恩與天同酬未得。生平區區忠孝心，歲」晚願為松與柏。可堪清賞屬登臨，風景不殊人事別。
徘徊徙倚十二闌，角聲吹上梅梢月。

《燕子樓》
文天祥
[
编辑
]

《自別》張公子，「嬋娟不下樓。遂令樓上燕，百歲稱風流。我遊彭城門，來弔楚王闕。問樓在何處，城東草如雪。蛾眉代不乏，埋沒安足論。因何張家妾，名與山川存。自古皆有死，忠義長不沒。但傳美人心，不說美人色。」《黃鶴樓歌》
元·陳孚
[
编辑
]

「嶪嶪乎黃鶴之樓兮，突起乎天之東南。吾不知其幾百尺兮，踞石磴而仰望。眩金碧之耽耽，手捫星漢如可近。但見天飆吹髮寒鬖鬖，瞿塘三峽之波濤。洶湧訇擊而下兮，雷聲怒撼於江潭。忽繞城以北匯，淨若萬頃之青藍。楚山數點，鸞騰蛟躍兮，碧影倒浸乎煙嵐。殘霞似落未落兮，蒲獵獵以風偃，柳裊裊以露含。」武昌亭臺，一十萬瓦，光參差，浮楩楠。下視十二之衢
兮，袨服士女東西行者，藐蠕蠕之吳蠶。黃鶴之仙人，
霓冠青瑤簪，御絳旌於列缺。倒景兮，偶見我以大笑，
欲駐我之征驂。攀東溟之博羅曜，折西極之優缽曇。
飲我以葡萄。鴨頭之綠兮，侑以洞庭之蒼柑。洞庭帝
子鼓軒轅之瑟兮，舞干戚而撞宮函。白也挾赤鯨以
旁睨，崔顥怩縮而不敢以談。浩浩乎萬丈之氣兮，長
虹橫空夭矯而方酣。下蟠黃之輿，上斡元之堪。安得
挽招搖以酌元氣兮，妙太極而函三。慨彼在昔，如焚
如惔。陶司馬之狂悖，庾太令之貪惏。鸚鵡之洲，何罪
而戮？赤壁之磯，何功而戡？吾豈若二三子斷崑崙之
璞兮，輕蹈夫大阿之鐔。「飛來兮黃鶴，跨汝從兮彭聃。」《燕子樓歌二首》
前人
[
编辑
]

長相思，久別離，東風不暖殘燕支。乳鴉困，柔鸞悲。櫻
桃泫紅膩，蘼蕪凋綠滋。牙床琥珀枕，夢君君不知。

又

《長相思》，久別離，珠樓無人但有月。翠屏寒，銀燭歇。芙
蕖為誰憐，丁香空自結。淚滴錦襜褕，十年化為血。

《鄧州城樓》
元·好問
[
编辑
]

鄧州城下湍水流，鄧州城隅多古丘。隆中布衣不復
見，浮雲西去空悠悠。長鯨駕空海波立，老鶴叫月蒼
煙愁。自古江山感游子，今人誰解賦《登樓》。

《魚樂樓》
趙孟頫
[
编辑
]

樓下南來水，清冷百尺深。菰蒲終夜響，楊柳半溪陰。
日月馳人世，江湖動客心。向來歌舞宴，達曉看橫參。

《八詠樓》
前人
[
编辑
]

山城秋色淨朝暉，極目登臨未擬歸。羽士曾聞遼鶴
語，征人又見塞鴻飛。西流二水玻璃合，南去千峰紫
翠圍。如此山川良不惡，休文何事不勝衣。

《題豐樂樓》
楊載
[
编辑
]

崢嶸飛構壓名邦，西望平湖東望江。氣合重元蒙沆
瀣，標存九域奠洪龐。朝來散霧縈朱栱，夜後流星透
碧窗。倚遍闌干愁目眩，鳶飛旋轉故雙雙。

===
《層樓晚眺》
薩都剌
===
​
廣寒世界夜迢迢，醉拍闌干酒易消。河漢入樓天不

夜，江風吹月夜初潮。光搖翠幕金蓮炬，夢斷涼雲碧
玉簫。休唱當時《後庭曲》，六朝宮殿草蕭蕭。

《樓居春曉望元圃》
張雨
[
编辑
]

子晉新宮倚太霞，繞湖煙火萬人家。觀臺一面無人
處，日出煙消都是花。

《岳陽樓》
〈有序〉
張經
[
