《九日曲江　　　　　　　　　》唐·杜甫

「綴席茱萸好，浮舟菡苕衰。季秋時欲半，九日意兼悲。」江水清源曲，荊門此路疑。晚來高興盡，搖蕩「菊花期。」
九日楊奉先會白水崔明府　　　前人
[
编辑
]

「今日潘懷縣，同時陸浚儀。坐開桑落酒，來把菊花枝。」天宇清霜淨，公堂宿霧披。晚酣留客舞，《鳧舄》共差池。

九日諸人集於林　　　　　　　前人
[
编辑
]

《九日》明朝是，相要舊俗非。老翁難早出，賢客幸知歸。
舊采黃花賸，新梳白髮微。漫看年少樂，忍淚已霑衣。

復愁　　　　　　　　　　　　前人
[
编辑
]

每恨陶彭澤，無錢對菊花。如今《九日至》，自覺酒須賒。

九日藍田崔氏莊　　　　　　　前人
[
编辑
]

老去悲秋強自寬，興來今日盡君歡。羞將短髮還吹
帽，笑倩旁人為正冠。藍水遠從千澗落，玉山高並兩
峰寒。明年此會知誰健，醉把茱萸子細看。

九日登梓州城　　　　　　　　前人
[
编辑
]

客心驚暮序，賓雁下襄州。共賞重陽節，言尋戲馬遊。
湖風秋戍柳，江雨暗山樓。且酌東籬菊，聊祛《南國》愁。

九日二首　　　　　　　　　　前人
[
编辑
]

「舊日重陽酒，傳杯不放杯。即今蓬鬢改，但媿菊花開。」《北闕》心長戀，西江首獨回。茱萸賜朝士，難得一枝來。
舊與蘇司業，兼隨鄭廣文。采花香泛泛，坐客醉紛紛。
《野樹》歌還倚，秋砧醒卻聞。歡娛兩冥漠，西北有孤雲。

九日　　　　　　　　　　　　前人
[
编辑
]

「重陽獨酌杯中酒，抱病起登江上臺。」竹葉於人既無
​
分，菊花從此不須開。殊方日落元猿哭，舊國霜前「白雁來。」弟妹蕭條各何在，干戈衰謝兩相催。

登高　　　　　　　　　　　　前人
[
编辑
]

風急天高猿嘯哀，渚清沙白鳥飛迴。無邊落木蕭蕭
下，不盡長江滾滾來。萬里悲秋常作客，百年多病獨
登臺。艱難苦恨繁霜鬢，潦倒新停濁酒杯。

九日奉寄嚴大夫　　　　　　　前人
[
编辑
]

「九日應愁思，經時冒險艱。不眠持漢節，何路出巴山。」小驛香醪嫩，重嚴細菊斑。遙知簇鞍馬，迴首白雲間。

九日閒居寄登高數子　　　　　錢起
[
编辑
]

初服棲窮巷，重陽憶舊遊。門閒謝病日，心醉授衣秋。
酒盡寒花笑，庭空暝雀愁。今朝落帽客，幾處管絃留。

九日田舍　　　　　　　　　　前人
[
编辑
]

今日吾家野興偏，東籬黃菊映秋田。浮雲暝鳥飛將
盡，始達青山新月前。

九日登玉山　　　　　　　　　前人
[
编辑
]

「霞景青山上，誰知此勝遊。」龍沙傳往事，菊酒對今秋。
步石隨雲起，題詩向水流。忘歸更有處，松下片雲幽。

九日寄姪箊箕亭　　　　　　　前人
[
编辑
]

采菊偏相憶，傳香寄便風。今朝竹林下，莫使桂樽空。

九日巴丘楊公臺上宴集　　　　張繼
[
编辑
]

淒淒霜日上高臺，水國秋涼客思哀。萬疊銀山寒浪
起，一行斜字早鴻來。誰家搗練孤城暮，何處題衣遠
信回。江漢路長身不定，菊花三笑旅懷開。

同徐侍郎五雲谿新亭重陽宴作
[
编辑
]

獨孤及

萬峰蒼翠色，雙谿清淺流。已符東山趣，況值江南秋。
白露天地肅，黃花門館幽。山公惜美景，肯為芳樽留。
五馬照池塘，繁絃催獻酬。臨風孟嘉帽，乘興李膺舟。
騁望傲千古，當歌遺《四愁》。豈令永和人，獨擅山陰遊。

九月九日李蘇州東樓宴　　　　前人
[
编辑
]

「是菊花開日，當君乘興秋。」風前孟嘉帽，月下庾公樓。
酒最留征客，歌能破別愁。醉歸無以贈，祇奉萬年酬。

重陽日酬李觀　　　　　　　皇甫冉
[
编辑
]

不見白衣來送酒，但令黃菊自開花。愁看日晚良辰
過，步步行尋「陶令家。」
九日送別　　　　　　　　　王之渙
[
编辑
]

薊庭蕭瑟故人稀。何處登高且送歸。今日暫同芳菊
酒，明朝應作斷蓬飛。

九日陪崔峒郎中北山讌　　　　嚴維
[
编辑
]

上客南臺至，重陽此會文。菊芳寒露洗，杯翠夕陽曛。
務簡人同醉，溪閒鳥自群。府中官最小，惟有孟參軍。

九日賈明府見訪　　　　　　　戎昱
[
