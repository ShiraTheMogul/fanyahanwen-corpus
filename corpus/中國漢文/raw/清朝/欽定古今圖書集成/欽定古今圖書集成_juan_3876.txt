交誼典第七十六卷

餞別部藝文六
〈詩〉

编辑
]

《都門觀別》
金·劉昂
[
编辑
]

買酒消閒愁，剪刀剪流水。閒愁不可消，流水無窮已
悠悠。窗下斷腸波，總是行人墮淚多。門外馬嘶思遠
道，小嚬猶唱《渭城歌》。聲未斷征鞍發，望斷垂楊人影
滅。斜陽照影卻歸來。兩地相望今夜月，閱人多矣主
人翁，離別多歸一笑中。陌上行人總不悟，年年楊柳
怨春風。

《送客》
周昂
[
编辑
]

「相見席不煖，送行情更牽。只愁人面隔，不放馬蹄前。」寒迥雲垂地，溪平水接天。山川後期闊，把臂兩茫然。

《留別》
李芳
[
编辑
]

祿食媿踰量，智困念歸愚。符竹恆為累，幸及引年初。
驅馬國西門，初服返田廬。金閨富才彥，絕足駃高衢。
眷我謝朝幘，冠蓋寵歸途。歸途豈不榮，顧瞻亦踟躕。
煌煌丹山鳳，覽德萃清都。行人得棲止，老鶴青天孤。
石樓俯清伊，旁有野人居。儻有經過便，山水足相娛
​

《留別》
李俊民
[
编辑
]

耳畔頻頻杜宇聲，馬頭山色翠相迎。一杯不盡留連
意，送客風來便好行。

《潁亭留別》
元·好問
[
编辑
]

故人重分攜，臨流駐歸駕。乾坤展清眺，萬景若相借。
北風三日雪，太素秉元化。九山鬱崢嶸，了不受陵跨。
寒波淡淡起，白鳥悠悠下。懷歸人自急，物態本閒暇。
壺觴負吟嘯，塵土足悲咤。回首亭中人，平林澹如畫。

《別李用卿二首》
前人
[
编辑
]

行路澀於棘，單車望千山。歌君《歸雲曲》，清涕留餘潸。
六年河朔州，動輒得謗訕。惟君篤高誼，日來款柴關。
古交松柏心，今交桃李顏。古人去不返，古道挽不還。
相思一尊酒，幽恨寄山間。

城居日蛙黽，局促復局促。去作山中客，放浪誰檢束。
溪光淡於冰，山骨淨如玉。懷我同心人，團茅住深竹。
垂綸鮮可食，種秫酒亦足。石壇三萬丈，醉眼天一粟。
安得萬里風，相從兩黃鵠。

[
编辑

霜落江寒鳴鴈稀，倚樓人定怨歸遲。笛聲喚起山頭
月，飛上青天照別離。

《別友人》
楊惟中
[
编辑

良朋不易得，此去復誰群。別酒無勞勸，濃愁已自醺。
間關花外鳥，冷淡日邊雲。莫唱《陽關》徹，離聲忍更聞。

《宜春贈別》
郭昂
[
编辑

微茫煙浪浦帆開，一曲《琵琶》淚滿腮。江水不如湘水
好，送人東去復西來。

《長歌出門別親友》
陳孚
[
编辑
]

停君漢水浮鴨之翠杓，聽我嶧山棲鸞之綠桐。男兒
拂衣出門去，龍泉三尺光如虹。君不見磻溪鶴髮釣
魚者，偶擲漁竿來牧野。白旄麾開炮烙煙，桓圭朱芾
侯青社。又不見南陽臥龍人不識，一朝佐漢坐狼石。
羽扇輕搖蛇鳥驚，火精焰焰天西極。旂亭四月柳如
藍，紫騮嘶風黃金驂。豈無《叩牛歌》，亦有捫蝨談天生
巉巖崒嵂骨，蒿萊槁死誰能甘。我欲登泰山，扶筇款
天關。東溟若木如可攀，手弄日月青雲間。我欲渡黃
河，赤腳凌秋波。水仙樓閣銀嵯峨，徑叱海若笞蛟鼉。
停君翠杓，聽我綠桐。真人開天六合同風。騶虞鳳凰
飛舞，鎬宮有線五色，獻於重瞳，補舜衣裳。山龍華蟲
虎豹，九關兮不可以達。吾則脫冠歸來兮，丹丘之青
峰。長揖二三子，目送西征鴻。

《延祥餞夢符行》
張伯淳
[
编辑
]

古交重氣誼，不為勢位隔。會少別離多，志士深所惜。
驄馬東南來，來暮去何亟。留連苦無計，杯酒聊永日。
絕嫌城市喧，一舸訪荒寂。孤山芳意歇，青子漸堪摘。
淒淒風雨橫，黯黯楊柳碧。天公豈有意，助我動秋色。
重來定何時，慰此長相益。

《留別學宮諸友》
李彝
[
编辑
]

萬事貴知止，吾行已覺遲。忍聞《三疊曲》，聊贈一篇詩。
載酒相從處，停舟不語時。感君無盡意，重會若為期。

《重餞李九時毅賦得南樓月》
揭傒斯
[
编辑
]

娟娟臨古戍，晃晃辭煙樹。寒通雲夢深，白映蒼祠暮。
胡床看逾近，楚酒愁難駐。鴈背欲成霜，林梢初泣露。
故人明夜泊，相望定何處？且照東湖歸，行送歸舟去。

《送別曲》
察伋
[
编辑
]

曈曨出扶桑，照見大黑洋。直升中天上，萬國蒙清光。
三山樓閣蓬萊東。丹霞翠壁金芙蓉，鴻濛凝結古元
氣。我欲往遊從赤松。郯郎朝玉京，船發南風生。海頭。
撾鼓人起舞，椎牛釃酒祈神明。遠寄平安書，十日到
直沽。阿翁髮半白，莫醉黃公壚。

《折楊柳送方叔高》
趙期頤
[
编辑
]

楊柳青青春水生，借問行人行未行。雕弓在弢馬騰
櫪，家住湓江江上城。柔條好拂江頭路，千縷萬縷牽
情緒。馬上郎君新得官，阿誰解使留春住。留春住，住
欲歸，江南江北柳花飛。柳花飛，渡江水，遮莫東風吹
不起。

《留別京門知己》
〈并序〉
李泂
[
编辑
]

「我本山人，素志丘壑，獲歸名山，為願畢矣。」 爰以四月十一日離京師，是夜抵潞陽。慨然賦詩，遙慰匡廬隱者，并示金門諸公，為一噱云。

「野馬脫羈鞅，倏疑天地寬。臨風一長鳴，風吹散入青冥間。」頗如魯仲連，蹈海不復還。又如安期生，長留一
舄令人看。《江南》浩蕩忽如海，落日照耀浮雲關。既不
能低眉伏氣摧心顏，詭遇特達驚冥頑。又不能抱書
挾策干萬乘，調笑日月相迴盤。匡廬迢迢接仙山，仙
翁泛若秋雲閒。長松之陰引孤鶴，望我不見空長嘆。
「采鉛天池津，飲醁桃花灣。蒼梧倒影三湘寒，赤城霞氣生微瀾。鯨鯢翻空海波赤，曉色欲上扶桑難。人間之樂兮誠不足恃，何如歸臥棲巖巒。」棲巖巒，臥巖穴。
夜半天風吹酒醒，猶有西溪萬年月。

《古別離》
周權
[
编辑
]

天河限東西，經歲別女牛。社燕辭歸鴻，亦背春與秋
​
「人生苦離別，別多白人頭。十年阻江漢，音問何沈浮。豈惟腸九迴，輪轉日萬周。君看江頭水，東去無回流。君看山上雲，來往任悠悠。」
《懷別》
前人
[
编辑
]

青桑蔽繁陰，元鳥春將暮。東風老松花，長林翳黃霧。
俛首事鉛簡，流光暗中度。淮水日夜流，美人邈難晤。
賓鴻盡北歸，誰與達書素。長歌復徘徊，晴川渺煙樹。

《別友人》

[
编辑

別酒相傾別淚流，江流亦不為君留。片帆今夜又何
處，明月當天誰共樓。一鴈叫霜紅入葉，十年為客白
侵頭。莫嫌歸計多蕭索，三涇西風菊正秋。

《赴京別親友》
貢師泰
[
编辑
]

崇隄衛芳塘，塘上種楊柳。楊柳年年青，慈親未白首。
送我不忍別，出門復攜手。親友陟高岡，立馬望良久。
離懷急欲醉，盡此尊中酒。

《留別諸友分韻得日字》
陳高
[
编辑
]

寒色滿大江，北風吹落日。停舟別諸彥，中懷抱湮鬱。
夤緣結金蘭，深固比膠漆。佳會不可常，歲晏政寥慄。
居者成淹留，行者念家室。分攜在俄頃，東西永相失。
俯視流波去，仰看飛鳥疾。人生如浮萍，乾坤渺蕭瑟。

《折楊柳》
前人
[

二

三

昨日與子別，子已戒葷酒。予為念衝寒，屏飲未宜久。
況復羇旅間，亦須小飲否？子聞忽大笑，此言一何醜。
酒徒食肉人，嗷嗷特饞口。不見學道人，終年但飯糗。
但問志若為，酒乎亦何有。一飲不自持，終恐復濡首。
子言故自超，使我心獨疚。區區印跡泥，我愧猶株守。

四

「一別或千古，如何不念之。此地一相失，徘徊空爾為。」擾擾行路人，肩摩各東西。當其一投分，誰能無相離。
譬如未相識，紛紛復誰思。底須似師冕，而必某在斯。
