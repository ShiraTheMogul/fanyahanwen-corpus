許思謙妻李氏
[
编辑
]

按《漳州府志》：「李氏，南靖許思謙妻。嫁八月而謙亡，李堅貞自矢，以夫弟子承嗣。崇禎間，奉詔表其廬。」
陳一韓妻趙氏
[
编辑
]

按《漳州府志》：趙氏，海澄陳一韓妻。一韓署遼州，城陷
戰死。子燿曦方稚，趙聞訃，慟哭自縊。姑救之，不得死，
勸以存孤，趙悉遣其家人，僅留一老嫗曰：「寡婦不可以僮僕供使令。」課燿曦，非祭祀不使出。及燿曦登賢
書，趙氏病數日而卒，曦進藥不受。

謝珊妻張氏
[
编辑
]

按《漳州府志》：「張氏，龍溪庠生謝珊妻。珊早亡多難，氏百計存孤，死守成立。崇禎初，孫宗貴顯具疏題請，奉詔建坊旌表。」
王虞德妻黃氏
[
编辑
]

按《龍溪縣志》：「黃氏，王虞德妻，山東黃子道女也。幼端靜，習詩禮。及歸王，事舅姑以孝聞。年二十八，夫亡，即欲自經，姑諭撫孤為重，乃矢志養姑，盡力教子，嚴閨閫以肅婦道，勤紡績以供祀事。平生不妄言笑，鄉黨以為楷範。孀居六十餘年，年九十一卒。」
桂蕃妻張氏
[
编辑
]

按《漳浦縣志》：「張氏，應襲指揮桂蕃妻。蕃為父奏事於京，道亡。張年二十二，子方在乳，哀毀守志，坐臥一室，人罕見其面，以壽終。」
林雨濮妻陳氏
[
编辑
]

按《漳浦縣志》：「陳氏，鎮海衛林雨濮妻。年十八歸林。二十夫亡，家貧，唯一女矢志不可奪，依母家終其身。崇禎間旌表。」
鄭彥明繼室何氏
[
编辑
]

按《漳浦縣志》：何氏，鄭彥明繼室。年二十，適鄭，甫三載
夫亡，撫前妻子若己出。翁憐之，給銀四十兩供薪水。
何俟子十六歲付之，封識宛然。

蘇可教妻胡氏
[
编辑
]

按《海澄縣志》：胡氏，蘇可教妻，戶部郎中文耀女。可教
應試溺水死，胡擗踴江濱，籲天求之，三日得夫屍，抱
而親沐，慟絕者數。遺孤民俊甫六日，百計護持，謝絕
歸寧，雖至戚不一見。民俊弱冠舉南宮第十人，授戶
部主事。疏陳母節，奉詔坊表。

江汝松妻陳氏
[
编辑
]

按《海澄縣志》：陳氏，江汝松妻。夫與計偕客死，子思孝
生甫三日，母諷改適，陳指孤泣曰：「江氏四世遺此而已。」因斷髮自誓。姑歿，值洪水暴漲，終夜守柩，立水中，
仰天大慟，水為之退。卒年五十餘。有司表其門。

李能梁母許氏
[
编辑

按《平和縣志》：「許氏，貢士李能梁母。年二十九，生四子，夫亡。粵寇張璉作亂，財產盡失，幼者在懷，氏以一孀力持門戶，教四子俱列黌序。三貢大廷，年九十三卒。」
余先疇妻伍氏
[
编辑
]

按《清流縣志》：「伍氏，兵馬指揮使伍承杰孫女，適邑廩生余先疇。疇亡，教四子以詩書，夜執女紅，與共燈火誦讀，四子俱克成立。長日升，膺歲薦，有文行；次日光、日章，悉有聲。黌序守志四十餘年卒。」
雷憲章妻溫氏
[
编辑
]

按《清流縣志》：「溫氏，雷憲章妻，庠生雷作霖母。年十六適雷，越九載夫歿，氏苦守以養翁姑，自忍饑寒，甘旨無闕。親喪，哀毀骨立，祭葬如禮。居平紡績教子，履不及戶外，宗族以為家範。」
雷衢亨妻楊氏
[
编辑
]

按《清流縣志》：楊氏，雷衢亨妻，邑庠生雷方麒母。年十
七于歸，十八衢病亡，麒生未彌月，楊氏有死志。姑慰
之曰：「念能存我孤孫，勝死多也。」乃強起治喪。嗣是事
翁姑愈孝，教子極嚴，杜門屏息，僧尼巫覡不容往來。
年七十餘，始終如一。縣令表其門。

劉欽向妻伍氏
[
编辑

按《清流縣志》：「伍氏，永康縣令伍可願孫女。幼適儒士劉欽向，事夫有禮。舅姑年老，潔滫瀡勤定省以養之。欽向早世，守志撫孤，備極艱苦。長子夢橘，姿性警敏，以明經為名儒，孀居四十年如一日。」

吳士智妻葉氏
[
编辑

按《清流縣志》：「葉氏，吳士智妻。年十六歸吳，事繼姑伍氏盡孝。二十一，生子鎬。二十二智亡，截髮刺額，誓死撫孤。家貧姑老，勢不可支，力紡績以供甘旨。姑死，苦心營葬，早夜課子讀書，艱辛四十餘年。有司旌表。」
鄒銓妻李氏
[
编辑

按《清流縣志》：「李氏，鄒銓妻。年十七歸鄒，值翁永豐沒，未幾銓亦亡。氏年二十七，二子幼，家業傾頹，族人欲奪其志，不聽。苦守教子，以完夫志。孀居五十餘年。學使及觀察使并月給米一石優卹之。」
王承家妻曾氏
[
编辑

按《清流縣志》：「曾氏，處士王承家妻。生二子，長若，次顓。歸十年而承家亡，氏日夜哀慟，懿親慰解之。因苦節事老姑，更相為命。未幾，姑死，居喪營葬無違禮。年五十一卒。旌表。」
伍一翰妻余氏
[
编辑
]

按《清流縣志》：余氏，廩生伍一翰妻。翰亡，余氏慟哭，呼
天搶地，誓欲從死地下。家人固勸曰：「煢煢孤兒，既失怙，復失恃，將誰撫耶？」乃強起育子，課以詩書，悉見成
立。翁堣守雷州，清風兩袖，余氏謹守家訓，無敢少越。
學使行縣旌表。

伍宗銘妻黃氏
[
编辑
]

按《清流縣志》：「黃氏，明經伍元母，宗銘妻。幼有儀範。宗銘早亡，黃痛欲絕，謂所親曰：『吾夫罹此大變，吾將相隨九泉矣。家人環守之。姑復慰之曰：『而翁老且無他子，汝不為二孤計，寧忍吾二老無依乎』？遂強起治喪葬，延師教子，孀居三十年，始終如一。年六十有六，孫六人，曾孫九人。臨終曰：『吾苦守教汝曹，汝曹宜自奮志』』！」尋卒。

伍材妻黃氏
[
编辑

按《清流縣志》：「黃氏，伍材妻。材病亡，氏年二十五，無子，執喪以禮，誓無二志。養舅姑尤孝敬。或諷之嫁，咈然怒，築鴛鴦塚以自待。學使旌之。」
胡文顯妻湯氏
[
编辑
]

按《清流縣志》：湯氏，國子生胡文顯妻。歸十年，文顯以
事謫戍，止二女，無他親屬可依。湯氏勤紡績以事舅
姑。或勸改適，湯曰：「夫屬妾，養舅姑，守墳墓，吾已許之。今二親沒，胡氏無嗣，祖宗墳墓無託，若他適，是背義而失信，何以為人？」及二女長成，或勸贅婿，婦曰：「戶在軍籍，奈何累彼？」皆擇士族嫁之。年八十餘卒。

鄧向榮繼室鍾氏
[
编辑

按《清流縣志》：「鍾氏，奉訓大夫鄧向榮繼室，文選司鍾文俊女。善事舅姑。年二十七，夫暴亡，痛絕復甦，數日不食。親戚勸慰，強起治喪事。向榮蒞政廉潔，家計蕭然。鍾仗外氏為養，艱苦數十年，獲見前室子于京、于蘇、于林，聯翩仕宦。己生子于安，孫應中，先後魁鄉薦，年七十三終封恭人。」
葉福妻陳氏
[

按《清流縣志》：「陳氏年十六歸葉福。福會試北行，至南豐病還而沒。陳誓不再嫁，取篋中衣飾之美者，悉分諸妹。以年少，恐母奪其志，絕不往母家。年七十餘卒。」
賴世傳妻鄧氏
[
编辑

按《清流縣志》：「鄧氏，戶部主事鄧向榮女，行人賴世傳妻。世傳沒京邸，姑老子幼，路遠囊空，鄧氏伶仃，扶櫬歸葬，養姑教子，以完夫志。姑九十遘疾卒，氏年二十八而寡，苦節幾四十年。御史李如圭奏聞，旌其門。」
李亭妻裴氏
[
编辑
]

按《清流縣志》：裴氏，御史養清女。生而端慧，通經史，適
提學副使李于堅第三子亭。亭少有大志，草寇攻城
急，憤怒率民兵出城奮擊，陣陷被害。裴聞報號慟氣
絕，久之，救蘇，誓曰：「不能殺賊以復仇，奚用生為！」仗劍
欲往，家人力止以危詞。乃斷葷茹素，課二子讀書，歷
三十年，備極辛苦，應候旌表。

陳汝皋妻裴氏
[
编辑
]

按《清流縣志》：裴氏，郡庠生陳汝皋妻。年十八于歸，夫
弱冠學于莆，病亡。氏年二十，子士炳未及週，氏聞訃
死而復甦者三。及櫬至，觸地絕飲食數日。母慰之曰：
「盍念孤子，為存祀計。」始強啜粥，獨居一室，紡績供給。
事翁姑孝謹，教士炳成諸生，終身縞素，不簪花，不與
筵宴，苦節五十二年。崇禎間旌表。

雷廷秬妻伊氏

馮氏女
[
编辑
]

按《廣東通志》：馮氏女，南海馮希聘女也。幼失父母，吳
氏撫之。兒時習見其母志操，即知節孝大義，許婚里
人子高日煥。亡何，高子死，女請往執高喪。母與大母
難之曰：「若尚未字，非高婦也。」女泫然曰：「心已許之，有死無二，為節母女而二聘，不愧乎？且身為女子，終無益於父母，留將安歸？」固請往，母不能奪，從之。於是匍
匐詣高，撫屍哭盡哀。請於高父母曰：「煥雖未昏，今兒歸，則煥有婦，非殤也。請冠而殮，他日以祔於廟。」許之。
隨脫簪珥，具棺，出所織帛，手製衣衾。衣成，加冠於首，
躬為含殮。酌酒酹地，一慟幾絕。既殯，辭歸母家，笄而
後返。及歸，高事煥父母甚謹，撿身以禮，足不踰閫，同
室罕見其面。越八年，煥弟既娶，有子為立嗣。遠近聞
者，莫不稱歎，一時縉紳大夫作為詩歌，集而傳之。其
後二十餘年，煥父母俱歿，乃還母家養母，終其身，年
​
六十三卒。
