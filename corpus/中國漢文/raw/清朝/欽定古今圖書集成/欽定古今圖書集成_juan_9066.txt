苑囿部藝文二
〈詩〉
[
编辑
]

《大雅靈臺首章次章》
[
编辑
]

東萊呂氏曰：「前二章，樂文王有臺池鳥獸之樂也。」 

經始《靈臺》，經之營之。庶民攻之，不日成之。經始勿亟，
庶民子來。

王在靈囿，麀鹿攸伏。麀鹿濯濯，白鳥翯翯。王在靈沼，
於牣魚躍。

《雜詩》
〈四首錄二〉
魏·王粲
[
编辑
]

吉日簡清時，從君出西園。方軌策良馬，並驅厲中原。
北臨清漳水，西看《柏楊山》。回翔遊廣囿，逍遙波水間。

又

列車息眾駕，相伴綠水湄。幽蘭吐芳烈，芙蓉發紅暉。
百鳥何繽翻，振翼群相追。投網引潛魚，強弩下高飛。
白日已西邁，歡樂忽忘歸。

《樂遊應詔詩》
宋·范曄
[
编辑
]

崇盛歸朝闕，虛寂在川岑。山梁協孔性，黃屋非堯心。
軒駕時未肅，文囿降照臨。流雲起行蓋，晨風引鑾音。
原薄信平蔚，臺澗備曾深。蘭池清夏氣，修帳含秋陰。
遵渚攀蒙密，隨山上嶇嶔。睇目有極覽，遊情無近尋。
聞道雖已積，年力互頹侵。探己謝丹黻，感事懷長林。

《侍太子九日宴元圃詩》
齊·王儉
[
编辑
]

明明儲后，沖默其量。徘徊禮樂，優游風尚。微言外融，
幾神內王。就日齊暉，儀雲等望。本茂條榮，源澄流潔。
漢稱間平，周云魯衛。咨我藩華，方軼前軌。秋日在房，
鴻雁來翔。寥寥清景，靄靄微霜。草木搖落，幽蘭獨芳。
眷言淄苑，尚想濠梁。既暢旨酒，亦飽徽猷。有來斯悅，
無遠不柔。

《春日想上林》
梁·簡文帝
[
编辑
]

春風本自奇，楊柳最相宜。柳條恆著地，楊花好上衣。
處處春心動，常惜光陰移。西京董賢館，南宛習都池。
荇間魚共樂，桃上鳥相窺。香車雲母幰，駛馬黃金羈。

《元圃納涼》
同前
[
编辑
]

登山相劍閣，逗浦憶辰陽。飛流如凍雨，夜月似秋霜。
螢翻競晚熱，蟲思引秋涼。鳴波如礙石，闇草別蘭香。

《九日侍皇太子樂遊苑》
同前
[
编辑
]

離光麗景，神英春裕，副極儀天。金鏘玉度，監撫昭明。
善物宣布，惠潤崑瓊。澤熙垂露，秋晨精曜，駕動宮闈。
露點金節，霜沈玉璣。元戈側影，翠羽翻暉。庭回鶴蓋，
水照犀衣。蘭羞薦俎，竹酒澄芬。千音寫鳳，百戲承雲。
紫燕躍武，赤兔越空。橫飛鳥箭，半轉蛇弓。

《元圃講》
蕭統
[
编辑
]

白藏氣已暮，元英序方及。稍覺螿聲悽，轉聞鳴鴈急。
穿池狀浩汗，築峰形嶪岌。旰雲緣宇陰，晚景乘軒入。
風來幔影轉，霜流樹條濕。林際素羽翾，漪間赬尾吸。
試欲遊寶山，庶攸信根立。名利白巾談，筆札劉王給。
茲樂踰笙磬，寧止消涓邑。雖娛慧有三，終寡聞知十。

《九日侍宴樂遊苑》
丘遲
[
编辑
]

朱明已謝，《蓐收》司禮。爰理秋祓，備揚旌棨。奉璋峨峨，
金貂濟濟。上林弘敞，離宮非一。綵殿迴風，丹樓映日。
隋珠甲帳，屯衛周悉。睟容徐動，天儀澄謐。雲物斿颺，
光景高麗。枯葉未落，寒花委砌。絲桐激舞，《楚雅》閒慧。
參差繁響，殷勤流詣。

《侍宴樂遊苑送張徐州應詔詩》
前人
[
编辑
]

《詰旦》閶闔開，馳道聞鳳吹。輕荑承玉輦，細草藉龍騎。
風遲山尚響，雨息雲猶積。巢空初鳥飛，荇亂新魚戲。
實為北門重，匪親孰為寄。參差別念舉，肅穆恩波被。
小臣信多幸，投生豈酬義。

《九日侍宴樂遊苑》
何遜
[
编辑
]

皇德無餘讓，重規襲帝勛。垂衣化比屋，睠顧慎為君。
翾飛悅有道，卉木荷平分。宸襟動時豫，歲序屬涼氛。
城霞旦晃朗，槐霧曉氤氳。鸞輿和八襲，鳳駕啟千群。
羽觴懽湛露，佾舞奏《承雲》。禁林終宴晚，華池物色曛。
疏樹飜高葉，寒流聚細紋。晴軒連瑞氣，同惹御香芬。
日斜迢遞宇，風起嵯峨雲。運偶參侯服，恩洽廁朝聞。
於焉藉多幸，歲暮仰遊汾。

《南苑》
前人
[
编辑
]

花門闢千扇，苑戶開萬扉。樓殿聞珠履，竹樹隔羅衣。

《九日侍宴樂遊苑》
任昉
[
编辑
]

帝德峻《韶》《夏》，王功書《頌》平。共貫沿五勝，獨道邁三英。
我皇撫歸運，時乘信告成。一唱華鍾石，再撫被絲笙。

黃草歸雒木，梯山薦玉榮。時來濁河變，瑞起溫洛清
​
物色動宸眷，民豫降皇情。

《前題》
沈約
[
编辑
]

憑玉宅海，端扆御天。止流飛壑，靜震騰川。凝神貫極，
摛道漏泉。西裘委衽，南風在絃。暮芝始綠，年桂初丹。
上林葉下，滄池水寒。霜霑玉樹，鴈動輕瀾。停蹕玉陛，
徙衛璿墀。琱箱鳳彩，羽蓋鸞姿。虹旌迢遞，翠華葳蕤。
禮弘灞汭，義高洛湄。

《侍宴樂遊苑餞呂僧珍應詔》
前人
[
编辑
]

丹浦非樂戰，負重切君臨。我皇秉至德，忘己用堯心。
愍茲區宇內，魚鳥失飛沈。推轂二崤道，揚斾九河陰。
超乘盡三屬，選士皆百金。戎車出細柳，餞席遵上林。
命師誅後服，授律緩前禽。函轘方解帶，驍武稍披襟。
伐罪芒山曲，弔民伊水潯。將陪告成禮，待此未抽簪。

《從皇太子出元圃應令》
庾肩吾
[
编辑
]

春光起麗譙，屣步陟山椒。閣影臨飛蓋，鶯鳴入《洞簫》。
水還登故渚，樹長蔭前橋。綠荷生綺葉，丹藤上細苗。
顧循慚振藻，何用擬瓊瑤。

《蔬圃堂應詔》
前人
[
编辑
]

北宮多暇豫，時駕總鑾鑣。路靜繁葭撤，輪移羽蓋飄。
臨空坐飛觀，回首望浮橋。風長曙鐘近，地迥洛城遙。
疏林不礙日，涸浦暫通潮。徒然等賓從，並作媿群僚。

《奉和太子納涼梧下應令》
前人
[
编辑
]

北園涼氣早，步輦暫逍遙。避日交長扇，迎風列短簫。
山帶彈琴曲，桐橫棲鳳條。懸門開溜水，錦石鎮浮橋。
黑米生菰葉，青花出稻苗。無因學山藻，雲氣徒飄飄。

《送別於建興苑相逢》
前人
[
编辑
]

「相逢小苑北，停車問苑中。梅新雜柳故，粉白映綸紅。」
去影背斜日，香衣臨上風。雲流階漸黑，冰開池半通。
去馬船難駐，啼烏曲未終。「眷然從此別，車西馬復東。」

《暮遊山水應令賦得磧字》
前人
[
编辑
]

餘春屬清夜，西園恣遊歷。入逕轉金輿，開橋通畫鷁。
細藤初上楥，新流漸涵磧。雲峰沒城柳，電影開巖壁。

《九日侍宴樂遊苑應令》
前人
[
编辑
]

轍跡光周頌，巡遊盛夏功。鉤陳萬騎轉，閶闔九關通。
秋暉逐行漏，朔氣繞相風。獻壽重陽節，迴鑾上苑中。
疏山開輦道，間樹出離宮。玉醴吹巖菊，銀床落井桐。
御梨寒更紫，仙桃秋轉紅。飲羽山西射，浮雲冀北驄。
塵飛金埒滿，葉破柳條空。騰猿疑矯箭，驚雁避虛弓。
彫材濫杞梓，花綬接鵷鴻。愧乏天庭藻，徒參文雅雄。

《行過康王故第苑》
劉潛
[
编辑
]

入梁逢故苑，度薛見餘宮。尚識招賢閣，猶懷愛士風。
靈光一超遠，衡館亦蒙籠。洞門餘舊色，甘棠留故藂。
送禽悲不去，過客慕難窮。池竹徒如在，林堂曖已空。
遠橋隔樹出，迥澗隱岸通。芳流小山桂，塵起大王風。
具物咸如此，是地感余衷。空想陵前劍，徒悲壟上童。

《奉和六月壬午應令》
劉孝威
[
编辑
]

「元圃棲金碧，靈澗挹琨瑤。築山圖碣岫，穿池控海潮。
雷奔石鯨動，水闊牽牛遙。乘黿猶怯渡，鞭石詎成橋。
岸崩下生窟，壁峭上干霄。噪蛙常獨沸，游魚或自跳。
荒徑橫臨浦，空舟斜插橈。愁鴟集古樹，白鷺隱青苗。
神心重丘壑，散步懷漁樵。石累元卿徑，枝挂許由瓢。
伊臣本寂寞，由來畏市朝。為貪止山水，所競惟逍遙。」
寄言周伯況，勞君擅縠綃。

《奉和晚日》
前人
[
编辑
]

虯簷挂珠箔，虹梁卷霜綃。迷迭涵香長，芙蓉逐浪搖。
飛輪摶羽扇，翻車引落潮。甘泉推激水，迎風慚遠飆。
寄言王待詔，因聲張子僑。吾君安已樂，無勞誦《洞簫》。

《遊建興苑》
紀少瑜
[
编辑
]

丹陵抱天邑，紫淵更上林。銀臺懸百仞，玉樹起千尋。
水流冠蓋影，風揚歌吹音。踟躕憐拾翠，顧步惜遺簪。
日落庭光轉，方幰屢移陰。終言樂未極，不道愛黃金。

《遊故苑》
陳釋曇瑗
[
编辑

「丹陽松葉少，白水黍苗多。浸淫下客淚，哀怨動民歌。」
春溪度短葛，秋浦沒長莎。麋鹿自騰倚，車騎絕經過。
蕭條四野望，惆悵將如何。

《遊故苑》
釋洪偃
[
编辑
]

龍田留故苑，汾水結餘波。悵望傷遊目，辛酸思緒多。
涼颸慘高樹，濃露變輕蘿。澤葵猶帶荇，池竹尚侵荷。
秋風徒自急，無復《白雲歌》。

《御幸樂遊苑侍宴》
張正見
[
编辑
]

「大君臨四表，榮光普八埏。」區中文化洽，海外武功宣。
鳳下書丹篆，龜符著綠編。昆明不習戰，雲夢豈遊畋。
軌文通萬國，旗節靖三邊。高秋藐姑射，睿想屬汾川。

文徵明《西苑詩後記》云：「嘉靖乙酉春，同官陳侍講魯南、馬修撰仲房、王編修繩武，偕余為西苑之遊。先是，魯南教內書堂，識守苑官王滿，是日實導余三人行，因得盡歷諸勝。既歸，隨所記憶，為詩十篇。竊念神宮祕府，迥出天上，非人間所得窺視。而吾徒際會清時，列官禁近，遂得以其暇日遊衍其中，獨非幸與？然而」 勝踐難逢，佳期不再，而余行且歸老江南，追思舊遊，可復得耶？因盡錄諸詩藏之。他時邂逅林翁溪叟，展卷理詠，殆猶置身於廣寒太液之間也。是歲四月既望識。

沉浮。控飛梁以架迥，列層閣以環洲。漬檀欒之脩竹，
映迢遰之危樓。風未生而葉動，景將昃而光收。若夫
瑞草奇色，祥樹嘉名；霏紅曜紫，垂緗拖青。或玲瓏於
玉砌，或點綴於金楹；交九衢而結影，分四照以開榮。
浥朝露而逾馥，帶星風而更輕。於是登崇觀以周覽，
闢層軒而遐矚。樹含嶺而共青，草帶原而同綠，俯八
紘而非遠，顧千里而為局，飛霞斂而復舒，輕煙斷而
還續，既神王以情暢，乃遣累而思足。

宋曹組《艮嶽賦應制》，「霽色晚靜，風光曉凝，陟崔嵬而
直上，俯磴道以寬平。雜花異香，莫知其名，佳木繁陰，
欣欣其榮，珍叢幽芳，古木長藤，籠絡蔽虧，高低相層。
鳥啼花發，則春容澹蕩，霜降木脫，則石角峻嶒，或重
羅以瞑晝，或偃草而進風，裊長春之翠莖，挺堅節之
霜松，每晨曦之照耀，靄朝霧以空濛。」

陳徐陵《奉和簡文帝山齋詩》：「架嶺承金闕，飛橋對石
梁。竹密山齋冷，荷開水殿香。山花臨舞席，水影照歌
床。」
