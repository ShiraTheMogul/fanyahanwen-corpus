雜花草部彙考三

《王象晉群芳譜》
[
编辑
]

《旌節花》
[
编辑
]

旌節花，高四五尺，花小類茄花，俗譌「錦茄兒花」，節節
對生，紅紫如錦。

《西番葵》
[
编辑
]

西番葵莖如竹，高丈餘，葉似蜀葵而大，花托圓二三
尺，如蓮房而扁，花黃色，子如萆麻子而扁。孕婦忌經
其下，能墮胎。

《金雀花》
[
编辑
]

金雀花，叢生，莖褐色，高數尺，有柔刺，一簇數葉。花生
葉傍，色黃形尖，旁開兩瓣，勢如飛雀，甚可愛。春初即
開，采之滾湯，入少鹽微焯，可作茶品清供。春間分栽，
最易繁衍。

《吉祥草》
[
编辑
]

吉祥草叢生，不拘水土，石上俱可種。色長青，莖柔葉，
青綠色，花紫，蓓結小紅子，然不易開花，候雨過，分其
根種於陰崖處即活。惟得水為佳，亦可登盆，用以伴
孤石靈芝，清雅之甚，堪作書窗佳玩。或云：「花開則有赦。」一云「花開則家有喜慶事」，人以其名佳，多喜種之。
或云：吉祥草蒼翠若建蘭，不藉土而自活，涉冬不枯。
杭人多植瓷盎。置几案間。今以土栽有岐枝者。非是。

《書帶草》
[
编辑
]

書帶草叢生，葉如韭而更細，性柔紉，色翠綠鮮妍。出
山東淄川縣城北黌山鄭康成讀書處，名「康成書帶草。」藝之盆中，蓬蓬四垂，頗堪清賞
​

《翠雲草》
[
编辑
]

翠雲草，性喜陰，色蒼翠可愛，細葉柔莖，重重碎蹙，儼
若翠鈿。其根遇土便生，見日則消。栽於虎刺芭蕉、秋
海棠下，極佳。

種植春雨時分，其勾萌種於幽厓深谷之間，即活。

《高濂草花譜》
[
编辑
]

《笑靨花》
[
编辑
]

花細如豆，一條千花，望之若堆雪。然無子可種。根窠
叢生，茂者數十條。

《蝴蝶花》
[
编辑
]

草花，儼若蝶狀，色黃，上有赤色細點，闊葉。秋時分種。

《金莖花》
[
编辑
]

金莖花如蛺蝶，風過花如飛舞搖蕩，婦人採之為飾。
諺曰：「不戴金莖花，不得入仙家。」
《萵苣花》
[
编辑
]

俗名「金盞花」也。色金黃，細瓣攢簇肖盞。當春初即開，
獨先諸花。

《金雀花》
[
编辑
]

春初開黃花，甚可愛，儼狀飛雀，且可采，以滾湯著鹽
焯過，作茶供。一品

《寶相花》
[
编辑
]

花「較薔薇」朵大而千瓣塞心，有大紅粉色二種。

《金沙羅》
[
编辑
]

似「薔薇」，而花單瓣，色更紅艷奪目。

《金缽盂》
[
编辑
]

似「沙羅」而花小，夾瓣如甌，紅鮮可觀。

《間間紅》
[
编辑
]

花似薔薇，色紅，瓣短，葉差小於薇。

《錦帶花》
[
编辑
]

花開，蓓虆可愛，形如小鈴，色粉紅而嬌，植之屏籬，可
折供玩。

《繅絲花》
[
编辑
]

花葉儼似玫瑰，而色淺紫無香，枝生刺針，時至煮繭，
花盡開放，故名。種從根分。

《結香花》
[
编辑
]

花色鵝黃，較瑞香稍長，花開無葉，花謝葉生，枝極柔
軟，多以盤結上盆。

《海桐花》
[
编辑
]

花細白如丁香，而嗅味甚惡，遠觀可也。

《秋牡丹》
[
编辑
]

草本，遍地延蔓，葉肖牡丹花開淺紫黃心，根生分種。

《練樹花》
[
编辑
]

苦練發花如海棠，一蓓數朵，滿樹可觀。

《淡竹花》
[
编辑
]

花開二瓣，色最青翠，羌人用綿收之，貨作「畫燈」青色，
并砂綠等用。

《紫羅襴》
[
编辑
]

草本，色紫翠，如鹿蔥花。秋深分本栽種，四月發花可
愛。

《四季花》
[
编辑
]

花小葉細色白，午開子落，自三月開至九月。其枝葉
搗汁，可治跌撲。

《紫花兒》
[
编辑
]

遍地叢生，花紫可愛，柔枝嫩葉，摘可作蔬。春時子種。

《紅麥》
[
编辑
]

麥種：花妙如剪子，大於麥數倍，色紅可愛。

《水木樨》
[
编辑
]

花色如蜜，香與木樨同味，但草本耳，亦在二月分種。

《雪下紅》
[
编辑
]

一種藤本生子類珠，大若芡實，色紅如日，粲粲下垂，
積雪盈顆，似更有致，故名。

《青珊瑚》
[
编辑
]

產廣中。結實如《珊瑚鉤》，色青翠可愛。

《閩書》
[
编辑
]

《龍牙草》
[
编辑
]

龍牙草出福州，治痢最神。《本草》謂即馬鞭草，非也。

《密槱》
[
编辑
]

密槱花，紅千葉。六一居士《牡丹記》曰：「如密槱，緋桃，皆以名稱之。」是密槱為花，自宋有之。

《俱那衛》
[
编辑
]

俱那衛，一作俱那異，僧舍多植之。樹高七、八尺，其枝
脆弱，葉狹而長，花紅，根似玉簪花而小。曾師建《閩中
記》：「南方花有北地所無者。」闍提、茉莉、俱那異皆出西
域，盛傳閩中。北地多寒，莫能植也。

《闍提》
[
编辑
]

闍提，南海種，商舶傳入閩中。花晳白而香勝如素馨，
蓋巖桂之流品。《僊書》曰：「闍提花春」，即此亦名麝茶。

《滿堂紅》
[
编辑
]

滿堂紅，一曰「花椰」，一曰「朱草」，花穗生，淺黃色，香聞百
步，開即為瑞。

===
《真珠》
===
​
《真珠花有單葉者，有千葉者。許將詩》：「蓛蓛圓英淡粉妝，肯隨桃李媚春陽。金刀不到春風外，草密林深只自香。」
《鳳尾》
[
编辑
]

鳳尾有二種，大者高丈餘，花穗生，黃心而白，英長竟
尺，若鳳尾然。一種高數尺，花疏而香勝，一名「鳳柳」，一
名「七里香。」置書帙中，可辟蠹。

《御帶》
[
编辑
]

御帶：枝長，花密如帶。

《鷹爪》
[
编辑
]

鷹爪藤生，花淡黃色，末銳似鷹爪。夏開，香如爛瓜氣。

《剪金紅》
[
编辑
]

剪金紅，花圓如香，葉分數岐，如刀剪之狀。

《聚八仙》
[
编辑
]

《聚八仙》，狀類瓊花，八蝶簇一心，又有蝴蝶兩兩相對
者。又有小蝶簇聚如碧玉者，出澗谷間，皆曰玉蝴蝶，
又有玉翼蟬、碧蟬。

《寶相》
[
编辑
]

寶相藤，生花類酴醾，秀整過之。

《玉屑》
[
编辑
]

《玉屑厥》藤生花狀如碎玉。

《玉籠鬆》
[
编辑
]

藤生，花微紅而圓。又一種花類葉尖，名《醉楊妃》。

《袞繡毬》
[
编辑
]

袞繡毬藤生花，一簇數十葉，其圓如毬。初開微帶粉
紅色，開盡則白。

《蛇麻》
[
编辑
]

蛇麻：葉如青麻藤蔓生籬落間。土人採為麴用。

《吉祥》
[
编辑
]

吉祥葉如萱而小，四時一色，生泉石中。山村人以插
瓶祀先，雖在蔭宇，蔥翠不凋。家有吉事，定自開花，故
名吉祥。邵武天池山有之，佛書「天援菩薩」，吉祥子，菩
薩到貝多樹下敷草，東向西坐。所從來遠矣。

《紫貝》
[
编辑
]

紫貝解一切蛇毒。

《候潮草》
[
编辑
]

《候潮草》草間有莢如榆莢，潮至則開，退則合。

《仙草》
[
编辑
]

仙草生山谷中，搗爛絞汁，和麪粉煮之成凍。

《廣群芳譜》
[
编辑
]

《錦帶花》
[
编辑
]

錦帶花，一名「海仙花」，一名「文官花。」此花出荊楚間，有
花如錦，遂名「錦帶花」，條如郁李，春末方開，紅、白二色。

《黃花》
[
编辑
]

黃花，不知其名，一朵四瓣，合抱如金盞，其色鵝黃出
汗，帖木兒巔以北，每一莖只一朵，翩然獨秀，眾草經
霜凋萎，是花經霜，顏色愈覺鮮明。

《馬蹄蘭》
[
编辑
]

馬蹄蘭生平地亂草間，葉劍樣如建蘭，堅韌不可斷，
其花翠色可愛，秋則結苞成子，塞外尢多。

《地椹花》
[
编辑
]

地椹花，青紫色，花瓣如葵，一花八九瓣，徑二寸許，瓣
落盡則花心結子成堆，取之可以為漿。

《藍雀花》
[
编辑
]

《藍雀花》，其花如雀，有身、有翼、有尾、有黃心，如兩目。或
云即茱萸花。

《翠蛾眉》
[
编辑
]

《翠蛾眉》花翠色，隨日側映，鮮妍有致。

《蝎子草》
[
编辑
]

蝎子草塞外多有之，高四、五尺，叢生亂草間，其葉最
毒，人誤觸之，立即紅。
如蝎子所螫，故名。馬亦不敢
近之，惟駝能食，與䕭相類。

《特勒蘇草》
[
编辑
]

特勒蘇草，塞外叢生，蔥翠挺拔，經秋霜則變而為白。
取之組織為涼帽，光皎異常。

《煙草》
[
编辑
]

煙草一名煙酒。味辛，溫，有毒。治風寒濕痹，滯氣停痰，
解山嵐瘴氣。多食則火氣熏灼，耗血損年。閩產者佳，
燕次之。春種夏花，秋日取葉，曝乾。切葉形如細髮，草
頂數葉，名曰「蓋露。」
《山蓮》
[
编辑
]

百丈山有草，花如蓮花。

《西番蓮》
[
编辑
]

西番蓮，花淡雅，似菊之「月下西施。」自春至秋，相繼不
絕，亦花中佳品。春間，將藤壓地自生根，隔年鑿斷分
栽。

《鐵線蓮》
[
编辑
]

鐵線蓮：花、葉俱似西番，花心黑如鐵線。

《雪瓣》
[
编辑
]

「雪瓣」，一名「狗牙」，似茉莉而瓣大，其香清絕。出《海南》。

===
《紫茉莉》
===
​
紫茉莉，草本，春間下子，早開午收。一名「臙脂」花，可以

點脣。子有白粉，可傅面。亦有黃、白二色者。

《萬年花》
[
编辑
]

萬年花，草本，小朵如盞，一莖百朵。其色粉紅而有紅
絲。雖經久乾枯及沾泥污，顏色鮮新不變。

《金蓮》
[
编辑
]

金蓮花，出山西五臺山塞外。尢多，花色金黃，七瓣，兩
層，花心亦黃色，碎蕊平正，有尖小、長狹，黃瓣環繞其
心，一莖數朵，若蓮而小。六月盛開，一望遍地金色爛
然。至秋，花乾而不落，結子如粟米而黑。其葉綠色，瘦
尖而長，五尖或七尖。

《黃山志》
[
编辑
]

《青鸞花》
[
编辑

名。抽莖䔿䔿，布葉英英，二八而落，三五而盈。陰德自
然，仰蟾蜍而知晦；太陽常近，與葵藿而同傾。爾乃丕
體其祥，博考其義，所以厚上天之德，所以表皇王之
瑞。其國亂也，則植之猶難；其國理也，則生之孔易。惟
我后之欽若，亦合符而受賜。承榮金殿，旁沾三露之
滋；每奉玉階，上蔭五雲之施。豈無萱草，以悅其性？豈
無靈芝，以彰其盛？芝擢其秀，既以紛綸於策書；萱樹

士，來應弓招。受成於天，諒多聞於國瑞；託得其地，且
有異於山苗。竊預談於皇道，庶有望於《遷喬》。

若乃一人當宁，超黃越虞，百辟來朝，日臨雲趨。風力
論道，伊咎陳謨，斯瑞在前，疇敢以諛？故曰「物生於有，有生於無。」感此變化，發為禎符。不然，彼植物之何知，
乃同功於帝俞。天道不言，聖人無心，寓形闡教，其用
則深。禾穎降於周王，芝房發於漢后。信呈豐兮告慶，

主所以超三英之躅，彼靈草所以為百瑞之首，有由
然也。史魚守直，宣父惡佞，佞直不分，邦家靡定。惟草
所指，惟皇所聽，指歸乎一，聽戒乎失。苟君道之不弘，
徒倚瑞以自必。重曰：「煜彼草兮直而指佞。聖之瑞兮時之禮，頌皇休兮無極已。」

伊嘉卉兮，昔生軒廷，蓋歷代而莫觀其狀，至我后而

匪然，何以於昭其異？有赫厥靈，根莖竦擢，枝葉靜，好
惡夫佞，允葉乎聖心；作乎祥，特異於靈草。況今勤施
五至，克奉三無，多忠良之士，絕讒佞之夫。非斯草之
助化，何以臻於此乎？指佞之為德也廣，指佞之為瑞
也深。逢聖斯生，介一人之景福；有佞必指，俾百寮而
革心。故能殊眾芳之質，標群瑞之首。彼獬廌之觸邪
抵罪，在法則嚴；伊平露之傾葉知方，於人何有？孰若
我應明聖，指邪佞昔之輔德，告軒后之功成；今也呈
祥，贊吾君之理定。一名屈軼，千載挺出。有佞則指，孰
云無必。豈比夫萐莆空扇於堯廚，芝房徒歌於漢室
哉？足以彰致理，薦嘉祉。君子在位，我則恭默以傾心；
佞人入朝，我則無私以直指。信可以美芳聲於《雅》《頌》，
垂不朽於國史。
