陳與延
[
编辑
]

按《寧波府志》：「陳與延，名延，以字行。記覽該博，尢熟於《春秋》。家頗饒產，悉以散諸親舊之貧者，僅存周廬田數十畝，朝耕暮讀，雖屢空無怨悔。洪武二十七年，邑大夫多其賢，薦授本邑訓導。開導後學，諄諄先義後利，一言一行，惟恐或後古人。故當時從游之士，接其模範者，率知敦尚古道云。」
胡壽卿
[
编辑
]

按《歙縣志》：「胡壽卿，字本仁，號南山，路口人。閱《節俠列傳》，則掀髯呼酒，里族窘乏，輒傾橐周之。洪武二十七年，邑奉部牒興水利，壽卿自任邑西永豐新堨，閱一載堨成，溉田三千七百餘畝。邑上其事，委勘官覈實，詔邑令李珊褒之，珊手為製記，并贈以詩。江浦令與壽卿更相友善，攜其一子往，遂籍江浦，衣冠踵盛稱『右族』」云。

李勝剛
[
编辑
]

按《霸州志》：「李勝剛，西永里人。洪武三十五年，歲澇民饑，剛捐粟設粥，復捕魚給人。」
談綽
[
编辑
]

按《無錫縣志》：「談綽，字公綽，性質直。洪武中，以人才徵，奉命督賦蘇州。郡守李某餽以百金，綽曰：『太守不知我』。李退而嘆。常客松江，同舍郎夜召娼置酒而迫狎之，綽終不許。明燈竟夕，娼感泣，遂改行為良家。」
高林
[
编辑
]

按《廣西通志》：「高林，慶遠人。慷慨有義氣。洪武閒，以功讓舅指揮使彭舉，合為義族。後林得象嶺地，適合鈐記一穴南山地，石龍走過江，欲去未去，停停而聚，葬著天然二品官，兒孫世代爭馳譽。至孫嵩，以弘治鄉魁，嘉靖初拜太僕正卿，人謂指揮使三品官也，卿亦三品，冥報殊不爽云。」
王荂
[
编辑
]

按《金壇縣志》：「王荂，字子輝，天性孝友。洪武閒，兄榮以人才舉，授杭州府同知，佐崇山侯李新開溧水縣臙脂河。新受富民錢，為迂其道，事發，伏誅，榮坐當剜膝。荂走京師，擊登聞鼓，請以身代，上義而許之。旨下，兄已刑矣。榮卒，荂為撫其孤。正統初，出粟三千石助官賑饑。上聞，遣行人賜敕獎勞，表其門，復其家。」
宋通
[
编辑
]

按《蘇州府志》：「宋通，字文傑，長洲人。在元為萬戶侯。至壬辰兵起，散家產萬金，為一方保障，遠近皆歸之。偽吳平，洪武時，舉賢良方正，徵聘不赴，乃卜宅楓江相地九龍曰：『吾世有隱德，然不敢望富貴，吾子孫得為善人，能保詩書之澤足矣』。」妻沈氏，即萬三女，知有家
難，不受嫁。貲，亦奇女也。

湯有容
[
编辑
]

按《廣西通志》：「湯有容，字載行，新會人。少年能文章，勇於為義，不擇利害為趨舍，時輩多推服之。洪武閒，任廣西恭城教諭，又歷興安，以兄死，具疏棄官歸。後復官容縣，值縣大疫，皆謂疫能染人，人莫敢出，雖縣門無行者。知縣彭清中奇病，煢然一身，自分必死。有容日令家人具湯粥而自節宣之，晝夜不離其側，清得」不死，時人以為難。

尢裔
[
编辑
]

按《蘇州府志》：「尢裔，字從道，長洲人。元末辟為樞密掾。洪武中，以人材薦，授湖廣布政司經歷。居官稱廉謹，早擅文名，與陳基相友善。基當亂離之際，以百金託裔，時平橐而還之。基感其誼，將中分焉，裔堅卻不受。性沈厚明哲，處患難不失守。著《元史輯要》，藏于家。」
葉天保
[
编辑
]

按《衢州府志》：「葉天保，字彥祥，居晝錦里。洪武中，有江山王姓虧糧累千，太守郭敦親判券契，田一頃零二十四畝，招富民出金以田償之，莫有應者。遣使取資於天保，保輸資一千兩有奇，以應太守之急，活王氏之命。田在隔縣，夷然不受。且一方之民，待之舉火，麥舟之惠，比於范公。曾孫孔禮兄弟四人，仲兄亡應，繼」叔尚《六序》及孔禮當得產四百頃，禮止受二百頃，而
以二百頃讓三兄弟，族人義之。其後族孫棐亦以己
產讓弟，有足多焉。

===李潤甫　陳孚===
​
按《揚州府志》：「李潤甫，通州人。洪武中，颶風海溢，漂沒廬舍。潤甫念婦弟陳孚幼弱，恐不免，倉皇棄妻走，抱孚急避范公隄上。頃之，妻亦附敗屋至隄，皆得不死。後孚登進士，為戶部郎，教潤甫子永常如己子。永常及子周開皆登鄉薦。周開為御史，有聲潤甫。今祀鄉賢。」
胡斌
[
编辑

按《畿輔通志》：「胡斌，雄縣人。洪武末，雄有東門之變，枕骸蔽野，行者心悸。斌荷荊筐往瘞之，被霜冒雪，越六旬而事竣。男女各為叢塚。」
尤安禮
[
编辑
]

按《蘇州府志》：「『尤安禮，字文度，裔子。生而孝謹，少從父裔官武昌，與文貞、士奇及楊尚書翥友善，以德業相勵。生平講學，辨認理欲。嘗行委巷，邂逅一姝，若將獻笑者，安禮亟引去，後不復由是路。同學生陳某當遠戍，妻女穉弱，泣告安禮，吾必不生還，妻少，且更嫁，奈幼女何』？安禮曰：『我在何患』？已而陳果死，安禮贍其妻」，
得守節。以弟之子配其女。弟以女病，難之曰：「吾豈食言于亡友！」卒娶之。建文元年舉鄉薦，授崇安教諭。秩
滿，諸生詣闕請留，上命增秩還任。尋擢兵部武庫郎
中，楊翥薦為祭酒，安禮辭。改授都御史，又辭。擢貴州
參議，條上利弊二十事，上嘉納行之。既謝病歸，貧甚，
不給朝夕。知府況鍾入朝，楊文貞問安禮起居，鍾謝
不知。楊曰：「公廉吏，不識尤文度耶？」及歸訪之，得一老
絡絲巷中，布衣芒履，環堵蕭然，況見所居隘陋？請更
之，不可。遺以金，亦不受。

黎和
[
编辑
]

按《廣東還志》：「黎和，字伯英，南海人。少警悟能文，美風儀，事親以孝謹聞。與孫蕡、唐豫友善。元季避地槎溪，歲凶，竭力以給供養，雖當亂離，手不釋卷。親沒，廬墓三年。朝廷混一，流徙復業，始還夏溪，闢萊蕪，耕鑿吟嘯自如。嘗揭八行為家訓，鄉人化之，有王烈風。捐資建永安橋二，以通利涉。永樂庚寅，辟茂才，至京，以老」疾乞歸，逍遙巖壑，名士多從之遊。時東莞袁友信亦
兩被徵書，弗究厥用，皆所謂「姱修之士」者也。

劉輔

编辑

按《博野縣志》：「劉輔，永樂時有艾瑛者，以在繫之父托輔。瑛父病死，輔傾囊殯之。瑛後為副使，館輔家，病死，復殯如其父。後輔生子吉，官至太師。」
劉潔
[
编辑
]

按《博野縣志》：「劉潔，永樂朝從征東昌，北軍過滋水，多為居民所殺。有旨命千戶盡殲其民。潔為嚮道，恐傷無辜，徐至其處，民多逃匿，潔全王姓一家。又以裴徵為姪，幸而得生。後徵為指揮，事潔如父。」
嚴本
[
编辑
]

按《江陰縣志》：「嚴本，字志道，先居崑山之巴城里。既冠，受父命，僦居江陰邑城北，遂占籍焉。以句讀為童子師，得斗粟尺布，躬負歸以養父。喜讀書，取五經諸史之要者丹鉛之，以自取衷，不矜浮華之詞。父沒，哀毀治喪，斥佛道教，一本《朱子家禮》。永樂癸巳，詔舉嚴異才，吏部郎何澄薦至京師，拜刑部主事。洪熙初，遷大」理寺正。時法網密，獄吏文致每以「致情故縱」及「大不敬」為擬。本特爭之曰：「國家定律，除叛逆外，別無故縱之文。即不敬，所犯殊科。安得一概重比，傷聖朝明慎至意。」大理卿虞謙深是之，請著為令。本前後皆刑官，
絕不喜一切苛深，平反冤獄甚眾。居身清峭壁立，然
未嘗自廉而污人。曾奉使督辦於太平僦，居僧舍時，
所需甚急。民懷金他求，使者誤投本所，笑卻之。即日
徙舍，人莫知其故。既事竣，懷金者顯其事，人皆稱為
長者。又督辦後期者，例罰工作，本不忍急責民。或曰：
「獨不慮罰工乎？」曰：「吾已辦之。」蓋先寓書其子鬻田為
工作費矣。當家食時，周文襄巡撫江南，夜半叩門，本
曰：「此必故人周恂如」也，披衣迎之，促膝深談良久，出
索雞卵啖之，盡其風致簡淡如此。生平鄭、衛之音不
經耳，靡麗之色不經目。親友聲妓佐酒，必毅然起。巫
祝禱祀絕不道。著「《律疑解略》《刑統輯義》」兩書。

余學夔
[
编辑
]

按《松江府志》：「余學夔，台州人。方正學孝孺被收時，寧海尉魏澤匿其幼子德宗。學夔微聞之，變形佯狂，乞食於市。一日，迎澤於城隅，作狂歌曰：『當年豫讓豈純臣，猶肯吞炭併漆身。堪笑今來執政者，叩頭新主乞恩綸。不慚周粟可偷身，首陽節義如飄萍。向日都俞今反目，區區尚願效程嬰』。澤默會之，叱曰：『扶顛子出』」城去，兩日後復遇在市，仍作狂歌。澤乃密致書，將孝
孺文稿併德宗盡託之。學夔，逃赴海島彌月。及松江
青村學，治繒網，易米日給。潛入城訪進士俞允。允以
孝孺門人，家居不仕，三叩乃得見。呈澤手啟大驚，遂
逆德宗於家。長史任勉以金遺學夔，不受，意欲他徙。
勉出《試錄》示之，知亦孝孺門人也，始安然絕跡城市，
終不詣任氏。德宗後冒姓余，而學夔亦有子孫，世居
白沙里

按《江西通志》：「王賢，字茂先，德化人。永樂閒，九江衛指揮使許壽、衡州太守史中，俱以賢良方正薦之，賢固辭不就。精岐黃之學，所藥危疾，往往立已。嘗過玉波橋畔，得遺金一綻，坐待其人還之，年九十有三乃卒。」
秦初
[
编辑
]

按《紹興府志》：「秦初，字性初，山陰人。卓有行誼。居太學時，同舍生以使出及妻死無主，初為之經紀喪事甚周。有金安者，除後山衛經歷，當之任，貧無以治裝，初脫所乘驢資遣之，徒步出入。永樂中，舉進士，官翰林檢討。」
王稌
[
编辑
]

按《金華府志》：「王稌，字叔豐。自幼潛心勉學，博覽群書。侍父入蜀，游學京師。及父沒，扶柩歸葬，終喪復登方孝孺之門以卒。所業文行重於士林。及孝孺被刑狼藉，人莫敢收，稌與鄭恂潛至聚寶門外求其骸骨以歸，禍幾不測，人稱其義。永樂中，以儒士舉，預修郡邑志，及採上二朝實錄事跡，以病瞶不仕，號瞶樵。所著」有《青巖類槁》。

馮詠
[
编辑

按《臨海縣志》：「馮詠，字處夔，隱居力學。永樂閒，歲連饑，里人王德章以重逋無償鬻，妻子聞而貸之粟。德章感激，繪其像祀之。江右鹽商有覆舟者，窘迫求貸，不留券，與以五十金。其好義樂施，不特一二事也。又嘗以佳城讓弟，其後子孫代有科名。」
王跡懋
[
