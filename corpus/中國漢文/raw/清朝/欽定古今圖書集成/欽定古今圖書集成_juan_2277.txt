宣化府部藝文四
〈詩〉
[
编辑
]

《燕然山銘》
漢·班固
[
编辑
]

鑠王師兮征荒裔，𠞰凶虐兮截海外。敻其邈兮亙地
界，封神丘兮建隆碣，熙帝載兮振萬世。

《涿鹿山》
唐·胡曾
[
编辑
]

涿鹿茫茫白草秋，軒轅曾此破蚩尤。丹霞遙映山前
水，疑是成川血尚流。

===
《李陵臺》
前人
===
​
北入單于萬里疆，五千兵敗滯窮荒。英雄不伏他鄉

死，更築高臺望故鄉。

《桑乾河》
賈島
[
编辑
]

客舍并州已十霜，歸心日夜憶《咸陽》。無端更渡桑乾
水，卻望并州是故鄉。

《渡桑乾》
宋·蘇轍
[
编辑
]

北渡桑乾冰欲結，心畏穹廬三尺雪。南渡桑乾風始
和，冰開《易》水應生波。

《八達嶺》
金·劉迎
[
编辑
]

山險路已出，彌望盡荒坡。風土日已殊，氣象惟沙陀。
余老倦行役，輕車此經過。時和春已夏，土寒地無禾。
行路不肯留，奈此居人何！

《推車行》
前人
[
编辑
]

渾河洶湧從西來，黃流正觸山之崖。山險路窄僅容
過，小誤往往車輪摧。車摧料理動半日，後人欲過何
艱澀。深山日暮人已稀，食物有錢無處覓。何時真宰
遣六丁，鏟此疊嶂如掌平。幢幢車馬山西路，萬古行
人易來去。

《敗車行》
前人
[
编辑
]

《前車行》後車逐，車聲夜隨山詰屈。前車失守落高崖，
車聲直下聲如雷。同行急捄捄不得，人牛翻壓鳴聲
哀。我時潛問覆車說，前車使牛何太拙。只知拍手笑
前人，不道後來當改轍。前途猶有坡陀在，後車當以
前車戒。

《翠屏山》
周昂
[
编辑
]

去歲翠屏下，臨流看湧波。愁將新鬢髮，還對舊關河。
翅健翻秋隼，峰高並晚駝。草深饒虎跡，夜黑欲誰過。

其二

地擁山河壯，營開劎甲重。馬牛來細路，燈火出寒松。
刁斗方嚴夜，羔裘欲禦冬。可憐天設險，不入漢提封。

其三

玉帳初鳴鼓，金鞍半偃弓。傷心看塞水，對面隔華風。
山去何時斷，雲來本自通。不須驚異域，曾在版圖中。

其四

旌節瞻前帳，風塵識舊坡。眼平青草短，情亂碧山多。
晚起纔投筆，前驅效執戈。馬蹄須愛惜，留渡北流河。

《雞鳴山》
趙秉文
[
编辑
]

煙蒸山腹晴猶濕，河帶冰澌暖漸流。獨立雞鳴看日
出，五雲多處是皇州。

《登雞鳴山絕頂題永寧寺壁》
前人
[
编辑
]

鳥道盤雲上碧霄，洋河衣帶瞰洪濤。閻浮國土迷華
藏，忉利天宮跨妙高。塵世幾回擒走鹿，長竿何代釣
靈鰲。打頭半世蓬茅底，「九萬天風散鬱陶。」《過桑乾》
元·馮昂霄
[
编辑
]

幾年朔客渡桑乾，野水潺潺滴瀝寒。回首燕南煙雨
外，西風沙鴈報平安。

《金蓮川》
前人
[
编辑
]

金蓮川上富秋光，的皪花枝不著房。只合潘妃微步
惜，凌波羅襪寄芬芳。

《廣昌古寺》
劉因
[
编辑
]

何事招提好，山深馬可驅。松巢低映帽，竹溜細通廚。
霜栗千封戶，雲屏四畫圖。冠巾如用我，白鹿起規模。

其二

聞昔蜚狐口，奇兵入《擣虛》。人才九州外，天道百年餘。
草木皆成騎，衣冠盡化魚。遺民心膽破，諱說戰爭初。

其三

關嶺通山後，風謠采路旁。地寒人好壽，草淺俗宜羊。
用水如奴婢，從川貯米糧。西風如有約，乘興即吾鄉。

《雲州》
陳孚
[
编辑
]

天險龍門峽，懸崖兀老蒼。千蹄天馬躍，一寸地椒香。
夜雪青氈帳，秋煙白土房。路人遙指語，十里是溫湯。

《李老峪聞杜鵑呈應奉馮昂霄》
前人
[
编辑
]

《三月十九日》，客行桑乾坂。「杜鵑啼一聲，清淚悽以澘。故園渺何處，萬里隔雲巘。燕子三見歸，我車猶未返。杜鵑爾何來，弔我萬里遠。同行二三子，相顧一笑莞。問我此何鳥，怪我苦悲惋。掉頭不復言，日落千山晚。」《洪贊井》
前人
[
编辑
]

《洪贊》「山岧嶢，勢如舞雙鳳。大井千尺深，窈然見空洞。野人驅十牛，汲以五石甕。滴水寶如珠，一甕千室共。我生海東頭，漣漪飽清弄。嘗聞惠山泉，萬里驛騎送。急呼茗碗來，試作清淨供。」《夜宿灤河觜兒》
前人
[
编辑
]

貂裘塵土黑如鴉，海角孤臣扈翠華。萬里親庭應鶴
髮，一生客路又龍沙。囊中藥捲蓯蓉葉，盤裏蔬堆芍
藥芽。漸見馬前添喜氣，明朝天近玉皇家。

《懷來縣》
前人
[
编辑
]

榆林青茫茫，塞煙三十里。忽聞雞犬聲，見此千家市。
石橋百尺橫，其下跨媯水。人言古媯州，殘城無乃是。
民家坐土床，嬉笑圍老稚。糲飯侑山蔥，勸客顏有喜。
足跡半天下，愛此俗淳美。醉就軟沙眠，夢游葛天氏。

===
《鵰窠道中》
前人
===
​
曉馳漠北暮居庸，千里山河一瞬中。江左故人知我

否，馬蹄聲裏度秋風。

其二

車外塵沙十丈黃，車中客子黑貂裳。拂雲堆上閒回
首，無數征鴻帶夕陽。

《赤城驛》
前人
[
编辑
]

一溪流水繞千峰，宛與天台景物同。魂夢不知家萬
里，卻疑只在赤城中。

《保安州黃帝祠前橋山》
鮮于樞
[
编辑
]

旁通日月上星辰，有路遙應接玉京。仙弈未終人世
換，秦鞭不到海波平。當時混沌知誰鑿，他日崆峒強
自名。枯樹重榮事尤異，欲從樵者問《長生》。

《龍門》
袁桷
[
编辑
]

蒼崖出雙闕，群山俯首尊。陰風起晴雷，摩盪盡日昏。
鐵峽擁偪仄，百川為之奔。疑下有龍湫，呈怪蹲天門。
渰兮出膚寸，頃刻黃流渾。側徑出石壁，巨浸存遺痕。
緬昔設天險，事久難窮論。征衣襲輕雨，神君儼雲根。

其二

「瀚海雙龍鐵鱗甲，卷壑挐雲蹲冀闕。千泉百道湊東南，急雨翻空迸晴雪。古言神禹功最多，導山鑿石疏九河。幽都之地不復顧，乃使雙龍下地成盤渦。陰風何颼颼，磅礡太古秋。墜崖落車砲，怪木森戈矛，碎沙晴日鋪金麩，云是昔日當關挽勁之僕姑。」寒泉組練
結九曲，亭午赫赫光，模糊車聲何轔轔。昨宵急水迷
無津。垂堂之言猶在耳，遊子商人行不已。子規徹天
呼我歸，翠華北幸那得辭。龍門之石高不磨，泚筆書
我《龍門歌》。

《李陵臺》
前人
[
编辑
]

雪滾寒沙風滾灰，眼穿猶上《望鄉臺》。《隴西》可是無迴
鴈，不寄《平安》一字來。

《雲州》
前人
[
编辑
]

天闊雲中郡，剛風起泬寥。氈房聯澗曲，土屋覆山椒。
橦布朝朝市，通薪戶戶燒。遙看塵起處，深羨霍嫖姚。

《度懷來沙磧》
前人
[
编辑
]

沙清圓石瘦，千里聞風聲。驅此觳觫車，索索莎車鳴。
遠山列翠席，近坡環碧城。高下各有險，轍跡那由平。
驚兔導我前，歷錄為之驚。天低雲搖蕩，土曠塵縱橫。
謬膺翰墨選，遠行有期程。回頭望南阪，初月隨風生。

《龍門》
周伯琦
[
编辑
]

踰險夢頻悸，循夷氣始愉。千巖奇互獻，萬壑勢爭趨。
峭壁劎門壯，重梁皇渚紆。凡鱗期變化，雷雨在斯須。

《野狐嶺》
前人
[
编辑
]

高嶺出雲表，白晝生虛寒。冰霜四時凜，星斗咫尺攀。
