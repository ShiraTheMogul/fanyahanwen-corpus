歲功典第一百十卷

晨昏晝夜部藝文五
〈詞〉
[
编辑
]

菩薩蠻
〈秋夜〉
　　　　　南唐盧絳
[
编辑
]

「玉京人去秋蕭索，畫簷鵲起梧桐落。」攲枕悄無言。月
和清夢圓。　背燈惟暗泣。甚處砧聲急。眉黛小山攢。
芭蕉生暮寒。

何滿子
〈泛湖夜歸〉
　　　　宋張先
[
编辑
]

溪女送花隨處，沙鷗避樂分行。遊舸已如圖障裏，小
屏猶畫瀟湘。人面新生酒豔，日痕更欲春長。　衣上
​
交枝𩰚色，釵頭比翼相雙。片段落霞明水底，風紋時
動妝光。賓從夜歸無月，千燈萬火湖塘。

玉樓春
〈夜雨寄弟〉
　　　　　蘇軾
[
编辑
]

梧桐葉上三更雨。驚破夢魂無覺處。夜涼枕簟已知
秋，更聽寒蛩促機杼。　夢中歷歷來時路。猶在江亭
醉歌舞。尊前必有問君人，為道別來心與緒。

行香子
〈與泗守南山晚歸〉
　　前人
[
编辑
]

北望平川。野水荒灣。共尋春、飛步孱顏。和風弄袖，香
霧縈鬟。酒正酣、適人語笑，白雲間。　飛鴻落照，相將
歸去澹涓涓。玉「宇清閒。何人無事，晏坐空山。望長橋上，燈火亂，使君還。」浣溪沙
〈晚景〉
　　　　　　　賀鑄
[
编辑
]

鸚鵡驚人促下簾。碧紗如霧隔青匳。雪兒窺鏡晚蛾
纖。　烏鵲橋邊河絡角，鴛鴦樓外月西南。門前嘶馬
弄金銜。

前調
〈晚景〉
　　　　　　　　前人
[
编辑
]

樓角紅綃一縷霞。淡黃楊柳帶棲鴉。玉人和月折梅
花。　笑撚粉香歸繡戶，半垂羅幕護窗紗。東風寒似
夜來些。

夜行船
〈雨夜泊吳江〉
　　　　毛滂
[
编辑
]

寒滿一衾誰共。夜沉沉，醉魂朦。鬆雨呼煙喚付凄涼，
又不成、那些好夢。　忽明日，煙江暝。曚扁舟繫一行
蝃蝀。季鷹生事水瀰漫，過鱸船、再三目送。

踏莎行
〈陳興宋夜集〉
　　　　前人
[
编辑
]

天質嬋娟，妝光蕩漾。御酥做出花模樣。夭桃繁杏本
妖妍，文鴛彩鳳能偎傍。　艾綠濃杳，鵝黃新釀。緣雲
清切歌音上。夜寒不近繡芙蓉，醉中祇覺春相向。

感皇恩
〈晚酌〉
　　　　　　　前人
[
编辑
]

「多病。酒尊疏，飲少輒醉。年少銜杯可追記。無多酌我，醉倒阿誰扶起。」滿懷明月冷，爐煙細。　雲幕雖高，風
波無際，何似歸來醉鄉裏。玻璃缸上，滿載春光花氣。
蒲萄僊浪軟，迷紅翠。

南歌子
〈春夜〉
　　　　　　　謝逸
[
编辑
]

雨洗溪光淨，風掀柳帶斜。畫樓朱戶玉人家。簾外一
眉新月、浸梨花。　金鴨香凝袖，銅荷燭映紗。鳳盤宮
錦小屏遮。夜靜寒生春筍、理琵琶。

驀山溪
〈月夜〉
　　　　　　　前人
[
编辑
]

霜清木落，深院簾櫳靜。池面卷煙波，瑩香冰、一匳明
鏡。修筠拂檻，疏節晚嬋娟，山霧斂，水雲收，野闊江天
迥。　紅銷醉玉，酒面風前醒。羅幕護輕寒，錦屏空、金
鑪燼冷。星橫參昴，梅徑月黃昏，清夢覺，淺眉顰，窗外
橫斜影。

蝶戀花
〈早行〉
　　　　　　周邦彥
[
编辑
]

月皎驚烏棲不定。更漏將闌，轆轤牽金井。喚起兩眸
清炯炯。淚花落枕紅綿冷。　執手霜風吹鬢影。去意
徘徊，別語愁難聽。樓上闌干橫斗柄。露寒人遠雞相
應。

早梅芳
〈曉別〉
　　　　　　　前人
[
编辑
]

「花竹深，房櫳好。夜闃無人到。」隔窗寒雨，向壁孤燈弄
餘照。淚多羅袖重，意密鶯聲小。正魂驚夢怯，門外已
知曉。　去難留，話未了。早促登長道。風披宿霧，露洗
初陽射林表。亂愁迷遠覽，苦語縈懷抱。漫回頭，更堪
歸路杳。

選冠子　　　　　　　　　　　前人
[
编辑
]

水浴清蟾，葉喧涼吹，巷陌雨聲初斷。閒依露井，笑撲
流螢，惹破畫羅輕扇。人靜夜久憑闌，愁不歸眠，立殘
更箭。歎年華一瞬，人今千里，夢沈書遠。　空見說、鬢
怯瓊梳，容消金鏡，漸懶趁時勻染。梅風地溽，虹雨苔
滋，一架舞紅都變。誰信無聊，為伊才減江淹，情傷荀
倩。但明河影下，遙看稀星數點。

眼兒媚
〈曉行〉
　　　　　　林少瞻
[
编辑
]

霽霞散曉月猶明。疏木挂殘星。山徑人稀，翠蘿深處，
啼鳥兩三聲。　霜華重逼雲裘冷，心共馬蹄輕。十里
青山，一溪流水，都做許多情。

鷓鴣天
〈揖翠晚望〉
　　　　趙師俠
[
编辑
]

「榕葉陰陰未著霜。淺寒猶試夾衣裳。」「霧濃煙重遙山暗，雲淡天低去水長。」　風淅瀝，景凄涼。亂鴉聲裏又
斜陽。孤帆落處驚鷗鷺，飛映書空雁字長。

清平樂
〈早起聞鶯〉
　　　　趙長卿
[
编辑
]

綺疏新曉。學語雛鶯巧。煙暖瑤階梧葉老。滿地東風
芳草。　少年不合風流。償他酒債花愁。望斷綠蕪春
去，銷魂嬾上層樓。

前調
〈晚晴賞荷〉
　　　　　　前人
[
编辑
]

水鄉清楚。襟袖消殘暑。綽約藕花初過雨。出浴楊妃
無語。　葡萄滿酌，玻璃已𢬵，一醉酬伊。浪捲夕陽紅
碎，池光飛上簾幃。

踏莎行
〈夜涼〉
　　　　　　　前人
[
编辑
]

樹影將圓，林梢不動。汗珠裛透紗衣重。薄風忽送雨
飛來，晚涼習習生幽夢。　珠箔高鉤，瑤琴閒弄。移尊
邀取嬋娟共。今宵𢬵著醉眠呵，夜香聞早添金鳳。

===南歌子
〈夜坐〉
　　　　　　　前人===
​
霜結凝寒夜，星輝識曉晴。蘭膏重剔且教明。為照梢

頭香縷、一絲輕。　坐久看看困，新詞綴未成。梅花熏
得酒初醒。更向耳邊低道、月三更。

江城子
〈夜涼對景〉
　　　　　前人
[
编辑
]

綵雲飛盡楚天空。碧溶溶。一簾風。吹起荷花，香霧噴
人濃。明月凄涼多少恨，恨難許，我情鍾。　相思魂夢
幾時窮。洞房中。憶從容。須信別來，應也斂眉峰。好景
良宵添悵望，無計與，一尊同。

菩薩蠻
〈湖光亭晚集〉
　　　葉夢得
[
编辑
]

「平波不盡蒹葭遠。清霜半落沙痕淺。」煙樹晚微茫。孤
鴻下夕陽。　梅花消息近。試向南枝問。記得水邊春。
江南別後人。

鷓鴣天
〈晚雨泛舟〉
　　　　　前人
[
编辑
]

天末殘霞卷暮紅。波間時見沒鵌翁。斜風細雨家何
在，老矣生涯盡箇中。　惟此意，與公同。未須持酒祝
牛宮。傍人不解青蓑意，猶說黃金寶帶重。

玉樓春
〈晚雨集客湖上〉
　　　前人
[
编辑
]

花殘卻似春留戀，幾日餘香吹酒面。濕煙不隔柳條
青，小雨池塘初有燕。　波光縱使明如練。可奈落紅
紛似霰。解將心事訴東風，只有啼鶯千萬囀。

南鄉子
〈池亭新成晚步〉
　　　前人
[
编辑
]

淺碧蘸鱗鱗。照眼全無一點塵。百草千花都過了，初
新。翠竹高槐不占春。　歌笑墮綸巾。午睡醒來尚欠
伸。待得月明歸去也，香蘋。更有涼風解送人。

前調
〈自後圃晚步湖上〉
　　　前人
[
编辑
]

小院雨新晴。初聽黃鸝第一聲。滿地綠陰人不到，盈
盈。一點孤花尚有情。　卻傍水邊行。葉底跳魚浪自
驚。日暮小舟何處去，斜橫。衝破波痕久未平。

西江月
〈夜行黃沙道中〉
　　辛棄疾
[
编辑
]

明月別枝驚鵲，清風半夜鳴蟬。稻花香裏說豐年，聽
取蛙聲一片。　七八箇星天外，兩三點雨山前。舊時
茆店社林邊。路轉溪橋忽見。

八聲甘州
〈夜讀李廣傳寄友〉
　前人
[
编辑
]

「故將軍、飲罷夜歸來，長亭解雕鞍。恨灞陵醉尉，匆匆未識，桃李無言。射虎山橫一騎，裂石響驚弦。落魄封侯事，歲晚田園。　誰向桑麻杜曲，要短衣匹馬，移住南山。看風流慷慨，談笑過殘年。」漢開邊，功名萬里，甚
當時、健者也曾閒。紗窗外，斜風細雨，一陣輕寒。

滿江紅
〈夜飲海棠花下〉
　　劉克莊
[
编辑
]

老子年來，頗自許、心腸鐵石。尚一點、消磨不盡，愛花
成癖。「懊惱每嫌寒勒住，丁寧莫被晴烘拆。」奈暄風、烈
日太無情，如何得。　張畫燭，頻頻惜。憑素手，輕輕摘。
更一番雨過，綵雲無跡。今夕不來花下飲，明朝空向
枝頭覓。對殘紅、滿院杜鵑啼，添愁寂。

臨江仙
〈夜景〉
　　　　　　　李石
[
编辑
]

煙柳疏疏人悄悄，畫樓風外吹笙。倚闌聞喚小紅聲。
薰香臨欲睡，玉漏已三更。　生待不來來不去，一方
明月中庭。粉牆東畔小橋橫。起來花影下，扇子撲飛
螢。

滿江紅
〈春曉〉
　　　　　　　劉儗
[
编辑
]

著意留春，留不住、春歸難戀。最苦是、梅天煙雨，麥秋
庭院。嫩竹濃陰鶯出谷，柔桑採盡蠶成繭。奈沈腰、寬
盡有誰知，難消遣。　幽閣恨，雙眉斂。香牋寄，飛鴻遠。
向風簾羞見，一雙歸燕。翠被閒將情做夢，青樓賺得
恩成怨。對尊前、莫惜喚瓊姬，持杯勸。

水龍吟
〈夜泛鑑湖懷歸〉
　　　姜夔
[
编辑
