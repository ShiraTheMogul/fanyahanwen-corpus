張掖妻康氏
[
编辑
]

按《松江府志》：「康氏，張掖妻。掖以督運遘疾，沒於毗陵道中。康年二十一，遺腹越月生男，荼苦萬狀，育之以衍宗祀。嘉靖壬午，郡人刑部郎中周珮表其墓。」
富于德妻張氏
[
编辑
]

按《松江府志》：「張氏，華亭人，工部烈之姊。年十七，歸憲副富好禮仲子于德。于德以父沒哀毀成疾不起。氏年二十，家務倥傯，徭役旁午，又值倭警，撐持拮据，備歷艱辛。撫一女，贅孝廉郁伯純為婿，以姪孫永祚為嗣。邑令旌之。」
楊子安妻褚氏
[
编辑
]

按《松江府志》：褚氏，十五保楊子安妻。倭難作，子安率
義捍蔽，死之。氏曰：「夫以義死，妾豈以不義生。」收屍殯
葬，苦節終身，年七十六。郡邑旌其門。

陸𦐂妻徐氏
[
编辑
]

按《松江府志》：「徐氏，七寶鎮陸𦐂妻。年二十，夫亡未葬。會倭掠七寶，縱火焚廬舍，氏拊膺哀悼，欲投火自焚，父掖止之，乘間收骸骨囊枕中，持枕以行。雖踉蹌避難，未嘗去手。倭退歸葬，守節終身。」
顧從仁妻沈氏
[
编辑
]

按《松江府志》：「沈氏，布政使沈恩女，歸庠生顧從仁。年二十五夫亡。值倭變，離亂播遷，備嘗艱苦。子九敘甫孩，撫之成立。年五十終。督學旌其門。」
秦環妻趙氏
〈張氏附〉
[
编辑
]

按《松江府志》：趙氏，秦環妻。年二十二，夫病危，囑其兄
璽曰：「婦少無子，我死只作一壙。」趙聞之，閉戶自縊。家
人驚救，遂截髮見志。夫死，璽尋亦喪。妻張氏年亦少，
與趙同苦守，妯娌煢煢，始終一節。督學旌其門。

杜時官妻唐氏

编辑

按《松江府志》：「唐氏，上海杜時官妻。時官少服賈，抱病將死，氏年二十三，無子，姑老，時官命之曰：『伯氏有子宗彝，可立為後以養姑』。及夫亡，家日貧，三遇大祲，氏苦操愈勵。年五十餘，以子貴，敕贈孺人​姜從謙妻鄭氏[编辑]按《松江府志》：「鄭氏年十七，歸邑庠生姜從謙。夫亡，氏年二十七，斷髮毀容，屏息一房，紡績以給薪水。值歲祲，姑令改節，氏悲，以帨就縊，救之復甦，守節至老。嘉靖間，郡邑表其閭。」

按《松江府志》：「陸氏，上海人，華亭徐從教妻。從教避倭吳興，鬱鬱不得志。一日，趣客與談，其言若訣。客去，面壁西向而死。氏上奉孀姑，攜十歲子益孫舁喪歸，葬訖，歸女與彭太學汝讓課益孫成大名，守節七十六年卒。」
張天恩妻周氏
[
编辑

按《松江府志》：「周氏，張天恩妻。年十九，夫亡未殮。值倭寇亂，族眾奔竄，氏日夜號泣不去，撤屋板為棺，權厝室中。寇退，手自經營，躬紡績，為夫營葬。一生未嘗解衣而寢，族子亦罕見其面。年九十六終。」
姚氏女
[
编辑
]

按《松江府志》：「姚氏女，孝廉簣仲女也。年十二，受黃籌幼子聘。未幾，籌子夭，父母將別許，女不從，或強委禽焉。女聞，持刀自刎，眾救止之，訟於官，太守方廉，司理吳時來嘆曰：『吾輩當扶植節義，可令抑其志耶』？」自是
獨扃一室，持齋事佛，終其身。

莊銓妻王氏
[
编辑
]

按《松江府志》：王氏，名妙真，莊銓妻。嫁五年夫亡，遺孤
世忠方三歲，舅姑欲奪其志，王抱世忠泣曰：「陰瑜妻以屍還陰尚病。其不早決，我當死莊氏戶內。」卒不為
奪。嘉靖戊申，直指饒天民廉得其實，與顧嶽妻秦氏、
曹雷妻陳氏、山禧妻某氏並奏於朝，值倭變未報。

宋氏女
[
编辑
]

按《松江府志》：「宋氏女，少參宋愷女也。生而端靜，父母鍾愛之。見布政葉萱孫周，聰慧能文，遂許配焉。周沒，女年十七，泣謂其母，欲往守喪以俟死。父母多方開諭，號慟彌甚。不得已，遂報葉，葉仍行納徵禮。卜日，萱夫婦並至，與女髻會。拜畢，遂更衰絰，迎周魂旌歸，居繐帳中凡四十六載，卒嘉靖丙午，與周合葬南賢村」祖塋之西，郡縣交旌其門。

張九經妻楊氏
〈臧氏附〉
[
编辑
]

按《武進縣志》：「楊氏，張九經妻。年二十二，經死，家貧無子。氏於臥榻側設几，置經冠履衣服，每旦哭拜食飲，必相對，如是四十餘年。有姊適同鄉巨室，姊亡，囑其夫曰：『吾死，汝必再娶。非吾妹不克撫吾子』。巨室賄其兄弟，謀娶之，楊斷髮以誓。其母召歸，復勸之。楊乘夜遽攜燈還，母挽之，絕袖而去。年六十五卒。經弟九緒」妻臧，年二十五而寡，亦無子。父母兄弟舅姑咸欲嫁
之，臧不從。與楊氏晝夜同哭泣，室中器物為涕淚淹
漬濯之，凝結如故。年六十四沒。嘉靖間，巡方使者表
其門為「埋葬。」

按《武進縣志》：「徐氏，楊天瑞妻。夫亡，與妾薛氏同勵志守節，撫孤成人。」
陳所安妻趙氏
[
编辑
]

按《武進縣志》：趙氏，陳所安妻。安家貧，舌耕餬口，氏織
屨佐之。未幾，安死，氏方少艾，撫一女二子，家徒四壁，
日拮据無戚容。嘗曰：「夫死子孤，自當食貧度日。」二子
以耕讀《蜚聲黌序》。氏年七十有三終。

陳履中妻郁氏
[
编辑

按《武進縣志》：「郁氏，陳履中妻。中早亡，遺一子，氏年二十七，家貧甚，惟事織紉以自給。或欲奪其志，不從。子既長，為之畢婚成家。事聞，旌其門。年六十九卒。」

按《武進縣志》：楊氏，翰林孔目瑞女。六歲，受朱復性聘。
十七，母疾革，而復性議贅，泣曰：「焉有當親疾而婚燕哉？母死，終三年喪，然後從前議成禮。」年二十，夫患疾，
二年死，氏哀毀不欲生，因無出。其翁姑又貧，父諷改
適，不從，屢自覓死。家人救甦，翁姑送歸，氏盡出奩資，
令夫兄弟賈田以助養翁姑。姑死克葬，年逾六十。嘉
靖間詔「旌表。」

孟澤民妻莫氏
〈談氏附〉
[
编辑

按《無錫縣志》：莫氏，孟澤民妻。年二十一，夫亡。媵妾談
年十七，莫泣謂曰：「我義無再辱，爾去可也。」談亦泣曰：
「主誠有志，妾奈何二心？且舍妾誰輔主者？」遂相與共
守，撫其孤五十年，家亦小裕。莫年八十有七，談亦七
十有九而卒。

按《無錫縣志》：「錢氏，周文妻。文有文翰，能丹青，所居齋多古名蹟奇器，有小清閟之目。亾何，遇道人授祕戲之術，以不檢為蘇州武弁所訟，遂亡命湖海。錢被羈紲榜掠幾死。一夕，文忽夜歸，妻泣謂曰：『今夕不留子，則夫婦恩絕。萬一留子而妊，何辭於官』？」文然其言，相
持慟哭而去。錢時年二十九，家已蕩盡，作網巾自給，
又四十年而終。通判周俊民斂葬之，題其墓曰「節婦塚。」

[
编辑

按《宜興縣志》：萬氏，邵寶妻，封君璵女吉之姊也。少聰
慧不群，八九歲時，父教以書，即能領略。十三，《孝經》《論
語》《列女傳》諸書，皆通習成誦。一日，父見炊籠，啟之，書
紙盈器，皆女所抄《列女傳》也。扣所自，對曰：「欲學書，仍默識此傳耳。」父大異之。年十六歸邵，六年而夫亡。有
一子，矢志撫孤，父母舅姑諳其素，不之強。力治女紅
鬻釵環，為孤卒業。舅姑沒，依兩弟居。子長，育一孫而
亡。嘆曰：「命如此。」仍撫孤孫，逾二十稔而卒，年七十二。
嘉靖七年旌表。
