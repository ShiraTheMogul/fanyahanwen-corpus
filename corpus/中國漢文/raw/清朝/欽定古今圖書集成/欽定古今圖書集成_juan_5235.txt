王贊
[
编辑
]

按《宋史王贊傳》：「贊，澶州觀城人。少為小吏，累遷本州馬步軍都虞候。周世宗鎮澶淵，每旬決囚，贊引律令辨析中理，問之，知其嘗事學問，即署右職。及即位，補東頭供奉官，累遷右驍衛將軍、三司副使。建隆初，始平李重進，太祖素知贊才幹，可委以完葺，即令知揚州。既行，舟覆于閶橋下溺死。」
王杲
[
编辑
]

按《宋史王杲傳》：「杲，齊州人。周顯德中，應募為卒，從世宗收三關，隸先鋒。宋初，征澤潞，平揚州，杲應選從行。既獲戰功，乃拔遷散指揮使。雍熙中，為龍衛右第二軍都虞候。契丹入寇，隸大將郭守文扞城，杲守北關。寇退，命督餉，遇賊河上，即按兵拒之，殺賊，奪所乘馬。守文上聞，得召見問狀，補部軍頭，領勤州刺史。至道」初，遷靈州副部署。咸平五年卒。

王繼勳
[
编辑
]

按《宋史王繼勳傳》，「繼勳，陝州平陸人，隸河中府為牙校。李守貞之叛，繼勳度守貞必敗，遂降周祖，奏補供奉官。廣順初，領汾州刺史，充晉、磁、隰等州緣邊巡檢，歷憲、麟、石、磁四州刺史。宋初，遷磁州團練使。坐境上用兵失律，荊罕儒陷陣，責授右監門衛率。初平荊襄，命權知道州。未幾，授本州刺史。及王師南伐，以為賀」州道行營馬步軍都監。繼勳有武勇，在軍陣常用鐵
鞭、鐵槊、鐵撾，軍中目為「王三鐵。」
王繼勳
[
编辑
]

按《宋史王繼勳傳》：「繼勳，彰德節度饒之子，孝明皇后同母弟也。美風儀，性兇率無賴。以后故，為內殿供奉官、都知、溪州刺史。建隆二年，改龍捷右廂都指揮使，尋領永州防禦使。四年，收復湖南，改領彭州防禦使，遷保寧軍節度觀察留後，領虎捷左右廂都虞候。繼勳所為多不法，乾德四年，為部曲所訟，詔中書鞫之」，
解兵柄，為彰國軍留後，奉朝請。繼勳自以失職，常怏
怏，專以臠割奴婢為樂，前後多被害。一日，天雨牆壞，
群婢突出守國門訴冤。上大駭，命中使就詰之，盡得
繼勳所為不法事。詔削奪官爵，配流登州。未至，改右
監門率府副率。開寶三年，命分司西京。繼勳殘暴愈
甚，太宗在藩邸，頗聞其事。及即位，人有訴者，命雷德
驤往鞫之。繼勳具伏，乃斬洛陽市。

王處訥
[
编辑
]

按《宋史王處訥傳》：「處訥，河南洛陽人。少時，有老叟至舍，煮洛河石如麪，令處訥食之，且曰：『汝性聰悟，後當為人師』。」又嘗夢人持巨鑑，星宿燦然滿中，剖腹納之
​
覺而汗洽，月餘心胸猶覺痛，因留意星曆占候之學，
深究其旨。晉末之亂，避地太原。漢祖時領節制，辟置
幕府。即位，擢為司天夏官正，出補許田令，召為國子
尚書博士，判司天監事。廣順中，遷司天少監。世宗以
舊曆差舛，俾處訥詳定。曆成未上，會樞密使王朴作
《欽天曆》以獻，頗為精密。處訥私謂朴曰：「此曆且可用，不久即差矣。」因指以示朴，朴深然之。至建隆二年，以
《欽天曆》謬誤，詔處訥別造新曆，經三年而成，為六卷。
太祖自製序，命為《應天曆》。處訥又以漏刻無準，重定
水稱及候中星分、五鼓時刻。俄遷少府少監。太平興
國初，改司農少卿，並判司天事。六年，又上《新曆》二十
卷，拜司天監。歲餘卒，年六十八。子熙元。

王昭素
[
编辑
]

按《宋史王昭素傳》：「昭素，開封酸棗人。少篤學不仕，有至行，為鄉里所稱，常聚徒教授以自給。李穆與弟肅及李惲皆常師事焉。昭素博通九經，兼究莊老，尢精《詩》《易》。開寶中，穆薦之朝，詔召赴闕，見於便殿，賜坐，令講《易》乾卦，因訪以民間事，昭素所言誠實無隱，上嘉之。以衰老求歸鄉里，拜國子博士致仕。年八十九，卒」於家。子仁著，亦有《隱德》。

王貽孫
[
编辑
]

按《宋史王溥傳》：「溥子貽孫，字象賢，少隨周祖典商、潁二州，署衙內都指揮使。顯德中，以父在中書，改朝散大夫，著作佐郎。宋初，遷金部員外郎，賜紫，累遷右司郎中。淳化中卒。」
王廷義
[
编辑
]

按《宋史王景傳》：「景子廷義，起家供奉官，改如京副使，以善騎射，周世宗擢為虎捷都虞候，領珍州刺史。宋初，改內外馬步軍副都軍頭。開寶二年，加領橫州團練使，從征太原，親鼓士乘城，獨免胄，矢中其腦而卒。」
王廷睿
[
编辑
]

按《宋史王景傳》：景子廷睿，好夸誕，每言「我當代王景之子。」聞者笑之，因目為「王當代。」
王嗣宗
[
编辑
]

按《宋史王嗣宗傳》：「嗣宗字希阮，汾州人。曾祖同節，寶鼎令。祖待價，汾州防禦推官。父夢證，成州軍事判官。嗣宗少力學，開寶八年登進士甲科，補秦州司寇參軍。太宗征河東，陳邊事，召赴行在，就改大理寺丞，通判睦州，徙河州。太宗遣武德卒潛察遠方事，嗣宗械送京師，因奏曰：『陛下不委任天下賢俊，猥信此輩以為耳目，臣竊不取』。」太宗怒其橫，遣使械嗣宗下吏。會
赦，復官。咸平三年，以漕運稱職，就拜太常少卿。踰年，
以右諫議大夫充三司戶部使，改鹽鐵使，出知并州，
兼并代部署，召拜御史中丞。嗣宗剛果率易，無所畏
憚，每進見，極談時事，或及人間細務，頗輕險好進。拜
耀州觀察使、知永興軍府，真宗作詩賜之。寇準為相，
命以左屯衛上將軍、檢校太尉致仕。五年卒，諡景莊。

王熙元
[
编辑
]

按《宋史王處訥傳》：「處訥子熙元，幼習父業，開寶中，補司天曆筭。端拱初，改監丞，累遷太子洗馬兼春官正，加殿中丞。景德中，同判監事。東封，隨經度制置使詣祠所，禮畢，授權知司天少監。祠汾陰，真拜少監。奉詔於後苑纘陰陽事十卷上之，真宗為製序，賜名《靈臺祕要》。玉清昭應宮成，以祗事之勤，授司天監。坐擇日差謬」，降為少監，以目疾，改將作監，致仕。天禧二年卒，
年五十八。

王濟
[
编辑
]

按《宋史王濟傳》：「濟字巨川，其先真定人。祖卿，有詞辨，趙王鎔召置幕府。鎔政衰，卿懼禍，避地深州饒陽，遂為縣人。父恕，後唐時童子及第，開寶中知秀州。會盜起，城陷，為盜所殺，將并害濟。濟伏柩號慟，賊義之，捨去。濟攜父骨匿山谷間。既而官軍大集，濟脫身謁其帥朱乙，陳討賊之計。乙嘉之，遺以束帛，奏假驛置遣」歸，乃護喪還饒陽。雍熙中，上書自陳死事之孤，得試
學士院，補龍溪主簿，再調胙城尉，徙臨河主簿。轉運
使王嗣宗被詔舉法官，以濟名聞，遷光祿寺丞，改刑
部詳覆官，通判鎮州，就遷太子中舍。召判登聞鼓院，
拜監察御史，改鹽鐵判官，復為監察御史、通判河南
府。景德初，徙知河中府，召拜工部員外郎。三年，判司
農寺。四年，拜本曹郎中，出知杭州。大中祥符三年，徙
知洪州，卒。濟頗涉經史，好讀《左氏春秋》，性剛直，無所
畏避。子孝傑，國子博士。

王延德
[
编辑
]

按《宋史王延德傳》：「延德，開封東明人。曾祖芝，濮陽令。祖璋，相州錄事參軍。父溫，晉末契丹內寇，溫率鄉豪捍蔽境內，里人德之。宣祖掌畿甸兵，與溫厚善，延德方總角，宣祖愛其謹重，召置左右。太宗尹京，署為親校，專主庖膳，尢被倚信。太平興國初，授御廚副使，遷正使，加尚食使，俄領薊州刺史，改皇城使，掌御輦院」、
左藏庫。端拱初，領本州團練使。至道二年，加領平州
防禦使。真宗嗣位，改領懷州。永熙復土，提點緣路供
​
頓。咸平初，出知華州。上幸大名，為東京舊城都巡檢
使。明年，以風痹請告，遣還本郡。是冬，卒。子應昌，莊宅
使、端州團練使。

王繼恩
[
编辑
]

按《宋史王繼恩傳》：「繼恩，陝州陝人。周顯德中，為內班高品。初養於張氏，名德鈞。開寶中，求復本宗，太祖召見，許之，因賜名焉。累為內侍行首。九年，改裏面內班小底都知，充永昌陵使。太平興國三年，遷宮苑使。久之，領河州刺史，掌軍器弓槍庫。雍熙中，為天雄軍駐泊都監。四年，遣將北伐，又為排陣都監，屯中山，改皇」城使。端拱初，領本州團練使，又為鎮、定、高陽關兩路
排陣鈐轄。淳化五年，李順亂成都，命為劍南兩川招
安使，率兵討之。進領順州路防禦使。真宗惡其朋結，
黜為右監門衛將軍，均州安置。咸平二年，卒於貶所。
大中祥符三年，特詔追復官爵。子懷珪，轉入內高班。

王漢忠
[
编辑
]

按《宋史王漢忠傳》：「漢忠，字希傑，徐州彭城人也。少豪蕩，有膂力。西至京師，太宗在藩邸，召見，奇其材，署左右。及即位，補殿前指揮使，累遷內殿直都知。端拱初，出為賓州團練使，歷冀、貝二州部署，徙天雄軍。淳化初，徙定州。五年，遷殿前都虞候。真宗即位，自中山召歸，俄復出為高陽關都部署，進領威塞軍、保靜軍節」度。五年，罷西面經略使，命為邠寧、環慶兩路都部署。
坐違詔，責為左屯衛上將軍，出知襄州。卒，贈太尉。

王懷隱

编辑

按《宋史王懷隱傳》：「懷隱，宋州睢陽人。初為道士，住京城建隆觀，善醫診。太宗尹京，懷隱以湯劑祗事。太平興國初，詔歸俗，命為尚藥奉御，三遷至翰林醫官，後數年卒。」
王仁睿
[
编辑

按《宋史王仁睿傳》：「仁睿，不知何許人。年十餘歲，事太宗於晉邸，服勤左右，甚淳謹。及即位，宣傳指揮頗稱旨。歷入內小底都知、洛苑副使，命典宮闈出納之命。雍熙四年卒。」
王超
[
编辑
]

按《宋史王超傳》：「超，趙州人。太宗尹京，召置麾下。及即位，以隸御龍直。淳化二年，累遷至河西軍節度使、殿前都虞候。真宗嗣位，以翊戴功，加檢校太傅，領天平軍節度。從幸大名，與都虞候張進並為先鋒，又帥鎮、定、高陽關三路。契丹入邊，與戰於遂城西，俘馘二萬計。宰相言超材堪將帥，遂以帥定州路行營，尋加鎮」、
定、高陽關三路都部署。景德初，上親巡澶淵，召赴行
在。緩期，責為崇信軍節度使，徙知河陽，又移鎮建雄、
知青州，卒，追封魯國公，諡「武康。」
王榮
[
编辑
]

按《宋史王榮傳》：「榮，定州人。父洪嗣，仕晉為本州十縣遊奕使。榮少有膂力，事瀛州馬仁瑀為廝役。太宗在藩邸，得隸左右。即位，補殿前指揮使，加御前忠佐馬步軍都軍頭，領懿州刺史。坐受秦王廷美宴勞，出為濮州馬軍教練使。未行，馬仁瑀子告榮與秦王親吏善，坐削籍流海島。雍熙中，召還為副軍頭。端拱初，累」遷龍衛都指揮使、領羅州團練使，率兵戍遂城。召拜
侍衛馬軍都虞候、峰州觀察使。出為定州行營都部
署。榮麤率所為不中理，母老不迎養，太宗聞而怒，責
授右驍衛大將軍，遷右羽林軍大將軍。真宗即位，領
獎州刺史，尋授濱州防禦使，遷涇原儀渭駐泊部署。
咸平二年，車駕北征，召為貝、冀行營副都部署。師旋，
復還涇原。明年，援送靈武芻糧，疏於智略，為蕃寇所
劫，除名、配均州。六年，起為左衛將軍。景德初，命為黃
河南岸都巡檢使。二年，遷左神武軍大將軍、領恩州
刺史。郊祀，改左龍武軍、領達州團練使。大中祥符中，
遷左衛大將軍，領昌州防禦使。六年，朝太清宮，命為
河南府。九年，卒，官。其一子榮善射，嘗引強注屋棟，矢
入木數寸，時人目為「王硬弓。」
王繼升
[
编辑

按《宋史王繼升傳》：「繼升，冀州阜城人。性純質謹，愿事太宗於藩邸，太宗信任之。即位，補供奉官，累遷軍器庫副使。陳洪進來獻漳、泉之地，以繼升為泉州兵馬都監。會游洋洞民萬餘叛攻泉，繼升夜擊破之，擒其魁，械送闕下。召還，遷軍器庫使，知諸道陸路發運事。端拱初，改領本州團練使，卒。」
